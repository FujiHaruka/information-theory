                      ergodic_shiftZ #

                      Two-sided shift ergodicity via cylinder approximation + ℕ-factor transfer.

                      For a shiftZ-invariant measurable set A ⊆ (ℤ → α):

                      1. Approximate A by a finite cylinder t (over some F ⊆ ℤ) up to ε in symmetric difference — via MeasureTheory.exists_measure_symmDiff_lt_of_generateFrom_isSetRing on measurableCylinders (a set ring generating the product σ-algebra).
                      2. For k large enough that F + k ⊆ ℕ, the shifted cylinder shiftZ^[k]⁻¹' t is a cylinder over a nonnegative index set, hence lies in cylinderEvents {i : ℤ | 0 ≤ i}.
                      3. By measure-preservation of shiftZ^[k] and shift-invariance of A, μZ(A Δ shiftZ^[k]⁻¹' t) = μZ(A Δ t) < ε, so A is approximable to within any ε by sets in cylinderEvents {i : ℤ | 0 ≤ i}.
                      4. Hence A is μZ-a.e. equal to some A' = natProj⁻¹' B for measurable B, and B is shiftN-invariant mod-null on μ.map forwardEmbed.
                      5. (ℕ → α, shiftN, μ.map forwardEmbed) is ergodic (forward ergodic_of_ergodic_semiconj from (Ω, T, μ) via forwardEmbed).
                      6. Conclude μZ(A) = μN(B) ∈ {0, 1}.
