      Slepian–Wolf conditional typical slice #

      This file publishes the conditional typical slice size bound, the key new ingredient for the full Slepian–Wolf rate region (Cover–Thomas Theorem 15.4.1). For a fixed Y-block y : Fin n → β, the X-fiber of the jointly typical set is bounded in size by exp(n · (H(X|Y) + 2ε)), where H(X|Y) := H(X, Y) - H(Y).

      Main definitions #

      • conditionalTypicalSlice μ Xs Ys n ε y — the fiber {x : Fin n → α | (x, y) ∈ jointlyTypicalSet μ Xs Ys n ε}.

      Main statements #

      • conditionalTypicalSlice_card_le — the slice size is bounded by exp(n · (H(X, Y) - H(Y) + 2ε)).

      Implementation notes #

      • Each fiber element x makes (x, y) jointly typical, so the joint sequence i ↦ (x i, y i) lies in typicalSet μ (jointSequence Xs Ys) n ε and each sample has probability at least exp(-n · (H(X, Y) + ε)) by typicalSet_prob_ge. Summed over the fiber this is at most Pr[Yⁿ = y], which for Y-typical y is at most exp(-n · (H(Y) - ε)) by typicalSet_prob_le.
