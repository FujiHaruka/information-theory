      The random Gaussian codebook #

      The random codebook law for AWGN achievability (Cover–Thomas 9.2): M codewords, each with n i.i.d. 𝒩(0, σsq) components, carried by Fin M → Fin n → ℝ and built as a two-stage Measure.pi so that it is definitionally equal to AwgnCode.encoder.

      Main definitions #

      • gaussianCodebook M n σsq — the random codebook law.

      Main statements #

      • gaussianCodebook_codeword_law — projecting onto a single codeword index gives the inner i.i.d. Gaussian product measure.
      • gaussianCodebook_indepFun_codewords — distinct codewords are independent.

      source
      (M n : ℕ) (σsq : NNReal) :
      MeasureTheory.Measure (Fin M → Fin n → ℝ)

      The random Gaussian codebook: M codewords, each n i.i.d. components X(m, i) ∼ 𝒩(0, σsq), built as a two-stage Measure.pi. The concrete carrier type Fin M → Fin n → ℝ matches AwgnCode.encoder definitionally, so no measurable-equivalence transport is needed.
