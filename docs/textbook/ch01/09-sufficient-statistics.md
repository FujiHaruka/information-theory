# 1.9 充足統計量

前節のデータ処理不等式は「加工すると情報は減る（$\le$）」と言っていた。では、
**減らない**のはどういうときか。この等号の場合を特徴づけるのが本節の主題である。

動機は統計にある。データ $X$ からパラメータ $\theta$ を推定するとき、$X$ をそのまま
持ち歩くのは大きい。標本平均や最大値のように、データを要約する関数 $T$ を **統計量**
という。ある統計量の値 $T(X)$ だけ持っていれば $\theta$ について $X$ と同じだけ分かる、
という状況があれば、以降の議論は $T(X)$ の上でやってよい。このとき $T$ を
**充足統計量** という。

一つ断っておく。以下では $\theta$ を確率変数として扱う。統計では未知パラメータを定数と
みなすことが多いが、$I(\theta; X)$ のような情報量は同時分布に対して定まる量なので、
$\theta$ 自身に分布がなければ書けない。そこで $\theta$ に分布を一つ与え、$(\theta, X)$ を
同時分布をもつ組として扱う。以下で使うのはその同時分布の構造だけで、$\theta$ の分布の
具体形は使わない。

**典型例.** コインを $n$ 回投げて表裏の列 $X = (X_1,\dots,X_n)$ を得たとする。表の確率
$\theta$ を推定したいなら、どの順番で表が出たかは要らない。表の**回数**
$T(X) = \sum_i X_i$ だけあれば十分である。実際、表の回数を $k$ と固定してしまえば、
その条件のもとで列 $X$ がどれになるかは $\binom{n}{k}$ 通りの等確率で、$\theta$ に
まったく依存しない。$T$ を知ったあとの $X$ の分布が $\theta$ に依存しない——これが
「$T$ が $\theta$ の情報をすべて吸い上げている」ということであり、以下の定義が
形式化しているのはこの状況である。

## 定義

::: definition 1.9.1 充足統計量
統計量 $T(X)$ が $\theta$ に対し**充足的**であるとは、$\theta \to T(X) \to X$ が
マルコフ連鎖（定義 1.8.3）をなすことをいう。すなわち $T(X)$ を与えたとき $\theta$ と
$X$ が条件付き独立になること（$\theta \perp X \mid T(X)$）である。
:::

マルコフ連鎖 $\theta \to T(X) \to X$ は「$\theta$ から $X$ への影響が、
すべて $T(X)$ を経由している」と読む。上のコインの例なら、$\theta$ が決めているのは
表の回数の分布だけで、回数さえ決まれば列の並びは $\theta$ と無関係に決まる、という
構造がそのまま矢印になっている。$X$ から $T(X)$ は関数（情報が減る向き）なのに、
$\theta$ から見ると $T(X)$ で十分——この非対称さが「充足」の内容である。

## 情報の保存

::: theorem 1.9.2
$T$ が充足的なら
$$
I(\theta; X) \;=\; I\big(\theta; T(X)\big).
$$
:::

::: proof
一般に後処理不等式（定理 1.8.2）から $I(\theta; T(X)) \le I(\theta; X)$。一方、
充足性すなわちマルコフ連鎖から DPI のマルコフ版（定理 1.8.4）が逆向き
$I(\theta; X) \le I(\theta; T(X))$ を与える。両者を挟めば等号。
:::

一般のデータ処理は情報を減らしうる（$\le$）。充足統計量はその等号がちょうど
成り立つ「情報を一切落とさない要約」である。十分統計量を使えば、推定の議論を低次元の
$T(X)$ 上で行ってよい、という実用上の御利益がある。

::: formalization-note
教科書は充足性を因子分解 $p(x\mid\theta) = g(T(x),\theta)\,h(x)$
（Neyman–Fisher）で導入することが多い。本ライブラリは、定理 1.8.4 の結論に直結する
**マルコフ連鎖形**でまず定義し（因子分解形を直接 def 化すると条件付き分布の
$\theta$-非依存性を経由する長い橋渡しを要するため）、因子分解形
`IsSufficientStatisticFactorized` との**同値** `isSufficient_iff_factorized` を別途
形式化している。同値は Mathlib の条件付き独立性補題（標準ボレル機構）を経由する。
:::
