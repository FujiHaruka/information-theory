# 4.5 McMillan の不等式

4.1 節で，語頭符号は一意復号可能な符号の真に狭いクラスであることを見た（例 4.1.5）．狭いクラスに制限しているのだから，読みながら区切れるという便利さの代わりに，平均符号長で損をしていてもおかしくない．本節はそうではないことを示す．鍵は，定理 4.2.1 の不等式が語頭性をまったく使わずに一意復号可能性だけから出る，という点にある．

証明では二項定理，すなわち実数 $\delta > 0$ と整数 $k \ge 0$ に対して $(1+\delta)^k = \sum_{j=0}^{k} \binom{k}{j} \delta^j$ が成り立つことを既知として使う．

## 一意復号可能な符号への拡張

::: theorem 4.5.1 McMillan の不等式
$\mathcal X$ を有限アルファベット，$D \ge 2$ を整数とする．$c$ を $\mathcal X$ 上の一意復号可能な $D$ 元情報源符号，$\ell(x)$ をその符号語長とすると
$$
\sum_{x \in \mathcal X} D^{-\ell(x)} \;\le\; 1
$$
が成り立つ．
:::

::: proof
$\mathcal X$ が空なら左辺は $0$ で主張は成り立つから，空でないとしてよい．$K := \sum_{x} D^{-\ell(x)}$，$\ell_{\max} := \max_{x} \ell(x)$ とおく．定義 4.1.1 より符号語は空でないので $\ell(x) \ge 1$ であり，$\ell_{\max} \ge 1$ である．

$K$ の冪を長さごとに数え直す．整数 $k \ge 1$ をとると，積を展開して
$$
K^k \;=\; \sum_{(x_1, \dots, x_k) \in \mathcal X^k}
  D^{-(\ell(x_1) + \cdots + \ell(x_k))}
$$
である．列 $(x_1, \dots, x_k)$ に対して $c^*(x_1, \dots, x_k)$ の長さはちょうど $\ell(x_1) + \cdots + \ell(x_k)$ であり，この値は $k$ 以上 $k\,\ell_{\max}$ 以下である．そこで，$c^*$ での像の長さが $m$ になる $\mathcal X^k$ の元の個数を $N(m)$ と書くと
$$
K^k \;=\; \sum_{m = k}^{k\,\ell_{\max}} N(m)\, D^{-m}
$$
となる．

一意復号可能性を数え上げに変える．$c^*$ は単射だから，像の長さが $m$ である $\mathcal X^k$ の元は，長さ $m$ の相異なる列に写る．長さ $m$ の列は $D^m$ 本しかないので $N(m) \le D^m$ であり，上の和の各項は $1$ 以下である．項の個数は $k\,\ell_{\max} - k + 1$ だから
$$
K^k \;\le\; k\,\ell_{\max} - k + 1 \;\le\; k\,\ell_{\max}
$$
を得る．これがすべての $k \ge 1$ で成り立つ．

$K$ が $1$ を超えられないことを見る．$K > 1$ として $\delta := K - 1 > 0$ とおく．二項定理の展開はすべての項が正だから，$k \ge 2$ のとき $j = 2$ の項だけを残して
$$
K^k \;=\; (1 + \delta)^k \;\ge\; \binom{k}{2} \delta^2 \;=\; \frac{k(k-1)}{2}\, \delta^2
$$
である．上の評価と合わせると $\frac{k(k-1)}{2}\delta^2 \le k\,\ell_{\max}$，すなわち $(k-1)\,\delta^2 \le 2\,\ell_{\max}$ がすべての $k \ge 2$ で成り立つことになる．左辺は $k$ とともにいくらでも大きくなるので，これは矛盾である．よって $K \le 1$ である．
:::

::: formalized
`kraftSum_le_one_of_uniquelyDecodable` (`InformationTheory/Shannon/McMillanKraftBridge.lean`)
:::

::: formalization-note
形式化は，定義 4.1.2 の一意復号可能性を二つに分けて仮定している．符号語の集合に対する述語（符号語を並べてつないだ列が，並べ方が違えば違う列になる）と，写像 $c$ が単射であることの二つで，合わせると定義 4.1.2 と同じことを言っている．ただし，定義 4.1.2 の一意復号可能性からこの二つを取り出すには $c$ の単射性が要り，それは命題 4.1.3 の後半にあたるので，対応する宣言はない．また，証明の中核にあたる数え上げの定理は Mathlib にあり，形式化はそれを本書の枠組みへつないでいる．
:::

証明の中身は，語頭符号のときの数え上げ（定理 4.2.1）とは別のものである．あちらは深さ $\ell_{\max}$ で場所が重ならないことを一度数えただけだったが，こちらは $k$ 文字の列をまとめて符号化し，$k$ を大きくして矛盾を出す．定理 4.2.1 が語頭性を $1$ 回の数え上げに直せたのに対し，一意復号可能性から直に取り出せるのは「$k$ 文字ぶんの列が相異なる列に写る」という形で，本節の証明はそれを $k$ について効かせている．$K > 1$ なら $K^k$ は指数で増えるのに，長さで数えた上界は $k$ について一次でしか増えないという，増え方の差が矛盾を生んでいる．

::: corollary 4.5.2
$\mathcal X$ を有限アルファベット，$D \ge 2$ を整数とし，$X$ を $\mathcal X$ 上に分布 $p$ をもつ確率変数とする．$\mathcal X$ 上の任意の一意復号可能な $D$ 元情報源符号 $c$ について $H_D(X) \le L(c)$ である．
:::

::: proof
$c$ の符号語長を $\ell$ とすると，定理 4.5.1 より $\ell$ は Kraft の不等式を満たす．定理 4.3.2 を当てて $H_D(X) \le \sum_x p(x) \ell(x) = L(c)$ を得る．
:::

::: formalization-note
下界には対応する宣言があるが，すべての記号の確率が正である場合について述べてあるので，本文の主張をそのまま覆ってはいない．宣言は `entropyD_le_expectedLength_of_uniquelyDecodable` (`InformationTheory/Shannon/McMillanKraftBridge.lean`) である．
:::

::: corollary 4.5.3
$\mathcal X$ を有限アルファベット，$D \ge 2$ を整数とする．$\mathcal X$ 上の一意復号可能な $D$ 元情報源符号 $c$ に対し，$\mathcal X$ 上の $D$ 元語頭符号で，各 $x$ の符号語長が $c$ のそれに等しいものが存在する．
:::

::: proof
$c$ の符号語長を $\ell$ とする．定義 4.1.1 より $\ell(x) \ge 1$ であり，定理 4.5.1 より $\sum_x D^{-\ell(x)} \le 1$ である．定理 4.2.2 を当てればよい．
:::

::: formalization-note
系 4.5.3 に対応する単独の宣言はない．定理 4.5.1 の形式化と定理 4.2.2 の形式化を組み合わせれば得られるが，その組み合わせを書いた宣言はない．二つの宣言は符号アルファベットの表し方も違っていて，前者は大きさ $D$ の有限集合として一般にとり，後者は $0$ から $D-1$ までの整数に固定している．この取り替えも形式化では別に要る．
:::

::: example 4.5.4 語頭符号への置き換え
例 4.1.5 の符号は一意復号可能だが語頭符号ではない．その符号語長の組は $\ell(1) = 1$，$\ell(2) = 2$，$\ell(3) = 3$ であり，同じ長さの組をもつ二元語頭符号として例 4.1.4 の $c(1), c(2), c(3)$ がとれる．$\mathcal X = \{1, 2, 3\}$ 上のどの分布についても，二つの符号の平均符号長は等しい．
:::

::: proof
例 4.1.5 の符号語は $0$，$01$，$011$ で，長さは $1, 2, 3$ である．例 4.1.4 の $c(1) = 0$，$c(2) = 10$，$c(3) = 110$ も長さが $1, 2, 3$ で，例 4.1.4 の証明よりこの三つのあいだに語頭の関係はない．平均符号長は定義 4.1.1 より符号語長の組と分布だけで決まるから，二つの符号で同じ値になる．
:::

系 4.5.2 と系 4.3.3 を並べると，下界 $H_D(X)$ は語頭符号に限っても一意復号可能な符号まで広げても同じである．系 4.5.3 はその理由をもっと直接に述べていて，一意復号可能な符号は，長さを一切変えずに語頭符号に取り替えられる．読みながら区切れるという性質は，ただで手に入るということである．したがって最小の平均符号長を求める問題は，Kraft の不等式を満たし，かつすべての $x$ で $\ell(x) \ge 1$ である長さの組 $\ell$ のうちで $\sum_x p(x)\ell(x)$ を最小にするものを探す問題に，何も失わずに書き換えられる．系 4.2.5 より，この二つの条件を満たす長さの組はちょうど $D$ 元語頭符号の符号語長の組である．次節は，符号アルファベットが $2$ 文字の場合について，その最小を与える手続きを作る．
