# 4.3 平均符号長の下界

4.2 節で，符号を作る問題は長さの組を選ぶ問題に置き換わった．残っているのは最小化である．Kraft の不等式を満たす $\ell$ すべてにわたって $\sum_x p(x)\ell(x)$ を小さくしたい．本節はその値を下から抑える．答えはエントロピーで，しかも下界を与える道具は第1章の情報不等式ただ一つである．

符号アルファベットが $D$ 文字あるので，比べる相手も底を $D$ にとったエントロピーになる．先に記号を用意する．

::: definition 4.3.1 底を $D$ にとったエントロピー
$\mathcal X$ を有限アルファベット，$D \ge 2$ を整数とし，$X$ を $\mathcal X$ 上に分布 $p$ をもつ確率変数とする．
$$
H_D(X) \;:=\; -\sum_{x \in \mathcal X} p(x) \log_D p(x)
$$
と書く．$p(x) = 0$ の項は定義 1.1.1 と同じく $0$ と約束する．
:::

$\log_D t = \log t / \log D$ だから $H_D(X) = H(X) / \log D$ であり，新しい量が増えたわけではない．エントロピーを「$D$ 文字を単位として測り直した」だけである．$D = 2$ なら $\log D = 1$ なので $H_2(X) = H(X)$ である．

::: formalized
`entropyD` (`InformationTheory/Shannon/ShannonCode/Basic.lean`)
:::

## 下界

::: theorem 4.3.2
$\mathcal X$ を有限アルファベット，$D \ge 2$ を整数とし，$X$ を $\mathcal X$ 上に分布 $p$ をもつ確率変数とする．$\ell : \mathcal X \to \{0, 1, 2, \dots\}$ が Kraft の不等式を満たすならば
$$
H_D(X) \;\le\; \sum_{x \in \mathcal X} p(x)\,\ell(x)
$$
である．等号が成り立つのは，すべての $x \in \mathcal X$ で $p(x) = D^{-\ell(x)}$ となるとき，かつそのときに限る．
:::

::: proof
$\mathcal X$ が空なら両辺とも $0$ で，等号条件も空虚に成り立つ．以下 $\mathcal X$ は空でないとし，$K := \sum_{x} D^{-\ell(x)}$ とおく．各項は正だから $K > 0$ であり，仮定より $K \le 1$ である．$r(x) := D^{-\ell(x)} / K$ とおくと，$r$ は $\mathcal X$ 上の分布で，すべての $x$ で $r(x) > 0$ である．

差を二つの部分に分ける．定義 4.3.1 より
$$
\sum_{x} p(x)\ell(x) \;-\; H_D(X)
  \;=\; \sum_{x} p(x)\Big(\ell(x) + \log_D p(x)\Big)
  \;=\; \sum_{x} p(x) \log_D \frac{p(x)}{D^{-\ell(x)}}
$$
である（$p(x) = 0$ の項はどの表示でも $0$ である）．$D^{-\ell(x)} = K\,r(x)$ を入れ，$\sum_x p(x) = 1$ を使うと
$$
\sum_{x} p(x)\ell(x) \;-\; H_D(X)
  \;=\; \sum_{x} p(x) \log_D \frac{p(x)}{r(x)} \;+\; \log_D \frac1K
$$
となる．

二つの項がどちらも非負であることを見る．$\log_D t = \log t / \log D$ と $\log D > 0$ より
$$
\sum_{x} p(x) \log_D \frac{p(x)}{r(x)}
  \;=\; \frac{1}{\log D} \sum_{x} p(x) \log \frac{p(x)}{r(x)}
$$
であり，右辺の和は分布 $p$ と分布 $r$ の相対エントロピーだから，定理 1.6.1 より $0$ 以上である．また $0 < K \le 1$ より $\log_D (1/K) \ge 0$ である．よって差は $0$ 以上で，不等式が従う．

等号を調べる．差が $0$ になるのは二つの項がともに $0$ のときに限る．定理 1.6.1 の等号条件より，第 1 項が $0$ になるのは $p = r$ のとき，かつそのときに限る．第 2 項が $0$ になるのは $K = 1$ のとき，かつそのときに限る．両方が成り立てば $p(x) = r(x) = D^{-\ell(x)}$ である．逆にすべての $x$ で $p(x) = D^{-\ell(x)}$ ならば $K = \sum_x p(x) = 1$ かつ $r = p$ となり，二つの項はどちらも $0$ になる．
:::

::: formalized
$\sum_x D^{-\ell(x)}$ にあたる `kraftSum`，下界 `entropyD_le_expectedLength_of_kraft` (`InformationTheory/Shannon/ShannonCode/Basic.lean`)
:::

::: formalization-note
形式化の下界は，すべての記号の確率が正である場合について述べてある（本文の主張はこの限定を必要としない）．等号条件に対応する宣言はない．
:::

証明の要点は一つだけである．Kraft の不等式を満たす長さの組 $\ell$ は，$D^{-\ell(x)}$ を正規化すれば分布 $r$ を作る．そして平均符号長と $H_D(X)$ の差は，真の分布 $p$ とその $r$ との隔たりに，正規化で捨てたぶん $\log_D(1/K)$ を足したものになる．どちらも非負なので下界が出る．第1章 1.6 節で相対エントロピーを「$q$ だと思い込んで符号化したために余計に払う符号長」と読んだが，本節はその読み方を字義どおりに実現している．長さの組 $\ell$ を選ぶことが分布 $r$ を信じることに対応し，信じ違いのぶんがそのまま超過符号長になる．

::: corollary 4.3.3
$\mathcal X$ を有限アルファベット，$D \ge 2$ を整数とし，$X$ を $\mathcal X$ 上に分布 $p$ をもつ確率変数とする．$\mathcal X$ 上の任意の $D$ 元語頭符号 $c$ について $H_D(X) \le L(c)$ である．
:::

::: proof
$c$ の符号語長を $\ell$ とする．定義 4.1.1 より符号語は空でないから $\ell(x) \ge 1$ であり，定理 4.2.1 より $\sum_x D^{-\ell(x)} \le 1$ である．よって $\ell$ は Kraft の不等式を満たし，定理 4.3.2 より $H_D(X) \le \sum_x p(x)\ell(x) = L(c)$ を得る．
:::

::: formalization-note
系 4.3.3 に対応する単独の宣言はない．定理 4.2.1 の側が形式化されていないためで，形式化されているのはより広い一意復号可能な符号についての形（4.5 節）のほうである．
:::

::: example 4.3.4 三つの記号が等確率のとき
$D = 2$，$\mathcal X = \{1, 2, 3\}$ とし，$X$ は $\mathcal X$ 上の一様分布に従うとする．Kraft の不等式を満たすどの $\ell : \mathcal X \to \{0, 1, 2, \dots\}$ についても，定理 4.3.2 の等号は成り立たない．一方，$\ell(1) = 1$，$\ell(2) = \ell(3) = 2$ は Kraft の不等式を満たし，その平均符号長は $5/3$ である．下界 $H_2(X) = \log 3$ との差は $0.0817\ldots$ である．
:::

::: proof
定理 4.3.2 の等号条件は，すべての $x$ で $p(x) = 2^{-\ell(x)}$ となることを要求する．ここで $p(x) = 1/3$ であり，$\ell(x)$ が整数であるかぎり $2^{-\ell(x)}$ が $1/3$ になることはないから，等号は成り立たない．

後半は計算である．$2^{-1} + 2^{-2} + 2^{-2} = 1$ だから $\ell$ は Kraft の不等式を満たし，平均符号長は $\frac13(1 + 2 + 2) = \frac53$ である．例 1.1.3 より $H(X) = \log 3$ で，$D = 2$ だから $H_2(X) = \log 3 = 1.5849\ldots$ であり，$5/3 = 1.6666\ldots$ との差が $0.0817\ldots$ になる．
:::

定理 4.3.2 が言っているのは「どんな符号でも $H_D(X)$ を下回れない」ことだけで，$H_D(X)$ に届く符号があるとは言っていない．等号が成り立つのは，確率がちょうど $D$ の冪の逆数に並んでいるという特別な場合に限る（例 4.1.4 がそれで，例 4.3.4 はそうでない）．一般には $\log_D(1/p(x))$ を整数に丸めるぶんだけ損をする．その損が高々 $1$ 文字で収まることを，次節で符号を一つ作って示す．
