# 4.6 Huffman 符号の最適性

4.5 節までで問題は次の形に整理された．Kraft の不等式を満たし，かつすべての $x$ で $\ell(x) \ge 1$ である長さの組のうち，$\sum_x p(x)\ell(x)$ を最小にするものを求めよ．定理 4.3.2 はこの最小値が $H_D(X)$ 以上であることを，定理 4.4.4 は $H_D(X) + 1$ 未満であることを教えたが，最小値そのものはまだ分かっていない．例 4.4.5 で見たとおり，Shannon 符号はその最小を与えるとは限らない．本節は最小を与える長さの組を，確率を見比べるだけの手続きで作る．

本節では $D = 2$ に固定する．一般の $D$ にも同じ考えで拡張できるが，一度に併合する個数の調整が要るので，本書は二元の場合だけを扱う．

## 手続き

::: definition 4.6.1 Huffman 符号語長
$\mathcal X$ を $2$ 個以上の文字からなる有限アルファベット，$p$ を $\mathcal X$ 上の分布ですべての $x \in \mathcal X$ で $p(x) > 0$ を満たすものとする．長さの組 $\ell^{\mathrm H}$ を，アルファベットの大きさについての再帰で次のように定める．

$|\mathcal X| = 2$ のときは，二つの文字のどちらにも値 $1$ を与える．

$|\mathcal X| \ge 3$ のときは，$p(u) \le p(z)$ がすべての $z \in \mathcal X$ で成り立つ文字 $u$ と，$p(v) \le p(z)$ が $u$ 以外のすべての $z$ で成り立つ文字 $v \ne u$ をとる．$u$ と $v$ を新しい $1$ 文字 $w$ に置き換えたアルファベットを $\mathcal X'$，その上の分布 $p'$ を $p'(w) := p(u) + p(v)$，$p'(z) := p(z)$（$z \ne w$）で定める．$(\mathcal X', p')$ に対して定まる長さの組を $\ell'$ として
$$
\ell^{\mathrm H}(u) := \ell'(w) + 1, \qquad
\ell^{\mathrm H}(v) := \ell'(w) + 1, \qquad
\ell^{\mathrm H}(z) := \ell'(z) \quad (z \ne u, v)
$$
と定める．こうして得られる $\ell^{\mathrm H}$ を **Huffman 符号語長** と呼ぶ．確率が等しい文字があって $u$ と $v$ の選び方に任意性があるときは，そのいずれから得られる組も Huffman 符号語長と呼ぶ．
:::

手続きの読み方は素直で，確率のいちばん小さい二つの文字を一つにまとめる操作を，文字が二つになるまで繰り返している．まとめられるたびに，そのまとまりに入っている文字の符号語が一つずつ伸びる．最後に残った二つに長さ $1$ を与える操作も，二つを一つにまとめる操作を一度行ったと数えれば，符号語長の勘定は一つの規則にまとまる．すなわち各文字の符号語長は，その文字を含むまとまりが併合に加わった回数に等しい．確率の小さい文字ほど早い段階でまとめられる．4.2 節の言葉でいえば，これは短い符号語から場所を詰めていくのとは逆向きで，いちばん狭い幅を確率の小さい二つに先に与え，その二つが占める場所をまとめて一つの幅として扱い直していく作り方である．

::: formalized
`huffmanLength` (`InformationTheory/Shannon/Huffman/Length.lean`)
:::

::: formalization-note
形式化はこの手続きを，文字の集まりと重みの組を並べた多重集合の上の再帰として書いている．確率が等しいときの選び方を一つに決めるため，アルファベットに全順序を入れて優先順位を添えてあり，形式化が与える長さの組は，本文が許す組の一つにあたる．本節の形式化ポインタはどれもその一つについての主張で，選び方すべてを覆ってはいない．
:::

::: example 4.6.2 五つの記号
$D = 2$，$\mathcal X = \{1, 2, 3, 4, 5\}$ とし，$p(1) = p(2) = 0.25$，$p(3) = 0.2$，$p(4) = p(5) = 0.15$ とする．どの Huffman 符号語長も $\ell^{\mathrm H}(1) = \ell^{\mathrm H}(2) = \ell^{\mathrm H}(3) = 2$，$\ell^{\mathrm H}(4) = \ell^{\mathrm H}(5) = 3$ であり，平均符号長は $2.3$ である．同じ分布に対する Shannon 符号語長は $\ell^{\mathrm S}(1) = \ell^{\mathrm S}(2) = 2$，$\ell^{\mathrm S}(3) = \ell^{\mathrm S}(4) = \ell^{\mathrm S}(5) = 3$ で，平均符号長は $2.5$ である．また $H_2(X) = 2.2854\ldots$ である．
:::

::: proof
手続きを実行する．最初の併合では，最小の確率が $0.15$ でそれをもつのは $4$ と $5$ の二つだけだから，$u, v$ はこの二つに決まる．まとめてできた文字の重みは $0.3$ で，残りは $0.25$，$0.25$，$0.2$ である．二度目の併合では最小が $0.2$，次が $0.25$ で，$0.25$ をもつ文字が二つあるためどちらを選んでもよいが，$1$ と $2$ を入れ替えるだけなので得られる長さの組は変わらない．$3$ と $1$ をまとめたとすると重みは $0.45$ で，残りは $0.25$（文字 $2$）と $0.3$（$4$ と $5$ の組）である．三度目の併合ではこの二つがまとめられて重み $0.55$ になり，このとき残る文字は $\{3, 1\}$ のまとまりと $\{2, 4, 5\}$ のまとまりの二つである．ここから定義 4.6.1 の再帰を巻き戻す．文字が二つになった段では，どちらのまとまりにも値 $1$ が与えられる．一つ手前の段に戻ると，$\{2, 4, 5\}$ を分けた文字 $2$ と $\{4, 5\}$ のまとまりの値が $1 + 1 = 2$ になり，$\{3, 1\}$ の値は $1$ のままである．さらに一つ戻ると，$\{3, 1\}$ を分けた文字 $3$ と文字 $1$ の値が $1 + 1 = 2$ になる．最初の段まで戻ると，$\{4, 5\}$ を分けた文字 $4$ と文字 $5$ の値が $2 + 1 = 3$ になる．

値を計算する．平均符号長は
$$
2 \times (0.25 + 0.25 + 0.2) + 3 \times (0.15 + 0.15) \;=\; 1.4 + 0.9 \;=\; 2.3
$$
である．Shannon 符号語長は定義 4.4.1 より $\lceil \log_2 4 \rceil = 2$，$\lceil \log_2 5 \rceil = 3$，$\lceil \log_2 (1/0.15) \rceil = 3$（$\log_2 5 = 2.3219\ldots$，$\log_2(1/0.15) = 2.7369\ldots$）で，その平均符号長は $2 \times 0.5 + 3 \times 0.5 = 2.5$ である．エントロピーは定義 4.3.1 より
$$
H_2(X) \;=\; 2 \times 0.25 \log_2 4 + 0.2 \log_2 5 + 2 \times 0.15 \log_2 \frac{1}{0.15}
  \;=\; 2.2854\ldots
$$
である．
:::

::: example 4.6.3 確率が $2$ の冪であるとき
$D = 2$，$\mathcal X = \{1, 2, 3, 4\}$ とし，$p(1) = 1/2$，$p(2) = 1/4$，$p(3) = p(4) = 1/8$ とする．どの Huffman 符号語長も $\ell^{\mathrm H}(1) = 1$，$\ell^{\mathrm H}(2) = 2$，$\ell^{\mathrm H}(3) = \ell^{\mathrm H}(4) = 3$ であり，平均符号長は $7/4$ である．
:::

::: proof
最小の確率は $1/8$ で，それをもつのは $3$ と $4$ の二つだけだから，最初の併合はこの二つに決まる．できたまとまりの重みは $1/4$ で，残りは $1/2$ と $1/4$（文字 $2$）である．二度目の併合では重み $1/4$ の二つがまとめられ，どちらを $u$ にとっても同じ組がまとまるので，重み $1/2$ のまとまりと文字 $1$ が残る．再帰を巻き戻すと，文字が二つになった段でこの二つに値 $1$ が与えられ，一つ手前に戻ると文字 $2$ と $\{3, 4\}$ のまとまりの値が $2$ になり，最初の段まで戻ると文字 $3$ と文字 $4$ の値が $3$ になる．文字 $1$ の値は $1$ のままである．平均符号長は $\frac12 \cdot 1 + \frac14 \cdot 2 + \frac18 \cdot 3 + \frac18 \cdot 3 = \frac74$ である．
:::

例 4.6.3 の長さの組は例 4.1.4 の符号の符号語長そのもので，例 4.2.3 が定理 4.2.2 の構成でたどりついた組でもある．確率がちょうど $2$ の冪の逆数に並んでいるので定理 4.3.2 の等号が成り立ち，平均符号長 $7/4$ は $H_2(X)$ に等しい．手続きが $H_2(X)$ そのものに届いたということである．

::: proposition 4.6.4
$\mathcal X$ を $2$ 個以上の文字からなる有限アルファベット，$p$ を $\mathcal X$ 上の分布ですべての $x \in \mathcal X$ で $p(x) > 0$ を満たすものとする．定義 4.6.1 のどの Huffman 符号語長 $\ell^{\mathrm H}$ についても，すべての $x$ で $\ell^{\mathrm H}(x) \ge 1$ であり，
$$
\sum_{x \in \mathcal X} 2^{-\ell^{\mathrm H}(x)} \;=\; 1
$$
が成り立つ．したがって $\mathcal X$ 上の二元語頭符号で，各 $x$ の符号語長が $\ell^{\mathrm H}(x)$ に等しいものが存在する．
:::

::: proof アルファベットの大きさについての帰納法
$|\mathcal X| = 2$ のときは両方の値が $1$ で，和は $2^{-1} + 2^{-1} = 1$ である．

$|\mathcal X| \ge 3$ とし，定義 4.6.1 の $u$，$v$，$w$，$\mathcal X'$，$p'$，$\ell'$ をとる．$p'$ はすべての点で正であり $|\mathcal X'| = |\mathcal X| - 1 \ge 2$ だから，$\ell'$ に帰納法の仮定が使える．$z \ne u, v$ については $\ell^{\mathrm H}(z) = \ell'(z) \ge 1$ であり，$\ell^{\mathrm H}(u) = \ell^{\mathrm H}(v) = \ell'(w) + 1 \ge 2$ である．和は
$$
\sum_{x \in \mathcal X} 2^{-\ell^{\mathrm H}(x)}
  \;=\; \sum_{z \ne u, v} 2^{-\ell'(z)} + 2 \cdot 2^{-(\ell'(w)+1)}
  \;=\; \sum_{y \in \mathcal X'} 2^{-\ell'(y)}
  \;=\; 1
$$
となる（$2$ 個ぶんの $2^{-(\ell'(w)+1)}$ が $2^{-\ell'(w)}$ にまとまる）．

最後の主張は，得られた $\ell^{\mathrm H}$ に定理 4.2.2 を当てれば従う．
:::

::: formalized
$\ell^{\mathrm H}(x) \ge 1$ にあたる `huffmanLength_pos` (`InformationTheory/Shannon/Huffman/Length.lean`)，$\sum_x 2^{-\ell^{\mathrm H}(x)} = 1$ にあたる `huffmanLength_kraft_eq_one`，語頭符号の存在 `exists_huffman_prefix_code` (`InformationTheory/Shannon/Huffman/KraftSum.lean`)
:::

::: definition 4.6.5 Huffman 符号
$\mathcal X$ を $2$ 個以上の文字からなる有限アルファベット，$p$ を $\mathcal X$ 上の分布ですべての $x \in \mathcal X$ で $p(x) > 0$ を満たすものとする．Huffman 符号語長（定義 4.6.1）を符号語長にもつ二元語頭符号を **Huffman 符号** と呼ぶ．命題 4.6.4 より，そのような符号は存在する．
:::

Huffman 符号は一つに定まらない．符号語の中身は定理 4.2.2 の構成の取り方に依り，長さの組 $\ell^{\mathrm H}$ のほうも定義 4.6.1 の $u$ と $v$ の選び方に依る．$4$ 文字の確率が $0.4$，$0.2$，$0.2$，$0.2$ のときがそうで，長さの組は $2, 2, 2, 2$ にも $1, 3, 3, 2$ にもなる．どちらでも平均符号長は $2$ である．選び方に依らずこの値が定まることは，定理 4.6.9 から従う．

和がちょうど $1$ になることには意味がある．4.2 節の木の言葉でいえば，場所を一つも余らせずに使いきったということである．場所が余っていればどれかの符号語を $1$ 文字縮められるので，余らせる符号は最良ではありえない．この観察を最良の長さの組がもつ性質として書き下すために，比べる相手に名前を付けておく．

::: definition 4.6.6 候補
$\mathcal X$ を有限アルファベットとする．$\mathcal X$ 上の長さの組 $\ell$（定義 4.2.4）が，すべての $x \in \mathcal X$ で $\ell(x) \ge 1$ を満たし，かつ
$$
\sum_{x \in \mathcal X} 2^{-\ell(x)} \;\le\; 1
$$
を満たすとき，$\ell$ を $\mathcal X$ 上の **候補** と呼ぶ．
:::

定義 4.2.4 の長さの組は $0$ 以上の整数値をとる関数だから，候補は $1$ 以上の整数値をとる．系 4.2.5 を $D = 2$ に当てると，候補とはちょうど二元語頭符号の符号語長の組のことである．補題 4.6.7 は，場所を余らせる長さの組が最良ではないことを，候補の言葉で書き下したものである．

## 最良の長さの組がもつ性質

::: lemma 4.6.7
$\mathcal X$ を $2$ 個以上の文字からなる有限アルファベット，$p$ を $\mathcal X$ 上の分布ですべての $x \in \mathcal X$ で $p(x) > 0$ を満たすものとする．$u \in \mathcal X$ を $p(u) \le p(z)$ がすべての $z \in \mathcal X$ で成り立つ文字，$v \in \mathcal X \setminus \{u\}$ を $p(v) \le p(z)$ が $u$ 以外のすべての $z$ で成り立つ文字とする．$\mathcal X$ 上の候補（定義 4.6.6）$\ell$ すべてにわたる $\sum_x p(x)\ell(x)$ の最小値は存在し，しかもそれを達成する候補のうちには
$$
\ell(u) \;=\; \ell(v) \;=\; \max_{z \in \mathcal X} \ell(z)
$$
を満たすものがある．
:::

::: proof
最小値が存在することを示す．系 4.4.3 より Shannon 符号語長 $\ell^{\mathrm S}$ はすべての $x$ で $1$ 以上であり，命題 4.4.2 よりその Kraft 和は $1$ 以下だから，$\ell^{\mathrm S}$ は候補である．$B := \sum_x p(x)\ell^{\mathrm S}(x)$ とおくと，最小を探すのは $\sum_x p(x)\ell(x) \le B$ を満たす候補の中だけでよい．この条件のもとでは各項が非負なので $p(x)\ell(x) \le B$ であり，$p(x) > 0$ だから $\ell(x) \le B / p(x)$ となる．候補の値は $1$ 以上の整数だから，$\ell(x)$ のとりうる値は文字ごとに有限個で，そのような候補は有限個しかない．空でない有限集合の上の最小値だから，最小値が存在する．

値の入れ替えが何をするかを見る．$\ell$ を候補，$z, z' \in \mathcal X$ とし，$\ell$ の $z$ での値と $z'$ での値を入れ替えたものを $\tilde\ell$ と書く．値の多重集合は変わらないので，$\tilde\ell$ も候補である．平均符号長の差は
$$
\sum_x p(x)\tilde\ell(x) - \sum_x p(x)\ell(x)
  \;=\; \big(p(z) - p(z')\big)\big(\ell(z') - \ell(z)\big)
$$
となる．したがって $p(z) \le p(z')$ かつ $\ell(z) \le \ell(z')$ ならば差は $0$ 以下であり，$\ell$ が最小を達成していれば $\tilde\ell$ も達成する．

最大値を二つ以上の文字が達成することを示す．$\ell$ を最小を達成する候補とし，$m := \max_z \ell(z)$ を達成する文字がただ一つ，それを $t$ とする．$|\mathcal X| \ge 2$ だから他の文字があり，その値は $1$ 以上 $m$ 未満なので $m \ge 2$ である．ここで
$$
2^m \sum_{z} 2^{-\ell(z)} \;=\; \sum_{z} 2^{m - \ell(z)}
$$
を見ると，$z = t$ の項は $1$ で，他の項は $m - \ell(z) \ge 1$ より偶数だから，右辺は奇数である．Kraft の不等式より右辺は $2^m$ 以下で，$m \ge 1$ より $2^m$ は偶数だから，右辺は $2^m - 1$ 以下である．すなわち $\sum_z 2^{-\ell(z)} \le 1 - 2^{-m}$ である．そこで $t$ での値だけを $m - 1$ に取り替えた長さの組を考えると，その値は $1$ 以上で，Kraft の和は $\sum_z 2^{-\ell(z)} + 2^{-m} \le 1$ となるから候補であり，平均符号長は $p(t) > 0$ だけ小さい．これは $\ell$ の最小性に反する．よって最大値を達成する文字は二つ以上ある．

あとは最長の位置へ $u$ と $v$ を順に運ぶだけである．入れ替えても平均符号長は増えないのだから，最長の値をもつ文字と入れ替えていけばよい．以下はその確認である．

まず $u$ を移す．$\ell$ を最小を達成する候補とし，$m := \max_z \ell(z)$ とおく．前段より $m$ を達成する文字は二つ以上あるので，そのうち相異なる二つを $a, b$ とする．$u \notin \{a, b\}$ のときは，$p(u) \le p(a)$ かつ $\ell(u) \le m = \ell(a)$ だから，$u$ と $a$ の値を入れ替えても最小性は保たれる．入れ替えたあと $\ell(u) = m$ であり，$b$ は $u$ とも $a$ とも異なるので $\ell(b) = m$ のままである．$u \in \{a, b\}$ のときは名前を付け替えて $a = u$ としてよく，はじめから $\ell(u) = m$ かつ $\ell(b) = m$ である．どちらの場合も，$\ell(u) = m$ であり，$u$ と異なる文字 $b$ が $\ell(b) = m$ を満たす．

次に $v$ を扱う．$v = b$ ならすでに $\ell(v) = m$ である．$v \ne b$ のときは，$b \ne u$ より $p(v) \le p(b)$ であり，$\ell(v) \le m = \ell(b)$ だから，$v$ と $b$ の値を入れ替えても最小性は保たれる．入れ替えたあと $\ell(v) = m$ であり，$u$ は $v$ とも $b$ とも異なるので $\ell(u) = m$ のままである．値の多重集合は入れ替えで変わらないから最大値も $m$ のままで，$\ell(u) = \ell(v) = \max_z \ell(z)$ を満たす候補が最小を達成している．
:::

奇偶を見た段は，最長の符号語の隣が空いていることを見つけている．最長の値 $m$ をもつ文字が $t$ ただ一つだとすると，他の符号語はどれも深さ $m$ より浅いので，それが深さ $m$ で塞ぐ場所は偶数個ずつまとまっており，$t$ の場所と対になる隣の場所を塞ぐなら $t$ の場所も一緒に塞ぐことになる．$t$ の場所は $t$ が使っているのだから，隣は空いている．空いているなら $t$ の符号語を $1$ 文字縮めて，対になる二つの場所をまとめて使える．縮めれば平均符号長は $p(t)$ だけ小さくなるから，最長を一つの文字しか達成しない長さの組は最小を達成していない．

::: formalization-note
補題 4.6.7 に対応する単独の宣言はない．形式化にも値の入れ替えによる正規化の段があり，`swap_normalization_strong` (`InformationTheory/Shannon/Huffman/StrongForm.lean`) がそれである．そこで扱うのは「確率が最小の二文字の長さを等しくそろえる」という部分だけで，本文の補題とは切り取り方が違う．
:::

## 併合が最小値を引き継ぐ

::: lemma 4.6.8
$\mathcal X$ を $3$ 個以上の文字からなる有限アルファベット，$p$ を $\mathcal X$ 上の分布ですべての $x \in \mathcal X$ で $p(x) > 0$ を満たすものとする．$u \in \mathcal X$ と $v \in \mathcal X \setminus \{u\}$ を補題 4.6.7 と同じ条件でとり，$u$ と $v$ を新しい $1$ 文字 $w$ に置き換えたアルファベットを $\mathcal X'$，その上の分布を $p'(w) := p(u) + p(v)$，$p'(z) := p(z)$（$z \ne w$）とする．$\mathcal X$ 上の候補（定義 4.6.6）$\ell$ すべてにわたる $\sum_x p(x)\ell(x)$ の最小値を $L^*$，$\mathcal X'$ と $p'$ について同じように定めた最小値を $L'^{*}$ と書くと
$$
L^{*} \;=\; L'^{*} + p(u) + p(v)
$$
が成り立つ．
:::

::: proof
どちらの最小値も，補題 4.6.7 より存在する（$|\mathcal X'| = |\mathcal X| - 1 \ge 2$ であり，$p'$ もすべての点で正である）．

$L^{*} \le L'^{*} + p(u) + p(v)$ を示す．$\mathcal X'$ 上で最小を達成する長さの組 $\ell'$ をとり，$\mathcal X$ 上の長さの組 $\ell$ を $\ell(u) := \ell'(w) + 1$，$\ell(v) := \ell'(w) + 1$，$\ell(z) := \ell'(z)$（$z \ne u, v$）で定める．値はすべて $1$ 以上で，
$$
\sum_{x} 2^{-\ell(x)}
  \;=\; \sum_{z \ne u, v} 2^{-\ell'(z)} + 2 \cdot 2^{-(\ell'(w)+1)}
  \;=\; \sum_{y \in \mathcal X'} 2^{-\ell'(y)} \;\le\; 1
$$
だから Kraft の不等式も満たす．平均符号長は
$$
\sum_{x} p(x)\ell(x)
  \;=\; \sum_{z \ne u, v} p'(z)\ell'(z) + \big(p(u) + p(v)\big)\big(\ell'(w) + 1\big)
  \;=\; L'^{*} + p(u) + p(v)
$$
である．最小値はこれ以下だから，主張の不等式を得る．

$L'^{*} \le L^{*} - p(u) - p(v)$ を示す．補題 4.6.7 より，$\mathcal X$ 上で最小を達成し $\ell(u) = \ell(v) = m := \max_z \ell(z)$ を満たす長さの組 $\ell$ がとれる．$m \ge 2$ である．というのも $m = 1$ ならすべての値が $1$ になり，Kraft の和が $|\mathcal X| / 2$ となって $|\mathcal X| \le 2$ を強いるが，これは仮定に反するからである．そこで $\mathcal X'$ 上の長さの組 $\ell'$ を $\ell'(w) := m - 1$，$\ell'(z) := \ell(z)$（$z \ne w$）で定めると，値はすべて $1$ 以上で
$$
\sum_{y \in \mathcal X'} 2^{-\ell'(y)}
  \;=\; \sum_{z \ne u, v} 2^{-\ell(z)} + 2 \cdot 2^{-m}
  \;=\; \sum_{x \in \mathcal X} 2^{-\ell(x)} \;\le\; 1
$$
だから Kraft の不等式を満たす．平均符号長は
$$
\sum_{y} p'(y)\ell'(y)
  \;=\; \sum_{z \ne u, v} p(z)\ell(z) + \big(p(u) + p(v)\big)(m - 1)
  \;=\; L^{*} - p(u) - p(v)
$$
である．最小値はこれ以下だから，主張の不等式を得る．

二つを合わせて等号が従う．
:::

::: formalization-note
補題 4.6.8 に対応する単独の宣言はない．形式化は最小値そのものを扱わず，任意の候補と Huffman 符号語長を直接比べる形で最適性へ進む．
:::

補題 4.6.8 は，最小化の問題が一段小さい同じ問題に化けることを言っている．確率が最小の二文字については，その二つが同じ長さの最長の符号語をもつような最良の符号を必ずとれる（補題 4.6.7）．ならばその二文字は一つにまとめてしまってよく，まとめたぶんだけ符号語が $1$ 文字伸びる代償として $p(u) + p(v)$ を払う．この代償は長さの組の選び方に依らない定数なので，最小化には関わらない．手続きが確率の小さい二つをまとめていくのは，この読み替えを繰り返しているということである．

## 最適性

::: theorem 4.6.9 Huffman 符号の最適性
$\mathcal X$ を $2$ 個以上の文字からなる有限アルファベット，$p$ を $\mathcal X$ 上の分布ですべての $x \in \mathcal X$ で $p(x) > 0$ を満たすものとする．定義 4.6.1 のどの Huffman 符号語長 $\ell^{\mathrm H}$ についても，$\mathcal X$ 上のどの候補（定義 4.6.6）$\ell$ に対しても
$$
\sum_{x \in \mathcal X} p(x)\,\ell^{\mathrm H}(x) \;\le\; \sum_{x \in \mathcal X} p(x)\,\ell(x)
$$
である．
:::

::: proof アルファベットの大きさについての帰納法
$|\mathcal X| = 2$ のとき，$\ell^{\mathrm H}$ は両方の文字で $1$ だから左辺は $1$ である．右辺は $\ell(x) \ge 1$ より $1$ 以上である．

$|\mathcal X| \ge 3$ とし，定義 4.6.1 の $u$，$v$，$w$，$\mathcal X'$，$p'$，$\ell'$ をとる．$\ell'$ は $(\mathcal X', p')$ の Huffman 符号語長であり，$|\mathcal X'| = |\mathcal X| - 1 \ge 2$ で $p'$ はすべての点で正だから，帰納法の仮定より $\ell'$ は $\mathcal X'$ 上のどの候補にも負けない．命題 4.6.4 より $\ell'$ 自身も候補だから，$\sum_y p'(y)\ell'(y)$ は補題 4.6.8 の $L'^{*}$ に等しい．定義 4.6.1 の作り方から
$$
\sum_{x} p(x)\ell^{\mathrm H}(x)
  \;=\; \sum_{z \ne u, v} p'(z)\ell'(z) + \big(p(u) + p(v)\big)\big(\ell'(w) + 1\big)
  \;=\; L'^{*} + p(u) + p(v)
$$
であり，補題 4.6.8 よりこれは $L^{*}$ に等しい．$L^{*}$ は候補にわたる最小値だから，どの候補 $\ell$ に対しても $\sum_x p(x)\ell^{\mathrm H}(x) = L^{*} \le \sum_x p(x)\ell(x)$ である．
:::

::: formalized
`huffmanLength_optimal` (`InformationTheory/Shannon/Huffman/StrongForm.lean`)
:::

::: corollary 4.6.10
$\mathcal X$ を $2$ 個以上の文字からなる有限アルファベット，$X$ を $\mathcal X$ 上に分布 $p$ をもつ確率変数で，すべての $x \in \mathcal X$ で $p(x) > 0$ を満たすものとする．このとき定義 4.6.1 のどの Huffman 符号語長 $\ell^{\mathrm H}$ についても
$$
H_2(X) \;\le\; \sum_{x \in \mathcal X} p(x)\,\ell^{\mathrm H}(x) \;<\; H_2(X) + 1
$$
である．
:::

::: proof
左側は，命題 4.6.4 より $\ell^{\mathrm H}$ が Kraft の不等式を満たすので，定理 4.3.2 から従う．

右側を見る．系 4.4.3 より Shannon 符号語長 $\ell^{\mathrm S}$ はすべての $x$ で $1$ 以上であり，命題 4.4.2 より Kraft の不等式を満たすから，定理 4.6.9 を $\ell = \ell^{\mathrm S}$ に当てて $\sum_x p(x)\ell^{\mathrm H}(x) \le \sum_x p(x)\ell^{\mathrm S}(x)$ を得る．定理 4.4.4 より右辺は $H_2(X) + 1$ 未満である．
:::

::: formalization-note
系 4.6.10 に対応する単独の宣言はない．左側は，命題 4.6.4 の形式化のうち `huffmanLength_kraft_le_one` (`InformationTheory/Shannon/Huffman/KraftSum.lean`) を，定理 4.3.2 の形式化 `entropyD_le_expectedLength_of_kraft` (`InformationTheory/Shannon/ShannonCode/Basic.lean`) と合わせた形になる．右側は定理 4.6.9 の形式化と定理 4.4.4 の形式化を合わせた形だが，前者が Shannon 符号語長を比べる相手として受け取るには，それが $1$ 以上であることが要り，それを与える宣言はない．
:::

本章の問いはこれで閉じた．一意復号可能などんな符号でも平均符号長は $H_D(X)$ を下回れず（定理 4.3.2，系 4.5.2），アルファベットが $2$ 文字以上ですべての記号の確率が正なら $H_D(X) + 1$ 未満で済ませる符号があり（系 4.4.3，定理 4.4.4），$D = 2$ のときは同じ仮定のもとで，最良の符号を手続きで作れる（命題 4.6.4 が符号を与え，定理 4.6.9 がその最良性を保証する）．例 4.4.5 で Shannon 符号が最良でない場合を見たが，その「最良」がどこにあるかは，確率を小さいものから二つずつまとめていくだけで決まる．エントロピーが答えるのは幅 $1$ までで，その幅の中で最良の平均符号長がどこに落ちるかは定義 4.6.1 の手続きが答える，というのが本章の結論である．
