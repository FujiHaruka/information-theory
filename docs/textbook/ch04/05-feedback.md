# 4.5 フィードバックのある通信路

ここまで、送る側は符号語を決めたら最後まで送りきるものとしてきた。受け取る側に何が
届いたかは、送る側には分からない。では、受け取る側が受け取った記号をそのつど送る側へ
完全に返せるとしたら——次の記号を決めるまでに、いま何が届いたかを送る側が知って
いられるとしたら——容量は増えるだろうか。

直感は「増える」と答える。送る側は通信路がいまどう振る舞ったかを見て次の入力を選べる。
消失したと分かればもう一度送ればよいし、雑音の出方に合わせて送るものを変えることも
できる。何も知らずに送りっぱなしにするより、賢く振る舞えるはずである。ところが答えは、
容量は増えない、である。この意外さが本節の主題で、なぜ増えないのか、そして増えないのに
フィードバックの何が有用なのかを見る。

## フィードバック符号

::: definition 4.5.1 フィードバック符号
長さ $n$ の **フィードバック符号** とは、メッセージ数 $M \ge 1$、符号化写像の族
$c_i : \{1, \dots, M\} \times \mathcal Y^{i} \to \mathcal X$（$i = 0, \dots, n-1$）、
復号器 $d : \mathcal Y^n \to \{1, \dots, M\}$ の組である。メッセージ $m$ を送るとき、
時刻 $i$ の入力を
$$
x_i \;=\; c_i\big(m,\, y^{<i}\big), \qquad y^{<i} := (y_0, \dots, y_{i-1})
$$
——それまでに受け取られた出力に依存してよい——で定める。**レート** は
$R := \frac1n \log M$、メッセージ $m$ の **誤り確率** は
$P_e(m) := \Pr[d(Y^n) \ne m]$（$Y^n$ はこの手順で通信路を $n$ 回使ったときの出力）とし、
**最大誤り確率** と **平均誤り確率** は定義 4.2.1 と同じく $m$ についての最大と平均で
定める。
:::

$c_i$ が $y^{<i}$ によらない場合が定義 4.2.1 のブロック通信路符号である。すなわち
フィードバック符号は定義 4.2.1 の符号をすべて含む。だから、フィードバックを許して
達成できるレートの範囲は、少なくとも許さないときと同じだけはある。本節の内容は、それが
広がりもしない、ということである。

**返せるとしたら、を問うている.** 定義 4.5.1 が置いている前提は強い。受け取る側の記号が
遅れなく、誤りもなく送る側へ戻るとしている。現実の通信路でそれが可能かは別の問いで、
ここでは可能だとしたら何が変わるかを問うている。実際にはフィードバックの経路自身も雑音を
もつので、この定義は「フィードバックがいちばん有利に働いたとき」を表している。それでも
容量が増えないなら、雑音のあるフィードバックでも増えない。

::: formalization-note
符号化写像の族は `FeedbackCode`
(`InformationTheory/Shannon/ChannelCoding/Feedback.lean`) として形式化されている。時刻
ごとの符号化器がメッセージと長さ $i$ の過去出力だけを見るという因果性は型に入っており、
過去出力によらない場合が定義 4.2.1 のブロック通信路符号だという埋め込みも同じところに
ある。ただし本節の逆定理はそれを使わず、入力の列 $X_i$ を確率変数としてそのまま扱って、
それが過去の出力とメッセージから決まるという構造を定義 4.5.2 の条件付き独立に吸収させて
いる。
:::

## 記憶のなさと因果性

::: definition 4.5.2 フィードバックのもとで各時刻で記憶がない
確率変数 $\mathrm{Msg}$、入力の組 $X^n = (X_0, \dots, X_{n-1})$、出力の組
$Y^n = (Y_0, \dots, Y_{n-1})$ が **フィードバックのもとで各時刻で記憶がない** とは、
すべての $i$ について
$$
\big(Y^{<i},\, \mathrm{Msg}\big) \;\to\; X_i \;\to\; Y_i
$$
がマルコフ連鎖（定義 1.8.3）をなすことをいう。ここで $Y^{<i} := (Y_0, \dots, Y_{i-1})$ で
ある。
:::

::: formalized
`IsMemorylessFeedback`
(`InformationTheory/Shannon/ChannelCoding/FeedbackMemoryless.lean`)
:::

一つの条件が二つのことを同時に言っている。一つは記憶のなさで、時刻 $i$ の入力さえ決まれば
出力はそれまでに何が受け取られたかによらない。もう一つは因果性で、$X_i$ を決めてしまえば
出力はメッセージそのものを覗き見ない——メッセージの影響は入力を通ってしか届かない。

条件に並んでいるのが過去の出力とメッセージであって、他の時刻の入力ではないことに注意
したい。定義 4.4.4 は他の時刻の入出力を条件に置いていた。フィードバックがあると $X_i$ が
過去の出力の関数になるので、入力どうしの独立性を問う形にはもう意味がない。代わりに、
$X_i$ を決めるのに使えた情報——過去の出力とメッセージ——をすべて条件に並べ、それでも
$Y_i$ は $X_i$ しか見ないと述べている。

## 1 時刻ごとの評価

::: lemma 4.5.3
$n \ge 1$ とし、$\mathrm{Msg}$、$X^n = (X_0, \dots, X_{n-1})$、
$Y^n = (Y_0, \dots, Y_{n-1})$ をフィードバックのもとで各時刻で記憶がない（定義 4.5.2）
確率変数の組とする。このとき各 $i$ について
$$
I\big(\mathrm{Msg}; Y_i \,\big|\, Y^{<i}\big) \;\le\; I(X_i; Y_i)
$$
が成り立つ。
:::

::: proof
$L := (Y^{<i}, \mathrm{Msg})$ とおく。定義 4.5.2 は $L \to X_i \to Y_i$ がマルコフ連鎖で
あることをいうので、定理 1.8.4 より $I(L; Y_i) \le I(X_i; Y_i)$ である。

いっぽう定理 1.5.1 を $Z \leftarrow Y^{<i}$、$X \leftarrow \mathrm{Msg}$、
$Y \leftarrow Y_i$ として当てると
$$
I(L; Y_i) \;=\; I\big(Y^{<i}; Y_i\big) \;+\; I\big(\mathrm{Msg}; Y_i \mid Y^{<i}\big)
$$
であり、命題 1.3.2 より第 1 項は非負だから
$I(\mathrm{Msg}; Y_i \mid Y^{<i}) \le I(L; Y_i)$ である。二つを合わせて主張を得る。
:::

::: formalized
`feedback_per_letter_bound`
(`InformationTheory/Shannon/ChannelCoding/FeedbackMemoryless.lean`)
:::

補題 4.5.3 が本節の核である。左辺は「これまでに受け取ったものを踏まえたうえで、時刻 $i$ の
出力がメッセージについて新しく教えてくれる情報」、右辺は「時刻 $i$ の入力と出力が共有する
情報」である。フィードバックは左辺の側にいくらでも仕掛けを入れられる——過去の出力を見て
$X_i$ を選び直せる——のに、その結果はやはり右辺で抑えられる。**フィードバックが変えられる
のは各時刻の入力の選び方だけで、選んだ入力に対して通信路が運べる量そのものではない**、と
いうのがこの補題の内容である。

## フィードバック逆定理

::: theorem 4.5.4
$M \ge 2$、$n \ge 1$ とし、$C$ を実数とする。$\mathrm{Msg}$ を $\{1, \dots, M\}$ 上の
一様分布に従う確率変数、$X^n = (X_0, \dots, X_{n-1})$、$Y^n = (Y_0, \dots, Y_{n-1})$ を
有限集合に値をとる確率変数の組、$d$ を $Y^n$ の値から $\{1, \dots, M\}$ への写像とし、
$P_e := \Pr[d(Y^n) \ne \mathrm{Msg}]$ とおく。組がフィードバックのもとで各時刻で
記憶がなく（定義 4.5.2）、かつすべての $i$ で $I(X_i; Y_i) \le C$ なら
$$
\log M \;\le\; n\,C \;+\; H_b(P_e) \;+\; P_e \log(M - 1)
$$
が成り立つ。
:::

::: proof
定理 4.4.1 を、観測を $Y^n$、復号器を $d$ として当てると
$$
\log M \;\le\; I\big(\mathrm{Msg}; Y^n\big) + H_b(P_e) + P_e \log(M-1)
$$
である。第 1 項を $nC$ で抑えればよい。

相互情報量は対称（命題 1.3.3）だから
$I(\mathrm{Msg}; Y^n) = I(Y^n; \mathrm{Msg})$ である。定理 1.5.2 を、変数列
$Y_0, \dots, Y_{n-1}$ と、相手側の変数 $\mathrm{Msg}$ として当てると
$$
I\big(Y^n; \mathrm{Msg}\big) \;=\; \sum_{i=0}^{n-1} I\big(Y_i; \mathrm{Msg} \mid Y^{<i}\big)
$$
となる。条件付き相互情報量も対称（命題 1.4.2）なので、各項は
$I(\mathrm{Msg}; Y_i \mid Y^{<i})$ に等しい。これを補題 4.5.3 で $I(X_i; Y_i)$ で抑え、
仮定でさらに $C$ で抑えると、和は $nC$ 以下である。
:::

::: formalized
`channel_coding_feedback_converse_memoryless`
(`InformationTheory/Shannon/ChannelCoding/FeedbackMemoryless.lean`)
:::

**分解の軸を入力から出力に取り替える.** 4.4 節の逆定理は、まず系 4.4.2 で
$I(\mathrm{Msg}; Y^n)$ を $I(X^n; Y^n)$ に移し、そこから入力の側でチェイン則を使った
（定理 4.4.3）。フィードバックがあると最初の一歩が壊れる。$X_i$ が過去の出力の関数に
なるので、メッセージから出力への影響が符号語だけを通るとはいえなくなり、
$\mathrm{Msg} \to X^n \to Y^n$ はもうマルコフ連鎖ではない。出力が入力へ回り込むからで
ある。そこで $I(\mathrm{Msg}; Y^n)$ をそのまま抱えたまま、**出力の側で**チェイン則を使う。
分解の軸を入力から出力へ取り替えたことが、この節の技術的な要点である。回り込みが起きる
軸を避けて、起きない軸で分解した、と読める。

## フィードバックは容量を増やさない

::: corollary 4.5.5 フィードバックは容量を増やさない
$W$ を通信路（定義 4.1.1）とする。フィードバック符号の族
$\big(M_n, (c_{n,i})_{i}, d_n\big)_{n \ge 1}$——第 $n$ 項は長さ $n$ の符号——が、
最大誤り確率 $P^{(n)}_{e,\max} \to 0$ を満たし、レートの列
$R_n = \frac1n \log M_n$ が上に有界であるとする。このとき $\liminf_n R_n \le C(W)$ である。
:::

::: proof
**下ごしらえ.** 達成可能性が最大誤り確率で書かれているのでメッセージには一様分布を入れて
よく、$P^{(n)}_e := \Pr[d_n(Y^n) \ne \mathrm{Msg}]$ は平均誤り確率に等しくて
$P^{(n)}_e \le P^{(n)}_{e,\max} \to 0$ である。$M_n \ge 1$ より $R_n \ge 0$ であり、
$\delta_n := H_b\big(P^{(n)}_e\big)/n + P^{(n)}_e R_n$ とおくと、これは非負で、
$(R_n)$ の有界性と合わせて補題 4.4.7 より $\delta_n \to 0$ である。$M_n = 1$ の $n$ では
$R_n = 0$ で、命題 4.1.6 より $R_n \le C(W) \le C(W) + \delta_n$ が成り立つ。以下
$M_n \ge 2$ とする。

**定理 4.5.4 の仮定を確かめる.** 時刻 $i$ の入力は $X_i = c_{n,i}(\mathrm{Msg}, Y^{<i})$ で
あり、それを通信路に通すのだから、$(\mathrm{Msg}, Y^{<i})$ を知ったうえでの $Y_i$ の
条件付き分布は $W(\cdot \mid X_i)$ である。これは $X_i$ だけで決まるので、組は
フィードバックのもとで各時刻で記憶がない（定義 4.5.2）。同じ条件付き分布を
$(\mathrm{Msg}, Y^{<i})$ について平均すれば、$X_i$ だけで条件付けても
$W(\cdot \mid X_i)$ である。よって $X_i$ の分布を $p_i$ と書けば対 $(X_i, Y_i)$ の
同時分布は $p_i(x) W(y \mid x)$ であり、
命題 4.1.3 と定義 4.1.4 より $I(X_i; Y_i) = I(p_i; W) \le C(W)$ である。

**当てて割る.** 定理 4.5.4 を $C \leftarrow C(W)$ として使い、$n$ で割ると
$$
R_n \;\le\; C(W) \;+\; \frac{H_b\big(P^{(n)}_e\big)}{n}
  \;+\; P^{(n)}_e \,\frac{\log(M_n - 1)}{n}
$$
である。$M_n \ge 2$ より $\log(M_n - 1) \le \log M_n = n R_n$ だから、右辺の第 3 項は
$P^{(n)}_e R_n$ 以下であり、$R_n \le C(W) + \delta_n$ を得る。どの $n$ でもこれが成り立ち
$\delta_n \to 0$ だから、両辺で下極限をとって主張を得る。
:::

::: formalization-note
系 4.5.5 に対応する単独の宣言はない。定理 4.5.4 に紐付けた宣言は各時刻の上界 $C$ を引数と
して受け取る形なので、そこに $C(W)$ を渡した合成で得られる。
:::

系 4.5.5 が示したのは片側だけである。もう片側——$C(W)$ 未満のレートがフィードバックを
使っても達成できること——は、定義 4.5.1 の直後に見たとおり、フィードバックを使わない符号が
そのままフィードバック符号になることから出る。定理 4.3.7 が作った符号をそのまま使えば
よい。二つを合わせると、フィードバックのあるなしで到達できるレートの範囲は変わらない。

**最大をとったあとでは動かせない.** 増えない理由は、補題 4.5.3 と容量の定義の組み合わせに
尽きる。フィードバックが与えるのは各時刻の入力分布を履歴に応じて選び直す自由だが、
$C(W)$ はもともと入力分布のすべてにわたる最大値（定義 4.1.4）である。どの時刻にどんな
分布を選んでも、その時刻に運べる量は最大値を超えない。すでに最大をとってある量は、選び方を
工夫しても動かない。

## 増えないのに、何が変わるのか

::: example 4.5.6 消失した記号を送り直す
$\eta \in [0, 1]$、$n \ge 1$ とし、消失確率 $\eta$ の二元消失通信路（例 4.1.9）に
フィードバックを付ける。送る側は、いま送ったビットが届いたか消失したかを、次の入力を
決めるまでに知ることができる。そこで、消失していたら同じビットをもう一度送り、届いて
いたら次のビットへ進む、という方式をとる。$n$ 回の使用でこの方式が運ぶビット数を
$N_n$ とすると
$$
\mathbb E\big[N_n\big] \;=\; (1 - \eta)\, n
$$
である。
:::

::: proof
時刻 $i$ の出力が消失でないという事象の指示変数を $Z_i$ とおく。例 4.1.9 の通信路では
$W(\ast \mid x) = \eta$ が入力によらないので、送る側が何を選んでも
$\Pr[Z_i = 1] = 1 - \eta$ であり、$\mathbb E[Z_i] = 1 - \eta$ である。

この方式では、消失しなかった記号がそのつどちょうど 1 ビットを運ぶ。届いた記号がどの
ビットのものかは、受け取る側も消失の位置を見ているので分かる。よって $n$ 回で運ばれた
ビット数は $N_n = \sum_{i=0}^{n-1} Z_i$ であり、期待値の線形性から
$\mathbb E[N_n] = (1-\eta)\,n$ を得る。
:::

$\eta = 1$ は全時刻が消失する縮退した場合で、この方式は 1 ビットも進まない。そのときは
右辺も 0 になるので、等式はそのまま成り立っている。

1 回の使用あたり平均 $1 - \eta$ ビット——例 4.1.9 で計算した容量とちょうど同じ値である。
$\eta = 0.1$ なら $n$ 回で運べるビット数の期待値は $0.9\,n$、すなわち 1 回あたり
$0.9$ ビットである。

この方式には符号語も復号器の設計も入っていない。届かなければもう一度送るだけで、$n$ を
大きくとる必要さえない。同じレートにフィードバックなしで達するには、4.3 節のランダム符号化
と結合典型復号器が要った——しかも作れることが分かるだけで、どの符号帳が当たりかは
分からないままだった。**フィードバックが変えるのは、到達できるレートではなく、そこへ届く
ための手間である。**系 4.5.5 が否定しているのは前者だけで、後者については何も
言っていない。

なお、この方式で $1 - \eta$ 未満のどのレートでも誤り確率が 0 に向かうことまで言うには、
$N_n$ が期待値のまわりに集中することを示す必要がある。ここでは期待値の計算までにとどめる。

::: formalization-note
例 4.5.6 に対応する宣言は形式化されていない。例 4.5.6 に付した証明が、この主張の保証の
すべてである。
:::
