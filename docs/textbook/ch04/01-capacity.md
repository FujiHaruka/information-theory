# 4.1 通信路と通信路容量

第2章と第3章は、情報源のもつ冗長さを取り除く話だった。同じ内容をより短く書けるのは
どこまでか——その限界がエントロピーだった。本章で扱うのは逆向きの操作である。通信路は
送った記号を確率的に取り違えるので、受け取った側が誤りを直せるように、送る側があらかじめ
冗長さを**足す**。足しすぎれば運べる情報が減り、足りなければ誤りが残る。この綱引きの
決着がどこにつくかが本章の主題である。

素朴に考えると、雑音のある通信路では誤り確率を 0 に近づけようとするたびに伝送速度が
0 に落ちそうに思える。同じ記号を何度も繰り返して多数決をとれば誤りは減らせるが、
繰り返した回数だけ速度は落ちる。Shannon の発見は、そうはならないということである。
通信路ごとにある数 $C$ が定まっていて、$C$ より小さい速度である限り、誤り確率は
いくらでも 0 に近づけられる。本節ではその $C$——通信路容量——を定義し、それが上限では
なく最大値として達成されることを示し、二つの通信路で値を計算する。

以下、入力アルファベット $\mathcal X$ と出力アルファベット $\mathcal Y$ はどちらも
有限とする。本章では $\log$ の底を 2 にとる。第2章・第3章と同じく $2^{nR}$ の形の量を
扱うので、指数と対数の底をそろえておくと式が読みやすい。

## 通信路と、その相互情報量

::: definition 4.1.1 離散無記憶通信路
**通信路** とは、各 $x \in \mathcal X$ に対して $\mathcal Y$ 上の分布 $W(\cdot \mid x)$ を
与える対応である。すなわち $W(y \mid x) \ge 0$ であって、各 $x$ について
$\sum_{y \in \mathcal Y} W(y \mid x) = 1$ を満たす。長さ $n$ の入力
$x^n = (x_0, \dots, x_{n-1})$ に対する出力の分布が
$$
W^n\big(y^n \,\big|\, x^n\big) \;=\; \prod_{i=0}^{n-1} W\big(y_i \,\big|\, x_i\big)
$$
で与えられるとき、この通信路を **記憶のない（memoryless）通信路** という。本書は
$\mathcal X$ と $\mathcal Y$ が有限な場合だけを扱うので、これを **離散無記憶通信路** とも
呼ぶ。$\mathcal X$ 上の分布 $p$ を入力に与えたときの入力と出力の **結合分布** を
$p(x)W(y \mid x)$、その第 2 成分の周辺分布 $q(y) := \sum_{x} p(x) W(y \mid x)$ を
**出力分布** と呼ぶ。
:::

$W(y \mid x)$ は「$x$ を送ったときに $y$ が受け取られる確率」である。通信路が定めるのは
この条件付き分布だけで、何を送るかは通信路の側では決まっていない。入力分布 $p$ を
与えてはじめて入力と出力が対になり、結合分布と出力分布が定まる。積の形の条件が言って
いるのは、各時刻の雑音がそれ以前の入出力に一切依存しない、ということである。これが
「記憶のない」の内容で、第3章の記憶のある情報源とちょうど逆向きの仮定になっている
——あちらは情報源に記憶があってよかったが、こちらは通信路に記憶がない。

::: formalized
`Channel`、結合分布 `jointDistribution`、出力分布 `outputDistribution`
(`InformationTheory/Shannon/ChannelCoding/Basic.lean`)
:::

::: definition 4.1.2 通信路の相互情報量
$\mathcal X$ 上の分布 $p$ と通信路 $W$ に対し、出力分布を
$q(y) := \sum_{x} p(x) W(y \mid x)$ とおく。**入力分布 $p$ のもとでの $W$ の相互情報量** を
$$
I(p; W) \;:=\; \sum_{x, y} p(x)\, W(y \mid x) \log \frac{W(y \mid x)}{q(y)}
$$
で定める。和は $p(x)W(y \mid x) > 0$ の項についてとる。
:::

対数の中身 $W(y \mid x) / q(y)$ は、「$x$ が送られたと知ることで、$y$ が受け取られると
いう見込みが何倍になったか」である。何を送っても出力の分布が変わらない通信路——雑音が
入力を完全に潰してしまう通信路——では、この比が全点で 1 になって $I(p;W) = 0$ になる。
逆に $x$ ごとに出力の分布がはっきり違えば比は 1 から離れ、$I(p;W)$ は大きくなる。
1.3 節の言葉でいえば、$I(p;W)$ は入力と出力が独立からどれだけ隔たっているかを一つの数に
まとめた量である。

::: formalized
`mutualInfoOfChannel` (`InformationTheory/Shannon/ChannelCoding/Basic.lean`)
:::

定義 4.1.2 は通信路の側から書いた式で、第1章の相互情報量とは見た目が違う。両者が
同じものであることを先に確かめておく。

::: proposition 4.1.3
$\mathcal X$ 上の分布 $p$ と通信路 $W$ をとり、$(X, Y)$ を結合分布 $p(x)W(y \mid x)$ に
従う対とする。このとき
$$
I(p; W) \;=\; I(X; Y) \;=\; H(X) + H(Y) - H(X, Y)
  \;=\; H(Y) - H(Y \mid X) \;=\; H(X) - H(X \mid Y).
$$
:::

::: proof
$(X, Y)$ の同時分布は $p(x,y) = p(x) W(y \mid x)$ であり、その周辺分布は
$\sum_y p(x,y) = p(x)$ と $\sum_x p(x,y) = q(y)$ である。和をとる範囲
$p(x,y) > 0$ では $p(x) > 0$ なので約分してよく、定義 1.3.1 の対数の中身は
$$
\frac{p(x,y)}{p(x)\, q(y)} \;=\; \frac{p(x) W(y \mid x)}{p(x)\, q(y)}
  \;=\; \frac{W(y \mid x)}{q(y)}
$$
になる。したがって定義 4.1.2 の右辺は定義 1.3.1 の右辺そのもので、$I(p;W) = I(X;Y)$ で
ある。残る三つの等式は、この対 $(X, Y)$ に定理 1.3.4 を当てたものである。
:::

::: formalized
結合分布の相互情報量との一致 `mutualInfoOfChannel_eq_mutualInfo_prod`、エントロピーの
差の形 `mutualInfoOfChannel_eq_HX_add_HY_sub_HZ`
(`InformationTheory/Shannon/ChannelCoding/Basic.lean`)
:::

::: formalization-note
形式化されているのは前の二つの等式までで、$H(Y) - H(Y \mid X)$ の形に対応する単独の
宣言はない。定理 1.3.4 の形式化との合成で得られる。
:::

**雑音の分だけ減る、と読む.** 以下でいちばん使うのは $I(p;W) = H(Y) - H(Y \mid X)$ の
形である。$H(Y)$ は受け取った側から見た出力の不確かさ、$H(Y \mid X)$ は何を送ったかを
知ってもなお残る不確かさ——すなわち雑音そのものの不確かさである。運べた情報とは、出力の
不確かさから雑音の分を差し引いた残りだ、と読める。送る側に選べるのは $p$ だけで、
$p$ を動かせば $H(Y)$ も $H(Y \mid X)$ も動く。その中で差を最大にする $p$ を探す、と
いうのが次の定義である。

## 通信路容量

::: definition 4.1.4 通信路容量
通信路 $W$ の **通信路容量** を、入力分布全体にわたる上限
$$
C(W) \;:=\; \sup_{p} I(p; W)
$$
で定める。$p$ は $\mathcal X$ 上の分布——すなわち $p(x) \ge 0$ かつ
$\sum_{x} p(x) = 1$ を満たす関数——全体を動く。
:::

::: formalized
`capacity` (`InformationTheory/Shannon/ChannelCoding/ShannonTheorem.lean`)
:::

$C(W)$ は通信路だけで決まる数で、入力分布にも符号にも依存しない。定義の時点では
「1 回の使用あたりどれだけ運べるか」という操作的な意味はまだ持っておらず、単に
相互情報量の最大化問題の値でしかない。それが誤りなく送れるレートの限界と一致する、
というのが 4.3 節以降の内容である。

上限と書いたが、実際には最大値である。それを示すには、$I(\cdot\,; W)$ が入力分布の
つくる集合の上で連続であることと、その集合がコンパクトであることの二つが要る。後者から
最大値の存在を引き出すために、次の一つを証明せずに借りる。

**Weierstrass の最大値定理を借りる.** 借りるのは「コンパクト集合の上の実数値連続関数は
最大値をとる」という形である。当てる相手は、有限次元の実ベクトル空間 $\mathbb R^{\mathcal X}$ の
有界閉集合である確率単体
$$
\Delta \;:=\; \Big\{\, p : \mathcal X \to \mathbb R \;\Big|\;
  p(x) \ge 0 \ (\forall x \in \mathcal X), \ \textstyle\sum_{x} p(x) = 1 \,\Big\}
$$
の上の実数値関数である。この借用に依存するのは定理 4.1.5 だけで、以降の節は定理 4.1.5 の
結論だけを使う。$I(\cdot\,; W)$ の連続性のほうは借りずに、1.1 節で認めた
$\varphi(t) = -t\log t$ の $[0,\infty)$ 上の連続性から下で組み立てる。

::: theorem 4.1.5
$\mathcal X$、$\mathcal Y$ を有限アルファベットとし、$W$ を通信路とする。このとき
$I(\cdot\,; W)$ を最大にする入力分布 $p^*$ が存在し、$C(W) = I(p^*; W)$ である。
:::

::: proof
$(X, Y)$ を結合分布 $p(x)W(y \mid x)$ に従う対とすると、命題 4.1.3 より
$I(p;W) = H(X) + H(Y) - H(X,Y)$ である。三つの項を $p$ の関数として書き下すと
$$
H(X) = \sum_{x} \varphi\big(p(x)\big), \quad
H(Y) = \sum_{y} \varphi\Big(\sum_{x} p(x) W(y \mid x)\Big), \quad
H(X, Y) = \sum_{x, y} \varphi\big(p(x) W(y \mid x)\big)
$$
となる。どの項も、$p$ の成分の一次結合に $\varphi$ を合成したものの有限和である。一次
結合は連続で、$\varphi$ は $[0,\infty)$ 上で連続だから、$p \mapsto I(p;W)$ は $\Delta$ の
上で連続である。

$\Delta$ は $\mathbb R^{\mathcal X}$ の有界閉集合である（有界性は $0 \le p(x) \le 1$ から、
閉であることは定義が等式と不等式で書けていることから従う）。よって借用した
Weierstrass の最大値定理により、$I(\cdot\,; W)$ は $\Delta$ の上で最大値をとる。それを
与える点を $p^*$ とする。

最後に $C(W) = I(p^*;W)$ を見る。$I(p^*;W)$ は値の集合 $\{I(p;W) : p \in \Delta\}$ の
上界であり、かつその集合の元でもある。上限は上界のうち最小のものだから、この二つから
$C(W) = I(p^*; W)$ である。
:::

::: formalized
最大化する入力分布の存在 `exists_capacity_achiever`、証明が使う連続性
`continuous_mutualInfoOfChannel_left` と上に有界であること `capacity_bddAbove`
(`InformationTheory/Shannon/ChannelCoding/ShannonTheorem.lean`)
:::

::: proposition 4.1.6
任意の通信路 $W$ に対し $C(W) \ge 0$。
:::

::: proof
定理 4.1.5 の $p^*$ をとると $C(W) = I(p^*;W)$ であり、命題 4.1.3 よりこれは対
$(X, Y)$ の相互情報量 $I(X;Y)$ に等しい。命題 1.3.2 よりそれは非負である。
:::

::: formalized
`capacity_nonneg` (`InformationTheory/Shannon/ChannelCoding/ShannonTheorem.lean`)
:::

::: proposition 4.1.7
任意の通信路 $W$ に対し
$C(W) \le \log \min\big(|\mathcal X|, |\mathcal Y|\big)$。
:::

::: proof
任意の入力分布 $p$ をとり、$(X, Y)$ を結合分布に従う対とする。命題 4.1.3 より
$I(p;W) = H(Y) - H(Y \mid X)$ であり、条件付きエントロピーは非負量の平均なので非負
（定義 1.2.2 と命題 1.1.4）。よって $I(p;W) \le H(Y)$ で、定理 1.1.5 より
$H(Y) \le \log|\mathcal Y|$ である。同じことを命題 4.1.3 のもう一つの形
$I(p;W) = H(X) - H(X \mid Y)$ で行えば $I(p;W) \le \log|\mathcal X|$ を得る。$p$ は任意
だったので、$\log\min(|\mathcal X|, |\mathcal Y|)$ は値の集合の上界であり、上限はそれ以下
である。
:::

読み方は素直である。1 回の使用で運べる情報は、入れ物の大きさを超えられない。送れる
記号が $|\mathcal X|$ 通りしかなければ、雑音がまったくなくても 1 回あたり
$\log|\mathcal X|$ より多くは運べないし、受け取る側の区別が $|\mathcal Y|$ 通りしか
ないなら同じことが出口の側で起きる。命題 4.1.7 は、容量が雑音の少なさだけでなく、
入口と出口の狭いほうにも押さえられていることを言っている。

## 二つの通信路で計算する

::: example 4.1.8 二元対称通信路
$\rho \in [0,1]$ を固定する。$\mathcal X = \mathcal Y = \{0, 1\}$ とし、
$$
W(1 \mid 0) \;=\; W(0 \mid 1) \;=\; \rho, \qquad
W(0 \mid 0) \;=\; W(1 \mid 1) \;=\; 1 - \rho
$$
で定まる通信路を、**反転確率** $\rho$ の **二元対称通信路** という。送ったビットが確率
$\rho$ で裏返り、確率 $1-\rho$ でそのまま届く通信路である。その容量は
$$
C(W) \;=\; 1 - H_b(\rho)
$$
であり、一様入力 $p(0) = p(1) = 1/2$ で達成される（$H_b$ は例 1.1.2 の二値エントロピー）。
:::

::: proof
まず $H(Y \mid X)$ が入力分布によらないことを見る。$X = x$ を固定すると、$Y$ は確率
$1-\rho$ で $x$、確率 $\rho$ で $x$ の反対をとるので、その分布のエントロピーは
$x$ によらず $H_b(\rho)$ である。定義 1.2.2 はこれを $p(x)$ で平均したものだから、
どんな入力分布 $p$ に対しても $H(Y \mid X) = H_b(\rho)$ である。

次に上界をとる。命題 4.1.3 より
$I(p; W) = H(Y) - H(Y \mid X) = H(Y) - H_b(\rho)$ であり、$|\mathcal Y| = 2$ に定理 1.1.5 を
当てると $H(Y) \le \log 2 = 1$ だから $I(p;W) \le 1 - H_b(\rho)$ である。

最後にこれが達成されることを見る。$p(0) = p(1) = 1/2$ とすると
$$
q(1) \;=\; \tfrac12 W(1 \mid 0) + \tfrac12 W(1 \mid 1)
  \;=\; \tfrac12 \rho + \tfrac12 (1-\rho) \;=\; \tfrac12
$$
であり、$q(0) = 1/2$ も同様である。出力は一様なので $H(Y) = 1$ となり、
$I(p;W) = 1 - H_b(\rho)$ に等しい。上界が達成されたので、定義 4.1.4 の上限はこの値で
ある。
:::

::: example 4.1.9 二元消失通信路
$\eta \in [0,1]$ を固定する。$\mathcal X = \{0,1\}$、$\mathcal Y = \{0, 1, \ast\}$ とし、
$$
W(x \mid x) \;=\; 1 - \eta, \qquad W(\ast \mid x) \;=\; \eta, \qquad
W\big(1 - x \,\big|\, x\big) \;=\; 0 \qquad (x \in \{0,1\})
$$
で定まる通信路を、**消失確率** $\eta$ の **二元消失通信路** という。送ったビットは確率
$1-\eta$ でそのまま届き、確率 $\eta$ で「読めなかった」ことを示す記号 $\ast$ に化ける。
裏返って届くことはない。その容量は
$$
C(W) \;=\; 1 - \eta
$$
であり、一様入力 $p(0) = p(1) = 1/2$ で達成される。
:::

::: proof
入力分布 $p$ を任意にとり、$\pi := p(1)$ とおく。二元対称通信路のときと同じく、
$X = x$ を固定したときの $Y$ の分布は「確率 $1-\eta$ で $x$、確率 $\eta$ で $\ast$」で、
そのエントロピーは $x$ によらず $H_b(\eta)$ である。よって $H(Y \mid X) = H_b(\eta)$。

出力分布は $q(0) = (1-\pi)(1-\eta)$、$q(1) = \pi(1-\eta)$、$q(\ast) = \eta$ である。
定義 1.1.1 に代入し、$\log$ の積を和に分けると
$$
H(Y) \;=\; -(1-\eta)\Big(\pi\log\pi + (1-\pi)\log(1-\pi)\Big)
  \;-\; (1-\eta)\log(1-\eta) \;-\; \eta\log\eta
  \;=\; (1-\eta)\,H_b(\pi) + H_b(\eta)
$$
となる（確率 0 の項は $0\log 0 = 0$ の約束により両辺で消えるので、分け方に注意は
要らない）。命題 4.1.3 より
$$
I(p; W) \;=\; H(Y) - H(Y \mid X) \;=\; (1-\eta)\,H_b(\pi)
$$
である。例 1.1.2 より $H_b(\pi) \le \log 2 = 1$ で、等号は $\pi = 1/2$ に限る。よって
$I(p;W) \le 1-\eta$ であり、一様入力でこの値が達成される。上界が達成されたので、
定義 4.1.4 の上限はこの値である。
:::

**二つを数で比べる.** 反転確率 $\rho = 0.1$ の二元対称通信路の容量は
$1 - H_b(0.1) \approx 0.531$ ビットである。いっぽう消失確率 $\eta = 0.1$ の二元消失
通信路は $1 - 0.1 = 0.9$ ビットで、こちらのほうがずっと大きい。どちらも 10 回に 1 回は
届いた記号が信用できないのに、差がこれだけ開くのは、**どこが壊れたかを受け取る側が
知っているかどうか**の違いによる。消失通信路では壊れた位置が $\ast$ として見えるので、
残りの $9$ 割はそのまま信用してよい。対称通信路では壊れた位置が見えないので、届いた
ビットのどれもが疑わしくなる。反転確率を $0.11$ まで上げると容量は約 $0.500$ ビットに
なり、ちょうど半分に落ちる。

**両端で確かめる.** 二元対称通信路で $\rho = 0$ なら $H_b(0) = 0$ で容量は 1 ビット
——雑音がないので 1 回に 1 ビット運べる。$\rho = 1$ でも $H_b(1) = 0$ なので容量は
やはり 1 ビットで、これは「必ず裏返る」通信路が受け取る側で読み替えれば無雑音と同じ
だからである。いちばん悪いのは $\rho = 1/2$ で、$H_b(1/2) = 1$ より容量は 0 になる。
このとき出力は入力に依らず一様で、何も運べない。二元消失通信路のほうは $\eta = 0$ で
1 ビット、$\eta = 1$ で 0 ビットと、消失確率にそのまま比例して減る。

::: formalization-note
命題 4.1.7、例 4.1.8、例 4.1.9 に対応する宣言は形式化されていない。本節の証明が
これら三つの保証のすべてである。

単位も本文と形式化で違う。形式化は $\log$ を自然対数にとるので、相互情報量も容量も
ナットが単位であり、本文が $2^{nR}$ と書く量はあちらでは $\exp(nR)$ にあたる。底を
そろえれば同じ主張である。本文が本節で底を 2 に固定したのは、第2章・第3章と同じく
指数の肩と対数の底をそろえて読みやすくするためで、この断りは本章でここ 1 度きりである。
:::

容量を達成する入力分布 $p^*$ は定理 4.1.5 で存在だけが分かっている。それを具体的に
見分ける条件——どの入力記号にどれだけ重みを置けばよいか——は 4.6 節で与える。二つの例で
一様入力が最大化したのは通信路の対称性のおかげで、一般にはそうならない。
