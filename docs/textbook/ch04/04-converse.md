# 4.4 逆定理

4.3 節は、レートが $C(W)$ を下回ってさえいれば誤り確率をいくらでも小さくできることを
示した。残るのは逆向きの問いである。$C(W)$ を超えるレートではどうなるのか——言い換えれば、
信頼できる通信ができるためにレートが満たさなければならない条件は何か。本節が示すのは
$R \le C(W)$ が必要だ、ということである。第2章が達成可能性（定理 2.3.2）と弱逆定理
（定理 2.3.4）を対にして情報源符号化定理に至ったのと、同じ形の対をここで作る。

達成可能性の証明は符号を一つ作れば済んだが、逆定理は**どんな符号を設計しても**という
全称の主張なので、構成では歯が立たない。使う道具は第2章の逆定理と同じ、ファノの不等式
（定理 1.10.1）である。ただし今度は情報源のエントロピーではなく、メッセージの個数
$\log M$ を左辺に置く。

論証は 4 歩でできている。**(i)** 一様なメッセージのもつ情報量 $\log M$ を、ファノの
不等式で「通信路が運んだぶん」と「誤りで説明されるぶん」に分ける（定理 4.4.1）。
**(ii)** データ処理不等式で、復号器の手前——通信路の入口と出口——の相互情報量に移す
（系 4.4.2）。ここまでは通信路に何の仮定も要らない。そこから先は二つの行き先がある。
**(iii)** チェイン則で時刻ごとに分解する（定理 4.4.3）。記憶のなさを仮定しないので、
記憶のある通信路にもそのまま当たる。**(iv)** 記憶のなさを入れて、各時刻の相互情報量の和
という扱いやすい形に落とす（定理 4.4.5）。最後にこれを容量で抑えて弱逆定理を得る
（系 4.4.6）。

以下、$W$ を 4.1 節の通信路とし、長さ $n$ のブロック通信路符号（定義 4.2.1）を扱う。
メッセージを表す確率変数を $\mathrm{Msg}$、その符号語を $X^n = c(\mathrm{Msg})$、通信路を
通した出力を $Y^n$、復号結果を $d(Y^n)$ と書く。$X_i$、$Y_i$ は第 $i$ 成分、
$X^{<i} := (X_0, \dots, X_{i-1})$ は先頭 $i$ 文字である。メッセージが一様分布に従うとき、
$\Pr[d(Y^n) \ne \mathrm{Msg}]$ は定義 4.2.1 の平均誤り確率 $\bar P_e$ に一致する
——メッセージごとの誤り確率を一様な重み $1/M$ で平均したものだからである。

## 一様なメッセージを分ける

::: theorem 4.4.1 単発逆定理
$M \ge 2$ とし、$\mathrm{Msg}$ を $\{1, \dots, M\}$ 上の一様分布に従う確率変数とする。
$Y$ を確率変数、$g$ を $Y$ の値から $\{1, \dots, M\}$ への写像とし、
$P_e := \Pr\big[g(Y) \ne \mathrm{Msg}\big]$ とおく。このとき
$$
\log M \;\le\; I(\mathrm{Msg}; Y) \;+\; H_b(P_e) \;+\; P_e \log(M - 1)
$$
（$H_b$ は例 1.1.2 の二値エントロピー）。
:::

::: proof
一様分布のエントロピーは定義 1.1.1 から
$$
H(\mathrm{Msg}) \;=\; -\sum_{m=1}^{M} \frac1M \log \frac1M \;=\; \log M
$$
である。定理 1.3.4 のエントロピー表現を対 $(\mathrm{Msg}, Y)$ に当てると
$$
H(\mathrm{Msg}) \;=\; I(\mathrm{Msg}; Y) + H(\mathrm{Msg} \mid Y)
$$
となる。右辺の第 2 項に、対象を $\mathrm{Msg}$、観測を $Y$、復号器を $g$ としてファノの
不等式（定理 1.10.1）を当てると
$H(\mathrm{Msg} \mid Y) \le H_b(P_e) + P_e \log(M-1)$ である。二つを合わせて主張を得る。
:::

::: formalized
`shannon_converse_single_shot` (`InformationTheory/Shannon/Converse.lean`)
:::

**左辺が誰のものかを見る.** 第2章 定理 2.3.4 では、左辺のブロックのエントロピー
$nH(X)$ が情報源だけで決まって動かせない量だった。こちらの左辺 $\log M$ は逆に、符号を
設計する側が決める量である。だから不等式の読み方も裏返る——あちらは「情報源が要求する
量を符号語数が支えなければならない」だったが、こちらは「設計者が $M$ を大きくとりたければ、
それを支えるだけの相互情報量が要る」になる。右辺の後ろ 2 項は誤りで説明がつく分で、
誤り確率を 0 に近づけるとどちらも消える。すると $\log M$ をすべて $I(\mathrm{Msg}; Y)$ が
支えなければならない。

::: formalization-note
形式化のルートは本文と一段ずれる。本文はファノの不等式が復号器を引数にとる形
（定理 1.10.1）をそのまま使ったが、形式化はまず復号結果で条件付けた形にファノの不等式を
当て、そのあとデータ処理不等式（定理 1.8.2）で観測を $Y$ に戻す。到達する不等式は同じで
ある。

形式化は出力の空間を有限とは仮定しないので、相互情報量が有限であるという前提が付く。
本章は有限アルファベットだけを扱うので、これは自動的に満たされる。
:::

## 復号器の手前へ移す

::: corollary 4.4.2
$M \ge 2$ とし、$\mathrm{Msg}$ を $\{1, \dots, M\}$ 上の一様分布に従う確率変数とする。
$X$、$Y$ を確率変数、$g$ を $Y$ の値から $\{1, \dots, M\}$ への写像とし、
$P_e := \Pr[g(Y) \ne \mathrm{Msg}]$ とおく。$\mathrm{Msg} \to X \to Y$ がマルコフ連鎖
（定義 1.8.3）をなすなら
$$
\log M \;\le\; I(X; Y) \;+\; H_b(P_e) \;+\; P_e \log(M - 1).
$$
:::

::: proof
定理 1.8.4 を連鎖 $\mathrm{Msg} \to X \to Y$ に当てると
$I(\mathrm{Msg}; Y) \le I(X; Y)$ である。定理 4.4.1 の右辺の第 1 項をこれで置き換えれば
よい。
:::

::: formalized
`shannon_converse_single_shot_markov_encoder`
(`InformationTheory/Shannon/Converse.lean`)
:::

マルコフ連鎖の仮定がどこから来るのかを確かめておく。符号語 $X = c(\mathrm{Msg})$ は
メッセージの関数だから、$\mathrm{Msg}$ を知れば $X$ も決まる。しかし系 4.4.2 が要求して
いるのはその向きではなく、**$X$ を知ってしまえば出力 $Y$ が $\mathrm{Msg}$ には直接
よらない**という向きである。通信路は符号語しか見ない、というのがその内容で、定義 4.1.1 の
通信路を符号語に当てるかぎり自動的に満たされる。裏返せば、符号語を通さずにメッセージが
出力へ漏れる経路があれば、この評価は使えない。

## 時刻ごとに分解する

::: theorem 4.4.3
$M \ge 2$、$n \ge 1$ とし、$\mathrm{Msg}$ を $\{1, \dots, M\}$ 上の一様分布に従う確率変数と
する。$X^n = (X_0, \dots, X_{n-1})$、$Y^n = (Y_0, \dots, Y_{n-1})$ を確率変数の組、$d$ を
$Y^n$ の値から $\{1, \dots, M\}$ への写像とし、$P_e := \Pr[d(Y^n) \ne \mathrm{Msg}]$ と
おく。$\mathrm{Msg} \to X^n \to Y^n$ がマルコフ連鎖（定義 1.8.3）をなすなら
$$
\log M \;\le\; \sum_{i=0}^{n-1} I\big(X_i; Y^n \,\big|\, X^{<i}\big)
  \;+\; H_b(P_e) \;+\; P_e \log(M-1)
$$
ここで $X^{<i} := (X_0, \dots, X_{i-1})$ である。
:::

::: proof
定理 1.5.2 を、変数列 $X_0, \dots, X_{n-1}$ と、相手側の変数を $Y^n$ として当てると
$$
I\big(X^n; Y^n\big) \;=\; \sum_{i=0}^{n-1} I\big(X_i; Y^n \,\big|\, X^{<i}\big)
$$
である。系 4.4.2 を $X \leftarrow X^n$、$Y \leftarrow Y^n$、$g \leftarrow d$ として使い、
その右辺の第 1 項をこの和で置き換えればよい。
:::

::: formalized
`channel_coding_converse_general_chainRule`
(`InformationTheory/Shannon/ChannelCoding/ConverseGeneral.lean`)
:::

定理 4.4.3 は通信路の記憶について何も仮定していない。積の形（定義 4.1.1）を満たさない
通信路——時刻をまたいで雑音が相関する通信路——にもそのまま当たる。そのぶん右辺の項は
扱いにくい。$I(X_i; Y^n \mid X^{<i})$ は「それ以前の入力を知ったうえで、時刻 $i$ の入力が
出力ブロック**全体**について与える情報」であって、1 時刻分の量ではない。これを 1 時刻分に
落とすところで、記憶のなさが初めて要る。

## 記憶のなさを入れる

::: definition 4.4.4 各時刻で記憶がない
確率変数の組 $X^n = (X_0, \dots, X_{n-1})$、$Y^n = (Y_0, \dots, Y_{n-1})$ が
**各時刻で記憶がない** とは、すべての $i$ について
$$
\big(X^{\ne i},\, Y^{\ne i}\big) \;\to\; X_i \;\to\; Y_i
$$
がマルコフ連鎖（定義 1.8.3）をなすことをいう。ここで $X^{\ne i}$ は $X_i$ 以外の入力を
すべて並べた組、$Y^{\ne i}$ は $Y_i$ 以外の出力をすべて並べた組である。
:::

::: formalized
`IsMemorylessChannel`
(`InformationTheory/Shannon/ChannelCoding/ConverseMemorylessChainRule.lean`)
:::

定義 4.1.1 は記憶のなさを、出力ブロックの条件付き分布が積に分かれるという通信路自身の
性質として書いた。定義 4.4.4 が書いているのはそこから出る別の顔——**時刻 $i$ の入力を
知ってしまえば、時刻 $i$ の出力は他の時刻の入出力について何も教えない**——である。逆定理で
要るのはこちらの形で、積の形のままでは相互情報量の評価に持ち込めない。積の形から定義 4.4.4
が従うことは、実際にそれを使う系 4.4.6 の証明の中で確かめる。

::: theorem 4.4.5 記憶のない通信路の逆定理
$M \ge 2$、$n \ge 1$ とし、$\mathrm{Msg}$ を $\{1, \dots, M\}$ 上の一様分布に従う確率変数と
する。$X^n = (X_0, \dots, X_{n-1})$、$Y^n = (Y_0, \dots, Y_{n-1})$ を確率変数の組、$d$ を
$Y^n$ の値から $\{1, \dots, M\}$ への写像とし、$P_e := \Pr[d(Y^n) \ne \mathrm{Msg}]$ と
おく。$\mathrm{Msg} \to X^n \to Y^n$ がマルコフ連鎖（定義 1.8.3）をなし、かつ $X^n$ と
$Y^n$ が各時刻で記憶がない（定義 4.4.4）なら
$$
\log M \;\le\; \sum_{i=0}^{n-1} I(X_i; Y_i) \;+\; H_b(P_e) \;+\; P_e \log(M-1).
$$
:::

::: proof
系 4.4.2 を $X \leftarrow X^n$、$Y \leftarrow Y^n$、$g \leftarrow d$ として使うと
$\log M \le I(X^n; Y^n) + H_b(P_e) + P_e\log(M-1)$ である。あとは第 1 項を
$\sum_i I(X_i; Y_i)$ で抑えればよい。

そのために定理 1.8.5 を使う。あの定理が「記憶がない」として要求していたのは二つの条件
——$X^n$ を与えたとき出力 $Y_0, \dots, Y_{n-1}$ が条件付き独立であること、各 $Y_i$ の
条件付き分布が同じ時刻の入力 $X_i$ だけで決まること——だった。定義 4.4.4 からこの二つが
出ることを見る。定義 4.4.4 は、$X_i$ を与えたとき $Y_i$ が $(X^{\ne i}, Y^{\ne i})$ と
条件付き独立であること、すなわち
$p(y_i \mid x^n, y^{\ne i}) = p(y_i \mid x_i)$ を言っている。条件を減らしてよいから
$$
p\big(y_i \mid x^n\big) \;=\; p\big(y_i \mid x_i\big), \qquad
p\big(y_i \mid x^n, y^{<i}\big) \;=\; p\big(y_i \mid x_i\big)
$$
がどちらも成り立つ。前者が第 2 の条件そのものである。後者を条件付き確率のチェイン則
$p(y^n \mid x^n) = \prod_i p(y_i \mid x^n, y^{<i})$ に代入すると
$$
p\big(y^n \mid x^n\big) \;=\; \prod_{i=0}^{n-1} p\big(y_i \mid x_i\big)
  \;=\; \prod_{i=0}^{n-1} p\big(y_i \mid x^n\big)
$$
となり、これが第 1 の条件——$X^n$ のもとでの出力の条件付き独立——である。

よって定理 1.8.5 より $I(X^n; Y^n) \le \sum_i I(X_i; Y_i)$ であり、主張を得る。
:::

`channel_coding_converse_general_memoryless_pure`
(`InformationTheory/Shannon/ChannelCoding/ConverseMemoryless.lean`)
:::

::: formalization-note
本文と形式化で証明のルートが違う。形式化は定理 4.4.3 のチェイン則形から出発し、各項を

## 弱逆定理

::: corollary 4.4.6 弱逆定理
$W$ を通信路（定義 4.1.1）とする。ブロック通信路符号の族 $(M_n, c_n, d_n)_{n\ge1}$ が
定義 4.2.2 の意味で達成可能なら、その達成レートは $C(W)$ 以下である。すなわち
$\mathcal R(W)$ のどの元も $C(W)$ を超えない。
:::

::: proof
族を一つとり、$R_n := \frac1n \log M_n$ とおく。定義 4.2.2 より
$P^{(n)}_{e,\max} \to 0$ であり、レートの列は上に有界だから $R_n \le B$ を満たす実数 $B$ が
とれる。

**メッセージに一様分布を入れる.** 定義 4.2.2 の達成可能性は最大誤り確率で書かれている
ので、メッセージにどんな分布を与えても平均誤り確率は $P^{(n)}_{e,\max}$ 以下である。
そこで各 $n$ について、$\mathrm{Msg}$ が $\{1, \dots, M_n\}$ 上の一様分布に従うとして
議論する。これは符号に置く追加の仮定ではなく、評価のためにこちらが選ぶ分布である。
このとき $P^{(n)}_e := \Pr[d_n(Y^n) \ne \mathrm{Msg}]$ は平均誤り確率に等しく、
$P^{(n)}_e \le P^{(n)}_{e,\max} \to 0$ である。

**$M_n = 1$ の項を片付ける.** そのような $n$ では $R_n = 0$ であり、命題 4.1.6 より
$0 \le C(W)$ だから $R_n \le C(W)$ が成り立つ。この $n$ については、以下で置く補正項を
$\delta_n := 0$ と定めておく。残る $n$ では $M_n \ge 2$ である。

**定理 4.4.5 の仮定を確かめる.** 符号語 $X^n = c_n(\mathrm{Msg})$ を通信路に通すのだから、
$X^n$ を与えたときの $Y^n$ の条件付き分布は
$W^n(y^n \mid x^n) = \prod_i W(y_i \mid x_i)$ であって $\mathrm{Msg}$ にはよらない。よって
$\mathrm{Msg} \to X^n \to Y^n$ はマルコフ連鎖である。またこの積の形から、$X^n$ を与えた
とき出力は互いに独立で、各 $Y_i$ の条件付き分布は $W(\cdot \mid x_i)$ である。したがって
$x^n$ と $y^{\ne i}$ の両方を知っても $Y_i$ の条件付き分布は $W(\cdot \mid x_i)$ のままで、
$X^n$ と $Y^n$ は各時刻で記憶がない（定義 4.4.4）。同じ計算から、$X_i$ の分布を $p_i$ と
書けば対 $(X_i, Y_i)$ の同時分布は $p_i(x) W(y \mid x)$ である。

**当てて割る.** 定理 4.4.5 より
$$
\log M_n \;\le\; \sum_{i=0}^{n-1} I(X_i; Y_i) \;+\; H_b\big(P^{(n)}_e\big)
  \;+\; P^{(n)}_e \log(M_n - 1)
$$
である。命題 4.1.3 より $I(X_i; Y_i) = I(p_i; W)$ であり、定義 4.1.4 の上限より
$I(p_i; W) \le C(W)$ だから、和は $n\,C(W)$ 以下である。$n$ で割ると
$$
R_n \;\le\; C(W) \;+\; \underbrace{\frac{H_b\big(P^{(n)}_e\big)}{n}
  \;+\; P^{(n)}_e \,\frac{\log(M_n - 1)}{n}}_{=:\ \delta_n}
$$
を得る。

**補正項が消える.** 第 1 項は、$P^{(n)}_e \to 0$ と定義 1.1.1 で置いた
$p \log p \to 0$（$p \downarrow 0$）の約束から $H_b(P^{(n)}_e) \to 0$ となり、さらに $n$ で
割るので 0 に収束する。第 2 項でレートの有界性が効く。$M_n \ge 2$ より
$\log(M_n - 1) \le \log M_n = n R_n$ だから
$$
P^{(n)}_e \,\frac{\log(M_n - 1)}{n} \;\le\; P^{(n)}_e\, R_n \;\le\; P^{(n)}_e\, B
$$
であり、$P^{(n)}_e \to 0$ よりこれも 0 に収束する。よって $\delta_n \to 0$ であり、
$R_n \le C(W) + \delta_n$ の両辺で下極限をとって $\liminf_n R_n \le C(W)$ を得る。
:::

::: formalization-note
系 4.4.6 に対応する単独の宣言はない。定理 4.4.5 に紐付けた宣言と、和の各項を容量で
抑える段——`mutualInfoOfChannel_toReal_le_capacity`
(`InformationTheory/Shannon/BlockwiseChannel/MemorylessCapacity.lean`)——の合成で得られる。
後者はファイルの中に閉じた補題である。
:::

**二つの補正項を見分ける.** $H_b(P^{(n)}_e)/n$ のほうは「誤ったかどうか」の 1 ビット以下
しかなく、$n$ で割れば無条件に消える。$P^{(n)}_e \log(M_n-1)/n$ のほうはそうではない。
$\log(M_n-1)$ は
$n$ とともに増える量——ほぼ $nR_n$——なので、$n$ で割っても $R_n$ 程度にしか小さくならない。
これが消えるのは $P^{(n)}_e$ が 0 に向かうからであり、しかもそのためにレートが上に有界で
ある
ことが要る。定義 4.2.2 がレートの列に上界を課していたのは、ここで効かせるためである。
第2章 定理 2.3.4 では同じ項が $\log(|\mathcal X|^n - 1) \le n \log|\mathcal X|$ と
アルファベットの大きさで抑えられたので、この心配は要らなかった。符号のメッセージ数は
設計者が決める量なので、上から抑える手が別に要る。

**二つの向きが $C(W)$ を挟む.** 定理 4.3.7 は $C(W)$ 未満のどのレートでも符号が作れる
ことを、系 4.4.6 は達成レートが $C(W)$ を超えないことを言っている。前者は符号を一つ構成
する存在の主張、後者はあらゆる符号にわたる全称の主張で、道具も証明の形も違う。この二つが
$C(W)$ を両側から挟むことで、4.1 節で最大化問題の値として定義したにすぎない $C(W)$ が、
通信路を 1 回使うあたりに運べる情報量という操作的な意味をもつ。

系 4.4.6 が $P^{(n)}_{e,\max} \to 0$ を仮定していることに注意しておきたい。言えているのは
「レートが $C(W)$ を超えるなら誤り確率は 0 に向かわない」までで、誤り確率がどこまで大きく
なるかは何も言っていない。この仮定を置かない形——誤り確率がむしろ 1 に向かうこと——は
4.6 節で扱う。
