# 4.4 逆定理

4.3 節は、レートが $C(W)$ を下回ってさえいれば誤り確率をいくらでも小さくできることを示した。残るのは逆向きの問いである。$C(W)$ を超えるレートではどうなるのか——言い換えれば、信頼できる通信ができるためにレートが満たさなければならない条件は何か。本節が示すのは$R \le C(W)$ が必要だ、ということである。第2章が達成可能性（定理 2.3.2）と弱逆定理（定理 2.3.4）を対にして情報源符号化定理に至ったのと、同じ形の対をここで作る。

達成可能性の証明は符号を一つ作れば済んだが、逆定理は**どんな符号を設計しても**という全称の主張なので、構成では歯が立たない。使う道具は第2章の逆定理と同じ、ファノの不等式（定理 1.10.1）である。ただし今度は情報源のエントロピーではなく、メッセージの個数$\log M$ を左辺に置く。

論証は 4 歩でできている。**(i)** 一様なメッセージのもつ情報量 $\log M$ を、ファノの不等式で「通信路が運んだぶん」と「誤りで説明されるぶん」に分ける（定理 4.4.1）。
**(ii)** データ処理不等式で、復号器の手前——通信路の入口と出口——の相互情報量に移す（系 4.4.2）。ここまでは通信路に何の仮定も要らない。そこから先は二つの行き先がある。
**(iii)** チェイン則で時刻ごとに分解する（定理 4.4.3）。記憶のなさを仮定しないので、記憶のある通信路にもそのまま当たる。ただしこれは本節の弱逆定理には使わない寄り道で、次の (iv) は (iii) を経由せず (ii) から直接出る。**(iv)** 記憶のなさを入れて、各時刻の相互情報量の和という扱いやすい形に落とす（定理 4.4.5）。最後にこれを容量で抑えて弱逆定理を得（系 4.4.8）、4.3 節の達成可能性（系 4.3.8）と突き合わせて通信路符号化定理（定理 4.4.9）に至る。

以下、$W$ を 4.1 節の通信路とし、長さ $n$ のブロック通信路符号（定義 4.2.1）を扱う。メッセージを表す確率変数を $\mathrm{Msg}$、その符号語を $X^n = c(\mathrm{Msg})$、通信路を通した出力を $Y^n$、復号結果を $d(Y^n)$ と書く。$X_i$、$Y_i$ は第 $i$ 成分、$X^{<i} := (X_0, \dots, X_{i-1})$ は先頭 $i$ 文字である。メッセージが一様分布に従うとき、$\Pr[d(Y^n) \ne \mathrm{Msg}]$ は定義 4.2.1 の平均誤り確率 $\bar P_e$ に一致する——メッセージごとの誤り確率を一様な重み $1/M$ で平均したものだからである。

## 一様なメッセージを分ける

::: theorem 4.4.1 単発逆定理
$M \ge 2$ とし、$\mathrm{Msg}$ を $\{1, \dots, M\}$ 上の一様分布に従う確率変数とする。$Y$ を有限集合に値をとる確率変数、$g$ を $Y$ の値から $\{1, \dots, M\}$ への写像とし、$P_e := \Pr\big[g(Y) \ne \mathrm{Msg}\big]$ とおく。このとき
$$
\log M \;\le\; I(\mathrm{Msg}; Y) \;+\; H_b(P_e) \;+\; P_e \log(M - 1)
$$
（$H_b$ は例 1.1.2 の二値エントロピー）。
:::

::: proof
一様分布のエントロピーは定義 1.1.1 から
$$
H(\mathrm{Msg}) \;=\; -\sum_{m=1}^{M} \frac1M \log \frac1M \;=\; \log M
$$
である。定理 1.3.4 のエントロピー表現を対 $(\mathrm{Msg}, Y)$ に当てると
$$
H(\mathrm{Msg}) \;=\; I(\mathrm{Msg}; Y) + H(\mathrm{Msg} \mid Y)
$$
となる。右辺の第 2 項に、対象を $\mathrm{Msg}$、観測を $Y$、復号器を $g$ としてファノの不等式（定理 1.10.1）を当てると$H(\mathrm{Msg} \mid Y) \le H_b(P_e) + P_e \log(M-1)$ である。二つを合わせて主張を得る。
:::

::: formalized
`shannon_converse_single_shot` (`InformationTheory/Shannon/Converse.lean`)
:::

**左辺が誰のものかを見る.** 第2章 定理 2.3.4 では、左辺のブロックのエントロピー$nH(X)$ が情報源だけで決まって動かせない量だった。こちらの左辺 $\log M$ は逆に、符号を設計する側が決める量である。だから不等式の読み方も裏返る——あちらは「情報源が要求する量を符号語数が支えなければならない」だったが、こちらは「設計者が $M$ を大きくとりたければ、それを支えるだけの相互情報量が要る」になる。右辺の後ろ 2 項は誤りで説明がつく分で、誤り確率を 0 に近づけるとどちらも消える。すると $\log M$ をすべて $I(\mathrm{Msg}; Y)$ が支えなければならない。

::: formalization-note
形式化のルートは本文と一段ずれる。本文はファノの不等式が復号器を引数にとる形（定理 1.10.1）をそのまま使ったが、形式化はまず復号結果で条件付けた形にファノの不等式を当て、そのあとデータ処理不等式（定理 1.8.2）で観測を $Y$ に戻す。到達する不等式は同じである。

形式化は出力の空間を有限とは仮定しないので、相互情報量が有限であるという前提が付く。本章は有限アルファベットだけを扱うので、これは自動的に満たされる。
:::

## 復号器の手前へ移す

::: corollary 4.4.2
$M \ge 2$ とし、$\mathrm{Msg}$ を $\{1, \dots, M\}$ 上の一様分布に従う確率変数とする。$\mathcal X$ を有限集合、$c : \{1, \dots, M\} \to \mathcal X$ を写像とし、$X := c(\mathrm{Msg})$ とおく。$Y$ を有限集合に値をとる確率変数、$g$ を $Y$ の値から$\{1, \dots, M\}$ への写像とし、$P_e := \Pr[g(Y) \ne \mathrm{Msg}]$ とおく。$\mathrm{Msg} \to X \to Y$ がマルコフ連鎖（定義 1.8.3）をなすなら
$$
\log M \;\le\; I(X; Y) \;+\; H_b(P_e) \;+\; P_e \log(M - 1).
$$
:::

::: proof
定理 1.8.4 を連鎖 $\mathrm{Msg} \to X \to Y$ に当てると$I(\mathrm{Msg}; Y) \le I(X; Y)$ である。定理 4.4.1 の右辺の第 1 項をこれで置き換えればよい。
:::

::: formalized
`shannon_converse_single_shot_markov_encoder` (`InformationTheory/Shannon/Converse.lean`)
:::

マルコフ連鎖の仮定がどこから来るのかを確かめておく。符号語 $X = c(\mathrm{Msg})$ はメッセージの関数だから、$\mathrm{Msg}$ を知れば $X$ も決まる。しかし系 4.4.2 が要求しているのはその向きではなく、**$X$ を知ってしまえば出力 $Y$ が $\mathrm{Msg}$ には直接よらない**という向きである。通信路は符号語しか見ない、というのがその内容で、定義 4.1.1 の通信路を符号語に当てるかぎり自動的に満たされる。裏返せば、符号語を通さずにメッセージが出力へ漏れる経路があれば、この評価は使えない。

## 時刻ごとに分解する

::: theorem 4.4.3
$M \ge 2$、$n \ge 1$ とし、$\mathrm{Msg}$ を $\{1, \dots, M\}$ 上の一様分布に従う確率変数とする。$\mathcal X$ を有限集合、$c : \{1, \dots, M\} \to \mathcal X^n$ を写像とし、$X^n = (X_0, \dots, X_{n-1}) := c(\mathrm{Msg})$ とおく。$Y^n = (Y_0, \dots, Y_{n-1})$ を有限集合に値をとる確率変数の組、$d$ を $Y^n$ の値から $\{1, \dots, M\}$ への写像とし、$P_e := \Pr[d(Y^n) \ne \mathrm{Msg}]$ とおく。$\mathrm{Msg} \to X^n \to Y^n$ がマルコフ連鎖（定義 1.8.3）をなすなら
$$
\log M \;\le\; \sum_{i=0}^{n-1} I\big(X_i; Y^n \,\big|\, X^{<i}\big)
  \;+\; H_b(P_e) \;+\; P_e \log(M-1)
$$
ここで $X^{<i} := (X_0, \dots, X_{i-1})$ である。
:::

::: proof
定理 1.5.2 を、変数列 $X_0, \dots, X_{n-1}$ と、相手側の変数を $Y^n$ として当てると
$$
I\big(X^n; Y^n\big) \;=\; \sum_{i=0}^{n-1} I\big(X_i; Y^n \,\big|\, X^{<i}\big)
$$
である。系 4.4.2 を $X \leftarrow X^n$、$Y \leftarrow Y^n$、$g \leftarrow d$ として使い、その右辺の第 1 項をこの和で置き換えればよい。
:::

::: formalized
`channel_coding_converse_general_chainRule` (`InformationTheory/Shannon/ChannelCoding/ConverseGeneral.lean`)
:::

定理 4.4.3 は通信路の記憶について何も仮定していない。積の形（定義 4.1.1）を満たさない通信路——時刻をまたいで雑音が相関する通信路——にもそのまま当たる。そのぶん右辺の項は扱いにくい。$I(X_i; Y^n \mid X^{<i})$ は「それ以前の入力を知ったうえで、時刻 $i$ の入力が出力ブロック**全体**について与える情報」であって、1 時刻分の量ではない。これを 1 時刻分に落とすところで、記憶のなさが初めて要る。

## 記憶のなさを入れる

::: definition 4.4.4 各時刻で記憶がない
確率変数の組 $X^n = (X_0, \dots, X_{n-1})$、$Y^n = (Y_0, \dots, Y_{n-1})$ が**各時刻で記憶がない** とは、すべての $i$ について
$$
\big(X^{\ne i},\, Y^{\ne i}\big) \;\to\; X_i \;\to\; Y_i
$$
がマルコフ連鎖（定義 1.8.3）をなすことをいう。ここで $X^{\ne i}$ は $X_i$ 以外の入力をすべて並べた組、$Y^{\ne i}$ は $Y_i$ 以外の出力をすべて並べた組である。
:::

::: formalized
`IsMemorylessChannel` (`InformationTheory/Shannon/ChannelCoding/ConverseMemorylessChainRule.lean`)
:::

定義 4.1.1 は記憶のなさを、出力ブロックの条件付き分布が積に分かれるという通信路自身の性質として書いた。定義 4.4.4 が書いているのはそこから出る別の顔——**時刻 $i$ の入力を知ってしまえば、時刻 $i$ の出力は他の時刻の入出力について何も教えない**——である。逆定理で要るのはこちらの形で、積の形のままでは相互情報量の評価に持ち込めない。積の形から定義 4.4.4が従うことは補題 4.4.6 で確かめる。

::: theorem 4.4.5 記憶のない通信路の逆定理
$M \ge 2$、$n \ge 1$ とし、$\mathrm{Msg}$ を $\{1, \dots, M\}$ 上の一様分布に従う確率変数とする。$\mathcal X$ を有限集合、$c : \{1, \dots, M\} \to \mathcal X^n$ を写像とし、$X^n = (X_0, \dots, X_{n-1}) := c(\mathrm{Msg})$ とおく。$Y^n = (Y_0, \dots, Y_{n-1})$ を有限集合に値をとる確率変数の組、$d$ を $Y^n$ の値から $\{1, \dots, M\}$ への写像とし、$P_e := \Pr[d(Y^n) \ne \mathrm{Msg}]$ とおく。$\mathrm{Msg} \to X^n \to Y^n$ がマルコフ連鎖（定義 1.8.3）をなし、かつ $X^n$ と $Y^n$ が各時刻で記憶がない（定義 4.4.4）なら
$$
\log M \;\le\; \sum_{i=0}^{n-1} I(X_i; Y_i) \;+\; H_b(P_e) \;+\; P_e \log(M-1).
$$
:::

::: proof
系 4.4.2 を $X \leftarrow X^n$、$Y \leftarrow Y^n$、$g \leftarrow d$ として使うと$\log M \le I(X^n; Y^n) + H_b(P_e) + P_e\log(M-1)$ である。あとは第 1 項を$\sum_i I(X_i; Y_i)$ で抑えればよい。

そのために定理 1.8.5 を使う。あの定理が「記憶がない」として要求していたのは二つの条件——$X^n$ を与えたとき出力 $Y_0, \dots, Y_{n-1}$ が条件付き独立であること、各 $Y_i$ の条件付き分布が同じ時刻の入力 $X_i$ だけで決まること——だった。定義 4.4.4 からこの二つが出ることを見る。以下、条件付き確率を $\Pr[\,\cdot \mid \cdot\,]$ と書き、$\Pr[y_i \mid x^n]$ のように事象 $\{Y_i = y_i\}$・$\{X^n = x^n\}$ を値だけで表す（条件の側が正の確率をもつ点で考える）。定義 4.4.4 は、$X_i$ を与えたとき $Y_i$ が$(X^{\ne i}, Y^{\ne i})$ と条件付き独立であること、すなわち$\Pr[y_i \mid x^n, y^{\ne i}] = \Pr[y_i \mid x_i]$ を言っている。細かい条件での等式が全点で成り立つので、落とした変数について平均をとれば粗い条件での等式が従う。よって
$$
\Pr\big[y_i \mid x^n\big] \;=\; \Pr\big[y_i \mid x_i\big], \qquad
\Pr\big[y_i \mid x^n, y^{<i}\big] \;=\; \Pr\big[y_i \mid x_i\big]
$$
がどちらも成り立つ。前者が第 2 の条件そのものである。後者を条件付き確率のチェイン則$\Pr[y^n \mid x^n] = \prod_i \Pr[y_i \mid x^n, y^{<i}]$ に代入すると
$$
\Pr\big[y^n \mid x^n\big] \;=\; \prod_{i=0}^{n-1} \Pr\big[y_i \mid x_i\big]
  \;=\; \prod_{i=0}^{n-1} \Pr\big[y_i \mid x^n\big]
$$
となり、これが第 1 の条件——$X^n$ のもとでの出力の条件付き独立——である。

よって定理 1.8.5 より $I(X^n; Y^n) \le \sum_i I(X_i; Y_i)$ であり、主張を得る。
:::

`channel_coding_converse_general_memoryless_pure` (`InformationTheory/Shannon/ChannelCoding/ConverseMemoryless.lean`)
:::

::: formalization-note
形式化も本文と同じく、系 4.4.2 から定理 1.8.5 へ渡る。定理 4.4.3 のチェイン則形から出発して各項を $I(X_i; Y^n \mid X^{<i}) \le I(X_i; Y_i)$ と時刻ごとに抑える道は、符号化写像を一般にとると途中で要る条件付き独立が成り立たないため通れない。同じ入力記号を二つの時刻に並べる符号化写像がその反例になる。

定理 4.4.5 が仮定に置いた定義 4.4.4 が、実際に通信路を使う場面では満たされていることを確かめておく。ここが積の形（定義 4.1.1）から記憶のなさの条件付き独立形へ渡る唯一の箇所であり、4.7 節も同じ橋をこの補題を通して渡る。

::: lemma 4.4.6 積の形から各時刻の記憶のなさへ
$W$ を通信路（定義 4.1.1）、$n \ge 1$ とする。$X^n = (X_0, \dots, X_{n-1})$ を$\mathcal X^n$ に値をとる確率変数の組とし、$Y^n = (Y_0, \dots, Y_{n-1})$ を、$X^n = x^n$ を与えたときの条件付き分布が$W^n(\cdot \mid x^n) = \prod_{i} W(\cdot \mid x_i)$ である $\mathcal Y^n$ に値をとる確率変数の組とする。このとき、$X^n$ を与えたとき $Y_0, \dots, Y_{n-1}$ は条件付き独立であって各 $Y_i$ の条件付き分布は $W(\cdot \mid X_i)$ であり、$X^n$ と $Y^n$ は各時刻で記憶がなく（定義 4.4.4）、さらに各 $i$ について $X_i$ の分布を $p_i$ と書けば対$(X_i, Y_i)$ の同時分布は $p_i(x)\,W(y \mid x)$ である。
:::

::: proof
以下、条件付き確率を $\Pr[\,\cdot \mid \cdot\,]$ と書き、条件の側が正の確率をもつ点で考える。

**条件付き独立と各時刻の条件付き分布.** 仮定は$\Pr[y^n \mid x^n] = \prod_{i} W(y_i \mid x_i)$ そのものである。右辺は$y_0, \dots, y_{n-1}$ それぞれだけに依る因子の積だから、$X^n$ を与えたときの $Y^n$ の条件付き分布は積に分かれており、これが条件付き独立である。第 $i$ 成分の条件付き周辺分布は、$j \ne i$ の $y_j$ について和をとれば各因子の総和が 1 になるので、$W(\cdot \mid x_i)$である。

**各時刻で記憶がない.** 積に分かれることから$\Pr[y_i \mid x^n, y^{\ne i}] = W(y_i \mid x_i)$ である。右辺は $x_i$ だけの関数だから、$x_i$ を固定して $x^{\ne i}$ について平均をとると $\Pr[y_i \mid x_i] = W(y_i \mid x_i)$ を得る。二つを合わせて $\Pr[y_i \mid x^n, y^{\ne i}] = \Pr[y_i \mid x_i]$ であり、これは$X_i$ を与えたとき $Y_i$ が $(X^{\ne i}, Y^{\ne i})$ と条件付き独立だということ、すなわち定義 4.4.4 である。

**対の同時分布.** 条件付き周辺分布が $W(\cdot \mid x_i)$ であることから
$$
\Pr\big[X_i = x,\; Y_i = y\big]
  \;=\; \sum_{x^n \,:\, x_i = x} \Pr\big[X^n = x^n\big]\, W\big(y \mid x\big)
  \;=\; p_i(x)\, W\big(y \mid x\big)
$$
である。
:::

## 弱逆定理

弱逆定理の証明には、ファノの不等式が残す二つの項が消えるという評価が要る。それだけを先に切り出しておく。

::: lemma 4.4.7 補正項は消える
$(P_n)_{n \ge 1}$ を $[0, 1]$ に値をとる実数列、$(R_n)_{n \ge 1}$ を上に有界な非負実数列とする。$P_n \to 0$ ならば
$$
\frac{H_b\big(P_n\big)}{n} \;+\; P_n\, R_n \;\longrightarrow\; 0 \qquad (n \to \infty)
$$
である（$H_b$ は例 1.1.2 の二値エントロピー）。
:::

::: proof
第 1 項について。命題 1.1.4 より $H_b(P_n) \ge 0$ であり、例 1.1.2 より$H_b(P_n) \le \log 2 = 1$ である。$n$ で割れば $0 \le H_b(P_n)/n \le 1/n$ であり、これは0 に収束する。

第 2 項について。$R_n \le B$ を満たす実数 $B$ をとる。$R_n \ge 0$ と $P_n \ge 0$ から$0 \le P_n R_n \le P_n B$ であり、$P_n \to 0$ よりこれも 0 に収束する。二つを足して主張を得る。
:::

::: formalization-note
補題 4.4.7 に対応する宣言は形式化されていない。補題 4.4.7 に付した証明が、この主張の保証のすべてである。
:::

::: corollary 4.4.8 弱逆定理
$W$ を通信路（定義 4.1.1）とする。ブロック通信路符号の族 $(M_n, c_n, d_n)_{n\ge1}$ が定義 4.2.2 の意味で達成可能なら、その達成レートは $C(W)$ 以下である。すなわち$\mathcal R(W)$ のどの元も $C(W)$ を超えない。
:::

::: proof
族を一つとり、$R_n := \frac1n \log M_n$ とおく。定義 4.2.2 より$P^{(n)}_{e,\max} \to 0$ であり、レートの列は上に有界である。$M_n \ge 1$ より$R_n \ge 0$ でもある。

**メッセージに一様分布を入れる.** 定義 4.2.2 の達成可能性は最大誤り確率で書かれているので、メッセージにどんな分布を与えても平均誤り確率は $P^{(n)}_{e,\max}$ 以下である。そこで各 $n$ について、$\mathrm{Msg}$ が $\{1, \dots, M_n\}$ 上の一様分布に従うとして議論する。これは符号に置く追加の仮定ではなく、評価のためにこちらが選ぶ分布である。このとき $P^{(n)}_e := \Pr[d_n(Y^n) \ne \mathrm{Msg}]$ は平均誤り確率に等しく、$P^{(n)}_e \le P^{(n)}_{e,\max} \to 0$ である。

**補正項を置く.** $\delta_n := H_b\big(P^{(n)}_e\big)/n + P^{(n)}_e R_n$ とおく。これは非負であり、$P^{(n)}_e \to 0$ と $(R_n)$ の有界性から、補題 4.4.7 より $\delta_n \to 0$ である。以下、どの $n$ でも $R_n \le C(W) + \delta_n$ であることを示せばよい。

**$M_n = 1$ の項を片付ける.** そのような $n$ では $R_n = 0$ であり、命題 4.1.6 より$0 \le C(W)$ だから $R_n \le C(W) \le C(W) + \delta_n$ が成り立つ。残る $n$ では$M_n \ge 2$ である。

**定理 4.4.5 の仮定を確かめる.** 符号語 $X^n = c_n(\mathrm{Msg})$ を通信路に通すのだから、$X^n$ を与えたときの $Y^n$ の条件付き分布は$W^n(y^n \mid x^n) = \prod_i W(y_i \mid x_i)$ であって $\mathrm{Msg}$ にはよらない。$\mathrm{Msg}$ によらないことが定義 1.8.3 の条件付き独立そのものだから、$\mathrm{Msg} \to X^n \to Y^n$ はマルコフ連鎖である。積の形から、補題 4.4.6 より $X^n$ と$Y^n$ は各時刻で記憶がなく（定義 4.4.4）、$X_i$ の分布を $p_i$ と書けば対$(X_i, Y_i)$ の同時分布は $p_i(x) W(y \mid x)$ である。

**当てて割る.** 定理 4.4.5 より
$$
\log M_n \;\le\; \sum_{i=0}^{n-1} I(X_i; Y_i) \;+\; H_b\big(P^{(n)}_e\big)
  \;+\; P^{(n)}_e \log(M_n - 1)
$$
である。命題 4.1.3 より $I(X_i; Y_i) = I(p_i; W)$ であり、定義 4.1.4 の上限より$I(p_i; W) \le C(W)$ だから、和は $n\,C(W)$ 以下である。$M_n \ge 2$ より$\log(M_n - 1) \le \log M_n = n R_n$ でもある。$n$ で割ると
$$
R_n \;\le\; C(W) \;+\; \frac{H_b\big(P^{(n)}_e\big)}{n} \;+\; P^{(n)}_e\, R_n
  \;=\; C(W) \;+\; \delta_n
$$
を得る。

**下極限をとる.** どの $n$ でも $R_n \le C(W) + \delta_n$ であり $\delta_n \to 0$ だから、両辺で下極限をとって $\liminf_n R_n \le C(W)$ を得る。
:::

::: formalization-note
系 4.4.8 に対応する単独の宣言はない。定理 4.4.5 に紐付けた宣言と、和の各項を容量で抑える段——`mutualInfoOfChannel_toReal_le_capacity` (`InformationTheory/Shannon/BlockwiseChannel/MemorylessCapacity.lean`)——の合成で得られる。後者はファイルの中に閉じた補題である。
:::

**二つの補正項を見分ける.** $H_b(P^{(n)}_e)/n$ のほうは「誤ったかどうか」の 1 ビット以下しかなく、$n$ で割れば無条件に消える。$P^{(n)}_e \log(M_n-1)/n$ のほうはそうではない。$\log(M_n-1)$ は $n$ とともに増える量——ほぼ $nR_n$——なので、$n$ で割っても $R_n$ 程度にしか小さくならない。これが消えるのは $P^{(n)}_e$ が 0 に向かうからであり、しかもそのためにはレートが上に有界であることが要る。補題 4.4.7 が有界性を仮定に置き、定義 4.2.2 がレートの列に上界を課していたのは、ここで効かせるためである。第2章 定理 2.3.4 では同じ項が$\log(|\mathcal X|^n - 1) \le n \log|\mathcal X|$ とアルファベットの大きさで抑えられたので、この心配は要らなかった。符号のメッセージ数は設計者が決める量なので、上から抑える手が別に要る。

## 通信路符号化定理

達成可能性（系 4.3.8）と弱逆定理（系 4.4.8）がそろったので、本章の題目そのものを述べる。第2章が達成可能性と弱逆定理を情報源符号化定理（定理 2.3.6）にまとめたのと、同じ形の合わせ方である。

::: theorem 4.4.9 通信路符号化定理
$W$ を通信路（定義 4.1.1）とする。このとき定義 4.2.2 の達成レートの集合 $\mathcal R(W)$ は空でなく、
$$
\sup \mathcal R(W) \;=\; C(W)
$$
である。
:::

::: proof
**$\mathcal R(W)$ は空でない.** 各 $n$ でメッセージ数 1 の符号——符号語は 1 本、復号器はつねに $1$ を返す——をとる。誤りの事象は空だから最大誤り確率は 0 であり、レートの列は$R_n = 0$ で上に有界である。よってこの族は定義 4.2.2 の意味で達成可能で、その達成レートは$\liminf_n R_n = 0$ である。すなわち $0 \in \mathcal R(W)$ である。

**$\sup \mathcal R(W) \le C(W)$.** 系 4.4.8 より $\mathcal R(W)$ のどの元も $C(W)$ 以下だから、$C(W)$ は $\mathcal R(W)$ の上界である。上限は上界のうち最小のものだから$\sup \mathcal R(W) \le C(W)$ である。

**$C(W) \le \sup \mathcal R(W)$.** 命題 4.1.6 より $C(W) \ge 0$ なので、$C(W) = 0$ か$C(W) > 0$ かで場合は尽きている。$C(W) = 0$ なら $0 \in \mathcal R(W)$ から$\sup \mathcal R(W) \ge 0 = C(W)$ である。$C(W) > 0$ なら、$0 < R < C(W)$ を満たす実数 $R$を任意にとると、系 4.3.8 より $R \in \mathcal R(W)$ であり $\sup \mathcal R(W) \ge R$ である。$R$ は $C(W)$ 未満の任意の正数だったから $\sup \mathcal R(W) \ge C(W)$ である。

二つを合わせて等号を得る。
:::

::: formalization-note
定理 4.4.9 に対応する単独の宣言はない。達成レートの集合そのものに対応する宣言が通信路の側には用意されていないので、両側を突き合わせるこの主張も形式化の外にある。片側ずつの機械検証は、達成可能性が定理 4.3.7 に、逆定理が定理 4.4.5 に紐付けた宣言まで及んでいる。
:::

定理 4.4.9 は上限が達成されるかどうかを言っていない。$R = C(W)$ ちょうどのレートで最大誤り確率が 0 に収束する符号族があるかは、ここでは問わない。第2章 定理 2.3.6 が下限の達成を問わなかったのと同じである。

**二つの向きが $C(W)$ を挟む.** 定理 4.3.7 は $C(W)$ 未満のどのレートでも符号が作れることを、系 4.4.8 は達成レートが $C(W)$ を超えないことを言っている。前者は符号を一つ構成する存在の主張、後者はあらゆる符号にわたる全称の主張で、道具も証明の形も違う。この二つが$C(W)$ を両側から挟むことで、4.1 節で最大化問題の値として定義したにすぎない $C(W)$ が、通信路を 1 回使うあたりに運べる情報量という操作的な意味をもつ。

系 4.4.8 が $P^{(n)}_{e,\max} \to 0$ を仮定していることに注意しておきたい。言えているのは「レートが $C(W)$ を超えるなら誤り確率は 0 に向かわない」までで、誤り確率がどこまで大きくなるかは何も言っていない。この仮定を置かない形——誤り確率がむしろ 1 に向かうこと——は4.6 節で扱う。
