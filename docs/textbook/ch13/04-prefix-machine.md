# 13.4 自己限定万能機械と万能確率

13.3 節は，情報源が出した長さ $n$ のブロックの複雑性を平均し，その値が $1$ 文字あたりでエントロピーに近づくことを示した．そこで測っていたのは分布から出た系列であり，主役は分布のほうだった．本節から先は分布を持ち出さない．以下に現れる対象は情報源ではなく，一つの自然数と一つの機械だけである．

13.3 節までの記述長は，一つの対象に最短の記述の長さを与えるものだった．見ているのは最短の一本だけで，同じ対象に短い記述が何本あるかは値に効かない．本節は測り方を裏返す．プログラムをでたらめに書いたとき，その対象が出てくる確率を，対象の重みとするのである．こう測れば，短い記述を持つ対象ほど重く，短い記述を何本も持つ対象はそのぶんさらに重い．二つの測り方は無関係ではなく，本節の 定理 13.4.10 が，記述の短さと重みの大きさが係数 $2$ の範囲で互いを決めることを示す．この重みを情報源の分布に結びつける話，すなわちその対数を第12章の意味の万能符号の符号長として読む話は，本書では扱わない．

重みの作り方は素朴である．プログラムをでたらめなビット列だと思えば，投げたビットがちょうど $s$ になる確率は $2^{-\lvert s\rvert}$ だから，$x$ を出すプログラム $s$ についてこれを足し合わせればよい．足した値が確率として読めるためには，プログラムの側に一つ条件が要る．読む側が，渡されたビットをどこまで読めばプログラムが終わるかを，読んだ範囲だけで決められることである．プログラムが自分の終わりを自分で告げる，と言ってもよい．そうなっていれば，値を持つプログラムのどの一本も，他の一本の先頭には現れない．

定義 13.1.4 の $\mathcal U$ はそうなっていない．$\mathcal U$ は先頭が $0$ でその後ろが任意のビット列であるものすべてに値を持つので，たとえば $0$ も $00$ も値 $0$ を持ち，前者は後者の語頭（定義 4.1.2）である．終わりを告げる手立てがないぶん，同じ値を出すプログラムがいくらでも長く作れて，重みの和がそれに引きずられる．先頭が $0$ で長さが $j + 1$ のプログラムは $2^j$ 本あるから，重みの和は長さごとに $1/2$ になり，全部足すといくらでも大きくなる．

そこで機械を取り替える．値を持つプログラムのどの一本も他の一本の語頭にならないような機械をとれば，重みの総和は $1$ を超えない．本節はそのような機械を一つ固定し，その機械についての記述長 $K_{\mathcal V}$ と重み $P_{\mathcal V}$ を定めて，二つが定数倍の範囲で互いを決めることを見る．$K_{\mathcal U}$ と $K_{\mathcal V}$ は別々の量だが無関係ではなく，命題 13.4.6 が両者を等式で結ぶ．固定する機械の作り方は，渡すビット列の長さを $1$ の個数で書くという最も素朴なものである．そのぶん前置きが記述と同じだけの長さを食い，係数 $2$ が本節から 13.6 節までの評価に残りつづける．前置きをもっと短く書く作り方はあるが，本書はこの一つだけを固定して，その係数ごと引き受ける．以下で係数 $2$ が，13.6 節で係数 $4$ が現れるのは，どれもこの一つの選択から来ている．

## 語頭のない集合

::: definition 13.4.1 語頭のない集合
ビット列の集合 $S$ が **語頭のない集合** であるとは，$S$ の元 $s$ と $t$ について，$s$ が $t$ の語頭（定義 4.1.2）ならば $s = t$ が成り立つことをいう．
:::

::: formalized
`PrefixFree` (`InformationTheory/Shannon/Kolmogorov/PrefixMachine.lean`)
:::

第4章 定義 4.1.2 の語頭符号は，相異なる文字に与えた符号語のあいだに語頭の関係が無いことを要求していた．定義 13.4.1 はその条件を，符号語の集合そのものについて言い換えたものである．違いは二つある．写像ではなく集合について述べていることと，集合が無限であってよいことである．無限であってよいところが本節に効く．機械が値を持つプログラムは無限にあるからである．

和を一つ約束しておく．非負の実数を項とする可算個の和は，有限個の項を選んで足したものの全体の上限として定める（上に有界でなければ $+\infty$ とする）．項が有限個のときは通常の和に一致すること，項の並べ方に依らないこと，項ごとに大小があればそのまま和の大小になることを既知とする．この約束を使うのは，本節の 補題 13.4.2，定義 13.4.8，命題 13.4.9，定理 13.4.10 と 例 13.4.11，13.5 節の 定義 13.5.4，命題 13.5.5，補題 13.5.7，定理 13.5.8 と 例 13.5.9，および第14章 14.6 節の 定義 14.6.6 である．これらの和を実数として扱うのは，本章では 命題 13.4.9 と 命題 13.5.5 で値が $1$ 以下であることを示したあとだけである．第14章 14.6 節が実数として扱うのは別の上界を通してで，そちらは出力アルファベットの大きさの対数で和を抑える．

::: formalization-note 本節と 13.5 節に共通
いま約束した和は，形式化ではどれも拡張非負実数の値として定義されている．そちらでは和が有限であることを先に示さずに書けるので，本文が上限として置いた定義の段は形式化に現れない．有限部分和の上限をとる段そのものは，形式化の証明にはそのまま現れる．13.5 節の 定義 13.5.6 が $0$ 以上の実数について書く条件も，形式化では同じ拡張非負実数の上の述語として書かれている．
:::

::: lemma 13.4.2
$S$ を，空列を含まない 定義 13.4.1 の意味の語頭のない集合とすると
$$
\sum_{s \in S} 2^{-\lvert s\rvert} \;\le\; 1
$$
が成り立つ（$S$ は無限であってよい）．
:::

::: proof
$S'$ を $S$ の有限部分集合とする．$S'$ を有限アルファベット，$D := 2$ とし，$s \in S'$ にその列自身を対応させる写像を $c$ とする．$S$ は空列を含まないから $c(s)$ は $\{0, 1\}$ の文字を並べた空でない有限列であり，$c$ は 定義 4.1.1 の意味で $S'$ 上の二元情報源符号である．相異なる $s, t \in S'$ について $c(s) = s$ が $c(t) = t$ の語頭だとすると，定義 13.4.1 より $s = t$ となって相異なることに反するから，$c$ は語頭符号である．よって 定理 4.2.1 より $\sum_{s \in S'} 2^{-\lvert s\rvert} \le 1$ である．

$S$ にわたる和を有限部分和の上限として定めたことから，主張の左辺はいま抑えた有限和の全体の上限であり，どの有限和も $1$ 以下だから，上限も $1$ 以下である．
:::

::: formalized
`PrefixFree.tsum_inv_two_pow_length_le_one` (`InformationTheory/Shannon/Kolmogorov/PrefixMachine.lean`)
:::

補題 13.4.2 は Kraft の不等式（定理 4.2.1）を，無限の符号語の集合へ広げたものにほかならない．第4章では符号語の本数が有限だったので，長さがいちばん長い符号語をとって木の深さを固定できた．集合が無限だとその深さがとれないので，有限部分集合ごとに第4章の不等式を当て，上限をとって全体に広げる．上限をとる操作が入るぶん，等号がどこで成り立つかの話は落ちるが，$1$ 以下という上界はそのまま残る．空列を含まないという仮定は，定理 4.2.1 を経由するために要る条件であって，結論には要らない．空列を含む語頭のない集合は空列だけからなり，そのとき和は $1$ だからである．

## 自己限定万能機械

::: definition 13.4.3 自己限定形と自己限定万能機械
ビット列 $d$ に対し，$1$ を $\lvert d\rvert$ 個並べ，$0$ を一つ置き，そのあとに $d$ をつないだビット列を $d$ の **自己限定形** と呼ぶ（その長さは $2\lvert d\rvert + 1$ である）．ビット列 $s$ に自然数を対応させる部分関数 $\mathcal V$ を次のように定める．$s$ の先頭から最初の $0$ が現れるまでの $1$ の個数を $m$，その $0$ より後ろのビット列を $d$ とする（$s$ に $0$ が現れないときは $m := \lvert s\rvert$，$d$ を空列とする）．$m = \lvert d\rvert$ のとき $\mathcal V(s) := \mathcal U(d, 0)$ とし，そうでないとき $\mathcal V(s)$ は値を持たないとする．$\mathcal V$ を **自己限定万能機械** と呼ぶ．$x \in \mathbb N$ に対し
$$
K_{\mathcal V}(x) \;:=\; \min\big\{\, \lvert s\rvert \;:\; \mathcal V(s) = x \,\big\}
$$
と定める（$s$ はビット列の全体をわたる．そのようなビット列が一つも無いときは $+\infty$ とする）．
:::

::: formalized
自己限定形 `selfDelimit`，機械 `prefixUniversalEval`，記述長 `prefixComplexity` (`InformationTheory/Shannon/Kolmogorov/PrefixMachine.lean`)
:::

本節の $K_{\mathcal V}$ は，機械 $\mathcal V$ についての記述長である．$\mathcal V$ の作り方を変えたときに $K_{\mathcal V}$ の値がどれだけ動くかについて，本書は何も述べない．本章が $K$ につねに機械を添字として書くのは，このためでもある．

$\mathcal V$ の読み方は，長さを先に書いておく，というだけのものである．$\mathcal U$ に渡したいビット列 $d$ があるとき，その長さを $1$ の個数で書き，区切りの $0$ を置いてから $d$ を並べる．読む側は $1$ を数えて長さを知り，区切りのあとをちょうどその長さだけ読めばよいので，どこで読み終えるかが読んだ範囲だけで決まる．長さが合わないプログラムを捨てるのはそのためで，捨てておかないと，同じ $d$ に対して前置きの長さの違うプログラムがいくつも値を持ってしまう．はじめに見た，プログラムが自分の終わりを自分で告げるという形が，ここで具体の姿をとる．自己限定という名前もそこから来ている．

$\mathcal U$ と同じく，$\mathcal V$ も 定義 13.1.3 の意味の機械ではない．13.1 節が $\mathcal U$ について述べたとおり，機械はビット列をそれが表す自然数を通してしか見ないのに対し，$\mathcal V$ はビット列そのものを読むからである．いっぽう $\mathcal V$ も計算の手続きで定まる．$1$ の並びを数えて長さを比べるところは有限回の繰り返しで，残りは $\mathcal U$ を走らせるところだから，Church–Turing のテーゼより $\mathcal V$ は部分計算可能である．

::: proposition 13.4.4
$\mathcal V$ が値を持つビット列は，どれもあるビット列の自己限定形（定義 13.4.3）である．とくに，$\mathcal V$ が値を持つビット列の全体は 定義 13.4.1 の意味で語頭のない集合であり，空列を含まない．
:::

::: proof
$\mathcal V(s)$ が値を持つとし，定義 13.4.3 の $m$ と $d$ をとる．$s$ に $0$ が現れないときは $d$ が空列で $m = \lvert s\rvert$ だから，$m = \lvert d\rvert = 0$ は $s$ が空列であることを意味する．ところが空列については $d$ も空列で $\mathcal V(s) = \mathcal U(d, 0)$ となり，定義 13.1.4 より空列に対する $\mathcal U$ は値を持たない．よって $s$ には $0$ が現れ，$s$ は $1$ を $m$ 個並べ，$0$ を一つ置き，長さ $m$ のビット列 $d$ をつないだ形である．これは $d$ の自己限定形にほかならない．

空列を含まないことは，いま見たとおりである．語頭のない集合であることを示す．$s$ と $t$ が $\mathcal V$ で値を持ち，$s$ が $t$ の語頭だとする．前段より $s$ はあるビット列 $d$ の，$t$ はあるビット列 $e$ の自己限定形であり，$s$ の先頭から最初の $0$ までの $1$ の個数は $\lvert d\rvert$，$t$ については $\lvert e\rvert$ である．$\lvert d\rvert < \lvert e\rvert$ とすると，$1$ を $\lvert d\rvert$ 個並べた直後の位置で，$s$ のビットは $0$ であり，$t$ のビットは $1$ である（$t$ の先頭 $\lvert e\rvert$ ビットはすべて $1$ だからである）．この位置は $s$ の中にある．$\lvert s\rvert = 2\lvert d\rvert + 1$ が $\lvert d\rvert$ より大きいからである．いっぽう $s$ が $t$ の語頭なら，この位置の二つのビットは一致しなければならず，矛盾する．$\lvert d\rvert > \lvert e\rvert$ としても，$1$ を $\lvert e\rvert$ 個並べた直後の位置で同じ矛盾が出る．よって $\lvert d\rvert = \lvert e\rvert$ であり，$\lvert s\rvert = 2\lvert d\rvert + 1 = \lvert t\rvert$ である．長さの等しい語頭は列そのものだから $s = t$ である．
:::

::: proposition 13.4.5
$x \in \mathbb N$ とすると，$\lvert s\rvert = K_{\mathcal V}(x)$ かつ $\mathcal V(s) = x$ を満たすビット列 $s$ が存在する．
:::

::: proof
命題 13.1.5 を $y := 0$ に当てると，$\mathcal U(d, 0) = x$ を満たすビット列 $d$ がある．$t$ を $d$ の自己限定形とすると，$t$ の先頭から最初の $0$ までの $1$ の個数は $\lvert d\rvert$，その後ろは $d$ だから，定義 13.4.3 より $\mathcal V(t) = \mathcal U(d, 0) = x$ である．よって集合 $\{\lvert s\rvert : \mathcal V(s) = x\}$ は空でない自然数の集合であり，最小元をもつ．その最小元は $K_{\mathcal V}(x)$ にほかならず，しかも $\mathcal V(s) = x$ を満たすあるビット列 $s$ の長さだから，その $s$ が求めるものである．
:::

::: proposition 13.4.6
$x \in \mathbb N$ とすると $K_{\mathcal V}(x) = 2\,K_{\mathcal U}(x) + 1$ である．
:::

::: proof
上から抑える．命題 13.1.5 を $y := 0$ に当てて，$\lvert d\rvert = K_{\mathcal U}(x \mid 0) = K_{\mathcal U}(x)$ かつ $\mathcal U(d, 0) = x$ を満たすビット列 $d$ をとる．$s$ を $d$ の自己限定形とすると，命題 13.4.5 の証明と同じ読み方で $\mathcal V(s) = x$ であり，$\lvert s\rvert = 2\lvert d\rvert + 1 = 2K_{\mathcal U}(x) + 1$ だから，定義 13.4.3 の最小はこの値以下である．

下から抑える．$\mathcal V(s) = x$ とすると，命題 13.4.4 より $s$ はあるビット列 $d$ の自己限定形である．このとき 定義 13.4.3 の $m$ は $\lvert d\rvert$ に等しいので $\mathcal V(s) = \mathcal U(d, 0)$ であり，$\mathcal U(d, 0) = x$ が従う．よって 定義 13.1.4 の最小より $\lvert d\rvert \ge K_{\mathcal U}(x)$ であり，$\lvert s\rvert = 2\lvert d\rvert + 1 \ge 2K_{\mathcal U}(x) + 1$ である．$\mathcal V(s) = x$ を満たす $s$ は任意だったから，その長さの最小である $K_{\mathcal V}(x)$ も $2K_{\mathcal U}(x) + 1$ 以上である．
:::

::: formalization-note
命題 13.4.6 に対応する単独の宣言は無い．形式化は同じ等式を，$\mathcal U$ に渡すビット列の長さの最小値について `prefixComplexity_eq_two_mul_payloadComplexity_add_one` (`InformationTheory/Shannon/Kolmogorov/Levin.lean`) として持っている．そこに現れる `payloadComplexity` は，本文の $K_{\mathcal U}(\cdot \mid 0)$ にあたる量を $\mathcal V$ の側から定め直したもので，二つが一致することを述べる宣言は無い．定義を開けば同じ部分関数についての最小だが，その等式には名前が与えられていないからである．
:::

命題 13.4.6 は，本書の $K_{\mathcal V}$ が $K_{\mathcal U}$ から完全に決まることを言っている．すなわち記述長の側では，機械を取り替えたことで新しく得たものは何も無い．得たものは重みの側にある．命題 13.4.4 のとおり $\mathcal V$ が値を持つプログラムの全体は語頭のない集合なので，補題 13.4.2 よりそれらの重みの総和は $1$ を超えない．このあと 定義 13.4.8 で入れる $P_{\mathcal V}$ を確率として読めるのは，この一点による．$\mathcal V$ を置いたのはそのためである．

等式が成り立つのは 定義 13.4.3 で機械を一つに固定したからであって，値を持つプログラムの全体が語頭のない集合であるような機械の一般について成り立つ話ではない．情報理論の文献が語頭複雑性と呼ぶ量は，そのような機械のうち，どの機械の記述も定数の払いで真似できるものをとって定めるもので，機械の取り方に定数のずれが残るぶん，命題 13.4.6 のような等式を主張として持たない．読者が本書の外で語頭複雑性を引くときは，本書の $K_{\mathcal V}$ とは別の量である．

::: theorem 13.4.7 係数 $2$ の不変性
$\mathcal M$ を 定義 13.1.3 の意味の機械とすると，定数 $b \in \mathbb N$ があって，すべての $x \in \mathbb N$ とすべてのビット列 $s$ について，$\mathcal M(s, 0) = x$ ならば $K_{\mathcal V}(x) \le 2\lvert s\rvert + b$ が成り立つ．
:::

::: proof
定理 13.1.7 をこの $\mathcal M$ に当てて定数 $b_0 \in \mathbb N$ をとり，$b := 2b_0 + 1$ と置く．$x \in \mathbb N$ とビット列 $s$ が $\mathcal M(s, 0) = x$ を満たすとすると，定理 13.1.7 より $K_{\mathcal U}(x) = K_{\mathcal U}(x \mid 0) \le \lvert s\rvert + b_0$ である．命題 13.4.6 と合わせて
$$
K_{\mathcal V}(x) \;=\; 2K_{\mathcal U}(x) + 1 \;\le\; 2\lvert s\rvert + 2b_0 + 1 \;=\; 2\lvert s\rvert + b
$$
である．
:::

定理 13.4.7 と 定理 13.1.7 の違いは係数 $2$ だけである．定理 13.1.7 の右辺は $\lvert s\rvert$ に定数を足したものだったので，$\lvert s\rvert$ が大きくなるほど払いは相対的に軽くなった．定理 13.4.7 の右辺は $\lvert s\rvert$ の $2$ 倍なので，そうはならない．ただし，この $2$ を定数に落とした形が成り立たない，とまでは 定理 13.4.7 からは出ない．定理 13.4.7 は一つの上界を与えるだけで，これより良い上界が無いことは言っていないからである．

## 万能確率

::: definition 13.4.8 万能確率
$x \in \mathbb N$ に対し
$$
P_{\mathcal V}(x) \;:=\; \sum_{s \,:\, \mathcal V(s) = x} 2^{-\lvert s\rvert}
$$
と定め（$s$ は $\mathcal V(s) = x$ を満たすビット列の全体をわたる），$x$ の **万能確率** と呼ぶ．
:::

::: formalized
`universalProb` (`InformationTheory/Shannon/Kolmogorov/PrefixMachine.lean`)
:::

$P_{\mathcal V}$ はつねに $\mathcal V$ を添字にとり，引数を一つとる．第10章から第12章までが裸の $P$ で書いてきた分布とは別の量であり，13.3 節が $p^n$ と書いた積分布とも関係がない．$P_{\mathcal V}(x)$ が測っているのは，でたらめに投げたビット列を $\mathcal V$ に読ませたとき，$x$ が出てくる重みである．$x$ を出すプログラムが短いほど，そのプログラムの重み $2^{-\lvert s\rvert}$ は大きい．すなわち $P_{\mathcal V}$ は，短く書ける対象ほど大きな値をとる．次の 定理 13.4.10 が言うのは，この対応が定数倍の範囲で逆向きにも成り立つことである．

::: proposition 13.4.9
$x \in \mathbb N$ とすると $2^{-K_{\mathcal V}(x)} \le P_{\mathcal V}(x) \le 1$ である．とくに $P_{\mathcal V}(x) > 0$ である．
:::

::: proof
左の不等式を示す．命題 13.4.5 より $\lvert s\rvert = K_{\mathcal V}(x)$ かつ $\mathcal V(s) = x$ を満たすビット列 $s$ がある．定義 13.4.8 の和はこの $s$ の項を含み，項はどれも非負だから，和はこの項の値 $2^{-K_{\mathcal V}(x)}$ 以上である．

右の不等式を示す．$\mathcal V(s) = x$ を満たすビット列の全体を $S$ と置くと，$S$ は $\mathcal V$ が値を持つビット列の全体の部分集合である．命題 13.4.4 より後者は空列を含まない語頭のない集合であり，その部分集合も同じ条件を満たすから，補題 13.4.2 を $S$ に当てて $P_{\mathcal V}(x) \le 1$ を得る．最後に，$2^{-K_{\mathcal V}(x)}$ は正だから $P_{\mathcal V}(x) > 0$ である．
:::

::: formalized
左の不等式 `universalProb_ge_two_pow_neg_prefixComplexity`，右の不等式 `universalProb_le_one` (`InformationTheory/Shannon/Kolmogorov/UniversalProbability.lean`)
:::

::: formalization-note
正値性に対応する単独の宣言は無い．左の不等式に紐付けた宣言と，$2^{-K_{\mathcal V}(x)}$ が正であることを合わせれば得られる．
:::

::: theorem 13.4.10 記述長と万能確率
$x \in \mathbb N$ とすると
$$
-\log_2 P_{\mathcal V}(x) \;\le\; K_{\mathcal V}(x) \;\le\; 2\big(-\log_2 P_{\mathcal V}(x)\big) + 1
$$
が成り立つ．
:::

::: proof
命題 13.4.9 より $P_{\mathcal V}(x) > 0$ だから，$\log_2 P_{\mathcal V}(x)$ は定まる．

左の不等式を示す．命題 13.4.9 の左の不等式に 補題 8.2.5 を当てると $-K_{\mathcal V}(x) \le \log_2 P_{\mathcal V}(x)$ であり，両辺の符号を変えて $-\log_2 P_{\mathcal V}(x) \le K_{\mathcal V}(x)$ を得る．

右の不等式の準備として $P_{\mathcal V}(x) \le 2^{-K_{\mathcal U}(x)}$ を示す．$\mathcal V(s) = x$ とすると，命題 13.4.6 の証明で見たとおり $s$ はあるビット列 $d$ の自己限定形で，$\mathcal U(d, 0) = x$ かつ $\lvert d\rvert \ge K_{\mathcal U}(x)$ である．そこで，$1$ を $\lvert d\rvert - K_{\mathcal U}(x)$ 個並べ，$0$ を一つ置き，そのあとに $d$ をつないだビット列を $\tilde s$ と書く．$s$ の前置きの $1$ を $K_{\mathcal U}(x)$ 個だけ剥がした列である．その長さは
$$
\lvert\tilde s\rvert \;=\; \big(\lvert d\rvert - K_{\mathcal U}(x)\big) + 1 + \lvert d\rvert \;=\; \lvert s\rvert - K_{\mathcal U}(x)
$$
である．剥がすのは，$x$ を出すプログラムの重みの和を 補題 13.4.2 に持ち込むためである．$\mathcal V$ が値を持つビット列そのものに 補題 13.4.2 を当てても $1$ 以下しか出ないが，長さをどれも $K_{\mathcal U}(x)$ だけ縮めてから当てれば，縮めたぶんが $2^{-K_{\mathcal U}(x)}$ の因子として残る．なお，長さ $\ell$ の $d$ の本数を $2^{\,\ell}$ で抑えて長さごとに足しても同じ上界は出る．ここでこの形をとるのは，次節の 例 13.5.9 が上からの評価に同じ剥がし方を使うからである．

対応 $s \mapsto \tilde s$ は単射である．というのも $\tilde s$ の最初の $0$ より後ろが $d$ で，$s$ は $d$ の自己限定形として $d$ から決まるからである．また $\tilde s$ の全体は空列を含まない語頭のない集合である．$\tilde s$ が $\tilde t$ の語頭だとして，$t$ に対応するビット列を $e$ と書く．$\tilde s$ の先頭には $1$ が $\lvert d\rvert - K_{\mathcal U}(x)$ 個並んでその直後が $0$ であり，$\tilde t$ の先頭には $1$ が $\lvert e\rvert - K_{\mathcal U}(x)$ 個並ぶ．$\lvert d\rvert < \lvert e\rvert$ とすると，$1$ を $\lvert d\rvert - K_{\mathcal U}(x)$ 個並べた直後の位置で，$\tilde s$ のビットは $0$ であり，$\tilde t$ のビットは $1$ である．この位置は $\tilde s$ の中にある．$\lvert\tilde s\rvert = 2\lvert d\rvert + 1 - K_{\mathcal U}(x)$ が $\lvert d\rvert - K_{\mathcal U}(x)$ より大きいからである．いっぽう $\tilde s$ が $\tilde t$ の語頭なら，この位置の二つのビットは一致しなければならず，矛盾する．$\lvert d\rvert > \lvert e\rvert$ としても，$1$ を $\lvert e\rvert - K_{\mathcal U}(x)$ 個並べた直後の位置で同じ矛盾が出る．よって $\lvert d\rvert = \lvert e\rvert$ であり，$\lvert\tilde s\rvert = \lvert\tilde t\rvert$ となるから，長さの等しい語頭は列そのものだから $\tilde s = \tilde t$ である．空列でないことは，$\tilde s$ が $0$ を含むことによる．

$\mathcal V(s) = x$ を満たす $s$ の有限個の集まりを $F$ とすると，いま見たことと 補題 13.4.2 から
$$
\sum_{s \in F} 2^{-\lvert s\rvert} \;=\; 2^{-K_{\mathcal U}(x)} \sum_{s \in F} 2^{-\lvert\tilde s\rvert} \;\le\; 2^{-K_{\mathcal U}(x)}
$$
である．和を有限部分和の上限として定めたことから，$P_{\mathcal V}(x) \le 2^{-K_{\mathcal U}(x)}$ である．

右の不等式を示す．いま示した不等式に 補題 8.2.5 を当てると $\log_2 P_{\mathcal V}(x) \le -K_{\mathcal U}(x)$，すなわち $K_{\mathcal U}(x) \le -\log_2 P_{\mathcal V}(x)$ である．命題 13.4.6 と合わせて
$$
K_{\mathcal V}(x) \;=\; 2K_{\mathcal U}(x) + 1 \;\le\; 2\big(-\log_2 P_{\mathcal V}(x)\big) + 1
$$
を得る．
:::

::: formalized
左の不等式 `neg_logb_universalProb_le_prefixComplexity` (`InformationTheory/Shannon/Kolmogorov/UniversalProbability.lean`)，右の不等式 `prefixComplexity_le_two_mul_neg_logb_universalProb` (`InformationTheory/Shannon/Kolmogorov/Levin.lean`)
:::

定理 13.4.10 は，記述の短さと重みの大きさが同じことを測っているという主張である．左の不等式は，$x$ を出すプログラムが一本でも短ければ重みが大きいという当たり前の向きで，最短の一本だけを数えて出る．右の不等式が言っているのは逆向きで，重みが大きければ短いプログラムが実際にあるということである．こちらは短いプログラムが一本もない場合を排除しなければならないので，長いプログラムがいくら集まっても重みが稼げないこと，すなわち 補題 13.4.2 の数え上げが要る．挟み撃ちの幅は係数 $2$ で，$-\log_2 P_{\mathcal V}(x)$ が大きいほど広がる．

この幅は，一方についての主張をもう一方へ移すときに効く．$K_{\mathcal U}$ の値を返す手続きが無いことは 定理 13.2.3 で見たので，命題 13.4.6 より $K_{\mathcal V}$ についても同じことが言える．ところが 定理 13.4.10 は幅のある挟み撃ちなので，$P_{\mathcal V}$ の値についても同じだ，とはここから出ない．本書は $P_{\mathcal V}$ の計算可能性を述べない．

この形の主張は Levin の符号化定理と呼ばれる．文献の主張は，値を持つプログラムの全体が語頭のない集合であるような機械のうち，どの機械の記述も定数の払いで真似できるものについてのもので，記述長と $-\log_2$ をとった重みが定数の差で一致するという，係数のない鋭い形をしている．本書が示すのは 定理 13.4.10 の係数 $2$ の挟み撃ちまでであり，文献の形は示さない．形式化もされていない．

命題 13.4.9 の左の不等式は最短の一本だけを見ており，和はまだ効いていない．和が効く例を一つ見ておく．

::: example 13.4.11 $0$ の万能確率
$K_{\mathcal V}(0) = 3$ であり，$P_{\mathcal V}(0) \ge 1/6 > 1/8 = 2^{-K_{\mathcal V}(0)}$ である．とくに 命題 13.4.9 の左の不等式は等号ではない．
:::

::: proof
$K_{\mathcal V}(0)$ を求める．空列に対して $\mathcal U$ は 定義 13.1.4 より値を持たないから $K_{\mathcal U}(0) \ge 1$ である．いっぽう $0$ の一文字からなるビット列 $d$ をとると，$d$ の先頭のビットは $0$ でその後ろは空列だから，定義 13.1.4 より $\mathcal U(d, 0)$ は空列が表す自然数，すなわち $0$ である．よって $K_{\mathcal U}(0) = 1$ であり，命題 13.4.6 より $K_{\mathcal V}(0) = 2 \times 1 + 1 = 3$ である．

下から抑える．$j \ge 1$ に対し，$d_j$ を $0$ を $j$ 個並べたビット列，$s_j$ を $d_j$ の自己限定形（定義 13.4.3）とする．$d_j$ の先頭のビットは $0$ で，その後ろは $0$ を $j - 1$ 個並べた列だから，定義 13.1.4 より $\mathcal U(d_j, 0)$ はその列が表す自然数，すなわち $0$ である．よって 定義 13.4.3 より $\mathcal V(s_j) = 0$ であり，その長さは $\lvert s_j\rvert = 2j + 1$ である．長さが違うから $s_1, s_2, \dots$ は相異なる．

$J \ge 1$ を任意にとる．$j = 1, \dots, J$ の $s_j$ は相異なる有限個のビット列で，どれも $\mathcal V$ の値が $0$ だから，それらの重みの和は 定義 13.4.8 の和の有限部分和である．その値は
$$
\sum_{j=1}^{J} 2^{-(2j+1)} \;=\; \frac12 \sum_{j=1}^{J} 4^{-j} \;=\; \frac16\big(1 - 4^{-J}\big)
$$
である．和を有限部分和の上限として定めたことから $P_{\mathcal V}(0)$ はこの値以上であり，$J$ を大きくすると右辺は $1/6$ に近づくから，$P_{\mathcal V}(0) \ge 1/6$ である．最後に $1/6 > 1/8 = 2^{-3}$ である．
:::

証明が数えたプログラムは，$1$ を $j$ 個，$0$ を一つ，$0$ を $j$ 個と並べたもので，$j \ge 1$ ごとに一本ずつある．$\mathcal U$ に渡る部分はどれも「これから書くとおりに書け」という同じ指示で，違うのは後ろに並ぶ $0$ の個数だけである．最短の一本 $s_1 = 100$ が重み $1/8$ を持ち，残りが合わせて $1/24$ を足す．$P_{\mathcal V}$ が最短の記述だけでなく記述の本数も見ていることが，ここで初めて数として出る．次節の 例 13.5.9 の下からの評価は，同じ数え方を，$\mathcal U$ に渡る部分が $0$ で始まるプログラムの全体に広げる．

次節は，この機械について二つの計算不可能性を示す．一つは $K_{\mathcal V}$ の値を返す手続きが無いこと，もう一つは $\mathcal V$ が値を持つかどうかを答える手続きが無いことである．そのうえで，値を持つプログラム全体の重みを一つの実数にまとめ，その実数もまた計算できないことを見る．
