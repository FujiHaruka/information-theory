# 13.2 圧縮できない対象と計算不可能性

13.1 節は一つの自然数に $K_{\mathcal U}$ という尺度を与え，機械の選び方が定数のずれにしか効かないことを見た．尺度が定まったので，次は何が測れるかである．命題 13.1.6 はどの $x$ についても $K_{\mathcal U}(x) \le \lvert x\rvert + 1$ を与えていた．すなわち，どの対象も自分を書き写す長さでは書き出せる．問いは逆向きで，それより短く書き出せる対象がどれだけあるかである．

答えは数え上げから出る．短い指示は本数が限られているので，短く書き出せる対象も本数が限られている．本節の主張はすべてこの一行から出る．どんな長さをとってもそれ以上の複雑性をもつ対象があること（系 13.2.2）も，$K_{\mathcal U}$ の値を返す手続きが無いこと（定理 13.2.3）もそうである．

## 記述の短い対象を数える

::: theorem 13.2.1
$y, k \in \mathbb N$ とすると，集合 $\{x \in \mathbb N : K_{\mathcal U}(x \mid y) < k\}$ は有限であり，その要素数は $2^k$ より小さい．
:::

::: proof
$S := \{x \in \mathbb N : K_{\mathcal U}(x \mid y) < k\}$ とおく．各 $x \in S$ に対し，命題 13.1.5 より $\lvert s\rvert = K_{\mathcal U}(x \mid y)$ かつ $\mathcal U(s, y) = x$ を満たすビット列 $s$ があるので，そのようなものを一つ選んで $s_x$ と書く．$\lvert s_x\rvert = K_{\mathcal U}(x \mid y) < k$ である．

対応 $x \mapsto s_x$ は単射である．というのも $x, x' \in S$ が $s_x = s_{x'}$ を満たすなら，$\mathcal U$ は部分関数で，値を持つならその値は一つだから，$x = \mathcal U(s_x, y) = \mathcal U(s_{x'}, y) = x'$ となるからである．

長さが $k$ 未満のビット列の本数を数える．長さ $j$ のビット列は $2^j$ 本だから，$j = 0, 1, \dots, k - 1$ について足して
$$
2^0 + 2^1 + \cdots + 2^{k-1} \;=\; 2^k - 1
$$
本である．$S$ の元はこの $2^k - 1$ 本の中の相異なるビット列に写るから，$S$ は有限で，その要素数は $2^k - 1$ 以下，とくに $2^k$ より小さい．
:::

::: formalized
有限性 `condComplexity_lt_finite`，要素数の評価 `condIncompressible_count` (`InformationTheory/Shannon/Kolmogorov/Counting.lean`)
:::

数え方の要点は一つだけである．指示は対象を決めるが，対象は指示を決めない．それでも各 $x$ に最短の指示を一つ選んでしまえば，選んだ先は相異なるので，対象の個数を指示の本数で抑えられる．そして指示はビット列だから，長さで区切れば本数が数えられる．長さが $k$ 未満のビット列は $2^k - 1$ 本しかないので，複雑性が $k$ 未満の対象も $2^k - 1$ 個までである．

::: corollary 13.2.2
$y, k \in \mathbb N$ とすると，$K_{\mathcal U}(x \mid y) \ge k$ を満たす $x \in \mathbb N$ が存在する．
:::

::: proof
そのような $x$ が無いとすると，すべての $x \in \mathbb N$ が $K_{\mathcal U}(x \mid y) < k$ を満たすので，定理 13.2.1 の集合は $\mathbb N$ の全体になる．ところが 定理 13.2.1 よりその集合は有限であり，$\mathbb N$ は無限だから矛盾する．
:::

::: formalized
`exists_condIncompressible` (`InformationTheory/Shannon/Kolmogorov/Noncomputable.lean`)
:::

系 13.2.2 は，どれだけ大きな $k$ をとっても，$k$ ビット未満では書き出せない自然数があると言っている．この意味で圧縮できない対象はいくらでもある．ただし証明は，そのような $x$ を一つも指していない．有限個しか無いはずの集合が全体になってしまう，という数え方の矛盾から存在を出しているだけである．指す手立てのほうは，次の 定理 13.2.3 の証明が扱う．そこでは，$K_{\mathcal U}$ の値を返す手続きがあると仮定し，それを使って $K_{\mathcal U}(x \mid y) \ge k$ を満たす $x$ を探す手続きを組み立てて，矛盾を出す．

## 記述長を返す手続きはない

::: theorem 13.2.3
$y \in \mathbb N$ とすると，自然数 $x$ に $K_{\mathcal U}(x \mid y)$ を対応させる関数は計算可能でない．
:::

::: proof
$y \in \mathbb N$ を固定し，$x \mapsto K_{\mathcal U}(x \mid y)$ が計算可能だとする．

$k \in \mathbb N$ に対し，$K_{\mathcal U}(x \mid y) \ge k$ を満たす $x$ のうち最小のものを $f(k)$ と書く．系 13.2.2 よりそのような $x$ は存在するので，$f(k)$ は定まる．$f(k)$ は，$x = 0, 1, 2, \dots$ の順に $K_{\mathcal U}(x \mid y)$ を計算して，値が $k$ 以上になる最初の $x$ を返す探索で求まり，この探索は必ず停止する．そこで $\mathcal M(z, y') := f(z)$（第 $2$ 引数は使わない）と定めると，Church–Turing のテーゼより $\mathcal M$ は計算可能であり，とくに 定義 13.1.3 の意味で機械である．

定理 13.1.7 をこの $\mathcal M$ に当てて定数 $b \in \mathbb N$ をとる．$k \in \mathbb N$ とし，$s$ を $k$ の二進表示のビット列とすると，$s$ が表す自然数は $k$ だから $\mathcal M(s, y) = f(k)$ であり，$K_{\mathcal U}(f(k) \mid y) \le \lvert s\rvert + b = \lvert k\rvert + b$ である．いっぽう $f(k)$ の定め方から $k \le K_{\mathcal U}(f(k) \mid y)$ である．二つを合わせると，すべての $k \in \mathbb N$ について
$$
k \;\le\; \lvert k\rvert + b
$$
が成り立つ．

これは $k$ を大きくとると破れる．$k := 2^{b+2}$ とおくと，$2^{b+2}$ の二進表示は $1$ の後ろに $0$ を $b + 2$ 個並べたものだから $\lvert k\rvert = b + 3$ であり，上の不等式は $2^{b+2} \le 2b + 3$ になる．ところが $b$ についての帰納法より $2^b \ge b + 1$ だから
$$
2^{b+2} \;=\; 4 \cdot 2^b \;\ge\; 4b + 4 \;>\; 2b + 3
$$
である．矛盾した．
:::

::: formalized
`condComplexity_not_computable` (`InformationTheory/Shannon/Kolmogorov/Noncomputable.lean`)
:::

この証明は Berry のパラドックスと呼ばれる古い言い回しを，そのまま定理にしたものである．「三十文字未満の日本語で言い表せない最小の自然数」という言い回しは，二十三文字でその数を言い表しており，自分自身に反している．証明の $f(k)$ がこの言い回しにあたり，$k$ を二進表示で書き下す $\lvert k\rvert$ ビットが「三十文字」にあたる．言い回しのほうは「言い表せる」という言葉が曖昧なためにパラドックスにとどまるが，$K_{\mathcal U}$ の側ではその言葉が 定義 13.1.4 で確定しているので，パラドックスは $K_{\mathcal U}$ が計算可能だという仮定への反証になる．

定理 13.2.3 が否定しているのは，すべての $x$ について $K_{\mathcal U}(x \mid y)$ の値を返す手続きの存在である．個々の $x$ について上界を与えることは，命題 13.1.6 や 定理 13.1.7 のとおりできる．できないのは，どの $x$ についても与えた上界が最短だと確かめられる，一つの手続きを持つことのほうである．確かめようとすると，それより短い指示を試して，どれも $x$ を出さないことを見なければならない．短い指示は有限本しかないのだから全部走らせればよさそうだが，走らせた指示が値を返さないとき，まだ返っていないのか永久に返らないのかを見分けなければならない．その見分けがつかないことは，$\mathcal U$ についても言える．見分けがつくなら，短い指示から順に，止まると分かったものだけを走らせて最短のものを見つけられ，定理 13.2.3 に反するからである．本書はこれを，13.4 節で固定する別の機械についてだけ 13.5 節で書く．

## 書き写す長さとの隔たり

::: example 13.2.4 書き写す長さはほぼ達成される
$n \ge 1$ とする．$0$ 以上 $2^n$ 未満のどの自然数 $x$ についても $K_{\mathcal U}(x) \le n + 1$ であり，$0$ 以上 $2^n$ 未満の自然数のうち少なくとも一つは $K_{\mathcal U}(x) \ge n$ を満たす．
:::

::: proof
前半から見る．$x$ を $0$ 以上 $2^n$ 未満の自然数とする．$x = 0$ なら $\lvert x\rvert = 0 \le n$ である．$x \ge 1$ なら，$x$ の二進表示の桁数を $j$ として，先頭の桁が $1$ であることから $x \ge 2^{j-1}$ であり，$2^{j-1} \le x < 2^n$ と 補題 8.2.5 より $j \le n$ である．どちらの場合も $\lvert x\rvert \le n$ だから，命題 13.1.6 を $y := 0$ に当てて $K_{\mathcal U}(x) \le \lvert x\rvert + 1 \le n + 1$ を得る．

後半に移る．定理 13.2.1 を $y := 0$，$k := n$ に当てると，$K_{\mathcal U}(x) < n$ を満たす自然数は $2^n$ 個より少ない．$0$ 以上 $2^n$ 未満の自然数はちょうど $2^n$ 個あるから，そのすべてが $K_{\mathcal U}(x) < n$ を満たすことはない．
:::

例 13.2.4 の二つの評価の隔たりは $1$ ビットである．上からは，$n$ ビットで書ける対象の複雑性はどれも $n + 1$ 以下で，これは 命題 13.1.6 の書き写す上界にほかならない．下からは，そのうち少なくとも一つが $n$ 以上で，これは 定理 13.2.1 の数え上げから出る．つまり，書き写すという素朴な手続きは，最悪の対象については $1$ ビットしか損をしていない．機械を工夫する余地は，対象を選べば大きいが（例 13.1.9），すべての対象について一律に稼ぐことはできない．

ここまでの $K_{\mathcal U}$ は一つの自然数についての量で，分布は一度も出てこなかった．次節は，情報源から出た長さ $n$ のブロックにこの量を当て，$1$ 文字あたりの平均が第2章のエントロピーに近づくことを示す．分布についての量と，一本の系列についての量が，そこで初めて結びつく．
