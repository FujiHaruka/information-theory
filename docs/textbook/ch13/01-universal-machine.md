# 13.1 記述の長さと万能機械

第2章から第12章まで，系列がどれだけ縮むかはつねに分布を通して測ってきた．第2章の漸近等分配性は情報源の分布からエントロピーを取り出し，第4章の符号長の下界も，第12章の冗長度も，分布があってはじめて書ける量である．ところが実際に手元にあるのは，分布ではなく一本の系列である．$0$ を $1000$ 個並べた系列と，コインを $1000$ 回投げて得た系列を並べれば，前者のほうが単純だと言いたくなる．どちらも同じ一様分布から同じ確率で出うるのだから，この単純さは分布では説明できない．

本章は，一つの対象そのものに複雑性の尺度を与える．考え方は素朴で，その対象を書き出す手続きのうち，いちばん短いものの長さを複雑性とする．$0$ を $1000$ 個並べた系列は「$0$ を $1000$ 回書け」という短い手続きで書き出せる．コイン投げの結果にそのような手続きがあるとは限らず，短い手続きを持つ対象がどれだけあるかは 13.2 節で数える．手続きを長さで測るには，手続きを読んで実行する側の規約を一つ決めなければならない．規約を取り替えれば長さも変わるので，このままでは対象だけで決まる量にならない．本節は規約を一つ固定する作り方を与え，その選び方が定数のずれにしか効かないこと（定理 13.1.5）までを示す．

本章では対数の底を $2$ にとる．測るのはビット列の長さであり，$2^k$ の形の量を数えるので，指数と対数の底をそろえておくと式が読みやすい．底を明示するため，以下では $\log_2$ と書く．エントロピー $H$（定義 1.1.1）と二値エントロピー $H_b$（例 1.1.2）もこの底で測り，単位はビットである．対数が狭義単調増加であること（補題 8.2.5）は，以下ことわりなく使う．

自然数とビット列を行き来する対応も先に決めておく．自然数 $x$ には二進表示のビット列を対応させ，そのビット数を $\lvert x\rvert$ と書く．$0$ には空列を対応させるので $\lvert 0\rvert = 0$ であり，$\lvert 1\rvert = 1$，$n \ge 1$ について $\lvert 2^n\rvert = n + 1$ である．逆に，自然数を引数にとる関数にビット列 $s$ を渡すときは，$s$ を二進表示として読んだ値を渡し，これを $s$ が表す自然数と呼ぶ（空列が表す自然数は $0$ とする）．自然数の二進表示が表す自然数はもとの自然数であり，本章が使うのはこの向きだけである．集合 $\mathcal X$ の要素数を書く $\lvert\mathcal X\rvert$ と字面が重なるが，そちらは引数が集合である．

「計算の手続き」という言葉を，本書は定義しない．定義するには計算模型（Turing 機械や部分再帰関数）を一つ選んで書き下す必要があり，それは本書の主題ではないからである．そのかわり，計算可能性の理論から二つ借りる．一つめを **部分計算可能関数の番号づけと万能定理** と呼ぶ（Kleene）．自然数をいくつか受け取って自然数を返す部分関数のうち，計算の手続きで定まるものを **部分計算可能** と呼び，そのうちすべての引数で値を持つものを **計算可能** と呼ぶ．借りるのは次の主張である．自然数の対から自然数への部分計算可能な部分関数の全体に番号 $0, 1, 2, \dots$ を与える対応 $i \mapsto \mathcal M_i$ があり，しかも三つ組 $(i, z, y)$ に $\mathcal M_i(z, y)$ を対応させる部分関数もまた部分計算可能である．当てる先は 定義 13.1.2 の万能機械 $\mathcal U$ と 定理 13.1.5，および 定義 13.4.3 の自己限定万能機械 $\mathcal V$ と 定理 13.4.7 である．依存範囲は本章の全節で，$\mathcal U$ と $\mathcal V$ の定め方がこの枠組みの上にあるから，本章のどの主張もこれを認めたうえでの主張である．

二つめを **Church–Turing のテーゼ** と呼ぶ．有限個の場合分け・有限回の繰り返し・停止しうる探索で書き下せる対応は部分計算可能であり，そのうち必ず停止して答えを返すものは計算可能である，という主張である．当てるのは本章が書き下す手続きで，例 13.1.7 の $2$ の冪を返す手続き，定理 13.2.3 と 定理 13.5.1 の Berry の探索，命題 13.3.3 の型と型類からの復元，補題 13.5.6 の手数の予算をつけた実行，定理 13.6.3 の二部記述からの復元である．依存範囲はこれらだけで，ほかの主張はこれらを経由してのみこれに依存する．これは定理ではない．「計算の手続き」という言葉を部分計算可能な部分関数のクラスで代表させるという約束であり，本書はこれを証明しない．

::: formalization-note 本章共通
本文は，書き下した手続きが計算可能であることを Church–Turing のテーゼで認めて先へ進む．形式化の側は，そのうちのいくつかについて部分計算可能であることを証明している．型と型類から系列を復元する手続きは `typeDecoder_partrec` (`InformationTheory/Shannon/Kolmogorov/EntropyRateUpper.lean`)，自己限定万能機械そのものは `prefixUniversalEval_partrec` (`InformationTheory/Shannon/Kolmogorov/PrefixComputability.lean`)，その機械を手数の予算をつけて走らせる手続きは `prefixEvaln_primrec` (`InformationTheory/Shannon/Kolmogorov/OmegaNoncomputable.lean`)，二部記述から対象を復元する手続きは `decodePayload_partrec` (`InformationTheory/Shannon/Kolmogorov/SufficientStatistic.lean`) である．
:::

## 機械と記述長

::: definition 13.1.1 機械と記述長
自然数の対から自然数への部分計算可能な部分関数を **機械** と呼ぶ．機械 $\mathcal M$ にビット列 $s$ を渡すとは，$s$ が表す自然数を第 $1$ 引数に与えることをいい，その値を $\mathcal M(s, y)$ と書く．$\mathcal M(s, y) = x$ とは，$\mathcal M$ がその引数で値を持ち，その値が $x$ であることをいう．機械 $\mathcal M$ と $x, y \in \mathbb N$ に対し
$$
K_{\mathcal M}(x \mid y) \;:=\; \min\big\{\, \lvert s\rvert \;:\; \mathcal M(s, y) = x \,\big\}
$$
と定め（$s$ はビット列の全体をわたる），$\mathcal M$ についての **記述長** と呼ぶ．そのようなビット列が一つも無いときは $K_{\mathcal M}(x \mid y) := +\infty$ と定める．
:::

$K$ には，つねに機械を添字として書く．既刊の章は裸の $K$ を，第4章 4.3 節と 4.5 節，第12章 12.3 節では Kraft の不等式の左辺として，第5章 5.3 節ではオッズの逆数の総和として，第6章 6.6 節では証明の中の定数として使っている．本章の $K$ はつねに機械を添字にとり，引数もとるので，裸の $K$ は本章に現れない．

::: formalization-note
定義 13.1.1 の $K_{\mathcal M}$，すなわち一般の機械についての記述長に名前を与えた宣言は無い．形式化が名前を与えているのは万能機械についての `condComplexity` (`InformationTheory/Shannon/Kolmogorov/UniversalMachine.lean`) だけで，一般の機械については 定理 13.1.5 が，記述そのものの長さを直に扱う形で書かれている．
:::

読み下しておく．$s$ は $\mathcal M$ に渡す指示で，$y$ は最初から手元にある知識である．$K_{\mathcal M}(x \mid y)$ は，$y$ を知ったうえで $x$ を $\mathcal M$ に書き出させる指示のうち，いちばん短いもののビット数にほかならない．この量は $\mathcal M$ を取り替えれば大きくも小さくもなる．極端な場合を見ておくと，引数によらず $x_0$ を返す機械をとれば，空列を渡すだけで $x_0$ が出るので $K_{\mathcal M}(x_0 \mid y) = 0$ である．だから記述長そのものは対象だけで決まる量ではなく，機械と対象の組についての量である．本節の残りは，機械を一つ固定する作り方を与え，その固定の仕方が定数のずれにしか効かないことを示す．

## 万能機械

::: definition 13.1.2 万能機械
ビット列 $s$ と $y \in \mathbb N$ の対に自然数を対応させる部分関数 $\mathcal U$ を，次のように定める．$s$ が空列のとき，$\mathcal U(s, y)$ は値を持たない．$s$ の先頭のビットが $0$ のとき，その後ろのビット列を $d$ として，$\mathcal U(s, y)$ を $d$ が表す自然数とする．$s$ の先頭のビットが $1$ のとき，$2$ 番目のビットから最初の $0$ が現れるまでの $1$ の個数を $i$，その $0$ より後ろのビット列を $d$ とし（$2$ 番目以降に $0$ が現れないときは $2$ 番目以降のビットの個数を $i$，$d$ を空列とする），$\mathcal U(s, y) := \mathcal M_i(d, y)$ とする．ここで $\mathcal M_i$ は，部分計算可能関数の番号づけと万能定理が与える番号 $i$ の部分関数である．$\mathcal U$ を **万能機械** と呼ぶ．$x, y \in \mathbb N$ に対し
$$
K_{\mathcal U}(x \mid y) \;:=\; \min\big\{\, \lvert s\rvert \;:\; \mathcal U(s, y) = x \,\big\}
$$
と定め（$s$ はビット列の全体をわたる），$y$ を知ったうえでの $x$ の **コルモゴロフ複雑性** と呼ぶ．また $K_{\mathcal U}(x) := K_{\mathcal U}(x \mid 0)$ と書く．
:::

::: formalized
万能機械 `universalEval`，コルモゴロフ複雑性 `condComplexity` と `complexity` (`InformationTheory/Shannon/Kolmogorov/UniversalMachine.lean`)
:::

$\mathcal U$ は 定義 13.1.1 の意味の機械ではない．機械はビット列を，それが表す自然数を通してしか見ないのに対し，$\mathcal U$ はビット列そのものを読み，先頭のビットで場合を分けるからである．それでも記述長は同じ形の式で定まるので，$K$ の添字が機械の名前か $\mathcal U$ かで読み分ければよい．$\mathcal U$ を万能と呼ぶのは，どの機械の記述も定数の払いで真似できるからであって（定理 13.1.5），$\mathcal U$ が機械の一つだからではない．なお $\mathcal U$ 自身も計算の手続きで定まる．先頭のビットを読んで場合を分け，$1$ の並びを数えるところは Church–Turing のテーゼが与え，番号 $i$ の部分関数を走らせるところは部分計算可能関数の番号づけと万能定理の後半が与える．

$\mathcal U$ の二つの場合は，指示の二つの出し方に対応している．先頭が $0$ の場合は「これから書くとおりに書け」で，後ろに $x$ の二進表示をそのまま置く．先頭が $1$ の場合は「番号 $i$ の機械を，これから書く指示で走らせろ」で，$1$ の並びが番号を単進で書いたもの，最初の $0$ がその区切りである．第 $1$ の出し方は誰にでも使えるかわりに $x$ の長さだけ払う．第 $2$ の出し方は，$x$ に見合った機械があれば短く済むかわりに，その機械の番号を書く分だけ余計に払う．二つを式にするのは 命題 13.1.4 と 定理 13.1.5 で，その前に，$K_{\mathcal U}$ を定める最小が実際に達成されることを見ておく．

::: proposition 13.1.3
$x, y \in \mathbb N$ とすると，$\lvert s\rvert = K_{\mathcal U}(x \mid y)$ かつ $\mathcal U(s, y) = x$ を満たすビット列 $s$ が存在する．
:::

::: proof
$t$ を，$0$ の後ろに $x$ の二進表示をつないだビット列とする．$t$ の先頭のビットは $0$ で，その後ろは $x$ の二進表示だから，定義 13.1.2 より $\mathcal U(t, y)$ は $x$ の二進表示が表す自然数，すなわち $x$ である．よって集合 $\{\lvert s\rvert : \mathcal U(s, y) = x\}$ は空でない自然数の集合であり，最小元をもつ．その最小元は $K_{\mathcal U}(x \mid y)$ にほかならず，しかも $\mathcal U(s, y) = x$ を満たすあるビット列 $s$ の長さだから，その $s$ が求めるものである．
:::

::: formalized
`condComplexity_spec` (`InformationTheory/Shannon/Kolmogorov/UniversalMachine.lean`)
:::

::: proposition 13.1.4
$x, y \in \mathbb N$ とすると $K_{\mathcal U}(x \mid y) \le \lvert x\rvert + 1$ である．
:::

::: proof
$t$ を，$0$ の後ろに $x$ の二進表示をつないだビット列とすると，定義 13.1.2 より $\mathcal U(t, y) = x$ である．$t$ の長さは $x$ の二進表示のビット数より $1$ 大きいから $\lvert t\rvert = \lvert x\rvert + 1$ であり，定義 13.1.2 の最小はこの値以下である．
:::

::: formalized
`condComplexity_le_natLen_add_one` (`InformationTheory/Shannon/Kolmogorov/UniversalMachine.lean`)
:::

命題 13.1.4 は，どの自然数もその二進表示を書き写す長さで書き出せることを言っているにすぎない．どんなに複雑な対象でも，複雑性はそれを書き下す長さを超えない，という当たり前の上界である．おもしろいのはここから先で，機械を工夫すればこの上界をどれだけ下回れるか，そして工夫の余地がどこで尽きるかである．

## 不変性定理

::: theorem 13.1.5 不変性定理
$\mathcal M$ を機械とすると，定数 $b \in \mathbb N$ があって，すべての $x, y \in \mathbb N$ とすべてのビット列 $s$ について，$\mathcal M(s, y) = x$ ならば $K_{\mathcal U}(x \mid y) \le \lvert s\rvert + b$ が成り立つ．
:::

::: proof
部分計算可能関数の番号づけと万能定理より，$\mathcal M = \mathcal M_i$ となる番号 $i$ がある．$b := i + 2$ とおく．

$x, y \in \mathbb N$ とビット列 $s$ が $\mathcal M(s, y) = x$ を満たすとする．$t$ を，$1$ を $i + 1$ 個並べ，次に $0$ を置き，最後に $s$ をつないだビット列とする．$t$ の先頭のビットは $1$ で，$2$ 番目のビットから最初の $0$ が現れるまでの $1$ の個数は $i$，その $0$ より後ろは $s$ だから，定義 13.1.2 の第 $3$ の場合に当たって $\mathcal U(t, y) = \mathcal M_i(s, y) = x$ である．$t$ の長さは $(i + 1) + 1 + \lvert s\rvert = \lvert s\rvert + b$ だから，定義 13.1.2 の最小はこの値以下である．
:::

::: formalized
`invariance` (`InformationTheory/Shannon/Kolmogorov/Invariance.lean`)
:::

::: corollary 13.1.6
$\mathcal M$ を機械とすると，定数 $b \in \mathbb N$ があって，すべての $x, y \in \mathbb N$ について $K_{\mathcal U}(x \mid y) \le K_{\mathcal M}(x \mid y) + b$ である．
:::

::: proof
定理 13.1.5 の定数 $b$ をとり，$x, y \in \mathbb N$ とする．$K_{\mathcal M}(x \mid y) = +\infty$ のときは不等式が成り立つ．そうでないときは，定義 13.1.1 の最小をとる集合が空でないので，$\mathcal M(s, y) = x$ かつ $\lvert s\rvert = K_{\mathcal M}(x \mid y)$ を満たすビット列 $s$ がある（自然数の空でない部分集合は最小元をもつ）．定理 13.1.5 をこの $s$ に当てると $K_{\mathcal U}(x \mid y) \le \lvert s\rvert + b = K_{\mathcal M}(x \mid y) + b$ である．
:::

::: formalization-note
系 13.1.6 に対応する単独の宣言は無い．`invariance` (`InformationTheory/Shannon/Kolmogorov/Invariance.lean`) が同じことを記述そのものの長さについて述べており，最小をとった形にした宣言は無い．
:::

系 13.1.6 が，本節のはじめに述べた問いへの答えである．機械をどう選び直しても，$K_{\mathcal U}$ が $K_{\mathcal M}$ より本質的に大きくなることはない．ずれは $b$ という定数までで，$b$ は $x$ にも $y$ にも依らず，$\mathcal M$ の番号だけで決まる．したがって，長い対象を並べて複雑性を比べるかぎり，機械の選び方は結論を変えない．コルモゴロフ複雑性が対象の量として意味を持つのは，この一点による．そのかわり，一つの $x$ についての $K_{\mathcal U}(x)$ の値そのものは，$b$ の分だけ機械の選び方に左右される．本章が $K$ につねに機械を添字として書くのはそのためである．

::: example 13.1.7 $2$ の冪
$n \ge 1$ とすると $\lvert 2^n\rvert = n + 1$ であり，命題 13.1.4 より $K_{\mathcal U}(2^n) \le n + 2$ である．また，定数 $b \in \mathbb N$ があって，すべての $n \ge 1$ について $K_{\mathcal U}(2^n) \le \lvert n\rvert + b$ が成り立つ．
:::

::: proof
$2^n$ の二進表示は $1$ の後ろに $0$ を $n$ 個並べたものだから $\lvert 2^n\rvert = n + 1$ であり，命題 13.1.4 を $x := 2^n$，$y := 0$ に当てて第 $1$ の主張を得る．

第 $2$ の主張に移る．$\mathcal M(z, y') := 2^z$（第 $2$ 引数は使わない）と定めると，$z$ から $2^z$ を求める手続きは有限回の繰り返しで書けて必ず停止するから，Church–Turing のテーゼより $\mathcal M$ は計算可能であり，とくに 定義 13.1.1 の意味で機械である．定理 13.1.5 をこの $\mathcal M$ に当てて定数 $b$ をとる．$n \ge 1$ とし，$s$ を $n$ の二進表示のビット列とすると，$s$ が表す自然数は $n$ だから $\mathcal M(s, 0) = 2^n$ であり，$K_{\mathcal U}(2^n) = K_{\mathcal U}(2^n \mid 0) \le \lvert s\rvert + b = \lvert n\rvert + b$ である．
:::

二つの上界の違いは，何を書き下しているかの違いである．第 $1$ の上界 $n + 2$ は $2^n$ という数そのものを書き写す長さで，第 $2$ の上界 $\lvert n\rvert + b$ は $n$ を書いて「$2$ の冪をとれ」と言う長さである．$\lvert n\rvert$ は $n$ の二進表示の桁数だから，$n$ が倍になるたびに $1$ しか増えない．したがって $n$ を大きくすれば，どこかで第 $2$ の上界のほうが小さくなる．どこで小さくなるかは $b$ で決まり，$b$ は 定理 13.1.5 の証明のとおり $\mathcal M$ に与えられた番号で決まるから，番号づけの取り方に依る．本書はその値を書かない．定理 13.1.5 が言っているのは，このように機械の側へ寄せた指示を，$\mathcal U$ が定数の払いで真似できるということである．
