# 5.2 比例賭けの最適性

例 5.1.5 では二つの配分を比べただけだった．$\mathcal X$ 上の賭け金の配分は $\lvert\mathcal X\rvert - 1$ 個の自由度をもつので，比べる相手はいくらでもある．本節はそのすべてを見渡して倍加率を最大にする配分を決める．答えは比例賭け（定義 5.1.3），すなわち自分が信じている確率をそのまま配分にしたものであり，最大を与える配分はそれだけである．しかも同じ計算から，比例賭けを離れたときに何をどれだけ損するのかまで出る．道具は第1章の情報不等式（定理 1.6.1）ただ一つで足りる．

## 最大を与える配分

::: theorem 5.2.1
$\mathcal X$ を有限アルファベット，$o$ を $\mathcal X$ 上のオッズ，$b$ を $\mathcal X$ 上の賭け金の配分（どちらも定義 5.1.1），$p$ を $\mathcal X$ 上のすべての $x \in \mathcal X$ で正な分布とする．このとき
$$
W(p, o, p) - W(b, o, p) \;=\; D(p \,\|\, b)
$$
である．とくに $W(b, o, p) \le W(p, o, p)$ であり，等号が成り立つのは $b = p$ のとき，かつそのときに限る．
:::

::: proof
二つの倍加率の差をとる．定義 5.1.3 より
$$
W(p, o, p) - W(b, o, p)
  \;=\; \sum_{x} p(x) \Big( \log\big(p(x)o(x)\big) - \log\big(b(x)o(x)\big) \Big)
  \;=\; \sum_{x} p(x) \log \frac{p(x)}{b(x)}
$$
である．ここで $p(x) > 0$，$b(x) > 0$，$o(x) > 0$ だからどの対数も有限の値をとり，オッズの項 $\log o(x)$ は引き算で消える．右辺は分布 $p$ と分布 $b$ の相対エントロピー $D(p \,\|\, b)$ にほかならない（定義 5.1.1 より $b$ は $\mathcal X$ 上の分布である）．これで等式が示された．

不等式と等号条件は等式から出る．定理 1.6.1 より $D(p \,\|\, b) \ge 0$ であり，等号は $p = b$ のとき，かつそのときに限る．よって $W(b, o, p) \le W(p, o, p)$ であり，等号が成り立つのは $b = p$ のとき，かつそのときに限る．
:::

::: formalized
等式 `doublingRate_gap_eq_klDivPmf`，不等式 `doublingRate_le_proportional`，等号条件 `doublingRate_eq_proportional_iff` (`InformationTheory/Shannon/Gambling/Basic.lean`)
:::

**最大を与える配分にオッズは現れない.** 定理 5.2.1 の等号条件は $b = p$ であって，そこにオッズ $o$ は現れない．証明でオッズの項が引き算で消えたのがその理由で，オッズは倍加率の値そのものは動かすものの，どの配分が最大を与えるかには関わらない．胴元がどんなオッズをつけていようと，賭け手は自分の信じる確率どおりに資産を割ればよいということである．例 5.1.4 のオッズと例 5.1.5 のオッズはまったく違い，同じ比例賭けに対する倍加率も $0$ と $0.2780\ldots$ で違うが，最大を与える配分はどちらでも $b = p$ である．この比例賭けは Kelly の基準として知られている．

**損の側から読む.** 定理 5.2.1 の等式は，比例賭けから配分 $b$ に変えたときの倍加率の落ち込みが，ちょうど $D(p \,\|\, b)$ だと言っている．第1章 1.6 節では相対エントロピーを「$q$ だと思い込んで符号化したために余計に払う符号長」と読んだが，ここでは「$b$ だと思い込んで賭けたために取り逃がす倍加率」になる．符号長では損が支払いとして出ていき，賭けでは損が稼ぎ損ねとして現れる．どちらも「思い込みで得をすることはない」という同じ一つの不等式の姿である．

::: example 5.2.2 比例賭けからずらす
例 5.1.5 の設定，すなわち $\mathcal X = \{1, 2\}$，$p(1) = 0.8$，$p(2) = 0.2$，$o(1) = o(2) = 2$ で，配分 $b(1) = 0.9$，$b(2) = 0.1$ をとる．このとき $W(b, o, p) = 0.2140\ldots$ であり，比例賭けとの差 $W(p, o, p) - W(b, o, p)$ は $0.0640\ldots$ で，定理 5.2.1 の等式のとおり $D(p \,\|\, b)$ に一致する．
:::

::: proof
定義 5.1.3 より $W(b, o, p) = 0.8 \log(0.9 \cdot 2) + 0.2 \log(0.1 \cdot 2) = 0.8 \log 1.8 + 0.2 \log 0.2$ であり，$\log 1.8 = 0.8479\ldots$，$\log 0.2 = -2.3219\ldots$ だから $0.6783\ldots - 0.4643\ldots = 0.2140\ldots$ である．例 5.1.5 より $W(p, o, p) = 0.2780\ldots$ なので差は $0.0640\ldots$ になる．一方 $D(p \,\|\, b) = 0.8 \log\frac{0.8}{0.9} + 0.2 \log\frac{0.2}{0.1} = 0.8 \cdot (-0.1699\ldots) + 0.2 \cdot 1 = 0.0640\ldots$ で，二つは一致する．
:::

例 5.2.2 のずらし方は，$1$ 番の馬をわずかに買いすぎただけである．それでも倍加率は $0.0640\ldots$ だけ落ちる．落ちる量は，第1章 1.6 節で相対エントロピーとして測った量そのものである．そして定理 5.2.1 の等号条件により，この落ち込みが消えるのは $b = p$ のときに限る．

::: example 5.2.3 ずらすと倍加率が負になる
$\mathcal X = \{1, 2\}$，$p(1) = 0.8$，$p(2) = 0.2$，$o(1) = 1.2$，$o(2) = 6$ とする．比例賭けの倍加率は $W(p, o, p) = 0.0054\ldots$ で正だが，一様な配分 $b(1) = b(2) = 1/2$ の倍加率は $-0.2725\ldots$ で負である．
:::

::: proof
定義 5.1.3 より $W(p, o, p) = 0.8 \log(0.8 \cdot 1.2) + 0.2 \log(0.2 \cdot 6) = 0.8 \log 0.96 + 0.2 \log 1.2$ である．$\log 0.96 = -0.0588\ldots$，$\log 1.2 = 0.2630\ldots$ だから，値は $-0.0471\ldots + 0.0526\ldots = 0.0054\ldots$ になる．一様な配分では $W(b, o, p) = 0.8 \log(0.5 \cdot 1.2) + 0.2 \log(0.5 \cdot 6) = 0.8 \log 0.6 + 0.2 \log 3$ であり，$\log 0.6 = -0.7369\ldots$，$\log 3 = 1.5849\ldots$ だから $-0.5895\ldots + 0.3169\ldots = -0.2725\ldots$ である．
:::

例 5.2.3 のオッズは，勝ちにくい $2$ 番の馬に $6$ 倍という大きな戻りをつけている．それに釣られて $2$ 番を買い増すと，定理 5.2.1 のとおり倍加率は比例賭けより下がり，しかもこの例では正から負に転じる．倍加率が正であるか負であるかで資産の長時間のふるまいが分かれることは，5.5 節で見る．

そもそも，倍加率という尺度で配分を比べることの根拠はどこにあるのか．別の尺度をとれば答えも変わる．

::: example 5.2.4 資産の期待値で選ぶと別の配分になる
例 5.1.5 の設定，すなわち $\mathcal X = \{1, 2\}$，$p(1) = 0.8$，$p(2) = 0.2$，$o(1) = o(2) = 2$ とし，勝ち馬 $X_1$ が分布 $p$ に従うとする．$1$ レース後の資産の期待値 $\mathbb E\big[S_1(b)\big]$ は，例 5.2.2 の配分 $b(1) = 0.9$，$b(2) = 0.1$ については $1.48$，比例賭けについては $1.36$，配分 $b(1) = 0.99$，$b(2) = 0.01$ については $1.588$ である．三つめの配分の倍加率は $W(b, o, p) = -0.3403\ldots$ で負である．
:::

::: proof
定義 5.1.2 で $n = 1$ とすると $S_1(b) = b(X_1)\,o(X_1)$ だから，$\mathbb E\big[S_1(b)\big] = \sum_x p(x)\,b(x)\,o(x)$ である．例 5.2.2 の配分では $0.8 \cdot 0.9 \cdot 2 + 0.2 \cdot 0.1 \cdot 2 = 1.44 + 0.04 = 1.48$，比例賭けでは $0.8 \cdot 0.8 \cdot 2 + 0.2 \cdot 0.2 \cdot 2 = 1.28 + 0.08 = 1.36$，三つめの配分では $0.8 \cdot 0.99 \cdot 2 + 0.2 \cdot 0.01 \cdot 2 = 1.584 + 0.004 = 1.588$ である．三つめの倍加率は定義 5.1.3 より $0.8 \log(0.99 \cdot 2) + 0.2 \log(0.01 \cdot 2) = 0.8 \log 1.98 + 0.2 \log 0.02$ であり，$\log 1.98 = 0.9855\ldots$，$\log 0.02 = -5.6438\ldots$ だから $0.7884\ldots - 1.1287\ldots = -0.3403\ldots$ になる．
:::

例 5.2.2 と例 5.2.4 は同じ二つの配分を別の尺度で比べていて，順位が逆になっている．三つめの配分はそのずらし方をさらに押し進めたもので，$1$ 番の馬にほとんど全額を寄せると，$1$ レースの資産の期待値は三つの中でいちばん大きくなる一方，倍加率は負に落ちる．どちらの尺度で配分を選ぶべきかは 5.5 節で決着する．長く賭け続けたときの資産の増え方を確率 $1$ で支配するのは，$1$ レースの期待値ではなく倍加率のほうだからである．

なお，馬をいくつもの投資先に，オッズを価格の比に置き換えれば，資産をどう割るかという同じ形の問いが株式の運用についても立てられる．本書ではポートフォリオ理論の章で扱う．
