# 5.5 資産の長時間のふるまい

ここまでに扱った倍加率は，どれも $1$ レースあたりの期待値である．期待値が大きいことと，実際に手元の資産が増えることは別の話である．$1$ 回のレースだけを見れば倍加率の低い配分のほうが資産を増やすこともあり，そのことは例 5.5.5 で確かめる．本節はこの隔たりを埋める．レースが独立に同じ分布で繰り返されるなら，資産の増え方は確率 $1$ で倍加率そのものになり，倍加率が正なら資産は限りなく増え，負なら $0$ に吸い込まれる．倍加率がちょうど $0$ のときにどちらへ行くかは本節では決まらない．5.1 節で「賭け方の良さの尺度」として倍加率を選んだことが，ここで正当化される．

道具は第2章 2.1 節で借りた **大数の強法則** である．形は「i.i.d. で期待値をもつ確率変数列の相加平均は，期待値に **概収束** する」，すなわち確率 $1$ の事象の上で各点収束するというもので，当てる相手は有限アルファベット上の i.i.d. な列から作った有界な確率変数の相加平均である．第2章が宣言した当てる相手と同じ形をしている．直接借りるのは定理 5.5.1 の証明だけで，本節の残りはすべて定理 5.5.1 を経由してのみこの道具に依存する．ほかに三つを既知とする．正の実数に収束する数列に $n$ を掛けたものが $+\infty$ に発散すること（極限が負の実数なら $-\infty$ に発散すること），有限個の確率 $1$ の事象の共通部分がまた確率 $1$ であること，そして正の数の列について，対数が $+\infty$ に発散することと列そのものが限りなく大きくなることが同じであり，対数が $-\infty$ に発散することと列そのものが $0$ に近づくことが同じであることの三つである．

## 増え方は倍加率になる

::: theorem 5.5.1
$\mathcal X$ を有限アルファベット，$o$ を $\mathcal X$ 上のオッズ，$b$ を $\mathcal X$ 上の賭け金の配分（どちらも定義 5.1.1），$p$ を $\mathcal X$ 上の分布とする．勝ち馬の列 $X_1, X_2, \dots$ が i.i.d. で，各 $X_i$ が分布 $p$ に従うとき，確率 $1$ で
$$
\lim_{n \to \infty} \frac1n \log S_n(b) \;=\; W(b, o, p)
$$
が成り立つ（$S_n(b)$ は定義 5.1.2 の資産，$W$ は定義 5.1.3 の倍加率である）．
:::

::: proof
定義 5.1.2 の積は，$b(x) > 0$ かつ $o(x) > 0$ よりどの因子も正だから，対数をとって
$$
\log S_n(b) \;=\; \sum_{i=1}^{n} \log\big(b(X_i)\, o(X_i)\big)
$$
と和に直せる．各項は $X_i$ だけの関数だから，この列は i.i.d. である．また値は有限個の数 $\log\big(b(x)o(x)\big)$（$x \in \mathcal X$）のどれかなので有界であり，期待値は $\sum_x p(x) \log\big(b(x)o(x)\big)$，すなわち定義 5.1.3 の $W(b, o, p)$ である．

$\frac1n \log S_n(b)$ はこの列の相加平均だから，大数の強法則を当てると $W(b, o, p)$ に概収束する．すなわち確率 $1$ の事象の上で主張の等式が成り立つ．
:::

::: formalized
`seqLogWealth_div_tendsto_doublingRate` (`InformationTheory/Shannon/Gambling/OperationalSequences.lean`)
:::

::: formalization-note
形式化が扱うのは資産そのものではなく資産の対数で，`seqLogWealth` (`InformationTheory/Shannon/Gambling/OperationalSequences.lean`) が定義 5.1.2 の $\log S_n(b)$ にあたる．積を先に定義してから対数をとる本文と，和として定義する形式化との違いだけで，定理 5.5.1 の証明の第 1 段がその橋渡しになっている．また形式化は勝ち馬の列に，相互独立ではなく対ごとの独立と同分布性だけを求めている．
:::

定理 5.5.1 は第2章の漸近等分配性（定理 2.1.4）と同じ形をしている．あちらは経験エントロピー（定義 2.1.1）が $H(X)$ に張り付くという主張で，こちらは $\frac1n \log S_n(b)$ が $W(b,o,p)$ に張り付くという主張である．どちらも $1$ 文字ごと，$1$ レースごとの量の相加平均に大数の強法則を当てただけで，違うのは当てる相手が驚きの量か $1$ レースの倍率の対数か，という点だけである．

**規模感.** 定理 5.5.1 は $\frac1n \log S_n(b)$ が $W(b, o, p)$ に近づくと言っているので，$n$ の大きいところでは $\log S_n(b)$ はおよそ $n\,W(b, o, p)$ である．例 5.1.5 の比例賭けなら $W(p, o, p) = 0.2780\ldots$ だから，$100$ レースのあとの $\log S_{100}(p)$ はおよそ $27.8$，すなわち資産はおよそ $2^{27.8}$ 倍で，$2$ 億倍を超える．$1$ レースあたりでは $0.28$ という小さな値でも，掛け算で積み上がるとこの規模になる．

## 符号で決まる二つの行き先

::: corollary 5.5.2
$\mathcal X$ を有限アルファベット，$o$ を $\mathcal X$ 上のオッズ，$b$ を $\mathcal X$ 上の賭け金の配分（どちらも定義 5.1.1），$p$ を $\mathcal X$ 上の分布とする．勝ち馬の列 $X_1, X_2, \dots$ が i.i.d. で，各 $X_i$ が分布 $p$ に従うとき，$W(b, o, p) > 0$ ならば確率 $1$ で $\log S_n(b) \to +\infty$，$W(b, o, p) < 0$ ならば確率 $1$ で $\log S_n(b) \to -\infty$ である（$S_n(b)$ は定義 5.1.2 の資産である）．
:::

::: proof
$n \ge 1$ について $\log S_n(b) = n \cdot \frac1n \log S_n(b)$ と書く．定理 5.5.1 より確率 $1$ の事象の上で $\frac1n \log S_n(b) \to W(b,o,p)$ だから，その事象の上では，正の実数に収束する数列に $n$ を掛けたものが $+\infty$ に発散し，極限が負の実数なら $-\infty$ に発散するという既知の規則により，$W(b,o,p) > 0$ なら積は $+\infty$ に，$W(b,o,p) < 0$ なら $-\infty$ に発散する．
:::

::: formalized
正のとき `seqLogWealth_tendsto_atTop_of_pos_doublingRate`，負のとき `seqLogWealth_tendsto_atBot_of_neg_doublingRate` (`InformationTheory/Shannon/Gambling/OperationalSequences.lean`)
:::

正の数の列について対数が $+\infty$ に発散することと列そのものが限りなく大きくなることは同じであり，$-\infty$ への発散と $0$ に近づくことも同じだから，倍加率の符号だけで，資産が限りなく増えるか $0$ に吸い込まれるかが決まる．例 5.2.3 の一様な配分は倍加率が $-0.2725\ldots$ だったから，例 5.2.3 のオッズと分布のレースが i.i.d. に繰り返されるなら，そこで賭け続ける人の資産は確率 $1$ で $0$ に近づく．同じレースで比例賭けをする人の倍加率は $0.0054\ldots$ と正なので，資産は確率 $1$ で限りなく増える．賭ける相手も戻る倍率も同じなのに行き先が正反対になるのは，指数の速さで効く量の符号が違うからである．例 5.3.6 のオッズと分布のレースが i.i.d. に繰り返される場合はもっと厳しい．比例賭けの倍加率が $-0.0438\ldots$ と負で，定理 5.2.1 よりどの配分の倍加率もそれ以下だから，どう賭けても資産は確率 $1$ で $0$ に近づく．胴元の取り分が見立て違いを上回るとは，そういうことである．

倍加率がちょうど $0$ のときに資産がどうなるかは，系 5.5.2 の外である．

::: example 5.5.3 倍加率が $0$ でも資産は振れ続ける
$\mathcal X = \{1, 2\}$，$p(1) = p(2) = 1/2$，$o(1) = 4$，$o(2) = 4/3$，$b(1) = 3/4$，$b(2) = 1/4$ とする．このオッズは $\sum_x 1/o(x) = 1$ を満たして公平であり，倍加率は $W(b, o, p) = 0$ である．一方，勝ち馬の列 $X_1, X_2, \dots$ の各項が分布 $p$ に従うとき，資産（定義 5.1.2）は $1$ レースごとに $3$ 倍か $1/3$ 倍になり，そのどちらが起こるかは確率 $1/2$ ずつである．
:::

::: proof
$1/4 + 3/4 = 1$ だから前半が成り立つ．$1$ レースの倍率は $b(1)\,o(1) = \frac34 \cdot 4 = 3$ と $b(2)\,o(2) = \frac14 \cdot \frac43 = \frac13$ であり，定義 5.1.3 より $W(b, o, p) = \frac12 \log 3 + \frac12 \log\frac13 = 0$ である．定義 5.1.2 の積の各因子はこの二つのどちらかで，$X_i = 1$ なら $3$，$X_i = 2$ なら $1/3$ であり，$p(1) = p(2) = 1/2$ だからそのどちらもが確率 $1/2$ で起こる．
:::

倍加率が $0$ だというだけでは，資産が止まるとは言えない．例 5.1.4 の比例賭けは倍加率が $0$ で資産もまったく動かなかったが，例 5.5.3 の資産は $3$ 倍と $1/3$ 倍のあいだで振れ続ける．同じ $0$ でも，配分しだいで資産のふるまいは違う．

倍加率と $1$ レースの期待値のどちらで配分を選ぶべきかも，ここで決着する．例 5.2.4 の三つめの配分は，比べた三つの中で $1$ レースの資産の期待値がいちばん大きいのに，倍加率は $-0.3403\ldots$ と負である．例 5.1.5 のオッズと分布のレースが i.i.d. に繰り返されるなら，系 5.5.2 よりその資産は確率 $1$ で $0$ に近づく．$1$ レースの期待値の大きさは，長い目で見た資産のふるまいを支配しない．

## 比例賭けは長い目で見ても最適である

::: corollary 5.5.4
$\mathcal X$ を有限アルファベット，$o$ を $\mathcal X$ 上のオッズ，$b$ を $\mathcal X$ 上の賭け金の配分（どちらも定義 5.1.1），$p$ を $\mathcal X$ 上のすべての $x \in \mathcal X$ で正な分布とする．勝ち馬の列 $X_1, X_2, \dots$ が i.i.d. で，各 $X_i$ が分布 $p$ に従うとき，確率 $1$ で $\frac1n \log S_n(b)$ と $\frac1n \log S_n(p)$ はともに収束し，
$$
\lim_{n \to \infty} \frac1n \log S_n(b) \;\le\; \lim_{n \to \infty} \frac1n \log S_n(p)
$$
が成り立つ（$S_n(b)$ は定義 5.1.2 の資産である）．
:::

::: proof
$p$ はすべての $x$ で正で総和が $1$ だから，定義 5.1.1 の賭け金の配分である．定理 5.5.1 を配分 $b$ と配分 $p$ にそれぞれ当てると，二つの確率 $1$ の事象が得られ，有限個の確率 $1$ の事象の共通部分は確率 $1$ だから，その共通部分の上では二つの極限が同時に存在して $W(b, o, p)$ と $W(p, o, p)$ に等しい．定理 5.2.1 より $W(b, o, p) \le W(p, o, p)$ だから，不等式が従う．
:::

::: formalized
`seqLogWealth_proportional_asymptotically_optimal` (`InformationTheory/Shannon/Gambling/OperationalSequences.lean`)
:::

系 5.5.4 は定理 5.2.1 を実際の資産の言葉に翻訳したものである．定理 5.2.1 は期待値どうしの比較だったので，「たまたま今回は他の配分が勝つ」ことを排除していなかった．系 5.5.4 は，$n$ を大きくしたときの増え方については確率 $1$ でその追い越しが起きないと言っている．

ここで確率 $1$ の事象は配分 $b$ ごとに定まる．系 5.5.4 が言うのは，配分を一つ決めるごとに，その配分について確率 $1$ で追い越しが起きないということであって，すべての配分について同時に成り立つ一つの事象があるとは言っていない．配分は連続無限個あるので，証明で使った有限個の共通部分ではそこまで届かない．

定理 5.2.1 の等号条件はここで配当を生む．$b \ne p$ なら $W(b, o, p) < W(p, o, p)$ は真の不等式だから，系 5.5.4 の二つの極限のあいだにも真の差が残る．増え方そのものに差があるということは，$\log S_n(b)$ と $\log S_n(p)$ の開きが $n$ に比例して広がるということで，よそ見をした賭け手は一度の幸運では埋められない差をつけられる．

比べているのは資産そのものではなく増え方であることに注意したい．資産そのものなら追い越しは起こりうる．

::: example 5.5.5 $1$ レースなら倍加率の低い配分が勝つ
例 5.1.5 の設定，すなわち $\mathcal X = \{1, 2\}$，$p(1) = 0.8$，$p(2) = 0.2$，$o(1) = o(2) = 2$ で，例 5.2.2 の配分 $b(1) = 0.9$，$b(2) = 0.1$ をとる．この配分の倍加率は比例賭けのそれより小さいが，勝ち馬の列 $X_1, X_2, \dots$ の第 $1$ 項が $X_1 = 1$ であれば，資産（定義 5.1.2）は $S_1(b) = 1.8$ が $S_1(p) = 1.6$ を上回る．
:::

::: proof
例 5.2.2 より $W(b, o, p) = 0.2140\ldots$ であり，例 5.1.5 より $W(p, o, p) = 0.2780\ldots$ だから，前半が成り立つ．定義 5.1.2 で $n = 1$ とすると $S_1(b) = b(X_1)\,o(X_1)$ だから，$X_1 = 1$ のとき $S_1(b) = 0.9 \cdot 2 = 1.8$，$S_1(p) = 0.8 \cdot 2 = 1.6$ である．
:::

::: corollary 5.5.6
$\mathcal X$ を有限アルファベット，$p$ を $\mathcal X$ 上のすべての $x \in \mathcal X$ で正な分布で，かつ一様分布でないものとする．すべての $x \in \mathcal X$ で $o(x) = \lvert\mathcal X\rvert$ であるオッズ（定義 5.1.1）のもとで，勝ち馬の列 $X_1, X_2, \dots$ が i.i.d. で各 $X_i$ が分布 $p$ に従うとき，確率 $1$ で $\log S_n(p) \to +\infty$ である（$S_n(p)$ は定義 5.1.2 の資産である）．
:::

::: proof
系 5.3.2 より $W(p, o, p) \ge 0$ であって，等号は $p$ が一様分布のとき，かつそのときに限る．$p$ は一様分布ではないから $W(p, o, p) > 0$ である．$p$ 自身が定義 5.1.1 の賭け金の配分だから，系 5.5.2 を配分 $p$ に当てればよい．
:::

::: formalization-note
系 5.5.6 に対応する単独の宣言はない．系 5.5.2 の紐付け先に，系 5.3.2 から出る $W(p, o, p) > 0$ を渡した形で得られる（系 5.3.2 のほうも形式化されていない）．なお比例賭けの増え方そのものについては，一般のオッズのもとで極限を閉じた形で与える単独の宣言 `seqLogWealth_proportional_div_tendsto` (`InformationTheory/Shannon/Gambling/OperationalSequences.lean`) がある．
:::

系 5.5.6 が本章の結論である．どの馬にも同じ倍率を返すという偏りのないオッズに，偏った情報源をぶつける．すると比例賭けの資産は確率 $1$ で限りなく増え，その増え方は定理 5.5.1 と系 5.3.2 より $1$ レースあたり $\log\lvert\mathcal X\rvert - H(X)$ である（$X$ は分布 $p$ に従う勝ち馬である）．第1章 1.1 節ではこの差を「偏りのぶんだけ圧縮できる余地」と読んだ．同じ差が本章では資産の増える速さになっている．情報源の偏りは，短く書くのにも，賭けて増やすのにも，同じ量だけ使えるということである．
