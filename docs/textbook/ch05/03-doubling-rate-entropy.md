# 5.3 倍加率とエントロピー

定理 5.2.1 で，賭け手が達成できる倍加率の最大値が $W(p, o, p)$ に決まった．次に知りたいのは，この値が何で決まるのかである．賭けの結果はオッズと真の分布の両方に左右されるが，最大値のほうはこの二つがきれいに分かれた形に書ける．しかも分布の効きぶんはエントロピーそのものであり，ここで第1章の量が賭けの場面に戻ってくる．

## 保存則

::: theorem 5.3.1
$\mathcal X$ を有限アルファベット，$o$ を $\mathcal X$ 上のオッズ（定義 5.1.1），$p$ を $\mathcal X$ 上のすべての $x \in \mathcal X$ で正な分布とし，$X$ を $\mathcal X$ 上に分布 $p$ をもつ確率変数とする．このとき
$$
W(p, o, p) \;=\; \sum_{x \in \mathcal X} p(x) \log o(x) \;-\; H(X),
$$
すなわち
$$
W(p, o, p) + H(X) \;=\; \sum_{x \in \mathcal X} p(x) \log o(x)
$$
である．
:::

::: proof
すべての $x$ で $p(x) > 0$ かつ $o(x) > 0$ だから $\log\big(p(x)o(x)\big) = \log p(x) + \log o(x)$ である．定義 5.1.3 の和をこの二つに分けると
$$
W(p, o, p) \;=\; \sum_{x} p(x) \log o(x) \;+\; \sum_{x} p(x) \log p(x)
$$
となる．第 2 項は定義 1.1.1 より $-H(X)$ に等しい．移項すれば第 2 の式を得る．
:::

::: formalized
`doublingRate_proportional_eq`，和の形 `doublingRate_proportional_add_entropy` (`InformationTheory/Shannon/Gambling/Basic.lean`)
:::

::: formalization-note
形式化がここで引くエントロピーは，アルファベット上の関数としての分布から直に組んだ和であって，定理の主張では名前のついた宣言を経由していない（同じ和には `entropyOfFn` (`InformationTheory/Fano/Entropy.lean`) として別に名前がついている）．第1章 1.1 節が紐付けた `entropy` (`InformationTheory/Shannon/Bridge.lean`) は確率変数の像測度について述べたもので，値はどちらも $H(X)$ で一致するが，単独の宣言としては別のものである．
:::

第 2 の式は保存則として読める．右辺 $\sum_x p(x)\log o(x)$ はオッズと分布だけで決まり，賭け手がどう賭けるかには関わらない．左辺は賭け手が稼げるぶん $W(p, o, p)$ と，勝ち馬の不確かさ $H(X)$ の和である．つまり分布とオッズを固定すると，稼ぎと不確かさの和は動かせない一定の量になる．賭ける前に何かを知れば，勝ち馬の不確かさは平均として下がる．そのぶんがそのまま稼ぎに移るのかどうかは，右辺が観測のあとでも平均として動かないかどうかで決まる．知るというのは分布を条件付き分布に取り替えることだから，右辺も観測値ごとに変わってしまい，この保存則だけでは決まらない．それを 5.4 節で確かめる．エントロピーは第1章では「平均驚き量」，第4章では「平均符号長の下界」だったが，ここでは「稼ぎ損ねるぶん」として現れる．

::: corollary 5.3.2
$\mathcal X$ を有限アルファベット，$p$ を $\mathcal X$ 上のすべての $x \in \mathcal X$ で正な分布とし，$X$ を $\mathcal X$ 上に分布 $p$ をもつ確率変数とする．すべての $x \in \mathcal X$ で $o(x) = \lvert\mathcal X\rvert$ であるオッズ（定義 5.1.1）について
$$
W(p, o, p) \;=\; \log \lvert\mathcal X\rvert - H(X)
$$
である．とくに $W(p, o, p) \ge 0$ であり，等号は $p$ が $\mathcal X$ 上の一様分布のとき，かつそのときに限る．
:::

::: proof
定理 5.3.1 の右辺に $o(x) = \lvert\mathcal X\rvert$ を入れると，$\sum_x p(x)\log\lvert\mathcal X\rvert = \log\lvert\mathcal X\rvert$ だから等式を得る．定理 1.1.5 より $H(X) \le \log\lvert\mathcal X\rvert$ であり，等号は $X$ が一様分布のとき，かつそのときに限るから，後半も従う．
:::

::: formalization-note
系 5.3.2 に対応する単独の宣言はない．定理 5.3.1 の形式化に $o(x) = \lvert\mathcal X\rvert$ を入れると，引かれる第 2 項は `entropyOfFn` (`InformationTheory/Fano/Entropy.lean`) そのものだから，同じ型の分布についての最大エントロピー限界 `entropyOfFn_le_log_card` (`InformationTheory/Fano/Entropy.lean`) を組めば不等式が出る．等号条件のほうは，制約に使う関数を $0$ にとった `entropy_eq_gibbs_iff_of_constraints` (`InformationTheory/Shannon/MaxEntropy/Constrained.lean`) が与える．そのときの Gibbs 分布は `gibbsPmf_zero_eq_uniform` (`InformationTheory/Shannon/MaxEntropy/Constrained.lean`) により一様分布だからである．
:::

どの馬にも同じ $\lvert\mathcal X\rvert$ 倍を返すオッズは，馬のあいだに差をつけないという意味で偏りのないオッズである．全部の馬に均等に賭ければ資産はどう転んでも変わらない．系 5.3.2 が言っているのは，そこに偏った分布をぶつけたぶんだけ稼げるということで，予測しやすい情報源ほど倍加率が大きい．しかも定理 5.2.1 より比例賭けを超える配分はないから，どう賭けても稼げないのは分布まで一様な場合だけであり，そのときは賭け手の側にも偏りの手がかりがない．第1章 1.1 節では $\log\lvert\mathcal X\rvert - H(X)$ を「偏りのぶんだけ圧縮できる余地」と読んだが，同じ差がここでは $1$ レースあたりに稼げる量になっている．

## 公平なオッズ

オッズを確率に読み替えてみる．例 5.1.4 では，勝つ確率が $p(x)$ の馬に $o(x) = 1/p(x)$ 倍をつけると掛け金と戻りが釣り合った．逆に見れば，$o(x)$ 倍という倍率は，胴元が $x$ の勝つ見込みを $1/o(x)$ と見積もった結果だと読める．この読み替えがそれ自体で分布になっている場合に，名前をつけておく．

::: definition 5.3.3 公平なオッズ
$\mathcal X$ を有限アルファベット，$o$ を $\mathcal X$ 上のオッズ（定義 5.1.1）とする．$\sum_{x \in \mathcal X} 1/o(x) = 1$ であるとき，$o$ は **公平** であるという．
:::

例 5.1.4 のオッズ $o(x) = 1/p(x)$ は，逆数の総和が $\sum_x p(x) = 1$ だから公平である．

::: proposition 5.3.4
$\mathcal X$ を有限アルファベット，$o$ を $\mathcal X$ 上のオッズ（定義 5.1.1），$p$ を $\mathcal X$ 上のすべての $x \in \mathcal X$ で正な分布とする．$o$ が公平（定義 5.3.3）ならば，$q(x) := 1/o(x)$ は $\mathcal X$ 上の分布であって
$$
W(p, o, p) \;=\; D(p \,\|\, q)
$$
である．とくに $W(p, o, p) \ge 0$ であり，等号は $p = q$ のとき，かつそのときに限る．
:::

::: proof
$o(x) > 0$ より $q(x) > 0$ であり，仮定より総和が $1$ だから $q$ は $\mathcal X$ 上の分布である．$X$ を $\mathcal X$ 上に分布 $p$ をもつ確率変数とする．$\log o(x) = -\log q(x)$ なので，定理 5.3.1 より
$$
W(p, o, p) \;=\; -\sum_{x} p(x) \log q(x) - H(X)
  \;=\; \sum_{x} p(x) \log \frac{p(x)}{q(x)}
$$
となり，右辺は $D(p \,\|\, q)$ である（第 2 の等号は定義 1.1.1 による）．定理 1.6.1 より $D(p \,\|\, q) \ge 0$ で，等号は $p = q$ のとき，かつそのときに限る．
:::

::: formalization-note
命題 5.3.4 に対応する単独の宣言はない．$q$ 自身を配分にとると $q(x)\,o(x) = 1$ でその倍加率が $0$ になるから，5.2 節が紐付けた等式 `doublingRate_gap_eq_klDivPmf` (`InformationTheory/Shannon/Gambling/Basic.lean`) の配分に $q$ を渡せば，そのまま主張の等式が出る．非負性と等号条件は，第1章 1.6 節が紐付けた `klDivPmf_nonneg` (`InformationTheory/Shannon/CsiszarProjection.lean`) と `klDivPmf_eq_zero_iff_pmf` (`InformationTheory/Shannon/MaxEntropy/Constrained.lean`) である．
:::

命題 5.3.4 は，公平なオッズのもとでの稼ぎが，胴元の見積もり $q$ と真の分布 $p$ の隔たりそのものだと言っている．第1章 1.6 節では $D(p \,\|\, q)$ を「$q$ だと思い込んで符号化したために余計に払う符号長」と読んだ．ここで思い込んでいるのは胴元の側で，その損がそのまま賭け手の得になる．胴元が正しく見積もっていれば，賭け手には取り分がない．例 5.1.4 で資産が動かなかったのは $p = q$ の場合だったからで，例 5.2.3 のオッズは $1/1.2 + 1/6 = 1$ を満たすので公平だが $q \ne p$ であり，そこには $0.0054\ldots$ の取り分があった．

::: example 5.3.5 三頭立て
$\mathcal X = \{1, 2, 3\}$，$p(1) = 1/2$，$p(2) = p(3) = 1/4$，$o(1) = o(2) = 4$，$o(3) = 2$ とする．このオッズは公平（定義 5.3.3）であり，比例賭けの倍加率は $W(p, o, p) = 0.25$ である．
:::

::: proof
$1/4 + 1/4 + 1/2 = 1$ だから前半が成り立つ．$X$ を $\mathcal X$ 上に分布 $p$ をもつ確率変数とし，定理 5.3.1 で計算すると，$\sum_x p(x)\log o(x) = \frac12 \cdot 2 + \frac14 \cdot 2 + \frac14 \cdot 1 = 1.75$ であり，$H(X) = \frac12 \cdot 1 + \frac14 \cdot 2 + \frac14 \cdot 2 = 1.5$ だから $W(p, o, p) = 1.75 - 1.5 = 0.25$ である．命題 5.3.4 でも同じ値が出る．$q(1) = q(2) = 1/4$，$q(3) = 1/2$ だから $D(p \,\|\, q) = \frac12 \log 2 + \frac14 \log 1 + \frac14 \log \frac12 = \frac12 - \frac14 = 0.25$ である．
:::

例 5.3.5 の胴元は $1$ 番の馬を軽く見ており（見積もりが $1/4$ なのに真の確率は $1/2$），$3$ 番の馬を買いかぶっている．賭け手はその食い違いから $1$ レースあたり $0.25$ の倍加率を得る．$2$ 番の馬については見積もりが真の確率に一致しているが，それでも取り分は残る．命題 5.3.4 の等号条件によれば，取り分が消えるのはすべての馬で見積もりが真の確率に一致したときだけだからである．

## 胴元の取り分

現実の胴元は，集めた掛け金をそのまま配ってしまっては商売にならない．そこで見積もりの総和を $1$ より大きくとる，すなわち各馬の倍率をいくらか低めにつける．そうすると命題 5.3.4 の $q$ は分布でなくなるが，総和で割れば分布に直せる．

::: proposition 5.3.6
$\mathcal X$ を有限アルファベット，$o$ を $\mathcal X$ 上のオッズ（定義 5.1.1），$p$ を $\mathcal X$ 上のすべての $x \in \mathcal X$ で正な分布とする．$K := \sum_{x \in \mathcal X} 1/o(x)$ とおくと $K > 0$ であり，$r(x) := \big(1/o(x)\big)/K$ は $\mathcal X$ 上の分布であって
$$
W(p, o, p) \;=\; D(p \,\|\, r) \;-\; \log K
$$
である．
:::

::: proof
$\mathcal X$ には分布 $p$ が載っているから空ではなく，$o(x) > 0$ より各項 $1/o(x)$ は正だから $K > 0$ である．よって $r(x) > 0$ であり，総和は $\big(\sum_x 1/o(x)\big)/K = 1$ だから $r$ は $\mathcal X$ 上の分布である．$X$ を $\mathcal X$ 上に分布 $p$ をもつ確率変数とする．$1/o(x) = K\,r(x)$ より $\log o(x) = -\log K - \log r(x)$ だから，定理 5.3.1 より
$$
W(p, o, p) \;=\; -\log K - \sum_{x} p(x) \log r(x) - H(X)
  \;=\; \sum_{x} p(x) \log \frac{p(x)}{r(x)} \;-\; \log K
$$
となり（第 2 の等号は定義 1.1.1 による），右辺の和は $D(p \,\|\, r)$ である．
:::

::: formalization-note
命題 5.3.6 に対応する単独の宣言はない．$r$ 自身を配分にとると $r(x)\,o(x) = 1/K$ でその倍加率が $-\log K$ になるから，5.2 節が紐付けた等式 `doublingRate_gap_eq_klDivPmf` (`InformationTheory/Shannon/Gambling/Basic.lean`) の配分に $r$ を渡せば，そのまま主張の等式が出る．
:::

命題 5.3.6 の $K$ は胴元の取り分を測っている．$K = 1$ なら集めた額をそのまま配るということで，これが命題 5.3.4 の場合である．$K > 1$ なら胴元は $\log K$ のぶんを手元に残す．そして賭け手の稼ぎは，胴元の見積もり $r$ と真の分布 $p$ の隔たりから，その取り分の対数を引いた値になる．つまり賭け手が勝つには，胴元の見積もり違いが取り分を上回らなければならない．胴元が取り分を大きくとるほど，賭け手に要求される見積もりの優位も大きくなる．なお，逆数の総和 $K$ で割って分布 $r$ を作るこの正規化は，定理 4.3.2 の証明で長さの組から分布を作った操作と同じものである．そこでの $D^{-\ell(x)}$ の役を，ここではオッズの逆数 $1/o(x)$ が演じている．

::: example 5.3.7 取り分が見積もり違いを上回る
例 5.1.5 の設定，すなわち $\mathcal X = \{1, 2\}$，$p(1) = 0.8$，$p(2) = 0.2$ で，オッズだけを $o(1) = o(2) = 1.6$ に取り替える．このとき $K = 1.25$ で $r$ は $\mathcal X$ 上の一様分布であり，$D(p \,\|\, r) = 0.2780\ldots$，$\log K = 0.3219\ldots$ だから，比例賭けの倍加率は $W(p, o, p) = -0.0438\ldots$ で負である．
:::

::: proof
$1/1.6 + 1/1.6 = 1.25$ だから $K = 1.25$ であり，$r(1) = r(2) = (1/1.6)/1.25 = 1/2$ で $r$ は一様分布である．$D(p \,\|\, r) = 0.8 \log\frac{0.8}{0.5} + 0.2 \log\frac{0.2}{0.5} = 0.8 \log 1.6 + 0.2 \log 0.4$ であり，例 5.1.5 と同じ計算で $0.2780\ldots$ になる．$\log 1.25 = 0.3219\ldots$ だから，命題 5.3.6 より $W(p, o, p) = 0.2780\ldots - 0.3219\ldots = -0.0438\ldots$ である．
:::

例 5.3.7 の胴元の見積もりは真の分布から $0.2780\ldots$ 隔たっているのに，$1.6$ 倍という控えめな倍率が $0.3219\ldots$ を取っていくので，賭け手は比例賭けでも負ける．定理 5.2.1 より比例賭けを超える配分はないので，この設定ではどの配分で賭けても倍加率は負である．ただしこれは全額を配分する賭け手についての話である．現金を手元に残す賭け方を配分で再現できるのは逆数の総和が $1$ のときだけで，このオッズはそうなっていない．賭けずにいれば資産は動かないのだから，どの配分で賭けるよりも賭けないほうが有利だということである．本書は定義 5.1.1 の配分だけを扱うので，以下もその範囲で読む．そのとき資産がどうなるかは 5.5 節で見る．なお定理 5.2.1 の等号条件にオッズは現れないから，取り分がいくらであっても最適な配分は比例賭けのままである．胴元の取り分が動かすのは賭け手の選び方ではなく，選んだあとの取り高だけである．
