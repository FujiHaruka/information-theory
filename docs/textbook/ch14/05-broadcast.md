# 14.5 ブロードキャスト通信路と重ね合わせ符号化

14.1 節は送り手が二人で受け手が一人だった．本節はその裏返しで，送り手が一人，受け手が二人である．送り手は一本の入力列を流し込み，二人の受け手はそれぞれ自分の側の出力列だけを見て，**別々の**メッセージを取り出す．無線の基地局が複数の端末に同時に配信する場面がこれにあたる．

答えの形は 14.1 節と同じくレート対の集合になるが，取り引きの中身は違う．多元接続では二人が同じ出力に混ざり込むことが制約だったのに対し，ここでは送れる入力列が一本しかないことが制約である．一本の列に二人ぶんのメッセージを載せるので，片方に合わせて作ると他方には読みにくいものが届く．二人の受け手の性能に差があるとき，この対立をどう調停するかが本節の主題である．

## 通信路と符号

::: definition 14.5.1 ブロードキャスト通信路
$\mathcal X$，$\mathcal Y_1$，$\mathcal Y_2$ をどれも空でない有限アルファベットとする．**ブロードキャスト通信路**（broadcast channel）とは，入力 $x \in \mathcal X$ ごとに $\mathcal Y_1 \times \mathcal Y_2$ 上の分布 $W(\cdot, \cdot \mid x)$ を与える対応である．すなわち $W(y_1, y_2 \mid x) \ge 0$ であって，各 $x$ について $\sum_{y_1, y_2} W(y_1, y_2 \mid x) = 1$ を満たす．その二つの **周辺通信路** を
$$
W_1(y_1 \mid x) \;:=\; \sum_{y_2 \in \mathcal Y_2} W(y_1, y_2 \mid x), \qquad
W_2(y_2 \mid x) \;:=\; \sum_{y_1 \in \mathcal Y_1} W(y_1, y_2 \mid x)
$$
で定める．長さ $n$ の入力 $x^n = (x_0, \dots, x_{n-1})$ に対する出力の対の分布を
$$
W^n\big(y_1^n, y_2^n \,\big|\, x^n\big) \;:=\; \prod_{i=0}^{n-1} W\big(y_{1,i}, y_{2,i} \,\big|\, x_i\big)
$$
で定める．
:::

$W_1$，$W_2$ はどちらも第6章 定義 6.1.1 の意味の通信路で，受け手 $1$，受け手 $2$ が自分の出力だけを見るかぎり相手にしているのはこの二つである．ところが通信路の側はそれ以上のもの，すなわち二つの出力の**同時**分布まで決めている．同じ周辺をもつ $W$ は何通りもあり，どれを選ぶかで二人の出力の相関が変わる．以下で劣化という条件を置くときに効くのが，まさにこの同時分布のほうである．

::: formalized
`BCChannel` (`InformationTheory/Shannon/BroadcastChannel/Basic.lean`)
:::

::: definition 14.5.2 ブロードキャスト符号
$W$ をブロードキャスト通信路（定義 14.5.1）とし，$n \ge 1$ とする．長さ $n$ の **ブロードキャスト符号** とは，メッセージ数 $M_1 \ge 1$，$M_2 \ge 1$ と，符号化写像 $c : \{1, \dots, M_1\} \times \{1, \dots, M_2\} \to \mathcal X^n$，および受け手ごとの復号器 $d_1 : \mathcal Y_1^n \to \{1, \dots, M_1\}$，$d_2 : \mathcal Y_2^n \to \{1, \dots, M_2\}$ の組である．メッセージの対 $(m_1, m_2)$ を送ったときの受け手 $j$ の **誤り確率** と，対について平均した受け手 $j$ の **平均誤り確率** を
$$
P_{e,j}(m_1, m_2) \;:=\; \sum_{y_1^n, y_2^n \,:\; d_j(y_j^n) \ne m_j}
  W^n\big(y_1^n, y_2^n \,\big|\, c(m_1, m_2)\big),
\qquad
\bar P_{e,j} \;:=\; \frac{1}{M_1 M_2} \sum_{m_1 = 1}^{M_1} \sum_{m_2 = 1}^{M_2} P_{e,j}(m_1, m_2)
$$
で定める（$j = 1, 2$）．
:::

14.1 節の 定義 14.1.2 と左右が入れ替わっている．あちらは符号化が二本に分かれて復号が一本だったが，こちらは符号化が一本で復号が二本である．一本になった符号化写像は二つのメッセージの**対**を受け取るので，送り手は両方を知っている．分かれたのは読む側で，受け手 $1$ は $y_1^n$ しか見ず，受け手 $2$ は $y_2^n$ しか見ない．誤りも受け手ごとに数える．自分のメッセージさえ当たっていればその受け手にとっては誤りでないので，誤り確率は二つある．

::: formalized
符号 `BroadcastCode`，メッセージの対ごとの誤り確率 `errorProbAt₁`，`errorProbAt₂`，受け手ごとの平均誤り確率 `averageErrorProb₁`，`averageErrorProb₂` (`InformationTheory/Shannon/BroadcastChannel/Basic.lean`)
:::

::: definition 14.5.3 達成可能なレート対と容量領域
$W$ をブロードキャスト通信路（定義 14.5.1）とする．実数の対 $(R_1, R_2)$ が **達成可能** であるとは，任意の $\zeta > 0$ に対してある $N \ge 1$ があって，$N \le n$ を満たすすべての $n$ について，長さ $n$ のブロードキャスト符号（定義 14.5.2）で
$$
\frac1n \log M_1 \;\ge\; R_1, \qquad \frac1n \log M_2 \;\ge\; R_2, \qquad
\bar P_{e,1} \;<\; \zeta, \qquad \bar P_{e,2} \;<\; \zeta
$$
を満たすものが存在することをいう．達成可能な対全体の集合の閉包を $W$ の **容量領域** と呼び，$\mathcal C(W)$ と書く．
:::

14.1 節 定義 14.1.3 と同じ形で，誤り確率についての条件が二人ぶんに増えただけである．閉包をとる理由も 14.2 節 定義 14.2.1 と同じで，達成可能性が与えるのはつねに不等式が真に成り立つ側だから，境界の対を極限で拾っておく．閉包は 14.2 節で借りた **平面の閉集合と閉包の基本性質** の意味でとる．

この定義はレートの符号を問うていない．14.2 節の 定理 14.2.5 が第一象限との共通部分について述べたのに対し，ここでは容量領域を第一象限で切らない．定義 14.5.3 がレートに求めているのは $\frac1n\log M_j \ge R_j$ という下からの不等式だけなので，$R_j$ を負にとれば条件はそれだけ緩くなる．以下で置く内界も外界も同じく第一象限で切らないので，三つの領域はそのまま比べられる．

::: formalized
達成可能性 `BCAchievable`，容量領域 `bcCapacityRegion` (`InformationTheory/Shannon/BroadcastChannel/Operational.lean`)
:::

## 劣化

二人の受け手の性能に差があるという状況を，通信路の側の条件として書く．いちばん強い書き方は，一方の出力がもう一方の出力をさらに雑音に通したものになっている，というものである．

::: definition 14.5.4 物理的に劣化している
$W$ をブロードキャスト通信路（定義 14.5.1）とする．$W$ が **物理的に劣化している** とは，$\mathcal Y_1$ を入力，$\mathcal Y_2$ を出力とする通信路 $W_{2\mid1}$（第6章 定義 6.1.1）があって，すべての $x$，$y_1$，$y_2$ について
$$
W\big(y_1, y_2 \,\big|\, x\big) \;=\; W_1\big(y_1 \,\big|\, x\big)\, W_{2\mid1}\big(y_2 \,\big|\, y_1\big)
$$
が成り立つことをいう．
:::

右辺を読むと，入力から出るのは $y_1$ だけで，$y_2$ はそこからさらに $W_{2\mid1}$ を通して作られている．つまり受け手 $2$ は，受け手 $1$ が見たものを又聞きしているにすぎない．これは同時分布についての条件であって，周辺だけでは決まらない．$W_2$ が $W_1$ より雑音が多いという言い方は周辺どうしの比較だが，定義 14.5.4 が求めているのは，同じ確率空間の上で $X \to Y_1 \to Y_2$ という順に情報が流れていることである．14.6 節では，周辺だけを見る弱い条件を二つ置いて，劣化していればそのどちらも満たされることを見る．

::: formalized
`IsBCDegraded` (`InformationTheory/Shannon/BroadcastChannel/Basic.lean`)
:::

::: example 14.5.5 二元対称通信路を二段つなぐ
$\rho_1, \rho_2 \in [0,1]$ とし，$\mathcal X = \mathcal Y_1 = \mathcal Y_2 = \{0,1\}$ とする．$Z_1$，$Z_2$ を互いに独立で $\Pr[Z_1 = 1] = \rho_1$，$\Pr[Z_2 = 1] = \rho_2$ を満たす確率変数とし，入力 $x$ に対する出力の対を $Y_1 := x \oplus Z_1$，$Y_2 := Y_1 \oplus Z_2$（$\oplus$ は排他的論理和）で定める．このとき定まるブロードキャスト通信路 $W$ は 定義 14.5.4 の意味で物理的に劣化しており，$W_1$ は反転確率 $\rho_1$ の二元対称通信路（例 6.1.8），$W_2$ は反転確率 $\rho_1(1-\rho_2) + (1-\rho_1)\rho_2$ の二元対称通信路である．
:::

::: proof
まず劣化を見る．$W_{2\mid1}$ を反転確率 $\rho_2$ の二元対称通信路，すなわち $W_{2\mid1}(y_1 \oplus 1 \mid y_1) = \rho_2$ かつ $W_{2\mid1}(y_1 \mid y_1) = 1 - \rho_2$ とする．$\rho_1$ が $0$ または $1$ のときは，$x$ に対して $Y_1$ のとりうる値が一つに決まる．そこで先に，$W_1(y_1 \mid x) = 0$ である組 $(x, y_1)$ を片づけておく．定義 14.5.1 の和より $W(y_1, y_2 \mid x) \le W_1(y_1 \mid x)$ だから，この組では示すべき等式の両辺がどちらも $0$ である．以下 $W_1(y_1 \mid x) > 0$，すなわち条件の側が正の確率をもつ組で考える．$Z_2$ が $Z_1$ と独立で，したがって $(x, Y_1)$ とも独立だから，$Y_1 = y_1$ を与えたときの $Y_2$ の条件付き分布は $W_{2\mid1}(\cdot \mid y_1)$ である．よって
$$
W\big(y_1, y_2 \,\big|\, x\big) \;=\; \Pr\big[Y_1 = y_1 \,\big|\, x\big]\,
  \Pr\big[Y_2 = y_2 \,\big|\, x,\ Y_1 = y_1\big]
  \;=\; W_1\big(y_1 \mid x\big)\, W_{2\mid1}\big(y_2 \mid y_1\big)
$$
であり，これが 定義 14.5.4 の条件である．$W_1$ のほうは $Y_1 = x \oplus Z_1$ から直に読める．$Z_1 = 1$ の確率が $\rho_1$ なので，$Y_1$ が $x$ と違う確率は $\rho_1$ である．

$W_2$ を計算する．$Y_2 = x \oplus Z_1 \oplus Z_2$ だから，$Y_2$ が $x$ と違うのは $Z_1 \oplus Z_2 = 1$ のとき，すなわち $Z_1$ と $Z_2$ のちょうど一方が $1$ のときである．二つは独立だから，その確率は $\rho_1(1-\rho_2) + (1-\rho_1)\rho_2$ である．この値は $x$ によらないので，$W_2$ は反転確率がこの値の二元対称通信路である．
:::

反転確率を二つ重ねると反転しやすくなる．実際，つないだ通信路の反転確率と $\rho_1$ の差は $\rho_2(1 - 2\rho_1)$ だから，$\rho_1 < 1/2$ かつ $0 < \rho_2 < 1/2$ のとき，つないだ反転確率は $\rho_1$ より大きく $1/2$ より小さい．補題 9.3.1 の第 $3$ の主張より $H_b$ は $[0,1/2]$ の上で減らないから，例 6.1.8 の容量 $1 - H_b(\rho)$ はこの範囲で $\rho$ を大きくしても増えない．よってこの場合の受け手 $2$ の側の容量は受け手 $1$ の側の容量以下である（補題 9.3.1 の第 $3$ の主張は非狭義の単調性なので，真に小さいとまでは言えない）．劣化という言葉はこの「後ろに置かれたほうが不利になる」という関係を，容量の比較ではなく通信路の作り方として書いたものである．

## 重ね合わせ符号化

道具を一つ借りる．**重ね合わせ符号化の達成可能性**，すなわち「補助変数を一つ挟んで測った情報量の内側のレート対が実際に達成できる」という主張である．使う形を書いておく．

$W$ をブロードキャスト通信路（定義 14.5.1）とする（二人の性能を比べる条件は求めない）．空でない有限アルファベット $\mathcal U$ 上の分布 $p_U$ と，$\mathcal U$ を入力，$\mathcal X$ を出力とする通信路 $K$（第6章 定義 6.1.1）をとり，$p_U$，$K$，$W$ がどれも全点で正，すなわち $p_U(u) > 0$，$K(x \mid u) > 0$，$W(y_1, y_2 \mid x) > 0$ がすべての $u \in \mathcal U$，$x \in \mathcal X$，$y_1 \in \mathcal Y_1$，$y_2 \in \mathcal Y_2$ で成り立つとする．四つ組 $(U, X, Y_1, Y_2)$ を，同時分布が $p_U(u)\,K(x \mid u)\,W(y_1, y_2 \mid x)$ であるような確率変数の組とする．実数の対 $(R_1, R_2)$ が $0 < R_1$，$0 < R_2$ と
$$
R_1 \;<\; I\big(X; Y_1 \,\big|\, U\big), \qquad R_2 \;<\; I\big(U; Y_2\big), \qquad
R_1 + R_2 \;<\; I\big((U, X); Y_1\big)
$$
を満たすならば，$(R_1, R_2)$ は 定義 14.5.3 の意味で達成可能である．さらに $W$ が 定義 14.5.4 の意味で物理的に劣化しているなら，三本目を落として最初の二本だけを課しても同じ結論が成り立つ．

当てる対象は 定義 14.5.2 のブロードキャスト符号だけである．これに依存するのは三箇所で，劣化を仮定した形を引くのが本節の終わりの地の文（逆定理との突き合わせ），三本の枠を課した形を引くのが 14.6 節 命題 14.6.5 の直後の地の文と，同じ節で借りる **能力がより高い通信路の容量領域** の筋書きである．あとの二つはこの名前で引く．

借りたままにするので，中で何が起きているかの筋書きだけ書いておく．符号語を二段に作る．まず補助変数の側の符号語 $U^n(m_2)$ を $p_U$ の $n$ 重積から $M_2$ 本引き，その一本ごとに，入力の側の符号語 $X^n(m_1, m_2)$ を $K(\cdot \mid U^n(m_2))$ の各文字からの積で $M_1$ 本引く．一本目の層を **雲**，その周りに散らした二本目の層を **衛星** と呼ぶ．受け手 $2$ は雲の符号語だけを読み，それが $m_2$ を教える．受け手 $1$ は，まず雲を読んで $m_2$ を当て，そのうえで雲に付いた衛星の中から $m_1$ を読む．$U$ は二人に共通で見える粗い層，$X$ は受け手 $1$ だけが見分けられる細かい層にあたり，二つの情報量 $I(U;Y_2)$ と $I(X;Y_1 \mid U)$ がそれぞれの層で運べる量である．三本目の枠が出るのはここからで，受け手 $1$ は雲と衛星の両方を読むのだから，二つを合わせた $I((U,X);Y_1)$ を超えては読めない．劣化しているときにこの三本目を落とせる理由は，14.6 節 命題 14.6.5 とその直後の地の文で見る．

本書はこの主張を証明しない．二段の符号帳についてのランダム符号化で，14.1 節で借りたものと同じ段，すなわち三通りに分かれる誤りの勘定と，符号帳についての平均から良い一組を取り出す段が要る．そのうえ雲と衛星が入れ子になっているので，第6章 6.3 節の一本の符号帳についての議論をそのまま二度使うのでは済まない．本節が借りたこの主張は，本書が証明を載せないだけで，無条件の機械検証済みの定理として形式化されている．

::: formalized
三本の枠を課した形 `bc_achievability_of_rate_lt`，劣化を仮定した形 `bc_achievability` (`InformationTheory/Shannon/BroadcastChannel/Achievability/Assembly.lean`)
:::

::: formalization-note
形式化の宣言は，目標の誤り確率を結論の中で全称にとらず，仮定の側に置いた形で書かれている．定義 14.5.3 はその全称を達成可能性の定義の中に入れているので，書き方が違うだけで述べていることは同じである．三本目の枠も，宣言では $R_1$ が非正の場合まで扱えるように $\max(R_1, 0) + R_2$ の形で書かれているが，借りた形は $0 < R_1$ を課しているので同じ式である．情報量のほうは，$I(X; Y_1 \mid U)$ と $I(U; Y_2)$ をエントロピーの差の形（定理 1.4.3 と 定理 1.3.4 の表現）で書いた `bcInfo₁`，`bcInfo₂` (`InformationTheory/Shannon/BroadcastChannel/Achievability/Setup.lean`)，$I((U,X); Y_1)$ を同じ形で書いた `bcInfoJoint` (`InformationTheory/Shannon/BroadcastChannel/Achievability/ErrorAnalysis.lean`) である．値は同じでも，宣言としては別の式である．
:::

## 劣化した通信路の逆定理

逆向き，すなわち達成できるレート対が上の二つの情報量で抑えられることを見る．抑えに現れる補助変数は，符号の側から作る．時刻 $i$ ごとに，受け手 $2$ のメッセージと，受け手 $2$ が時刻 $i$ までに見た出力とを束ねたものを $U_i$ とおく．これが上で借りた雲の役を果たす．

以下ではメッセージの対が一様分布に従うとして議論する．補題 14.5.7 と 定理 14.5.8 はこれを主張の仮定として書いている．証明が一様性を実際に使うので落とせる条件ではないが，符号の側に課すものではない．定義 14.5.2 の平均誤り確率はメッセージの対ごとの誤り確率を一様な重み $1/(M_1M_2)$ で平均した量なので，対に一様分布を与えると，受け手 $j$ の誤り確率 $\Pr[d_j(Y_j^n) \ne \mathrm{Msg}_j]$ がちょうど $\bar P_{e,j}$ になる．それを合わせるためにこちらが選ぶ分布である．

このあとの証明は，同じ計算を繰り返し使う．細かい条件のもとで条件付き分布が全点で同じ形をしているなら，条件を粗くしてもその形は変わらない，という計算である．先に切り出して名前を付けておく．

::: lemma 14.5.6 条件を粗くする
$A$ と $B$ を有限集合に値をとる確率変数とする（どちらも確率変数の組を一つにまとめたものでよい）．$g$ を $B$ の値の集合から有限集合への写像とし，$A$ の値と $g$ の値の対に実数を対応させる写像 $f$ をとる．$\Pr[B = b] > 0$ を満たすどの $b$ と，$A$ のどの値 $a$ についても
$$
\Pr\big[A = a \,\big|\, B = b\big] \;=\; f\big(a,\, g(b)\big)
$$
が成り立つとする．このとき，$\Pr[g(B) = c] > 0$ を満たすどの $c$ と，$A$ のどの値 $a$ についても $\Pr[A = a \mid g(B) = c] = f(a, c)$ である．
:::

::: proof
$\Pr[g(B) = c] > 0$ を満たす $c$ と，$A$ の値 $a$ を固定する．事象 $\{g(B) = c\}$ は，$g(b) = c$ を満たす $b$ についての事象 $\{B = b\}$ の交わらない合併だから
$$
\Pr\big[A = a,\ g(B) = c\big] \;=\; \sum_{b \,:\, g(b) = c} \Pr\big[A = a,\ B = b\big]
$$
である．右辺で $\Pr[B = b] = 0$ の項は $0$ だから落としてよい．残る項は，条件付き確率の定め方と仮定から $\Pr[B = b]\, f(a, g(b)) = \Pr[B = b]\, f(a, c)$ に等しい．$f(a,c)$ は $b$ によらないので和の外に出せて，残る $\sum_b \Pr[B = b]$ は $\Pr[g(B) = c]$ である．よって $\Pr[A = a,\ g(B) = c] = f(a,c)\,\Pr[g(B) = c]$ であり，両辺を $\Pr[g(B) = c]$ で割れば主張を得る．
:::

そのうえで，逆定理の証明に要る三つの評価を切り出しておく．

::: lemma 14.5.7
$W$ をブロードキャスト通信路（定義 14.5.1），$n \ge 1$ とし，$(M_1, M_2, c, d_1, d_2)$ を長さ $n$ のブロードキャスト符号（定義 14.5.2）とする．$(\mathrm{Msg}_1, \mathrm{Msg}_2)$ を $\{1,\dots,M_1\} \times \{1,\dots,M_2\}$ 上の一様分布に従う対とし，$X^n = (X_0,\dots,X_{n-1}) := c(\mathrm{Msg}_1, \mathrm{Msg}_2)$ とおく．$(Y_1^n, Y_2^n)$ を，$(\mathrm{Msg}_1, \mathrm{Msg}_2)$ を与えたときの条件付き分布が $W^n(\cdot, \cdot \mid X^n)$（定義 14.5.1）である確率変数の組とする．$Y_1^{<i} := (Y_{1,0},\dots,Y_{1,i-1})$，$Y_2^{<i} := (Y_{2,0},\dots,Y_{2,i-1})$ と書く．このとき次の三つが成り立つ．

1. $H\big(Y_1^n \,\big|\, \mathrm{Msg}_1, \mathrm{Msg}_2\big) = \sum_{i=0}^{n-1} H\big(Y_{1,i} \,\big|\, X_i\big)$ である．
2. $0 \le i < n$ を満たす各 $i$ について $H\big(Y_{1,i} \,\big|\, \mathrm{Msg}_2,\, Y_2^{<i},\, X_i\big) = H\big(Y_{1,i} \,\big|\, X_i\big)$ である．
3. $W$ が 定義 14.5.4 の意味で物理的に劣化しているなら，$0 \le i < n$ を満たす各 $i$ について $H\big(Y_{1,i} \,\big|\, \mathrm{Msg}_2,\, Y_1^{<i}\big) \le H\big(Y_{1,i} \,\big|\, \mathrm{Msg}_2,\, Y_2^{<i}\big)$ である．
:::

::: proof
以下，条件付き確率を $\Pr[\,\cdot \mid \cdot\,]$ と書き，条件の側が正の確率をもつ点で考える．

まず，時刻 $i$ の第 $1$ 出力の条件付き分布が同じ時刻の入力だけで決まることを見る．メッセージの対 $(m_1, m_2)$ を固定すると符号語 $x^n = c(m_1, m_2)$ が定まり，仮定より $Y^n$ の条件付き分布は $\prod_j W(\cdot, \cdot \mid x_j)$ である．右辺は時刻ごとの因子の積だから，$(\mathrm{Msg}_1, \mathrm{Msg}_2)$ を与えたとき対 $(Y_{1,j}, Y_{2,j})$ たちは条件付き独立で，時刻 $j$ の対の条件付き分布は $W(\cdot, \cdot \mid x_j)$ である．その第 $1$ 成分についての周辺は 定義 14.5.1 より $W_1(\cdot \mid x_j)$ だから
$$
\Pr\big[Y_{1,i} = y \,\big|\, \mathrm{Msg}_1 = m_1,\ \mathrm{Msg}_2 = m_2,\
  Y_1^{\ne i} = \cdot,\ Y_2^{\ne i} = \cdot\big] \;=\; W_1\big(y \,\big|\, x_i\big)
$$
がどの値の組についても成り立つ（$Y_1^{\ne i}$，$Y_2^{\ne i}$ は時刻 $i$ 以外の出力をすべて並べた組である）．右辺は $x_i$，すなわち $X_i$ の値だけの関数である．そこで，$(\mathrm{Msg}_1, \mathrm{Msg}_2, Y_1^{\ne i}, Y_2^{\ne i})$ の関数として書ける確率変数の組 $Z$ で，$X_i$ の値が $Z$ の値から定まるものをとるごとに，補題 14.5.6 を，$A$ に $Y_{1,i}$，$B$ にこの四つ組，$g$ に四つ組の値から $Z$ の値を与える対応，$f$ に「$A$ の値 $y$ と $Z$ の値の対を受け取り，$Z$ の値から読める $X_i$ の値 $x$ を使って $W_1(y \mid x)$ を返す写像」と読み替えて当てることができる．結論は $\Pr[Y_{1,i} = y \mid Z] = W_1(y \mid X_i)$ である．第 $1$ と第 $2$ の主張では，$Z$ のとり方を変えてこれを使う．第 $3$ の主張では，同じ 補題 14.5.6 を別の読み替えで当てる．

1. $(\mathrm{Msg}_1, \mathrm{Msg}_2) = (m_1, m_2)$ を与えたとき，$Y_{1,0}, \dots, Y_{1,n-1}$ は条件付き独立で，第 $j$ 成分の条件付き分布は $W_1(\cdot \mid x_j)$ である．独立な成分の組のエントロピーは成分のエントロピーの和である（定理 1.2.3 のチェイン則と，独立なら条件付きエントロピーが周辺のエントロピーに一致すること（定理 1.3.4 と 命題 1.3.2 の等号条件）を $n$ 回繰り返せばよい）．よってこの条件のもとでの $Y_1^n$ のエントロピーは $\sum_j H\big(W_1(\cdot \mid x_j)\big)$ である．定義 1.2.2 によりこれを $(m_1, m_2)$ について平均すると
   $$
   H\big(Y_1^n \,\big|\, \mathrm{Msg}_1, \mathrm{Msg}_2\big)
     \;=\; \sum_{j=0}^{n-1} \mathbb E\Big[\, H\big(W_1(\cdot \mid X_j)\big) \,\Big]
   $$
   である．いっぽう時刻 $j$ について $Z$ を $X_j$ 一つにとると，$X_j = x$ を与えたときの $Y_{1,j}$ の条件付き分布は $W_1(\cdot \mid x)$ だから，定義 1.2.2 より $H(Y_{1,j} \mid X_j) = \mathbb E[H(W_1(\cdot \mid X_j))]$ である．二つを合わせて第 $1$ の主張を得る．

2. $Z$ を $(\mathrm{Msg}_2, Y_2^{<i}, X_i)$ にとる．$\mathrm{Msg}_2$ はそのもの，$Y_2^{<i}$ は $Y_2^{\ne i}$ の一部，$X_i$ は $(\mathrm{Msg}_1, \mathrm{Msg}_2)$ の関数だから，これは四つ組の関数として書ける組である．$Z$ の値で $X_i = x$ のものを与えたときの $Y_{1,i}$ の条件付き分布は $W_1(\cdot \mid x)$ であり，そのエントロピーは $H(W_1(\cdot \mid x))$ である．定義 1.2.2 により平均すると $H(Y_{1,i} \mid \mathrm{Msg}_2, Y_2^{<i}, X_i) = \mathbb E[H(W_1(\cdot \mid X_i))]$ であり，第 $1$ の主張の後半で見たとおりこれは $H(Y_{1,i} \mid X_i)$ に等しい．

3. 劣化の因子 $W_{2\mid1}$ をとる．メッセージの対を固定したときの $Y^n$ の条件付き分布は $\prod_j W(\cdot, \cdot \mid x_j) = \prod_j W_1(\cdot \mid x_j) W_{2\mid1}(\cdot \mid \cdot)$ だから，$(\mathrm{Msg}_1, \mathrm{Msg}_2)$ と $Y_1^n = y_1^n$ を与えたときの $Y_2^n$ の条件付き分布は $\prod_j W_{2\mid1}(\cdot \mid y_{1,j})$ である．時刻 $i$ より前だけを取り出すと
   $$
   \Pr\big[Y_2^{<i} = y_2^{<i} \,\big|\, \mathrm{Msg}_1, \mathrm{Msg}_2,\ Y_1^n = y_1^n\big]
     \;=\; \prod_{j < i} W_{2\mid1}\big(y_{2,j} \,\big|\, y_{1,j}\big)
   $$
   であり，右辺は $y_1^{<i}$ だけの関数である．そこで 補題 14.5.6 を，$A$ に $Y_2^{<i}$，$B$ に $(\mathrm{Msg}_1, \mathrm{Msg}_2, Y_1^n)$ と読み替えて二度当てる．$g$ の行き先を $(\mathrm{Msg}_2, Y_1^{<i}, Y_{1,i})$ にとった場合と $(\mathrm{Msg}_2, Y_1^{<i})$ にとった場合とで，どちらも $y_1^{<i}$ が値から読めるので $f$ は同じ写像でよい．よって
   $$
   \Pr\big[Y_2^{<i} = y_2^{<i} \,\big|\, \mathrm{Msg}_2,\ Y_1^{<i},\ Y_{1,i}\big]
     \;=\; \Pr\big[Y_2^{<i} = y_2^{<i} \,\big|\, \mathrm{Msg}_2,\ Y_1^{<i}\big]
   $$
   が成り立つ．これは $(\mathrm{Msg}_2, Y_1^{<i})$ を与えたとき $Y_{1,i}$ と $Y_2^{<i}$ が条件付き独立だということだから，命題 1.4.2 の等号条件より $I\big(Y_{1,i}; Y_2^{<i} \mid \mathrm{Msg}_2, Y_1^{<i}\big) = 0$ である．定理 1.4.3 をこの相互情報量に当てると
   $$
   H\big(Y_{1,i} \,\big|\, \mathrm{Msg}_2, Y_1^{<i}\big)
     \;=\; H\big(Y_{1,i} \,\big|\, \mathrm{Msg}_2, Y_1^{<i}, Y_2^{<i}\big)
   $$
   であり，定理 1.2.4 より右辺は $H(Y_{1,i} \mid \mathrm{Msg}_2, Y_2^{<i})$ 以下である．
:::

::: theorem 14.5.8 劣化したブロードキャスト通信路の逆定理
$W$ をブロードキャスト通信路（定義 14.5.1）で 定義 14.5.4 の意味で物理的に劣化しているものとし，$n \ge 1$ とする．$(M_1, M_2, c, d_1, d_2)$ を長さ $n$ のブロードキャスト符号（定義 14.5.2）で $M_1 \ge 2$ かつ $M_2 \ge 2$ を満たすものとし，$(\mathrm{Msg}_1, \mathrm{Msg}_2)$，$X^n$，$(Y_1^n, Y_2^n)$ を 補題 14.5.7 のとおりとする．$P_{e,1} := \Pr[d_1(Y_1^n) \ne \mathrm{Msg}_1]$，$P_{e,2} := \Pr[d_2(Y_2^n) \ne \mathrm{Msg}_2]$ とおき，各 $i$ について $U_i := (\mathrm{Msg}_2, Y_2^{<i})$ とおく．このとき
$$
\log M_1 \;\le\; \sum_{i=0}^{n-1} I\big(X_i; Y_{1,i} \,\big|\, U_i\big)
  \;+\; H_b\big(P_{e,1}\big) \;+\; P_{e,1} \log\big(M_1 - 1\big),
$$
$$
\log M_2 \;\le\; \sum_{i=0}^{n-1} I\big(U_i; Y_{2,i}\big)
  \;+\; H_b\big(P_{e,2}\big) \;+\; P_{e,2} \log\big(M_2 - 1\big)
$$
である（$H_b$ は 例 1.1.2 の二値エントロピー）．

::: proof
**受け手 $2$ の側の評価は，ファノの不等式を出力列のチェイン則でほどけば出る.** 定理 6.4.1 を，対象に $\mathrm{Msg}_2$，観測に $Y_2^n$，復号器に $d_2$ を置いて当てると
$$
\log M_2 \;\le\; I\big(\mathrm{Msg}_2; Y_2^n\big) + H_b\big(P_{e,2}\big) + P_{e,2}\log\big(M_2-1\big)
$$
である（$\mathrm{Msg}_2$ は一様分布に従う．対 $(\mathrm{Msg}_1,\mathrm{Msg}_2)$ が一様なら成分も一様だからである）．第 $1$ 項を分解する．定理 1.5.2 を，変数列に $Y_{2,0},\dots,Y_{2,n-1}$ を，相手側の変数に $\mathrm{Msg}_2$ を置いて当て，命題 1.3.3 と 命題 1.4.2 の対称性で向きをそろえると
$$
I\big(\mathrm{Msg}_2; Y_2^n\big)
  \;=\; \sum_{i=0}^{n-1} I\big(\mathrm{Msg}_2; Y_{2,i} \,\big|\, Y_2^{<i}\big)
$$
である．各項に 定理 1.5.1 を，その $Z$ に $Y_2^{<i}$，$X$ に $\mathrm{Msg}_2$，$Y$ に $Y_{2,i}$ と読み替えて当てると
$$
I\big(U_i; Y_{2,i}\big) \;=\; I\big(Y_2^{<i}; Y_{2,i}\big)
  + I\big(\mathrm{Msg}_2; Y_{2,i} \,\big|\, Y_2^{<i}\big)
$$
であり，命題 1.3.2 より第 $1$ 項は非負だから $I(\mathrm{Msg}_2; Y_{2,i} \mid Y_2^{<i}) \le I(U_i; Y_{2,i})$ である．和をとって第 $2$ の主張を得る．

**受け手 $1$ には，相手のメッセージをただで渡してよい.** 渡したうえでの評価もそのまま $\log M_1$ の上界になるので，そこから始める．定理 6.4.1 を，対象に $\mathrm{Msg}_1$，観測に対 $(\mathrm{Msg}_2, Y_1^n)$，復号器に「第 $2$ 成分だけを見て $d_1$ を当てる写像」を置いて当てる．その復号器の誤り確率は $\Pr[d_1(Y_1^n) \ne \mathrm{Msg}_1] = P_{e,1}$ だから
$$
\log M_1 \;\le\; I\big(\mathrm{Msg}_1; (\mathrm{Msg}_2, Y_1^n)\big)
  + H_b\big(P_{e,1}\big) + P_{e,1}\log\big(M_1-1\big)
$$
である．第 $1$ 項を書き換える．定理 1.5.1 を，その $Z$ に $\mathrm{Msg}_2$，$X$ に $Y_1^n$，$Y$ に $\mathrm{Msg}_1$ と読み替えて当て，命題 1.3.3 と 命題 1.4.2 の対称性で向きをそろえると
$$
I\big(\mathrm{Msg}_1; (\mathrm{Msg}_2, Y_1^n)\big)
  \;=\; I\big(\mathrm{Msg}_1; \mathrm{Msg}_2\big) + I\big(\mathrm{Msg}_1; Y_1^n \,\big|\, \mathrm{Msg}_2\big)
$$
である．対 $(\mathrm{Msg}_1, \mathrm{Msg}_2)$ が一様分布に従うので二つの成分は独立であり，命題 1.3.2 の等号条件より第 $1$ 項は $0$ である．

残りをエントロピーの差に直す．定理 1.4.3 を，その $X$ に $Y_1^n$，$Y$ に $\mathrm{Msg}_2$，$Z$ に $\mathrm{Msg}_1$ と読み替えて当て，命題 1.4.2 の対称性で向きをそろえると
$$
I\big(\mathrm{Msg}_1; Y_1^n \,\big|\, \mathrm{Msg}_2\big)
  \;=\; H\big(Y_1^n \,\big|\, \mathrm{Msg}_2\big)
    - H\big(Y_1^n \,\big|\, \mathrm{Msg}_1, \mathrm{Msg}_2\big)
$$
である．第 $1$ 項に 定理 1.2.3 のチェイン則を $n$ 回繰り返して
$$
H\big(Y_1^n \,\big|\, \mathrm{Msg}_2\big)
  \;=\; \sum_{i=0}^{n-1} H\big(Y_{1,i} \,\big|\, \mathrm{Msg}_2,\ Y_1^{<i}\big)
$$
を得る（条件に $\mathrm{Msg}_2$ を置いたままチェイン則を当てている）．第 $2$ 項には 補題 14.5.7 の第 $1$ の主張を当てる．よって
$$
I\big(\mathrm{Msg}_1; Y_1^n \,\big|\, \mathrm{Msg}_2\big)
  \;=\; \sum_{i=0}^{n-1} \Big( H\big(Y_{1,i} \,\big|\, \mathrm{Msg}_2, Y_1^{<i}\big)
    - H\big(Y_{1,i} \,\big|\, X_i\big) \Big)
$$
である．

**劣化が効くのはここ一箇所で，条件を受け手 $1$ の過去の出力から受け手 $2$ の過去の出力に置き換えるところである.** 各項の第 $1$ 成分に 補題 14.5.7 の第 $3$ の主張を当てると，右辺は
$$
\sum_{i=0}^{n-1} \Big( H\big(Y_{1,i} \,\big|\, U_i\big) - H\big(Y_{1,i} \,\big|\, X_i\big) \Big)
$$
以下である．補題 14.5.7 の第 $2$ の主張より $H(Y_{1,i} \mid X_i) = H(Y_{1,i} \mid U_i, X_i)$ だから，各項は 定理 1.4.3 を，その $X$ に $Y_{1,i}$，$Y$ に $U_i$，$Z$ に $X_i$ と読み替えて当てた形になっており，命題 1.4.2 の対称性で向きをそろえれば $I(X_i; Y_{1,i} \mid U_i)$ に等しい．合わせて第 $1$ の主張を得る．
