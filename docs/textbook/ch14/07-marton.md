# 14.7 Marton の内界

14.6 節は三つのクラスで容量領域を決めた．どのクラスも二人の受け手に優劣が付いていることを求めている．どのクラスにも入らない通信路，すなわち入力の選び方によって有利な受け手が入れ替わるような通信路については，容量領域は分かっていない．そこで内側と外側から挟む．外側からの評価は 14.6 節の UV 外界が与えた．本節は内側からの評価，すなわち確かに達成できるレート対の集合を置く．そういう通信路が本当にあることは，本節の終わりに 例 14.7.6 として一つ書き下す．

道具立ては 14.5 節と同じ補助変数だが，置き方が違う．重ね合わせ符号化は補助変数を一つだけ置いて，それを二人に共通で見える粗い層にした．優劣が付かないなら共通の層をとる理由がないので，受け手ごとに一つずつ補助変数を置く．二つの符号帳を別々に作り，送る直前に組み合わせる，という作り方がそれにあたる．

本節は二つの補助変数を $V_1$，$V_2$ と書く．$V$ の字は本書ですでに三通りに使われていて，第6章 6.6 節が強逆定理の証明で対数尤度比 $V_i$ に，第8章 8.3 節がガウス通信路の受信列 $V$ に，第9章 9.4 節が情報源と再生の食い違い $V$ に使っている．本節の $V_1$，$V_2$ はそのどれでもなく，情報量の引数に置かれる補助変数である．添字が付いているが，第6章のものにも添字が付くので見分けの根拠にはならない．直前の 14.6 節の $V$ は，これと同じ役の補助変数である．定義 14.6.6 の $U$ と $V$ が本節の $V_2$ と $V_1$ にそれぞれ対応することは，下の 定理 14.7.5 の証明が使う読み替えでもある．

## 四辺形

::: definition 14.7.1 Marton の四辺形
$W$ をブロードキャスト通信路（定義 14.5.1）とする．空でない有限アルファベット $\mathcal V_1$，$\mathcal V_2$ と，$\mathcal V_1 \times \mathcal V_2$ 上の分布 $p_V$，および $\mathcal V_1 \times \mathcal V_2$ を入力・$\mathcal X$ を出力とする通信路 $K$（第6章 定義 6.1.1）をとる．五つ組 $(V_1, V_2, X, Y_1, Y_2)$ を，同時分布が
$$
p_V\big(v_1, v_2\big)\, K\big(x \,\big|\, v_1, v_2\big)\, W\big(y_1, y_2 \,\big|\, x\big)
$$
であるような確率変数の組とする．三つの不等式
$$
R_1 \;\le\; I\big(V_1; Y_1\big), \qquad R_2 \;\le\; I\big(V_2; Y_2\big), \qquad
R_1 + R_2 \;\le\; I\big(V_1; Y_1\big) + I\big(V_2; Y_2\big) - I\big(V_1; V_2\big)
$$
をすべて満たす実数の対 $(R_1, R_2)$ の集合を **Marton の四辺形** と呼び，$\mathcal M(p_V, K)$ と書く．
:::

前の二本は，受け手ごとの粗い層がその受け手にどれだけ届くかを言っているだけで，14.5 節の枠と同じ形である．目新しいのは三本目の $-I(V_1;V_2)$ で，二つの補助変数が独立でないぶんだけ和レートから引かれている．$I(V_1;V_2) = 0$，すなわち二つが独立なら三本目は前の二本から従うので，四辺形は長方形に戻る．

わざと相関をもたせたい理由は，送れる入力列が一本しかないところにある．$V_1$ の側の符号語と $V_2$ の側の符号語は $K$ を通して一本の入力列に合わさるので，二つをまったく無関係に引くと，出来上がった入力列がどちらの受け手にも中途半端になりうる．二つの補助変数に相関を許せば，受け手ごとに合わせた符号語どうしのうち相性のよい組だけを選んで合わせられる．前の二本の右辺 $I(V_1;Y_1)$ と $I(V_2;Y_2)$ は，そうして選んだ組についての量になる．選ぶために余分な符号語を用意するぶんが $I(V_1;V_2)$ で，三本目の和レートから引かれる．損が和レートの一本だけに掛かり，前の二本には掛からないところが，この取り引きの要である．どちらのとり方が得かは通信路による．定義 14.7.2 の内界は $(p_V, K)$ のとり方すべてにわたる合併なので，独立にとった長方形も相関をもたせた四辺形もどちらも入っており，得なほうが自動的に拾われる．

道具を一つ借りる．**Marton の内界の達成可能性**，すなわち「四辺形はまるごと達成できる」という主張である．使う形を書いておく．

$W$ をブロードキャスト通信路とし，$W$ が全点で正，すなわち $W(y_1, y_2 \mid x) > 0$ がすべての $x \in \mathcal X$，$y_1 \in \mathcal Y_1$，$y_2 \in \mathcal Y_2$ で成り立つとする．このとき，空でない有限アルファベットの対と $p_V$，$K$ をどう選んでも
$$
\mathcal M\big(p_V, K\big) \;\subseteq\; \mathcal C(W)
$$
である（$\mathcal C(W)$ は 定義 14.5.3 の容量領域）．

当てる対象は 定義 14.7.1 の四辺形と 定義 14.5.3 の容量領域だけで，依存するのは 定理 14.7.3 の証明だけである．

借りたままにするので，中で何が起きているかの筋書きだけ書いておく．受け手ごとに別の符号帳を引く．$V_1$ の側の符号帳から $m_1$ のための行を一本，$V_2$ の側から $m_2$ のための行を一本選び，その二本が結合典型になる組み合わせを探して，見つかった対を $K$ に通して入力列を作る．二本の符号語をこうして**噛み合わせる**には，行ごとに符号語を何本か余分に用意しておかなければならない．余分に要る本数がちょうど $2^{n I(V_1;V_2)}$ ほどで，それが和レートから引かれる．引き算の正体は，二本の符号語を噛み合わせる手間である．受け手 $1$ は $V_1$ の符号帳だけを，受け手 $2$ は $V_2$ の符号帳だけを読むので，前の二本の枠はそれぞれの読み取りが通る条件になっている．

本書はこの主張を証明しない．噛み合う組が確かに見つかることを言う段（この段は**相互被覆**と呼ばれる）が，第2章・第6章の典型性の道具の外にあるからである．さらに，補助変数の分布と $K$ に全点で正であることを課さずに済ませる段が要る．そこは 14.2 節が五角形について借りた主張と同じ形で，補助変数の側を一様分布のほうへわずかにずらして全点で正にし，三つの情報量が連続的に動くことを確かめて，ずらし幅を $0$ にする極限で戻す．

## 内界

::: definition 14.7.2 Marton の内界

## 内界は外界に含まれる

内界と外界は，どちらも容量領域を挟むために別々に定めたものだから，両端どうしが直につながるかどうかは改めて確かめることになる．結論からいえばつながり，しかも 定理 14.7.3 と違って $W$ が全点で正であることは要らない．道具を一つ用意しておく．第1章 定理 1.8.4 のデータ処理不等式は，条件を置かない形で述べられていた．以下で要るのは，何かを知っている人から見た形である．

::: lemma 14.7.4 条件付きデータ処理不等式
$A$，$B$，$C$，$D$ を有限集合に値をとる確率変数とする（どれも確率変数の組を一つにまとめたものでよい）．対 $(D, A)$，対 $(D, C)$，$B$ がこの順にマルコフ連鎖（定義 1.8.3）をなすとする．このとき
$$
I\big(A; B \,\big|\, D\big) \;\le\; I\big(C; B \,\big|\, D\big)
$$
である．
:::

::: proof
定理 1.5.1 を，その $Z$ に $D$，$X$ に $A$，$Y$ に $B$ と読み替えて当てると $I\big((D, A); B\big) = I(D;B) + I(A;B \mid D)$ である．同じ定理を $X$ に $C$ と読み替えて当てると $I\big((D, C); B\big) = I(D;B) + I(C;B \mid D)$ である．いっぽう 定理 1.8.4 を仮定のマルコフ連鎖に，その $X$ に対 $(D,A)$，$Z$ に対 $(D,C)$，$Y$ に $B$ と読み替えて当てると $I\big((D,A); B\big) \le I\big((D,C); B\big)$ である．$B$ のとりうる値の集合を $\mathcal B$ と書くと，定理 1.1.5 より $H(B) \le \log\lvert\mathcal B\rvert$ であり，定理 1.2.4 より $H(B \mid D) \le H(B)$ だから，定理 1.3.4 の表す $I(D;B) = H(B) - H(B \mid D)$ は有限の実数である．よって二つの等式を不等式に入れ，両辺から $I(D;B)$ を引けば主張を得る．
:::

::: theorem 14.7.5
$W$ をブロードキャスト通信路（定義 14.5.1）とする（全点で正であることは求めない）．このとき
$$
\mathcal I_M(W) \;\subseteq\; \mathcal O_{UV}(W)
$$
である（$\mathcal O_{UV}(W)$ は 定義 14.6.6 の UV 外界）．
:::

::: proof
空でない有限アルファベットの対と $p_V$，$K$ を一組固定し，五つ組 $(V_1, V_2, X, Y_1, Y_2)$ を 定義 14.7.1 のとおりとする．成分を並べ替えた五つ組 $(V_2, V_1, X, Y_1, Y_2)$ の同時分布を $\nu$ と書く．つまり 定義 14.6.6 の $U$ に $V_2$ を，$V$ に $V_1$ を当てる．以下，条件付き確率を $\Pr[\,\cdot \mid \cdot\,]$ と書き，条件の側が正の確率をもつ点で考える．

**$\nu$ は通信路の法である.** 定義 14.7.1 の同時分布で $(V_2, V_1, X) = (v_2, v_1, x)$ を与えると，$(Y_1, Y_2)$ の条件付き分布は残る因子 $W(\cdot, \cdot \mid x)$ である．これは $x$ だけで決まるから，定義 14.6.6 の条件がそのまま成り立つ．有限アルファベットは可算なので，補助アルファベットについての条件も満たされている．

**相関を引いた残りは，補助変数を条件に置いた入力の情報量で抑えられる.** 二つの評価
$$
I\big(V_1; Y_1\big) - I\big(V_1; V_2\big) \;\le\; I\big(X; Y_1 \,\big|\, V_2\big), \qquad
I\big(V_2; Y_2\big) - I\big(V_1; V_2\big) \;\le\; I\big(X; Y_2 \,\big|\, V_1\big)
$$
を示す．前者を二段で出す．第一段は，相関を条件に移すところである．定理 1.5.1 を，その $Z$ に $V_2$，$X$ に $Y_1$，$Y$ に $V_1$ と読み替えて当て，命題 1.3.3 と 命題 1.4.2 の対称性で向きをそろえると $I\big(V_1; (V_2, Y_1)\big) = I(V_1;V_2) + I(V_1;Y_1 \mid V_2)$ である．同じ定理を $Z$ に $Y_1$，$X$ に $V_2$ と読み替え，同じく向きをそろえて当てると $I\big(V_1; (Y_1, V_2)\big) = I(V_1;Y_1) + I(V_1;V_2 \mid Y_1)$ である．左辺は対の並べ方によらないので二つの右辺は等しく，命題 1.4.2 より $I(V_1;V_2 \mid Y_1) \ge 0$ だから $I(V_1;Y_1) - I(V_1;V_2) \le I(V_1;Y_1 \mid V_2)$ である．

第二段は，補助変数を入力に取り替えるところである．補題 14.7.4 を，その $A$ に $V_1$，$B$ に $Y_1$，$C$ に $X$，$D$ に $V_2$ と読み替えて当てる．仮定を確かめる．条件の側に $V_2$ が入っているので，対 $(V_2, V_1)$ と $Y_1$ の条件付き独立は，$V_1$ と $Y_1$ の条件付き独立と同じことである．そこで $(V_2, X)$ を与えたとき $V_1$ と $Y_1$ が条件付き独立であることを示す．定義 14.7.1 の同時分布で $(V_1, V_2, X) = (v_1, v_2, x)$ を与えると $(Y_1, Y_2)$ の条件付き分布は $W(\cdot, \cdot \mid x)$ だから，第 $1$ 成分についての周辺をとって $\Pr[Y_1 = y_1 \mid V_1, V_2, X] = W_1(y_1 \mid X)$ である（$W_1$ は 定義 14.5.1 の周辺通信路）．右辺は $(V_2, X)$ の値から読めるので，補題 14.5.6 を，$A$ に $Y_1$，$B$ に三つ組 $(V_1, V_2, X)$，$g$ にその値から $(V_2, X)$ の値を与える対応，$f$ に「$Y_1$ の値 $y_1$ と $(V_2, X)$ の値の対から，そこに含まれる $X$ の値 $x$ を読んで $W_1(y_1 \mid x)$ を返す写像」と読み替えて当てると $\Pr[Y_1 = y_1 \mid V_2, X] = W_1(y_1 \mid X)$ を得る．条件付き確率のチェイン則に二つを入れると $\Pr[V_1 = v_1,\, Y_1 = y_1 \mid V_2, X] = \Pr[V_1 = v_1 \mid V_2, X]\, \Pr[Y_1 = y_1 \mid V_1, V_2, X] = \Pr[V_1 = v_1 \mid V_2, X]\,\Pr[Y_1 = y_1 \mid V_2, X]$ であり，これが 定義 1.8.3 の条件である．よって 補題 14.7.4 より $I(V_1;Y_1 \mid V_2) \le I(X;Y_1 \mid V_2)$ であり，第一段と合わせて前者を得る．後者は，$(V_1, Y_1)$ と $(V_2, Y_2)$ を入れ替えた五つ組に同じ議論を当てれば出る．入れ替えた組の同時分布も 定義 14.7.1 の形をしている（$p_V$ の二つの成分を入れ替え，$K$ の引数も入れ替え，$W$ の二つの出力を入れ替えたものをとればよい）．$I(V_1;V_2)$ が入れ替えで変わらないことは 命題 1.3.3 による．

**四辺形は $\mathcal{UV}(\nu)$ に含まれる.** $(R_1, R_2) \in \mathcal M(p_V, K)$ をとる．定義 14.7.1 の第 $1$ と第 $2$ の不等式は，読み替えのもとで 定義 14.6.6 の第 $1$ と第 $2$ の不等式そのものである．第 $3$ の不等式の右辺に，いま示した二つの評価をそれぞれ当てると
$$
R_1 + R_2 \;\le\; I\big(V_2;Y_2\big) + I\big(X;Y_1 \,\big|\, V_2\big), \qquad
R_1 + R_2 \;\le\; I\big(V_1;Y_1\big) + I\big(X;Y_2 \,\big|\, V_1\big)
$$
であり，これが 定義 14.6.6 の第 $3$ と第 $4$ の不等式である．よって $\mathcal M(p_V, K) \subseteq \mathcal{UV}(\nu)$ である．

**合併と閉包に移しても包含は保たれる.** $\nu$ は通信路の法だから $\mathcal{UV}(\nu)$ は 定義 14.6.6 の合併に含まれ，合併はその閉包 $\mathcal O_{UV}(W)$ に含まれる．$(p_V, K)$ は任意だったから，四辺形の合併が $\mathcal O_{UV}(W)$ に含まれる．14.2 節で借りた **平面の閉集合と閉包の基本性質** の第一より $\mathcal O_{UV}(W)$ は閉集合であり，同じ第一により合併の閉包 $\mathcal I_M(W)$ は合併を含む最小の閉集合だから，$\mathcal O_{UV}(W)$ に含まれる．
:::

## 挟み込み

定理 14.7.3 と，14.6 節で借りた **UV 外界は容量領域を含む** を並べると，$W$ が全点で正であるかぎり
$$
\mathcal I_M(W) \;\subseteq\; \mathcal C(W) \;\subseteq\; \mathcal O_{UV}(W)
$$
である．定理 14.7.5 は，この両端を真ん中を経由せずに直につないでいる．真ん中が左の端と一致するのかどうかも，右の端と一致するのかどうかも，**本書も形式化も述べない**．一般のブロードキャスト通信路の容量領域は分かっていない，というのが現在の状況である．分かっていないというのは，領域を与える式がまだ見つかっていないという意味であって，そういう式が存在しえないことが示されているわけではない．

14.6 節の三つのクラスでは，右の二つが一致する（系 14.6.7 と，そこで借りた **能力がより高い通信路の容量領域**）．左がそれに一致するかどうかは，そのクラスの中でも本書は述べない．内界が容量領域を超えないという向きは 定理 14.7.3 が与えるが，逆向き，すなわち容量領域の点がどれも四辺形の合併の閉包に入ることを述べる主張は，本書にも形式化にもない．挟み込みで言えているのは，左と右のあいだに真ん中があるというところまでである．

## どのクラスにも入らない通信路

本節の出発点は，14.6 節の三つのクラスのどれにも入らない通信路がある，というところだった．そういう通信路を一つ書き下しておく．二人の受け手に別の種類の雑音を割り当てれば，入力の選び方で有利な受け手が入れ替わる．

::: example 14.7.6 対称な雑音と消失を並べる
$\mathcal X = \{0,1\}$，$\mathcal Y_1 = \{0,1\}$，$\mathcal Y_2 = \{0,1,\ast\}$ とし，$W_1$ を反転確率 $0.1$ の二元対称通信路（例 6.1.8），$W_2$ を消失確率 $0.5$ の二元消失通信路（例 6.1.9）として，
$$
W\big(y_1, y_2 \,\big|\, x\big) \;:=\; W_1\big(y_1 \mid x\big)\, W_2\big(y_2 \mid x\big)
$$
で定まる対応を $W$ とする．このとき $W$ は 定義 14.5.1 の意味でブロードキャスト通信路であり，その二つの周辺通信路は $W_1$，$W_2$ である．$\mathcal X$ 上の分布 $p$ が $p(1) = 1/2$ を満たすなら $I(p; W_2) < I(p; W_1)$ であり，$p(1) = 0.05$ を満たすなら $I(p; W_1) < I(p; W_2)$ である（$I(p; \cdot)$ は第6章 定義 6.1.2 の通信路の相互情報量）．したがって受け手 $1$ が受け手 $2$ より 定義 14.6.2 の意味で能力がより高いことはなく，受け手の番号を入れ替えても同じである．$W$ は 14.6 節の三つのクラスのどれにも，どちらの向きにも入らない．
:::

::: proof
通信路であることと周辺通信路を確かめる．$W(y_1, y_2 \mid x) \ge 0$ であり，$\sum_{y_1, y_2} W_1(y_1 \mid x) W_2(y_2 \mid x)$ は二つの和の積 $1 \cdot 1$ に等しい．定義 14.5.1 の周辺は，$y_2$ について和をとると $W_1(y_1 \mid x)$，$y_1$ について和をとると $W_2(y_2 \mid x)$ である．

二つの量を入力分布の式で書く．$\pi := p(1)$ とおく（例 6.1.9 の証明と同じ置き方である）．消失通信路の側は 例 6.1.9 の証明が任意の入力分布について計算しており，消失確率 $\eta$ に対して $I(p; W_2) = (1-\eta) H_b(\pi)$ である（$H_b$ は 例 1.1.2 の二値エントロピー）．$\eta = 0.5$ だから $I(p;W_2) = H_b(\pi)/2$ である．対称通信路の側は，例 6.1.8 の証明より $H(Y_1 \mid X) = H_b(0.1)$ であり，出力が $1$ になる確率は $0.9\pi + 0.1(1-\pi)$ だから，命題 6.1.3 と 定理 1.3.4 より $I(p; W_1) = H_b\big(0.9\pi + 0.1(1-\pi)\big) - H_b(0.1)$ である．

値を入れる．$\pi = 1/2$ では $0.9\pi + 0.1(1-\pi) = 1/2$ だから $I(p;W_1) = 1 - H_b(0.1)$ で，$H_b(0.1) = 0.4689\ldots$ よりおよそ $0.531$ である．いっぽう $I(p;W_2) = H_b(1/2)/2 = 1/2$ だから，$I(p;W_2) < I(p;W_1)$ である．$\pi = 0.05$ では $0.9 \cdot 0.05 + 0.1 \cdot 0.95 = 0.14$ だから $I(p;W_1) = H_b(0.14) - H_b(0.1)$ で，$H_b(0.14) = 0.5842\ldots$ よりおよそ $0.115$ である．いっぽう $I(p;W_2) = H_b(0.05)/2$ で，$H_b(0.05) = 0.2863\ldots$ よりおよそ $0.143$ だから，$I(p;W_1) < I(p;W_2)$ である．

クラスの外にあることを見る．定義 14.6.2 が求めているのは，どの入力分布についても $I(p;W_2) \le I(p;W_1)$ が成り立つことである．$\pi = 0.05$ の分布がこれを破るので，受け手 $1$ は受け手 $2$ より能力がより高くない．定理 14.6.4 の対偶より受け手 $1$ は受け手 $2$ より 定義 14.6.1 の意味で雑音がより少なくもなく，定理 14.6.3 の対偶より $W$ は 定義 14.5.4 の意味で物理的に劣化してもいない．番号を入れ替えた向きは，出力の対の二つの成分を入れ替えて得られるブロードキャスト通信路に同じ議論を当てる．その周辺通信路は順に $W_2$，$W_1$ なので，定義 14.6.2 がそちらに求めるのはどの入力分布についても $I(p;W_1) \le I(p;W_2)$ が成り立つことであり，$\pi = 1/2$ の分布がこれを破る．あとは同じ二つの対偶による．
:::

一様な入力では，反転確率 $0.1$ の二元対称通信路のほうが消失確率 $0.5$ の二元消失通信路より多く運べる．これは第6章 6.1 節が計算した二つの容量 $1 - H_b(0.1)$ と $1 - 0.5$ の比較そのものである．ところが入力を $0$ の側へ偏らせると，対称通信路の側では出力の偏りが雑音で薄められて $H_b(0.14)$ までしか下がらず，そこから $H_b(0.1)$ を引くと残りが小さい．消失通信路の側は届いたビットがそのまま信用できるので，$H_b(0.05)$ に $1/2$ を掛けるだけで済む．その差が $\pi = 0.05$ では大小をひっくり返す．どちらの受け手に合わせて入力を選ぶかで優劣が入れ替わるので，14.6 節の三つのクラスはどれも当たらず，系 14.6.7 も，そこで借りた **能力がより高い通信路の容量領域** も，この $W$ には当てられない．残るのが，定理 14.7.3 と 定理 14.7.5 の挟み込みである．
