# 14.7 Marton の内界

14.6 節は三つのクラスで容量領域を決めた．どのクラスも二人の受け手に優劣が付いていることを求めている．どのクラスにも入らない通信路，すなわち入力の選び方によって有利な受け手が入れ替わるような通信路については，容量領域は分かっていない．そこで内側と外側から挟む．外側からの評価は 14.6 節の UV 外界が与えた．本節は内側からの評価，すなわち確かに達成できるレート対の集合を置く．

道具立ては 14.5 節と同じ補助変数だが，置き方が違う．重ね合わせ符号化は補助変数を一つだけ置いて，それを二人に共通で見える粗い層にした．優劣が付かないなら共通の層をとる理由がないので，受け手ごとに一つずつ補助変数を置く．二つの符号帳を別々に作り，送る直前に組み合わせる，という作り方がそれにあたる．

本節は二つの補助変数を $V_1$，$V_2$ と書く．$V$ の字は本書ですでに三通りに使われていて，第6章 6.6 節が強逆定理の証明で対数尤度比 $V_i$ に，第8章 8.3 節がガウス通信路の受信列 $V$ に，第9章 9.4 節が情報源と再生の食い違い $V$ に使っている．本節の $V_1$，$V_2$ はそのどれでもなく，情報量の引数に置かれる補助変数である．添字が付いているが，第6章のものにも添字が付くので見分けの根拠にはならない．

## 四辺形

::: definition 14.7.1 Marton の四辺形
$W$ をブロードキャスト通信路（定義 14.5.1）とする．空でない有限アルファベット $\mathcal V_1$，$\mathcal V_2$ と，$\mathcal V_1 \times \mathcal V_2$ 上の分布 $p_V$，および $\mathcal V_1 \times \mathcal V_2$ を入力・$\mathcal X$ を出力とする通信路 $K$（第6章 定義 6.1.1）をとる．五つ組 $(V_1, V_2, X, Y_1, Y_2)$ を，同時分布が
$$
p_V\big(v_1, v_2\big)\, K\big(x \,\big|\, v_1, v_2\big)\, W\big(y_1, y_2 \,\big|\, x\big)
$$
であるような確率変数の組とする．三つの不等式
$$
R_1 \;\le\; I\big(V_1; Y_1\big), \qquad R_2 \;\le\; I\big(V_2; Y_2\big), \qquad
R_1 + R_2 \;\le\; I\big(V_1; Y_1\big) + I\big(V_2; Y_2\big) - I\big(V_1; V_2\big)
$$
をすべて満たす実数の対 $(R_1, R_2)$ の集合を **Marton の四辺形** と呼び，$\mathcal M(p_V, K)$ と書く．
:::

前の二本は，受け手ごとの粗い層がその受け手にどれだけ届くかを言っているだけで，14.5 節の枠と同じ形である．目新しいのは三本目の $-I(V_1;V_2)$ で，二つの補助変数が独立でないぶんだけ和レートから引かれている．$I(V_1;V_2) = 0$，すなわち二つが独立なら三本目は前の二本から従うので，四辺形は長方形に戻る．引き算が効くのは，わざと相関をもたせたときである．

::: formalized
`martonRegion` (`InformationTheory/Shannon/BroadcastChannel/Operational.lean`)
:::

::: formalization-note
形式化の三つの情報量は，$I(V_1;Y_1)$，$I(V_2;Y_2)$，$I(V_1;V_2)$ をエントロピーの差の形（定理 1.3.4 の表現）で書いた `martonInfo₁`，`martonInfo₂`，`martonInfoV₁V₂` (`InformationTheory/Shannon/BroadcastChannel/Marton/Setup.lean`) である．値は同じでも，宣言としては別の式である．
:::

道具を一つ借りる．**Marton の内界の達成可能性**，すなわち「四辺形はまるごと達成できる」という主張である．使う形は次のとおり．

$W$ をブロードキャスト通信路とし，$W$ が全点で正，すなわち $W(y_1, y_2 \mid x) > 0$ がすべての $x \in \mathcal X$，$y_1 \in \mathcal Y_1$，$y_2 \in \mathcal Y_2$ で成り立つとする．このとき，空でない有限アルファベットの対と $p_V$，$K$ をどう選んでも
$$
\mathcal M\big(p_V, K\big) \;\subseteq\; \mathcal C(W)
$$
である（$\mathcal C(W)$ は 定義 14.5.3 の容量領域）．

当てる対象は 定義 14.7.1 の四辺形と 定義 14.5.3 の容量領域だけで，依存するのは 定理 14.7.3 の証明だけである．

借りたままにするので，筋書きだけ書いておく．受け手ごとに別の符号帳を引く．$V_1$ の側の符号帳から $m_1$ のための行を一本，$V_2$ の側から $m_2$ のための行を一本選び，その二本が結合典型になる組み合わせを探して，見つかった対を $K$ に通して入力列を作る．二本の符号語をこうして**噛み合わせる**には，行ごとに符号語を何本か余分に用意しておかなければならない．余分に要る本数がちょうど $2^{n I(V_1;V_2)}$ ほどで，それが和レートから引かれる．引き算の正体は，二本の符号語を噛み合わせる手間である．受け手 $1$ は $V_1$ の符号帳だけを，受け手 $2$ は $V_2$ の符号帳だけを読むので，前の二本の枠はそれぞれの読み取りが通る条件になっている．

本書はこの主張を証明しない．噛み合う組が確かに見つかることを言う段（この段は**相互被覆**と呼ばれる）が，第2章・第6章の典型性の道具の外にあるからである．さらに，補助変数の分布と $K$ に全点で正であることを課さずに済ませる段が要る．そこは 14.2 節が五角形について借りた主張と同じ形で，補助変数の側を一様分布のほうへわずかにずらして全点で正にし，三つの情報量が連続的に動くことを確かめて，ずらし幅を $0$ にする極限で戻す．「本書で証明しない」ことと「形式化されていない」ことは別である．本節が借りたこの主張は，本書が証明を載せないだけで，無条件の機械検証済みの定理として形式化されている．

## 内界

::: definition 14.7.2 Marton の内界
$W$ をブロードキャスト通信路（定義 14.5.1）とする．空でない有限アルファベットの対と $p_V$，$K$ のとり方すべてにわたる Marton の四辺形（定義 14.7.1）の合併の閉包を **Marton の内界** と呼び，$\mathcal I_M(W)$ と書く．
:::

補助アルファベットの大きさに上限を置いていないので，合併は無限個の四辺形にわたる．閉包をとる理由は 定義 14.2.1 や 定義 14.5.3 と同じで，比べたい相手がどれも閉集合だからである．閉包は 14.2 節で借りた **平面の閉集合と閉包の基本性質** の意味でとる．

::: formalized
`martonRegionUnion` (`InformationTheory/Shannon/BroadcastChannel/MartonUnion.lean`)
:::

::: formalization-note
宣言は補助アルファベットを $\{1, \dots, k+1\}$ の形のものに固定して $k$ を動かす．空でない有限の補助アルファベットについての四辺形がどれもこの合併に含まれることは，形式化の側に `martonRegion_subset_union`（同じファイル）として置かれている．
:::

::: theorem 14.7.3
$W$ をブロードキャスト通信路（定義 14.5.1）とし，$W(y_1, y_2 \mid x) > 0$ がすべての $x \in \mathcal X$，$y_1 \in \mathcal Y_1$，$y_2 \in \mathcal Y_2$ で成り立つとする．このとき
$$
\mathcal I_M(W) \;\subseteq\; \mathcal C(W)
$$
である．
:::

::: proof
借りた **Marton の内界の達成可能性** より，どの $(p_V, K)$ についても $\mathcal M(p_V,K) \subseteq \mathcal C(W)$ だから，四辺形の合併も $\mathcal C(W)$ に含まれる．$\mathcal C(W)$ は 定義 14.5.3 により達成可能な対全体の閉包であり，14.2 節で借りた **平面の閉集合と閉包の基本性質** の第一より，閉包は閉集合である．同じ第一により，合併の閉包 $\mathcal I_M(W)$ は合併を含む最小の閉集合だから，$\mathcal C(W)$ に含まれる．
:::

::: formalized
`martonRegionUnion_subset_capacity` (`InformationTheory/Shannon/BroadcastChannel/MartonFullSupport.lean`)
:::

道具をもう一つ借りる．**Marton の内界は UV 外界に含まれる**，すなわち内界と外界が直につながるという主張である．使う形は次のとおり．$W$ をブロードキャスト通信路とする（全点で正であることは求めない）．このとき $\mathcal I_M(W) \subseteq \mathcal O_{UV}(W)$ である（$\mathcal O_{UV}(W)$ は 定義 14.6.6 の UV 外界）．当てる対象は 定義 14.7.2 の内界と 定義 14.6.6 の外界だけで，依存するのは本節の終わりの地の文だけである．

筋書きは計算である．四辺形の $(p_V, K)$ から通信路の法を作るには，$U := V_2$，$V := V_1$ と読み替えるだけでよい．$(Y_1, Y_2)$ の条件付き分布が $X$ だけで決まることは，定義 14.7.1 の同時分布の作り方からそのまま出る．四辺形の最初の二本は，外界の最初の二本そのものになる．三本目は，外界の和レートの二本のうち $U$ を先に置いたほうに落ちる．本書はこの主張を証明しない．落とすところで，$V_1$ が $Y_1$ について持つ情報を $V_2$ を条件に置いた形に書き直すチェイン則と，条件を置いたままの形のデータ処理不等式とが一段ずつ要り，後者を本書は用意していないからである（定理 1.8.4 は条件を置かない形である）．借りた主張は，本書が証明を載せないだけで，無条件の機械検証済みの定理として形式化されている．

## 挟み込み

定理 14.7.3 と，14.6 節で借りた **UV 外界は容量領域を含む** を並べると，$W$ が全点で正であるかぎり
$$
\mathcal I_M(W) \;\subseteq\; \mathcal C(W) \;\subseteq\; \mathcal O_{UV}(W)
$$
である．いま借りた **Marton の内界は UV 外界に含まれる** は，この両端を真ん中を経由せずに直につないでいる．真ん中が二つの端のどちらとも一致しない例があるかどうか，すなわち三つが同じ集合かどうかは，**本書も形式化も述べない**．一般のブロードキャスト通信路の容量領域は分かっていない，というのが現在の状況である．分かっていないというのは，領域を与える式がまだ見つかっていないという意味であって，そういう式が存在しえないことが示されているわけではない．

14.6 節の三つのクラスでは，右の二つが一致する（系 14.6.7 と，そこで借りた **能力がより高い通信路の容量領域**）．左がそれに一致するかどうかは，そのクラスの中でも本書は述べない．内界が容量領域を超えないという向きは 定理 14.7.3 が与えるが，逆向き，すなわち容量領域の点がどれも四辺形の合併の閉包に入ることを述べる主張は，本書にも形式化にもない．挟み込みで言えているのは，左と右のあいだに真ん中があるというところまでである．
