# 14.6 通信路のクラスと UV 外界

定理 14.5.7 は劣化を仮定していた．劣化は強い条件である．定義 14.5.4 が求めているのは二つの出力の**同時**分布についての等式で，受け手 $2$ の出力が受け手 $1$ の出力から作り直せることまで言っている．ところが通信の問題として本当に効くのは，二人がそれぞれ自分の出力から何を読めるか，すなわち出力の**周辺**だけである．そこで本節では，周辺だけを見る条件を二つ置き，劣化がそのどちらも含むことを見る．

そのうえで，二人の性能を比べる条件を一切置かない外界を用意する．こちらは補助変数を二つ使う四辺形の合併として書かれ，本節の到達点，すなわち三つのクラスでは容量領域がこの外界にちょうど一致する，という形にまとまる．

## 二つのクラス

::: definition 14.6.1 雑音がより少ない
$W$ をブロードキャスト通信路（定義 14.5.1）とする．受け手 $1$ が受け手 $2$ より **雑音がより少ない**（less noisy）とは，空でない有限アルファベット $\mathcal U$，$\mathcal U$ 上の分布 $p_U$，$\mathcal U$ を入力・$\mathcal X$ を出力とする通信路 $K$（第6章 定義 6.1.1）をどうとっても，同時分布が $p_U(u)\,K(x \mid u)\,W(y_1, y_2 \mid x)$ である四つ組 $(U, X, Y_1, Y_2)$ について
$$
I\big(U; Y_2\big) \;\le\; I\big(U; Y_1\big)
$$
が成り立つことをいう．
:::

補助変数 $U$ を入力の手前に置いて，そこから通信路に流し込む．そういう流し込み方をどう選んでも，$U$ について受け手 $1$ の側に届く情報が受け手 $2$ の側に届く情報を下回らない，というのが条件の中身である．$U$ を動かすので，これは入力分布を一つ動かすより強い要求になっている．いっぽう見ているのは $I(U;Y_1)$ と $I(U;Y_2)$ という周辺どうしの量で，二つの出力の同時分布は現れない．

::: formalized
`IsBCLessNoisy` (`InformationTheory/Shannon/BroadcastChannel/Classes.lean`)
:::

::: definition 14.6.2 能力がより高い
$W$ をブロードキャスト通信路（定義 14.5.1）とし，$W_1$，$W_2$ をその周辺通信路とする．受け手 $1$ が受け手 $2$ より **能力がより高い**（more capable）とは，$\mathcal X$ 上のどの分布 $p$ についても
$$
I\big(p; W_2\big) \;\le\; I\big(p; W_1\big)
$$
が成り立つことをいう（$I(p; \cdot)$ は第6章 定義 6.1.2 の通信路の相互情報量）．
:::

こちらは補助変数を挟まず，入力分布を直に動かすだけである．定義 14.6.1 で $U$ として入力そのものをとった場合にあたり，要求が弱い．名前のとおり，どの入力分布のもとでも受け手 $1$ のほうが多く運べる，という意味である．$p$ について上限をとれば 定義 6.1.4 より $C(W_2) \le C(W_1)$ が従う．逆向き，すなわち容量どうしの比較から 定義 14.6.2 が出るかどうかは本書では扱わない．容量の比較は最大化した値を一つずつ比べるもので，同じ入力分布のもとでの比較にはなっていない．

::: formalized
`IsBCMoreCapable` (`InformationTheory/Shannon/BroadcastChannel/Classes.lean`)
:::

::: theorem 14.6.3
$W$ をブロードキャスト通信路（定義 14.5.1）とする．$W$ が 定義 14.5.4 の意味で物理的に劣化しているなら，受け手 $1$ は受け手 $2$ より 定義 14.6.1 の意味で雑音がより少ない．
:::

::: proof
$\mathcal U$，$p_U$，$K$ をとり，四つ組 $(U, X, Y_1, Y_2)$ を 定義 14.6.1 のとおりとする．劣化の因子を $W_{2\mid1}$ と書く．

$Y_1$ を与えたとき $U$ と $Y_2$ が条件付き独立であることを示す．四つ組の同時分布は，劣化の等式より
$$
p(u, x, y_1, y_2) \;=\; p_U(u)\,K(x \mid u)\, W_1\big(y_1 \mid x\big)\, W_{2\mid1}\big(y_2 \mid y_1\big)
$$
である．$x$ について和をとると $p(u, y_1, y_2) = W_{2\mid1}(y_2 \mid y_1) \sum_x p_U(u) K(x\mid u) W_1(y_1\mid x)$ であり，右辺の和は $p(u, y_1)$ にほかならない．$p(y_1) > 0$ である $y_1$ を固定して両辺を $p(y_1)$ で割ると $p(u, y_2 \mid y_1) = W_{2\mid1}(y_2 \mid y_1)\, p(u \mid y_1)$ である．さらに $u$ について和をとると $p(y_2 \mid y_1) = W_{2\mid1}(y_2 \mid y_1)$ だから
$$
p\big(u, y_2 \,\big|\, y_1\big) \;=\; p\big(u \,\big|\, y_1\big)\, p\big(y_2 \,\big|\, y_1\big)
$$
であり，これが 定義 1.8.3 の条件である．すなわち $Y_2 \to Y_1 \to U$ はマルコフ連鎖をなす（定義 1.8.3 は両端について対称なので，同じことを $U \to Y_1 \to Y_2$ とも書ける）．

定理 1.8.4 をこの連鎖に，その $X$ に $Y_2$，$Z$ に $Y_1$，$Y$ に $U$ と読み替えて当てると $I(Y_2; U) \le I(Y_1; U)$ である．命題 1.3.3 の対称性で向きをそろえれば主張を得る．
:::

::: formalized
`IsBCDegraded.isBCLessNoisy` (`InformationTheory/Shannon/BroadcastChannel/Classes.lean`)
:::

::: theorem 14.6.4
$W$ をブロードキャスト通信路（定義 14.5.1）とする．受け手 $1$ が受け手 $2$ より 定義 14.6.1 の意味で雑音がより少ないなら，定義 14.6.2 の意味で能力がより高い．
:::

::: proof
$\mathcal X$ 上の分布 $p$ をとる．定義 14.6.1 を，$\mathcal U := \mathcal X$，$p_U := p$，$K$ として入力をそのまま通す通信路（$K(x' \mid u) = 1$ が $x' = u$ のとき，それ以外で $0$）にとって当てる．この四つ組では $X = U$ が確率 $1$ で成り立つので，$I(U; Y_j) = I(X; Y_j)$ である（$j = 1, 2$）．いっぽう $(X, Y_j)$ の同時分布は $p(x)\,W_j(y_j \mid x)$ だから，命題 6.1.3 より $I(X; Y_j) = I(p; W_j)$ である．よって 定義 14.6.1 の不等式がそのまま $I(p; W_2) \le I(p; W_1)$ になる．
:::

::: formalized
`IsBCLessNoisy.isBCMoreCapable` (`InformationTheory/Shannon/BroadcastChannel/Classes.lean`)
:::

二つの含意の逆向きが成り立つかどうかは，本書では扱わない．落ちるときに何を捨てているかは見ておける．劣化から雑音がより少ないへ落ちるところでは，同時分布についての条件を周辺どうしの比較に読み替えて，同時分布の情報を捨てている．雑音がより少ないから能力がより高いへ落ちるところでは，動かす対象を補助変数から入力そのものに狭めている．以下では三つの条件を，劣化がいちばん強く能力がより高いがいちばん弱いものとして扱う．次の命題は，真ん中の条件が重ね合わせ符号化にとって何をしてくれるかを述べたものである．

::: proposition 14.6.5
$W$ をブロードキャスト通信路（定義 14.5.1）とし，受け手 $1$ は受け手 $2$ より 定義 14.6.1 の意味で雑音がより少ないとする．空でない有限アルファベット $\mathcal U$，$\mathcal U$ 上の分布 $p_U$，$\mathcal U$ を入力・$\mathcal X$ を出力とする通信路 $K$ をとり，四つ組 $(U, X, Y_1, Y_2)$ を 定義 14.6.1 のとおりとすると
$$
I\big(X; Y_1 \,\big|\, U\big) \;+\; I\big(U; Y_2\big) \;\le\; I\big((U, X); Y_1\big)
$$
である．
:::

::: proof
定理 1.5.1 を，その $Z$ に $U$，$X$ に $X$，$Y$ に $Y_1$ と読み替えて当てると
$$
I\big((U, X); Y_1\big) \;=\; I\big(U; Y_1\big) + I\big(X; Y_1 \,\big|\, U\big)
$$
である．定義 14.6.1 より $I(U; Y_2) \le I(U; Y_1)$ だから，右辺の第 $1$ 項をこれで下から置き換えれば主張を得る．
:::

::: formalized
`bc_lessNoisy_infoJoint_ge` (`InformationTheory/Shannon/BroadcastChannel/Classes.lean`)
:::

::: formalization-note
形式化の三つの情報量は，$I(X; Y_1 \mid U)$，$I(U; Y_2)$，$I((U,X); Y_1)$ をエントロピーの差の形（定理 1.4.3 と 定理 1.3.4 の表現）で書いた `bcInfo₁`，`bcInfo₂`，`bcInfoJoint` (`InformationTheory/Shannon/BroadcastChannel/Achievability/Setup.lean`) である．値は同じでも，宣言としては別の式である．
:::

14.5 節で借りた **重ね合わせ符号化の達成可能性** は，二つの枠 $R_1 \le I(X;Y_1\mid U)$ と $R_2 \le I(U;Y_2)$ だけを課していた．二段の符号帳を素直に勘定すると，本当はもう一本，和レートについての枠 $R_1 + R_2 \le I((U,X);Y_1)$ が要る．受け手 $1$ は雲と衛星の両方を読むので，その二つを合わせた量を超えては読めないからである．命題 14.6.5 が言っているのは，雑音がより少ないかぎりこの三本目が最初の二本から自動的に従う，ということである．劣化を仮定した 14.5 節でこの枠が出てこなかったのは，定理 14.6.3 によりそこが雑音のより少ない場合に含まれていたからである．

## UV 外界

二人の性能を比べる条件を置かないまま外側から抑えたい．定理 14.5.7 の $U_i$ は受け手 $2$ のメッセージと過去の出力を束ねたものだったが，二人に優劣がないなら受け手 $1$ の側にも同じ役の補助変数を用意しなければならない．そこで補助変数を二つ使う．

::: definition 14.6.6 通信路の法と UV 外界
$W$ をブロードキャスト通信路（定義 14.5.1）とする．可算集合 $\mathcal U$，$\mathcal V$ に値をとる変数の対 $(U, V)$ を加えた五つ組 $(U, V, X, Y_1, Y_2)$ の同時分布 $\nu$ が $W$ の **通信路の法** であるとは，$(U, V, X)$ を与えたときの $(Y_1, Y_2)$ の条件付き分布が $X$ だけで決まって $W(\cdot, \cdot \mid X)$ に等しいことをいう．通信路の法 $\nu$ に対し，四つの不等式
$$
R_1 \le I\big(V; Y_1\big), \quad R_2 \le I\big(U; Y_2\big), \quad
R_1 + R_2 \le I\big(U; Y_2\big) + I\big(X; Y_1 \,\big|\, U\big), \quad
R_1 + R_2 \le I\big(V; Y_1\big) + I\big(X; Y_2 \,\big|\, V\big)
$$
をすべて満たす実数の対 $(R_1, R_2)$ の集合を $\mathcal{UV}(\nu)$ と書く．通信路の法すべてにわたる $\mathcal{UV}(\nu)$ の合併の閉包を $W$ の **UV 外界** と呼び，$\mathcal O_{UV}(W)$ と書く．
:::

条件が二つの補助変数について対称でないことに注意する．$U$ は受け手 $2$ の側の，$V$ は受け手 $1$ の側の粗い層で，最初の二本は 14.5 節の二つの枠をそれぞれの受け手について書いたものである．和レートの枠が二本あるのは，どちらの受け手を先に読むかで別の抑えが出るからで，二本とも課す．通信路の法という条件は落とせない．四つの情報量は五つ組の同時分布だけで決まって $W$ を名指していないので，条件を外すと入力を出力にそのまま写す法が入り込み，合併が平面全体になってしまう．

::: formalized
四辺形 `uvRegion`，合併の閉包 `bcOuterRegionUV` (`InformationTheory/Shannon/BroadcastChannel/OuterBoundUV/Region.lean`)
:::

::: formalization-note
通信路の法にあたる述語は `IsUVChannelLaw`（同じファイル）で，条件付き分布についての言い方ではなく，五つ組の法を $(U,V,X)$ の周辺と通信路との合成に等しいと書いた一本の等式として置かれている．また宣言は二つの補助アルファベットをどちらも自然数全体に固定している．可算集合はどれも自然数全体の部分集合と対応がつくので，これで可算な補助変数すべてを動かしたことになる．
:::

道具を二つ借りる．どちらも 定義 14.5.3 の容量領域と 定義 14.6.6 の UV 外界を結ぶもので，向きが違う．

一つめは **UV 外界は容量領域を含む**，すなわち「達成できるレート対は四つの不等式を満たす法をもつ」という主張である．使う形は次のとおり．$W$ をブロードキャスト通信路とする（二人の性能を比べる条件も，全点で正であることも求めない）．このとき $\mathcal C(W) \subseteq \mathcal O_{UV}(W)$ である．当てる対象は 定義 14.5.3 の容量領域と 定義 14.6.6 の UV 外界だけで，依存するのは 14.7 節の終わりの地の文（挟み込み）だけである．

筋書きは 定理 14.5.7 の骨格を二つの補助変数に広げたものである．長さ $n$ の符号を一つとり，時刻 $i$ ごとに $U_i := (\mathrm{Msg}_2, Y_2^{<i})$，$V_i := (\mathrm{Msg}_1, Y_1^{<i})$ とおく．受け手ごとの二本の枠は，定理 14.5.7 の受け手 $2$ の側の議論を，受け手 $1$ についても同じ形で行えば出る．和レートの二本は，二人ぶんのメッセージをまとめて抑えてから時刻ごとにほどくときに，どちらの補助変数を先に置くかで二通り出る．最後に時刻を一様に選ぶ変数を束ねて一文字あたりの形に直し，誤り確率を $0$ に送る．本書はこの主張を証明しない．劣化を使えないので 補題 14.5.6 (iii) にあたる評価が立たず，かわりに二つの和レートの枠を突き合わせる勘定が要る．借りた主張は，本書が証明を載せないだけで，無条件の機械検証済みの定理として形式化されている．

::: formalized
`bc_capacity_subset_uv` (`InformationTheory/Shannon/BroadcastChannel/OuterBoundUV/Assembly.lean`)
:::

二つめは **能力がより高い通信路の容量領域**，すなわち「能力がより高いなら外界がそのまま答えになる」という主張である．使う形は次のとおり．$W$ をブロードキャスト通信路とし，$W$ が全点で正，すなわち $W(y_1, y_2 \mid x) > 0$ がすべての $x$，$y_1$，$y_2$ で成り立つとする．受け手 $1$ が受け手 $2$ より 定義 14.6.2 の意味で能力がより高いなら
$$
\mathcal C(W) \;=\; \mathcal O_{UV}(W)
$$
である．当てる対象は 定義 14.5.3 の容量領域と 定義 14.6.6 の UV 外界だけで，依存するのは 系 14.6.7 の証明と，14.7 節の終わりの地の文（挟み込み）の二箇所である．

筋書きはこうである．$\subseteq$ は一つめの借用そのものである．$\supseteq$ を出すには，UV 外界の点が重ね合わせ符号化で届くことを言えばよい．14.5 節で借りた **重ね合わせ符号化の達成可能性** が与えるのは補助変数を一つ使う長方形だから，四辺形の点をその長方形に押し込む段が要る．能力がより高いことは，和レートの二本目の枠を一本目に落とし，二つの補助変数のうち片方を消すところで効く．消したあとに残る和レートの枠は 命題 14.6.5 と同じ形のもので，それが受け手ごとの二本の枠から従うので，長方形のまま扱える．本書はこの主張を証明しない．補助変数を消す段が，補助アルファベットの大きさを抑える議論と極限の取り替えの両方を要するからである．借りた主張も，本書が証明を載せないだけで，無条件の機械検証済みの定理として形式化されている．

::: corollary 14.6.7
$W$ をブロードキャスト通信路（定義 14.5.1）とし，$W(y_1, y_2 \mid x) > 0$ がすべての $x \in \mathcal X$，$y_1 \in \mathcal Y_1$，$y_2 \in \mathcal Y_2$ で成り立つとする．受け手 $1$ が受け手 $2$ より 定義 14.6.1 の意味で雑音がより少ないか，または $W$ が 定義 14.5.4 の意味で物理的に劣化しているなら
$$
\mathcal C(W) \;=\; \mathcal O_{UV}(W)
$$
である．
:::

::: proof
雑音がより少ない場合は，定理 14.6.4 より能力がより高いので，借りた **能力がより高い通信路の容量領域** がそのまま当たる．物理的に劣化している場合は，定理 14.6.3 より雑音がより少なく，いま示した場合に帰着する．
:::

::: formalized
雑音がより少ない場合 `bc_lessNoisy_capacity_eq_uv` (`InformationTheory/Shannon/BroadcastChannel/Superposition/Assembly.lean`)，劣化している場合 `bc_degraded_capacity_eq_uv` (`InformationTheory/Shannon/BroadcastChannel/Superposition/MoreCapable.lean`)
:::

系 14.6.7 と借用を合わせると，三つのクラスで容量領域が決まったことになる．劣化・雑音がより少ない・能力がより高いの三つはこの順に弱くなるので，実際に内容があるのはいちばん弱い三つめで，前の二つはそこへの帰着である．どのクラスでも答えが同じ $\mathcal O_{UV}(W)$ になる，つまり二人の受け手に優劣があるかぎり，優劣の付き方によらず同じ形の式が容量領域を与える．

## 協力外界

外界をもう一つ作る．こちらは補助変数を使わず，第6章の一人用の逆定理だけから出る．道具立てが軽いぶん抑えも粗いが，本書が自前で証明できる唯一の外界である．土台になる評価を先に切り出しておく．

::: lemma 14.6.8
$V$ を通信路（第6章 定義 6.1.1），$R$ を実数とする．任意の $\zeta > 0$ に対してある $N \ge 1$ があって，$N \le n$ を満たすすべての $n$ について，長さ $n$ のブロック通信路符号（定義 6.2.1）で $\frac1n\log M \ge R$ かつ平均誤り確率が $\zeta$ 未満のものが存在するとする．このとき $R \le C(V)$（定義 6.1.4）である．
:::

::: proof
$R \le 0$ のときは 命題 6.1.6 より $0 \le C(V)$ だから主張が成り立つ．以下 $R > 0$ とする．

$\zeta \in (0,1)$ を一つとり，仮定の与える $N$ をとる．$N \le n$ を満たす $n$ を一つ固定し，そこで得られる符号を $(M_n, c_n, d_n)$ と書く．メッセージが $\{1,\dots,M_n\}$ 上の一様分布に従うとして議論する．これは符号に置く追加の仮定ではなく，評価のためにこちらが入れる分布である．このとき $P_n := \Pr[d_n(Y^n) \ne \mathrm{Msg}]$ は平均誤り確率に等しく，$P_n < \zeta$ である．$\frac1n\log M_n \ge R > 0$ より $M_n \ge 2$ でもある．

定理 6.4.5 の仮定を確かめる．符号語 $X^n = c_n(\mathrm{Msg})$ を通信路に通すのだから，$X^n$ を与えたときの $Y^n$ の条件付き分布は $\prod_i V(y_i \mid x_i)$ であって $\mathrm{Msg}$ にはよらない．$\mathrm{Msg}$ によらないことが 定義 1.8.3 の条件付き独立そのものだから $\mathrm{Msg} \to X^n \to Y^n$ はマルコフ連鎖であり，積の形から 補題 6.4.6 より $X^n$ と $Y^n$ は各時刻で記憶がなく（定義 6.4.4），$X_i$ の分布を $p_i$ と書けば対 $(X_i, Y_i)$ の同時分布は $p_i(x)V(y\mid x)$ である．よって 定理 6.4.5 より
$$
\log M_n \;\le\; \sum_{i=0}^{n-1} I\big(X_i; Y_i\big) + H_b\big(P_n\big) + P_n \log\big(M_n - 1\big)
$$
である．命題 6.1.3 より $I(X_i; Y_i) = I(p_i; V)$ であり，定義 6.1.4 の上限より $I(p_i; V) \le C(V)$ だから，和は $n\,C(V)$ 以下である．例 1.1.2 より $H_b(P_n) \le \log 2 = 1$ であり，$M_n \ge 2$ より $0 \le \log(M_n - 1) \le \log M_n$ だから，$P_n < \zeta$ と合わせて $P_n\log(M_n-1) \le \zeta \log M_n$ である．三つを入れて移項すると
$$
\big(1 - \zeta\big)\log M_n \;\le\; n\,C(V) + 1
$$
であり，$n$ で割り $\frac1n\log M_n \ge R$ と $1 - \zeta > 0$ を使うと $(1-\zeta)R \le C(V) + \frac1n$ である．

これが $N \le n$ を満たすすべての $n$ で成り立つので，$n \to \infty$ として $(1-\zeta)R \le C(V)$ を得る．$\zeta$ は $(0,1)$ の任意の数だったから，$\zeta \to 0$ として $R \le C(V)$ を得る．
:::

::: formalization-note
補題 14.6.8 に対応する宣言として `channelCoding_operational_rate_le_capacity` (`InformationTheory/Shannon/ChannelCoding/StrongConverseAsymptotic.lean`) があるが，ポインタは付けない．形式化はこの不等式を強逆定理（第6章 定理 6.6.11）の対偶として出しており，そのため容量を達成する入力分布の存在と，その入力分布が生む出力分布が全点で正であることとを仮定に持つ．本文の証明は第6章 定理 6.4.5 の弱い逆定理だけを使うので，これらを仮定に置かない．宣言のほうが強い仮定をもつ形になる．
:::

::: proposition 14.6.9 協力外界
$W$ をブロードキャスト通信路（定義 14.5.1），$W_1$，$W_2$ をその周辺通信路とし，$\mathcal Y_1 \times \mathcal Y_2$ を一つの出力アルファベットとみなした $W$ を，第6章 定義 6.1.1 の意味の通信路として読む．$C$ を 定義 6.1.4 の通信路容量とし，
$$
\mathcal O_{\mathrm{coop}}(W) \;:=\; \Big\{ (R_1, R_2) \in \mathbb R^2 \;:\;
  R_1 \le C\big(W_1\big),\ \ R_2 \le C\big(W_2\big),\ \ R_1 + R_2 \le C\big(W\big) \Big\}
$$
とおく．このとき $\mathcal C(W) \subseteq \mathcal O_{\mathrm{coop}}(W)$ である（$\mathcal C(W)$ は 定義 14.5.3 の容量領域）．
:::

::: proof
まず，達成可能な対（定義 14.5.3）が三つの不等式を満たすことを示す．三つとも 補題 14.6.8 に帰着させる．そのために，ブロードキャスト符号から一人用のブロック通信路符号を三通りに作る．

**受け手 $1$ の取り分.** $\zeta > 0$ をとり，定義 14.5.3 の与える $N$ をとる．$N \le n$ を満たす $n$ を固定し，そこで得られる符号を $(M_1, M_2, c, d_1, d_2)$ と書く．$m_2$ を一つ固定するごとに，符号化写像 $m_1 \mapsto c(m_1, m_2)$ と復号器 $d_1$ の組は，$W_1$ についての長さ $n$ のブロック通信路符号（定義 6.2.1）である．定義 14.5.1 の積の形で $y_2^n$ について和をとると，$x^n$ を与えたときの $Y_1^n$ の条件付き分布が $\prod_i W_1(\cdot \mid x_i)$ になるからである．この符号の平均誤り確率は $\frac{1}{M_1}\sum_{m_1} P_{e,1}(m_1, m_2)$ であり，これを $m_2$ について一様に平均したものが 定義 14.5.2 の $\bar P_{e,1}$ にほかならない．平均以下の値をとる項が少なくとも一つあるので，$\frac{1}{M_1}\sum_{m_1} P_{e,1}(m_1, m_2) \le \bar P_{e,1} < \zeta$ を満たす $m_2$ がとれる．メッセージ数は $M_1$ でレートは $\frac1n\log M_1 \ge R_1$ だから，$\zeta$ と $N$ の対応はそのまま 補題 14.6.8 の仮定になり，$R_1 \le C(W_1)$ を得る．

**受け手 $2$ の取り分.** 添字の $1$ と $2$ を入れ替えれば同じ論法である．

**二人の合計.** $\zeta > 0$ をとり，定義 14.5.3 を目標の誤り確率 $\zeta/2$ に対して使って $N$ をとる．$N \le n$ を満たす $n$ を固定し，符号を $(M_1, M_2, c, d_1, d_2)$ とする．メッセージの対 $(m_1, m_2)$ を一つのメッセージとみなし，復号器を $(y_1^n, y_2^n) \mapsto (d_1(y_1^n), d_2(y_2^n))$ とすると，この組は $\mathcal Y_1\times\mathcal Y_2$ を出力とする $W$ についての長さ $n$ のブロック通信路符号であり，メッセージ数は $M_1 M_2$ である．対として当てそこなうのは少なくとも一方を当てそこなうときだから，$(m_1, m_2)$ での誤り確率は $P_{e,1}(m_1,m_2) + P_{e,2}(m_1,m_2)$ 以下である．メッセージの対について平均すると，平均誤り確率は $\bar P_{e,1} + \bar P_{e,2} < \zeta$ である．レートは $\frac1n\log(M_1M_2) = \frac1n\log M_1 + \frac1n\log M_2 \ge R_1 + R_2$ だから，補題 14.6.8 より $R_1 + R_2 \le C(W)$ を得る．

**閉包に移す.** $\mathcal O_{\mathrm{coop}}(W)$ は三つの半平面の共通部分である．半平面はどれも閉集合である．そこに属する対からなる収束列をとると，各不等式の両辺が極限に移って同じ不等式が成り立つので，14.2 節で借りた **平面の閉集合と閉包の基本性質** の第二により閉である．同じ基本性質の第一により，三つの共通部分も閉である．いま示したことから，達成可能な対全体は $\mathcal O_{\mathrm{coop}}(W)$ に含まれる．閉包はその集合を含む最小の閉集合だから（14.2 節の借用の第一），$\mathcal C(W) \subseteq \mathcal O_{\mathrm{coop}}(W)$ である．
:::

::: formalization-note
命題 14.6.9 と同じ包含を述べる宣言 `bc_capacity_subset_coop` (`InformationTheory/Shannon/BroadcastChannel/OuterBound.lean`) があるが，ポインタは付けない．あちらは三つの通信路それぞれについて，容量を達成する入力分布と，その入力分布が生む出力分布が全点で正であることとを仮定に持つ．補題 14.6.8 に付した注記と同じ理由で，宣言のほうが強い仮定をもつ形になる．抑えている集合そのものは `bcOuterRegionCoop`（同じファイル）として置かれている．
:::

同じ $W$ について $\mathcal C(W)$ と $C(W)$ の二つが現れるが，前者は 定義 14.5.3 の容量領域という平面の部分集合，後者は 定義 6.1.4 の通信路容量という実数で，別の記号である．14.2 節 例 14.2.6 も同じ書き分けをしている．

三本目の読み方を確かめておく．$\mathcal Y_1 \times \mathcal Y_2$ を一つの出力とみなすのは，二人の受け手が出力を持ち寄って協力し，二人ぶんのメッセージを一緒に言い当てる，という設定に相当する．協力してよいのだから，できることは増えるだけである．したがって協力した場合の限界 $C(W)$ は，協力しない場合の和レートの限界でもある．名前はこの読み方から来ている．

本章はこれで，容量領域を二つの外界で抑えたことになる．借用の与えた $\mathcal O_{UV}(W)$ と，命題 14.6.9 の与える $\mathcal O_{\mathrm{coop}}(W)$ である．**本書はこの二つの大小を比べない**．どちらも容量領域を含むことしか示しておらず，一方が他方に含まれることを述べる主張は本書にも形式化にもないからである．系 14.6.7 の三つのクラスでは前者が容量領域そのものなので，そこでは前者のほうが後者に含まれる．クラスの外でどうなるかは本書の範囲にない．
