# 14.2 多元接続通信路の容量領域

14.1 節は入力分布の対を一つ固定して，そこから五角形を作った．達成可能なレート対を集めた集合は，この五角形より広い．入力分布の対を取り替えれば別の五角形が出るからというだけではない．二つの符号を時間で分けて使えば，二つの五角形から一点ずつとった対の中間にも，いくらでも近いところまで届いてしまう．

本節は，この広がりを二つの操作で言い当てる．一つは時間で分ける操作で，レート対の凸結合を作る．もう一つは極限をとる操作で，境界に届く対を拾う．$W$ が全点で正のとき，容量領域と第一象限の共通部分は，ちょうど五角形の合併の閉凸包になる．

**平面の閉集合と閉包の基本性質を借りる.** $\mathbb R^2$ の部分集合についての次の三つを既知とする．第一に，閉集合の族の共通部分はふたたび閉集合である．したがって $S \subseteq \mathbb R^2$ に対し，$S$ を含む閉集合すべての共通部分は $S$ を含む最小の閉集合になる．これを $S$ の **閉包** と呼び $\overline S$ と書く．第二に，$K \subseteq \mathbb R^2$ が閉集合であることと，$K$ の点からなる収束列の極限がつねに $K$ に属することとは，同じことである．第三に，$\overline S$ の点はどれも $S$ の点からなる収束列の極限として書ける．当てる相手は，達成可能なレート対（定義 14.1.3）の集合と，五角形（定義 14.1.5）の合併という，どちらも $\mathbb R^2$ の部分集合である．これに依存するのは，本節の 定義 14.2.1 と 定義 14.2.2，および 命題 14.2.3・定理 14.2.4・定理 14.2.5 の証明と，14.6 節 命題 14.6.9 の証明，14.7 節 定理 14.7.3 の証明である．あとの二つが引くのは第一と第二で，閉包が閉集合でありかつ最小の閉集合であること（第一）と，半平面が閉集合であること（第二）に当たる．以降の節が容量領域や内界・外界を閉包で定めるところも，この宣言の意味で閉包を使う．

## 容量領域と閉凸包

::: definition 14.2.1 容量領域
$W$ を多元接続通信路（定義 14.1.1）とする．達成可能なレート対（定義 14.1.3）全体の集合を $\mathcal A(W)$ と書き，その閉包
$$
\mathcal C(W) \;:=\; \overline{\mathcal A(W)}
$$
を $W$ の **容量領域** と呼ぶ．
:::

$\mathcal A(W)$ そのものではなく閉包を容量領域と呼ぶのは，達成可能性が与えるのがつねに「不等式が真に成り立つ側」だからである．14.1 節で借りた形がまさにそれで，五角形の境界の上の対については何も言っていない．境界の対が一つずつ達成可能かどうかを問うかわりに，極限で届く対まで含めて領域と呼ぶ．第6章も同じところで手当てをしていて，達成レートの集合 $\mathcal R(W)$（定義 6.2.2）そのものではなく，その**上限**が容量に一致することを主定理にしていた（定理 6.4.9）．答えが 1 つの数から対の集合に変わったぶん，上限をとる操作のかわりに閉包をとる操作が出てくる．

::: formalized
`macCapacityRegion` (`InformationTheory/Shannon/MultipleAccess/TimeSharing.lean`)
:::

::: definition 14.2.2 閉凸包
$S \subseteq \mathbb R^2$ に対し，$S$ を含む閉凸集合すべての共通部分を $S$ の **閉凸包** と呼び，$\overline{\mathrm{conv}}\,S$ と書く．
:::

$\mathbb R^2$ 自身が $S$ を含む閉凸集合なので，共通部分をとる先の族は空でない．借りた **平面の閉集合と閉包の基本性質** の第一が閉包に与えた作り方と同じで，集める集合に凸という条件を足しただけである．

## 時分割

記号を一つ引いておく．実数 $t$ に対する床関数 $\lfloor t \rfloor$，すなわち $t$ 以下の最大の整数と，その性質 $\lfloor t \rfloor \le t < \lfloor t \rfloor + 1$ は，第12章 12.5 節で既知としたとおりに本節でも使う．

::: proposition 14.2.3
$W$ を多元接続通信路（定義 14.1.1）とする．その容量領域 $\mathcal C(W)$（定義 14.2.1）は閉集合であり，かつ凸集合である．
:::

::: proof
閉であることは定義から出る．$\mathcal C(W)$ は $\mathcal A(W)$ の閉包であり，平面の閉集合と閉包の基本性質の第一により閉包は閉集合である．

凸であることを二段に分けて示す．第一段では，達成可能な二つの対の凸結合に真に下から近い対が達成可能であることを見る．すなわち，$(a_1, a_2)$ と $(b_1, b_2)$ が達成可能で，$\lambda \in [0,1]$ と実数の対 $(R_1, R_2)$ が $R_j < \lambda a_j + (1-\lambda) b_j$（$j = 1, 2$）を満たすなら，$(R_1, R_2)$ は達成可能である．

はじめに，達成可能性が成分について単調であることに注意する．$(a_1, a_2)$ が達成可能で $R_j \le a_j$ なら，定義 14.1.3 が与える符号がそのまま $(R_1, R_2)$ についての条件を満たす．これで $\lambda = 1$ と $\lambda = 0$ の場合は済むので，以下 $0 < \lambda < 1$ とする．

$\zeta > 0$ をとる．達成可能性を目標の誤り確率 $\zeta/2$ に対して二つの対それぞれに使い，$(a_1, a_2)$ の側で得られる長さの下限を $N_a$，$(b_1, b_2)$ の側のものを $N_b$ とする．長さ $n$ に対し $k := \lfloor \lambda n \rfloor$ とおく．床関数の性質より $\lambda n - 1 < k \le \lambda n$ であり，$0 < \lambda < 1$ だから $k \to \infty$ かつ $n - k \ge (1-\lambda) n \to \infty$ である．よって，ある $N_0$ から先のすべての $n$ で $N_a \le k$ と $N_b \le n - k$ がともに成り立ち，しかも $k$ と $n-k$ はどちらも $1$ 以上である．

そのような $n$ を一つとる．長さ $k$ の多元接続符号で $\frac1k \log M^a_j \ge a_j$（$j = 1,2$）と平均誤り確率 $\zeta/2$ 未満を満たすものと，長さ $n-k$ の多元接続符号で $\frac{1}{n-k} \log M^b_j \ge b_j$ と平均誤り確率 $\zeta/2$ 未満を満たすものをとる．この二つを時間でつないで，長さ $n$ の符号を作る．利用者 $j$ のメッセージを対 $(u, v) \in \{1, \dots, M^a_j\} \times \{1, \dots, M^b_j\}$ で番号づけ，その符号語を，前半の符号語のうしろに後半の符号語をつないだものとする．復号器は，受け取った $y^n$ の前半 $k$ 文字を前半の符号の復号器に，後半 $n-k$ 文字を後半の符号の復号器に渡し，返ってきた二つの対から利用者ごとに番号を組み立てる．

つないだ符号のメッセージ数は $M_j = M^a_j M^b_j$ だから
$$
\frac1n \log M_j \;=\; \frac kn \cdot \frac1k \log M^a_j
  \;+\; \frac{n-k}{n} \cdot \frac{1}{n-k} \log M^b_j
  \;\ge\; \frac kn\, a_j + \frac{n-k}{n}\, b_j
$$
である．誤り確率のほうは，定義 14.1.1 の積の形により，前半 $k$ 文字の出力の分布が前半の入力だけで決まる長さ $k$ のものになり，後半についても同様で，しかも二つは独立である．つないだ符号が誤るのは前半か後半の少なくとも一方で誤るときだから，どのメッセージの対についても誤り確率は二つの符号の対応する誤り確率の和以下である．メッセージの対について平均すると，前半の平均誤り確率と後半の平均誤り確率の和で抑えられるので，$\bar P_e < \zeta/2 + \zeta/2 = \zeta$ である．

最後に $n$ を大きくする．$k/n \to \lambda$ かつ $(n-k)/n \to 1-\lambda$ だから，上の右辺は $\lambda a_j + (1-\lambda) b_j$ に収束する．$R_j$ はこの値より真に小さいので，$N_0$ を大きくとり直せば，$N_0 \le n$ を満たすすべての $n$ で $\frac1n \log M_j \ge R_j$ が $j = 1, 2$ の両方について成り立つ．$\zeta$ に対する $N$ としてこの $N_0$ がとれたから，$(R_1, R_2)$ は達成可能である．

第二段で凸性を出す．$x$，$y$ を $\mathcal C(W)$ の点，$\lambda \in [0,1]$ とし，$z := \lambda x + (1-\lambda) y$ とおく．平面の閉集合と閉包の基本性質の第三により，$\mathcal A(W)$ の点からなる列 $a^{(k)}$，$b^{(k)}$ で $a^{(k)} \to x$，$b^{(k)} \to y$ となるものがとれる．$k \ge 1$ に対し
$$
z^{(k)} \;:=\; \lambda a^{(k)} + (1-\lambda) b^{(k)} - \Big(\frac1k, \frac1k\Big)
$$
とおくと，成分ごとに $z^{(k)}_j < \lambda a^{(k)}_j + (1-\lambda) b^{(k)}_j$ だから，第一段より $z^{(k)}$ は達成可能である．いっぽう $z^{(k)} \to \lambda x + (1-\lambda) y = z$ である．$\mathcal A(W) \subseteq \mathcal C(W)$ であり $\mathcal C(W)$ は閉集合だから，平面の閉集合と閉包の基本性質の第二により極限 $z$ も $\mathcal C(W)$ に属する．
:::

::: formalized
閉であること `mac_capacityRegion_isClosed`，凸であること `mac_capacityRegion_convex` (`InformationTheory/Shannon/MultipleAccess/TimeSharing.lean`)
:::

第一段が時分割である．$n$ 回の使用のうち先頭の $\lambda$ 割を一つ目の符号に，残りを二つ目の符号に割り当てた．2 人が同じ割り当てを知っていることは要る（そうでなければ後半の符号語を前半に送ってしまう）が，互いのメッセージを知る必要はないので，定義 14.1.2 の枠の中に収まっている．レートが凸結合になるのは，メッセージ数が掛け算で増え，対数が足し算に変わるからである．誤りのほうは足し算のまま増えるので，目標を半分ずつに割っておけば間に合う．

## 五角形の合併から容量領域へ

道具をもう一つ借りる．**五角形の包含**，すなわち「どの入力の対がつくる五角形も容量領域に含まれる」という主張である．使う形は次のとおり．

$W$ を多元接続通信路とし，$W$ が全点で正，すなわち $W(y \mid x_1, x_2) > 0$ がすべての $x_1 \in \mathcal X_1$，$x_2 \in \mathcal X_2$，$y \in \mathcal Y$ で成り立つとする．このとき，$\mathcal X_1$ 上の分布 $p_1$ と $\mathcal X_2$ 上の分布 $p_2$ のどの対についても $\mathcal P(p_1, p_2) \subseteq \mathcal C(W)$ である．

当てる対象は 定義 14.1.5 の五角形と 定義 14.2.1 の容量領域だけで，依存するのは 定理 14.2.4 の証明だけである．

筋書きだけ書いておく．五角形の内側で両方のレートが正である対は，14.1 節で借りた**多元接続通信路の達成可能性**がそのまま与える．残るのは二つで，一つは五角形の境界と軸の上の対，もう一つは入力分布が全点で正でない場合である．前者は容量領域が閉包であることから拾える．後者は，入力分布を一様分布のほうへわずかにずらして全点で正にし，ずらし幅を $0$ に近づける極限で戻す．このとき三つの枠が連続的に動くことを確かめる必要がある．本書はこの二つを扱わない．借りた主張は，本書が証明を載せないだけで，無条件の機械検証済みの定理として形式化されている．

::: theorem 14.2.4
$W$ を多元接続通信路（定義 14.1.1）とし，$W(y \mid x_1, x_2) > 0$ がすべての $x_1 \in \mathcal X_1$，$x_2 \in \mathcal X_2$，$y \in \mathcal Y$ で成り立つとする．このとき
$$
\overline{\mathrm{conv}}\Big( \bigcup_{p_1, p_2} \mathcal P(p_1, p_2) \Big)
  \;\subseteq\; \mathcal C(W)
$$
である．ここで合併は，$\mathcal X_1$ 上の分布 $p_1$ と $\mathcal X_2$ 上の分布 $p_2$ の対すべてにわたる．

::: proof
借りた五角形の包含より，どの対 $(p_1, p_2)$ についても $\mathcal P(p_1, p_2) \subseteq \mathcal C(W)$ だから，合併も $\mathcal C(W)$ に含まれる．命題 14.2.3 より $\mathcal C(W)$ は閉集合であり凸集合である．したがって $\mathcal C(W)$ は，定義 14.2.2 で共通部分をとる先の族，すなわち合併を含む閉凸集合の族に属する．共通部分はその族のどの元にも含まれるから，左辺は $\mathcal C(W)$ に含まれる．
:::

左辺を合併ではなく閉凸包にしてあるのは，時分割で届く対が合併の中に収まらないからである．二つの入力の対 $(p_1, p_2)$ と $(p_1', p_2')$ をとり，それぞれの五角形から一点ずつ選ぶと，命題 14.2.3 の第一段は二点を結ぶ線分の上の対に成分ごとにいくらでも近い対を達成させるが，その線分がどちらかの五角形に入っているとは限らない．閉凸包はこの線分をはじめから含んでいる．この証明で 命題 14.2.3 が効いたのはそこで，時分割の議論がここではじめて働いた．

## 容量領域の特徴づけ

逆向き，すなわち容量領域が閉凸包より広くならないことを見る．ここでも道具を借りる．**多元接続通信路の逆定理**，すなわち「達成可能で第一象限にあるレート対は，五角形の合併の閉凸包に属する」という主張である．使う形は次のとおり．

$W$ を多元接続通信路とする（全点で正であることは求めない）．実数の対 $(R_1, R_2)$ が 定義 14.1.3 の意味で達成可能で，$R_1 \ge 0$ かつ $R_2 \ge 0$ なら，
$$
(R_1, R_2) \;\in\; \overline{\mathrm{conv}}\Big( \bigcup_{p_1, p_2} \mathcal P(p_1, p_2) \Big)
$$
である．合併は 定理 14.2.4 と同じく分布の対すべてにわたる．

当てる対象は 定義 14.1.3 の達成可能性と 定義 14.1.5 の五角形だけで，依存するのは 定理 14.2.5 の証明だけである．

筋書きはこうである．長さ $n$ の符号を一つとり，メッセージの対が一様に選ばれるとして，ファノの不等式（定理 1.10.1）を三通りに当てる．利用者 1 のメッセージを利用者 2 のメッセージと出力から推定する形，利用者 2 について同じ形，そして対をまとめて推定する形の三つで，$\log M_1$，$\log M_2$，$\log M_1 + \log M_2$ の上界がそれぞれ出る．第6章 定理 6.4.5 と同じように通信路の記憶のなさで時刻ごとにほどくと，右辺は時刻ごとの入力分布が定める五角形の枠の，時刻についての平均になる．平均は凸結合だから，得られた対は五角形の合併の凸包に入る．最後に誤り確率を $0$ に送るとファノの項が消えて，閉包の側に落ちる．

本書はこの主張を証明しない．時刻ごとにほどく段が，第6章のものをそのまま当てるのでは済まないからである．あちらは入力が 1 本だったので条件付き相互情報量の和に分ければ終わったが，こちらは三つの不等式それぞれで条件に置くものが違い，しかも時刻ごとの入力の対が独立であるとは限らないところを扱う必要がある．借りた主張は，本書が証明を載せないだけで，無条件の機械検証済みの定理として形式化されている．

::: theorem 14.2.5 容量領域の特徴づけ
$W$ を多元接続通信路（定義 14.1.1）とし，$W(y \mid x_1, x_2) > 0$ がすべての $x_1 \in \mathcal X_1$，$x_2 \in \mathcal X_2$，$y \in \mathcal Y$ で成り立つとする．$Q := \{(R_1, R_2) \in \mathbb R^2 : R_1 \ge 0,\ R_2 \ge 0\}$ とおくと
$$
\mathcal C(W) \cap Q
  \;=\; \overline{\mathrm{conv}}\Big( \bigcup_{p_1, p_2} \mathcal P(p_1, p_2) \Big)
$$
である．合併は 定理 14.2.4 と同じく，$\mathcal X_1$ 上の分布と $\mathcal X_2$ 上の分布の対すべてにわたる．
:::

::: proof
右辺を $K$ と書く．

$K \subseteq \mathcal C(W) \cap Q$ を示す．$K \subseteq \mathcal C(W)$ は 定理 14.2.4 である．$K \subseteq Q$ を見るには，$Q$ が合併を含む閉凸集合であることを言えばよい（定義 14.2.2 の共通部分はその族のどの元にも含まれる）．五角形はどれも 定義 14.1.5 の最初の二つの不等式により $Q$ に含まれるから，合併も $Q$ に含まれる．$Q$ の点の凸結合は成分がふたたび非負だから $Q$ は凸であり，$Q$ の点からなる収束列の極限も成分が非負だから，平面の閉集合と閉包の基本性質の第二により $Q$ は閉である．

$\mathcal C(W) \cap Q \subseteq K$ を示す．$(R_1, R_2) \in \mathcal C(W) \cap Q$ をとる．定義 14.2.1 より $\mathcal C(W)$ は $\mathcal A(W)$ の閉包だから，平面の閉集合と閉包の基本性質の第三により，達成可能な対からなる列 $a^{(k)} \to (R_1, R_2)$ がとれる．各 $k$ について $b^{(k)} := (\max(a^{(k)}_1, 0), \max(a^{(k)}_2, 0))$ とおく．これは三つのことを満たす．第一に $b^{(k)}$ は達成可能である．定義 14.1.3 はメッセージ数に $M_j \ge 1$ を求めているので $\frac1n \log M_j \ge 0$ であり，$a^{(k)}_j$ を $0$ に取り替えても条件は満たされたままだからである．第二に $b^{(k)} \in Q$ である．第三に $b^{(k)} \to (R_1, R_2)$ である．実数 $s$，$t$ について $|\max(s,0) - \max(t,0)| \le |s - t|$ が成り立ち（$s$ と $t$ の大小で場合を分ければ確かめられる），$R_j \ge 0$ より $\max(R_j, 0) = R_j$ だからである．

借りた多元接続通信路の逆定理を各 $b^{(k)}$ に当てると $b^{(k)} \in K$ を得る．$K$ は 定義 14.2.2 により閉集合の共通部分だから，平面の閉集合と閉包の基本性質の第一により閉集合である．よって平面の閉集合と閉包の基本性質の第二により，極限 $(R_1, R_2)$ も $K$ に属する．
:::

定理 14.2.5 が述べているのは，容量領域そのものではなく第一象限との共通部分についてである．定義 14.1.3 の達成可能性は負のレートを禁じていない．$R_1$ と $R_2$ がどちらも $0$ 以下なら，メッセージ数が $1$ ずつの符号（符号語は各利用者につき 1 本，復号器はつねに唯一の対を返すので誤り確率は $0$）が条件を満たすので，そのような対はすべて達成可能である．つまり $\mathcal C(W)$ は $Q$ からはみ出している．負のレートは符号の取り分としては読めないので，第一象限で切ってから特徴づけを述べている．

::: example 14.2.6 片方を黙らせる
$W$ を多元接続通信路とし，$W(y \mid x_1, x_2) > 0$ がすべての $x_1$，$x_2$，$y$ で成り立つとする．$x_2 \in \mathcal X_2$ を一つ固定し，$W_{x_2}(y \mid x_1) := W(y \mid x_1, x_2)$ とおく．これは第6章 定義 6.1.1 の意味の通信路である．$p_2$ を $x_2$ に集中した一点分布にとると，$\mathcal X_1$ 上のどの分布 $p_1$ についても，命題 14.1.4 の三つ組の三つの量は
$$
I(X_1; Y \mid X_2) = I(p_1; W_{x_2}), \qquad I(X_2; Y \mid X_1) = 0, \qquad
I\big((X_1, X_2); Y\big) = I(p_1; W_{x_2})
$$
であり，五角形 $\mathcal P(p_1, p_2)$ は線分 $\{(R_1, 0) : 0 \le R_1 \le I(p_1; W_{x_2})\}$ に潰れる．$p_1$ を動かしてこれらを合わせると線分 $\{(R_1, 0) : 0 \le R_1 \le C(W_{x_2})\}$ になり（$C$ は 定義 6.1.4 の通信路容量），定理 14.2.5 よりこれは $\mathcal C(W)$ に含まれる．
:::

::: proof
$p_2$ が $x_2$ に集中しているので，三つ組の同時分布は $x_2' \ne x_2$ で $0$ であり，$x_2' = x_2$ では $p_1(x_1) W_{x_2}(y \mid x_1)$ である．

まず $I(X_2; Y \mid X_1) = 0$ を見る．$x_1$ を固定すると，条件付き分布のもとで $X_2$ は $x_2$ をとる確率が $1$ だから，$p(x_2', y \mid x_1) = p(x_2' \mid x_1)\, p(y \mid x_1)$ がすべての $(x_2', y)$ で成り立つ（$x_2' \ne x_2$ では両辺とも $0$，$x_2' = x_2$ では $p(x_2 \mid x_1) = 1$ である）．命題 1.4.2 の等号条件より $I(X_2; Y \mid X_1) = 0$ である．

次に $I(X_1; Y \mid X_2)$ を計算する．定義 1.4.1 より，これは $I(X_1; Y \mid X_2 = x_2')$ を $x_2'$ について平均したものであり，重みが $0$ でない項は $x_2' = x_2$ の一つだけである．$X_2 = x_2$ のもとでの $(X_1, Y)$ の条件付き同時分布は $p_1(x_1) W_{x_2}(y \mid x_1)$ だから，命題 6.1.3 よりその相互情報量は $I(p_1; W_{x_2})$ である．

三つめに移る．定理 1.5.1 の三つの変数を，$Z$ に $X_2$，$X$ に $X_1$，$Y$ に $Y$ と読み替えて当てると $I((X_2, X_1); Y) = I(X_2; Y) + I(X_1; Y \mid X_2)$ である．$X_2$ は確率 $1$ で $x_2$ をとるから，上と同じ理由で $p(x_2', y) = p(x_2')\,p(y)$ がすべての $(x_2', y)$ で成り立ち，命題 1.3.2 の等号条件より $I(X_2; Y) = 0$ である．対の成分をどちらの順に並べても情報量は変わらないので，$I((X_1, X_2); Y) = I(X_1; Y \mid X_2)$ である．

五角形の形を見る．三つの枠が $I(p_1; W_{x_2})$，$0$，$I(p_1; W_{x_2})$ だから，定義 14.1.5 の五つの条件は $0 \le R_1 \le I(p_1; W_{x_2})$ と $R_2 = 0$ に同値である（$0 \le R_2 \le 0$ から $R_2 = 0$ が出て，和の条件は第 1 の条件に吸収される）．

最後に $p_1$ を動かす．どの $p_1$ についても $I(p_1; W_{x_2}) \le C(W_{x_2})$ だから，合わせたものは主張の線分に含まれる．逆に，定理 6.1.5 より $I(\cdot\,; W_{x_2})$ を最大にする入力分布 $p^*$ があって $I(p^*; W_{x_2}) = C(W_{x_2})$ だから，$p_1 = p^*$ の線分が主張の線分そのものである．これは 定理 14.2.5 の右辺の合併に含まれ，定義 14.2.2 で共通部分をとる先の集合はどれも合併を含むから閉凸包も合併を含む．よって 定理 14.2.5 より $\mathcal C(W)$ に含まれる．
:::

片方の利用者を黙らせると，残った側から見た通信路は第6章の 1 人用の通信路にほかならない．例 14.2.6 は，その容量が多元接続の容量領域の $R_2 = 0$ の辺として現れることを言っている．第6章の $C(W_{x_2})$ は，こうして領域の一部として読み直せる．黙らせる文字を $x_2$ ごとに取り替えれば別の $C(W_{x_2})$ が出るので，辺の長さは黙らせ方のうちいちばん良いものまで伸びる．

::: formalization-note
例 14.2.6 に対応する単独の宣言はない．片方の入力を一点分布にとった五角形について述べる宣言も，それを第6章の通信路容量と結ぶ宣言も形式化には無く，定理 14.2.5 に紐付けた宣言と，第6章の容量についての宣言を突き合わせて得られる．
:::
