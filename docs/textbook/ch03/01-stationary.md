# 3.1 定常情報源

第2章の情報源は i.i.d. だった——次に何が来るかは、それまでに何が出たかと無関係で、1 文字あたりの不確かさは最初から最後まで $H(X)$ のままである。しかし現実の情報源はそうではない。英文では q のあとにほとんど u しか来ないし、日本語で「情報」と読んだあとに「量」が続く確率は、文章全体での「量」の出現率よりずっと高い。前の文字を知っていると次の文字が当てやすくなる——その効き目を測る道具は第1章にすでにある。条件付けの単調性（定理 1.2.4）が $H(X_1 \mid X_0) \le H(X_1)$ を与えていた。

記憶のある情報源なら「1 文字あたりの不確かさ」は $H(X_0)$ より小さいはずで、第2章の圧縮限界も下がるはずである。だがその「1 文字あたり」を何と定義すればよいのか。$H(X_i)$ は $i$ ごとに違うかもしれず、$H(X_i \mid X_{i-1})$ も$H(X_i \mid X_{i-1}, X_{i-2})$ も候補になる。候補を一つに絞るには、まず情報源の側に「時間が経っても性質が変わらない」という仮定を置かねばならない。それが本節の定常性である。

以下、アルファベット $\mathcal X$ は有限とし、長さ $n$ のブロックを$X^n := (X_0, \dots, X_{n-1})$ と書く（第2章の記法をそのまま引き継ぐ）。本章では$\log$ の底を 2 にとる。第2章と同じく $2^{nH}$ の形の量を扱うので、指数と対数の底をそろえておくと式が読みやすい。

## 定義

::: definition 3.1.1 定常情報源
$\mathcal X$ に値をとる確率変数の列 $X_0, X_1, X_2, \dots$ が **定常** であるとは、任意の $n \ge 1$、任意の $\ell \ge 0$、任意の $x_0, \dots, x_{n-1} \in \mathcal X$ に対して
$$
\Pr\big[X_0 = x_0, \dots, X_{n-1} = x_{n-1}\big]
  \;=\; \Pr\big[X_\ell = x_0, \dots, X_{\ell+n-1} = x_{n-1}\big]
$$
が成り立つことをいう。定常な列を **定常情報源** と呼ぶ。
:::

定義が言っているのは、時計の針をどこに合わせても情報源が同じに見える、ということである。長さ $n$ の窓を系列の上で滑らせても、窓から見える並びの分布は動かない。個々の文字が独立である必要はまったくなく、$X_0$ と $X_1$ がどれだけ強く絡んでいてもよい。禁じているのは絡み方が時刻によって変わることだけである。

この仮定がなければ「1 文字あたり」を語る意味がない。たとえば $X_0$ だけが一様分布で$X_1$ 以降がすべて定数、という列を考えると、$H(X_i)$ は $i = 0$ とそれ以外で違う値をとる。どの $i$ の値を「1 文字あたりの不確かさ」と呼ぶべきかは決められない。定常性は、この問いを「どれでも同じ」にすることで消してしまう仮定である。

::: formalized
`StationaryProcess`、時刻 $i$ の文字 `obs`、ブロック `blockRV` (`InformationTheory/Shannon/Stationary/Basic.lean`)
:::

::: formalization-note
形式化は定義 3.1.1 の等式を直接書き下さず、**測度保存力学系**として与えている。確率空間$(\Omega, \nu)$ の上に、$\nu$ を保つ写像 $T$（シフト）と、$\mathcal X$ に値をとる単一の観測 $X$ を置き、時刻 $i$ の文字を $X_i := X \circ T^i$ と定める。$T$ が $\nu$ を保つことが、そのまま定義 3.1.1 の分布のシフト不変性にあたる。この $\nu$ は $\Omega$ 上の測度で、以下でマルコフ情報源の初期分布に使う $\mu$ とは別のものである。

本文の $\{X_i\}$ が「別々の確率変数の列」に見えるのに対し、こちらでは確率変数はただ一つで、動くのは点のほうだという違いがある。この形をとると 3.4 節の Birkhoff の定理がそのまま使える——あちらは軌道 $\omega, T\omega, T^2\omega, \dots$ に沿った平均を扱う定理だからである。3.4 節のエルゴード性も同じ流儀で、情報源そのものではなく力学系 $(\Omega, T, \nu)$に課される。$\Omega$ を系列の空間、$T$ をシフトにとる標準的な実現では、定義 3.4.1 と一致する。

定義 3.1.1 の等式そのものは、この形から導かれる定理として `shiftedMarginal_eq_of_shift` (`InformationTheory/Probability/TwoSidedExtension/Core.lean`) にある。
:::

::: example 3.1.2 i.i.d. 情報源
第2章の i.i.d. 情報源は定常である。実際、独立性と同分布性より両辺とも$\prod_{i=0}^{n-1} p(x_i)$ に等しい。$\ell$ がどこであっても、掛け合わせる周辺分布は同じ $p$ だからである。
:::

## 記憶のある情報源——マルコフ情報源

定常性は時間による変化を禁じただけで、記憶の有無については何も言っていない。記憶のあるもっとも単純な情報源は、次の 1 文字が直前の 1 文字だけで決まるものである。

::: definition 3.1.3 マルコフ情報源
遷移確率とは、$\mathcal X \times \mathcal X$ 上の非負関数 $P$ であって、各$a \in \mathcal X$ について $\sum_{b} P(a,b) = 1$ を満たすもののことをいう。$\mathcal X$ 上の分布 $\mu$ と遷移確率 $P$ に対し、任意の $n \ge 1$ と$x_0, \dots, x_{n-1} \in \mathcal X$ で
$$
\Pr\big[X_0 = x_0, \dots, X_{n-1} = x_{n-1}\big]
  \;=\; \mu(x_0) \prod_{i=1}^{n-1} P(x_{i-1}, x_i)
$$
を満たす情報源を、初期分布 $\mu$・遷移確率 $P$ の **マルコフ情報源** という。$\mu$ が
$$
\sum_{a} \mu(a) P(a, b) \;=\; \mu(b) \qquad (b \in \mathcal X)
$$
を満たすとき、$\mu$ を $P$ の **定常分布** という。
:::

**第1章のマルコフ連鎖との関係.** 定義 1.8.3 で「マルコフ連鎖」と呼んだのは三つの確率変数$X \to Z \to Y$ の条件付き独立のことで、遷移確率も時間も出てこなかった。ここで導入したのは時間発展する列のほうで、1.8 節で予告した意味である。二つは無関係ではない。定義 3.1.3の情報源では、任意の $i \ge 1$ について $X_{i-1} \to X_i \to X_{i+1}$ が定義 1.8.3 の意味でマルコフ連鎖をなす——直前の文字を知ってしまえば、それより前の文字は次の文字について何も語らないからである。同じ語が二つの意味をもつのは、この一致のためである。

::: proposition 3.1.4
定義 3.1.3 のマルコフ情報源が定常であるための必要十分条件は、初期分布 $\mu$ が遷移確率$P$ の定常分布であることである。
:::

::: proof
まず $X_\ell$ の分布がすべての $\ell$ で $\mu$ に等しいことを、$\ell$ についての帰納法で示す。$\ell = 0$ は仮定である。$X_\ell$ の分布が $\mu$ なら、定義 3.1.3 の分解を$n = \ell+2$ に使って $x_0, \dots, x_{\ell-1}$ を和で消すと
$$
\Pr\big[X_{\ell+1} = b\big] \;=\; \sum_{a} \Pr\big[X_\ell = a\big] P(a, b)
  \;=\; \sum_{a} \mu(a) P(a,b) \;=\; \mu(b)
$$
であり、最後の等号が定常分布の条件である。

次に定義 3.1.1 の等式を見る。定義 3.1.3 の分解で先頭の $\ell$ 文字——衝突を避けるため$y_0, \dots, y_{\ell-1}$ と書く——を和で消すと、残るのは $X_\ell$ の分布と $\ell$ 以降の遷移確率だけである：
$$
\Pr\big[X_\ell = x_0, \dots, X_{\ell+n-1} = x_{n-1}\big]
  \;=\; \Pr\big[X_\ell = x_0\big] \prod_{i=1}^{n-1} P(x_{i-1}, x_i).
$$
前段より $\Pr[X_\ell = x_0] = \mu(x_0)$ だから、右辺は $\ell$ に依らない。$\ell = 0$ の場合と比べれば定義 3.1.1 の等式を得る。

逆に情報源が定常だとする。定義 3.1.1 を $n = 1$、$\ell = 1$ に使うと $X_1$ の分布は $X_0$のそれ、すなわち $\mu$ に等しい。いっぽう定義 3.1.3 の分解を $n = 2$ に使って $x_0$ を和で消すと $\Pr[X_1 = b] = \sum_a \mu(a)P(a,b)$ である。二つを比べれば$\sum_a \mu(a) P(a,b) = \mu(b)$、すなわち $\mu$ は $P$ の定常分布である。
:::

命題 3.1.4 は、マルコフ情報源を定常にする初期分布の選び方はただ一つの条件——定常分布であること——に尽きる、と言っている。定常分布が存在するかどうかは別の問題で、本書では扱わない。以下でマルコフ情報源を持ち出すときは、定常分布が与えられているものとする。

::: example 3.1.5 二状態マルコフ情報源
$\mathcal X = \{0, 1\}$、$\alpha, \beta \in (0,1)$ とし、遷移確率を
$$
P(0,1) = \alpha, \quad P(0,0) = 1-\alpha, \qquad
P(1,0) = \beta, \quad P(1,1) = 1-\beta
$$
で定める。状態 $0$ からは確率 $\alpha$ で移り、状態 $1$ からは確率 $\beta$ で戻る、という情報源である。定常分布は
$$
\mu(0) = \frac{\beta}{\alpha+\beta}, \qquad \mu(1) = \frac{\alpha}{\alpha+\beta}
$$
である。実際
$$
\mu(0)(1-\alpha) + \mu(1)\beta
  \;=\; \frac{\beta(1-\alpha) + \alpha\beta}{\alpha+\beta}
  \;=\; \frac{\beta}{\alpha+\beta} \;=\; \mu(0)
$$
であり、もう一方の等式は全体が 1 であることから従う。

**滞在時間で読む.** 定常分布の比 $\mu(0) : \mu(1) = \beta : \alpha$ は、状態を出ていく確率の逆比である。出ていきにくい状態ほど長く滞在するので、その分だけ確率が集まる。
:::
