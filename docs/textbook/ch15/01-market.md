# 15.1 市場とポートフォリオ

第5章は，次に何が出るかに賭ける人の資産を追った．場面は競馬で，勝った馬だけが払い戻すから，$1$ レースで資産が何倍になるかは，その馬に賭けた比率とその馬のオッズとの積という一つの値だった（定義 5.1.2）．本章は同じ問いを株式の市場に移す．市場ではどの銘柄も同時に値をつけるので，資産を $m$ 個の銘柄に割っておくと，$1$ 期のあいだに各銘柄の持ち分がそれぞれ何倍かになり，手元の資産全体は，割った比率で重みをつけた和の倍になる．一つの積が和に変わる，というこの一点が本章と第5章のすべての違いを生む．

資産を毎期すべて配分し直すこと，資産の対数を期数で割って $1$ 期あたりの増え方に直すこと，そしてその期待値を良さの尺度にとることは，第5章 5.1 節の設定をそのまま引き継ぐ．引き継がないのはオッズだけで，その役は次に定める株価比が引き受ける．

::: definition 15.1.1 株価比と市場
$m \ge 1$ を銘柄の数とする．$1$ から $m$ までの各番号に正の実数を返す関数 $x$ を **株価比** と呼び，その値 $x(j)$ を，$1$ 期のあいだに銘柄 $j$ が資産を何倍にするかとする．株価比からなる空でない有限集合 $\mathcal X$ と，$\mathcal X$ に値をとる確率変数 $X$ の組を **市場** と呼び，$X$ の分布を $p$ と書く．
:::

本章の $m$ はつねに銘柄の数である．第6章 定義 6.2.1 以来，第8章と第14章もメッセージの番号を $m$ と書いてきたが，本章にメッセージは出てこない．

::: formalization-note
形式化は，起こりうる出来事の集合と，そこから株価比への写像とを分けて持つ．本文が株価比そのものを出来事とすることにしたのは，その写像を恒等写像にとった特別な場合である．市場そのものを束ねた宣言はない．
:::

::: definition 15.1.2 ポートフォリオと資産倍率
$m \ge 1$ とする．$1$ から $m$ までの各番号に非負の実数を返す関数 $b$ で $\sum_{j=1}^{m} b(j) = 1$ を満たすものを **ポートフォリオ** と呼ぶ．株価比 $x$（定義 15.1.1）に対する $b$ の **資産倍率** を
$$
\sum_{j=1}^{m} b(j)\, x(j)
$$
で定める．
:::

::: formalized
`wealthRelative` (`InformationTheory/Shannon/Portfolio/Basic.lean`)
:::

::: formalization-note
形式化のポートフォリオが動く単体は，成分が $0$ になることを許す．第5章 定義 5.1.1 の賭け金の配分はすべての点で正だったので，そこが違う．本章は正値性をポートフォリオではなく株価比のほうに課している（定義 15.1.1）．いっぽう形式化は，株価比ではなく資産倍率が正であることを，それが要る定理の仮定として置く．二つは同じことである．どのポートフォリオについても資産倍率が正であることと，どの株価比のどの成分も正であることとは，銘柄 $j$ に全額を寄せたポートフォリオを代入すれば互いに移り合うからである．
:::

第5章との違いはこの一点である．競馬では勝った馬だけが払い戻すので，$1$ レースの倍率は，その馬に賭けた比率とオッズとの積という一つの値だった．市場ではすべての銘柄が同時に値をつけるので，資産倍率は $m$ 個の項の和になる．第5章 定理 5.2.1 の証明は，二つの倍加率の差をとると，$1$ レースの倍率の対数からオッズの項が引き算で消えて相対エントロピーが残る，という計算だった．和の対数は項ごとには分かれないから，市場ではこの計算がそのままの形では動かない．何が代わりに残るかは 15.2 節で見る．

全額を配分するという約束についても，第5章とは事情が違う．第5章 5.1 節は，逆数の総和が $1$ であるオッズのもとでだけ，全額を賭けさせることが制限になっていないと言えた．市場でこれにあたるのは，株価比がつねに $1$ の銘柄，すなわち現金が銘柄の一つとして市場に含まれている場合である．そのときはその銘柄に全額を寄せれば資産が動かないので，現金を手元に置くことがポートフォリオで再現できる．含まれていない市場では，全額を配分させることは本当の制限である．本節の 例 15.1.6 の市場は，現金を銘柄の一つとして含む．

::: definition 15.1.3 資産
$m \ge 1$ とし，$\mathcal X$ を株価比（定義 15.1.1）からなる空でない有限集合，$b$ をポートフォリオ（定義 15.1.2）とする．$\mathcal X$ に値をとる株価比の列 $X_1, X_2, \dots$ に対し，初期資産を $1$ として，毎期すべての資産を同じ $b$ で配分し直すとき，$n$ 期後の **資産** を
$$
S_n(b) \;:=\; \prod_{i=1}^{n} \sum_{j=1}^{m} b(j)\, X_i(j)
$$
で定める（$n = 0$ のときは空の積で $S_0(b) = 1$ である）．記号 $S_n(b)$ は株価比の列にも依るが，固定されているものとして書かない．
:::

::: formalization-note
形式化は 定義 15.1.3 の資産にあたる量を，積そのものではなくその対数 `seqLogWealth` (`InformationTheory/Shannon/Portfolio/OperationalSequences.lean`) として持つ．積をとってから対数をとる本文とは違って，$1$ 期ごとの資産倍率の対数の和として直に定めてある．どの因子も正だから両者は同じ量を指している．
:::

毎期同じポートフォリオで配分し直すというのも約束である．15.7 節 は，それまでに出た株価比を見てそのつど組み替える戦略を扱い，そこでこの約束を外す．

$S_n(b)$ は $1$ 期ごとの資産倍率を $n$ 個掛け合わせたものである．積のままでは大きさを比べにくいので，第5章 5.1 節と同じく，対数をとって $n$ で割り，$1$ 期あたりの増え方に直す．ここで資産倍率が正であることを見ておく．定義 15.1.1 より株価比の成分はどれも正で，定義 15.1.2 よりポートフォリオの成分は非負で総和が $1$ だから，資産倍率は正である．だから次の定義の対数はつねに定まる．以下，本章では $\log$ の底を $2$ にとる．資産が $1$ 期あたり $2$ の何乗の速さで増えるかを測る量を次に置くので，指数の底と対数の底をそろえておく必要があるからである．

::: definition 15.1.4 倍加率
$m \ge 1$ とし，$\mathcal X$ を株価比（定義 15.1.1）からなる空でない有限集合，$p$ を $\mathcal X$ 上の分布，$b$ をポートフォリオ（定義 15.1.2）とする．$b$ の **倍加率** を
$$
W(b, p) \;:=\; \sum_{x \in \mathcal X} p(x) \log\Big( \sum_{j=1}^{m} b(j)\, x(j) \Big)
$$
で定める．
:::

::: formalized
`growthRate` (`InformationTheory/Shannon/Portfolio/Basic.lean`)
:::

::: formalization-note 本章共通
形式化は倍加率を自然対数で定めているので，そちらの値の単位はナットである．本章は底を $2$ にとっているから値は正の定数倍だけ違うが，以降の不等式・等式はどれも両辺が同じ倍率で変わるので，底を取り替えてもそのままの形で対応する（第5章 5.1 節と同じ断りである）．
:::

倍加率は第5章 定義 5.1.3 と同じ量で，引数からオッズが消えた形である．あちらが平均していたのは $1$ レースの倍率，すなわち勝ち馬に賭けた比率とそのオッズとの積の対数で，こちらが平均するのは資産倍率 $\sum_{j=1}^{m} b(j)\,x(j)$ の対数である．名前も第5章のまま使う．$W(b, p) = 1$ とは資産の対数が $1$ 期あたり平均して $1$ だけ増えるということで，底を $2$ にとったのだから，これは資産が $1$ 期につき $2$ 倍の速さで増えることを意味する．

このあとの節の証明は，資産倍率が正であることを繰り返し使う．番号で引けるように，上で見た論証を主張として書き留めておく．

::: lemma 15.1.5 資産倍率の正値性
$m \ge 1$ とし，$x$ を株価比（定義 15.1.1），$b$ をポートフォリオ（定義 15.1.2）とする．このとき $x$ に対する $b$ の資産倍率について
$$
\sum_{j=1}^{m} b(j)\, x(j) \;>\; 0
$$
である．
:::

::: proof
定義 15.1.1 より各 $x(j)$ は正だから，$x$ の成分の最小値も正である．定義 15.1.2 より $b(j) \ge 0$ かつ $\sum_{j=1}^{m} b(j) = 1$ だから，どの $j$ でも $b(j)\,x(j)$ はその最小値の $b(j)$ 倍以上であり，$j$ について足すと $\sum_{j=1}^{m} b(j)\,x(j)$ は最小値以上になる．とくに正である．
:::

::: example 15.1.6 現金と一つの株
$m = 2$ とする．銘柄 $1$ は株価比がつねに $1$ で（現金），銘柄 $2$ は $2$ 倍と $1/2$ 倍が確率 $1/2$ ずつであるとする．すなわち，上向きの株価比を $x_\uparrow$，下向きのそれを $x_\downarrow$ と書いて，$x_\uparrow(1) = 1$，$x_\uparrow(2) = 2$，$x_\downarrow(1) = 1$，$x_\downarrow(2) = 1/2$ とおき，$\mathcal X = \{x_\uparrow, x_\downarrow\}$，$p(x_\uparrow) = p(x_\downarrow) = 1/2$ とする．全額を現金にとったポートフォリオ（$b(1) = 1$，$b(2) = 0$）と，全額を株にとったポートフォリオ（$b(1) = 0$，$b(2) = 1$）の倍加率（定義 15.1.4）はどちらも $0$ であり，半々にとったポートフォリオ（$b(1) = b(2) = 1/2$）の倍加率は $\frac12\log\frac98 = 0.0849\ldots$ である．
:::

::: proof
全額を現金にとると，資産倍率はどちらの株価比でも $1$ だから，定義 15.1.4 の各項が $\log 1 = 0$ で和も $0$ である．全額を株にとると，資産倍率は $x_\uparrow$ で $2$，$x_\downarrow$ で $1/2$ だから，倍加率は $\frac12\log 2 + \frac12\log\frac12 = \frac12 - \frac12 = 0$ である．半々にとると，資産倍率は $x_\uparrow$ で $\frac12\cdot 1 + \frac12\cdot 2 = \frac32$，$x_\downarrow$ で $\frac12\cdot 1 + \frac12\cdot\frac12 = \frac34$ だから，倍加率は $\frac12\log\frac32 + \frac12\log\frac34 = \frac12\log\frac98$ である．$\log\frac98 = 0.1699\ldots$ だから，値は $0.0849\ldots$ になる．
:::

例 15.1.6 の三つのポートフォリオは，同じ市場に同じ額を置いていながら倍加率が違う．現金だけでも株だけでも $0$ なのに，半分ずつにすると正になる．株だけを持つと，$2$ 倍の対数と $1/2$ 倍の対数が打ち消し合って倍加率が $0$ になる．半分を現金にしておくと，下振れの側が $3/4$ 倍までしか下がらない一方，上振れの側は $3/2$ 倍まで残るので，対数の平均が正の側に傾く．この値が実際の資産の増え方とどう結びつくかは，15.5 節 で扱う．

第5章の競馬は，本章の市場の形で読み直すことができる．第5章のアルファベットの各元，すなわち各馬を一つの銘柄とみなす．そして，ある馬が勝つという結果に，その馬の銘柄には第5章のオッズの値を，ほかの銘柄には $0$ を返す関数を対応させる．すると資産倍率（定義 15.1.2）は，勝った馬に賭けた比率とその馬のオッズとの積という一つの項だけになり，定義 15.1.4 は 定義 5.1.3 と同じ式になる．ただしこうして得られる関数には値 $0$ が現れるので，これは 定義 15.1.1 の株価比ではない．第5章が賭け金の配分の側に正値性を課した（定義 5.1.1）のは，$0$ を賭けた馬が勝つと資産が $0$ になるのを防ぐためだった．本章は同じ役目を株価比の側に課している．正値性の置き場所が入れ替わっているということである．

::: formalization-note
この読み直しを述べる単独の宣言はない．定義 15.1.4 の倍加率にあたる `growthRate` と 定義 5.1.3 の倍加率にあたる `doublingRate` (`InformationTheory/Shannon/Gambling/Basic.lean`) の両方を結論に含む宣言を，結論の形で探して見つからなかった．
:::

第5章から消えるものもある．本章の市場にはオッズにあたる量がないので，公平なオッズ（定義 5.3.3）や胴元の取り分（命題 5.3.6）に対応する概念も出てこない．第5章 定理 5.3.1 の保存則，すなわち倍加率と勝ち馬のエントロピーの和がオッズと分布だけで決まる量になるという等式についても，本書は市場にあたるものを与えない．あの等式は，比例賭けの $1$ レースの倍率が分布の値とオッズの積であることを使い，その対数を二つに割ったところから出てくる．市場の資産倍率は積ではなく $m$ 項の和である．
