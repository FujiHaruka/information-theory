# 15.8 万能ポートフォリオ

本節は道具立てを変える．ここまでの本章は市場に分布を置き，株価比を確率変数として扱ってきた．本節は分布を置かない．株価比は $1$ 本の決まった系列として与えられ，確率も期待値も出てこない．したがって本節の対象について倍加率（定義 15.1.4）を書くことはできない．分布についての期待値として定めた量なので，当てる先がないからである．以下で倍加率が出てくるのは，分布を置いた節の市場とくらべるときだけである．

分布を置かないのは，これから見る戦略についての主張が，どの系列についても成り立つという形をしているからである．15.5 節 は市場が i.i.d. であることを，15.6 節 は定常でエルゴード的であることを仮定した．本節が課すのは，銘柄が二つ以上あることと，株価比がどれも正であること（定義 15.1.1）だけである．そのぶん，比べる相手を狭くとる．比べる相手は，毎期同じ比率に配分し直すポートフォリオ，しかも系列を全部見終わってから後知恵で選んだ最良のものである．後知恵で選べるなら苦労はないので，これは相手として強い．問いは，先を知らずに運用して，その相手にどこまで食らいつけるか，である．Cover が与えた答えは，どれか一つのポートフォリオを当てにいくのではなく，ポートフォリオ全体に薄く賭けておく，というものである．

::: definition 15.8.1 定率再配分ポートフォリオの資産
$m \ge 2$ とし，$x_0, x_1, x_2, \dots$ を株価比（定義 15.1.1）の列とする（分布は置かない）．ポートフォリオ（定義 15.1.2）$b$ を毎期同じ比率にとって配分し直す運用を **定率再配分ポートフォリオ** と呼び，初期資産を $1$ として，整数 $n \ge 0$ に対しその $n$ 期後の資産を
$$
S_n(b) \;:=\; \prod_{i=0}^{n-1} \sum_{j=1}^{m} b(j)\, x_i(j)
$$
と定める（$n = 0$ のときは空の積で $S_0(b) = 1$ である）．
:::

これは 定義 15.1.3 の資産を，確率変数の列ではなく決まった系列について書き直したものである．定義 15.1.1 より各 $x_i(j)$ は正で，定義 15.1.2 よりポートフォリオの成分は非負で総和が $1$ だから，どの因子も $x_i$ の成分の最小値以上であり，とくに $S_n(b) > 0$ である．

ポートフォリオ全体の上で薄く賭けるとは，どういうことか．ポートフォリオ $b$ は，はじめの $m-1$ 個の成分を並べた $y := (b(1), \dots, b(m-1))$ を決めれば，残りが $b(m) = 1 - \sum_{j=1}^{m-1} y_j$ で決まる．逆に
$$
y_j \ge 0 \quad (1 \le j \le m-1), \qquad \sum_{j=1}^{m-1} y_j \le 1
$$
を満たす $y \in \mathbb R^{m-1}$ に対し，$b_y(j) := y_j$（$1 \le j \le m-1$），$b_y(m) := 1 - \sum_{j=1}^{m-1} y_j$ とおけば，成分はどれも非負で総和は $1$ だから $b_y$ はポートフォリオである．そこで，この $y$ の動く範囲の上で $m-1$ 次元の体積について平均をとる．範囲の体積は正である．辺の長さ $1/m$ の立方体，すなわちすべての成分が $0$ 以上 $1/m$ 以下であるような $y$ の全体を含んでおり（成分の和は $(m-1)/m$ 以下だから条件を満たす），その体積が $m^{-(m-1)} > 0$ だからである．以下では，微積分の計算規則として，有限個の連続関数の積が連続であること，積分が関数の大小を保つこと，非負の関数の積分は積分する範囲を広げると減らないこと，$m-1$ 次元の体積が包含について単調であること，そして $\mathbb R^{m-1}$ の集合を比 $\lambda > 0$ で相似に縮めた像の体積がもとの体積の $\lambda^{m-1}$ 倍になることを既知とする．

::: definition 15.8.2 万能ポートフォリオの資産
定義 15.8.1 と同じ設定とし，$y$ の動く範囲を，$y_j \ge 0$（$1 \le j \le m-1$）と $\sum_{j=1}^{m-1} y_j \le 1$ を満たす $y \in \mathbb R^{m-1}$ の全体とする．整数 $n \ge 0$ に対し，**万能ポートフォリオの資産** を
$$
\hat S_n \;:=\; \frac{\displaystyle\int S_n(b_y)\,dy}{\displaystyle\int dy}
$$
と定める．二つの積分はどちらもこの範囲にわたる $m-1$ 次元の積分で，$b_y$ は $b_y(j) = y_j$（$1 \le j \le m-1$），$b_y(m) = 1 - \sum_{j=1}^{m-1} y_j$ で定まるポートフォリオ，$S_n$ は 定義 15.8.1 の資産である．
:::

$\hat S_n$ は，初期資産を $y$ の範囲に一様にばらまき，それぞれの取り分をそれぞれのポートフォリオで運用したときの，$n$ 期後の資産の合計にあたる．どのポートフォリオが良いかを当てにいっていないので，先を知る必要がない．いっぽう，どれか一つに集中していないので，最良のものにそのまま並ぶこともない．どれだけ離されるかを測るのが本節の仕事である．

::: definition 15.8.3 後知恵の最良の資産
定義 15.8.1 と同じ設定とし，整数 $n \ge 0$ に対し
$$
S^{*}_n \;:=\; \sup_{b} S_n(b)
$$
と定める．上限はポートフォリオ（定義 15.1.2）全体にわたるもので，$S_n$ は 定義 15.8.1 の資産である（この上限が実数であることは 命題 15.8.4 が与える）．
:::

::: proposition 15.8.4 最良の資産は達成される
$m \ge 2$ とし，$x_0, x_1, x_2, \dots$ を株価比（定義 15.1.1）の列，$n \ge 0$ を整数とする．このとき，どのポートフォリオ（定義 15.1.2）$b$ についても $S_n(b) \le S_n(b^{\star})$ を満たすポートフォリオ $b^{\star}$ が存在し，$S^{*}_n = S_n(b^{\star})$ である（$S_n$ は 定義 15.8.1，$S^{*}_n$ は 定義 15.8.3 のものである）．
:::

::: proof
ポートフォリオ全体は実ベクトル空間 $\mathbb R^{m}$ の部分集合であり，銘柄 $1$ に全額を寄せた組が入っているから空でなく，どのポートフォリオでも $0 \le b(j) \le 1$ だから有界であり，定義 15.1.2 の条件が成分についての等式と不等式で書けているから閉である．$b \mapsto \sum_{j} b(j) x_i(j)$ は成分の一次結合だから連続で，既知とした計算規則より有限個の積 $S_n(\cdot)$ も連続である．そこで 15.2 節 が借りた Weierstrass の最大値定理より，$S_n(\cdot)$ はポートフォリオ全体の上で最大値をとる．それを与えるポートフォリオを $b^{\star}$ とすれば，どのポートフォリオ $b$ についても $S_n(b) \le S_n(b^{\star})$ である．したがって 定義 15.8.3 の上限は $S_n(b^{\star})$ である．
:::

::: formalization-note
命題 15.8.4 に対応する単独の宣言はない．形式化は最大値の達成を自由座標の側で述べている（`bestConstantWealth_attained` (`InformationTheory/Shannon/Portfolio/Universal.lean`)）．すなわち，定義 15.8.2 の範囲の点 $y$ で，上限が $S_n(b_y)$ に等しく，かつ範囲のどの点 $z$ についても $S_n(b_z)$ がその上限以下であるようなものが存在する，という形である．どのポートフォリオも範囲のある点の $b_z$ だから，本文の主張はこの二つを合わせれば出る．
:::

::: proposition 15.8.5 万能ポートフォリオは後知恵の最良を超えない
$m \ge 2$ とし，$x_0, x_1, x_2, \dots$ を株価比（定義 15.1.1）の列とする．このとき，どの整数 $n \ge 0$ についても $\hat S_n \le S^{*}_n$ である（$\hat S_n$ は 定義 15.8.2，$S^{*}_n$ は 定義 15.8.3 のものである）．
:::

::: proof
命題 15.8.4 より $S^{*}_n$ は実数である．定義 15.8.2 の範囲のどの点 $y$ でも $b_y$ はポートフォリオだから，定義 15.8.3 より $S_n(b_y) \le S^{*}_n$ である．既知とした計算規則より積分は関数の大小を保つので，$\int S_n(b_y)\,dy \le S^{*}_n \int dy$ である．範囲の体積 $\int dy$ は正だから，両辺をそれで割れば主張を得る．
:::

平均は最大を超えない，というだけである．逆向き，すなわち平均が最大からどれだけ下かが本節の中身で，ここに $n$ が入ってくる．鍵は，最良のポートフォリオの近くには最良に近いポートフォリオが集まっており，その集まりの体積が $n$ の多項式の逆数ぶんしかつぶれない，という一点である．

::: theorem 15.8.6 後知恵の最良は万能ポートフォリオの多項式倍で抑えられる
$m \ge 2$ とし，$x_0, x_1, x_2, \dots$ を株価比（定義 15.1.1）の列とする．このとき，どの整数 $n \ge 0$ についても
$$
S^{*}_n \;\le\; e\,(n+1)^{m-1}\, \hat S_n
$$
である（$\hat S_n$ は 定義 15.8.2，$S^{*}_n$ は 定義 15.8.3 のもの，$e$ は自然対数の底である）．
:::

::: proof
$n = 0$ のときは 定義 15.8.1 よりどのポートフォリオでも $S_0(b) = 1$ だから，定義 15.8.2 と 定義 15.8.3 より $\hat S_0 = S^{*}_0 = 1$ であり，$e \ge 1$ から主張が従う．以下 $n \ge 1$ とし，$\lambda := 1/(n+1)$ とおく．

まず $(1-\lambda)^n \ge e^{-1}$ を見る．第1章 1.1 節 の信頼の底から出した対数不等式 $\log u \le (u-1)\log e$ を $u := (n+1)/n$ に当てると $\log\frac{n+1}{n} \le \frac1n\log e$ であり，両辺を $n$ 倍して $\log\big(\frac{n+1}{n}\big)^{n} \le \log e$ を得る．補題 8.2.5 より，正の二数の一方が他方より真に大きければ対数も真に大きいので，対数の側のこの不等号から $\big(\frac{n+1}{n}\big)^{n} \le e$ が従う．逆数をとれば $(1-\lambda)^n = \big(\frac{n}{n+1}\big)^{n} \ge e^{-1}$ である．

つぎに縮める先を作る．命題 15.8.4 の $b^{\star}$ をとり，その自由座標を $y^{\star} := (b^{\star}(1), \dots, b^{\star}(m-1))$ とおくと，$y^{\star}$ は 定義 15.8.2 の範囲に入る．範囲の点 $y$ に $(1-\lambda)y^{\star} + \lambda y$ を対応させる写像を考える．範囲は，成分についての不等式と成分の和についての不等式で書けているから凸であり，$0 \le \lambda \le 1$ だからこの写像は範囲を範囲の中へ移す．また各成分を見れば $b_{(1-\lambda)y^{\star} + \lambda y} = (1-\lambda)\,b_{y^{\star}} + \lambda\,b_y$ である（第 $m$ 成分については $(1-\lambda) + \lambda = 1$ による）．

像の上で資産を下から抑える．$y$ を範囲の点，$i$ を $0 \le i \le n-1$ の整数とすると，$b_y$ の資産倍率は正だから
$$
\sum_{j=1}^{m} b_{(1-\lambda)y^{\star} + \lambda y}(j)\, x_i(j)
  \;=\; (1-\lambda) \sum_{j=1}^{m} b^{\star}(j)\, x_i(j) + \lambda \sum_{j=1}^{m} b_y(j)\, x_i(j)
  \;\ge\; (1-\lambda) \sum_{j=1}^{m} b^{\star}(j)\, x_i(j)
$$
である．どちらの辺も正だから，$i = 0$ から $n-1$ まで掛け合わせて 定義 15.8.1 より
$$
S_n\big(b_{(1-\lambda)y^{\star} + \lambda y}\big) \;\ge\; (1-\lambda)^{n}\, S_n(b^{\star}) \;\ge\; e^{-1}\, S^{*}_n
$$
を得る（第 $2$ の不等号は上に見た $(1-\lambda)^n \ge e^{-1}$ と 命題 15.8.4 による）．

体積を数える．この写像は範囲を比 $\lambda$ で相似に縮めたものだから，既知とした計算規則より像の体積は範囲の体積の $\lambda^{m-1}$ 倍である．像を $A$ と書くと，$S_n$ は範囲の上で正で，$A$ は範囲に含まれるから
$$
\int S_n(b_y)\,dy \;\ge\; \int_{A} S_n(b_y)\,dy \;\ge\; e^{-1} S^{*}_n\, \lambda^{m-1} \int dy
$$
である．両辺を範囲の体積 $\int dy > 0$ で割ると 定義 15.8.2 より $\hat S_n \ge e^{-1}\lambda^{m-1} S^{*}_n$ であり，$\lambda^{-(m-1)} = (n+1)^{m-1}$ を掛けて整理すれば主張を得る．
:::

::: formalization-note
形式化は銘柄の数ではなく自由座標の個数で径数付ける．そのため銘柄の数は宣言では「自由座標の個数 $+1$」の形で現れ，右辺の指数はその自由座標の個数，すなわち本文の $m-1$ である．定数は本文と同じ $e$ で，両辺の係数まで本文の不等式と一致する．
:::

$(n+1)^{m-1}$ という因子は，縮めた像の体積が範囲の $\lambda^{m-1}$ 倍にしかならないことから出ている．銘柄が多いほど自由座標が増え，同じ比で縮めたときに残る体積が小さくなるので，薄く賭けたぶんの取り分も減る．いっぽう $e$ のほうは，縮める比を $\lambda = 1/(n+1)$ にとったときに $(1-\lambda)^n$ が下がりきらないことから出ていて，$n$ にも $m$ にも依らない．二つとも資産そのものにかかる倍率なので，期を重ねるほど効いてくるように見えるが，$1$ 期あたりに直すと様子が変わる．

::: corollary 15.8.7
$m \ge 2$ とし，$x_0, x_1, x_2, \dots$ を株価比（定義 15.1.1）の列とする．このとき，どの整数 $n \ge 1$ についても
$$
0 \;\le\; \frac1n\big(\log S^{*}_n - \log \hat S_n\big) \;\le\; \frac{\log e + (m-1)\log(n+1)}{n}
$$
である（$\hat S_n$ は 定義 15.8.2，$S^{*}_n$ は 定義 15.8.3 のものである）．
:::

::: proof
命題 15.8.4 より $S^{*}_n = S_n(b^{\star}) > 0$ であり，定理 15.8.6 より $\hat S_n \ge e^{-1}(n+1)^{-(m-1)}S^{*}_n > 0$ だから，どちらの対数も定まる．命題 15.8.5 と 補題 8.2.5 より $\log \hat S_n \le \log S^{*}_n$ で，$n > 0$ で割れば左の不等号を得る．定理 15.8.6 と 補題 8.2.5 より
$$
\log S^{*}_n \;\le\; \log\big(e\,(n+1)^{m-1}\,\hat S_n\big) \;=\; \log e + (m-1)\log(n+1) + \log \hat S_n
$$
であり，移項して $n$ で割れば右の不等号を得る．
:::

::: theorem 15.8.8 後知恵の最良との $1$ 期あたりの差は $0$ に収束する
$m \ge 2$ とし，$x_0, x_1, x_2, \dots$ を株価比（定義 15.1.1）の列とする．このとき
$$
\frac1n\big(\log S^{*}_n - \log \hat S_n\big) \;\longrightarrow\; 0 \qquad (n \to \infty)
$$
である（$\hat S_n$ は 定義 15.8.2，$S^{*}_n$ は 定義 15.8.3 のものである）．
:::

::: proof
系 15.8.7 の右辺は $\frac{\log e}{n} + (m-1)\frac{\log(n+1)}{n}$ であり，どちらの項も $n \to \infty$ で $0$ に収束する．左辺は $0$ だから，挟み撃ちにより中央も $0$ に収束する．
:::

定理 15.8.8 は，どの系列についても，$1$ 期あたりの増え方で測るかぎり万能ポートフォリオが後知恵の最良に追いつくと言っている．資産そのものの比は $e\,(n+1)^{m-1}$ まで開きうるので，追いついているのは指数の肩の話である．補題 3.5.3 が「期待値が $1$ で抑えられた比は $\frac1n\log$ の尺度では消える」と言っていたのと同じ粗さで見ている，ということでもある．どのくらい粗いかは，数を入れてみるとはっきりする．

::: example 15.8.9 交互に上下する系列
$m = 2$ とし，銘柄 $1$ は株価比がつねに $1$，銘柄 $2$ は偶数の期に $2$，奇数の期に $1/2$ であるとする．すなわち $x_i(1) = 1$ とし，偶数の $i$ で $x_i(2) = 2$，奇数の $i$ で $x_i(2) = 1/2$ とする．このとき偶数の整数 $n \ge 0$ について $S^{*}_n = (9/8)^{n/2}$ であり，そのうち $n \ge 2$ のものについては $\frac1n\log S^{*}_n = \frac12\log\frac98 = 0.0849\ldots$ である．いっぽう 系 15.8.7 の右辺の値は，$n = 94$ で $0.0852\ldots$，$n = 95$ で $0.0845\ldots$，$n = 100$ で $0.0810\ldots$，$n = 500$ で $0.0208\ldots$，$n = 1000$ で $0.0114\ldots$ である（$S^{*}_n$ は 定義 15.8.3 のものである）．
:::

::: proof
ポートフォリオを $b(2) = \beta$，$b(1) = 1-\beta$（$0 \le \beta \le 1$）と書く．資産倍率は偶数の期で $(1-\beta) + 2\beta = 1+\beta$，奇数の期で $(1-\beta) + \frac12\beta = 1 - \frac12\beta$ だから，偶数の $n$ について 定義 15.8.1 より $S_n(b) = \big[(1+\beta)(1-\frac12\beta)\big]^{n/2}$ である．平方完成すると
$$
(1+\beta)\Big(1 - \tfrac12\beta\Big) \;=\; \tfrac98 - \tfrac12\Big(\beta - \tfrac12\Big)^{2}
$$
だから，この値は $\beta = 1/2$ で最大 $9/8$ をとる．偶数の $n \ge 2$ については，正の数の $n/2$ 乗が単調だから 定義 15.8.3 より $S^{*}_n = (9/8)^{n/2}$ であり，$n = 0$ のときは両辺とも $1$ で等式が成り立つ．両辺の対数を $n$ で割れば $\frac1n\log S^{*}_n = \frac12\log\frac98$ で，例 15.1.5 よりこの値は $0.0849\ldots$ である．

系 15.8.7 の右辺は $m = 2$ だから $(\log e + \log(n+1))/n$ である．$\log e = 1.4426\ldots$，$\log 95 = 6.5698\ldots$，$\log 96 = 6.5849\ldots$，$\log 101 = 6.6582\ldots$，$\log 501 = 8.9686\ldots$，$\log 1001 = 9.9672\ldots$ を代入して割ると，順に $0.0852\ldots$，$0.0845\ldots$，$0.0810\ldots$，$0.0208\ldots$，$0.0114\ldots$ を得る．
:::

例 15.8.9 の系列は，例 15.1.5 の市場が上下を交互に出したものにあたる．$1$ 期あたりの増え方も 例 15.2.6 の対数最適ポートフォリオの倍加率と同じ $0.0849\ldots$ で，最良を与える比率 $\beta = 1/2$ も同じである．そこに 系 15.8.7 の上界を並べると，本章がほかの例で使ってきた $n = 100$ という規模では，上界のほうが増え方の $0.95$ 倍あって，ほとんど何も保証していない．上界が増え方を下回るのは $n = 94$ と $n = 95$ のあいだで，増え方の $0.25$ 倍まで下がるのが $n = 500$，$0.13$ 倍が $n = 1000$ である．増え方の $1/10$ にあたる $0.0084\ldots$ を下回るのは，$n = 1000$ でまだ $0.0114\ldots$ なのだから，さらに先になる．系 15.8.7 の右辺は $\log(n+1)/n$ の速さでしか落ちないからで，万能ポートフォリオが後知恵の最良に食らいついていると数のうえで言えるのは，銘柄が $2$ つのこの系列でも数百期から先である．

本節の評価を 15.5 節・15.6 節 のそれと比べる軸は三つある．

**広いのは仮定である.** 本節は分布を仮定せず，銘柄が二つ以上あることと株価比が正であること（定義 15.1.1）だけを課しているので，評価はどの系列にも当たる．i.i.d. でも定常でもない系列にも当たるし，市場が途中で性質を変えても当たる．

**狭いのは比べる相手である.** 定義 15.8.3 の上限は，毎期同じ比率に配分し直すポートフォリオの全体にわたるものである．15.7 節 が扱った，過去を見て組み替える戦略は相手にしていない．本書は定率再配分ポートフォリオを相手にした評価しか与えない．

**広い狭いが決まらない軸もある.** 市場が i.i.d. のとき，定義 15.8.3 の $1$ 期あたりの増え方が，定理 15.5.1 を 定義 15.2.3 の対数最適ポートフォリオに当てて得られる倍加率（定義 15.1.4）に近づくかどうかである．近づくと言うには，すべてのポートフォリオを同時に覆う確率 $1$ の事象が要る．15.5 節 が主張として立てないと書いた版がまさにそれで，本書はその段を扱わない．本節の評価と 15.5 節 の評価が同じものについて語っているかどうかは，そこを埋めるまで決まらない．
