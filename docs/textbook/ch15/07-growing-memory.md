# 15.7 記憶が伸びる戦略と $W_\infty$

例 15.6.4 の市場には記憶があった．直前が上向きなら次も確率 $9/10$ で上向きである．ところが 系 15.6.2 が指す行き先には，その記憶がどこにも入ってこなかった．入ってくる余地がない．系 15.6.2 の右辺は $X_0$ の分布だけで書かれていて，そう書けるのは，定義 15.1.3 が毎期同じポートフォリオで配分し直すと約束しており，直前に何が出たかを見ないまま配分を決めるからである．本節はこの約束を外す．第 $i$ 期のポートフォリオを，それまでに出た株価比に応じて選んでよいことにすると，$1$ 期あたりの期待対数収益はどこまで上がるか，という問いを立てる．

列は定常だから，時刻 $k$ で直前の $k$ 期を見ることと，時刻 $0$ で負の時刻を見ることとは同じである．それでも両側の列にしておくのは，節の終わりで無限の過去を見る戦略を述べるためである．直前の $k$ 期という言い方を時刻 $0$ でするには，負の時刻の株価比が要る．そこで第3章 3.5 節 が借りた **定常列の両側への拡張** を借り直す．借りる形は，定常な列 $X_0, X_1, X_2, \dots$ に対し，負の時刻まで延ばした列 $\dots, X_{-1}, X_0, X_1, \dots$ で，整数の $\ell$ をどこにとっても $(X_\ell, \dots, X_{\ell+n-1})$ の同時分布が $\ell$ に依らず，しかも非負の時刻の部分の同時分布が元の列と一致するものが存在する，というものである．元がエルゴード的なら，延ばした列もシフトについてエルゴード的である．当てる対象は，有限集合 $\mathcal X$，すなわち本章の株価比の全体に値をとる定常列である．第3章の宣言は有限アルファベットに値をとる情報源について書かれており，本章の $\mathcal X$ も空でない有限集合だから，射程は広がらない．依存範囲は三つで，一つは 定義 15.7.2 以降が負の時刻の株価比を書くところ全体，一つは 例 15.7.7 が 例 15.6.4 の列に拡張を当てて両側の定常列を作るところ，もう一つは，本節の終わりで借りる無限の過去を使う戦略の収束と記憶が伸びる戦略の収束が，エルゴード性を使うところである．本節のほかの主張はどれも，両側の列が与えられたところから先の議論である．本書はこの拡張を証明しない．そのことと，無条件の機械検証済みの定理として形式化されていることが別であるのは，15.6 節 が Birkhoff の個別エルゴード定理について書き分けたのと同じである．

以下，$\dots, X_{-1}, X_0, X_1, \dots$ は $\mathcal X$ に値をとる両側の列とする．時刻 $0$ から見た直前の $k$ 期の株価比は $(X_{-1}, \dots, X_{-k})$ である．深さ $k$ の記憶を使うとは，この $k$ 個の値を見てから第 $0$ 期のポートフォリオを決めることをいう．見た値ごとに一つのポートフォリオを選ぶのだから，選び方とは $\mathcal X^{k}$ の各元にポートフォリオを一つ割り当てる規則のことである．どう割り当てるのがいちばん良いかは，見た値ごとに別々に決まる．値を一つ固定してしまえば，残っているのは第 $0$ 期の株価比の条件付き分布についての 15.2 節 の問いだからである．

::: proposition 15.7.1
$m \ge 1$ とし，$\mathcal X$ を株価比（定義 15.1.1）からなる空でない有限集合，$k \ge 0$ を整数とする．$X_{-k}, \dots, X_{-1}, X_0$ を $\mathcal X$ に値をとる確率変数とし，$h \in \mathcal X^{k}$ を $\Pr[(X_{-1}, \dots, X_{-k}) = h] > 0$ を満たすものとする．このとき，ポートフォリオ（定義 15.1.2）$b$ を動かして
$$
\mathbb E\Big[ \log\Big( \sum_{j=1}^{m} b(j)\, X_0(j) \Big) \Bigm| (X_{-1}, \dots, X_{-k}) = h \Big]
$$
を最大にするポートフォリオが存在する．
:::

::: proof
$x \in \mathcal X$ について $p_h(x) := \Pr[X_0 = x \mid (X_{-1}, \dots, X_{-k}) = h]$ とおく．条件付き確率だから $p_h(x) \ge 0$ であり，$X_0$ は $\mathcal X$ の元しかとらないから $\sum_{x \in \mathcal X} p_h(x) = 1$ である．すなわち $p_h$ は $\mathcal X$ 上の分布である．$X_0$ のとる値が有限個だから，主張の条件付き期待値は有限和
$$
\sum_{x \in \mathcal X} p_h(x) \log\Big( \sum_{j=1}^{m} b(j)\, x(j) \Big)
$$
に等しく，これは 定義 15.1.4 の $W(b, p_h)$ にほかならない．命題 15.2.2 を分布 $p_h$ に当てれば，$W(\cdot, p_h)$ を最大にするポートフォリオが存在する．
:::

::: formalization-note
命題 15.7.1 に対応する単独の宣言はない．上の証明のとおりこれは 命題 15.2.2 を条件付き分布に当てたものであり，命題 15.2.2 のほうにも単独の宣言がないからである．形式化は，これにあたるものを一般の測度空間の上で，過去で条件付けた期待対数収益を最大にするポートフォリオを標本点ごとに可測に選ぶ形で述べている（`exists_condLogOptimalSeq` (`InformationTheory/Shannon/Portfolio/StationaryWinfty.lean`)）．本文は有限集合に値をとる列に限っているので，過去の実現が有限個しかなく，選び方の可測性は問題にならない．
:::

::: definition 15.7.2 深さ $k$ の条件付き対数最適ポートフォリオと $W_k$
$m \ge 1$ とし，$\mathcal X$ を株価比（定義 15.1.1）からなる空でない有限集合，$\dots, X_{-1}, X_0, X_1, \dots$ を $\mathcal X$ に値をとる両側の列，$k \ge 0$ を整数とする（$k = 0$ のとき $\mathcal X^{0}$ はただ一つの元，すなわち空の並びだけからなる集合とし，それによる条件付けは条件を付けないことと読む）．$h \in \mathcal X^{k}$ が $\Pr[(X_{-1}, \dots, X_{-k}) = h] > 0$ を満たすとき，$x \in \mathcal X$ について $p_h(x) := \Pr[X_0 = x \mid (X_{-1}, \dots, X_{-k}) = h]$ とおき，$W(\cdot, p_h)$（定義 15.1.4）を最大にするポートフォリオ（定義 15.1.2）を一つ選んで $b^{*}_k(h)$ と書く（命題 15.7.1 よりそのようなものは存在する）．$\Pr[(X_{-1}, \dots, X_{-k}) = h] = 0$ を満たす $h$ に対しては，$b^{*}_k(h)$ を銘柄 $1$ に全額を寄せたポートフォリオと定める．こうして定まる規則 $b^{*}_k$ を **深さ $k$ の条件付き対数最適ポートフォリオ** と呼び，
$$
W_k \;:=\; \sum_{h} \Pr\big[(X_{-1}, \dots, X_{-k}) = h\big]\, W\big(b^{*}_k(h),\, p_h\big)
$$
と定める．和は $\Pr[(X_{-1}, \dots, X_{-k}) = h] > 0$ を満たす $h \in \mathcal X^{k}$ についてとる．
:::

::: formalization-note 本節共通
形式化は $W_k$ も，このあとの 定義 15.7.6 の $W_\infty$ も，深さごとのポートフォリオの規則の族を引数にとる形で定める．その族が各段で最良のものになっていることは定義に含まれておらず，そのような族がとれることは別の宣言 `exists_condLogOptimalSeq` (`InformationTheory/Shannon/Portfolio/StationaryWinfty.lean`) が与える．宣言はまた，深さ $k$ の過去ではなく一般の増えていく情報の族について述べていて，本文の $(X_{-1}, \dots, X_{-k})$ はその特別な場合である．値の定め方も，本文の重みつき和ではなく，深さ $k$ の規則を当てたときの $1$ 期の対数収益の期待値である．$\mathcal X$ が有限で過去の実現が有限個だから値はどちらも同じだが，その一致を述べる宣言はない．
:::

$W_k$ は，深さ $k$ の記憶を使ってよいときの $1$ 期あたりの期待対数収益である．右辺は，見た値 $h$ ごとにそのときの最良の倍加率を計算し，$h$ の出方で平均した形をしている．これは 定義 15.4.2 の最適倍加率 $W^{*}(X \mid Y)$ で，副情報 $Y$ として直前の $k$ 期の株価比をとったものと同じ形である．違うのは，副情報が外から与えられるのではなく，市場自身の過去だというところだけである．

::: proposition 15.7.3 固定したポートフォリオの最大倍加率としての $W_0$
$m \ge 1$ とし，$\mathcal X$ を株価比（定義 15.1.1）からなる空でない有限集合，$\dots, X_{-1}, X_0, X_1, \dots$ を $\mathcal X$ に値をとる両側の列，$p_0$ を $X_0$ の分布とする．このとき，どのポートフォリオ（定義 15.1.2）$b$ についても $W(b, p_0) \le W_0$（定義 15.1.4，定義 15.7.2）であり，等号を与えるポートフォリオが存在する．
:::

::: proof
$k = 0$ のとき $\mathcal X^{0}$ はただ一つの元 $h$，すなわち空の並びからなり，それが実現する確率は $1$ である．条件を付けないのだから $p_h$ は $X_0$ の分布 $p_0$ であり，定義 15.7.2 の和は $h$ の項だけになって $W_0 = W(b^{*}_0(h), p_0)$ となる．定義 15.7.2 より $b^{*}_0(h)$ は $W(\cdot, p_0)$ を最大にするポートフォリオだから，どのポートフォリオ $b$ についても $W(b, p_0) \le W(b^{*}_0(h), p_0) = W_0$ であり，$b := b^{*}_0(h)$ が等号を与える．
:::

::: formalization-note
命題 15.7.3 に対応する単独の宣言はない．定義 15.7.2 の $W_k$ にあたる `condOptGrowth` (`InformationTheory/Shannon/Portfolio/StationaryWinfty.lean`) と 定義 15.1.4 の倍加率にあたる `growthRate` (`InformationTheory/Shannon/Portfolio/Basic.lean`) の両方を結論に含む宣言を，結論の形で探して見つからなかった．そもそも形式化の $k = 0$ が本文の $W_0$ にあたるとも限らない．あちらの $k$ は一般のフィルトレーションの段の番号で，第 $0$ 段が条件を付けないことを意味しないからである．
:::

系 15.6.2 は，固定したポートフォリオ $b$ で運用したときの時間平均が確率 $1$ で $W(b, p_0)$ に行き着くと言っていた．命題 15.7.3 の $W_0$ は，その行き先のうちいちばん大きいものである．記憶を使わない運用でできることは，ここで頭打ちになる．

深さを増やして損をすることはない．深さ $k$ までしか見ない規則は，深さ $k'$ まで見てよい場面でもそのまま使えるので，最良のものを選び直せば値は下がりようがない．

::: proposition 15.7.4 深さについての単調性
$m \ge 1$ とし，$\mathcal X$ を株価比（定義 15.1.1）からなる空でない有限集合，$\dots, X_{-1}, X_0, X_1, \dots$ を $\mathcal X$ に値をとる両側の列とする．$k$，$k'$ を $0 \le k \le k'$ を満たす整数とすると $W_k \le W_{k'}$（定義 15.7.2）である．
:::

::: proof
$h' \in \mathcal X^{k'}$ を $\Pr[(X_{-1}, \dots, X_{-k'}) = h'] > 0$ を満たすものとし，$h \in \mathcal X^{k}$ をその最初の $k$ 成分，すなわち $(X_{-1}, \dots, X_{-k})$ にあたる部分とする．$(X_{-1}, \dots, X_{-k'}) = h'$ ならば $(X_{-1}, \dots, X_{-k}) = h$ だから $\Pr[(X_{-1}, \dots, X_{-k}) = h] > 0$ であり，定義 15.7.2 より $b^{*}_k(h)$ は $W(\cdot, p_h)$ の最大化元，$b^{*}_{k'}(h')$ は $W(\cdot, p_{h'})$ の最大化元である．後者から
$$
W\big(b^{*}_k(h),\, p_{h'}\big) \;\le\; W\big(b^{*}_{k'}(h'),\, p_{h'}\big)
$$
である．両辺に $\Pr[(X_{-1}, \dots, X_{-k'}) = h'] \ge 0$ を掛け，正の確率をもつ $h'$ について足すと，右辺の和は 定義 15.7.2 より $W_{k'}$ だから
$$
\sum_{h'} \Pr\big[(X_{-1}, \dots, X_{-k'}) = h'\big]\, W\big(b^{*}_k(h),\, p_{h'}\big) \;\le\; W_{k'}
$$
を得る．

左辺が $W_k$ に等しいことを見る．$\Pr[(X_{-1}, \dots, X_{-k}) = h] > 0$ を満たす $h$ を一つ固定し，$b := b^{*}_k(h)$ とおく．最初の $k$ 成分が $h$ であり正の確率をもつ $h'$ について和をとると，どの $x \in \mathcal X$ でも
$$
\sum_{h'} \Pr\big[(X_{-1}, \dots, X_{-k'}) = h'\big]\, p_{h'}(x)
  \;=\; \Pr\big[(X_{-1}, \dots, X_{-k}) = h\big]\, p_h(x)
$$
である．両辺とも $\Pr[(X_{-1}, \dots, X_{-k}) = h,\; X_0 = x]$ に等しいからである（左辺で落とした $h'$ は確率 $0$ で，その項は $0$ である）．定義 15.1.4 より $W(b, p_{h'}) = \sum_{x} p_{h'}(x) \log(\sum_{j} b(j)x(j))$ だから，$x$ についての和と $h'$ についての和を入れ替えて，最初の $k$ 成分が $h$ である $h'$ の寄与は $\Pr[(X_{-1}, \dots, X_{-k}) = h]\, W(b, p_h)$ に等しい．正の確率をもつ $h'$ はどれもその最初の $k$ 成分が正の確率をもつので，$h$ について足せば左辺は 定義 15.7.2 の $W_k$ である．
:::

宣言は，深さごとのポートフォリオの規則の族が条件付き支配の性質をもつこと，すなわち過去で決まるどの規則についても，過去を与えたときの期待対数収益が深さ $k$ の規則のそれ以下であることを仮定に置く．本文の $\mathcal X$ は有限で過去の実現も有限個だから，この仮定は 定義 15.7.2 が実現ごとに課した最大性そのものである．

深さを増やして上がるとまでは，命題 15.7.4 は言っていない．実際に上がる市場があることは 例 15.7.7 が見せる．次の証明では，単調非減少で上に有界な実数列がその上限に収束することを，学部の解析の事実として既知とする．

::: proposition 15.7.5 $W_k$ の有界性と上限への収束
$m \ge 1$ とし，$\mathcal X$ を株価比（定義 15.1.1）からなる空でない有限集合，$\dots, X_{-1}, X_0, X_1, \dots$ を $\mathcal X$ に値をとる両側の列とし，$x_{\max} := \max_{x \in \mathcal X} \max_{1 \le j \le m} x(j)$ とおく（$\mathcal X$ は空でない有限集合だから，この最大値は定まる）．このとき次の二つが成り立つ（$W_k$ は 定義 15.7.2 のものである）．

1. どの整数 $k \ge 0$ についても $W_k \le \log x_{\max}$ である．
2. 数列 $(W_k)_{k \ge 0}$ は $\sup_{k \ge 0} W_k$ に収束する．
:::

::: proof
1. どのポートフォリオ $b$ とどの $x \in \mathcal X$ についても，定義 15.1.2 より $b(j) \ge 0$ かつ $\sum_{j} b(j) = 1$ であり，$x_{\max}$ のとり方より $x(j) \le x_{\max}$ だから $\sum_{j} b(j) x(j) \le x_{\max}$ である．いっぽう 補題 15.1.5 よりこの和は正だから，対数の単調性（補題 8.2.5）より $\log \sum_{j} b(j) x(j) \le \log x_{\max}$ である．したがって，非負で総和が $1$ の重み $p_h$ で平均した $W(b, p_h)$ も $\log x_{\max}$ 以下である．定義 15.7.2 の重み $\Pr[(X_{-1}, \dots, X_{-k}) = h]$ も非負で総和が $1$ だから，$W_k \le \log x_{\max}$ を得る．

2. 命題 15.7.4 より $(W_k)_{k \ge 0}$ は非減少で，1. より上に有界だから，既知とした解析の事実によりその上限に収束する．
:::

::: formalization-note
命題 15.7.5 に対応する単独の宣言はない．上に有界であることは `condOptGrowth_bddAbove` (`InformationTheory/Shannon/Portfolio/StationaryWinfty.lean`) が与えるが，こちらは一様な上界の存在を仮定にとる形で，本章の市場ではその仮定が 定義 15.1.1 から 1. の議論のとおりに出る．収束のほうは，深さごとの規則の族の存在とあわせて `exists_condOptGrowth_tendsto_condOptGrowthInfty` (`InformationTheory/Shannon/Portfolio/StationaryWinfty.lean`) が述べているが，結論が存在の形をしていて本文の主張とは形が違う．
:::

定義 15.7.2，命題 15.7.3，命題 15.7.4，定義 15.7.6 を並べると，どのポートフォリオ $b$ についても
$$

という連鎖になる．いちばん左が記憶を使わない運用の値，いちばん右がいくらでも深い記憶を使ってよいときの値である．ここまでの主張は，列が定常であることもエルゴード的であることも使っていない．どれも時刻 $0$ の一期についての量だからである．定常性を使うのは 例 15.7.7 の計算と，このあと時間平均が出てくるところで，エルゴード性を使うのは後者だけである．

::: example 15.7.7 記憶のあるマルコフ市場の $W_\infty$
$\mathcal X = \{x_\uparrow, x_\downarrow\}$（例 15.1.6 の二つの株価比）とし，例 15.6.4 の列，すなわちどちらの状態からも確率 $9/10$ で同じ状態にとどまり確率 $1/10$ でもう一方に移るマルコフ情報源（定義 3.1.3）を定常分布から始めたものに，本節のはじめに借りた両側への拡張を当てて，両側の定常列 $\dots, X_{-1}, X_0, X_1, \dots$ を得る．このとき
$$
W_0 \;=\; \tfrac12\log\tfrac98 \;=\; 0.0849\ldots, \qquad
W_k \;=\; \tfrac25 \quad (k \ge 1)
$$
であり，$W_\infty = \frac25$ である（$W_k$ は 定義 15.7.2，$W_\infty$ は 定義 15.7.6 のものである）．
:::

::: proof
$W_0$ から見る．両側への拡張の非負の時刻の部分は 例 15.6.4 の列と一致するから，例 15.6.4 より $X_0$ の分布 $p_0$ は $\{x_\uparrow, x_\downarrow\}$ 上の一様分布，すなわち 例 15.1.6 の $p$ であり，$W(\cdot, p_0)$ の最大値は $\frac12\log\frac98$ である．命題 15.7.3 よりこれが $W_0$ である．

条件付き分布を求める．$k \ge 1$ と，正の確率をもつ $h = (h_1, \dots, h_k) \in \mathcal X^{k}$ をとる．列は定常だから $(X_{-k}, \dots, X_{-1}, X_0)$ の同時分布は $(X_0, \dots, X_k)$ のそれに等しい．両側への拡張の非負の時刻の部分は 例 15.6.4 の列と一致するから，後者は 定義 3.1.3 より初期分布と遷移確率の積に分かれる．初期分布を $\mu$（例 15.6.4 の定常分布），遷移確率を $P$ と書いて並びを対応させると
$$
\Pr\big[(X_{-1}, \dots, X_{-k}) = h,\; X_0 = x\big]
  \;=\; \mu(h_k)\, P(h_k, h_{k-1}) \cdots P(h_2, h_1)\, P(h_1, x)
$$
であり，$x$ について足したものが $\Pr[(X_{-1}, \dots, X_{-k}) = h]$ だから，$p_h(x) = P(h_1, x)$ である．すなわち $p_h$ は $h$ の最初の成分だけで決まる．

$h_1 = x_\uparrow$ の場合を計算する．$p_h(x_\uparrow) = 9/10$，$p_h(x_\downarrow) = 1/10$ である．全額を銘柄 $2$ に寄せたポートフォリオ $b$ をとると，資産倍率は $x_\uparrow$ で $2$，$x_\downarrow$ で $1/2$ だから，定理 15.2.4 の左辺は $j = 1$ について $\frac9{10}\cdot\frac12 + \frac1{10}\cdot 2 = \frac{13}{20}$，$j = 2$ について $\frac9{10}\cdot 1 + \frac1{10}\cdot 1 = 1$ である．どちらも $1$ 以下だから，定理 15.2.4 より $b$ は分布 $p_h$ についての対数最適ポートフォリオであり，定義 15.1.4 より $W(b, p_h) = \frac9{10}\log 2 + \frac1{10}\log\frac12 = \frac45$ である．

$h_1 = x_\downarrow$ の場合も同じである．$p_h(x_\uparrow) = 1/10$，$p_h(x_\downarrow) = 9/10$ で，全額を銘柄 $1$ に寄せたポートフォリオ $b'$ をとると資産倍率はどちらの株価比でも $1$ だから，定理 15.2.4 の左辺は $j = 1$ について $1$，$j = 2$ について $\frac1{10}\cdot 2 + \frac9{10}\cdot\frac12 = \frac{13}{20}$ である．よって $b'$ が分布 $p_h$ についての対数最適ポートフォリオであり，定義 15.1.4 より $W(b', p_h) = \log 1 = 0$ である．

$W_k$ の値を出す．列は定常だから $X_{-1}$ の分布は $X_0$ の分布 $p_0$，すなわち一様分布であり，$\Pr[X_{-1} = x_\uparrow] = \Pr[X_{-1} = x_\downarrow] = \frac12$ である．$k \ge 1$ について，定義 15.7.2 の和のうち最初の成分が $x_\uparrow$ である $h$ の寄与は，$W(b^{*}_k(h), p_h)$ の値がどれも $\frac45$ で，重みの和が $\Pr[X_{-1} = x_\uparrow] = \frac12$ だから $\frac12\cdot\frac45$ であり，最初の成分が $x_\downarrow$ である $h$ の寄与は同様に $\frac12\cdot 0$ である．よって $W_k = \frac25$ である．定義 15.7.6 より $W_\infty = \sup_{k \ge 0} W_k$ で，$W_0 = 0.0849\ldots < \frac25$ だから $W_\infty = \frac25$ である．
:::

例 15.7.7 の市場では，記憶を一期ぶん使えるようにしただけで $1$ 期あたりの期待対数収益が $0.0849\ldots$ から $\frac25$ へ上がる．例 15.6.4 で見たとおり，この市場の $X_0$ の分布は記憶のない 例 15.1.6 の市場のそれと同じだから，固定したポートフォリオ $b$ について 系 15.6.2 の右辺 $W(b, p_0)$ も二つの市場で同じ値である．同じ値になるのは市場のせいではなく，運用の仕方のせいだったということである．そして二期以上さかのぼっても値は変わらない．次に何が出るかについて，直前の一つが知っていること以上のことを，それより前の株価比は知らないからである（定義 3.1.3）．

下向きと分かっているときの最良の値が $0$ にとどまるのは，15.4 節 で見たのと同じ事情による．下向きのときに資産を増やす銘柄がこの市場にはなく，できるのは減らないこと，すなわち全額を現金に寄せることまでだからである．

上がり幅そのものにも上限がある．$W_k$ が 定義 15.4.2 の最適倍加率と同じ形であることは 定義 15.7.2 のところで見たとおりで，副情報の値打ちを測った 15.4 節 の評価がそこから効く．

::: corollary 15.7.8 記憶による増分の上界
$m \ge 1$ とし，$\mathcal X$ を株価比（定義 15.1.1）からなる空でない有限集合，$\dots, X_{-1}, X_0, X_1, \dots$ を $\mathcal X$ に値をとる両側の列，$k \ge 0$ を整数とする．このとき
$$
W_k - W_0 \;\le\; I\big(X_0;\, (X_{-1}, \dots, X_{-k})\big)
$$
である（$W_k$ は 定義 15.7.2 のもの，$I$ は 定義 1.3.1 の相互情報量である）．
:::

::: proof
$Y := (X_{-1}, \dots, X_{-k})$ とおく．$Y$ は空でない有限集合 $\mathcal X^{k}$ に値をとる．これを 定義 15.4.1 の $\mathcal Y$ にとり，$p(h) := \Pr[Y = h]$ とおくと，$p$ は $\mathcal X^{k}$ 上の分布である．$p(h) > 0$ を満たす $h$ については $p(\cdot \mid h)$ を 定義 15.7.2 の $p_h$ とし，$p(h) = 0$ を満たす $h$ については $p(\cdot \mid h)$ を $\mathcal X$ の元を一つ選んだ一点分布とすると，どれも $\mathcal X$ 上の分布であり，どちらの場合も $p(h)\,p(x \mid h) = \Pr[Y = h,\; X_0 = x]$ だから，これが対 $(X_0, Y)$ の同時分布である．すなわち 定義 15.4.1 と 定義 15.4.2 の設定がそろう．

二つの最適倍加率（定義 15.4.2）を読み替える．$W^{*}(X_0 \mid Y)$ の和のうち $p(h) = 0$ の項は $0$ で，残る項は $p(h)\max_b W(b, p_h)$，すなわち 定義 15.7.2 の和の項そのものだから，$W^{*}(X_0 \mid Y) = W_k$ である．いっぽう 定義 15.4.2 の周辺分布は $\sum_{h} p(h)\,p(x \mid h) = \Pr[X_0 = x]$，すなわち $X_0$ の分布 $p_0$ だから，命題 15.7.3 より $W^{*}(X_0) = \max_b W(b, p_0) = W_0$ である．

そこで 系 15.4.4 を対 $(X_0, Y)$ に当てれば主張を得る．
:::

::: formalization-note
系 15.7.8 に対応する単独の宣言はない．合成で得るには，定義 15.7.2 の $W_k$ にあたる `condOptGrowth` (`InformationTheory/Shannon/Portfolio/StationaryWinfty.lean`) と，定義 15.4.1 の条件付き倍加率にあたる `condGrowthRate` (`InformationTheory/Shannon/Portfolio/SideInformation.lean`) とを結ぶ段が要るが，両方を結論に含む宣言を結論の形で探して見つからなかった．系 15.4.4 の側に単独の宣言がないことは，そちらに書いたとおりである．
:::

例 15.7.7 の市場で $k = 1$ ととって両辺を計算する．左辺の増分は $\frac25 - 0.0849\ldots = 0.3150\ldots$ である．右辺に移ると，$X_0$ は $2$ 点上の一様分布だから 定理 1.1.5 の等号の場合にあたり $H(X_0) = 1$ である．$X_{-1}$ を与えたときの $X_0$ の分布は，例 15.7.7 の証明のとおり，どちらの条件のもとでも一方に $9/10$，他方に $1/10$ を与える．条件付きエントロピー（定義 1.2.2）は各条件のもとのエントロピーの平均だから $H(X_0 \mid X_{-1}) = H_b(1/10) = 0.4689\ldots$ であり（$H_b$ は 例 1.1.2 の二値エントロピー関数である），定理 1.3.4 より $I(X_0; X_{-1}) = 1 - H_b(1/10) = 0.5310\ldots$ となる．たしかに増分のほうが小さい．副情報の値打ちを測った 15.4 節 の評価は，副情報が外から来るのではなく市場自身の過去であるときにも，そのまま効いている．

## 記憶をいくらでも深くしたとき

$W_\infty$ は定義のうえでは上限にすぎず，どれか一つの戦略が実際にその速さで資産を増やすとは，ここまでのどの主張も言っていない．言えることを二つ借りる．本節が列のエルゴード性を使うのは，この二つだけである．

一つめは **無限の過去を使う戦略の収束** である．借りる形は次のとおりである．$\mathcal X$ を株価比（定義 15.1.1）からなる空でない有限集合とし，$\mathcal X$ に値をとる両側の定常列 $\dots, X_{-1}, X_0, X_1, \dots$ がエルゴード的であるとする．このとき，無限の過去 $(X_{-1}, X_{-2}, \dots)$ の各実現にポートフォリオを一つ割り当てる規則 $b^{*}_\infty$ で，第 $i$ 期にそのときまでの過去を当てて $b^{*}_\infty(X_{i-1}, X_{i-2}, \dots)$ を使い続けると，確率 $1$ で
$$
\frac1n \sum_{i=0}^{n-1} \log\Big( \sum_{j=1}^{m} b^{*}_\infty(X_{i-1}, X_{i-2}, \dots)(j)\, X_i(j) \Big)
  \;\longrightarrow\; W_\infty
$$
となるものが存在する．当てる対象は 定義 15.7.6 の $W_\infty$ だけで，使うのはこのあとの筋書きの中だけだから，本書の主張がこれに依拠することはない．規則 $b^{*}_\infty$ を一つ決めてしまえば，時間平均が収束すること自体は 15.6 節 が借りた Birkhoff の個別エルゴード定理の当たる形になる．借用が言い足しているのは，そのような規則がとれることと，行き先が $W_\infty$ であることの二つである．

::: formalization-note
この言明をそのまま述べる単独の宣言はない．存在と収束を一本にまとめた宣言 `stationaryInfPast_logOptimal_growth_tendsto_condOptGrowthInfty` (`InformationTheory/Shannon/Portfolio/StationaryWinfty.lean`) はあるが，その結論に置かれているのは，ポートフォリオの規則の族と一つの規則が存在して後者の時間平均が前者から作った値に収束する，という形であって，収束先が 定義 15.7.6 の $W_\infty$ であることは結論に現れない．族のほうには結論のどこにも条件が付いていないので，定数のポートフォリオを並べた族をとれば収束先はその定数の倍加率になり，Birkhoff の個別エルゴード定理だけでこの形が満たされてしまう．上の言明にあたるものは四つを合わせて得られる．深さごとの規則の族の存在 `exists_condLogOptimalSeq`，無限の過去を与えたときの対数最適ポートフォリオを割り当てる規則の存在 `exists_infPast_condLogOptimal`，後者の $1$ 期あたりの期待対数収益が $W_\infty$ に等しいこと `condOptGrowthInfty_eq_integral_infPast`（三つとも同じファイルにある），および 15.6 節 が借りた Birkhoff の個別エルゴード定理 `birkhoff_ergodic_ae` (`InformationTheory/Shannon/BirkhoffErgodic.lean`) である．三つめは族の可測性・単体への帰属・条件付き支配を仮定として受け取るので，一つめがそれを供給する．
:::

二つめは **記憶が伸びる戦略の収束** である．同じ設定で，第 $i$ 期に深さ $i$ の条件付き対数最適ポートフォリオ（定義 15.7.2）を，そのときまでに出た $i$ 期ぶんの株価比に当てて使う戦略をとる．すなわち第 $0$ 期は $b^{*}_0$，第 $1$ 期は $b^{*}_1(X_0)$，第 $2$ 期は $b^{*}_2(X_1, X_0)$，と深さを一つずつ伸ばしていく．この戦略についても，確率 $1$ で
$$
\frac1n \sum_{i=0}^{n-1} \log\Big( \sum_{j=1}^{m} b^{*}_i(X_{i-1}, \dots, X_0)(j)\, X_i(j) \Big)
  \;\longrightarrow\; W_\infty
$$
となる．当てる対象は 定義 15.7.2 の $b^{*}_k$ と 定義 15.7.6 の $W_\infty$ だけで，本書のどの主張もこれを使わない．章の結論として述べるだけである．

本書はこの二つを証明しない．二つめの筋書きは上下からの挟み撃ちで，どちらの向きも資産の比を作り，補題 3.5.3（期待値が $1$ で抑えられた比は $\frac1n\log$ の尺度では消える）を当てる．そこで要るのは比の期待値の評価だが，本書が用意している評価は，分布を一つ固定した $1$ 期ぶんの 定理 15.3.1 だけで，各期のそのときまでの過去で条件付けた形のものは述べていない．

上からは，記憶が伸びる戦略の資産を，$b^{*}_\infty$ を使い続けたときの資産で割る．第 $i$ 期の分子が使う $b^{*}_i(X_{i-1}, \dots, X_0)$ は分母が条件付けている無限の過去で決まるので，条件付けた形の 定理 15.3.1 が当たって比の期待値は $1$ を超えず，補題 3.5.3 と一つめの借用とを合わせて上からの評価が $W_\infty$ になる．

下からは，深さ $k$ を固定した戦略の資産を，記憶が伸びる戦略の資産で割る．こちらは比の期待値が $1$ 以下だとは言えない．第 $i$ 期に深さ $k$ の戦略が見る $(X_{i-1}, \dots, X_{i-k})$ は，$i < k$ のとき，記憶が伸びる戦略が見ている $(X_{i-1}, \dots, X_0)$ に入っていないからである．実際，例 15.7.7 の市場で $k \ge 1$ とし，第 $0$ 期だけをとってみる．定義 15.7.2 が一つ選ぶポートフォリオとして，深さ $0$ には 例 15.2.6 の対数最適ポートフォリオを，深さ $k$ には 例 15.7.7 の証明が挙げたもの，すなわち $X_{-1}$ が上向きなら全額を銘柄 $2$ に，下向きなら全額を銘柄 $1$ に寄せたものをとる．資産倍率は，分母のほうが $x_\uparrow$ で $3/2$，$x_\downarrow$ で $3/4$（例 15.1.6 の計算），分子のほうが $X_{-1}$ の向きに応じて $2$ と $1/2$，またはどちらでも $1$ だから，比は $X_{-1}$ と $X_0$ がそろったとき $4/3$，食い違ったとき $2/3$ である．そろう確率は $9/10$ だから，期待値は $\frac9{10}\cdot\frac43 + \frac1{10}\cdot\frac23 = \frac{19}{15}$ になる．

そこで第 $i$ 期を $i \ge k$ のところだけ取り出す．$i \ge k$ なら深さ $k$ の戦略が見る $k$ 個は記憶が伸びる戦略の見る $i$ 個に入るので，条件付けた形の 定理 15.3.1 が当たり，比の期待値は $1$ を超えない．落とした最初の $k$ 期ぶんの対数収益は，$\mathcal X$ が有限で株価比がどれも正だから $n$ に依らない量で抑えられ，$\frac1n$ の尺度では消える．こうして下からの評価は深さ $k$ の戦略の時間平均以上になり，その時間平均には 15.6 節 が借りた Birkhoff の個別エルゴード定理が当たって $W_k$ に行き着く．$k$ はいくらでも大きくとれるので，命題 15.7.5 と合わせて下からの評価も $W_\infty$ になる．

足りないのは，各期のそのときまでの過去で条件付けた形の 定理 15.3.1 の一点である．

::: formalization-note
記憶が伸びる戦略の収束をそのまま述べる単独の宣言はない．これにあたる宣言 `growingMemory_logWealth_tendsto_condOptGrowthInfty` (`InformationTheory/Shannon/Portfolio/StationaryWinftyAEP.lean`) はあるが，深さごとの規則の族と，無限の過去を与えたときの対数最適ポートフォリオを割り当てる規則とを，仮定として受け取る形をしている．後者の存在は本書が借りたものであって本書が示したものではない．宣言はさらに，時計を進める写像と過去との噛み合いについての可測性を仮定に置く．いっぽう筋書きで足りないと言った，過去で条件付けた形の 定理 15.3.1 は，本書が述べていないだけで形式化はされている．無限の過去で条件付けたほうは公開された宣言 `condKuhnTucker_infPast` (`InformationTheory/Shannon/Portfolio/StationaryWinfty.lean`) で，無限の過去についての条件付き対数最適ポートフォリオを分母にとると，過去で決まるどのポートフォリオの規則についても，資産倍率の比の条件付き期待値が $1$ 以下であることを述べる．有限の深さで条件付けたほうは `stagewise_condKuhnTucker` (`InformationTheory/Shannon/Portfolio/StationaryWinftyAEP.lean`) で，深さを $K \le i$ に制限した形をしているのが，筋書きが $i \ge k$ の期だけを取り出したところにあたる．こちらは上の宣言の証明の中の足場で，公開された宣言にはなっていない．
:::

$W_\infty$ は，市場の記憶をどこまでも使ってよいときの $1$ 期あたりの増え方であり，記憶が伸びる戦略の収束によれば，過去を全部覚えなくても，覚える期数を一つずつ伸ばしていくだけでそこに届く．例 15.7.7 で見たとおり，同じ市場に同じ額を置いても行き先が変わるのは市場のせいではなく運用の仕方のせいだった．その運用の仕方でどこまで行けるかという問いに，借りた二つが $W_\infty$ という答えを与えていることになる．ただしここまでの最良の戦略はどれも，分布を知っている者のものである．$b^{*}$ を組むには $p$ が，$b^{*}_k$ を組むには条件付き分布が要る．ここまでの本章は，市場に分布を置き，株価比を確率変数として扱ってきた．15.8 節 はその枠組みを離れる．
