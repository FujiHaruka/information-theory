# 15.6 定常エルゴード市場

15.5 節 は市場が i.i.d. であることを仮定した．けれども，きのう上げた銘柄がきょうも上げやすいという市場を締め出す理由はない．第3章は情報源について同じ道を通っている．定常性（定義 3.1.1）は時計をどこに合わせても分布が同じだと言うだけで記憶を禁じておらず，そこにエルゴード性（定義 3.4.1）を足すと，$1$ 本の系列に沿った時間平均が期待値に一致した．市場にも同じ二つの仮定を置く．大数の強法則の代わりに Birkhoff の個別エルゴード定理を当てれば，固定したポートフォリオの $1$ 期あたりの増え方が確率 $1$ で決まる．そして決まった行き先は，第 $0$ 期の株価比の分布だけで書ける．

本節は株価比の列を第3章にならって $X_0, X_1, X_2, \dots$ と第 $0$ 期から数える．定義 15.1.3 は第 $1$ 期から数えたが，番号の付け替えだけである．また 定義 3.1.1 と 定義 3.4.1 は有限アルファベットに値をとる列について述べたもので，本章の $\mathcal X$ も空でない有限集合だから，その元が数ではなく関数であることはここでは効かない．

道具は第3章 3.4 節で借りた **Birkhoff の個別エルゴード定理** である．形は「エルゴード的な定常情報源では，実現の関数の時間平均がその期待値に確率 $1$ で収束する」で，当てる相手は，値がふたたび確率変数になり，確率 $1$ で有限で，絶対値の期待値が有限であるような系列の関数である．本節が当てるのは，有限集合 $\mathcal X$ に値をとるエルゴード的な定常列と，その第 $0$ 期の株価比だけで決まる資産倍率の対数で，第3章が宣言した当てる相手と同じ形をしている．本節でこれを直接借りるのは 定理 15.6.1 の証明だけで，ほかの主張はすべて 定理 15.6.1 を経由してのみこの道具に依存する．節の外では，15.7 節 が借りる無限の過去を使う戦略の収束と記憶が伸びる戦略の収束の筋書きが，この定理を当てる．そこで当てる関数は第 $0$ 期の株価比だけでは決まらず，無限の過去や直前の有限期の株価比にも依るが，系列の関数であることに変わりはないので，上に書いた当てる相手の中にとどまる．以下で $\sigma$ と書くのは 定義 3.4.1 のシフト，すなわち系列の先頭の $1$ 文字を捨てる写像である．本書はこの定理を証明しない．そのことと，無条件の機械検証済みの定理として形式化されていることは，第3章 3.4 節 が書き分けたとおりである．

::: theorem 15.6.1 時間平均と期待値の一致
$m \ge 1$ とし，$\mathcal X$ を株価比（定義 15.1.1）からなる空でない有限集合，$b$ をポートフォリオ（定義 15.1.2）とする．$\mathcal X$ に値をとる列 $X_0, X_1, X_2, \dots$ が定常（定義 3.1.1）でエルゴード的（定義 3.4.1）であるとき，確率 $1$ で
$$
\lim_{n \to \infty} \frac1n \sum_{i=0}^{n-1} \log\Big( \sum_{j=1}^{m} b(j)\, X_i(j) \Big)
  \;=\; \mathbb E\Big[ \log \sum_{j=1}^{m} b(j)\, X_0(j) \Big]
$$
が成り立つ．
:::

::: proof
$\mathcal X$ の元の列 $x = (x_0, x_1, x_2, \dots)$ に
$$
f(x) \;:=\; \log\Big( \sum_{j=1}^{m} b(j)\, x_0(j) \Big)
$$
を返す関数 $f$ をとる．補題 15.1.5 より，どの $x_0 \in \mathcal X$ でも $\sum_{j} b(j)\,x_0(j)$ は正だから $f$ は定まる．$f(X)$ は $X_0$ だけの関数で $X_0$ は $\mathcal X$ に値をとる確率変数だから，$f(X)$ もまた確率変数である．$\mathcal X$ は有限だから $f$ のとりうる値は有限個であり，とくに確率 $1$ で有限で，絶対値の期待値も有限である．

$\sigma^i$ は先頭の $i$ 文字を捨てる写像だから，$\sigma^i X$ の第 $0$ 期の株価比は $X_i$ であり，$f(\sigma^i X) = \log\sum_{j} b(j)\,X_i(j)$ である．借りた Birkhoff の個別エルゴード定理を $f$ に当てると，確率 $1$ で $\frac1n \sum_{i=0}^{n-1} f(\sigma^i X) \to \mathbb E[f(X)]$ となり，これが主張の等式である．
:::

::: formalized
`seqLogWealth_div_tendsto_stationary` (`InformationTheory/Shannon/Portfolio/StationaryMarket.lean`)
:::

::: formalization-note
形式化は同じ時間平均を，第 $0$ 期から第 $n$ 期までの $n+1$ 項を $n+1$ で割る形で書く．添字の付け替えだけで，収束することも収束先も変わらない．また宣言は一般の測度空間の上の測度保存エルゴード写像と，その上の可積分な観測について述べており，本文が有限集合に値をとる定常列に限っているのはその特別な場合である．可積分性は宣言の明示的な仮定だが，本文の設定では上の証明のとおり，とりうる値が有限個であることから出る．
:::

::: corollary 15.6.2 周辺分布による極限の表示
$m \ge 1$ とし，$\mathcal X$ を株価比（定義 15.1.1）からなる空でない有限集合，$b$ をポートフォリオ（定義 15.1.2）とする．$\mathcal X$ に値をとる列 $X_0, X_1, X_2, \dots$ が定常（定義 3.1.1）でエルゴード的（定義 3.4.1）であり，$p_0$ が $X_0$ の分布であるとき，確率 $1$ で
$$
\lim_{n \to \infty} \frac1n \sum_{i=0}^{n-1} \log\Big( \sum_{j=1}^{m} b(j)\, X_i(j) \Big)
  \;=\; W(b, p_0)
$$
が成り立つ（$W$ は 定義 15.1.4 の倍加率である）．
:::

::: proof
定理 15.6.1 の右辺を書き下す．$X_0$ は $\mathcal X$ の元しかとらず，その分布は $p_0$ だから，期待値は
$$
\mathbb E\Big[ \log \sum_{j=1}^{m} b(j)\, X_0(j) \Big]
  \;=\; \sum_{x \in \mathcal X} p_0(x) \log\Big( \sum_{j=1}^{m} b(j)\, x(j) \Big)
$$
という有限和になる．右辺は 定義 15.1.4 の $W(b, p_0)$ そのものである．
:::

::: formalization-note
定理 15.6.1 の紐付け先が極限に置くのは空間平均としての積分であって，定義 15.1.4 の倍加率にあたる `growthRate` (`InformationTheory/Shannon/Portfolio/Basic.lean`) ではない．二つが同じ値であることを述べる宣言はない．`stationaryLogReturn` (`InformationTheory/Shannon/Portfolio/StationaryMarket.lean`) の積分と `growthRate` の両方を結論に含む宣言を，結論の形で探して見つからなかった．系 15.6.2 に対応する単独の宣言もない．
:::

**記憶がどこに現れないか.** 系 15.6.2 の右辺は，第 $0$ 期の株価比の分布 $p_0$ だけで書かれている．列がどんな記憶をもつか，すなわち $X_0$ と $X_1$ がどう絡んでいるかは，右辺に入る余地がない．周辺分布が同じ市場をいくつ並べても，固定したポートフォリオの行き先として 系 15.6.2 が指すのは同じ値である．しかもその値は 定義 15.1.4 の倍加率そのものだから，どの固定ポートフォリオを選ぶべきかという問いは，周辺分布 $p_0$ を分布とする市場についての 15.2 節 の問いに帰着する．その帰着を書いたのが次である．

::: corollary 15.6.3
$m \ge 1$ とし，$\mathcal X$ を株価比（定義 15.1.1）からなる空でない有限集合，$b$ をポートフォリオ（定義 15.1.2）とする．$\mathcal X$ に値をとる列 $X_0, X_1, X_2, \dots$ が定常（定義 3.1.1）でエルゴード的（定義 3.4.1）であり，$p_0$ が $X_0$ の分布であるとし，$b^\circ$ を分布 $p_0$ についての対数最適ポートフォリオ（定義 15.2.3）とする．このとき確率 $1$ で二つの時間平均
$$
\frac1n \sum_{i=0}^{n-1} \log\Big( \sum_{j=1}^{m} b(j)\, X_i(j) \Big),
\qquad
\frac1n \sum_{i=0}^{n-1} \log\Big( \sum_{j=1}^{m} b^\circ(j)\, X_i(j) \Big)
$$
はともに収束し，前者の極限は後者の極限以下である．
:::

::: proof
系 15.6.2 をポートフォリオ $b$ と $b^\circ$ にそれぞれ当てると，二つの確率 $1$ の事象が得られる．有限個の確率 $1$ の事象の共通部分は確率 $1$ だから，その共通部分の上では二つの極限が同時に存在して $W(b, p_0)$ と $W(b^\circ, p_0)$ に等しい．定義 15.2.3 より $W(b, p_0) \le W(b^\circ, p_0)$ だから，不等式が従う．
:::

::: formalization-note
系 15.6.3 に対応する単独の宣言はない．時間平均が収束することは 定理 15.6.1 の紐付け先が与え，二つの $1$ 期あたりの対数収益の期待値のあいだの不等式は `stationaryLogReturn_integral_le_of_kuhnTucker` (`InformationTheory/Shannon/Portfolio/StationaryMarket.lean`) が単独で述べていて，二つを合わせれば得られる．後者の宣言は一般の測度空間について述べたもので，本文が 系 15.6.2 と 定義 15.2.3 で済ませた段を，資産倍率の比の積分を経由して直に証明している．$b^\circ$ に課すのも対数最適性ではなく 15.2 節 の Kuhn–Tucker 条件で，しかも本文の有限和ではなく積分の形である．本文の対数最適性からその条件が出ることは 定理 15.2.5 が与える．資産倍率の正値性と三種類の可積分性は宣言の明示的な仮定だが，前者は 定義 15.1.1 の正値性から，後者は $\mathcal X$ が有限で対数も比も有限個の値しかとらないことから出る．
:::

次の例で見たいのは 系 15.6.2 の右辺の値だけである．この列がエルゴード的であることについては，第3章 3.4 節 が，どの状態からどの状態へも有限歩で到達できるマルコフ情報源はエルゴード的だと述べているものの，そこに書いてあるとおり本書はそれを証明せず，形式化もしていない．だから 系 15.6.2 そのものをこの市場に当てるところまでは行かない．例に現れる $\alpha$，$\beta$ は 例 3.1.5 の遷移確率のほうで，15.2 節 が断った二つのうちの，銘柄 $2$ への配分ではない．

::: example 15.6.4 記憶のあるマルコフ市場でも倍加率は変わらない
例 15.1.6 の二つの株価比 $x_\uparrow$，$x_\downarrow$ を状態とし，例 3.1.5 のマルコフ情報源で状態 $0$，$1$ をそれぞれ $x_\uparrow$，$x_\downarrow$ と読み替え，$\alpha = \beta = 1/10$ としたものをとる．すなわち，どちらの状態からも確率 $9/10$ で同じ状態にとどまり，確率 $1/10$ でもう一方に移る．初期分布を定常分布にとると，この列は定常（定義 3.1.1）であり，$X_0$ の分布 $p_0$ は 例 15.1.6 の $p$，すなわち $\{x_\uparrow, x_\downarrow\}$ 上の一様分布に等しい．したがって，どのポートフォリオ（定義 15.1.2）$b$ についても $W(b, p_0)$（定義 15.1.4）は 例 15.1.6 の市場のそれと同じ値であり，その最大は $\frac12\log\frac98 = 0.0849\ldots$ である．いっぽうこの列は i.i.d. ではなく，$\Pr[X_1 = x_\uparrow \mid X_0 = x_\uparrow] = 9/10$ である一方で $\Pr[X_1 = x_\uparrow] = 1/2$ である．
:::

::: proof
例 3.1.5 の定常分布は $\mu(x_\uparrow) = \beta/(\alpha+\beta)$，$\mu(x_\downarrow) = \alpha/(\alpha+\beta)$ で，$\alpha = \beta = 1/10$ だからどちらも $1/2$ である．初期分布を $\mu$ にとれば，命題 3.1.4 よりこの列は定常であり，定義 3.1.3 を $n = 1$ に使えば $X_0$ の分布は $\mu$ である．これは 例 15.1.6 の $p$ に等しい．定義 15.1.4 より $W(b, p_0)$ は $\mathcal X$ と $p_0$ だけで決まるから，$b$ を動かして得られる値は 例 15.1.6 の市場のそれと同じである．その最大が $\frac12\log\frac98$ であることは，例 15.2.6 が $b(1) = b(2) = 1/2$ を対数最適ポートフォリオと定めており，例 15.1.6 がその倍加率を $\frac12\log\frac98$ と計算していることによる．

記憶があることを見る．定義 3.1.3 を $n = 2$ に使うと $\Pr[X_0 = x_\uparrow,\, X_1 = x_\uparrow] = \mu(x_\uparrow)\,P(x_\uparrow, x_\uparrow) = \frac12 \cdot \frac9{10}$ であり，$\Pr[X_0 = x_\uparrow] = \frac12$ だから，条件付き確率は $\frac9{10}$ である．いっぽう列は定常だから，定義 3.1.1 を $n = 1$，$\ell = 1$ に使って $\Pr[X_1 = x_\uparrow] = \Pr[X_0 = x_\uparrow] = \frac12$ である．
:::

それでも例が見せているものははっきりしている．この市場は記憶をもつ．直前が上向きなら次も確率 $9/10$ で上向きで，$X_0$ と $X_1$ は独立ではない．ところが 系 15.6.2 の右辺は，記憶のない 例 15.1.6 の市場のそれと一つも変わらない．系 15.6.2 の右辺は周辺分布だけで決まり，記憶の効き方はそこに現れない．そこで 15.7 節 は，それまでに出た株価比を見て組み替える戦略に移る．
