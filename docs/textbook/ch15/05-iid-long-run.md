# 15.5 i.i.d. 市場での長期のふるまい

ここまでの倍加率は，どれも $1$ 期あたりの期待値である．期待値が大きいことと，実際に手元の資産が増えることは別の話で，測り方を変えれば順位も変わりうることは第5章 例 5.2.4 が見せたとおりである．第5章 5.5 節 は競馬についてこの隔たりを埋め，レースが独立に同じ分布で繰り返されるなら資産の増え方が確率 $1$ で倍加率そのものになることを示した．$1$ レースの資産の期待値ではなく倍加率を賭け方の良さの尺度に選んだのは，そのためだった．市場でも同じ運びが通る．違うのは $1$ 期の倍率が積から和になったところだけで，対数をとって和に直したあとの議論はそのままである．

道具は第2章 2.1 節で借りた **大数の強法則** である．形は「i.i.d. で期待値をもつ確率変数列の相加平均は，期待値に概収束する」，すなわち確率 $1$ の事象の上で各点収束するというもので，当てる相手は有限アルファベット上の i.i.d. な列から作った有界な確率変数の相加平均である．本節が当てるのは，有限集合 $\mathcal X$ に値をとる i.i.d. な株価比の列から作った資産倍率の対数の相加平均で，第2章が宣言した当てる相手と同じ形をしている．主張の証明でこれを直接借りるのは 定理 15.5.1 だけで，本節のほかの主張はすべて 定理 15.5.1 を経由してのみこの道具に依存する．ほかに用いるのは，極限と対数についての微積分の初等規則と，有限個の確率 $1$ の事象の共通部分がまた確率 $1$ であることだけである．

## 増え方は倍加率になる

::: theorem 15.5.1
$m \ge 1$ とし，$\mathcal X$ を株価比（定義 15.1.1）からなる空でない有限集合，$p$ を $\mathcal X$ 上の分布，$b$ をポートフォリオ（定義 15.1.2）とする．株価比の列 $X_1, X_2, \dots$ が i.i.d. で，各 $X_i$ が分布 $p$ に従うとき，確率 $1$ で
$$
\lim_{n \to \infty} \frac1n \log S_n(b) \;=\; W(b, p)
$$
が成り立つ（$S_n(b)$ は 定義 15.1.3 の資産，$W$ は 定義 15.1.4 の倍加率である）．
:::

::: proof
第5章 定理 5.5.1 の証明がそのまま通る．$1$ レースの倍率，すなわち勝ち馬に賭けた比率とそのオッズとの積を，資産倍率 $\sum_{j=1}^{m} b(j)\,X_i(j)$ に置き換えるだけでよく，市場の側で増えるのは，定義 15.1.3 の積の各因子が正であることを 補題 15.1.5 で確かめる一行である．すなわち対数をとって
$$
\log S_n(b) \;=\; \sum_{i=1}^{n} \log\Big( \sum_{j=1}^{m} b(j)\, X_i(j) \Big)
$$
と和に直すと，各項は $X_i$ だけの関数だからこの列は i.i.d. であり，値は有限個の数 $\log\sum_{j} b(j)x(j)$（$x \in \mathcal X$）のどれかだから有界で，期待値は 定義 15.1.4 の $W(b, p)$ である．$\frac1n \log S_n(b)$ はこの列の相加平均だから，大数の強法則を当てると $W(b, p)$ に概収束し，確率 $1$ の事象の上で主張の等式が成り立つ．
:::

::: formalized
`seqLogWealth_div_tendsto_growthRate` (`InformationTheory/Shannon/Portfolio/OperationalSequences.lean`)
:::

::: formalization-note
形式化は株価比の列に，相互独立ではなく対ごとの独立と同分布性だけを求めている．結論の右辺に現れる分布は，株価比の像測度から作った `lawPmf` (`InformationTheory/Shannon/Gambling/OperationalSequences.lean`) である．
:::

**規模感.** 定理 15.5.1 は $\frac1n \log S_n(b)$ が $W(b, p)$ に近づくと言っているので，$n$ の大きいところでは $\log S_n(b)$ はおよそ $n\,W(b, p)$ である．例 15.1.6 の市場が i.i.d. に繰り返されるとして，半々にとったポートフォリオをとると $W(b, p) = 0.0849\ldots$ だから，この速さがそのまま続くとすれば $100$ 期後の $\log S_{100}(b)$ はおよそ $8.50$，すなわち資産はおよそ $361$ 倍という勘定になる．$1$ 期あたりでは $0.08$ という小さな値でも，掛け算で積み上がるとこの規模になる．ただし 定理 15.5.1 が述べているのは極限だけで，有限の $n$ でこの値からどれだけ散らばるかは本書では与えない．これは規模の見当であって，$100$ 期後の資産がこの値の近くにあるという主張ではない．

## 対数最適ポートフォリオは長い目で見ても最適

::: corollary 15.5.2
$m \ge 1$ とし，$\mathcal X$ を株価比（定義 15.1.1）からなる空でない有限集合，$p$ を $\mathcal X$ 上の分布，$b$ と $b^\circ$ をポートフォリオ（定義 15.1.2）とし，$b^\circ$ はすべての $j \in \{1, \dots, m\}$ について
$$
\sum_{x \in \mathcal X} p(x)\, \frac{x(j)}{\sum_{k=1}^{m} b^\circ(k)\,x(k)} \;\le\; 1
$$
を満たすものとする．株価比の列 $X_1, X_2, \dots$ が i.i.d. で，各 $X_i$ が分布 $p$ に従うとき，確率 $1$ で $\frac1n \log S_n(b)$ と $\frac1n \log S_n(b^\circ)$ はともに収束し，
$$
\lim_{n \to \infty} \frac1n \log S_n(b) \;\le\; \lim_{n \to \infty} \frac1n \log S_n(b^\circ)
$$
が成り立つ（$S_n(b)$ は 定義 15.1.3 の資産である）．
:::

::: proof
定理 15.5.1 をポートフォリオ $b$ と $b^\circ$ にそれぞれ当てると，二つの確率 $1$ の事象が得られる．有限個の確率 $1$ の事象の共通部分は確率 $1$ だから，その共通部分の上では二つの極限が同時に存在して $W(b, p)$ と $W(b^\circ, p)$ に等しい．仮定の $m$ 本の不等式は 定理 15.2.4 の Kuhn–Tucker 条件だから，同定理より $W(b, p) \le W(b^\circ, p)$ であり，不等式が従う．
:::

::: formalized
`seqLogWealth_asymptotically_optimal` (`InformationTheory/Shannon/Portfolio/OperationalSequences.lean`)
:::

系 15.5.2 は 定理 15.2.4 を実際の資産の言葉に翻訳したものである．定理 15.2.4 は期待値どうしの比較だったので，たまたま今回は別のポートフォリオが勝つことを排除していなかった．系 15.5.2 は，$n$ を大きくしたときの増え方については確率 $1$ でその追い越しが起きないと言っている．比べているのは，毎期同じ比率に配分し直すポートフォリオどうしである．ここで確率 $1$ の事象はポートフォリオ $b$ ごとに定まる．系 15.5.2 の証明が交わしているのは二つの事象だけなので，すべてのポートフォリオを同時に覆う一つの事象があるとまでは言えていない．すべてのポートフォリオを同時に覆う版が要るなら，第5章 5.5 節 が競馬について書いたのと同じく，各株価比の指示変数の相加平均，すなわち経験頻度に大数の強法則を当てて，$\lvert\mathcal X\rvert$ 個の確率 $1$ の事象を交わせばよい．$\mathcal X$ は有限だから，これも有限個の共通部分で済む．本書はこの版を主張として立てない．

## 符号で決まる二つの行き先

::: corollary 15.5.3
$m \ge 1$ とし，$\mathcal X$ を株価比（定義 15.1.1）からなる空でない有限集合，$p$ を $\mathcal X$ 上の分布，$b$ をポートフォリオ（定義 15.1.2）とする．株価比の列 $X_1, X_2, \dots$ が i.i.d. で，各 $X_i$ が分布 $p$ に従うとき，$W(b, p) > 0$ ならば確率 $1$ で $\log S_n(b) \to +\infty$ であり，したがって確率 $1$ で資産 $S_n(b)$ は限りなく大きくなる．$W(b, p) < 0$ ならば確率 $1$ で $\log S_n(b) \to -\infty$ であり，したがって確率 $1$ で $S_n(b)$ は $0$ に近づく（$S_n(b)$ は 定義 15.1.3 の資産，$W$ は 定義 15.1.4 の倍加率である）．
:::

::: proof
$n \ge 1$ について $\log S_n(b) = n \cdot \frac1n \log S_n(b)$ と書く．定理 15.5.1 より確率 $1$ の事象の上で $\frac1n \log S_n(b) \to W(b, p)$ だから，その事象の上では，正の実数に収束する数列に $n$ を掛けたものが $+\infty$ に発散し，極限が負の実数なら $-\infty$ に発散するという既知の規則により，$W(b,p) > 0$ なら積は $+\infty$ に，$W(b,p) < 0$ なら $-\infty$ に発散する．

資産そのものに読み替える．定義 15.1.3 の各因子は正だから $S_n(b) > 0$ であり，正の数の列については，対数が $+\infty$ に発散することと列そのものが限りなく大きくなることが同じ，対数が $-\infty$ に発散することと列そのものが $0$ に近づくことが同じである．これを上の二つの場合に当てれば後半を得る．
:::

::: formalization-note
系 15.5.3 に対応する単独の宣言はない．定理 15.5.1 の紐付け先に，正の実数に収束する数列に $n$ を掛けると発散するという規則を合わせて得られる．資産そのものへの読み替えにあたる宣言もない．第5章 系 5.5.2 の競馬版には対数についての宣言が二つあるが，市場についてはそれもない．
:::

::: example 15.5.4 現金と株と半々の行き先
例 15.1.6 の市場が繰り返されるとする．すなわち株価比の列 $X_1, X_2, \dots$ が i.i.d. で，各 $X_i$ が 例 15.1.6 の分布 $p$ に従うとする．全額を現金にとったポートフォリオの資産（定義 15.1.3）は，どの $n \ge 0$ についても $1$ である．全額を株にとったポートフォリオの資産は，$n \ge 0$ とし第 $1$ 期から第 $n$ 期までに $x_\uparrow$ が $u$ 回出たとすると，$2^{2u - n}$ である．半々にとったポートフォリオの資産は，確率 $1$ で限りなく大きくなる．
:::

::: proof
全額を現金にとると，資産倍率はどちらの株価比でも $1$ だから，定義 15.1.3 の積の各因子が $1$ で，資産は $1$ である．全額を株にとると，資産倍率は $x_\uparrow$ で $2$，$x_\downarrow$ で $1/2$ だから，$x_\uparrow$ が $u$ 回，$x_\downarrow$ が $n - u$ 回出れば積は $2^{u}\,(1/2)^{n-u} = 2^{2u-n}$ である．半々にとると，例 15.1.6 より倍加率は $\frac12\log\frac98$ であり，$\frac98 > 1$ と対数の単調性（補題 8.2.5）より $\log\frac98 > 0$ だからこれは正である．よって 系 15.5.3 の前半が当たる．
:::

全額を現金にとったものと全額を株にとったものは，どちらも倍加率が $0$ である（例 15.1.6）から，系 15.5.3 の外にある．前者の資産は $1$ から動かず，後者の資産は上向きと下向きの回数の差だけで決まって $2$ の整数乗のあいだを行き来する．$n = 100$ でいえば，上向きが $50$ 回なら資産はちょうど $1$ 倍だが，$40$ 回なら $2^{-20}$，すなわちおよそ $100$ 万分の $1$ 倍，$60$ 回なら $2^{20}$，すなわちおよそ $100$ 万倍である．半々にとったものだけが倍加率が正で，資産が確率 $1$ で限りなく大きくなる．混ぜる前の二つはどちらも 系 15.5.3 が何も言わない側にいるのに，混ぜたものは言い切れる側に移る．
