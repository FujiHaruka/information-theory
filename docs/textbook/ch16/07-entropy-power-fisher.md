# 16.7 エントロピーべきと Fisher 情報量

本節からは第7章の微分エントロピーの上に乗る．微分エントロピー $h(X)$（定義 7.1.2）は目盛の取り替えで動く量で，$X$ を $c$ 倍すると $\log\lvert c\rvert$ だけ増えた（系 7.3.4）．散らばりを測るもう一つの量である分散は，$c$ 倍すると $c^2$ 倍になる．二つを同じ物差しに載せるには，$h$ を $2$ 倍して指数に持ち上げればよい．そうして作った量なら $c$ 倍で $c^2$ 倍になるはずで，実際そうなる（命題 16.7.2）．本節はその量を定めてガウス分布と一様分布で計算し，分散との大小を決める．続いて，密度の傾きの大きさを測る Fisher 情報量を定め，こちらもガウス分布で計算する．二つの量は，独立なガウス雑音を少しずつ足していく道筋の上で結びつく．

16.4 節 で既知とした，$\log$ が正の実数の全体から実数の全体への狭義単調な全単射であることから，どの実数についても，その値を対数にもつ正の実数はただ一つ定まる．

::: definition 16.7.1 エントロピーべき
$X$ を密度をもつ実数値確率変数とし，$h(X)$（定義 7.1.2）が定まるとする．$\log N(X) = 2\,h(X)$ を満たすただ一つの正の実数 $N(X)$ を，$X$ の **エントロピーべき** と呼ぶ．
:::

$N$ はつねに引数をとる．第8章 が雑音の分散に使う裸の $N$ とは別の記号である．定める式は $\log$ の底に依らない．底を取り替えると $h$ も $\log$ も同じ倍率で変わるので，等式の両辺が同じ倍率で変わり，$N(X)$ の値は動かないからである．

::: formalization-note
形式化は $\log$ を自然対数にとるので，この量を $\exp\big(2h(X)\big)$ の形で直に定めている．また形式化は $h$ が定まらない場合にも $h$ に値 $0$ を返す約束なので，そのときこの量は $1$ になる．本文が $N(X)$ を書くのは $h(X)$ が定まる場合だけである．なお Cover–Thomas は $2\pi e$ で割った量を同じ名前で呼ぶので，本書の $N$ はその $2\pi e$ 倍にあたり，割ったほうの値をガウス分布について与える宣言 `entropyPower_div_two_pi_e_gaussianReal` (`InformationTheory/Shannon/EPI/Plumbing.lean`) もある．
:::

::: proposition 16.7.2 定数倍でのふるまい
$X$ を密度をもつ実数値確率変数，$c \ne 0$ を実数とする．$h(X)$ が定まるならば $h(cX)$ も定まり，$N(cX) = c^2\,N(X)$ である．
:::

::: proof
命題 7.3.3 より $h(cX)$ は定まって $h(cX) = h(X) + \log\lvert c\rvert$ である．よって
$$
\log N(cX) \;=\; 2\,h(cX) \;=\; 2\,h(X) + 2\log\lvert c\rvert \;=\; \log N(X) + \log c^2
$$
であり，右辺は $\log\big(c^2 N(X)\big)$ に等しい（$\lvert c\rvert^2 = c^2$ である）．定義 16.7.1 は $N(cX)$ を，対数が $2h(cX)$ に等しいただ一つの正の実数として定めているから，$N(cX) = c^2 N(X)$ である．
:::

::: formalized
`entropyPower_map_mul_const` (`InformationTheory/Shannon/EPI/Plumbing.lean`)
:::

::: formalization-note
宣言は結論の等式だけを述べ，本文の「$h(cX)$ も定まる」にあたる部分は含まない．命題 7.3.3 に紐付けた宣言も同じ形である．
:::

命題 16.7.2 が，$h$ を $2$ 倍して指数に持ち上げた理由である．分散も $c$ 倍で $c^2$ 倍になるので，$N$ と分散は同じ倍率で動く．二つの大小を比べる意味が出てくるのはそのためで，比べた結果は 命題 16.7.5 で出る．

::: example 16.7.3 一様分布のエントロピーべき
$w > 0$ とし，$X$ が長さ $w$ の区間の上の一様分布に従うとすると，$h(X)$ は定まり $N(X) = w^2$ である．
:::

::: proof
例 7.1.3 より $h(X)$ は定まって $h(X) = \log w$ である．よって $2h(X) = \log w^2$ であり，定義 16.7.1 より $N(X) = w^2$ である．
:::

::: proposition 16.7.4 ガウス分布のエントロピーべき
$\mu$ を実数，$\sigma^2 > 0$ とし，$X$ が $\mathcal N(\mu,\sigma^2)$（定義 7.2.1）に従うとすると，$h(X)$ は定まり $N(X) = 2\pi e\,\sigma^2$ である．
:::

::: proof
定理 7.2.2 より $h(X)$ は定まって $h(X) = \frac12\log\big(2\pi e\sigma^2\big)$ である．よって $2h(X) = \log\big(2\pi e\sigma^2\big)$ であり，定義 16.7.1 より主張を得る．
:::

::: formalized
`entropyPower_gaussianReal` (`InformationTheory/Shannon/EntropyPower/Inequality.lean`)
:::

**幅の $2$ 乗として読む.** 7.1 節 は $2^{h(X)}$ をその分布の実効的な幅と読んだ．底を $2$ にとれば $N(X) = 2^{2h(X)}$ はその幅の $2$ 乗である．例 16.7.3 の一様分布では幅が $w$ そのもので $N(X) = w^2$ になり，7.2 節 が幅を $\sqrt{2\pi e}\,\sigma$ と読んだガウス分布では，命題 16.7.4 のとおり $N(X) = 2\pi e\sigma^2$ になる．長さの $2$ 乗の次元をもつという点で，$N$ は分散と同じ物差しの上にある．

分散を固定したときにガウス分布が微分エントロピーを最大にする（定理 7.2.4）ことは，指数に持ち上げてもそのまま残る．

::: proposition 16.7.5 分散による上界
$\sigma^2 > 0$ とし，$X$ を密度をもつ実数値確率変数とする．$h(X)$ が定まり，$X$ が平均をもち，その分散が定まって $\sigma^2$ 以下であるならば $N(X) \le 2\pi e\,\sigma^2$ である．
:::

::: proof
定理 7.2.4 より $h(X) \le \frac12\log\big(2\pi e\sigma^2\big)$ である．両辺を $2$ 倍すると，定義 16.7.1 より左辺は $\log N(X)$ であり，右辺は $\log\big(2\pi e\sigma^2\big)$ である．$\log$ が狭義単調（16.4 節）だから主張を得る．
:::

::: formalization-note
この主張をそのまま述べる単独の宣言はない．定理 7.2.4 に紐付けた宣言と，微分エントロピーの大小をエントロピーべきの大小に移す `entropyPower_le_of_differentialEntropy_le` (`InformationTheory/Shannon/EPI/Plumbing.lean`) の合成で得られる．
:::

この上界が達成されることを見るために，第7章 7.2 節 が借りた **ガウス分布の基本性質** をそのまま引く．すなわち，定義 7.2.1 の関数は実軸の上での積分が $1$ であり，それを密度とする確率変数の平均は $\mu$，分散は $\sigma^2$ であって，$\int_{\mathbb R}(x-\mu)^2\,g_{\mu,\sigma^2}(x)\,dx = \sigma^2$ である．最後の形は，7.2 節 が 定理 7.2.2 の証明で使ったものと同じである．当てる対象は 定義 7.2.1 のガウス分布に従う実数値確率変数だけで，7.2 節 が宣言した射程からは広がらない．依存するのは 系 16.7.6 と 命題 16.7.8 の証明の二つである．7.2 節 と同じく，本書はこの性質を証明しない．

::: corollary 16.7.6
$\mu$ を実数，$\sigma^2 > 0$ とし，$X$ が $\mathcal N(\mu,\sigma^2)$（定義 7.2.1）に従うとすると，$X$ は 命題 16.7.5 の仮定をこの $\sigma^2$ について満たし，その不等式は等号で成り立つ．
:::

::: proof
借りたガウス分布の基本性質より $X$ は平均 $\mu$ をもち，分散は $\sigma^2$ で，これは $\sigma^2$ 以下である．また 定理 7.2.2 より $h(X)$ は定まる．よって 命題 16.7.5 の仮定を満たす．その値は 命題 16.7.4 より $2\pi e\sigma^2$ で，命題 16.7.5 の右辺に等しい．
:::

::: formalization-note
系 16.7.6 に対応する単独の宣言はない．命題 16.7.4 に紐付けた宣言と，ガウス分布の分散を与える `gaussianReal_variance_eq` (`InformationTheory/Shannon/DifferentialEntropy.lean`) を合わせて得られる．
:::

一様分布では等号にならない．例 7.2.6 の証明が求めたとおり，長さ $w$ の区間の上の一様分布の分散は $w^2/12$ である．命題 16.7.5 をこの値でとると上界は $2\pi e\,w^2/12 = (\pi e/6)\,w^2 = 1.4232\ldots\,w^2$ で，例 16.7.3 の $N(X) = w^2$ を確かに上から抑える．比 $\pi e/6$ は，例 7.2.6 が出した微分エントロピーの差 $\frac12\log\frac{\pi e}{6}$ を指数に持ち上げたものである．

ここまでは，密度がどれだけ広がっているかを測ってきた．次に測るのは，密度がどれだけ急に変わるかである．

::: definition 16.7.7 Fisher 情報量
$X$ を密度 $f$ をもつ実数値確率変数とし，$f$ は実軸のすべての点で微分可能かつ正であるとする．$\int_{\mathbb R}\Big(\dfrac{f'(x)}{f(x)}\Big)^2 f(x)\,dx$ が有限であるとき，その値を $X$ の **Fisher 情報量** と呼んで $J(X)$ と書き，このとき $J(X)$ が **定まる** という．
:::

$J$ は Fisher 情報量を表す．第7章 定理 7.1.6 が量子化の分割数に使う $J$ とも，第9章 9.3 節 の同時分布 $J(x,\hat x)$ とも別の記号である．定義 16.7.7 は密度を一つ選んだうえでの量である．被積分関数に現れる $f'/f$ は，密度の増え方をその点の密度自身で割ったもので，密度が急に立ち上がっている点ほど絶対値が大きい．その $2$ 乗を，やはり密度自身で平均している．広がりを測る 定義 16.7.1 と違って，$J$ が見ているのは密度の形の細かさである．

::: formalized
`fisherInfoOfDensity` (`InformationTheory/Shannon/FisherInfo/OfDensity.lean`)
:::

::: formalization-note
形式化も密度を引数として受け取る．分布から取り出した密度は一般に微分可能な代表元にならないためである．値は $[0,\infty]$ にとる約束なので，本文が「定まる」と呼ばなかった場合にも値を返す．定義の中の $f'/f$ は，形式化では対数微分として書かれている．
:::

計算のために **微積分の計算規則** を既知とする．合成関数の微分と指数関数の導関数，$\log t$ の導関数が $(\log e)/t$ であること，$1$ 次式による置換積分，部分積分，$t^2\log t$ が $t \downarrow 0$ で $0$ に近づくこと，連続関数の定積分が原始関数の差に等しいこと（微積分の基本定理），および有限な値に収束する広義積分の扱いである．第7章 7.1 節 と 7.3 節 が同じ資格で借りたものと同じ規則で，当てる対象は，本節と次節の証明に現れる密度と，それに多項式や対数を掛けて作る関数だけである．依存するのは 命題 16.7.8，例 16.7.9，例 16.8.2 の三つの証明である．

::: proposition 16.7.8 ガウス分布の Fisher 情報量
$\mu$ を実数，$\sigma^2 > 0$ とし，$X$ が $\mathcal N(\mu,\sigma^2)$（定義 7.2.1）に従うとすると，$J(X)$ は定まり $J(X) = 1/\sigma^2$ である．
:::

::: proof
定義 7.2.1 の密度 $g_{\mu,\sigma^2}$ は実軸のすべての点で正であり，借りた微積分の計算規則より微分可能で
$$
g_{\mu,\sigma^2}'(x) \;=\; -\frac{x-\mu}{\sigma^2}\,g_{\mu,\sigma^2}(x)
$$
である．よって 定義 16.7.7 の被積分関数は $\dfrac{(x-\mu)^2}{\sigma^4}\,g_{\mu,\sigma^2}(x)$ であり，借りたガウス分布の基本性質より
$$
\int_{\mathbb R}\frac{(x-\mu)^2}{\sigma^4}\,g_{\mu,\sigma^2}(x)\,dx \;=\; \frac{\sigma^2}{\sigma^4} \;=\; \frac{1}{\sigma^2}
$$
である．これは有限だから $J(X)$ は定まり，その値は $1/\sigma^2$ である．
:::

::: formalized
`fisherInfoOfDensity_gaussianPDFReal` (`InformationTheory/Shannon/FisherInfo/OfDensity.lean`)
:::

**二つの量を掛けてみる.** ガウス分布では 命題 16.7.4 より $N(X) = 2\pi e\sigma^2$，命題 16.7.8 より $J(X) = 1/\sigma^2$ だから，積は $\sigma^2$ に依らず $2\pi e$ である．散らばりが大きいほど $N$ は大きく $J$ は小さい，という向きが，ガウス分布では正確に釣り合っている．一般の分布について二つの積がどうなるかを，本書は述べない．

二つの量が結びつくのは，分布を動かしたときである．動かし方として，独立なガウス雑音を少しずつ足していくものをとる．そのために二つ用意する．

熱流を書くには，ガウス雑音を足したものがまたガウス分布に従うことが要る．第9章 9.4 節 が確率変数の言葉で借り直した **ガウス分布の畳み込み** を引く．独立で $\mathcal N(\mu_1,\sigma_1^2)$ と $\mathcal N(\mu_2,\sigma_2^2)$（定義 7.2.1）に従う二つの実数値確率変数の和が $\mathcal N(\mu_1+\mu_2,\ \sigma_1^2+\sigma_2^2)$ に従う，という事実である．9.4 節 は差についても借りたが，本章が使うのは和だけで，射程はそのぶん狭い．あわせて，独立な二つの実数値確率変数の一方に $0$ でない定数を掛けても独立性が保たれることを既知とする．当てる対象は，本節と次節に現れるガウス分布に従う実数値確率変数だけである．依存するのは 例 16.7.9 と 命題 16.8.1 の証明の二つである．9.4 節 と同じく，本書はこの事実を証明しない．

**de Bruijn の恒等式** を借りる．$X$ を密度をもつ実数値確率変数で $2$ 乗の平均をもつもの，$Z$ を $\mathcal N(0,1)$（定義 7.2.1）に従う確率変数とし，$X$ と $Z$ は独立であるとする．このとき $s > 0$ について $X+\sqrt s\,Z$ は密度をもち $J(X+\sqrt s\,Z)$（定義 16.7.7）は定まって，次の二つが成り立つ，という主張である．第一に，$t > 0$ において $s \mapsto h\big(X+\sqrt s\,Z\big)$ は微分可能で，その $t$ での導関数は $\frac{\log e}{2}\,J\big(X+\sqrt t\,Z\big)$ に等しい．第二に，さらに $h(X)$ が定まるならば，$t \ge 0$ について
$$
h\big(X+\sqrt t\,Z\big) - h(X) \;=\; \frac{\log e}{2}\int_0^{t} J\big(X+\sqrt s\,Z\big)\,ds
$$
である．二つは互いに他から出るものではないので，どちらも借りる．当てる対象は，本節の $X+\sqrt s\,Z$ だけである．本書のどの主張もこれを使わない．例 16.7.9 がガウス分布の場合にこれを確かめ，16.8 節 がエントロピーべき不等式の出どころを述べるために引く．本書はこの恒等式を証明しない．積分と微分の順序を入れ替える段が要り，本書はその道具を用意していないからである．

::: example 16.7.9 熱流に沿った微分エントロピー
$\mu$ を実数，$\sigma^2 > 0$ とし，$X$ が $\mathcal N(\mu,\sigma^2)$（定義 7.2.1）に従い，$Z$ が $\mathcal N(0,1)$ に従い，$X$ と $Z$ は独立であるとする．このとき $s \ge 0$ について $h\big(X+\sqrt s\,Z\big)$ は定まって $\frac12\log\big(2\pi e(\sigma^2+s)\big)$ に等しく，次の二つが成り立つ．

1. $t > 0$ において，$s \mapsto h\big(X+\sqrt s\,Z\big)$ は微分可能で，その $t$ での導関数は $\frac{\log e}{2}\,J\big(X+\sqrt t\,Z\big)$ に等しい．
2. $t \ge 0$ について $h\big(X+\sqrt t\,Z\big) - h(X) = \frac{\log e}{2}\int_0^{t} J\big(X+\sqrt s\,Z\big)\,ds$ である．
:::

::: proof
$s > 0$ とする．例 7.3.6 を，掛ける定数 $\sqrt s$，足す定数 $0$ ととって当てると $\sqrt s\,Z$ は $\mathcal N(0,s)$ に従い，ガウス分布の畳み込みとあわせて既知とした定数倍での独立性の保存より，$X$ と $\sqrt s\,Z$ は独立である．借りたガウス分布の畳み込みより $X+\sqrt s\,Z$ は $\mathcal N(\mu,\ \sigma^2+s)$ に従い，定理 7.2.2 より $h(X+\sqrt s\,Z)$ は定まって $\frac12\log\big(2\pi e(\sigma^2+s)\big)$ である．$s = 0$ のときは $X+\sqrt s\,Z = X$ で，同じ式が 定理 7.2.2 そのものである．

1 を示す．借りた微積分の計算規則より，$s \mapsto \frac12\log\big(2\pi e(\sigma^2+s)\big)$ は微分可能で，その $t$ での導関数は $\frac{\log e}{2(\sigma^2+t)}$ である．一方 命題 16.7.8 を $\mathcal N(\mu,\ \sigma^2+t)$ に当てると $J(X+\sqrt t\,Z) = 1/(\sigma^2+t)$ だから，二つは一致する．

2 を示す．借りた微積分の計算規則より $s \mapsto \frac{1}{\log e}\log(\sigma^2+s)$ の導関数は $\frac{1}{\sigma^2+s}$ であり，これは $[0,t]$ の上で連続だから，微積分の基本定理より
$$
\int_0^{t} \frac{ds}{\sigma^2+s} \;=\; \frac{1}{\log e}\Big(\log(\sigma^2+t) - \log\sigma^2\Big)
$$
である．命題 16.7.8 より被積分関数は $J(X+\sqrt s\,Z)$ に等しいので，両辺に $\frac{\log e}{2}$ を掛けると，右辺は $\frac12\log(\sigma^2+t) - \frac12\log\sigma^2$ になる．いっぽう 2 の左辺は，上で求めた値より $\frac12\log\big(2\pi e(\sigma^2+t)\big) - \frac12\log\big(2\pi e\sigma^2\big)$ であり，$\log$ の中の共通の因子 $2\pi e$ が引き算で消えて同じ値になる．
:::

**数で確かめる.** $\sigma^2 = 1$，$t = 3$ とし，底を $2$ にとる．例 16.7.9 の 2 の左辺は $\frac12\log_2(2\pi e\cdot 4) - \frac12\log_2(2\pi e) = \frac12\log_2 4 = 1$ ビットである．右辺は，$J(X+\sqrt s\,Z) = 1/(1+s)$ で $\int_0^3\frac{ds}{1+s} = \frac{1}{\log_2 e}\log_2 4 = \frac{2}{\log_2 e}$ だから，$\frac{\log_2 e}{2}\cdot\frac{2}{\log_2 e} = 1$ ビットである．雑音の分散を $0$ から $3$ まで増やすあいだに，微分エントロピーはちょうど $1$ ビット増える．

de Bruijn の恒等式は，微分エントロピーの増え方を Fisher 情報量で書いた．増え方が書けたということは，Fisher 情報量の側で成り立つ不等式を，積分して微分エントロピーの側へ運べるということである．次節はその運び先を見る．
