# 16.4 数え上げへの応用

16.1 節 から 16.3 節 までの不等式は，系 16.3.4 が集合の関数一般へ広げたのを別にすれば，どれも確率変数の族についてのものだった．本節はその族に，有限集合の上の一様分布から作った変数を置く．そうすると全体のエントロピーが集合の要素数の対数になり，部分集合についてのエントロピーは，座標の一部だけを見た像の要素数の対数で上から押さえられる．こうして 定理 16.3.1 は，確率の出てこない数え上げの不等式に化ける．得られるのは，有限集合の大きさを，座標を落として得られる影の大きさの積で上から押さえる不等式である．$3$ 次元で言えば，$\mathcal X^3$ の部分集合について，三つの座標平面への影にあたる射影の要素数の積が，元の集合の要素数の $2$ 乗を上から押さえる，という形になる．

::: definition 16.4.1 射影
$n \ge 1$ とし，$\mathcal X$ を有限集合とする．$\mathcal X^n$ で $\{1,\dots,n\}$ から $\mathcal X$ への関数の全体を表し，$A$ をその部分集合とする．$S \subseteq \{1,\dots,n\}$ に対し，$A$ の各元を $S$ の座標だけに切り詰めて得られる集合
$$
\pi_S(A) \;:=\; \{\, x|_S \;:\; x \in A \,\}
$$
を $A$ の $S$ への **射影** と呼ぶ（$x|_S$ は $x$ の定義域を $S$ に狭めた関数である）．$S = \{1,\dots,n\}\setminus\{i\}$ のときは $\pi_{-i}(A)$ とも書く．
:::

この $\pi$ はつねに添字 $S$ と引数 $A$ の両方をとる写像であり，円周率とは形が違う．$\pi_S(A)$ は $S$ から $\mathcal X$ への関数の全体の部分集合で，$\lvert S\rvert = 1$ のときの $\pi_{\{i\}}(A)$ は，$A$ の元の第 $i$ 座標として現れる値の全体にあたる．以下，$\mathcal X^n$ の元は $n$ 個の値の組として書く．

::: formalized
`projectionSubset` (`InformationTheory/Shannon/BrascampLieb.lean`)，$1$ 座標を落とす場合 `projectionExcept` (`InformationTheory/Shannon/LoomisWhitney.lean`)
:::

不等式を数え上げに移す道具は二つある．一つは 定義 16.1.1 の族の作り方で，$A$ の上の一様分布に従う確率変数 $X$ をとり，その第 $i$ 座標を $X_i$ と置く．もう一つは，対数で書かれた不等式の両辺から $\log$ をはずす操作で，そのために $\log$ が正の実数の全体から実数の全体への狭義単調な全単射であることと，正の数 $u$，$v$ と実数 $m$ について $\log(uv) = \log u + \log v$ および $\log u^m = m\log u$ が成り立つことを既知とする．当てる相手は，本節から 16.8 節 までの証明が，対数の和や定数倍を一つの対数にまとめるところと，対数で書かれた等式・不等式から $\log$ をはずすところと，対数の値からもとの正の数を読むところで，そのつど直前の式である．

本章はこれを皮切りに，本書が証明を載せない道具をいくつか借りる．どれも証明を載せないだけで，無条件の機械検証済みの定理として形式化されている．例外は三つあり，16.7 節 の de Bruijn の恒等式の積分の形と，16.8 節 の独立な和の密度と Stam の不等式は，機械検証が本文の借用より狭いところまでしか及ばない．どれもその場で範囲を書く．以下の借用ではこの断りを繰り返さない．

::: theorem 16.4.2 Loomis–Whitney の不等式
$n \ge 1$ とし，$\mathcal X$ を有限集合，$A \subseteq \mathcal X^n$ を空でない部分集合とすると
$$
\lvert A\rvert^{\,n-1} \;\le\; \prod_{i=1}^{n} \lvert \pi_{-i}(A)\rvert
$$
である．
:::

::: proof
$A$ の上の一様分布に従う確率変数 $X$ をとり，$1 \le i \le n$ に対し $X_i$ を $X$ の第 $i$ 座標とする．どの $X_i$ も $\mathcal X$ に値をとるから，$X_1,\dots,X_n$ は 定義 16.1.1 の設定を満たす族である．定義 1.1.1 のエントロピーは分布だけで決まり，確率 $0$ の値の項は約束により和に寄与しないから，以下ではどの確率変数についても，そのアルファベットを実際にとる値の全体にとってよい．

$X_{\{1,\dots,n\}}$ は $X$ そのもので，とりうる値は $A$ の元だから，例 1.1.3 を $M = \lvert A\rvert$ で当てて $H(X_{\{1,\dots,n\}}) = \log\lvert A\rvert$ である．また $S \subseteq \{1,\dots,n\}$ をとると $X_S$ のとりうる値は $\pi_S(A)$ の元に限られるから，定理 1.1.5 を当てて
$$
H(X_S) \;\le\; \log\lvert\pi_S(A)\rvert
$$
を得る．

族を $S_i := \{1,\dots,n\}\setminus\{i\}$（$1 \le i \le n$）ととる．番号 $j$ を含む $S_i$ は $i \ne j$ を満たす $i$ に対応するものだから，ちょうど $n-1$ 個ある．$k = n-1$ として 定理 16.3.1 を当て，右辺の各項に上の評価を当てると
$$
(n-1)\log\lvert A\rvert \;\le\; \sum_{i=1}^{n} \log\lvert\pi_{-i}(A)\rvert
$$
である．$A$ は空でなく，どの $\pi_{-i}(A)$ も空でないから，両辺を対数の中にまとめると左辺は $\log\lvert A\rvert^{\,n-1}$，右辺は $\log\prod_{i=1}^{n}\lvert\pi_{-i}(A)\rvert$ である．$\log$ が狭義単調だから主張を得る．
:::

::: formalized
`loomis_whitney` (`InformationTheory/Shannon/LoomisWhitney.lean`)
:::

::: formalization-note
宣言の指数は自然数の引き算で書かれていて，$n = 0$ では $n-1$ が $0$ に切り捨てられる．そのとき左辺は $1$，右辺は空の積で $1$ だから，宣言は $n = 0$ も込みで成り立っている．本文は $n \ge 1$ を仮定するので，この差は 定理 16.4.2 の範囲には出てこない．
:::

::: example 16.4.3
$n = 3$，$\mathcal X = \{0,1\}$ とする．(a) $A = \{0,1\}^3$ をとると 定理 16.4.2 の両辺はどちらも $64$ で等号である．(b) $A = \{(0,0,0),(1,0,0),(0,1,0),(0,0,1)\}$ をとると左辺は $16$，右辺は $27$ で狭義である．
:::

::: proof
(a) $\lvert A\rvert = 8$ だから左辺は $8^2 = 64$ である．どの $i$ についても $\pi_{-i}(A) = \{0,1\}^2$ で要素数は $4$ だから，右辺は $4^3 = 64$ である．

(b) $\lvert A\rvert = 4$ だから左辺は $4^2 = 16$ である．$\pi_{-1}(A)$ は第 $2$ 座標と第 $3$ 座標だけを見た像で，$A$ の四つの元はそれぞれ $(0,0)$，$(0,0)$，$(1,0)$，$(0,1)$ に移るから $\pi_{-1}(A) = \{(0,0),(1,0),(0,1)\}$ で要素数は $3$ である．$A$ は座標の入れ替えで自分自身に移るから $\pi_{-2}(A)$ と $\pi_{-3}(A)$ の要素数も $3$ であり，右辺は $3^3 = 27$ である．
:::

定理 16.4.2 の証明で族の形が効いたのは，どの番号もちょうど $n-1$ 回覆われることを確かめる一箇所だけだった．定理 16.3.1 が族を選ばせてくれる以上，落とす座標を $1$ 個に限る理由はない．族を一般にとった形には Brascamp–Lieb の名が付いている．この名は，$\mathbb R^n$ の上の積分について，いくつかの線形写像で低い次元へ送った先で定めた関数の積を，それぞれの積分の積の定数倍で上から押さえる解析の不等式に由来する．次の定理はその有限集合版にあたり，解析の側は本書では扱わない．

::: theorem 16.4.4 Brascamp–Lieb の不等式（組合せ形）
$n \ge 1$ とし，$\mathcal X$ を有限集合，$A \subseteq \mathcal X^n$ を空でない部分集合とする．$r \ge 1$，$S_1,\dots,S_r \subseteq \{1,\dots,n\}$ とし，$k$ を非負整数とする．どの $i \in \{1,\dots,n\}$ についても $i$ を含む $S_j$ が $k$ 個以上あるならば
$$
\lvert A\rvert^{\,k} \;\le\; \prod_{j=1}^{r} \lvert \pi_{S_j}(A)\rvert
$$
である．
:::

::: proof
定理 16.4.2 の証明で，族を $S_1,\dots,S_r$ に，覆う回数を $n-1$ から $k$ に取り替えればよい．$A$ の上の一様分布から作った族についての二つの事実，すなわち $H(X_{\{1,\dots,n\}}) = \log\lvert A\rvert$ であることと，どの $S \subseteq \{1,\dots,n\}$ についても $H(X_S) \le \log\lvert\pi_S(A)\rvert$ であることは，族の取り方に触れずに出したのでそのまま使える．仮定より 定理 16.3.1 が $k$ で当てられて
$$
k\log\lvert A\rvert \;\le\; \sum_{j=1}^{r} \log\lvert\pi_{S_j}(A)\rvert
$$
を得る．$A$ もどの $\pi_{S_j}(A)$ も空でないから，両辺を対数の中にまとめると左辺は $\log\lvert A\rvert^{\,k}$，右辺は $\log\prod_{j=1}^{r}\lvert\pi_{S_j}(A)\rvert$ であり，$\log$ が狭義単調だから主張を得る．
:::

::: formalization-note
宣言は族の添字を任意の有限型でとる．本文が族を $S_1,\dots,S_r$ と番号で並べているのは，その添字を $\{1,\dots,r\}$ にとった場合にあたる．

定理 16.4.2 は，定理 16.4.4 で族を「番号 $i$ を抜いた $n$ 個の集合」，$k = n-1$ ととった場合である．族をいちばん小さい集合でとると，別の形が出る．

::: corollary 16.4.5
$n \ge 1$ とし，$\mathcal X$ を有限集合，$A \subseteq \mathcal X^n$ を空でない部分集合とすると
$$
\lvert A\rvert \;\le\; \prod_{i=1}^{n} \lvert \pi_{\{i\}}(A)\rvert
$$
である．
:::

::: proof
族を $n$ 個の $1$ 点集合 $\{1\},\dots,\{n\}$ ととると，どの番号もちょうど一つの集合に含まれる．$k = 1$ として 定理 16.4.4 を当てると，左辺は $\lvert A\rvert^1 = \lvert A\rvert$ である．
:::

宣言の名前は超立方体を名乗るが，述べているのは 系 16.4.5 と同じく一般の有限アルファベットについての不等式である．

::: example 16.4.6
例 16.4.3 (b) の $A$ について 系 16.4.5 の両辺は $4$ と $8$ である．また $n = 4$，$\mathcal X = \{0,1\}$ とし，族を $S_1 = \{1,2\}$，$S_2 = \{3,4\}$ ととり $k = 1$ として，$A := \{(0,0,0,1),(0,0,1,0),(1,1,0,1),(1,1,1,0)\}$ とすると，定理 16.4.4 の両辺はどちらも $4$ で等号である．
:::

::: proof
例 16.4.3 (b) の $A$ ではどの座標にも $0$ と $1$ の両方が現れるから，どの $i$ についても $\pi_{\{i\}}(A) = \{0,1\}$ で，系 16.4.5 の右辺は $2^3 = 8$，左辺は $\lvert A\rvert = 4$ である．

後半の $A$ では，番号 $1$ と $2$ が $S_1$ だけに，番号 $3$ と $4$ が $S_2$ だけに含まれるから，どの番号もちょうど一つの集合に覆われて $k = 1$ として 定理 16.4.4 が使える．$\lvert A\rvert = 4$ だから左辺は $4$ である．$\pi_{S_1}(A) = \{(0,0),(1,1)\}$，$\pi_{S_2}(A) = \{(0,1),(1,0)\}$ でどちらも要素数は $2$ だから，右辺も $4$ である．
:::

**等号が起きる形を見る.** 例 16.4.3 (a) と 例 16.4.6 の後半では等号が起きた．どちらの $A$ も，座標の組ごとに集合を選んでその直積をとった形をしている．射影が見ているのは，各座標や各座標の組に現れる値の全体だけで，値どうしの組み合わせ方は落ちる．等号が起きた二つの例では，落ちた組み合わせ方がもともと無かったのである．いっぽう 例 16.4.3 (b) の $A$ では，どの座標にも $0$ と $1$ の両方が現れるので，$1$ 点集合への射影はどれも $\{0,1\}$ そのもの，すなわち目一杯である．それでも元の個数は $4$ しかなく，その開きが 系 16.4.5 の $4 \le 8$ になっている．$1$ 座標を落とした射影のほうは目一杯ではない．要素数は $4$ ではなく $3$ で，$(0,0,0)$ と $(1,0,0)$ が第 $1$ 座標を落とすと同じ $(0,0)$ に移るぶんだけ小さい．それでも組み合わせ方の落ちる余地は残っていて，定理 16.4.2 の $16 \le 27$ の開きになっている．

$\lvert A\rvert$ の上界が二つ出たので，どちらが強いかを決めておく．どちらも 定理 16.4.4 から出たもので，族の選び方が違うだけである．

::: proposition 16.4.7
$n \ge 2$ とし，$\mathcal X$ を有限集合，$A \subseteq \mathcal X^n$ を空でない部分集合とすると
$$
\prod_{i=1}^{n} \lvert \pi_{-i}(A)\rvert \;\le\; \Big(\prod_{i=1}^{n} \lvert \pi_{\{i\}}(A)\rvert\Big)^{\,n-1}
$$
である．すなわち 定理 16.4.2 が $\lvert A\rvert^{\,n-1}$ に与える上界は，系 16.4.5 の上界を $n-1$ 乗したものを超えない．
:::

::: proof
番号 $i$ を固定する．$\pi_{-i}(A)$ は $\{1,\dots,n\}\setminus\{i\}$ から $\mathcal X$ への関数の空でない集合だから，その番号を小さい順に $1,\dots,n-1$ へ読み替えて，系 16.4.5 を座標の個数 $n-1$ の場合に当てると
$$
\lvert\pi_{-i}(A)\rvert \;\le\; \prod_{j \ne i} \lvert \pi_{\{j\}}(A)\rvert
$$
である（読み替えても第 $j$ 座標に現れる値の全体は変わらないので，右辺の各因子は $A$ の $1$ 点集合への射影の要素数である）．$A$ が空でないからどの射影も空でなく，両辺はどちらも正である．よって $i$ について掛け合わせてよく，右辺では各 $j$ の因子が $j \ne i$ を満たす $i$ の個数だけ，すなわち $n-1$ 回ずつ現れるから，主張を得る．
:::

::: formalization-note
二つの上界の強弱を述べる宣言はない．射影の要素数の積を結論に含む宣言をすべて開いて確かめた．機械検証が及ぶのは 定理 16.4.2 と 系 16.4.5 のそれぞれまでで，二つを比べる段は本文の側にある．
:::

命題 16.4.7 を 例 16.4.3 の数で見ておく．(b) の $A$ では 定理 16.4.2 の右辺が $27$，系 16.4.5 の右辺を $2$ 乗したものが $8^2 = 64$ である．$\lvert A\rvert$ は整数で $6^2 = 36 > 27$ だから，前者からは $\lvert A\rvert \le 5$ が，後者からは $\lvert A\rvert \le 8$ が出る（真の値は $4$ である）．(a) の $A$ では $4^3 = 64$ と $8^2 = 64$ で，二つは一致する．

数え上げに移す道具はこれで揃った．次節は同じ道具を，$\mathcal X = \{0,1\}$ の場合に，集合の大きさではなく集合の境界の大きさへ当てる．
