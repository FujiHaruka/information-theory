# 16.4 数え上げへの応用

16.1 節 から 16.3 節 までの不等式は，どれも確率変数の族についてのものだった．本節はその族に，有限集合の上の一様分布から作った変数を置く．そうすると全体のエントロピーが集合の要素数の対数になり，部分集合についてのエントロピーは，座標の一部だけを見た像の要素数の対数で上から押さえられる．こうして 定理 16.3.1 は，確率の出てこない数え上げの不等式に化ける．得られるのは，有限集合の大きさを，座標を落として得られる影の大きさの積で上から押さえる不等式である．$3$ 次元で言えば，$\mathcal X^3$ の部分集合について，三つの座標平面への影にあたる射影の要素数の積が，元の集合の要素数の $2$ 乗を下から押さえる，という形になる．

::: definition 16.4.1 射影
$n \ge 1$ とし，$\mathcal X$ を空でない有限集合とする．$\mathcal X^n$ で $\{1,\dots,n\}$ から $\mathcal X$ への関数の全体を表し，$A$ をその空でない部分集合とする．$S \subseteq \{1,\dots,n\}$ に対し，$A$ の各元を $S$ の座標だけに切り詰めて得られる集合
$$
\pi_S(A) \;:=\; \{\, x|_S \;:\; x \in A \,\}
$$
を $A$ の $S$ への **射影** と呼ぶ（$x|_S$ は $x$ の定義域を $S$ に狭めた関数である）．$S = \{1,\dots,n\}\setminus\{i\}$ のときは $\pi_{-i}(A)$ とも書く．
:::

この $\pi$ はつねに添字 $S$ と引数 $A$ の両方をとる写像であり，円周率とは形が違う．$\pi_S(A)$ は $S$ から $\mathcal X$ への関数の全体の部分集合で，$\lvert S\rvert = 1$ のときの $\pi_{\{i\}}(A)$ は，$A$ の元の第 $i$ 座標として現れる値の全体にあたる．以下，$\mathcal X^n$ の元は $n$ 個の値の組として書く．

::: formalized
`projectionSubset` (`InformationTheory/Shannon/BrascampLieb.lean`)，$1$ 座標を落とす場合 `projectionExcept` (`InformationTheory/Shannon/LoomisWhitney.lean`)
:::

不等式を数え上げに移す道具は二つある．一つは 定義 16.1.1 の族の作り方で，$A$ の上の一様分布に従う確率変数 $X$ をとり，その第 $i$ 座標を $X_i$ と置く．もう一つは，対数で書かれた不等式の両辺から $\log$ をはずす操作で，そのために $\log$ が正の実数の全体から実数の全体への狭義単調な全単射であることを既知とする．当てる相手は，本節の 定理 16.4.2 と 定理 16.4.4 の証明，16.5 節 の 補題 16.5.5 と 命題 16.5.8 の証明，そして本章の後半でエントロピーべきを定める式がただ一つの正の数を決めることと，そこでの不等式の両辺から $\log$ をはずすところである．

::: theorem 16.4.2 Loomis–Whitney の不等式
$n \ge 1$ とし，$\mathcal X$ を空でない有限集合，$A \subseteq \mathcal X^n$ を空でない部分集合とすると
$$
\lvert A\rvert^{\,n-1} \;\le\; \prod_{i=1}^{n} \lvert \pi_{-i}(A)\rvert
$$
である．
:::

::: proof
$A$ の上の一様分布に従う確率変数 $X$ をとり，$1 \le i \le n$ に対し $X_i$ を $X$ の第 $i$ 座標とする．どの $X_i$ も $\mathcal X$ に値をとるから，$X_1,\dots,X_n$ は 定義 16.1.1 の設定を満たす族である．定義 1.1.1 のエントロピーは分布だけで決まり，確率 $0$ の値の項は約束により和に寄与しないから，以下ではどの確率変数についても，そのアルファベットを実際にとる値の全体にとってよい．

$X_{\{1,\dots,n\}}$ は $X$ そのもので，とりうる値は $A$ の元だから，例 1.1.3 を $M = \lvert A\rvert$ で当てて $H(X_{\{1,\dots,n\}}) = \log\lvert A\rvert$ である．また $S \subseteq \{1,\dots,n\}$ をとると $X_S$ のとりうる値は $\pi_S(A)$ の元に限られるから，定理 1.1.5 を当てて
$$
H(X_S) \;\le\; \log\lvert\pi_S(A)\rvert
$$
を得る．

族を $S_i := \{1,\dots,n\}\setminus\{i\}$（$1 \le i \le n$）ととる．番号 $j$ を含む $S_i$ は $i \ne j$ を満たす $i$ に対応するものだから，ちょうど $n-1$ 個ある．$k = n-1$ として 定理 16.3.1 を当て，右辺の各項に上の評価を当てると
$$
(n-1)\log\lvert A\rvert \;\le\; \sum_{i=1}^{n} \log\lvert\pi_{-i}(A)\rvert
$$
である．$A$ は空でなく，どの $\pi_{-i}(A)$ も空でないから，両辺を対数の中にまとめると左辺は $\log\lvert A\rvert^{\,n-1}$，右辺は $\log\prod_{i=1}^{n}\lvert\pi_{-i}(A)\rvert$ である．$\log$ が狭義単調だから主張を得る．
:::

::: formalized
`loomis_whitney` (`InformationTheory/Shannon/LoomisWhitney.lean`)
:::

::: formalization-note
宣言の指数は自然数の引き算で書かれていて，$n = 0$ では $n-1$ が $0$ に切り捨てられる．そのとき左辺は $1$，右辺は空の積で $1$ だから，宣言は $n = 0$ も込みで成り立っている．本文は $n \ge 1$ を仮定するので，この差は 定理 16.4.2 の範囲には出てこない．
:::

::: example 16.4.3
$n = 3$，$\mathcal X = \{0,1\}$ とする．(a) $A = \{0,1\}^3$ をとると 定理 16.4.2 の両辺はどちらも $64$ で等号である．(b) $A = \{(0,0,0),(1,0,0),(0,1,0),(0,0,1)\}$ をとると左辺は $16$，右辺は $27$ で狭義である．
:::

::: proof
(a) $\lvert A\rvert = 8$ だから左辺は $8^2 = 64$ である．どの $i$ についても $\pi_{-i}(A) = \{0,1\}^2$ で要素数は $4$ だから，右辺は $4^3 = 64$ である．

(b) $\lvert A\rvert = 4$ だから左辺は $4^2 = 16$ である．$\pi_{-1}(A)$ は第 $2$ 座標と第 $3$ 座標だけを見た像で，$A$ の四つの元はそれぞれ $(0,0)$，$(0,0)$，$(1,0)$，$(0,1)$ に移るから $\pi_{-1}(A) = \{(0,0),(1,0),(0,1)\}$ で要素数は $3$ である．$A$ は座標の入れ替えで自分自身に移るから $\pi_{-2}(A)$ と $\pi_{-3}(A)$ の要素数も $3$ であり，右辺は $3^3 = 27$ である．
:::

定理 16.4.2 の証明で族の形が効いたのは，どの番号もちょうど $n-1$ 回覆われることを確かめる一箇所だけだった．定理 16.3.1 が族を選ばせてくれる以上，落とす座標を $1$ 個に限る理由はない．

::: theorem 16.4.4 Brascamp–Lieb の不等式（組合せ形）
$n \ge 1$ とし，$\mathcal X$ を空でない有限集合，$A \subseteq \mathcal X^n$ を空でない部分集合とする．$r \ge 1$，$S_1,\dots,S_r \subseteq \{1,\dots,n\}$ とし，$k$ を非負整数とする．どの $i \in \{1,\dots,n\}$ についても $i$ を含む $S_j$ が $k$ 個以上あるならば
$$
\lvert A\rvert^{\,k} \;\le\; \prod_{j=1}^{r} \lvert \pi_{S_j}(A)\rvert
$$
である．
:::

::: proof
$A$ の上の一様分布に従う確率変数 $X$ をとり，$X_i$ を $X$ の第 $i$ 座標とすると，$X_1,\dots,X_n$ は 定義 16.1.1 の設定を満たす族である．エントロピーは分布だけで決まり，確率 $0$ の値の項は 定義 1.1.1 の約束により和に寄与しないから，どの確率変数についてもアルファベットを実際にとる値の全体にとってよい．$X_{\{1,\dots,n\}}$ は $X$ そのもので，とりうる値は $A$ の元だから，例 1.1.3 を $M = \lvert A\rvert$ で当てて $H(X_{\{1,\dots,n\}}) = \log\lvert A\rvert$ である．また $S \subseteq \{1,\dots,n\}$ に対し $X_S$ のとりうる値は $\pi_S(A)$ の元に限られるから，定理 1.1.5 を当てて $H(X_S) \le \log\lvert\pi_S(A)\rvert$ である．仮定より族 $S_1,\dots,S_r$ はどの番号も $k$ 個以上の集合で覆うから，定理 16.3.1 を当てて
$$
k\log\lvert A\rvert \;\le\; \sum_{j=1}^{r} \log\lvert\pi_{S_j}(A)\rvert
$$
を得る．$A$ もどの $\pi_{S_j}(A)$ も空でないから，両辺を対数の中にまとめると左辺は $\log\lvert A\rvert^{\,k}$，右辺は $\log\prod_{j=1}^{r}\lvert\pi_{S_j}(A)\rvert$ であり，$\log$ が狭義単調だから主張を得る．
:::

:::

::: formalization-note
宣言は族の添字を任意の有限型でとる．本文が族を $S_1,\dots,S_r$ と番号で並べているのは，その添字を $\{1,\dots,r\}$ にとった場合にあたる．
:::

定理 16.4.2 は，定理 16.4.4 で族を「番号 $i$ を抜いた $n$ 個の集合」，$k = n-1$ ととった場合である．族をいちばん小さい集合でとると，別の形が出る．

::: corollary 16.4.5
$n \ge 1$ とし，$\mathcal X$ を空でない有限集合，$A \subseteq \mathcal X^n$ を空でない部分集合とすると
$$
\lvert A\rvert \;\le\; \prod_{i=1}^{n} \lvert \pi_{\{i\}}(A)\rvert
$$
である．
:::

::: proof
族を $n$ 個の $1$ 点集合 $\{1\},\dots,\{n\}$ ととると，どの番号もちょうど一つの集合に含まれる．$k = 1$ として 定理 16.4.4 を当てると，左辺は $\lvert A\rvert^1 = \lvert A\rvert$ である．
:::

`hypercube_product_projection_bound` (`InformationTheory/Shannon/BrascampLieb.lean`)
:::

::: formalization-note
宣言の名前は超立方体を名乗るが，述べているのは 系 16.4.5 と同じく一般の有限アルファベットについての不等式である．
:::

::: example 16.4.6
例 16.4.3 (b) の $A$ について 系 16.4.5 の両辺は $4$ と $8$ である．また $n = 4$，$\mathcal X = \{0,1\}$ とし，族を $S_1 = \{1,2\}$，$S_2 = \{3,4\}$ ととり $k = 1$ として，$A := \{(0,0,0,1),(0,0,1,0),(1,1,0,1),(1,1,1,0)\}$ とすると，定理 16.4.4 の両辺はどちらも $4$ で等号である．
:::

::: proof
例 16.4.3 (b) の $A$ ではどの座標にも $0$ と $1$ の両方が現れるから，どの $i$ についても $\pi_{\{i\}}(A) = \{0,1\}$ で，系 16.4.5 の右辺は $2^3 = 8$，左辺は $\lvert A\rvert = 4$ である．

後半の $A$ では，番号 $1$ と $2$ が $S_1$ だけに，番号 $3$ と $4$ が $S_2$ だけに含まれるから，どの番号もちょうど一つの集合に覆われて $k = 1$ として 定理 16.4.4 が使える．$\lvert A\rvert = 4$ だから左辺は $4$ である．$\pi_{S_1}(A) = \{(0,0),(1,1)\}$，$\pi_{S_2}(A) = \{(0,1),(1,0)\}$ でどちらも要素数は $2$ だから，右辺も $4$ である．
:::

**等号が起きる形を見る.** 例 16.4.3 (a) と 例 16.4.6 の後半では等号が起きた．どちらの $A$ も，座標の組ごとに集合を選んでその直積をとった形をしている．射影が見ているのは，各座標や各座標の組に現れる値の全体だけで，値どうしの組み合わせ方は落ちる．等号が起きた二つの例では，落ちた組み合わせ方がもともと無かったのである．いっぽう 例 16.4.3 (b) の $A$ は，どの座標にも $0$ と $1$ の両方が現れるので射影は目一杯大きくなるのに，元の個数は $4$ しかない．その開きが $16 \le 27$ の差になっている．

数え上げに移す道具はこれで揃った．次節は同じ道具を，$\mathcal X = \{0,1\}$ の場合に，集合の大きさではなく集合の境界の大きさへ当てる．
