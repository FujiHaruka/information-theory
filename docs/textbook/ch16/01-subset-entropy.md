# 16.1 部分集合のエントロピー

第1章 1.2 節 は確率変数を二つ並べて，まとめて見たときの不確かさ（定義 1.2.1）と，片方を知ったあとに残る不確かさ（定義 1.2.2）を測った．二つはチェイン則（定理 1.2.3）で結ばれ，条件を増やしても残りの不確かさが増えないこと（定理 1.2.4）がそこに重なった．本章の前半，本節から 16.5 節 までは，この二つを確率変数の族に当てる．族が $n$ 個あるとき，まとめて見る相手は一通りではない．番号の集合を選ぶたびに一つの値が決まるので，見えているのは $\{1,\dots,n\}$ の部分集合に実数を返す関数である．後半の 16.6 節 から 16.8 節 までは，部分集合を動かす枠を離れる．扱うのは，正定値行列の行列式を $1$ 座標あたりに直した量と，第7章 の微分エントロピーを指数に持ち上げた量で，どちらについても，二つを足すと値が足し算以上になるという同じ形の不等式が現れる．

測る量そのものは新しくない．番号の集合 $S$ を選んだら，$S$ に属する番号の変数を一つの組にまとめてしまえばよく，定義 1.1.1 のエントロピーがそのまま値を与える．新しいのは $S$ を動かして値どうしを比べるところで，本節はその比べ方を三つ出す．番号を一つずつ足していったときの分解（定理 16.1.4），$S$ を大きくしても値が減らないこと（命題 16.1.5），そして二つの集合の和と交わりについての不等式（定理 16.1.6）である．あとの節の証明が直に引くのは一つ目である．残る二つは，三つをそろえたときに現れる枠（定義 16.1.7）を通して効く．

::: definition 16.1.1 部分集合のエントロピー
$n \ge 1$ とし，$\mathcal X$ を有限アルファベット，$X_1,\dots,X_n$ を $\mathcal X$ に値をとる確率変数とする．$S \subseteq \{1,\dots,n\}$ に対し，$S$ に属する番号を小さい順に並べ，対応する変数を並べた組を $X_S$ と書く．この組は $S$ の各番号に $\mathcal X$ の元を対応させる関数とみなせるから，$X_S$ は $S$ から $\mathcal X$ への関数の全体に値をとる一つの確率変数である（$S = \emptyset$ のときこの値域は要素が一つの集合である）．この確率変数のエントロピー（定義 1.1.1）を $S$ についての **部分集合のエントロピー** と呼んで $H(X_S)$ と書く．
:::

$\lvert S\rvert = 1$ のときは 定義 1.1.1 そのもの，$\lvert S\rvert = 2$ のときは 定義 1.2.1 の結合エントロピーであり，$S$ が全体のときの $H(X_{\{1,\dots,n\}})$ が，$n$ 個をまとめて見たときの不確かさにあたる．$X_\emptyset$ のとりうる値は一つしかないから，定義 1.1.1 の和は $-1\log 1$ の一項だけになり，$H(X_\emptyset) = 0$ である．

組のまとめ方について一つ断っておく．定義 1.1.1 のエントロピーは値の分布だけで決まるので，組の成分を並べ替えても，成分の一部をまとめて対とみても，値は変わらない．以下の証明はこの読み替えを繰り返し使うので，先に補題として置く．

::: lemma 16.1.2 値の付け替え
$\mathcal U$，$\mathcal V$，$\mathcal W$ を有限集合とし，$U$，$V$，$W$ をそれぞれに値をとる確率変数とする．$\phi$ を $\mathcal U$ から $\mathcal V$ への単射で $V = \phi(U)$ を満たすものとすると，$H(U) = H(V)$（定義 1.1.1）であり，$H(W \mid U) = H(W \mid V)$（定義 1.2.2）である．
:::

::: proof
$\phi$ は単射だから，$v = \phi(u)$ の形の値について，$V = v$ という事象と $U = u$ という事象は同じ事象である．よって二つの確率は等しい．$\phi$ の像に入らない $v$ については $V = v$ の確率が $0$ で，定義 1.1.1 の約束によりその項は和に寄与しない．したがって $H(V)$ の和は $H(U)$ の和と項ごとに一致する．

条件付きエントロピーも同じである．定義 1.2.2 は，条件の値ごとに残る不確かさを，その値の確率で平均したものである．いま見たとおり $V = \phi(u)$ と $U = u$ は同じ事象だから，その確率も，そのもとでの $W$ の条件付き分布も一致し，各項が対応する．像に入らない値の項は重み $0$ で寄与しないから，二つの平均は等しい．
:::

たとえば $S \subseteq T$ のとき，$X_T$ の値に対 $(X_S, X_{T\setminus S})$ の値を対応させる写像は単射だから，補題 16.1.2 より $X_T$ は対 $(X_S, X_{T\setminus S})$ とみてよい．条件の側についても同じである．

::: formalized
部分集合のエントロピー `jointEntropySubset` (`InformationTheory/Shannon/Han/D.lean`)，族の全体についてのエントロピー `jointEntropy` (`InformationTheory/Shannon/Han/Basic.lean`)
:::

::: formalization-note
形式化は，族の変数がどれも同じ有限アルファベットに値をとるものとして扱う（本文も同じである）．空集合についての値が $0$ であることは `jointEntropySubset_empty` (`InformationTheory/Shannon/Polymatroid.lean`) が，$S$ が全体のときに族の全体についてのエントロピーと一致することは `jointEntropySubset_univ` (`InformationTheory/Shannon/Han/D.lean`) が，それぞれ別の宣言として検証している．
:::

::: example 16.1.3 重複と排他的論理和
$\mathcal X = \{0,1\}$，$n = 3$ とし，値はビットで書く（1.1 節 の約束どおり $\log$ の底を $2$ にとる）．

**(a)** $X_1$ を公平なコイン，$X_2 := X_1$，$X_3$ を $X_1$ と独立な公平なコインとすると，$H(X_{\{1\}}) = H(X_{\{2\}}) = H(X_{\{3\}}) = 1$，$H(X_{\{1,2\}}) = 1$，$H(X_{\{1,3\}}) = H(X_{\{2,3\}}) = 2$，$H(X_{\{1,2,3\}}) = 2$ である．

**(b)** $X_1$，$X_2$ を独立な公平なコイン，$X_3 := X_1 \oplus X_2$（$\oplus$ は排他的論理和）とすると，$1$ 点集合についての値はどれも $1$，$2$ 点集合についての値はどれも $2$ であり，$H(X_{\{1,2,3\}}) = 2$ である．
:::

::: proof
確率 $0$ の値の項は 定義 1.1.1 の約束により和に寄与しないので，どの場合も実際にとりうる値だけを数え，それらが等確率であることを見て 例 1.1.3 を当てればよい．

**(a)** $X_1$，$X_2$，$X_3$ はどれも $\{0,1\}$ 上の一様分布に従うから，$1$ 点集合についての値は 例 1.1.3 を $M = 2$ で当てて $\log 2 = 1$ である．$X_{\{1,2\}}$ のとりうる値は $(0,0)$ と $(1,1)$ の二つで確率はどちらも $1/2$ だから，同じく $M = 2$ で当てて $1$ である．$X_1$ と $X_3$ は独立でどちらも一様だから対 $(X_1, X_3)$ は $4$ つの値を確率 $1/4$ ずつでとり，$M = 4$ で当てて $H(X_{\{1,3\}}) = \log 4 = 2$ である．$X_2 = X_1$ だから $H(X_{\{2,3\}})$ も同じ値である．$X_{\{1,2,3\}}$ は $(X_1, X_1, X_3)$ で，その値に $(X_1, X_3)$ の値を対応させる写像は単射だから，補題 16.1.2 より値は $2$ である．

**(b)** 写像 $(x_1, x_2) \mapsto (x_1,\, x_1 \oplus x_2)$ は $\{0,1\}^2$ から $\{0,1\}^2$ への全単射である．$X_1$ と $X_2$ は独立でどちらも一様だから対 $(X_1,X_2)$ は $4$ つの値を確率 $1/4$ ずつでとり，したがって対 $(X_1, X_3)$ も $4$ つの値を確率 $1/4$ ずつでとる．写像 $(x_1,x_2) \mapsto (x_2,\, x_1\oplus x_2)$ も全単射だから，対 $(X_2, X_3)$ についても同じである．よって $2$ 点集合についての値はどれも 例 1.1.3 を $M = 4$ で当てて $2$ であり，周辺分布をとれば $X_3$ も一様だから，$1$ 点集合についての値はどれも $M = 2$ で当てて $1$ である．$X_{\{1,2,3\}}$ のとりうる値は $(x_1, x_2, x_1\oplus x_2)$ の形の $4$ 通りで確率は $1/4$ ずつだから，値は $2$ である．
:::

**増えなくなる場所を見る.** 二つの族は，$1$ 点集合についての値がどれも $1$ で，全体についての値が $2$ である点まで一致する．違うのは途中である．(a) では番号 $1$ に番号 $2$ を足しても値が $1$ のまま増えないのに，(b) ではどの $1$ 点集合にどの番号を足しても値が $1$ から $2$ へ増え，そのかわり $2$ 点集合に残りの番号を足しても $2$ のままである．どこで増えなくなるかが族の作りを写しており，その「足したときの増分」を正面から書いたのが次の定理である．

::: theorem 16.1.4 部分集合のチェイン則
定義 16.1.1 の設定で，どの $S \subseteq \{1,\dots,n\}$ についても
$$
H(X_S) \;=\; \sum_{i \in S} H\big(X_i \,\big|\, X_{S \cap \{1,\dots,i-1\}}\big)
$$
である．
:::

::: proof $\lvert S\rvert$ についての数学的帰納法
$S = \emptyset$ のとき，$X_\emptyset$ のとりうる値は一つしかないから，定義 1.1.1 の和は $-1\log 1 = 0$ の一項だけで左辺は $0$ である．右辺は空の和で $0$ である．

$\lvert S\rvert = m$ のすべての集合について主張が成り立つとし，$\lvert S\rvert = m+1$ とする．$S$ に属する番号のうち最大のものを $j$ と書き，$R := S \setminus \{j\}$ とおく．補題 16.1.2 より $X_S$ は対 $(X_R, X_j)$ とみてよく，定理 1.2.3 をこの対に当てると
$$
H(X_S) \;=\; H(X_R) + H(X_j \mid X_R)
$$
である．$j$ は $S$ の最大の番号だから $S \cap \{1,\dots,j-1\} = R$ であり，第 $2$ 項は示すべき和の $i = j$ の項そのものである．第 $1$ 項に帰納法の仮定を当てると
$$
H(X_R) \;=\; \sum_{i \in R} H\big(X_i \,\big|\, X_{R \cap \{1,\dots,i-1\}}\big)
$$
である．$i \in R$ ならば $i < j$ だから $j \notin \{1,\dots,i-1\}$ であり，$R \cap \{1,\dots,i-1\} = S \cap \{1,\dots,i-1\}$ である．よってこの和は示すべき和の $i \ne j$ の項の和に等しく，$i = j$ の項と合わせて主張を得る．
:::

**順に足していくと読む.** 定理 1.2.3 は二つの変数について「まず一方，次にもう一方」と数えた．定理 16.1.4 はそれを $S$ の番号の小さい順に繰り返しただけである．$i$ の項は，$S$ の中で $i$ より小さい番号をすでに知ったうえで $X_i$ に残る不確かさで，足していくと $H(X_S)$ になる．番号の小さい順に足したのは書き方の都合で，左辺は $S$ だけで決まる．

::: proposition 16.1.5 包含についての単調性
定義 16.1.1 の設定で，$S \subseteq T \subseteq \{1,\dots,n\}$ ならば $H(X_S) \le H(X_T)$ である．
:::

::: proof
補題 16.1.2 より $X_T$ は対 $(X_S, X_{T\setminus S})$ とみてよく，定理 1.2.3 をこの対に当てると
$$
H(X_T) \;=\; H(X_S) + H\big(X_{T\setminus S} \,\big|\, X_S\big)
$$
である．定義 1.2.2 の中辺は，$X_S = y$ ごとの残りの不確かさを重み $p(y) \ge 0$ で平均したものであり，その各項は 命題 1.1.4 より非負だから，第 $2$ 項は非負である．
:::

::: theorem 16.1.6 劣モジュラ性
定義 16.1.1 の設定で，どの $S, T \subseteq \{1,\dots,n\}$ についても
$$
H(X_{S \cup T}) + H(X_{S \cap T}) \;\le\; H(X_S) + H(X_T)
$$
である．
:::

::: proof
$U := S \cap T$，$V := S \setminus T$ とおく．$S$ は $U$ と $V$ の交わらない和であり，$S \cup T$ は $T$ と $V$ の交わらない和である．補題 16.1.2 より，$X_S$ は対 $(X_U, X_V)$，$X_{S\cup T}$ は対 $(X_T, X_V)$ とみてよく，定理 1.2.3 をこの二つの対に当てると
$$
H(X_S) \;=\; H(X_U) + H(X_V \mid X_U),
\qquad
H(X_{S\cup T}) \;=\; H(X_T) + H(X_V \mid X_T)
$$
である．$U \subseteq T$ だから，補題 16.1.2 より，$H(X_V \mid X_T)$ の条件を対 $(X_U, X_{T\setminus U})$ とみて 定理 1.2.4 を当てると
$$
H(X_V \mid X_T) \;\le\; H(X_V \mid X_U)
$$
である．三つを合わせると
$$
H(X_{S\cup T}) + H(X_U)
  \;=\; H(X_T) + H(X_V \mid X_T) + H(X_U)
  \;\le\; H(X_T) + H(X_V \mid X_U) + H(X_U)
  \;=\; H(X_T) + H(X_S)
$$
であり，$U = S \cap T$ だから主張を得る．
:::

**同じものを足したときの増分で読む.** 定理 16.1.6 は移項すると $H(X_{S\cup T}) - H(X_T) \le H(X_S) - H(X_{S\cap T})$ と書ける．左辺は $T$ に $S \setminus T$ を足したときの増分，右辺は $S \cap T$ に同じ $S \setminus T$ を足したときの増分である．$S \cap T$ は $T$ に含まれるから，「すでに知っていることが多いほど，同じものを足したときの増分は小さい」と読める．証明で不等号が入ったのは 定理 1.2.4 を当てた一箇所だけで，劣モジュラ性は条件付けの単調性の言い換えにほかならない．

上の三つは，$S$ ごとに決まる値がどう並ぶかだけを述べていて，値がエントロピーであることをもう使っていない．同じ三つを満たす集合の関数には名前が付いている．

::: definition 16.1.7 ポリマトロイドの階数関数
$E$ を有限集合とし，$E$ の部分集合に実数を返す関数 $\mathrm{rk}$ が次の三つを満たすとする．

1. $\mathrm{rk}(\emptyset) = 0$ である．
2. $S \subseteq T \subseteq E$ ならば $\mathrm{rk}(S) \le \mathrm{rk}(T)$ である．
3. どの $S, T \subseteq E$ についても $\mathrm{rk}(S \cup T) + \mathrm{rk}(S \cap T) \le \mathrm{rk}(S) + \mathrm{rk}(T)$ である．

このとき $\mathrm{rk}$ を $E$ 上の **ポリマトロイドの階数関数** と呼ぶ．
:::

::: corollary 16.1.8
定義 16.1.1 の設定で，$S$ に $H(X_S)$ を対応させる関数は $\{1,\dots,n\}$ 上のポリマトロイドの階数関数（定義 16.1.7）である．
:::

::: proof
定義 16.1.7 の第 $1$ の条件は，$X_\emptyset$ のとりうる値が一つしかないので 定義 1.1.1 の和が $-1\log 1 = 0$ の一項だけになることによる．第 $2$ の条件は 命題 16.1.5，第 $3$ の条件は 定理 16.1.6 である．
:::

::: formalization-note
形式化はポリマトロイドを，階数関数と三つの条件を束ねた構造として持つ（`Polymatroid` (`InformationTheory/Polymatroid/Basic.lean`)．台となる集合に有限性を課していない点が 定義 16.1.7 と違う）．部分集合のエントロピーからその構造を組み立てる `entropyPolymatroid` (`InformationTheory/Shannon/Polymatroid.lean`) もあるが，構造も，構造を組み立てる宣言も結論をもたないので，どちらも形式化ポインタには置かない．機械検証が及ぶのは三つの条件のほうで，第 $1$ の条件を `jointEntropySubset_empty` (`InformationTheory/Shannon/Polymatroid.lean`) が，第 $2$ と第 $3$ の条件を 命題 16.1.5 と 定理 16.1.6 に紐付けた宣言が検証している．
:::

名前が付いたことで，$H(X_S)$ について示すことのどこまでが値の出どころに依らないのかを問えるようになる．この問いには 16.3 節 で答える（系 16.3.4）．次節の Han の不等式は，$(n-1)$ 倍した全体のエントロピーを，番号を $1$ 個ずつ抜いた $n$ 通りのエントロピーの和で上から押さえる不等式で，その証明が使うのは 定理 16.1.4 のチェイン則と，定理 1.2.3 と 定理 1.2.4 である．
