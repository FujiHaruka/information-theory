# 16.6 行列式の不等式

本節の対象は確率変数ではなく，$n$ 次の実対称正定値行列である．正定値行列 $\Sigma$ に対し $\det\Sigma$ は正で，その $1/n$ 乗は行列の大きさを $1$ 座標あたりに直した量にあたる．実際，$\alpha > 0$ に対し単位行列の $\alpha$ 倍では $\det(\alpha I) = \alpha^n$ だから，$1/n$ 乗はちょうど $\alpha$ になる．本節が示すのは，二つの正定値行列を足すとこの量が足し算以上になる，という不等式である．

行列式が出てくる筋は，ガウス分布を通すと見える．$X_1,\dots,X_n$ を独立な実数値確率変数とし，各 $X_i$ が分散 $a_i > 0$ のガウス分布に従うとする．結合微分エントロピー（7.4 節）は，系 7.4.4 と 定理 7.2.2 より各成分の値の和 $\sum_{i=1}^{n}\frac12\log\big(2\pi e\,a_i\big)$ で，$a_1\cdots a_n$ を分散を対角に並べた行列 $\Sigma$ の行列式と読めば $\frac12\log\big((2\pi e)^n\det\Sigma\big)$ と書ける．これを $n$ で割って $1$ 座標あたりに直したものを，16.7 節 のエントロピーべきと同じように $2$ 倍して指数に持ち上げると，出てくるのは $2\pi e\,(\det\Sigma)^{1/n}$ である（$1$ 次元の $\sigma^2$ で読むと 命題 16.7.4 の $2\pi e\sigma^2$ にあたる）．定数の $2\pi e$ を別にすれば，これが $(\det\Sigma)^{1/n}$ にほかならない．本節の不等式は，この量が二つの行列を足したときに足し算以上になると言っており，16.8 節 で借りるエントロピーべき不等式が実軸の上の独立な和について述べるのと，同じ形をしている．

Cover–Thomas はこの不等式を，共分散行列が $\Sigma_1$，$\Sigma_2$ であるガウスベクトルにエントロピーべき不等式を当てて導く．本書は $n$ 次元のエントロピーべき不等式を述べないので，その道は通らない．代わりに，前節の 補題 16.5.5 を行列の固有値に当てる直接の道をとる．そのために，線形代数の事実を一つ借りる．

**実対称行列のスペクトル分解**を借りる．$n$ 次の実対称行列は直交行列によって対角化でき，対角に並ぶ固有値はすべて実数である，という事実である．あわせて，行列式が固有値の積に等しいこと，行列式が積について $\det(MN) = \det M\cdot\det N$ と分かれること，および実対称行列が正定値であることと固有値がすべて正であることが同値であることも借りる．当てる相手は 定理 16.6.1 の証明に現れる三つの行列，すなわち $\Sigma_1$，$\Sigma_2$，およびそこで作る $\Sigma_0 := \Sigma_1^{-1/2}\,\Sigma_2\,\Sigma_1^{-1/2}$ である．依存するのは 定理 16.6.1 の証明だけで，本書のほかの主張はこれを使わない．

借りた事実が返す固有値を，以下 $\lambda_1,\dots,\lambda_n$ と書く．この文字は既出の章がそれぞれ別の意味に使っているが，本節のものはそのどれとも別である．

::: theorem 16.6.1 Minkowski の行列式不等式
$n \ge 1$ とし，$\Sigma_1$，$\Sigma_2$ を $n$ 次の実対称正定値行列とすると
$$
(\det\Sigma_1)^{1/n} + (\det\Sigma_2)^{1/n} \;\le\; \big(\det(\Sigma_1+\Sigma_2)\big)^{1/n}
$$
である．
:::

::: proof
はじめに $\Sigma_1$ の平方根を作る．借りたスペクトル分解により $\Sigma_1$ は直交行列で対角化でき，正定値だから対角に並ぶ固有値はすべて正である．それぞれを正の平方根に取り替えて同じ直交行列で戻した行列は実対称で，固有値がすべて正だから正定値であり，$2$ 乗すると $\Sigma_1$ になる．これを $\Sigma_1^{1/2}$ と書き，その逆行列を $\Sigma_1^{-1/2}$ と書く．逆行列も同じ直交行列で対角化され，固有値は正の数の逆数だから，これも実対称正定値である．

$\Sigma_0 := \Sigma_1^{-1/2}\,\Sigma_2\,\Sigma_1^{-1/2}$ とおく．$\Sigma_1^{-1/2}$ と $\Sigma_2$ が実対称だから $\Sigma_0$ も実対称であり，$x \ne 0$ に対し $\Sigma_1^{-1/2}$ が正則なので $\Sigma_1^{-1/2}x \ne 0$ であって
$$
x^{\mathsf T}\Sigma_0 x \;=\; \big(\Sigma_1^{-1/2}x\big)^{\mathsf T}\,\Sigma_2\,\big(\Sigma_1^{-1/2}x\big) \;>\; 0
$$
だから $\Sigma_0$ は正定値である．借りたスペクトル分解により $\Sigma_0$ の固有値 $\lambda_1,\dots,\lambda_n$ はすべて正で，$\Sigma_0$ を対角化する直交行列は $I + \Sigma_0$ も対角化するから
$$
\det\Sigma_0 \;=\; \prod_{i=1}^{n}\lambda_i,
\qquad
\det(I+\Sigma_0) \;=\; \prod_{i=1}^{n}(1+\lambda_i)
$$
である．$\Sigma_2 = \Sigma_1^{1/2}\,\Sigma_0\,\Sigma_1^{1/2}$ と $\Sigma_1 + \Sigma_2 = \Sigma_1^{1/2}\,(I+\Sigma_0)\,\Sigma_1^{1/2}$ に行列式の積の規則を当て，$\det(\Sigma_1^{1/2})^2 = \det\Sigma_1$ を使うと
$$
\det\Sigma_2 \;=\; \det\Sigma_1\cdot\det\Sigma_0,
\qquad
\det(\Sigma_1+\Sigma_2) \;=\; \det\Sigma_1\cdot\det(I+\Sigma_0)
$$
である．$\det\Sigma_1 > 0$ だから，示すべき不等式の両辺を $(\det\Sigma_1)^{1/n}$ で割ると
$$
1 + \Big(\prod_{i=1}^{n}\lambda_i\Big)^{1/n} \;\le\; \Big(\prod_{i=1}^{n}(1+\lambda_i)\Big)^{1/n}
$$
と同値になる．

これを示す．補題 16.5.5 を $t_i = 1/(1+\lambda_i)$ ととって当てたものと，$t_i = \lambda_i/(1+\lambda_i)$ ととって当てたものを足すと
$$
\Big(\prod_{i=1}^{n}\frac{1}{1+\lambda_i}\Big)^{1/n} + \Big(\prod_{i=1}^{n}\frac{\lambda_i}{1+\lambda_i}\Big)^{1/n}
  \;\le\; \frac1n\sum_{i=1}^{n}\frac{1}{1+\lambda_i} + \frac1n\sum_{i=1}^{n}\frac{\lambda_i}{1+\lambda_i}
  \;=\; 1
$$
である．最後の等号は，$i$ ごとに二つの項を足すと $1$ になり，それを $n$ 個足して $n$ で割ることによる．両辺に正の数 $\big(\prod_{i=1}^{n}(1+\lambda_i)\big)^{1/n}$ を掛けると，左辺の第 $1$ 項は $1$ に，第 $2$ 項は $\big(\prod_{i=1}^{n}\lambda_i\big)^{1/n}$ になるから，示すべき不等式を得る．
:::

::: formalized
`minkowskiDeterminantInequality` (`InformationTheory/Shannon/MinkowskiDet.lean`)
:::

::: formalization-note
宣言は行と列の添字を任意の有限型でとる．本文が $n$ 次と書いているのは，その型の要素数が $n$ である場合にあたる．形式化も $\Sigma_1$ の平方根を両側から掛けて $\det(\Sigma_1+\Sigma_2)$ を $\det\Sigma_1$ と $\det(I+\Sigma_0)$ の積に分けるが，その平方根の作り方が本文と違う．本文は借りたスペクトル分解で対角化してから対角の固有値を平方根に取り替えるのに対し，形式化は行列に関数を当てる一般の仕組み（連続汎関数計算）で平方根を直に取る．スペクトル分解が形式化の側で効くのは，行列式を固有値の積で書く段，すなわち $\det\Sigma_0$ と $\det(I+\Sigma_0)$ を $\lambda_i$ の積に直すところである．締めは固有値についてのスカラーの不等式 `geom_mean_superadditive` (`InformationTheory/Shannon/MinkowskiDet.lean`) で，これは本文が 補題 16.5.5 を二度当てて足すのと同じ計算を，重みつきの相加相乗平均から直に行うものである．一般に等号がいつ成り立つかを述べる宣言はなく，本文も 定理 16.6.1 については述べない．
:::

::: example 16.6.2
$n = 2$ とし，$\Sigma_1$ を単位行列，$\Sigma_2$ を対角成分が $a > 0$，$b > 0$ の対角行列とすると，定理 16.6.1 は
$$
1 + \sqrt{ab} \;\le\; \sqrt{(1+a)(1+b)}
$$
になる．$a = 4$，$b = 1$ では両辺が $3$ と $\sqrt{10} = 3.1622\ldots$ で狭義であり，$a = b = 2$ では両辺とも $3$ で等号である．この形で等号になるのは $a = b$ のとき，すなわち $\Sigma_2$ が $\Sigma_1$ の定数倍のときに限る．
:::

::: proof
$\det\Sigma_1 = 1$，$\det\Sigma_2 = ab$ であり，$\Sigma_1 + \Sigma_2$ は対角成分が $1+a$，$1+b$ の対角行列だから $\det(\Sigma_1+\Sigma_2) = (1+a)(1+b)$ である．$n = 2$ なので $1/n$ 乗は平方根であり，定理 16.6.1 はこの形になる．$a = 4$，$b = 1$ では左辺が $1 + \sqrt{4} = 3$，右辺が $\sqrt{5 \cdot 2} = \sqrt{10}$ である．$a = b = 2$ では左辺が $1 + \sqrt{4} = 3$，右辺が $\sqrt{3 \cdot 3} = 3$ である．なお両辺とも正だから，この不等式は両辺を $2$ 乗した $1 + 2\sqrt{ab} + ab \le 1 + a + b + ab$，すなわち $2\sqrt{ab} \le a + b$ と同値で，これは $n = 2$ の 補題 16.5.5 にほかならない．最後の不等式は $\big(\sqrt a - \sqrt b\big)^2 \ge 0$ を移項したものだから，等号になるのは $\sqrt a = \sqrt b$ のとき，すなわち $a = b$ のときに限る．そのとき $\Sigma_2 = a\,\Sigma_1$ である．
:::

**同時に対角化してしまうと読む.** 例 16.6.2 で見たとおり，$n = 2$ で片方を単位行列にとると 定理 16.6.1 は $2$ 点の相加相乗平均と同値になる．一般の場合の証明がやっているのも同じことで，$\Sigma_1^{-1/2}$ を両側から掛けて片方を単位行列に直し，残った $\Sigma_0$ をスペクトル分解で対角に直してしまえば，残るのは固有値についてのスカラーの不等式である．行列がそのままでは対角でないぶんの手間は，スペクトル分解の借用がすべて引き受けている．借りたスペクトル分解を別にすれば，本節が使う解析的な事実は，補題 16.5.5 の証明が 補題 1.1.6 を $\log$ に当てる一箇所だけである．残りは行列式と固有値の計算である．

**部分集合を動かす枠を離れる.** 本章の中心にあった 定義 16.1.1 の $H(X_S)$ は，16.1 節 から 16.5 節 までのすべての節に現れたが，本節にも 16.7 節 と 16.8 節 にも現れない．$H(X_S)$ は番号の集合 $S$ を動かして初めて意味を持つ量で，本節の対象である正定値行列にも，あとの二節が扱う実軸に値をとる確率変数 $1$ 個ないし $2$ 個にも，動かす部分集合がないからである．次節は，本節の入口で予告した実軸の側の量を定めにかかる．
