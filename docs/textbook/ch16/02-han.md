# 16.2 Han の不等式

16.1 節 は部分集合のエントロピーを集合の関数として眺め，三つの性質を出した．本節はそこから最初の不等式を引く．$n$ 個の変数を，番号を $1$ 個ずつ抜いた $n$ 通りの見方で観察する人たちがいるとしよう．どの人も $n-1$ 個しか見ていないので，一人ぶんでは全体に届かない．ところが $n$ 人ぶんを足すと，どの番号も $n-1$ 回ずつ数えられて全体を何重にも覆うことになる．そこで重なりのぶんを戻す．$n$ 人ぶんの合計を $n-1$ で割っても，なお全体のエントロピー以上である，というのが Han の不等式である．

::: theorem 16.2.1 Han の不等式
定義 16.1.1 の設定で
$$
(n-1)\,H\big(X_{\{1,\dots,n\}}\big) \;\le\; \sum_{i=1}^{n} H\big(X_{\{1,\dots,n\}\setminus\{i\}}\big)
$$
である．
:::

::: proof
番号 $i$ を一つ固定する．補題 16.1.2 より $X_{\{1,\dots,n\}}$ は対 $\big(X_{\{1,\dots,n\}\setminus\{i\}},\, X_i\big)$ とみてよく，定理 1.2.3 をこの対に当てると
$$
H\big(X_{\{1,\dots,n\}}\big) - H\big(X_{\{1,\dots,n\}\setminus\{i\}}\big)
  \;=\; H\big(X_i \,\big|\, X_{\{1,\dots,n\}\setminus\{i\}}\big)
$$
である．$\{1,\dots,i-1\}$ と $\{i+1,\dots,n\}$ は交わらず，和が $\{1,\dots,n\}\setminus\{i\}$ である．補題 16.1.2 より，右辺の条件を対 $\big(X_{\{1,\dots,i-1\}},\, X_{\{i+1,\dots,n\}}\big)$ とみて 定理 1.2.4 を当てると
$$
H\big(X_i \,\big|\, X_{\{1,\dots,n\}\setminus\{i\}}\big) \;\le\; H\big(X_i \,\big|\, X_{\{1,\dots,i-1\}}\big)
$$
である．$i$ について足し合わせる．左辺の和は $n\,H(X_{\{1,\dots,n\}}) - \sum_{i=1}^{n} H(X_{\{1,\dots,n\}\setminus\{i\}})$ であり，右辺の和は 定理 16.1.4 を $S = \{1,\dots,n\}$ に当てて $H(X_{\{1,\dots,n\}})$ に等しい．移項すれば主張を得る．
:::

::: formalized
`han_inequality` (`InformationTheory/Shannon/Han/Basic.lean`)
:::

::: formalization-note
宣言は，番号 $i$ を抜いた項を部分集合のエントロピー（定義 16.1.1）としてではなく，$i$ 番目を除いた族のエントロピーとして直に定めている（`jointEntropyExcept` (`InformationTheory/Shannon/Han/Basic.lean`)）．二つが同じ値であることは，系 16.2.2 に紐付けた宣言の証明の中で使われているが，公開された宣言としては立っていない．
:::

**覆いの回数で読む.** 証明を通してみると，やっていることは二段である．まず 定理 1.2.3 で，番号 $i$ を抜いた見方と全体との差が「$i$ 以外をすべて知ったうえで $X_i$ に残る不確かさ」であることを出す．次に 定理 1.2.4 で，その条件を $i$ より小さい番号だけに減らす．減らしたあとの項は $i$ によらず 定理 16.1.4 の項そのものなので，$n$ 個ぶんを足すと $H(X_{\{1,\dots,n\}})$ に化ける．左辺で $n$ 回数えた全体から，この $1$ 回ぶんを差し引いたものが $(n-1)$ 倍である．

::: corollary 16.2.2 部分集合版の Han の不等式
定義 16.1.1 の設定で，空でない $S \subseteq \{1,\dots,n\}$ について
$$
\big(\lvert S\rvert - 1\big)\,H(X_S) \;\le\; \sum_{i \in S} H\big(X_{S \setminus \{i\}}\big)
$$
である．
:::

::: proof
$S$ に属する番号を小さい順に $i_1 < \dots < i_{\lvert S\rvert}$ と並べ，$Y_k := X_{i_k}$ とおく．$Y_1,\dots,Y_{\lvert S\rvert}$ は 定義 16.1.1 の設定を満たす族である．補題 16.1.2 より，$R \subseteq S$ に対し，$R$ に属する番号を $Y$ の側の番号に読み替えた集合を $R'$ と書くと $H(X_R) = H(Y_{R'})$ である．定理 16.2.1 を $Y$ の族に当てると，左辺は $(\lvert S\rvert - 1)H(Y_{\{1,\dots,\lvert S\rvert\}}) = (\lvert S\rvert-1)H(X_S)$ であり，右辺は $Y$ の番号を $1$ 個ずつ抜いた項の和である．$Y$ の番号 $k$ を抜いた集合に対応する $S$ の部分集合は $S \setminus \{i_k\}$ だから，右辺は $\sum_{i \in S} H(X_{S\setminus\{i\}})$ に等しい．
:::

::: example 16.2.3
例 16.1.3 の族について 定理 16.2.1 の両辺を計算すると，(a) では $4$ と $5$，(b) では $4$ と $6$ である．
:::

::: proof
どちらの族でも $H(X_{\{1,2,3\}}) = 2$ だから，$n = 3$ より左辺は $2 \cdot 2 = 4$ である．右辺は $2$ 点集合についての値の和で，(a) では $H(X_{\{2,3\}}) + H(X_{\{1,3\}}) + H(X_{\{1,2\}}) = 2 + 2 + 1 = 5$，(b) では $2 + 2 + 2 = 6$ である．
:::

定理 16.2.1 が比べたのは，$n-1$ 点の集合と全体という隣り合う二つの大きさである．同じ比べ方は $k$ 点と $k+1$ 点のあいだでもできるはずで，そうすると $k$ を $1$ から $n$ まで動かした鎖ができる．大きさの違う集合どうしを比べるには，集合の個数と番号の個数で割って $1$ 番号あたりに直しておく必要がある．

::: definition 16.2.4 $k$ 点部分集合の平均エントロピー
定義 16.1.1 の設定で $1 \le k \le n$ とする．$\{1,\dots,n\}$ の $k$ 点部分集合すべてにわたる和をとって
$$
H_k \;:=\; \frac{1}{k\binom{n}{k}} \sum_{\lvert S\rvert = k} H(X_S)
$$
と定め，これを **$k$ 点部分集合の平均エントロピー** と呼ぶ．
:::

$H_k$ は引数をとらない．第4章 の $H_D(X)$ は底を $D$ にとったエントロピーで，つねに引数をとるので，二つは引数の有無で見分ける．$\binom{n}{k}$ は $k$ 点部分集合の個数だから，$H_k$ は「$k$ 点集合を一つ選んだときの，番号 $1$ 個あたりのエントロピー」を集合について平均したものである．$k = n$ のときは $H_n = H(X_{\{1,\dots,n\}})/n$ で，$k = 1$ のときは $H_1 = \frac1n\sum_{i=1}^{n} H(X_{\{i\}})$ である．

::: formalization-note 定義 16.2.4 と 定理 16.2.5 に共通
定義 16.2.4 の $H_k$ にあたる宣言も，定理 16.2.5 にあたる宣言もない．$k$ 点部分集合にわたる部分集合のエントロピーの和を結論に含む宣言を，名前ではなく結論の形で探して見つからなかった．機械検証が及ぶのは 系 16.2.2 までで，そこから先の数え上げは本文の側にある．
:::

::: theorem 16.2.5
定義 16.1.1 の設定で $1 \le k < n$ とすると，定義 16.2.4 の量について $H_{k+1} \le H_k$ である．
:::

::: proof
$\lvert S\rvert = k+1$ を満たす $S$ に 系 16.2.2 を当てると $k\,H(X_S) \le \sum_{i \in S} H(X_{S\setminus\{i\}})$ である．これを $\lvert S\rvert = k+1$ の $S$ すべてにわたって足すと
$$
k \sum_{\lvert S\rvert = k+1} H(X_S)
  \;\le\; \sum_{\lvert S\rvert = k+1}\ \sum_{i \in S} H\big(X_{S\setminus\{i\}}\big)
$$
である．右辺は，$\lvert S\rvert = k+1$ かつ $i \in S$ を満たす対 $(S, i)$ にわたる和である．対 $(S,i)$ に対 $(S\setminus\{i\},\, i)$ を対応させると，これは $\lvert T\rvert = k$ かつ $i \notin T$ を満たす対 $(T,i)$ の全体との一対一の対応になる（逆向きの対応は $(T,i)$ に $(T\cup\{i\},\, i)$ を対応させるものである）．$T$ を固定するごとに $i$ の選び方は $n-k$ 通りだから，右辺は $(n-k)\sum_{\lvert T\rvert = k} H(X_T)$ に等しい．よって
$$
k \sum_{\lvert S\rvert = k+1} H(X_S) \;\le\; (n-k) \sum_{\lvert T\rvert = k} H(X_T)
$$
である．$1 \le k < n$ だから $k(n-k)\binom{n}{k}$ は正で，両辺をこれで割ると
$$
\frac{1}{(n-k)\binom{n}{k}} \sum_{\lvert S\rvert = k+1} H(X_S)
  \;\le\; \frac{1}{k\binom{n}{k}} \sum_{\lvert T\rvert = k} H(X_T)
$$
である．右辺は 定義 16.2.4 の $H_k$ である．左辺については，いま使った対応の両側を数え直すと，対 $(S,i)$ の個数は $S$ を先に選ぶ数え方で $(k+1)\binom{n}{k+1}$，$T$ を先に選ぶ数え方で $(n-k)\binom{n}{k}$ だから，この二つは等しい．よって左辺は $H_{k+1}$ に等しい．
:::

::: example 16.2.6
例 16.1.3 の族について 定義 16.2.4 の値を計算すると，(a) では $H_1 = 1$，$H_2 = 5/6$，$H_3 = 2/3$ であり，(b) では $H_1 = H_2 = 1$，$H_3 = 2/3$ である．
:::

::: proof
$n = 3$ だから $\binom31 = \binom32 = 3$，$\binom33 = 1$ である．(a) では $1$ 点集合についての値の和が $1+1+1 = 3$，$2$ 点集合についての値の和が $1+2+2 = 5$，$3$ 点集合についての値が $2$ だから，$H_1 = 3/(1\cdot 3) = 1$，$H_2 = 5/(2\cdot 3) = 5/6$，$H_3 = 2/(3\cdot 1) = 2/3$ である．(b) では三つの和がそれぞれ $3$，$6$，$2$ だから，$H_1 = 3/3 = 1$，$H_2 = 6/6 = 1$，$H_3 = 2/3$ である．
:::

(a) では $H_1 > H_2 > H_3$ の不等号が二つとも狭義になり，(b) では最初の不等号が等号になる．(b) で等号が起きるのは，$2$ 点集合についての値 $2$ がちょうど $1$ 点集合についての値 $1$ の $2$ 倍で，番号 $1$ 個あたりに直すと $1$ 点集合のときと変わらないからである．その中身は，どの二つの変数も独立だということである．例 16.1.3 の証明で見たとおり，(b) ではどの $2$ 点集合についても対が $4$ 点上の一様分布に従い，これは二つの一様分布の積である．三つまとめると値が $2$ にとどまるので，そこから先の不等号は狭義になる．

$H_k$ が $k$ について下がっていくという読み方は，番号 $1$ 個あたりの不確かさが「まわりを何個いっしょに見るか」で決まり，いっしょに見る個数が増えるほど小さくなる，ということである．鎖の両端は $H_1$ と $H_n$ で，前者は $1$ 変数ずつのエントロピーの平均，後者は全体のエントロピーを $n$ で割ったものである．この両端どうしを直に比べる不等式は，次節で別の道から出る（系 16.3.2）．
