# 16.8 Stam の不等式とエントロピーべき不等式

16.7 節 で借りた de Bruijn の恒等式は，独立なガウス雑音を足していったときの微分エントロピーの増え方を Fisher 情報量で書いた．増え方が Fisher 情報量で書けるなら，Fisher 情報量の側で成り立つ不等式は，積分して微分エントロピーの側の不等式に移せる．その Fisher 情報量の側の不等式が Stam の不等式で，移した先がエントロピーべき不等式である．本節は二つを借り，借りたほうから何が出るかを見る．

和の Fisher 情報量やエントロピーべきを書くには，和が密度をもつことが要る．そこで **独立な和の密度** を借りる．独立な実数値確率変数 $X$，$Y$ がそれぞれ密度 $f$，$g$（定義 7.1.1）をもつとき，$X+Y$ は密度をもち，その一つは $z \mapsto \int_{\mathbb R} f(x)\,g(z-x)\,dx$ である，という学部の確率で扱う事実である．当てる対象は，本節に現れる独立な二つの実数値確率変数の和だけである．依存するのは，本節が借りる二つの不等式の主張と，例 16.8.2 の証明である．

::: formalization-note
和の分布から取り出した密度が，$X$ と $Y$ の分布から取り出した密度の畳み込みとほとんどすべての点で一致することは，`rnDeriv_map_sum_ae` (`InformationTheory/Shannon/EPI/InfiniteVariance/Truncation/Density.lean`) が検証している．ただし宣言が扱うのは，分布から Lebesgue 測度に対する Radon–Nikodym 微分として取り出したこの代表元だけで，本文が任意の密度 $f$，$g$ をとるより狭い．そのためポインタには置かない．
:::

**Stam の不等式** を借りる．独立な実数値確率変数 $X$，$Y$ について $J(X)$，$J(Y)$，$J(X+Y)$（定義 16.7.7）がいずれも定まって正であるならば
$$
\frac{1}{J(X+Y)} \;\ge\; \frac{1}{J(X)} + \frac{1}{J(Y)}
$$
である，という不等式である．当てる対象は，本節に現れる独立な二つの実数値確率変数だけである．本書のどの主張もこれを使わない．次に借りる不等式がどこから来るかを述べるために置く．

::: formalization-note
一般の密度についてこの不等式を述べる宣言 `stam_inequality_via_predicate_optimal` (`InformationTheory/Shannon/EPI/Stam/Inequality.lean`) はあるが，仮定が本文の借用より強い．本文が置くのは独立性と，三つの Fisher 情報量が定まって正であることだけなのに対し，宣言は密度それぞれに，実軸の全体で微分可能で正であること，両端で $0$ に近づくこと，導関数が積分できてその積分が $0$ であること，密度と導関数が有界であることといった正則条件の束を課す（不等式の核にあたる部分のほうは，可測で独立な二つの確率変数について別の宣言が無条件に供給する）．そのためポインタには置かない．この束が仮定なしに満たされる場合として，二つの密度がどちらも同じガウス核で平滑化されたものであるときの `stam_inequality_smoothed_density` (`InformationTheory/Shannon/EPI/Stam/Standalone.lean`) がある．機械検証が及ぶのはそこまでである．
:::

Stam の不等式は，$1/J$ という量が独立な和で足し算以上になると言っている．de Bruijn の恒等式に沿ってこれを積分する道筋が知られていて，その先に出てくるのが，微分エントロピーを指数に持ち上げた量についての同じ形の不等式である．本書はその積分の段を用意していないので，出てくる結論のほうを借りる．

**エントロピーべき不等式**（Shannon–Stam）を借りる．$X$，$Y$ を独立な実数値確率変数とし，どちらも密度をもつとする（借りた独立な和の密度より $X+Y$ も密度をもつ）．$h(X)$，$h(Y)$，$h(X+Y)$（定義 7.1.2）がいずれも定まるならば
$$
N(X+Y) \;\ge\; N(X) + N(Y)
$$
である，という不等式である（$N$ は 定義 16.7.1 のエントロピーべきである）．当てる対象は，本節に現れる独立な二つの実数値確率変数だけである．依存するのは 例 16.8.2 と 系 16.8.3 と 系 16.8.4 の三つである．証明を載せないのは，次の理由による．知られている証明は，借りた Stam の不等式を de Bruijn の恒等式に沿って積分するものである．その筋を本書の仮定のもとで通すには，Fisher 情報量が定まって正であることを確かめる段（Stam の不等式はそれを仮定に置くが，エントロピーべき不等式は置いていない）と，借りた de Bruijn の恒等式が課す $2$ 乗の平均を用意する段（こちらも本文の仮定にはない）と，積分して両端の極限をとる段の三つが要る．本書はどれも用意していない．

`entropy_power_inequality_of_ac` (`InformationTheory/Shannon/EPI/Unconditional/Dispatch.lean`)
:::

::: formalization-note
宣言の仮定は本文の四つと一つずつ対応する．独立性がそのまま，$X$ と $Y$ の分布が Lebesgue 測度について絶対連続であることが「どちらも密度をもつ」に，三つの対数密度が積分できることが「$h(X)$，$h(Y)$，$h(X+Y)$ がいずれも定まる」にあたる（可測性は形式化の都合である）．宣言は和が密度をもつことを仮定にとらず，$X$ が密度をもつことと独立性から導いている．形式化はさらに，密度も微分エントロピーの有限性も仮定せず，可測性と独立性だけを仮定する形 `entropyPowerExt_add_ge` (`InformationTheory/Shannon/EPI/Unconditional/DispatchFull.lean`) を持つ．そちらは，密度をもたない分布と微分エントロピーが $-\infty$ に発散する分布に $0$ を，$+\infty$ に発散する分布に $\infty$ を返す量についての不等式である．本書は 定義 7.1.2 で $h$ が定まる場合だけを扱うので，本文はその形を述べない．
:::

まず，不等号が等号になる場合を見ておく．

::: proposition 16.8.1 ガウス分布での加法性
$\mu_1$，$\mu_2$ を実数，$\sigma_1^2 > 0$，$\sigma_2^2 > 0$ とし，$X$ が $\mathcal N(\mu_1,\sigma_1^2)$，$Y$ が $\mathcal N(\mu_2,\sigma_2^2)$（定義 7.2.1）に従い，$X$ と $Y$ は独立であるとすると $N(X+Y) = N(X) + N(Y)$ である．
:::

::: proof
借りたガウス分布の畳み込み（16.7 節）より $X+Y$ は $\mathcal N(\mu_1+\mu_2,\ \sigma_1^2+\sigma_2^2)$ に従う．命題 16.7.4 を三つに当てると，$N(X+Y) = 2\pi e(\sigma_1^2+\sigma_2^2)$，$N(X) = 2\pi e\sigma_1^2$，$N(Y) = 2\pi e\sigma_2^2$ である．右の二つを足すと左の値になる．
:::

::: formalized
`entropyPower_gaussian_additivity` (`InformationTheory/Shannon/EntropyPower/Inequality.lean`)
:::

ガウス分布でなければ狭義になることがある．例 16.8.2 がそうで，そこでは下界と上界の両方を数で並べられる．上界を出すのに分散が要るので，独立な二つの実数値確率変数の和の分散が，それぞれの分散の和に等しいことを既知とする．当てる対象は 例 16.8.2 の $X+Y$ と，本節の終わりでエントロピーべきと分散を並べる段落の二つだけである．

::: example 16.8.2 独立な二つの一様分布の和
$X$，$Y$ を独立な実数値確率変数で，どちらも $[0,1]$ の上の一様分布に従うものとする．このとき $N(X) = N(Y) = 1$ であり，$X+Y$ は密度をもって $h(X+Y)$ は定まり $N(X+Y) = e$ である．借りたエントロピーべき不等式が与える下界は $2$，命題 16.7.5 が $X+Y$ の分散について与える上界は $\pi e/3$ で，
$$
2 \;<\; e = 2.7182\ldots \;<\; \pi e/3 = 2.8465\ldots
$$
である．
:::

::: proof
例 7.1.3 を $w = 1$ で当てると $h(X) = h(Y) = \log 1 = 0$ だから，定義 16.7.1 より $N(X) = N(Y) = 1$ である．借りた独立な和の密度より $X+Y$ は密度をもち，その一つは $z \mapsto \int_{\mathbb R} f(x)f(z-x)\,dx$（$f$ は $[0,1]$ の上で $1$，その外で $0$）である．この積分は $[0,1]$ と $[z-1,z]$ の共通部分の長さだから，$0 \le z \le 1$ で $z$，$1 \le z \le 2$ で $2-z$，その外で $0$ である．

$h(X+Y)$ を求める．借りた微積分の計算規則（16.7 節）の部分積分と $\log t$ の導関数より，$0 < \varepsilon < 1$ について
$$
\int_\varepsilon^1 t\log t\,dt \;=\; \Big[\frac{t^2}{2}\log t\Big]_\varepsilon^1 - \frac{\log e}{2}\int_\varepsilon^1 t\,dt
$$
であり，$\varepsilon \downarrow 0$ とすると $\varepsilon^2\log\varepsilon \to 0$ だから $\int_0^1 t\log t\,dt = -\frac{\log e}{4}$ である．密度は $[0,1]$ の上で $z$，$[1,2]$ の上で $2-z$ だから，定義 7.1.2 より
$$
h(X+Y) \;=\; -\int_0^1 z\log z\,dz \;-\; \int_1^2 (2-z)\log(2-z)\,dz
$$
であり，第 $2$ の積分は借りた置換積分を $z \mapsto 2-z$ ととって使うと第 $1$ の積分に移る．よって $h(X+Y) = -2\int_0^1 t\log t\,dt = \frac{\log e}{2}$ であり，$\log N(X+Y) = 2h(X+Y) = \log e$ だから 定義 16.7.1 より $N(X+Y) = e$ である．

下界と上界を求める．$X$ と $Y$ は独立で，どちらも密度をもち，$h(X)$，$h(Y)$，$h(X+Y)$ はいずれも定まるから，借りたエントロピーべき不等式が当たって下界は $N(X)+N(Y) = 2$ である．例 7.2.6 の証明が求めたとおり長さ $1$ の区間の上の一様分布の分散は $1/12$ だから，借りた独立な和の分散より $X+Y$ の分散は $1/6$ である．$X+Y$ は $[0,2]$ に値をとるので平均をもち，命題 16.7.5 を $\sigma^2 = 1/6$ ととって当てると $N(X+Y) \le 2\pi e/6 = \pi e/3$ である．$\pi e = 8.5397\ldots$ だから $\pi e/3 = 2.8465\ldots$ であり，$e = 2.7182\ldots$ と $2$ を並べて主張の不等式を得る．
:::

例 16.8.2 では，下界も上界も等号にならない．下界のほうは 命題 16.8.1 より，独立な二つのガウス分布をとれば等号になる．上界のほうは 系 16.7.6 より，やはりガウス分布で等号になる．一様分布は，どちらの端からも離れたところにいる．

なお，本節が借りた Stam の不等式のほうは，例 16.8.2 の三つの分布には当てられない．定義 16.7.7 は密度が実軸のすべての点で微分可能かつ正であることを求めるのに対し，一様分布の密度も和の密度も区間の外では $0$ だから，$J$ がそもそも定まらない．借りたエントロピーべき不等式のほうは $J$ を使わないので，そちらは当たる．

借りた不等式を微分エントロピーの言葉に戻しておく．

::: corollary 16.8.3 微分エントロピーの形の下界
$X$，$Y$ を独立な実数値確率変数とし，どちらも密度をもつとする．$h(X)$，$h(Y)$，$h(X+Y)$（定義 7.1.2）がいずれも定まるならば
$$
h(X+Y) \;\ge\; \frac12\log\big(N(X) + N(Y)\big)
$$
である（$N$ は 定義 16.7.1 のエントロピーべきである）．
:::

::: proof
借りたエントロピーべき不等式より $N(X+Y) \ge N(X)+N(Y)$ である．定義 16.7.1 より $\log N(X+Y) = 2\,h(X+Y)$ であり，$\log$ が狭義単調（16.4 節）だから $2\,h(X+Y) \ge \log\big(N(X)+N(Y)\big)$ である．両辺を $2$ で割る．
:::

::: formalization-note
微分エントロピーの形で述べた単独の宣言はない．エントロピーべきの和の対数を結論に含む宣言を結論の形で探しても，補題の途中式としてしか現れない．借りたエントロピーべき不等式の紐付け先に，$\log$ を当てる段で要るエントロピーべきの正値性 `entropyPower_pos` (`InformationTheory/Shannon/EntropyPower/Inequality.lean`) と，定義 16.7.1 に紐付けた `log_entropyPower` (`InformationTheory/Shannon/EPI/Plumbing.lean`) を合わせて得られる．
:::

::: corollary 16.8.4 独立な和での狭義増加
$X$，$Y$ を独立な実数値確率変数とし，どちらも密度をもつとする．$h(X)$，$h(Y)$，$h(X+Y)$（定義 7.1.2）がいずれも定まるならば $h(X+Y) > h(X)$ かつ $h(X+Y) > h(Y)$ である．
:::

::: proof
定義 16.7.1 より $N(Y)$ は正だから，借りたエントロピーべき不等式より $N(X+Y) \ge N(X) + N(Y) > N(X)$ である．$\log$ が狭義単調（16.4 節）だから $2\,h(X+Y) = \log N(X+Y) > \log N(X) = 2\,h(X)$ であり，両辺を $2$ で割って前半を得る．仮定は $X$ と $Y$ について対称だから，入れ替えれば後半を得る．
:::

::: formalization-note
系 16.8.4 に対応する単独の宣言もない．借りたエントロピーべき不等式の紐付け先に，エントロピーべきが正であること `entropyPower_pos` (`InformationTheory/Shannon/EntropyPower/Inequality.lean`) と `log_entropyPower` (`InformationTheory/Shannon/EPI/Plumbing.lean`) を合わせて得られる．
:::

系 16.8.4 は，独立なもう一つの確率変数を足すと微分エントロピーが真に増えると言っている．足す相手が雑音である必要はない．要るのは，独立であることと，どちらも密度をもつことと，三つの微分エントロピーがどれも定まることだけである．狭義になるのは $N(Y)$ が必ず正だからで，これは 定義 16.7.1 の作りによる．$N(Y)$ は $h(Y)$ を指数に持ち上げた値だから，$Y$ の散らばりがどれだけ小さくても，$h(Y)$ がどれだけ小さな負の数でも，$0$ にはならない．増える量そのものは，例 16.7.9 のガウス分布なら $\frac12\log\big((\sigma^2+t)/\sigma^2\big)$ と書けていた．

**分散と並べる.** 借りた独立な和の分散より，分散は独立な和でちょうど足し算になる．エントロピーべきは足し算以上にしかならず（借りたエントロピーべき不等式），足し算ちょうどになる場合として 命題 16.8.1 のガウス分布がある．いっぽう 命題 16.7.5 は，エントロピーべきが $2\pi e$ 倍した分散を超えないと言い，系 16.7.6 はガウス分布でその二つが一致すると言う．二つの量は，ガウス分布のところで値も足し算のふるまいも重なり，そこから離れると $N$ のほうが小さくなる余地をもつ．例 16.8.2 の $2 < e < \pi e/3$ は，その余地が実際に空いている一つの場合である．

本章の不等式が第1章のどこに戻るかをたどって，本書を閉じる．離散側，すなわち 16.1 節 から 16.5 節 までで不等号が生まれるのは三つの場所である．定理 1.2.4 と 定理 1.1.5 を当てるところ，命題 1.1.4 の非負性で項を落とすところ（命題 16.1.5 の証明と，定理 16.3.1 が覆う回数を $k$ まで減らす段），そして 16.5 節 が 補題 1.1.6 を $\log$ に直に当てる二箇所（補題 16.5.5 と 命題 16.5.8）である．定理 1.2.4 と 定理 1.1.5 の証明はどちらも 補題 1.1.6 を $\varphi(t) = -t\log t$ に当てるから，一つめと三つめは 補題 1.1.6 を通って $\varphi$ か $\log$ の狭義凹性に着く．二つめだけはそこを通らず，命題 1.1.4 が使う，$\log$ が $(0,1]$ の上で $0$ 以下であることに着く．ほかに引いた 例 1.1.3 と 定理 1.2.3 は 定義 1.1.1 の計算である（系 16.3.4 だけは 定義 16.1.7 の三条件を仮定に置いた主張で，その不等号は仮定から来る）．実軸側，すなわち 16.7 節 と本節で，借りたエントロピーべき不等式に乗らずに不等号が生まれるのは 命題 16.7.5 の一箇所で，定理 7.2.4 を通って 補題 7.2.3 が当てる対数不等式 $\log t \le (t-1)\log e$ に戻り，1.1 節 はこれを $\log$ の狭義凹性から接線として出した．

そこで，狭義凹性として残るのは二つである．$\varphi$ の狭義凹性と $\log$ の狭義凹性で，1.1 節 が信頼の底として認めた三つのうちの二つがこれである（残る一つは $\varphi$ の連続性で，1.1 節 はそれを，端点 $0$ を含む弦まで $\varphi$ の凹性を延ばすのに使った．$\varphi$ の側の帰着はそこも通る）．$n$ 個の変数の族についての Han の不等式も，有限集合の影の大きさについての Loomis–Whitney の不等式も，超立方体の辺の本数の下界も，正定値行列の行列式についての不等式も，たどればこの二つのどちらかに着く．ただし 定理 16.3.1 を経由するもの，すなわち Loomis–Whitney の不等式と，それを使う 定理 16.5.7 は，そのほかにいま見た非負性の段を一つ通る．行列式のほうだけは，そこへ着く前に，借りたスペクトル分解で固有値についての不等式に直す段を通る（16.6 節）．

戻らないのは，本書が名前で借りて証明しなかった定理に乗るものである．本章がそうして借りたのは，16.6 節 の実対称行列のスペクトル分解，16.7 節 の de Bruijn の恒等式，本節の Stam の不等式，そして本節のエントロピーべき不等式で，どれも証明を載せないだけであり，機械検証がどこまで及ぶかは 16.4 節 の断りと借りた場所の注記に書いた．このうち本章の主張の証明が乗っているのは二つである．定理 16.6.1 はスペクトル分解に乗り，例 16.8.2 の下界と 系 16.8.3 と 系 16.8.4 はエントロピーべき不等式に乗る．de Bruijn の恒等式と Stam の不等式は，エントロピーべき不等式がどこから来るかを述べるために置いたもので，本章のどの主張の証明も使わない．ほかに借りた事実と既知とした計算規則は，どれも学部の確率と解析の範囲にあって，不等号を運ぶことはあっても作りはしない．

第1章 1.1 節 は，観測する前の不確かさをどう測るかという問いから始めて，分布だけから決まる一つの数 $-\sum_x p(x)\log p(x)$ に行き着き，それを平均驚き量と読んだ．同じ数が，第2章では，情報源をどこまで短く書けるかの限界になり（定理 2.3.6），第5章では，偏りのないオッズの競馬で比例賭けをしたときの資産の増える速さが $\log\lvert\mathcal X\rvert$ からこの数を引いた残りになり（定理 5.5.1 と 系 5.3.2），第6章では，出力の不確かさから雑音のぶんを差し引いた残りの最大として，通信路で誤りなく送れるレートの限界を決め（定理 6.4.9），第13章では，分布を一度も見ない機械が一本の系列に払う記述の長さの，$1$ 文字あたりの平均になった（定理 13.3.6）．本章では，確率のない有限集合の上に一様分布を置くことで，同じ数についての不等式が，集合の影の大きさ（定理 16.4.2）と超立方体の辺の本数（定理 16.5.3）を数える不等式に化けた．第7章が実数値の確率変数に移した微分エントロピーは，指数に持ち上げれば分散と同じ物差しに載り（命題 16.7.2），ガウス分布では分散の $2\pi e$ 倍にちょうど届く（系 16.7.6）．

第1章 1.1 節 の問いに答えるなら，こうである．観測する前の不確かさを一つの数で測ると決めたことで，符号の長さも，通信路で送れる量も，資産の増える速さも，記述の長さも，その限界が同じ数で言えた．そしてその数は，確率の出てこない集合の影と超立方体の辺の本数まで数えた．
