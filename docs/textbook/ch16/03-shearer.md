# 16.3 Shearer の不等式

定理 16.2.1 が使った覆いは特別なものだった．番号を $1$ 個ずつ抜いた $n$ 個の集合という決まった族で，どの番号もちょうど $n-1$ 回覆われる．証明を読み返すと，この形はほとんど効いていない．効いたのは，各集合について 定理 16.1.4 を書き下し，条件をどれも $i$ より小さい番号の全体にそろえて物差しを合わせ，最後に「どの番号が何回覆われたか」を数えたことだけである．そこで族のほうを一般にとり，覆う回数だけを仮定に残す．

::: theorem 16.3.1 Shearer の不等式
定義 16.1.1 の設定で，$r \ge 1$，$S_1,\dots,S_r \subseteq \{1,\dots,n\}$ とし，$k$ を非負整数とする．どの $i \in \{1,\dots,n\}$ についても $i$ を含む $S_j$ が $k$ 個以上あるならば
$$
k\,H\big(X_{\{1,\dots,n\}}\big) \;\le\; \sum_{j=1}^{r} H\big(X_{S_j}\big)
$$
である．
:::

::: proof
各 $j$ について 定理 16.1.4 を $S_j$ に当てると
$$
H(X_{S_j}) \;=\; \sum_{i \in S_j} H\big(X_i \,\big|\, X_{S_j \cap \{1,\dots,i-1\}}\big)
$$
である．$\{1,\dots,i-1\}$ を，$S_j$ に属する番号と属さない番号に分けると，前者は $S_j \cap \{1,\dots,i-1\}$ であり，二つは交わらず和が $\{1,\dots,i-1\}$ である．$X_{\{1,\dots,i-1\}}$ をこの二つの組の対とみて（補題 16.1.2），定理 1.2.4 を当てると，右辺の各項は $H(X_i \mid X_{\{1,\dots,i-1\}})$ 以上である．よって
$$
\sum_{j=1}^{r} H(X_{S_j}) \;\ge\; \sum_{j=1}^{r} \sum_{i \in S_j} H\big(X_i \,\big|\, X_{\{1,\dots,i-1\}}\big)
$$
である．右辺の二重の和を $i$ ごとにまとめ直すと，$H(X_i \mid X_{\{1,\dots,i-1\}})$ が現れる回数は $i$ を含む $S_j$ の個数であり，仮定よりそれは $k$ 以上である．定義 1.2.2 の中辺の各項に 命題 1.1.4 を当てるとこの量は非負だから，回数を $k$ に減らしても和は小さくなるだけで
$$
\sum_{j=1}^{r} H(X_{S_j}) \;\ge\; k \sum_{i=1}^{n} H\big(X_i \,\big|\, X_{\{1,\dots,i-1\}}\big)
$$
である．最後に 定理 16.1.4 を $S = \{1,\dots,n\}$ に当てると，右辺の和は $H(X_{\{1,\dots,n\}})$ に等しい．
:::

::: formalized
`shearer_inequality` (`InformationTheory/Shannon/Han/DShearer.lean`)
:::

::: formalization-note
宣言は族の添字を任意の有限型でとる．本文が族を $S_1,\dots,S_r$ と番号で並べているのは，その添字を $\{1,\dots,r\}$ にとった場合にあたる．
:::

族を「番号 $i$ だけを抜いた $n$ 個の集合」ととると，どの番号も $n-1$ 個の集合に含まれるので $k = n-1$ ととれて，定理 16.3.1 は 定理 16.2.1 そのものになる．Han の不等式は Shearer の不等式の特別な場合である．

**物差しをそろえると読む.** 定理 16.3.1 の証明で二つの不等号が入った場所は，性質が違う．第 $1$ の不等号（定理 1.2.4）は，集合ごとにばらばらだった条件を $\{1,\dots,i-1\}$ の全体まで増やして，どの集合についても同じ量で下から押さえる段である．条件を増やせば残る不確かさは増えないので，もとの各項はその同じ量以上になる．ここを通すと，族の形は「どの番号が何回現れたか」という数だけに畳まれる．第 $2$ の不等号は，その回数を仮定の $k$ まで減らす段で，減らしてよいのは各項が非負だからである．

::: corollary 16.3.2 劣加法性
定義 16.1.1 の設定で
$$
H\big(X_{\{1,\dots,n\}}\big) \;\le\; \sum_{i=1}^{n} H(X_i)
$$
である（$H(X_i)$ は 定義 1.1.1 の $1$ 変数のエントロピーである）．
:::

::: proof
族を $n$ 個の $1$ 点集合 $\{1\},\dots,\{n\}$ ととると，どの番号もちょうど一つの集合に含まれるので，$k = 1$ として 定理 16.3.1 が使えて
$$
H\big(X_{\{1,\dots,n\}}\big) \;\le\; \sum_{i=1}^{n} H\big(X_{\{i\}}\big)
$$
である．$X_{\{i\}}$ は $\{i\}$ から $\mathcal X$ への関数に値をとる．その値に $i$ での値を対応させる写像は単射で，この写像で $X_{\{i\}}$ を移したものが $X_i$ だから，$H(X_{\{i\}}) = H(X_i)$ である（補題 16.1.2）．
:::

::: formalized
`entropy_pi_le_sum_entropy` (`InformationTheory/Shannon/CondEntropyMemoryless.lean`)
:::

::: formalization-note
宣言の右辺も $1$ 変数のエントロピーの和で，$1$ 点集合についての部分集合のエントロピーの和ではない．二つが等しいことを述べる単独の宣言はない．また，形式化は本文と別の道をとり，Shearer の不等式を経由せずに，$S$ が全体の場合のチェイン則の各項を条件のない $1$ 変数のエントロピーで直に押さえて証明している．結論の定理は同一である．
:::

系 16.3.2 は，$n$ 個をまとめて見たときの不確かさが，$1$ 個ずつ見たときの不確かさの合計を超えないと言っている．変数どうしに重なりがあれば，まとめて見るほうが得をする．$2$ 変数のときに，独立なら両辺が等しくなることは 第1章 1.2 節 で見た．結合密度をもち値が定まるかぎり，微分エントロピーについても同じ形の不等式が成り立つ（定理 7.4.3）．

::: example 16.3.3
例 16.1.3 の 1 の族について，$\{1,2\}$，$\{2,3\}$，$\{1,3\}$ を族にとるとどの番号もちょうど二つの集合に含まれ，$k = 2$ として 定理 16.3.1 の両辺は $4$ と $5$ である．$\{1\}$，$\{2\}$，$\{3\}$ を族にとると $k = 1$ として両辺は $2$ と $3$ である．
:::

::: proof
例 16.1.3 の 1 より $H(X_{\{1,2,3\}}) = 2$ だから，$k = 2$ の族では左辺が $2 \cdot 2 = 4$，右辺が $H(X_{\{1,2\}}) + H(X_{\{2,3\}}) + H(X_{\{1,3\}}) = 1 + 2 + 2 = 5$ である．$k = 1$ の族では左辺が $1 \cdot 2 = 2$，右辺が $1 + 1 + 1 = 3$ である．
:::

例 16.3.3 の二つの族は，どちらも 定理 16.3.1 の仮定を満たしながら，$H(X_{\{1,2,3\}})$ に与える上界が違う．$k = 2$ の族は $5/2$ で押さえ，$k = 1$ の族は $3$ で押さえる（実際の値は $2$ である）．

16.1 節 の終わりに置いた問い，すなわち $H(X_S)$ について示すことのどこまでが値の出どころに依らないのか，にここで答えておく．定理 16.3.1 の証明でエントロピーの中身が効いているのは，定理 16.1.4 のチェイン則と，条件付きエントロピーの非負性と，定理 1.2.4 の三つだけである．この三つは，定義 16.1.7 の三条件をそれぞれ書き換えたものである．チェイン則は第 $1$ の条件から増分を足し上げて出る等式であり，定理 1.2.4 を当てた段は，16.1 節 で見たとおり第 $3$ の劣モジュラ性の言い換えであり，条件付きエントロピーの非負性は第 $2$ の単調性にあたる．この対応をたどって 定理 16.3.1 を階数関数一般に書き直すと，次を得る．

::: corollary 16.3.4 Shearer の不等式の階数関数への一般化
$n \ge 1$ とし，$\mathrm{rk}$ を $\{1,\dots,n\}$ 上のポリマトロイドの階数関数（定義 16.1.7）とする．$r \ge 1$，$S_1,\dots,S_r \subseteq \{1,\dots,n\}$ とし，$k$ を非負整数とする．どの $i \in \{1,\dots,n\}$ についても $i$ を含む $S_j$ が $k$ 個以上あるならば
$$
k\,\mathrm{rk}\big(\{1,\dots,n\}\big) \;\le\; \sum_{j=1}^{r} \mathrm{rk}(S_j)
$$
である．とくに $r = n$，$S_i := \{1,\dots,n\}\setminus\{i\}$（$1 \le i \le n$），$k = n-1$ ととると
$$
(n-1)\,\mathrm{rk}\big(\{1,\dots,n\}\big) \;\le\; \sum_{i=1}^{n} \mathrm{rk}\big(\{1,\dots,n\}\setminus\{i\}\big)
$$
である．
:::

::: proof
定理 16.3.1 の証明が使った三つを，定義 16.1.7 の条件から順に作り直す（そこで 補題 16.1.2 を挟んだのは，条件を二つの組の対とみるための読み替えで，集合の関数を相手にするならその段は要らない）．以下，集合 $B$ に $B$ の外の番号 $i$ を足したときの $\mathrm{rk}(B \cup \{i\}) - \mathrm{rk}(B)$ を，$B$ に $i$ を足したときの増分と呼ぶ．

第一に，定理 16.1.4 にあたる等式である．$T \subseteq \{1,\dots,n\}$ をとり，$i \in T$ ごとに $B_i := T \cap \{1,\dots,i-1\}$ とおくと $T \cap \{1,\dots,i\} = B_i \cup \{i\}$ である．$i$ を $T$ の小さい順に動かすと $T \cap \{1,\dots,i\}$ の形の集合が順に大きくなるから，増分の和は隣どうしが打ち消し合って $\mathrm{rk}(T)$ と $\mathrm{rk}(\emptyset)$ の差だけが残る．第 $1$ の条件により
$$
\mathrm{rk}(T) \;=\; \sum_{i \in T}\big(\mathrm{rk}(B_i \cup \{i\}) - \mathrm{rk}(B_i)\big)
$$
である．

第二に，定理 1.2.4 にあたる不等式である．$B \subseteq C \subseteq \{1,\dots,n\}$ と $i \notin C$ をとり，第 $3$ の条件を二つの集合 $B \cup \{i\}$ と $C$ に当てる．二つの和集合は $C \cup \{i\}$，共通部分は $B$ だから
$$
\mathrm{rk}(C \cup \{i\}) - \mathrm{rk}(C) \;\le\; \mathrm{rk}(B \cup \{i\}) - \mathrm{rk}(B)
$$
であり，すでに知っている集合が大きいほど増分は小さい．

第三に，増分が非負であることは第 $2$ の条件そのものである．

あとは 定理 16.3.1 の証明のとおりである．各 $j$ について第一の等式を $T = S_j$ に当て，その $i$ 番目の項に第二の不等式を $B = S_j \cap \{1,\dots,i-1\}$，$C = \{1,\dots,i-1\}$ ととって当てると，各項は $\{1,\dots,i-1\}$ に $i$ を足したときの増分以上である．$j$ について足して $i$ ごとにまとめ直すと，$i$ の増分が現れる回数は $i$ を含む $S_j$ の個数で，仮定よりそれは $k$ 以上である．第三により増分は非負だから，回数を $k$ に減らしても和は小さくなるだけで
$$
\sum_{j=1}^{r} \mathrm{rk}(S_j) \;\ge\; k \sum_{i=1}^{n}\big(\mathrm{rk}(\{1,\dots,i\}) - \mathrm{rk}(\{1,\dots,i-1\})\big)
$$
である．第一の等式を $T = \{1,\dots,n\}$ に当てると，右辺の和は $\mathrm{rk}(\{1,\dots,n\})$ に等しい．後半は，番号 $i$ を抜いた $n$ 個の集合ではどの番号もちょうど $n-1$ 個の集合に含まれることによる．
:::

::: formalization-note
階数関数一般についてこの不等式を述べる宣言はない．ポリマトロイドの構造 `Polymatroid` (`InformationTheory/Polymatroid/Basic.lean`) を仮定にとる宣言を結論の形で探しても，部分集合のエントロピーからその構造を組み立てる `entropyPolymatroid` (`InformationTheory/Shannon/Polymatroid.lean`) のほかには見つからない．機械検証が及ぶのは 定理 16.3.1 の形までである．
:::

系 16.1.8 より $H(X_S)$ はポリマトロイドの階数関数だから，系 16.3.4 は 定理 16.3.1 を含み，したがって 定理 16.2.1 も含む．問いへの答えは，Han の不等式も Shearer の不等式も，値がエントロピーであることを使っていない，ということである．定義 16.1.7 の三条件を満たす集合の関数でありさえすれば，同じ不等式が成り立つ．

覆いを一般にとれるようになったことの値打ちは，族を目的に合わせて選べるところにある．次節は，有限集合の上の一様分布に従う確率変数を 定義 16.1.1 の族に置く．そうすると 例 1.1.3 によって左辺が集合の要素数の対数になり，右辺の各項は 定理 1.1.5 によって，座標の一部だけに切り詰めた像の要素数の対数で上から押さえられる．こうして 定理 16.3.1 は，集合の要素数とその像の要素数とを結ぶ数え上げの不等式になる．
