# 11.2 型類の確率

前節は型類について二つを得た．中の点はどれも同じ確率をもち，$Q$ が全点で正ならその確率は $\exp(-n(H(P)+D(P\,\|\,Q)))$ であること（命題 11.1.4），そして要素数が $e^{\,nH(P)}$ の前後にあること（定理 11.1.8）である．型類全体の確率は，一点の確率に要素数を掛けたものだから，この二つを掛け合わせれば出る．掛けるとエントロピーの項は打ち消し合い，相対エントロピーだけが指数に残る．これが本節の主張で，次節以降の議論はここから出発する．

## 挟み込み

::: theorem 11.2.1 型類の確率
$\mathcal X$ を空でない有限アルファベット，$n \ge 1$ とし，$Q$ を $\mathcal X$ 上の全点で正の分布，$Q^n$ をその $n$ 重の積分布とする．$P$ を長さ $n$ の型（定義 11.1.1）とすると
$$
(n+1)^{-\lvert\mathcal X\rvert}\,e^{-n D(P\,\|\,Q)}
  \;\le\; Q^n\big(\mathcal T_n(P)\big)
  \;\le\; e^{-n D(P\,\|\,Q)}
$$
である（$D$ は 1.6 節の相対エントロピー）．
:::

::: proof
命題 11.1.4 より，$\mathcal T_n(P)$ のどの点についても $Q^n$ による確率は $\exp(-n(H(P) + D(P\,\|\,Q)))$ であり，点のとり方に依らない．したがって
$$
Q^n\big(\mathcal T_n(P)\big)
  \;=\; \big\lvert\mathcal T_n(P)\big\rvert\,
    \exp\Big(-n\big(H(P) + D(P\,\|\,Q)\big)\Big)
$$
である．この要素数に 定理 11.1.8 の挟み込みを当てる．指数関数の値は正だから，不等式の向きは変わらない．

上界について，$\lvert\mathcal T_n(P)\rvert \le e^{\,nH(P)}$ より
$$
Q^n\big(\mathcal T_n(P)\big)
  \;\le\; e^{\,nH(P)}\exp\Big(-n\big(H(P) + D(P\,\|\,Q)\big)\Big)
  \;=\; e^{-n D(P\,\|\,Q)}
$$
である．下界も同じで，$\lvert\mathcal T_n(P)\rvert \ge (n+1)^{-\lvert\mathcal X\rvert}e^{\,nH(P)}$ の両辺に $\exp(-n(H(P) + D(P\,\|\,Q)))$ を掛ければ $Q^n(\mathcal T_n(P)) \ge (n+1)^{-\lvert\mathcal X\rvert}e^{-nD(P\,\|\,Q)}$ を得る．
:::

::: formalized
上界 `typeClassByCount_Qn_le` (`InformationTheory/Shannon/Sanov/LDP.lean`)，下界 `typeClassByCount_Qn_ge` (`InformationTheory/Shannon/Sanov/MultinomialLowerBound.lean`)
:::

指数に残るのは相対エントロピーだけである．エントロピーの項は，要素数の $e^{\,nH(P)}$ と一点の確率の $e^{-nH(P)}$ で打ち消し合った．読み方は素直で，$Q$ に従う情報源から型が $P$ の系列が出る確率は，$P$ が $Q$ からどれだけ隔たっているかだけで決まり，その隔たりが確率の落ちる速さになる，ということである．上下の隔たりは $(n+1)^{\lvert\mathcal X\rvert}$ 倍あるが，これが指数の速さに効かないことは 系 11.2.3 で確かめる．

1.6 節は相対エントロピーを「$q$ だと思い込んで符号化したために余計に払う符号長」として読んだ．定理 11.2.1 はもう一つの読み方を与える．$Q$ から見たとき，型 $P$ の系列がどれだけ出にくいかである．$D(P\,\|\,Q)$ が小さければ指数は $0$ に近く，確率は $n$ が増えてもゆっくりしか落ちない．大きければ速く落ちる．どちらの読み方でも，$D(P\,\|\,Q)$ が $0$ になるのは $P = Q$ のときに限る（定理 1.6.1）という性質が土台にある．

## 型の列に沿った極限

型の列を追う前に，本章で繰り返し使う一つの収束を切り出しておく．挟み込みの上下の隔たり $(n+1)^{\lvert\mathcal X\rvert}$ は，対数をとって $n$ で割ると $\lvert\mathcal X\rvert\log(n+1)/n$ になる．これが $0$ に行くというのが次の補題であり，多項式倍の差が $\frac1n\log$ の水準で消えるというのは，本章のどこでもこの形で効く．証明で使うのは 1.1 節の対数不等式ひとつである．

::: lemma 11.2.2
$$
\lim_{n \to \infty}\frac{\log(n+1)}{n} \;=\; 0
$$
である．
:::

::: proof
1.1 節の信頼の底から出した対数不等式 $\log t \le (t-1)\log e$ を，本章の底のもとで（$\log e = 1$ である）$t := \sqrt{n+1}$ に当てると $\tfrac12\log(n+1) \le \sqrt{n+1} - 1 \le \sqrt{n+1}$ であり，$n \ge 1$ では $\sqrt{n+1} \le \sqrt{2n}$ だから
$$
0 \;\le\; \frac{\log(n+1)}{n} \;\le\; \frac{2\sqrt{n+1}}{n} \;\le\; \frac{2\sqrt 2}{\sqrt n}
$$
である．右端は $0$ に収束するから，両端に挟まれた真ん中も $0$ に収束する．
:::

::: formalized
`log_succ_div_tendsto_zero` (`InformationTheory/Shannon/Sanov/LDP.lean`)
:::

::: corollary 11.2.3
$\mathcal X$ を空でない有限アルファベット，$Q$ を $\mathcal X$ 上の全点で正の分布，$Q^n$ をその $n$ 重の積分布とする．各 $n \ge 1$ について $P_n$ を長さ $n$ の型（定義 11.1.1）とし，$\mathcal X$ 上の分布 $P$ がどの文字 $a$ でも $P_n(a) \to P(a)$（$n \to \infty$）を満たすならば
$$
\frac1n\log Q^n\big(\mathcal T_n(P_n)\big) \;\longrightarrow\; -D(P\,\|\,Q)
$$
である（$D$ は 1.6 節の相対エントロピー）．
:::

::: proof
定理 11.2.1 を型 $P_n$ に当てる．下界が正だから $Q^n(\mathcal T_n(P_n))$ も正で対数がとれ，$\log$ は単調だから，対数をとって $n$ で割ると
$$
-D(P_n\,\|\,Q) - \frac{\lvert\mathcal X\rvert\log(n+1)}{n}
  \;\le\; \frac1n\log Q^n\big(\mathcal T_n(P_n)\big)
  \;\le\; -D(P_n\,\|\,Q)
$$
である．両端が $-D(P\,\|\,Q)$ に収束することを見れば，主張が従う．

左端の第 $2$ 項は，補題 11.2.2 と，$\lvert\mathcal X\rvert$ が $n$ に依らない有限の数であることから $0$ に収束する．

次に $D(P_n\,\|\,Q) \to D(P\,\|\,Q)$ を見る．$\mathcal X$ 上の分布 $\tilde P$ に対し
$$
D(\tilde P\,\|\,Q) \;=\; \sum_{a}\tilde P(a)\log \tilde P(a) \;-\; \sum_{a}\tilde P(a)\log Q(a)
  \;=\; -\sum_{a}\varphi\big(\tilde P(a)\big) \;-\; \sum_{a}\tilde P(a)\log Q(a)
$$
と書ける（$\varphi(t) = -t\log t$ は 1.1 節の記号であり，$\tilde P(a) = 0$ の項が両辺で $0$ になることは $Q(a) > 0$ と $0\log 0 = 0$ の約束による）．1.1 節で認めた $\varphi$ の $[0,\infty)$ 上の連続性から，どの文字でも $\varphi(P_n(a)) \to \varphi(P(a))$ である．また $Q$ は全点で正だから $\log Q(a)$ は有限な数で，$P_n(a)\log Q(a) \to P(a)\log Q(a)$ である．収束する数列を有限個足したものはそれぞれの極限の和に収束するから，$\mathcal X$ が有限であることと合わせて $D(P_n\,\|\,Q) \to D(P\,\|\,Q)$ を得る．
:::

系 11.2.3 が言っているのは，指数が型について連続である，ということである．長さ $n$ の型がとる値は $0, 1/n, \dots, 1$ に限られる（定義 11.1.1）ので，あらかじめ与えられた分布 $P$ が長さ $n$ の型であるとは限らない．そのときは $P$ に収束する型の列をとればよく，指数はそれでも $-D(P\,\|\,Q)$ に行く．次節はまさにこの形で使う．

## 自分の型類は多項式ぶんしか小さくならない

::: corollary 11.2.4
$\mathcal X$ を空でない有限アルファベット，$n \ge 1$ とし，$P$ を長さ $n$ の型（定義 11.1.1），$P^n$ をその $n$ 重の積分布とすると
$$
P^n\big(\mathcal T_n(P)\big) \;\ge\; (n+1)^{-\lvert\mathcal X\rvert}
$$
である．
:::

::: proof
系 11.1.5 より $P^n(\mathcal T_n(P)) = \lvert\mathcal T_n(P)\rvert\,e^{-nH(P)}$ であり，定理 11.1.8 の下界より $\lvert\mathcal T_n(P)\rvert \ge (n+1)^{-\lvert\mathcal X\rvert}e^{\,nH(P)}$ である．二つを合わせると $P^n(\mathcal T_n(P)) \ge (n+1)^{-\lvert\mathcal X\rvert}$ を得る．
:::

自分の型類に落ちる確率は，$n$ の多項式の逆数までしか小さくならない．指数では落ちないということである．補題 11.1.7 によればこの型類が $P^n$ で測っていちばん重いのだから，いちばん重い型類の重さについての評価でもある．$P$ が全点で正であれば，定理 11.2.1 で $Q$ に $P$ 自身をとっても同じ下界が出る（相対エントロピーが $0$ になることは 定理 1.6.1 の等号条件による）．系 11.2.4 はそれを，全点で正とは限らない型にまで広げた形である．

## 一様分布からの隔たり

本節から先の節では，公平なコインを基準の分布にとった例を繰り返し扱う．そこで現れる相対エントロピーは，二値エントロピー関数ひとつで書ける．引くたびに導き直さずに済むよう，先に補題として切り出しておく．

::: lemma 11.2.5 二値分布の一様分布からの隔たり
$\mathcal X = \{0,1\}$ とし，$Q$ を $Q(0) = Q(1) = 1/2$ で定まる分布，$H_b$ を 例 1.1.2 の二値エントロピー関数とする．$\mathcal X$ 上のどの分布 $P$ についても
$$
D(P\,\|\,Q) \;=\; \log 2 - H_b\big(P(1)\big) \;=\; \log 2 - H_b\big(P(0)\big)
$$
である（$D$ は 1.6 節の相対エントロピー）．
:::

::: proof
$Q$ は $\mathcal X$ 上の一様分布で $\lvert\mathcal X\rvert = 2$ だから，命題 10.1.2 より $D(P\,\|\,Q) = \log 2 - H(P)$ である（$H$ は 定義 1.1.1 のエントロピー）．例 1.1.2 の定め方から $H(P) = H_b(P(1))$ であり，補題 9.3.1 の第 $1$ の主張より $H_b(P(1)) = H_b(1 - P(1)) = H_b(P(0))$ である．
:::

::: formalization-note
補題 11.2.5 に対応する単独の宣言は無い．一般のアルファベットについて $D(P\,\|\,U) = \log\lvert\mathcal X\rvert - H(P)$ を述べる `klDiv_uniformOn_univ_toReal_eq` (`InformationTheory/Shannon/MaxEntropy/Basic.lean`) が第 $1$ の等号の骨格を与えるが，エントロピーを二値エントロピー関数の形に書き直すところと，第 $2$ の等号にあたる対称性は，本書の形式化には無い．対称性のほうは Mathlib の `Real.binEntropy_one_sub` が無条件の機械検証済みの補題として与えている．
:::

この形は，公平なコインからの隔たりが，エントロピーの目減りぶんとして測れることを言っている．$P$ が公平なコインに近いほど $H_b$ は $\log 2$ に近く，隔たりは $0$ に近い．$P$ が一方の文字に寄るほど $H_b$ は小さくなり，そのぶん隔たりが大きくなる．$P(0)$ と $P(1)$ のどちらで書いてもよいのは，二値エントロピー関数が $1/2$ を軸に左右対称だからである．

## 数値で見る

::: example 11.2.6 偏ったコインを公平なコインで測る
$\mathcal X = \{0,1\}$ とし，$Q$ を $Q(0) = Q(1) = 1/2$ で定まる分布，$P$ を $P(0) = 0.1$，$P(1) = 0.9$ で定まる分布とする．$Q^n$ を $Q$ の $n$ 重の積分布，$\mathcal T_n(\cdot)$ を 定義 11.1.1 のとおり，$H_b$ を 例 1.1.2 の二値エントロピー関数とすると，次の三つが成り立つ．

1. $D(P\,\|\,Q) = \log 2 - H_b(0.1)$ であり，その値は約 $0.368$ ナットである．
2. $n$ が $10$ の倍数ならば $P$ は長さ $n$ の型であり，$(n+1)^{-2}e^{-nD(P\,\|\,Q)} \le Q^n(\mathcal T_n(P)) \le e^{-nD(P\,\|\,Q)}$ が成り立つ．
3. $n = 100$ のとき $Q^{100}(\mathcal T_{100}(P)) = \binom{100}{10}2^{-100}$ であり，その値は約 $1.37 \times 10^{-17}$ である．このとき第 $2$ の挟み込みの上界は約 $1.04\times 10^{-16}$，下界は約 $1.02\times 10^{-20}$ である．
:::

::: proof
1. 補題 11.2.5 を $P$ に当てると $D(P\,\|\,Q) = \log 2 - H_b\big(P(0)\big) = \log 2 - H_b(0.1)$ である．値は $H_b(0.1) = -0.1\log 0.1 - 0.9\log 0.9 = 0.3250\ldots$，$\log 2 = 0.6931\ldots$ だから，差は $0.3680\ldots$ である．

2. $nP(0) = n/10$，$nP(1) = 9n/10$ は，$n$ が $10$ の倍数なら非負整数であり，和は $n$ である．$0$ を $n/10$ 個並べたあと $1$ を $9n/10$ 個並べた系列の型は $P$ だから，$P$ は長さ $n$ の型である．$Q$ は全点で正で $\lvert\mathcal X\rvert = 2$ だから，定理 11.2.1 がそのまま第 $2$ の主張を与える．

3. $\mathcal T_{100}(P)$ は $0$ をちょうど $10$ 個含む長さ $100$ の系列の全体だから，その要素数は，$100$ 個の位置から $0$ を置く $10$ 個を選ぶ選び方の数 $\binom{100}{10}$ である．$Q$ は一様なので各点の確率は $2^{-100}$ であり，掛け合わせて $Q^{100}(\mathcal T_{100}(P)) = \binom{100}{10}2^{-100}$ を得る．$\binom{100}{10} = 17310309456440$ と $2^{-100} = 7.888\ldots\times10^{-31}$ から，値は $1.365\ldots\times10^{-17}$ である．上界は $e^{-100 D(P\,\|\,Q)} = e^{-36.806\ldots} = 1.035\ldots\times10^{-16}$，下界はこれを $(100+1)^2 = 10201$ で割った $1.015\ldots\times10^{-20}$ である．
:::

この $P$ は 例 2.1.2 の偏ったコインと同じ分布である（あちらは $\log$ の底を $2$ にとったので，$H_b(0.1)$ の値が約 $0.469$ ビットと書かれている）．例 11.2.6 の第 $3$ の主張は，定理 11.2.1 の挟み込みが実際どれくらいの粗さかを見せている．真の値は上界より $1$ 桁ほど小さく，下界より $3$ 桁ほど大きい．上下の隔たりは $4$ 桁あるが，$\frac1n\log$ をとれば $\frac{\log 10201}{100} = 0.092\ldots$ の差でしかない．指数の速さだけを見るなら，公平なコインを $100$ 回投げて $1$ がちょうど $90$ 回出る確率は $e^{-100\,D(P\,\|\,Q)}$ のあたりにある．

::: formalization-note
例 11.2.6 の数値に対応する宣言は無い．形式化には，具体的な分布を入れて相対エントロピーや型類の確率を計算した実例が置かれていない．
:::

定理 11.2.1 が扱ったのは一つの型類である．次節は型の集合を指定し，経験分布がその集合に落ちる確率を問う．型の個数が多項式でしかないこと（命題 11.1.3）と本節の挟み込みが，そこで効く．集合全体の確率の指数を，その集合の中の一つの分布だけで書けるか，というのが次節の問いであり，答えを与えるのが Sanov の定理である．
