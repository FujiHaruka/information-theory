# 7.5 連続な相対エントロピーと相互情報量

7.3 節で見たとおり，微分エントロピーの数値そのものは目盛の取り方で動く．意味をもつのは同じ目盛で測った量の差である．第1章で相対エントロピー $D(p\,\|\,q)$ と相互情報量 $I(X;Y)$ を導入したとき，どちらも二つの分布の比の対数を平均する形をしていた（1.6 節と定義 1.3.1）．比の形は，分母と分子に同じ係数がかかる取り替えを見なくなる．本節はこの二つの量を密度で書き直し，離散のときと同じ性質が成り立つことを見る．

書き直したあとの相対エントロピーは，補題 7.2.3 が示した「$h(X)$ と $-\int f\log q$ の差」にほかならない．したがって非負性はすでに手元にある．新しく要るのは定義と，離散のときの読み方がそのまま通ることの確認である．

## 相対エントロピー

::: definition 7.5.1 相対エントロピー
$n \ge 1$ とし，$f$ と $q$ を $\mathbb R^n$ 上の密度とする．$S := \{x \in \mathbb R^n : f(x) > 0 \text{ かつ } q(x) > 0\}$ とおく．$\int_S f(x)\,dx = 1$ であり $\int_S f(x)\big\lvert\log\frac{f(x)}{q(x)}\big\rvert\,dx < \infty$ であるとき，$f$ の $q$ に対する **相対エントロピー** を
$$
D(f \,\|\, q) \;:=\; \int_S f(x)\log\frac{f(x)}{q(x)}\,dx
$$
で定め，このとき $D(f\,\|\,q)$ が **定まる** という．
:::

::: formalization-note
形式化の相対エントロピーは，密度ではなく分布に対して定義されていて，値は非負の拡張実数として返る．本文の $D(f\,\|\,q)$ にあたるのは，それを実数に直したものである．本節で紐付ける宣言と，注記で触れる宣言は，どれもこの形をしている．
:::

$\int_S f = 1$ という条件は，$q$ が $0$ になる点に $f$ が確率を置いていない，ということである．離散のときはその場合に $D(p\,\|\,q) = +\infty$ と読んだ（1.6 節）が，本書は密度についてその場合の $D$ を定めない．$+\infty$ を値として認めると，以下の主張がどれも「両辺が有限なら」という但し書きを抱えることになり，得るものより手間のほうが大きいからである．$q$ を「起こらないと決めつけた想定」と読むなら，決めつけが外れたときの罰が無限大になるという事情は離散のときと同じである．

::: theorem 7.5.2 情報不等式（連続版）
$n \ge 1$ とし，$X$ を $\mathbb R^n$ に値をとり密度 $f$ をもつ確率変数，$q$ を $\mathbb R^n$ 上の密度とし，$S$ を定義 7.5.1 のとおりとする．$\int_S f(x)\,dx = 1$ であり，$h(X)$ が定まり，$\int_S f(x)\lvert\log q(x)\rvert\,dx < \infty$ であるならば，$D(f\,\|\,q)$ は定まり
$$
D(f\,\|\,q) \;=\; -\,h(X) \;-\; \int_S f(x)\log q(x)\,dx \;\ge\; 0
$$
である．
:::

::: proof
まず $D(f\,\|\,q)$ が定まることを見る．$S$ の上で $\log\frac fq = \log f - \log q$ であり，$\int_S f\lvert\log f\rvert \le \int_{\mathbb R^n}\lvert f\log f\rvert$ は $h(X)$ が定まることから有限，$\int_S f\lvert\log q\rvert$ は仮定より有限だから，$\int_S f\lvert\log\frac fq\rvert$ は有限である．同時に，$D(f\,\|\,q) = \int_S f\log f - \int_S f\log q$ と分けてよい．

第 1 項を $-h(X)$ に直す．$S$ の外では $f(x) = 0$ か $q(x) = 0$ のどちらかであり，$f(x) = 0$ の点では $f\log f = 0$ である．残る「$f(x) > 0$ かつ $q(x) = 0$」の点の全体を $N$ とすると，$\int_N f = \int_{\mathbb R^n} f - \int_S f = 0$ である．7.2 節で借りた零集合の上での積分を，$f$ と「$f > 0$ の点で $\log f$，そのほかの点で $0$」という関数に当てると $\int_N f\log f = 0$ である．よって $\int_S f\log f = \int_{\mathbb R^n} f\log f = -h(X)$ であり，等式が従う．

非負性は補題 7.2.3 である．仮定は補題 7.2.3 の仮定そのものだから，$h(X) \le -\int_S f\log q$ が成り立ち，移項すれば右辺が $0$ 以上であることがわかる．
:::

定理 7.5.2 は，離散の情報不等式（定理 1.6.1）を密度で書き直したものである．離散のときは $-\sum_x p(x)\log q(x)$ と $H(p)$ をそれぞれ平均符号長として読めたが，連続では $-\int_S f\log q$ も $h(X)$ も負になりうる（例 7.1.3）ので，その読み方は個々の項には当てられない．当てられるのは差のほうで，$D(f\,\|\,q)$ が「密度が $q$ だと思い込んだために余計に払うぶん」にあたる．思い込みで得はしない，という主張になっている．離散のときに述べた等号条件（$p = q$ のとき，かつそのときに限る）にあたるものを，本書は密度について述べない．定理 7.2.4 の等号のときと同じ理由で，密度どうしの一致は確率 $0$ の集合の上での食い違いを許す形でしか言えないからである．

::: formalization-note
本書が述べないだけで，等号条件そのものは分布のレベルで機械検証されている．Mathlib の `klDiv_eq_zero_iff` がそれで，第1章 1.3 節は相互情報量の等号条件をこれに寄りかからせている．
:::

::: proposition 7.5.3 目盛の取り替えでの不変性
$f$ と $q$ を $\mathbb R$ 上の密度，$c \ne 0$ と $b$ を実数とし
$$
f_c(x) \;:=\; \frac{1}{\lvert c\rvert} f\Big(\frac{x-b}{c}\Big),
\qquad
q_c(x) \;:=\; \frac{1}{\lvert c\rvert} q\Big(\frac{x-b}{c}\Big)
$$
とおく．$D(f\,\|\,q)$ が定まるならば $D(f_c\,\|\,q_c)$ も定まり，$D(f_c\,\|\,q_c) = D(f\,\|\,q)$ である．
:::

::: proof
$f_c$ と $q_c$ が $\mathbb R$ 上の密度であることを見る．どちらも非負であり，7.3 節で借りた置換積分を $y = (x-b)/c$ で使うと $\int_{\mathbb R} f_c(x)\,dx = \int_{\mathbb R} f(y)\,dy = 1$ となり，$q_c$ についても同じ計算である．$f_c(x) > 0$ と $f\big(\frac{x-b}{c}\big) > 0$ は同値，$q_c$ についても同様だから，定義 7.5.1 の集合は $S_c = \{x : \frac{x-b}{c} \in S\}$ である．また $S_c$ の上で
$$
\log\frac{f_c(x)}{q_c(x)} \;=\; \log\frac{f\big(\frac{x-b}{c}\big)}{q\big(\frac{x-b}{c}\big)}
$$
であり，$1/\lvert c\rvert$ は分母と分子で打ち消し合う．7.3 節で借りた置換積分を $y = (x-b)/c$ で使うと，積分域 $S_c$ は $S$ に移り，$dx = \lvert c\rvert\,dy$ より
$$
\int_{S_c} f_c(x)\,\Big\lvert\log\frac{f_c(x)}{q_c(x)}\Big\rvert\,dx
  \;=\; \int_{S} f(y)\,\Big\lvert\log\frac{f(y)}{q(y)}\Big\rvert\,dy
$$
であり，同じ置き換えで $\int_{S_c} f_c = \int_S f = 1$ である．よって $D(f_c\,\|\,q_c)$ は定まり，絶対値を外した同じ計算でその値が $D(f\,\|\,q)$ に等しいことがわかる．
:::

::: formalization-note
命題 7.5.3 にあたる単独の宣言はない．より一般に，可測な同型で二つの分布を同時に送っても相対エントロピーが変わらないことが `klDiv_map_measurableEquiv` (`InformationTheory/Shannon/MutualInfo.lean`) として形式化されていて，本文の主張は $x \mapsto cx + b$ をその同型にとった場合にあたる．結論が分布について述べられているので，密度で書いた命題 7.5.3 とそのまま重なりはしない．
:::

命題 7.5.3 が，本節の量が微分エントロピーと違うところである．$h$ は引き伸ばしで $\log\lvert c\rvert$ だけ動いた（命題 7.3.3）のに対し，$D$ は動かない．比べる二つの密度に同じ変換をかければ，比が変わらないからである．目盛を変えても意味が変わらないので，$D$ の値はそれ自体で読んでよい量になっている．

## 相互情報量

::: definition 7.5.4 相互情報量
$X$ と $Y$ を実数値確率変数とし，$(X,Y)$ が結合密度 $f$ をもつとする．補題 7.4.1 を $n = 2$ の場合に読み，$X$ と $Y$ の周辺密度を $f_1$，$f_2$，その積を $q(x,y) := f_1(x) f_2(y)$ とする．$D(f\,\|\,q)$ が定まるとき，$X$ と $Y$ の **相互情報量** を
$$
I(X;Y) \;:=\; D(f \,\|\, q)
$$
で定める．
:::

離散のときの定義 1.3.1 は，相互情報量を「同時分布と周辺分布の積との隔たり」として読めるものだった（1.6 節）．定義 7.5.4 はその読み方をそのまま定義に据えている．なお $h$ のときと同じく，$D(f\,\|\,q)$ と $I(X;Y)$ の値も密度の選び方によらない．これも測度論を使って示される事実で，本書では証明しない．

::: formalized
`mutualInfo` (`InformationTheory/Shannon/MutualInfo.lean`)
:::

::: formalization-note
`mutualInfo` は結合分布と周辺分布の積との相対エントロピーとして定義されていて，定義 7.5.4 と同じ形をしている．第1章 1.3 節が定義 1.3.1 をこれに紐付けているとおり，離散と連続で別の宣言になっているわけではない．ただし，以下で定理 7.5.6 について触れる等式の宣言は `mutualInfo` を経由せず，相対エントロピーを直に書いたものである．値は一致するが，宣言としては別である．
:::

独立なときの値を先に見ておく．

::: proposition 7.5.5 独立なときの相互情報量
$X$ と $Y$ を独立な実数値確率変数とし，どちらも密度をもつとする．このとき $(X,Y)$ は結合密度をもち，$I(X;Y)$ は定まって $I(X;Y) = 0$ である．
:::

::: proof
$f_1$，$f_2$ を $X$，$Y$ の密度とする．7.4 節で借りた独立と積の密度により $q(x,y) := f_1(x)f_2(y)$ は $(X,Y)$ の結合密度であり，$f_1$ と $f_2$ はその周辺密度でもある．結合密度としてこの $q$ をとれば，定義 7.5.4 の $f$ も $q$ に等しい．どちらも同じ関数だから $S = \{q > 0\}$ で $\int_S q = 1$ であり，$S$ の上で $\log\frac qq = 0$ だから，$D(q\,\|\,q)$ は定まって $0$ である．
:::

::: theorem 7.5.6 相互情報量とエントロピーの関係
$X$ と $Y$ を実数値確率変数とし，$(X,Y)$ が結合密度をもつとする．$h(X,Y)$ が定まり，$h(X)$ と $h(Y)$ が定まるならば，$I(X;Y)$ は定まり
$$
I(X;Y) \;=\; h(X) + h(Y) - h(X,Y) \;\ge\; 0
$$
である．
:::

::: proof
$f$ を結合密度とし，$f_1$，$f_2$，$q$，$S$ を補題 7.4.1 の $n = 2$ の場合のとおりにとる．補題 7.4.1 より $q$ は $\mathbb R^2$ 上の密度で，$\int_S f = 1$ と $\int_S f\lvert\log q\rvert < \infty$ が成り立つ．よって定理 7.5.2 の仮定が満たされ，$D(f\,\|\,q)$ すなわち $I(X;Y)$ は定まって
$$
I(X;Y) \;=\; -\,h(X,Y) \;-\; \int_S f\log q \;\ge\; 0
$$
である．補題 7.4.1 より $-\int_S f\log q = h(X) + h(Y)$ だから，主張を得る．
:::

::: formalization-note
定理 7.5.6 の等式にあたるのは `klDiv_prod_marginals_toReal_eq_sum_sub_joint` で，$n$ 個の確率変数についての形は `klDiv_pi_marginals_toReal_eq_sum_sub_joint` (`InformationTheory/Shannon/MultivariateDiffEntropy.lean`) である．定理 7.4.2 のときと同じく，どちらも結合分布が周辺分布の積について絶対連続であることを仮定にもち，これは本文では補題 7.4.1 の結論なので，宣言は本文の主張をそのまま証明してはいない．残る仮定は，二つの周辺分布が Lebesgue 測度について絶対連続であること（借りた周辺密度の存在にあたる）と，五つの対数密度が積分できること（本文の三つの「定まる」にあたる）である．$2$ 変数の側は，結合分布が Lebesgue 測度について絶対連続であることを仮定にもたない．非負性の側には単独の宣言があって，`mutualInfo_nonneg` (`InformationTheory/Shannon/MutualInfo.lean`) がそれである．第1章 1.3 節が命題 1.3.2 をこれに紐付けており，実数で書いた形は定理 7.4.2 に触れた `jointDifferentialEntropy_le_sum` が与える．
:::

定理 7.5.6 は，離散のときのエントロピー表現 $I(X;Y) = H(X) + H(Y) - H(X,Y)$（定理 1.3.4）と同じ形をしている．離散のエントロピーと微分エントロピーは別物だったのに，それを組み合わせた相互情報量は同じ式で書ける．右辺が三つの差でできていて，微分エントロピーの数値そのものが表に出ないからである．7.1 節の終わりに予告した「差だけが現れる」というのは，このことである．

定理 7.4.2 との関係も読める．$n = 2$ の場合の劣加法性 $h(X,Y) \le h(X) + h(Y)$ は，定理 7.5.6 の $I(X;Y) \ge 0$ を移項したものにほかならない．離散のときに 1.6 節で情報不等式が既出の不等式を束ねたのと同じことが，ここでも起きている．例 7.4.4 の三角形の上の一様分布では $I(X;Y) = \log\frac e2$ で，底を $2$ にとれば約 $0.4427$ ビットである．$X$ と $Y$ の依存の強さが，それだけあるということである．

::: example 7.5.7 二つのガウス分布の相対エントロピー
$\mu_1$，$\mu_2$ を実数，$\sigma_1^2, \sigma_2^2 > 0$ とし，$f$ を $\mathcal N(\mu_1,\sigma_1^2)$ の密度，$q$ を $\mathcal N(\mu_2,\sigma_2^2)$ の密度とする（定義 7.2.1）．このとき $D(f\,\|\,q)$ は定まり
$$
D(f \,\|\, q) \;=\; \frac12\log\frac{\sigma_2^2}{\sigma_1^2}
  \;+\; \frac{\log e}{2}\left(\frac{\sigma_1^2 + (\mu_1-\mu_2)^2}{\sigma_2^2} - 1\right)
$$
である．
:::

::: proof
$X$ が $\mathcal N(\mu_1,\sigma_1^2)$ に従うとする．どちらの密度も実軸のすべての点で正だから定義 7.5.1 の $S$ は $\mathbb R$ 全体で，$\int_S f = 1$ である．定義 7.2.1 の二つの密度について対数の差をとると
$$
\log\frac{f(x)}{q(x)} \;=\; \frac12\log\frac{\sigma_2^2}{\sigma_1^2}
  \;+\; \log e\left(\frac{(x-\mu_2)^2}{2\sigma_2^2} - \frac{(x-\mu_1)^2}{2\sigma_1^2}\right)
$$
である．右辺は $x$ の $2$ 次式で，借りた正規分布の基本性質より $\mathbb E[X] = \mu_1$ と $\mathbb E[(X-\mu_1)^2] = \sigma_1^2$ はどちらも有限だから，$f$ を掛けた積分は絶対収束し $D(f\,\|\,q)$ は定まる．

平均をとる．$\mathbb E[(X-\mu_1)^2] = \sigma_1^2$ であり，$(X - \mu_2)^2 = (X-\mu_1)^2 + 2(\mu_1-\mu_2)(X-\mu_1) + (\mu_1-\mu_2)^2$ の平均をとると $\mathbb E[X - \mu_1] = 0$ より $\mathbb E[(X-\mu_2)^2] = \sigma_1^2 + (\mu_1-\mu_2)^2$ である．よって
$$
D(f\,\|\,q) \;=\; \frac12\log\frac{\sigma_2^2}{\sigma_1^2}
  \;+\; \log e\left(\frac{\sigma_1^2 + (\mu_1-\mu_2)^2}{2\sigma_2^2} - \frac{\sigma_1^2}{2\sigma_1^2}\right)
$$
となり，右辺は主張の式である．
:::

::: formalized
`klDiv_gaussianReal_gaussianReal_eq` (`InformationTheory/Shannon/DifferentialEntropy.lean`)
:::

**両端で確かめる.** $\sigma_1^2 = \sigma_2^2 = \sigma^2$ のとき，例 7.5.7 の式は $\frac{\log e}{2}\cdot\frac{(\mu_1-\mu_2)^2}{\sigma^2}$ になる．平均が離れているほど大きく，二つの密度が同じもの（$\mu_1 = \mu_2$）になったところで $0$ である．定理 7.5.2 の非負性と整合している．

**距離ではない.** 離散のときに 1.6 節で見たのと同じく，$D(f\,\|\,q)$ と $D(q\,\|\,f)$ は一致しない．$\mathcal N(0,1)$ と $\mathcal N(0,4)$ で例 7.5.7 の式を両向きに計算すると，底を $2$ にとって前者から後者への隔たりが約 $0.4590$ ビット，後者から前者への隔たりが約 $1.1640$ ビットである．狭い分布を広い分布だと思い込む損と，広い分布を狭い分布だと思い込む損は，別物だということである．

次の章は，本章で組み立てた量を通信路に当てる．雑音がガウス分布に従い，送る信号の電力に制約のかかる通信路では，容量が本節の相互情報量の最大値として書け，その最大を決めるのが定理 7.2.4 の最大エントロピー性である．本章が条件付き微分エントロピーを用意しなかったぶんは，そこで補うことになる．
