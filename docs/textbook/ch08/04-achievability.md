# 8.4 達成可能性

系 8.3.6 は，どんな符号を設計しても達成レートが $\frac12\log(1+P/N)$ を超えられないことを示した．残るのは逆向きで，それ未満のレートなら実際に符号が作れるか，という問いである．第6章 6.3 節で離散の通信路について答えたのと同じ問いで，答えも同じく肯定である．

本節はまず，なぜ $\frac12\log(1+P/N)$ という数がここに現れるのかを，符号語を $\mathbb R^n$ の点として置く幾何の言葉で見る．そのうえで達成可能性を借用として置き，逆定理と突き合わせて本章の主定理に至る．達成可能性を証明せずに借りる理由は，借りる場所で書く．

## 球で詰める

長さ $n$ の符号語 $c(m)$ は $\mathbb R^n$ の点である．電力制約は $\sum_i (c(m)_i)^2 \le nP$，すなわち原点からの距離が $\sqrt{nP}$ 以下ということで，符号語は半径 $\sqrt{nP}$ の球の中に置かれる．一方，各時刻の雑音は分散 $N$ をもつので，$n$ 個の時刻を合わせた雑音の $2$ 乗和の平均は $nN$ である．受け取る点は，送った符号語から距離 $\sqrt{nN}$ ほど離れたところに落ちる．そして出力の $2$ 乗和の平均は $n(P+N)$ だから（定理 8.2.2 の証明で見た $\mathbb E[Y_i^2] = \mathbb E[X_i^2] + N$ を足し合わせたものである），受け取る点は半径 $\sqrt{n(P+N)}$ の球の中に落ちる．

そこで，半径 $\sqrt{n(P+N)}$ の球の中に，半径 $\sqrt{nN}$ の球をいくつ重なりなく詰められるかを勘定する．詰められる個数だけメッセージを用意すれば，受け取った点がどの雑音球に入ったかで送った符号語が言い当てられる，という見当である．個数の見当は体積の比で与えられる．

::: proposition 8.4.1 球の体積の比
$n \ge 1$ とし，$r > 0$ に対し
$$
B_n(r) \;:=\; \Big\{\, y \in \mathbb R^n \;:\; \textstyle\sum_{i=0}^{n-1} y_i^2 \le r^2 \,\Big\}
$$
とおき，定数関数 $1$ の $B_n(r)$ の上での積分を $\mathrm{vol}\,B_n(r)$ と書く．このとき $0 < \mathrm{vol}\,B_n(r) < \infty$ であり，$r' > 0$ について
$$
\frac{\mathrm{vol}\,B_n(r)}{\mathrm{vol}\,B_n(r')} \;=\; \Big(\frac{r}{r'}\Big)^{n}
$$
である．とくに $N > 0$ と $P \ge 0$ について $r := \sqrt{n(P+N)}$，$r' := \sqrt{nN}$ ととると，この比は $2^{\,\frac n2\log(1 + P/N)}$ に等しい．
:::

::: proof
$\mathrm{vol}\,B_n(1)$ が有限で正であることを見る．$\lvert y_i\rvert \le 1/\sqrt n$ がすべての $i$ で成り立てば $\sum_i y_i^2 \le 1$ だから，$B_n(1)$ は一辺 $2/\sqrt n$ の立方体を含む．また $y \in B_n(1)$ なら各 $\lvert y_i\rvert \le 1$ だから，$B_n(1)$ は一辺 $2$ の立方体に含まれる．一辺 $a$ の立方体の上での定数関数 $1$ の積分は，8.1 節で借りた累次積分を成分ごとに繰り返せば $a^n$ である．したがって 7.1 節で既知とした非負な関数についての積分の単調性より $(2/\sqrt n)^n \le \mathrm{vol}\,B_n(1) \le 2^n$ であり，左辺は正，右辺は有限である．

半径による変化を見る．7.3 節で借りた置換積分を，各成分に $y_i = x_i / r$ という置き換え（$c_i = r$，$b_i = 0$）で使う．$B_n(r)$ の各点をこの置き換えで送った集合は $B_n(1)$ であり，$dx = r^n\,dy$ だから $\mathrm{vol}\,B_n(r) = r^n\,\mathrm{vol}\,B_n(1)$ である．よって $r$ と $r'$ についての比は $(r/r')^n$ である．

最後の主張を確かめる．$r/r' = \sqrt{(P+N)/N} = (1 + P/N)^{1/2}$ だから比は $(1+P/N)^{n/2}$ であり，底を $2$ にとった対数について $2^{\log u} = u$（$u > 0$）だから，これは $2^{\,\frac n2\log(1+P/N)}$ に等しい．
:::

命題 8.4.1 の指数に現れた $\frac12\log(1+P/N)$ が，8.2 節で計算した容量にほかならない．雑音球の詰め込みという幾何の勘定と，微分エントロピーの最大化という 8.2 節の勘定が，同じ数に着いている．偶然ではない．どちらも「出力の散らばりの広さを雑音の散らばりの広さで割る」という同じ量を測っていて，前者は体積で，後者は $2^{h}$ という実効的な幅（7.1 節）で測っているだけである．

命題 8.4.1 は体積の比についての主張であって，メッセージがその個数だけ区別できることを示してはいない．雑音の $2$ 乗和が正確に $nN$ になるわけではないし，球を重なりなく詰める配置が実際に作れるかどうかも別の問題である．次に借りる主張は，この見当が正しい答えを与えていることを言うものだが，その根拠はこの勘定とは別の道をたどる．

## 達成可能性

道具を一つ借りる．**ガウス通信路の達成可能性**，すなわち「レートが $\frac12\log(1+P/N)$ を下回っているかぎり，誤り確率をいくらでも小さくできる符号がある」という主張である．使う形を書いておく．

$N > 0$，$P > 0$ とし，$0 < R < \frac12\log(1 + P/N)$ と $\zeta > 0$ をとる．このとき，十分大きいすべての $n$ について，メッセージ数 $M \ge \lceil 2^{nR}\rceil$ の長さ $n$，電力 $P$ のブロック通信路符号（定義 8.3.1）で，最大誤り確率が $P_{e,\max} < \zeta$ を満たすものが存在する．

当てる対象は定義 8.3.1 のブロック通信路符号だけで，依存するのは系 8.4.2 の証明だけである．

本書はこの主張を証明しない．第6章 6.3 節のランダム符号化をそのまま連続版にすればよいのだが，そのために二つの部品を連続版に取り替える必要がある．一つは結合典型集合の勘定で，第6章では系列の個数を数えた（定理 6.2.5）ところを，$\mathbb R^n$ の部分集合の体積で測ることになる．もう一つは電力制約の始末である．入力分布から独立に引いた符号語が $\sum_i (c(m)_i)^2 \le nP$ を満たすとはかぎらないので，破っている符号語を捨てる段が要る．捨てる操作そのものは補題 6.3.6 と同じ形だが，捨てる基準が誤り確率ではなく電力になるので，捨てられる符号語が少ないことを別に示すことになる．どちらも第2章・第6章の道具の連続版で，本書はそれを用意していない．「本書で証明しない」ことと「形式化されていない」ことは別である．本節が借りた主張は，本書が証明を載せないだけで，無条件の機械検証済みの定理として形式化されている．

::: formalization-note
形式化の宣言の仮定は，借りた主張と一つずつ対応している．$P > 0$，雑音の分散が $0$ でないこと，$R > 0$，$R$ が閉じた式より小さいこと，目標の誤り確率が正であることの五つで，ほかに核が可測であるという正則性の条件が付くが，これは同じ名前空間の `isAwgnChannelMeasurable` が与える．結論も同じ形で，ある番号から先のすべての $n$ について，メッセージ数の下界と電力制約を満たす符号があり，どのメッセージについても誤り確率が目標を下回る，という形をしている．形式化は $\log$ を自然対数にとるので，本文が $2^{nR}$ と書く量はあちらでは $\exp(nR)$ にあたり，レートの単位もナットである．底をそろえれば同じ主張である．
:::

## ガウス通信路の符号化定理

達成可能性と逆定理がそろったので，本章の主定理を述べる．第6章 定理 6.4.9 と同じ形の合わせ方である．

::: corollary 8.4.2 ガウス通信路の符号化定理
$N > 0$，$P > 0$ とする．このとき定義 8.3.2 の達成レートの集合 $\mathcal R(P,N)$ は空でなく
$$
\sup \mathcal R(P,N) \;=\; \frac12\log\Big(1 + \frac PN\Big) \;=\; C(P,N)
$$
である．
:::

::: proof
**$\mathcal R(P,N)$ は空でない.** 各 $n$ でメッセージ数 $1$ の符号をとる．符号語は $c(1) := 0 \in \mathbb R^n$ の $1$ 本で，これは電力制約 $0 \le nP$ を満たす．復号器はつねに $1$ を返すものとし，誤りの事象は空だから最大誤り確率は $0$ である．レートの列は $R_n = 0$ で上に有界だから，この族は定義 8.3.2 の意味で達成可能で，その達成レートは $0$ である．

**$\sup\mathcal R(P,N) \le \frac12\log(1+P/N)$.** 系 8.3.6 より $\mathcal R(P,N)$ のどの元も $\frac12\log(1+P/N)$ 以下だから，これは上界である．上限は上界のうち最小のものだから，不等式が従う．

**$\frac12\log(1+P/N) \le \sup\mathcal R(P,N)$.** $0 < R < \frac12\log(1+P/N)$ を満たす実数 $R$ を任意にとり，$R \in \mathcal R(P,N)$ を示す．各 $k \ge 1$ について，借りたガウス通信路の達成可能性を目標値 $1/k$ に対して使い，得られる番号を $n_k$ と書く．$n'_k := \max(n_1, \dots, n_k, k)$ とおけば $(n'_k)$ は広義単調増加で $n'_k \ge k$ だから $n'_k \to \infty$ である．よって $n \ge n'_1$ のとき $\{\,k : n'_k \le n\,\}$ は空でない有限集合で，その最大値を $k(n)$ と書ける．$n \ge n'_{k(n)} \ge n_{k(n)}$ だから，長さ $n$ についてメッセージ数 $\lceil 2^{nR}\rceil$ 以上，最大誤り確率 $1/k(n)$ 未満の符号がとれる．メッセージを $\lceil 2^{nR}\rceil$ 個だけ選んで残し，番号を付け替える．符号語はそのままなので電力制約は保たれ，復号器は元のものを使って捨てたメッセージを指したときは $1$ を返すことにすれば，各メッセージの誤りの事象は元の事象と同じ集合か，その部分集合である．よって最大誤り確率は増えない．$n < n'_1$ の有限個については，上で作ったメッセージ数 $1$ の符号をとる．

得られた族について，$\zeta > 0$ をとり $1/k < \zeta$ となる $k$ を選ぶと，$n \ge n'_k$ では $k(n) \ge k$ だから最大誤り確率は $1/k$ 未満であり，$P^{(n)}_{e,\max} \to 0$ である．レートは，$R > 0$ と $n \ge 1$ より $2^{nR} \ge 1$ だから $2^{nR} \le \lceil 2^{nR}\rceil < 2^{nR} + 1 \le 2\cdot 2^{nR}$ であり，$\log$ をとって $n$ で割ると $n \ge n'_1$ について $R \le R_n < R + 1/n$ である．とくに上に有界で，$n \to \infty$ で $R$ に収束する．残りの $n$ は有限個で $R_n = 0$ だから，上に有界であることも下極限の値も変わらない．よってこの族は達成可能で，その達成レートは $R$ である．

$R$ は $\frac12\log(1+P/N)$ 未満の任意の正数だったから $\sup\mathcal R(P,N) \ge \frac12\log(1+P/N)$ である．二つを合わせて等号を得る．最後の等号は定理 8.2.4 による．
:::

::: formalization-note
系 8.4.2 に対応する単独の宣言はない．第6章 6.4 節で触れたとおり，達成レートの集合そのものに対応する宣言が通信路の側に用意されていないので，両側を突き合わせるこの主張も形式化の外にある．片側ずつの機械検証は，達成可能性が本節で借りた主張に，逆定理が定理 8.3.5 に紐付けた宣言まで及んでいる．
:::

系 8.4.2 によって，8.2 節で最大化問題の値として定めた $C(P,N)$ が，$1$ 回の使用あたりに運べるビット数という操作的な意味をもつ．第6章 定理 6.4.9 のときと同じで，上限が達成されるかどうかは言っていない．$R = C(P,N)$ ちょうどのレートで最大誤り確率が $0$ に収束する符号族があるかは，ここでは問わない．

**数で見る.** $P/N = 1$ とすると $C(P,N) = 0.5$ ビットである．ここで $R = 0.4$，$n = 100$ とすれば，符号語は $2^{40}$ 本（およそ $1.1\times10^{12}$ 本），どれも $\mathbb R^{100}$ の点で，原点からの距離は $\sqrt{100P} = 10\sqrt P$ 以下である．命題 8.4.1 の勘定でいえば，半径 $10\sqrt{2P}$ の球の中に半径 $10\sqrt P$ の雑音球を $2^{50}$ 個ほど詰める配置にあたり，$2^{40}$ 本はそれよりだいぶ余裕をとった本数になっている．その余裕が，雑音の $2$ 乗和が $nN$ ちょうどにはならないぶんを吸収する．
