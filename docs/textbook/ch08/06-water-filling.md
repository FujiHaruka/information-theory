# 8.6 並列ガウス通信路と注水

8.5 節の帯域制限ガウス通信路では，どの標本にも同じ分散 $N_0/2$ の雑音が乗るとした．実際の経路はそうとはかぎらない．周波数の帯域を細かく切ると，雑音の強さは帯域ごとに違う．これは，8.5 節の帯域制限ガウス通信路から，どの標本にも同じ分散という仮定だけを外した場合にあたる．いくつもの経路を束ねて使うときも，経路ごとに雑音の強さが違う．そのとき，限られた総電力をどう配るのがよいか．これが本節の問いで，答えは **注水** と呼ばれる形をとる．

答えを先に言えば，雑音の弱い経路ほど多くの電力を配り，雑音が強すぎる経路には何も配らない，という配分が最適になる．どこで打ち切るかを決めるのが水位と呼ばれる一つの数で，配る電力はその水位と雑音の強さの差である．8.2 節の例 8.2.6 が「同じ電力を分けたほうが得」を示していたが，分ける相手の条件が違うときにどう分けるか，というのが本節の内容である．

本節の $P_1, \dots, P_n$ は各通信路に配る電力で，定義 8.3.1 の誤り確率 $P_e$ とは別のものである．添字が通信路の番号か文字 $e$ かで見分ける．通信路の番号は本節に限り $1$ から $n$ までとする．本節の $n$ は並列に使う通信路の本数で，8.3 節・8.4 節がブロック長に使った $n$ とは別である．

## 電力配分の問題

::: definition 8.6.1 並列ガウス通信路と電力配分
$n \ge 1$ とし，$N_1, \dots, N_n$ を正の実数とする．雑音の分散がそれぞれ $N_1, \dots, N_n$ である $n$ 本のガウス通信路（定義 8.1.1）を，たがいに独立に $1$ 回ずつ同時に使うものを **並列ガウス通信路** と呼ぶ．総電力 $P > 0$ の制約のもとでの **電力配分** とは，$P_i \ge 0$（$1 \le i \le n$）かつ $\sum_{i=1}^{n} P_i \le P$ を満たす実数の組 $(P_1, \dots, P_n)$ のことをいう．その **合計容量** を
$$
\sum_{i=1}^{n} \frac12\log\Big(1 + \frac{P_i}{N_i}\Big)
$$
で定める．
:::

合計容量の各項は，$P_i > 0$ であれば，定理 8.2.4 により第 $i$ 通信路を電力 $P_i$ で使ったときの容量である．$P_i = 0$ の本は定理 8.2.4 の対象から外れる．8.2 節で見たとおり，電力 $0$ の制約を満たす入力は密度をもたないので，そこでは容量が定まらないからである．ただし項の値そのものは $\frac12\log 1 = 0$ で，電力を配らない本では何も運べない，という読みと食い違わない．運べる量について言えるのは，$1$ 本ずつの話までである．$P_i > 0$ の各本については，系 8.4.2 により，その $1$ 本だけを使ったときの達成レートの上限が第 $i$ 項 $\frac12\log(1 + P_i/N_i)$ に等しい．$n$ 本を別々の符号で使ったときにレートの合計がそのまま達成できるか，また $n$ 本をまとめて符号化すればそれを超えられるかは，どちらも本書では示さない．本節が解くのは合計容量という一つの式を電力配分について最大にする問題であって，それ以上でも以下でもない．

::: formalization-note
並列ガウス通信路全体の容量，すなわち $n$ 本の入力をまとめて一つの確率変数として選んでよいとしたときの相互情報量の上限が，定義 8.6.1 の合計容量の最大値に等しいことを，本書は示さない．形式化の側にも，そのままの形の単独の宣言はない．`parallel_gaussian_capacity_formula_minimal` (`InformationTheory/Shannon/ParallelGaussian/PerCoordRegularity.lean`) が与えるのは，測度論の言葉で定義した容量 `parallelGaussianCapacity` (`InformationTheory/Shannon/ParallelGaussian/Basic.lean`) が注水配分の合計容量に等しいところまでで，それが最大値でもあることは，定理 8.6.5 にあたる `isWaterFillingOptimal_of_kkt` (`InformationTheory/Shannon/ParallelGaussian/KKT.lean`) との合成で出る．仮定は，総電力が正であること，各雑音の分散が $0$ でないこと，二つの可測性（どちらも正則性の条件である），および水位が定理 8.6.3 の等式を満たすことである．
:::

`parallelGaussianChannel` (`InformationTheory/Shannon/ParallelGaussian/Basic.lean`)

形式化の `parallelGaussianChannel` は，入力の組 $x$ に対して，成分ごとに平均 $x_i$ 分散 $N_i$ のガウス分布をとった積測度を返す核で，定義 8.6.1 の並列ガウス通信路にあたる．核が可測であるという正則性の前提が二つ付くが，これは通信路の形を決める条件ではない．定義 8.6.1 の電力配分と合計容量には，対応する単独の宣言がない．合計容量の式は，注水配分の最適性を述べる `IsWaterFillingOptimal` (`InformationTheory/Shannon/ParallelGaussian/Basic.lean`) の中に書き下されている．電力の側の制約も，実数の組ではなく入力の分布に対する条件 `parallelGaussianPowerConstraintSet` (`InformationTheory/Shannon/ParallelGaussian/Basic.lean`) として書かれていて，定義 8.6.1 とは対象が違う．

::: definition 8.6.2 注水配分
$n \ge 1$ とし，$N_1, \dots, N_n$ を正の実数，$\nu$ を実数とする．
$$
P_i^{*}(\nu) \;:=\; \max\big(0,\; \nu - N_i\big) \qquad (1 \le i \le n)
$$
で定まる組を，**水位** $\nu$ の **注水配分** と呼ぶ．
:::

::: formalized
`waterFillingPower` (`InformationTheory/Shannon/ParallelGaussian/Basic.lean`)
:::

名前の由来は絵にある．底が段になった一続きの容器を思い浮かべる．横幅を $n$ 等分し，第 $i$ の区画の底の高さを $N_i$ にとる．そこに水を注ぐと，区画のあいだで水は行き来できるので，水面はどの区画でも同じ高さ $\nu$ でそろう．第 $i$ の区画に入る水の深さは，底が水面より低ければ $\nu - N_i$，底が水面より高ければ（$N_i \ge \nu$）$0$ である．どの区画も横幅が同じなので，入った水の量は深さに比例し，全体の量は $\sum_i \max(0, \nu - N_i)$ に比例する．これが総電力 $P$ に等しくなるように水位を決める，というのが以下の筋である．

水面がそろうところが最適なのはなぜか，を絵の言葉で言っておく．以下では，対数の導関数が $(\log e)/t$ であることと合成関数の微分を，微積分の計算規則として既知とする．当てる相手は，この段落で $\frac12\log(1 + P_i/N_i)$ を $P_i$ で微分するところだけである．第 $i$ 通信路に電力をほんの少し足したとき，合計容量の第 $i$ 項 $\frac12\log(1 + P_i/N_i)$ が電力 $1$ 単位あたりどれだけ増えるかは，$P_i$ で微分して $\frac{\log e}{2(N_i + P_i)}$ である．分母の $N_i + P_i$ は，底の高さに水の深さを足したもの，すなわちその区画の水面の高さにほかならない．だから，水面の低い区画ほど電力 $1$ 単位あたりの増分が大きい．任意の配分は，区画のあいだに仕切りを立てて水面の高さをばらばらにした状態にあたり，仕切りを外すと水面がそろう，と見ればよい．水の入っている区画のうち水面がいちばん高いものから，水面がいちばん低い区画へ電力を少し移せば，減るぶんより増えるぶんが大きく，合計は増える．移して得をする組がなくなるのは，水の入っている区画の水面がすべてそろい，しかも水の入っていない区画の底がその水面以上にあるときで，これが注水配分の形にほかならない．そこでは水の入っているどの区画でも増分が同じ $\frac{\log e}{2\nu}$ になる．この $\frac{\log e}{2\nu}$ が，あとで補題 8.6.4 が上から抑えるのに使う接線の傾きである．

## 水位の存在と一意性

道具を一つ借りる．**中間値の定理**，すなわち「有界閉区間の上の実数値連続関数は，両端での値のあいだのどの値もとる」という微積分の定理である．当てる相手は，定理 8.6.3 の証明で置く $1$ 変数の実数値関数 $\phi(\nu) = \sum_{i=1}^{n}\max(0, \nu - N_i)$ の，有界閉区間 $[0, N_1 + P]$ への制限だけであり，依存するのは定理 8.6.3 の証明だけである．また，連続関数の有限個の最大値と有限和がふたたび連続であることを，微積分の計算規則として既知とする．

::: theorem 8.6.3 水位の存在と一意性
$n \ge 1$，$P > 0$ とし，$N_1, \dots, N_n$ を正の実数とする．このとき
$$
\sum_{i=1}^{n} \max\big(0,\; \nu - N_i\big) \;=\; P
$$
を満たす実数 $\nu$ がただ一つ存在する．
:::

::: proof
$\phi(\nu) := \sum_{i=1}^{n}\max(0, \nu - N_i)$ とおく．各 $\nu \mapsto \max(0, \nu - N_i)$ は連続関数の最大値だから連続であり，その有限和である $\phi$ も連続である．

両端の値を見る．$N_i > 0$ より $\phi(0) = \sum_i \max(0, -N_i) = 0$ である．$\nu_1 := N_1 + P$ とおくと，第 $1$ 項だけを残して $\phi(\nu_1) \ge \max(0, \nu_1 - N_1) = P$ である．

$\phi$ は閉区間 $[0, \nu_1]$ の上で連続で，$\phi(0) = 0 \le P \le \phi(\nu_1)$ だから，借りた中間値の定理より $\phi(\nu) = P$ を満たす $\nu \in [0, \nu_1]$ が存在する．

そのような $\nu$ が二つとないことを見る．$N_1, \dots, N_n$ のうち最小のものを $N_{i_0}$ と書く．$\phi(\nu) = P > 0$ を満たす $\nu$ については，ある $i$ で $\max(0, \nu - N_i) > 0$，すなわち $\nu > N_i \ge N_{i_0}$ だから，そのような $\nu$ はすべて $N_{i_0}$ より大きい．そこで $N_{i_0} \le \nu_a < \nu_b$ とすると，各 $i$ について $\nu_a - N_i < \nu_b - N_i$ だから $\max(0, \nu_a - N_i) \le \max(0, \nu_b - N_i)$ であり，第 $i_0$ 項については $\nu_a \ge N_{i_0}$ より二つの項が $\nu_a - N_{i_0}$ と $\nu_b - N_{i_0}$ に等しい．項ごとに足し合わせると $\phi(\nu_b) - \phi(\nu_a) \ge \nu_b - \nu_a > 0$ である．よって $\phi$ は $N_{i_0}$ 以上のところで狭義単調増加であり，そこで値 $P$ をとる $\nu$ は一つしかない．
:::

::: formalization-note
定理 8.6.3 に対応する単独の宣言はない．存在の側を与えるのが `exists_waterFillingKKT_of_pos` (`InformationTheory/Shannon/ParallelGaussian/KKT.lean`) で，こちらは雑音の分散が正であることを仮定にもたない（$0$ でもよい）ので，定理 8.6.3 より広い場合を覆っている．仮定は総電力が正であること一つだけで，通信路が $1$ 本以上あることは仮定になっていない．通信路の本数を $n + 1$ と書き，添字の型が $n + 1$ 個の値をもつようにとることで，型のほうから出るようにしてある．一意性の側は，形式化されていない．
:::

## 接線による上界

最適性の証明は，1.1 節の信頼の底から出した対数不等式 $\log t \le (t-1)\log e$ だけで通る．対数のグラフが接線より下にあるという，第7章 補題 7.2.3 でも使ったのと同じ道具である．注水配分の点で対数に接線を引き，そのぶんだけ上から抑える．それを述べるのが補題 8.6.4 である．

::: lemma 8.6.4 注水配分での接線
$N > 0$，$\nu > 0$ とし，$p^{*} := \max(0, \nu - N)$ とおく．このとき，どの実数 $t \ge 0$ についても
$$
\frac12\log\Big(1 + \frac tN\Big)
  \;\le\; \frac12\log\Big(1 + \frac{p^{*}}{N}\Big) + \frac{\log e}{2\nu}\big(t - p^{*}\big)
$$
である．
:::

::: proof
$1 + t/N = (N+t)/N$ と $1 + p^{*}/N = (N+p^{*})/N$ はどちらも正である．1.1 節の信頼の底から出した対数不等式 $\log u \le (u-1)\log e$ を $u := (N+t)/(N+p^{*})$ に当てると
$$
\log\Big(1 + \frac tN\Big) - \log\Big(1 + \frac{p^{*}}{N}\Big)
  \;=\; \log u \;\le\; \frac{t - p^{*}}{N + p^{*}}\,\log e
$$
である．両辺を $2$ で割ると，示すべきことは
$$
\frac{t - p^{*}}{2(N + p^{*})}\,\log e \;\le\; \frac{\log e}{2\nu}\big(t - p^{*}\big)
$$
に帰着する．$\nu$ と $N$ の大小で場合を分ける．

$\nu > N$ のときは $p^{*} = \nu - N$ だから $N + p^{*} = \nu$ であり，両辺は等しい．

$\nu \le N$ のときは $p^{*} = 0$ だから $N + p^{*} = N$ であり，$t - p^{*} = t \ge 0$ である．$0 < \nu \le N$ と $\log e > 0$ から $\frac{t\log e}{2N} \le \frac{t\log e}{2\nu}$ であり，これが示すべき不等式である．
:::

`waterFillingCost_tangent_le` (`InformationTheory/Shannon/ParallelGaussian/KKT.lean`)
:::

::: formalization-note
形式化の `waterFillingCost_tangent_le` の仮定は，補題 8.6.4 と一つずつ対応している．雑音の分散が $0$ でないこと，水位が正であること，引数が $0$ 以上であることの三つで，これがすべてである．形式化では分散を非負の量として扱っているので，一つめは本文の $N > 0$ と同じことである．形式化は $\log$ を自然対数にとるので $\log e = 1$ であり，本文の $\frac{\log e}{2\nu}$ にあたる係数が $\frac{1}{2\nu}$ と書かれている．
:::

## 注水の最適性

::: theorem 8.6.5 注水配分の最適性
$n \ge 1$，$P > 0$ とし，$N_1, \dots, N_n$ を正の実数とする．実数 $\nu$ が $\sum_{i=1}^{n}\max(0, \nu - N_i) = P$ を満たすとする．このとき注水配分 $(P_1^{*}(\nu), \dots, P_n^{*}(\nu))$ は総電力 $P$ の制約のもとでの電力配分（定義 8.6.1）であり，$P'_i \ge 0$（$1 \le i \le n$）かつ $\sum_{i=1}^{n} P'_i \le P$ を満たすどの実数の組 $(P'_1, \dots, P'_n)$ についても
$$
\sum_{i=1}^{n} \frac12\log\Big(1 + \frac{P'_i}{N_i}\Big)
  \;\le\; \sum_{i=1}^{n} \frac12\log\Big(1 + \frac{P_i^{*}(\nu)}{N_i}\Big)
$$
である（$P_i^{*}(\nu)$ は定義 8.6.2 の注水配分）．
:::

::: proof
注水配分が電力配分であることを見る．各 $P_i^{*}(\nu) = \max(0, \nu - N_i)$ は $\max$ の形から $0$ 以上であり，総和は仮定よりちょうど $P$ で，$P$ 以下である．よって定義 8.6.1 の電力配分の条件を満たす．

まず $\nu > 0$ を見る．仮定の和は $P > 0$ だから，ある $i$ で $\max(0, \nu - N_i) > 0$，すなわち $\nu > N_i > 0$ である．

各項に補題 8.6.4 を，$N := N_i$，$t := P'_i$ ととって当てると，$p^{*} = P_i^{*}(\nu)$ であり
$$
\frac12\log\Big(1 + \frac{P'_i}{N_i}\Big)
  \;\le\; \frac12\log\Big(1 + \frac{P_i^{*}(\nu)}{N_i}\Big)
    + \frac{\log e}{2\nu}\big(P'_i - P_i^{*}(\nu)\big)
$$
である．$i$ について足すと
$$
\sum_{i=1}^{n} \frac12\log\Big(1 + \frac{P'_i}{N_i}\Big)
  \;\le\; \sum_{i=1}^{n} \frac12\log\Big(1 + \frac{P_i^{*}(\nu)}{N_i}\Big)
    + \frac{\log e}{2\nu}\Big(\sum_{i=1}^{n} P'_i - \sum_{i=1}^{n} P_i^{*}(\nu)\Big)
$$
となる．仮定より $\sum_i P_i^{*}(\nu) = P$ であり，$\sum_i P'_i \le P$ だから括弧の中は $0$ 以下である．$\nu > 0$ と $\log e > 0$ より係数は正だから，最後の項は $0$ 以下であり，落として主張を得る．
:::

::: formalized
`isWaterFillingOptimal_of_kkt` (`InformationTheory/Shannon/ParallelGaussian/KKT.lean`)
:::

::: formalization-note
形式化のルートも本文と同じで，注水配分の点で対数に接線を引く段（補題 8.6.4）を各成分に当ててから和をとる．
:::

証明で効いたのは二つだけである．接線の傾きが $\frac{\log e}{2\nu}$ という，$i$ によらない一つの値で抑えられること（補題 8.6.4）と，注水配分が総電力を使い切っていること（$\sum_i P_i^{*}(\nu) = P$）である．前者があるので，$n$ 本ぶんの接線の項が $\sum_i P'_i$ という一つの和にまとまる．後者があるので，その和が電力制約と直接くらべられる．雑音が強すぎて水位に届かない通信路（$N_i \ge \nu$）で接線の傾きがそのままでは足りないところを，補題 8.6.4 の第 $2$ の場合が $\frac{\log e}{2N_i} \le \frac{\log e}{2\nu}$ で吸収している．

## 数で見る

::: example 8.6.6 $2$ 本の並列ガウス通信路
$n = 2$，$N_1 = 1$，$N_2 = 4$ とする．総電力 $P = 2$ のとき水位は $\nu = 3$ で，注水配分は $(2, 0)$，その合計容量は $\frac12\log_2 3$ で約 $0.7925$ ビットである．等分した配分 $(1,1)$ の合計容量は約 $0.6610$ ビットで，これより小さい．総電力 $P = 5$ のときは水位が $\nu = 5$ で，注水配分は $(4,1)$，合計容量は約 $1.3219$ ビット，等分した配分 $(2.5, 2.5)$ の合計容量は約 $1.2539$ ビットである．
:::

::: proof
$P = 2$ のとき．水位が第 $2$ 通信路の底 $4$ に届かないと見当をつけると，水が入るのは第 $1$ 通信路だけで $\nu - 1 = 2$，すなわち $\nu = 3$ である．これは $4$ 以下だから見当と整合する．実際 $\max(0, 3-1) + \max(0, 3-4) = 2 + 0 = 2$ で定理 8.6.3 の等式を満たし，それを満たす実数はただ一つだから，これが水位である．注水配分は $(2, 0)$ で，合計容量は $\frac12\log_2(1 + 2/1) + \frac12\log_2(1 + 0/4) = \frac12\log_2 3$ である．$\log_2 3 = 1.5849\ldots$ だから約 $0.7925$ である．等分した配分では $\frac12\log_2 2 + \frac12\log_2 1.25 = 0.5 + 0.1610\ldots$ で約 $0.6610$ である．

$P = 5$ のとき．今度は水位が $4$ を超えると見当をつけると，両方の通信路に水が入るので $(\nu - 1) + (\nu - 4) = 5$，すなわち $\nu = 5$ である．これは $4$ より大きいから見当と整合する．実際 $\max(0, 5-1) + \max(0, 5-4) = 4 + 1 = 5$ で，これが水位である．注水配分は $(4,1)$ で，合計容量は $\frac12\log_2 5 + \frac12\log_2 1.25 = 1.1610\ldots + 0.1610\ldots$ で約 $1.3219$ である．等分した配分では $\frac12\log_2 3.5 + \frac12\log_2 1.625 = 0.9037\ldots + 0.3502\ldots$ で約 $1.2539$ である．
:::

::: formalization-note
例 8.6.6 に対応する宣言は形式化されていない．例 8.6.6 に付した証明が，この主張の保証のすべてである．
:::

例 8.6.6 の前半は，雑音の強い通信路を使わないほうがよい場合である．総電力 $2$ では水位 $3$ が第 $2$ 通信路の雑音 $4$ に届かないので，そちらには何も配らない．後半では総電力が $5$ に増えて水位が $5$ まで上がり，第 $2$ 通信路にも $1$ だけ配られる．注水の絵でいえば，注ぐ水の量を増やしていくと，あるところで二つめの区画の底が水没する，ということである．どちらの場合も等分した配分より合計容量が大きい．差は前半が約 $0.13$ ビット，後半が約 $0.07$ ビットで，合計容量に対する割合で見ると前半が約 $17$ パーセント，後半が約 $5$ パーセントである．後半では水位が第 $2$ 通信路の底を超えていて，注水配分も等分した配分もどちらの通信路にも電力を配っており，二つの配分の違いがそれだけ小さい．

**帯域ごとに雑音が違うとき.** 定義 8.6.1 の並列ガウス通信路は，8.5 節の帯域制限ガウス通信路の雑音が帯域ごとに違う場合にあたる．帯域を等しい幅に切り，第 $i$ の帯域を，$1$ 標本あたりの雑音の分散が $N_i$ であるガウス通信路と読む．8.5 節が帯域制限ガウス通信路を分散 $N_0/2$ のガウス通信路の使用に読み替えたのと同じ換算である．第 $i$ の帯域に配る電力も $1$ 標本あたりで測って $P_i$ と書けば，総電力をどの帯域に配るかという問題がそのまま定義 8.6.1 の形になる．どの帯域も幅が同じで $1$ 秒あたりの標本の個数がそろっているので，$1$ 標本あたりで測るか $1$ 秒あたりで測るかは，全体に共通の因子の違いにしかならない．雑音の弱い帯域に電力を集め，雑音が水位を超える帯域は使わない，というのが定理 8.6.5 の答えである．雑音の強さが帯域によらないときは全部の $N_i$ が等しく，注水配分は等分になって，8.5 節の設定に戻る．
