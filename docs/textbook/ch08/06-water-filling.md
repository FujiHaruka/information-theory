# 8.6 並列ガウス通信路と注水

8.5 節の帯域制限通信路では，どの標本にも同じ分散 $N_0/2$ の雑音が乗るとした．実際の経路はそうとはかぎらない．周波数の帯域を細かく切ると，雑音の強さは帯域ごとに違う．いくつもの経路を束ねて使うときも，経路ごとに雑音の強さが違う．そのとき，限られた総電力をどう配るのがよいか．これが本節の問いで，答えは **注水** と呼ばれる形をとる．

答えを先に言えば，雑音の弱い経路ほど多くの電力を配り，雑音が強すぎる経路には何も配らない，という配分が最適になる．どこで打ち切るかを決めるのが水位と呼ばれる一つの数で，配る電力はその水位と雑音の強さの差である．8.2 節の例 8.2.5 が「同じ電力を分けたほうが得」を示していたが，分ける相手の条件が違うときにどう分けるか，というのが本節の内容である．

本節の $P_1, \dots, P_n$ は各通信路に配る電力で，定義 8.3.1 の誤り確率 $P_e$ とは別のものである．添字が通信路の番号か文字 $e$ かで見分ける．通信路の番号は本節に限り $1$ から $n$ までとする．

## 電力配分の問題

::: definition 8.6.1 並列ガウス通信路と電力配分
$n \ge 1$ とし，$N_1, \dots, N_n$ を正の実数とする．雑音の分散がそれぞれ $N_1, \dots, N_n$ である $n$ 本のガウス通信路（定義 8.1.1）を，たがいに独立に $1$ 回ずつ同時に使うものを **並列ガウス通信路** と呼ぶ．総電力 $P > 0$ の制約のもとでの **電力配分** とは，$P_i \ge 0$（$1 \le i \le n$）かつ $\sum_{i=1}^{n} P_i \le P$ を満たす実数の組 $(P_1, \dots, P_n)$ のことをいう．その **合計容量** を
$$
\sum_{i=1}^{n} \frac12\log\Big(1 + \frac{P_i}{N_i}\Big)
$$
で定める．
:::

合計容量の各項は，定理 8.2.4 により第 $i$ 通信路を電力 $P_i$ で使ったときの容量である．$n$ 本を別々の符号で使えば，運べる量はその和になる．本節が解くのは，この和を電力配分について最大にする問題である．

::: formalization-note
並列ガウス通信路全体の容量，すなわち $n$ 本の入力をまとめて一つの確率変数として選んでよいとしたときの相互情報量の上限が，定義 8.6.1 の合計容量の最大値に等しいことを，本書は示さない．形式化の側にはその主張があり，`parallel_gaussian_capacity_formula_minimal` (`InformationTheory/Shannon/ParallelGaussian/PerCoordRegularity.lean`) が，測度論の言葉で定義した容量 `parallelGaussianCapacity` (`InformationTheory/Shannon/ParallelGaussian/Basic.lean`) が注水配分の合計容量に等しいことを与える．仮定は，総電力が正であること，各雑音の分散が $0$ でないこと，二つの可測性（どちらも正則性の条件である），および水位が定理 8.6.3 の等式を満たすことである．
:::

::: definition 8.6.2 注水配分
$n \ge 1$ とし，$N_1, \dots, N_n$ を正の実数，$\nu$ を実数とする．
$$
P_i^{*}(\nu) \;:=\; \max\big(0,\; \nu - N_i\big) \qquad (1 \le i \le n)
$$
で定まる組を，**水位** $\nu$ の **注水配分** と呼ぶ．
:::

名前の由来は絵にある．底の高さがそれぞれ $N_1, \dots, N_n$ の $n$ 本の桶を横に並べ，全体に水を注ぐと，水面は一つの高さ $\nu$ でそろう．第 $i$ の桶に入る水の深さが $\nu - N_i$ で，底が水面より高い桶（$N_i \ge \nu$）には水が入らない．注いだ水の総量が $\sum_i \max(0, \nu - N_i)$ で，これが総電力 $P$ に等しくなるように水位を決める，というのが以下の筋である．

## 水位の存在

::: theorem 8.6.3 水位の存在
$n \ge 1$，$P > 0$ とし，$N_1, \dots, N_n$ を正の実数とする．このとき
$$
\sum_{i=1}^{n} \max\big(0,\; \nu - N_i\big) \;=\; P
$$
を満たす実数 $\nu$ が存在する．
:::

証明には **中間値の定理**，すなわち「有界閉区間の上の実数値連続関数は，両端での値のあいだのどの値もとる」という微積分の定理を借りる．当てる相手は下の $\phi$ だけで，依存するのは定理 8.6.3 の証明だけである．また，連続関数の有限個の最大値と有限和がふたたび連続であることを，微積分の計算規則として既知とする．

::: proof
$\phi(\nu) := \sum_{i=1}^{n}\max(0, \nu - N_i)$ とおく．各 $\nu \mapsto \max(0, \nu - N_i)$ は連続関数の最大値だから連続であり，その有限和である $\phi$ も連続である．

両端の値を見る．$N_i > 0$ より $\phi(0) = \sum_i \max(0, -N_i) = 0$ である．$\nu_1 := N_1 + P$ とおくと，第 $1$ 項だけを残して $\phi(\nu_1) \ge \max(0, \nu_1 - N_1) = P$ である．

$\phi$ は閉区間 $[0, \nu_1]$ の上で連続で，$\phi(0) = 0 \le P \le \phi(\nu_1)$ だから，借りた中間値の定理より $\phi(\nu) = P$ を満たす $\nu \in [0, \nu_1]$ が存在する．
:::

## 接線による上界

最適性の証明は，1.1 節の信頼の底から出した対数不等式 $\log t \le (t-1)\log e$ だけで通る．対数のグラフが接線より下にあるという，第7章 補題 7.2.3 でも使ったのと同じ道具である．注水配分の点で対数に接線を引き，そのぶんだけ上から抑える，というのが次の補題である．

::: lemma 8.6.4 注水配分での接線
$N > 0$，$\nu > 0$ とし，$p^{*} := \max(0, \nu - N)$ とおく．このとき，どの実数 $t \ge 0$ についても
$$
\frac12\log\Big(1 + \frac tN\Big)
  \;\le\; \frac12\log\Big(1 + \frac{p^{*}}{N}\Big) + \frac{\log e}{2\nu}\big(t - p^{*}\big)
$$
である．
:::

::: proof
$1 + t/N = (N+t)/N$ と $1 + p^{*}/N = (N+p^{*})/N$ はどちらも正である．1.1 節の信頼の底から出した対数不等式 $\log u \le (u-1)\log e$ を $u := (N+t)/(N+p^{*})$ に当てると
$$
\log\Big(1 + \frac tN\Big) - \log\Big(1 + \frac{p^{*}}{N}\Big)
  \;=\; \log u \;\le\; \frac{t - p^{*}}{N + p^{*}}\,\log e
$$
である．両辺を $2$ で割ると，示すべきことは
$$
\frac{t - p^{*}}{2(N + p^{*})}\,\log e \;\le\; \frac{\log e}{2\nu}\big(t - p^{*}\big)
$$
に帰着する．$\nu$ と $N$ の大小で場合を分ける．

$\nu > N$ のときは $p^{*} = \nu - N$ だから $N + p^{*} = \nu$ であり，両辺は等しい．

$\nu \le N$ のときは $p^{*} = 0$ だから $N + p^{*} = N$ であり，$t - p^{*} = t \ge 0$ である．$0 < \nu \le N$ と $\log e > 0$ から $\frac{t\log e}{2N} \le \frac{t\log e}{2\nu}$ であり，これが示すべき不等式である．
:::

## 注水の最適性

::: theorem 8.6.5 注水配分の最適性
$n \ge 1$，$P > 0$ とし，$N_1, \dots, N_n$ を正の実数とする．実数 $\nu$ が $\sum_{i=1}^{n}\max(0, \nu - N_i) = P$ を満たすとする．このとき，$P'_i \ge 0$（$1 \le i \le n$）かつ $\sum_{i=1}^{n} P'_i \le P$ を満たすどの実数の組 $(P'_1, \dots, P'_n)$ についても
$$
\sum_{i=1}^{n} \frac12\log\Big(1 + \frac{P'_i}{N_i}\Big)
  \;\le\; \sum_{i=1}^{n} \frac12\log\Big(1 + \frac{P_i^{*}(\nu)}{N_i}\Big)
$$
である（$P_i^{*}(\nu)$ は定義 8.6.2 の注水配分）．
:::

::: proof
まず $\nu > 0$ を見る．仮定の和は $P > 0$ だから，ある $i$ で $\max(0, \nu - N_i) > 0$，すなわち $\nu > N_i > 0$ である．

各項に補題 8.6.4 を，$N := N_i$，$t := P'_i$ ととって当てると，$p^{*} = P_i^{*}(\nu)$ であり
$$
\frac12\log\Big(1 + \frac{P'_i}{N_i}\Big)
  \;\le\; \frac12\log\Big(1 + \frac{P_i^{*}(\nu)}{N_i}\Big)
    + \frac{\log e}{2\nu}\big(P'_i - P_i^{*}(\nu)\big)
$$
である．$i$ について足すと
$$
\sum_{i=1}^{n} \frac12\log\Big(1 + \frac{P'_i}{N_i}\Big)
  \;\le\; \sum_{i=1}^{n} \frac12\log\Big(1 + \frac{P_i^{*}(\nu)}{N_i}\Big)
    + \frac{\log e}{2\nu}\Big(\sum_{i=1}^{n} P'_i - \sum_{i=1}^{n} P_i^{*}(\nu)\Big)
$$
となる．仮定より $\sum_i P_i^{*}(\nu) = P$ であり，$\sum_i P'_i \le P$ だから括弧の中は $0$ 以下である．$\nu > 0$ と $\log e > 0$ より係数は正だから，最後の項は $0$ 以下であり，落として主張を得る．
:::

::: formalization-note
形式化のルートも本文と同じで，注水配分の点で対数に接線を引く段（`waterFillingCost_tangent_le`，同じファイル）を各成分に当ててから和をとる．形式化は $\log$ を自然対数にとるので $\log e = 1$ であり，本文の $\frac{\log e}{2\nu}$ にあたる係数が $\frac{1}{2\nu}$ と書かれている．
:::

証明で効いたのは二つだけである．接線の傾きが $\frac{\log e}{2\nu}$ という，$i$ によらない一つの値で抑えられること（補題 8.6.4）と，注水配分が総電力を使い切っていること（$\sum_i P_i^{*}(\nu) = P$）である．前者があるので，$n$ 本ぶんの接線の項が $\sum_i P'_i$ という一つの和にまとまる．後者があるので，その和が電力制約と直接くらべられる．雑音が強すぎて水位に届かない通信路（$N_i \ge \nu$）で接線の傾きがそのままでは足りないところを，補題 8.6.4 の第 $2$ の場合が $\frac{\log e}{2N_i} \le \frac{\log e}{2\nu}$ で吸収している．

## 数で見る

::: example 8.6.6 $2$ 本の並列ガウス通信路
$n = 2$，$N_1 = 1$，$N_2 = 4$ とする．総電力 $P = 2$ のとき水位は $\nu = 3$ で，注水配分は $(2, 0)$，その合計容量は $\frac12\log_2 3$ で約 $0.7925$ ビットである．等分した配分 $(1,1)$ の合計容量は約 $0.6610$ ビットで，これより小さい．総電力 $P = 5$ のときは水位が $\nu = 5$ で，注水配分は $(4,1)$，合計容量は約 $1.3219$ ビット，等分した配分 $(2.5, 2.5)$ の合計容量は約 $1.2539$ ビットである．
:::

::: proof
$P = 2$ のとき．$\nu = 3$ とすると $\max(0, 3-1) + \max(0, 3-4) = 2 + 0 = 2$ だから，定理 8.6.3 の等式を満たす．注水配分は $(2, 0)$ で，合計容量は $\frac12\log_2(1 + 2/1) + \frac12\log_2(1 + 0/4) = \frac12\log_2 3$ である．$\log_2 3 = 1.5849\ldots$ だから約 $0.7925$ である．等分した配分では $\frac12\log_2 2 + \frac12\log_2 1.25 = 0.5 + 0.1610\ldots$ で約 $0.6610$ である．

$P = 5$ のとき．$\nu = 5$ とすると $\max(0, 5-1) + \max(0, 5-4) = 4 + 1 = 5$ である．注水配分は $(4,1)$ で，合計容量は $\frac12\log_2 5 + \frac12\log_2 1.25 = 1.1610\ldots + 0.1610\ldots$ で約 $1.3219$ である．等分した配分では $\frac12\log_2 3.5 + \frac12\log_2 1.625 = 0.9037\ldots + 0.3502\ldots$ で約 $1.2539$ である．
:::

::: formalization-note
例 8.6.6 に対応する宣言は形式化されていない．例 8.6.6 に付した証明が，この主張の保証のすべてである．
:::

例 8.6.6 の前半は，雑音の強い通信路を使わないほうがよい場合である．総電力 $2$ では水位 $3$ が第 $2$ 通信路の雑音 $4$ に届かないので，そちらには何も配らない．後半では総電力が $5$ に増えて水位が $5$ まで上がり，第 $2$ 通信路にも $1$ だけ配られる．注水の絵でいえば，注ぐ水の量を増やしていくと，あるところで二つめの桶の底が水没する，ということである．どちらの場合も等分した配分より合計容量が大きく，しかも差は総電力が小さいときのほうが大きい．雑音の強さの違いが効くのは，配れる電力が少ないときだからである．

**8.5 節とのつながり.** 定義 8.6.1 の並列ガウス通信路は，8.5 節の帯域制限通信路の雑音が帯域ごとに違う場合にあたる．帯域を細かく切って，第 $i$ の小さな帯域での雑音の強さを $N_i$ と読めば，総電力 $P$ をどの帯域に配るかという問題がそのまま定義 8.6.1 の形になる．雑音の弱い帯域に電力を集め，雑音が水位を超える帯域は使わない，というのが定理 8.6.5 の答えである．雑音の強さが帯域によらないときは全部の $N_i$ が等しく，注水配分は等分になって，8.5 節の設定に戻る．
