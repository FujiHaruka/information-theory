# 10.1 最大エントロピー問題

第1章はエントロピーを分布の不確かさの尺度として立て，定理 1.1.5 でその最大値を求めた．すなわち，アルファベットの大きさしか分かっていないとき，いちばん不確かなのは一様分布である．だが分布について分かっていることが，それだけとは限らない．サイコロの目の平均が測定で分かっている，粒子の平均エネルギーが分かっている，文書の中で母音が占める割合だけが分かっている．こうした部分的な知識をもって，では分布そのものを何と定めればよいか．

候補は無数にある．目の平均が $4.5$ である分布は 1 つではないからである．そこで選び方の原則を一つ置く．**知っていることは反映し，知らないことは決めつけない**．測定が言っているのは平均が $4.5$ だということだけで，それ以上は何も言っていない．にもかかわらず「$1$ の目は出ない」と決めた分布を選べば，測定が支持していない主張を勝手に足したことになる．逆に，条件を満たす分布のうち**もっとも不確かなもの**を選べば，条件が強いること以外は何も決めつけていない．この選び方を定式化したのが，本章の最大エントロピー問題である．

本章では $\log$ の底を自然対数にとる．以下で主役になる分布は $\exp$ で書かれた形をしており，$\log$ と $\exp$ が互いに逆でなければ本章の恒等式が閉じないからである．単位はナットで，ビットで読みたいときは $\log 2 \approx 0.693$ で割る．アルファベット$\mathcal X$ は空でない有限集合とし，その上の分布，すなわち各点に非負の値を与えて総和が 1 になる関数を，一般には大文字 $P$，$Q$ で書き，あとで主役になる特定の分布だけを小文字に星印を付けて書く．

::: formalization-note 本章共通
形式化も $\log$ を自然対数にとるので，本章は本文と形式化で単位が一致する．

命題 10.1.2 の形式化は確率変数の像測度に対して述べられており，10.2 節以降が紐付ける宣言はアルファベット上の関数としての分布に対して述べられている．相対エントロピーも，前者は測度に対する形，後者は pmf に対する形で，単独の宣言としては別のものである．
:::

## 制約と実行可能集合

::: definition 10.1.1 モーメント制約と実行可能集合
空でない有限アルファベット $\mathcal X$ 上の実数値関数 $f_1, \dots, f_k$（$k \ge 0$）を**特徴関数**（feature function），実数 $c_1, \dots, c_k$ をその制約の値と呼ぶ．$\mathcal X$ 上の分布 $P$ が **モーメント制約** を満たすとは，
$$
\mathbb E_P[f_i] \;:=\; \sum_{x \in \mathcal X} P(x)\, f_i(x) \;=\; c_i
\qquad (i = 1, \dots, k)
$$
がすべての $i$ で成り立つことをいう．モーメント制約を満たす分布を **実行可能** と呼び，実行可能な分布全体の集合を **実行可能集合** という．実行可能集合の上で $H$ を最大にする分布を求める問題を，**最大エントロピー問題** という．
:::

制約は $P$ について線形である．$\mathbb E_P[f_i]$ は値の並び$\big(P(x)\big)_{x \in \mathcal X}$ の一次結合だから，$i$ 番目の制約は分布全体のなす集合を超平面で切る（$f_i$ が恒等的に 0 で $c_i \ne 0$ という退化した場合だけは，切り口が空になる）．実行可能集合はその $k$ 枚の切り口の共通部分であり，$k = 0$（制約を何も課さない場合）なら分布全体そのものである．何を知っているかは特徴関数の選び方に入る．$k = 1$ で $f_1(x) = x$ なら平均を知っていることになり，$f_2(x) = x^2$ を足せば 2 次モーメントまで，ある部分集合の指示関数をとればその部分集合の確率を知っていることになる．

::: formalization-note
定義 10.1.1 の実行可能集合を名指す宣言はない．モーメント制約は，形式化では定理 10.2.5 と定理 10.2.6 の仮定として直接現れる．
:::

## 一様分布からの隔たりとして読む

::: proposition 10.1.2
$\mathcal X$ を空でない有限アルファベット，$M := |\mathcal X|$ とし，$U$ を $\mathcal X$上の一様分布とする．$\mathcal X$ 上の任意の分布 $P$ に対して
$$
D(P \,\|\, U) \;=\; \log M - H(P).
$$
:::

::: proof
$U(x) = 1/M$ はすべての $x$ で正だから，1.6 節の相対エントロピーの和はどの項も有限で，
$$
D(P \,\|\, U) \;=\; \sum_{x} P(x) \log\frac{P(x)}{1/M}
  \;=\; \sum_{x} P(x)\log P(x) \;+\; \log M \sum_{x} P(x)
$$
と 2 つの和に分けられる（$P(x) = 0$ の項はどちらの形でも 0 なので，分け方に注意は要らない）．第 1 の和は定義 1.1.1 より $-H(P)$，第 2 の和は $\sum_x P(x) = 1$ より$\log M$ である．
:::

::: formalized
`klDiv_uniformOn_univ_toReal_eq` (`InformationTheory/Shannon/MaxEntropy/Basic.lean`)
:::

この恒等式が本章の全体を貫く読み替えを与える．$\log M$ は $P$ に依らない定数だから，$H(P)$ を大きくすることと $D(P \,\|\, U)$ を小さくすることは，同じ一つのことである．エントロピーが最大の分布とは，一様分布からの隔たりがもっとも小さい分布にほかならない．1.6 節が情報不等式から定理 1.1.5 を再現してみせたのも，この恒等式に $D \ge 0$ を当てただけだった．等式そのものはそこで一度使っている．本章ではこれが出発点になる．

::: corollary 10.1.3
$\mathcal X$ を空でない有限アルファベット，$U$ をその上の一様分布とする．特徴関数$f_1, \dots, f_k$ と制約の値 $c_1, \dots, c_k$ の定める実行可能集合を $\mathcal F$ と書く．$\mathcal F$ に属する分布 $P$ について，次の二つは同値である．

1. 任意の $Q \in \mathcal F$ に対して $H(Q) \le H(P)$ である．
2. 任意の $Q \in \mathcal F$ に対して $D(P \,\|\, U) \le D(Q \,\|\, U)$ である．
:::

::: proof
$M := |\mathcal X|$ とおく．$\mathcal F$ の 2 元 $P, Q$ をとり，命題 10.1.2 をそれぞれに当てると $D(P \,\|\, U) = \log M - H(P)$，$D(Q \,\|\, U) = \log M - H(Q)$ だから
$$
D(Q \,\|\, U) - D(P \,\|\, U) \;=\; H(P) - H(Q)
$$
が成り立つ．左辺が 0 以上であることと右辺が 0 以上であることは同じであり，これは$D(P \,\|\, U) \le D(Q \,\|\, U)$ と $H(Q) \le H(P)$ が同値だということである．$Q$ を$\mathcal F$ 全体で動かせば，1 と 2 の同値を得る．
:::

::: formalization-note
系 10.1.3 に対応する単独の宣言はない．命題 10.1.2 の形式化を 2 つの分布で使い，差をとった形になる．
:::

**基準を取り替える.** この読み替えの値打ちは，基準にとる分布を取り替えられるところにある．一様分布は，制約が何もないときの「何も決めつけていない分布」だった．だが制約があるとき一様分布が実行可能とは限らない．例 10.1.4 がまさにそうである．一様分布が実行可能でなければ，実行可能集合の外から隔たりを測っていることになる．もし基準を実行可能集合の中の分布に取り替えても**この読み替えが生き延びるなら**，隔たりが 0 になる点（基準そのもの）がそのまま最大化子になり，問題は「基準をどう選ぶか」に移る．どんな分布ならそれが本当に言えるのかが 10.2 節の主題であり，命題 10.1.2 はその特別な場合，制約が空で基準が一様分布である場合にあたる．

## 解きたい問題

::: example 10.1.4 平均の分かったサイコロ
$\mathcal X = \{1, 2, 3, 4, 5, 6\}$，$k = 1$，$f_1(x) = x$，$c_1 = 4.5$ とする．すなわち「目の平均が $4.5$ である」という制約を 1 つだけ課す．このとき実行可能集合は空ではなく，一様分布を含まない．さらに実行可能な分布 $P$ はすべて $H(P) < \log 6$ を満たす．
:::

::: proof
目 $4$ と目 $5$ に確率 $1/2$ ずつを置いた分布は平均が $4.5$ だから，実行可能集合は空でない．いっぽう一様分布の平均は $(1 + 2 + \dots + 6)/6 = 3.5$ で $4.5$ と異なるので，一様分布は実行可能でない．最後に $P$ を実行可能な分布とすると，定理 1.1.5 より$H(P) \le \log 6$ であり，その等号が成り立つのは $P$ が一様分布のときに限る．$P$ は一様分布ではないので，不等号は狭義である．
:::

::: formalization-note
例 10.1.4 に対応する宣言は形式化されていない．本節の計算がその保証のすべてである．
:::

制約が実際に効いていることが，この二つの事実に出ている．どの実行可能な分布も$\log 6 \approx 1.792$ ナット（$\approx 2.585$ ビット）には届かない．では実際にどこまで行けるのか．つまり，上限が真に下がっているのか，下がるとしてどこまでか．実行可能集合は無限個の分布を含むので，しらみつぶしにはできない．10.2 節がこの問いに閉じた答えを与える．
