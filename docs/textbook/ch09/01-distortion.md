# 9.1 歪みとレート歪み関数

第2章と第3章は，情報源の出した列をそのまま復元できることを求めて，どこまで短く書けるかを問うた．その限界がエントロピーだった．ところが実際に圧縮したいものの多くは，そのまま復元しなくてよい．写真を保存するとき，隣り合う画素の値がもとの値から少しずれても，見る側は同じ写真として受け取る．音声も同じで，人の耳に届かない差は落としてよい．実数値をとる量にいたっては，有限個の符号語のどれかに割り当てる時点で，どこかで値を丸めることになる．そこで本章が問うのは，どれだけの誤りを許せばレートをどこまで下げられるか，である．

許す誤りの量は，情報源の文字と，その代わりに出す文字との組に数を与えて測る．この数を歪みと呼び，歪みの平均を $D$ 以下に抑えるという条件のもとでレートの限界を与える量として，本章はレート歪み関数 $R(D)$ を立てる．進め方は第8章と同じ二段構えにする．本節で $R(D)$ を最適化問題の値として定義し，9.2 節から 9.4 節でその性質と具体例を調べ，そのうえで，それが符号についての限界でもあることを 9.5 節と 9.6 節で確かめる．

本章では $\log$ の底を $2$ にとる．符号語の個数を $2$ の何乗として数える段（9.5 節と 9.6 節）で，指数と対数の底がそろっていると式が読みやすい．記号も一つ断っておく．本章の裸の $D$ はつねに許す歪みの上限を指し，第4章 4.1 節が符号アルファベットの大きさに使う裸の $D$ とも，第1章の相対エントロピー $D(p\,\|\,q)$ とも別である．

::: formalization-note 本章共通
単位は本文と形式化で違う．形式化は $\log$ を自然対数にとるので，相互情報量もレート歪み関数もナットが単位である．本文が符号語の個数を $2$ の何乗として数えるところは，あちらでは $e$ の何乗として数えることになる．底をそろえれば同じ主張である．
:::

## 歪み尺度

::: definition 9.1.1 歪み尺度
$\mathcal X$ と $\hat{\mathcal X}$ を空でない有限集合とする．**歪み尺度** とは，写像
$$
d : \mathcal X \times \hat{\mathcal X} \longrightarrow [0,\infty)
$$
のことをいう．$\mathcal X$ を **情報源アルファベット**，$\hat{\mathcal X}$ を **再現アルファベット** と呼び，$d(x,\hat x)$ を，情報源の文字 $x$ の代わりに $\hat x$ を出したときに払う **歪み** と呼ぶ．
:::

歪み尺度は「どれだけ間違えたか」を数で決める約束である．何を損とみなすかは扱う対象で違うので，本書はその決め方に立ち入らず，決まったものとして受け取る．値が小さいほどよい再現で，$0$ は損がないことを表す．$D$ 以下に抑える，という本章の条件は，この数の平均についての条件である．

**距離ではない.** 定義 9.1.1 が課しているのは非負であることだけで，対称性も三角不等式も課していない．そもそも二つのアルファベットは違ってよいので，$d(x,\hat x)$ と並べて $d(\hat x, x)$ を書けるとは限らない．白を黒と読むときの損と，黒を白と読むときの損が等しいことも，定義 9.1.1 は要求しない．

::: formalized
`DistortionFn` (`InformationTheory/Shannon/RateDistortion/Achievability.lean`)
:::

::: formalization-note
形式化の `DistortionFn` は歪みの値を非負の実数の型にとる．定義 9.1.1 が値域を $[0,\infty)$ と書いたのと同じことで，非負性が型から出る．
:::

情報源は $1$ 文字ずつではなく，長さ $n$ のブロックにまとめて扱う．ブロックの歪みは，成分ごとの歪みを平均して定める．

::: definition 9.1.2 ブロックの歪み
$\mathcal X$，$\hat{\mathcal X}$，$d$ を定義 9.1.1 のとおりとし，$n \ge 1$ とする．列 $x^n = (x_0,\dots,x_{n-1}) \in \mathcal X^n$ と $\hat x^n = (\hat x_0,\dots,\hat x_{n-1}) \in \hat{\mathcal X}^n$ に対して，**ブロックの歪み** を
$$
d\big(x^n, \hat x^n\big) \;:=\; \frac1n \sum_{i=0}^{n-1} d\big(x_i, \hat x_i\big)
$$
で定める．
:::

足すのではなく平均するのは，$1$ 文字あたりの歪みで測るためである．そうしておくと，ブロックの長さを変えても値の大きさがそろい，$n$ を大きくする議論に乗る．$1$ 文字の歪みとブロックの歪みに同じ記号 $d$ を使うが，引数が文字の対か列の対かで見分けられる．

`blockDistortion` (`InformationTheory/Shannon/RateDistortion/Achievability.lean`)
:::

::: example 9.1.3 Hamming 歪み
$\mathcal X$ を空でない有限集合とし，$\hat{\mathcal X} = \mathcal X$ として
$$
d_H(x,\hat x) \;:=\; \begin{cases} 0 & (\hat x = x) \\ 1 & (\hat x \ne x) \end{cases}
$$
と定める．この $d_H$ は歪み尺度（定義 9.1.1）であり，$n \ge 1$ と $x^n, \hat x^n \in \mathcal X^n$ に対して，そのブロックの歪み（定義 9.1.2）は成分が食い違う位置の割合
$$
d_H\big(x^n,\hat x^n\big) \;=\; \frac1n\,\#\big\{\, i \in \{0,\dots,n-1\} \;:\; \hat x_i \ne x_i \,\big\}
$$
に等しい．さらに $X^n = (X_0,\dots,X_{n-1})$ と $\hat X^n = (\hat X_0,\dots,\hat X_{n-1})$ を $\mathcal X^n$ に値をとる確率変数の組とすると
$$
\mathbb E\big[d_H\big(X^n,\hat X^n\big)\big] \;=\; \frac1n\sum_{i=0}^{n-1}\Pr\big[\hat X_i \ne X_i\big]
$$
である．
:::

::: proof
$d_H$ の値は $0$ と $1$ だけなので $[0,\infty)$ に入り，$d_H$ は歪み尺度である．定義 9.1.2 の和 $\sum_i d_H(x_i,\hat x_i)$ は，$\hat x_i \ne x_i$ である $i$ ごとに $1$ を，そうでない $i$ には $0$ を足したものだから，食い違う位置の個数に等しい．これを $n$ で割ったものが第 $1$ の等式である．

期待値に移る．$d_H(X_i,\hat X_i)$ は事象 $\{\hat X_i \ne X_i\}$ の指示変数だから，その期待値は $\Pr[\hat X_i \ne X_i]$ である．第 $1$ の等式の右辺は $n$ 個の指示変数の平均なので，期待値の線形性から第 $2$ の等式を得る．
:::

Hamming 歪みは，一致したか否かだけを見る歪み尺度である．例 9.1.3 の第 $2$ の式が数えているのは成分ごとの食い違いであって，ブロック全体の一致ではない．第2章 定義 2.3.1 の誤り確率はブロック全体が一致しない確率で，別の量である．Hamming 歪みを小さくするとは，食い違う文字の割合を小さくすることであって，ブロックをそのまま当てることではない．

::: formalization-note
Hamming 歪みにあたる宣言は無い．形式化には，歪み尺度を具体的に取った実例が一つも置かれていない．例 9.1.3 に付した証明が，この主張の保証のすべてである．
:::

::: example 9.1.4 $2$ 乗歪み
$\mathcal X = \hat{\mathcal X} = \mathbb R$ とし，$d(x,\hat x) := (x - \hat x)^2$ と定める．この $d$ は非負の値をとり，定義 9.1.2 の式をそのまま当てると，ブロックの歪みは平均 $2$ 乗誤差 $\frac1n\sum_{i=0}^{n-1}(x_i - \hat x_i)^2$ になる．
:::

$\mathbb R$ は有限集合ではないので，例 9.1.4 は定義 9.1.1 の枠の外にある．本節から 9.3 節までの定義と主張は有限のアルファベットについて述べるので，$2$ 乗歪みで測る情報源は 9.4 節で別に扱う．

## レート歪み関数

歪み尺度が決まると，再現の良し悪しは数で比べられるようになる．次に決めたいのは，歪みを $D$ 以下に抑えるのに，情報源についてどれだけのことを知る必要があるか，である．必要な量を測る物差しとして，本章は相互情報量をとる．情報源 $X$ と，その再現 $\hat X$ を対にして見たとき，$I(X;\hat X)$ は二つがどれだけ強く結びついているかを測る量だった（1.3 節）．再現が情報源と独立なら $I(X;\hat X) = 0$ であり，値が大きいほど強く結びついている（命題 1.3.2）．歪みを $D$ 以下に抑えるという条件を満たす再現の作り方のうち，いちばん弱い結びつきで済むものを探して，その結びつきの強さを $R(D)$ と定める，というのが次の定義である．

::: definition 9.1.5 レート歪み関数
$\mathcal X$ と $\hat{\mathcal X}$ を空でない有限集合，$p$ を $\mathcal X$ 上の分布，$d$ を歪み尺度（定義 9.1.1），$D$ を実数とする．**条件付き分布** とは，各 $x \in \mathcal X$ と各 $\hat x \in \hat{\mathcal X}$ に非負の実数 $q(\hat x \mid x)$ を与える組であって，各 $x$ について $\sum_{\hat x \in \hat{\mathcal X}} q(\hat x\mid x) = 1$ を満たすもののことをいう．条件付き分布 $q$ に対し，$(X,\hat X)$ を同時分布が $p(x)\,q(\hat x\mid x)$ で与えられる対とし，その相互情報量（定義 1.3.1）を $I(p;q)$ と書き，その **期待歪み** を
$$
\mathbb E\big[d(X,\hat X)\big] \;=\; \sum_{x \in \mathcal X}\ \sum_{\hat x \in \hat{\mathcal X}} p(x)\,q(\hat x\mid x)\,d(x,\hat x)
$$
と書く．期待歪みが $D$ 以下である条件付き分布の全体を $\mathcal Q(D)$ と書く．$\mathcal Q(D)$ が空でないとき，**レート歪み関数** の値を
$$
R(D) \;:=\; \inf_{q \in \mathcal Q(D)} I(p;q)
$$
で定める．
:::

定義 9.1.5 が動かしているのは $q$ だけである．情報源の分布 $p$ と歪み尺度 $d$ は与えられていて動かせない．$q(\hat x\mid x)$ は「情報源が $x$ を出したときに再現として $\hat x$ を出す確率」であり，$\sum_{x,\hat x}p(x)q(\hat x\mid x) = \sum_x p(x) = 1$ だから，$p(x)q(\hat x\mid x)$ は確かに $\mathcal X\times\hat{\mathcal X}$ 上の分布である．期待歪みは，その分布のもとで $d$ を平均したものにほかならない．制約集合 $\mathcal Q(D)$ は「平均して $D$ 以下の歪みしか出さない再現の作り方」の全体で，$R(D)$ はその中で情報源と再現の結びつきをいちばん弱くしたときの，結びつきの強さである．記号 $I(p;q)$ は第6章 定義 6.1.2 の $I(p;W)$ にならった．あちらが通信路を置いた位置に，こちらは再現の作り方 $q$ を置く．$q$ を決めるごとに対 $(X,\hat X)$ が定まるので，$I(p;q)$ は $q$ の関数である．

なぜ最小にする量が相互情報量なのか，見当だけ先に書いておく．歪みを許さない第2章では，再現は $X$ そのものであり，そのときの結びつきの強さは $I(X;X) = H(X)$ である（1.3 節）．第2章が要したレートもちょうど $H(X)$ だった（定理 2.3.6）．再現を $X$ からずらすことを許したとき，同じ量が $I(X;\hat X)$ になる．勘定の形も第2章と変わらない．情報源のブロックはほぼ確実に典型集合（定義 2.2.1）に落ち，その元の個数は $2^{nH(X)}$ をわずかに上回るところまでで抑えられた（定理 2.2.5）．歪みを許すなら，一つの番号に一つの系列を対応させるのではなく，一本の再現の列に，そこから歪みの小さい情報源の列をまとめて引き受けさせればよい．一本が引き受けられる個数をおよそ $2^{nH(X\mid\hat X)}$ と読めば，覆うのに要る本数はその比 $2^{n\,I(X;\hat X)}$ ほどになる（指数の差が相互情報量になるのは定理 1.3.4 による）．本数を少なくしたければ $I(X;\hat X)$ を小さくすればよく，歪みの制約のもとでいちばん小さくした値が $R(D)$ にほかならない．本書はこの勘定を主張としては述べない．「$\hat x^n$ を知ったあとの典型な列」にあたる集合を，本書は用意していないからである．9.6 節でこの勘定にもう一度戻る．

ここまでは見当であって，符号の話は一つも入っていない．いまのところ $R(D)$ は最適化問題の値でしかなく，第6章 定義 6.1.4 の通信路容量と同じ立場にある．したがって「歪みを $D$ 以下に抑えるには $1$ 文字あたり $R(D)$ ビットで済む」と言う資格は，9.4 節までの段階ではない．その資格を与えるのが 9.5 節と 9.6 節で，前者は歪みを $D$ 以下に抑える符号のレートが $R(D)$ を下回れないこと，後者は $R(D)$ より大きいレートをとれば，歪みを $D$ に望むだけ近いところまで抑える符号が作れることを示す．

$D$ を小さくとりすぎると $\mathcal Q(D)$ は空になり，$R(D)$ は定まらない．どこから空でなくなるかは，歪み尺度と情報源で決まる．各 $x$ に対していちばん歪みの小さい $\hat x$ を決め打ちして出す再現を考えると，その期待歪みは $\sum_{x \in \mathcal X}p(x)\min_{\hat x \in \hat{\mathcal X}}d(x,\hat x)$ になる．どの条件付き分布の期待歪みもこの値以上だから，$\mathcal Q(D)$ が空でないのは，ちょうど $D$ がこの値以上のときである．そこで本章の主張は，どれも $\mathcal Q(D)$ が空でないことを仮定に置く．9.2 節は，$D = 0$ での値と，$R(D)$ が $0$ になる歪みの両方を扱う．

## 下限は最小値である

定義 9.1.5 は $R(D)$ を下限として定めたが，実際には最小値である．示すには，制約集合が有界閉集合であることと，その上で $I(p;\cdot)$ が連続であることの二つが要る．前者は制約の書き方から出る．後者は，一次結合・合成・有限和が連続性を保つという微積分の計算規則（これは既知とする）と，1.1 節で認めた $\varphi(t) = -t\log t$ の $[0,\infty)$ 上の連続性から組み立てる．そのうえで，最大値の存在を引き出すために次の一つを証明せずに借りる．

**Weierstrass の最大値定理を借りる.** 借りるのは「有限次元の実ベクトル空間の有界閉集合の上の実数値連続関数は最大値をとる」という形である．当てる相手は，実ベクトル空間 $\mathbb R^{\mathcal X\times\hat{\mathcal X}}$ の部分集合である制約集合 $\mathcal Q(D)$（定義 9.1.5）の上の，実数値関数 $q \mapsto -I(p;q)$ である．この借用に依存するのは命題 9.1.6 だけで，以降の節は命題 9.1.6 の結論だけを使う．第6章 6.1 節が通信路容量の達成（定理 6.1.5）のために借りたのと同じ定理である．本書はこの最大値定理を証明しないが，形式化されていないわけではない．命題 9.1.6 の形式化は，Mathlib にある無条件の機械検証済みのこの定理をそのまま呼び出しているからである．

::: proposition 9.1.6
$\mathcal X$ と $\hat{\mathcal X}$ を空でない有限集合，$p$ を $\mathcal X$ 上の分布，$d$ を歪み尺度（定義 9.1.1），$D$ を実数とし，$\mathcal Q(D)$，$I(p;\cdot)$，$R(D)$ を定義 9.1.5 のとおりとする．$\mathcal Q(D)$ が空でないならば，$I(p;\cdot)$ を $\mathcal Q(D)$ の上で最小にする $q^* \in \mathcal Q(D)$ が存在し，$R(D) = I(p;q^*)$ である．
:::

::: proof
$\mathcal Q(D)$ の元は各 $(x,\hat x)$ に実数を割り当てる組だから，$\mathcal Q(D)$ は実ベクトル空間 $\mathbb R^{\mathcal X\times\hat{\mathcal X}}$ の部分集合である．これが有界閉集合であることを見る．各成分の非負性と，各 $x$ についての $\sum_{\hat x}q(\hat x\mid x) = 1$ から $0 \le q(\hat x\mid x) \le 1$ なので有界である．$\mathcal Q(D)$ を定める三つの条件（各成分が非負であること，各 $x$ について和が $1$ であること，期待歪みが $D$ 以下であること）は，どれも $q$ の成分の一次式についての等式と不等式だから，$\mathcal Q(D)$ は閉である．

$q \mapsto I(p;q)$ が $\mathcal Q(D)$ の上で連続であることを見る．$q$ に対応する対 $(X,\hat X)$ の同時分布は $p(x)q(\hat x\mid x)$，第 $1$ 周辺分布は $p$，第 $2$ 周辺分布は $\hat x \mapsto \sum_x p(x)q(\hat x\mid x)$ である．これに定理 1.3.4 を当てると $I(p;q) = H(X) + H(\hat X) - H(X,\hat X)$ であり，定義 1.1.1 と定義 1.2.1 により三つの項は
$$
H(X) = \sum_{x}\varphi\big(p(x)\big), \qquad
H(\hat X) = \sum_{\hat x}\varphi\Big(\sum_{x} p(x)\,q(\hat x\mid x)\Big), \qquad
H(X,\hat X) = \sum_{x,\hat x}\varphi\big(p(x)\,q(\hat x\mid x)\big)
$$
と書ける（$\varphi(t) = -t\log t$ は 1.1 節の記号である）．第 $1$ 項は $q$ を含まない定数であり，残る二つはどちらも，$q$ の成分の一次結合に $\varphi$ を合成したものの有限和である．既知とした計算規則と，1.1 節で認めた $\varphi$ の連続性により，$q\mapsto I(p;q)$ は $\mathcal Q(D)$ の上で連続である．

最小値の存在に移る．$-I(p;\cdot)$ も同じ理由で $\mathcal Q(D)$ の上で連続だから，空でない有界閉集合の上のこの関数に，借りた Weierstrass の最大値定理を当てると，最大値を与える点 $q^*$ が存在する．そこで $I(p;\cdot)$ は最小値をとる．

最後に $R(D) = I(p;q^*)$ を見る．$I(p;q^*)$ は値の集合 $\{I(p;q) : q \in \mathcal Q(D)\}$ の下界であり，かつその集合の元でもある．下限は下界のうち最大のものだから，この二つから $R(D) = I(p;q^*)$ である．
:::

`rateDistortionFunctionPmf_attained` が与えるのは，制約集合の上で最小を与える点が存在するところまでで，$R(D)$ がその点での値に等しいという命題 9.1.6 の後半に対応する単独の宣言は無い．後半は，最小を与える点の存在（`rateDistortionFunctionPmf_attained`）と，$R(D)$ が値の集合の下限として定義されていること（`rateDistortionFunctionPmf` (`InformationTheory/Shannon/RateDistortion/Achievability.lean`)）との合成で得られる．また，あちらが動かすのは条件付き分布ではなく，情報源の分布を第 $1$ 周辺にもつ同時分布であり，最小にする量も定義 1.3.1 の相互情報量とは別に立てた宣言である．証明の筋は本文と同じで，制約集合がコンパクトであることと，最小にする量が連続であることを組み合わせている．
:::

命題 9.1.6 により，以降は $R(D)$ を最小値として扱ってよい．$D$ ごとに最小を与える条件付き分布 $q^*$ が一つとれる，ということでもある．どの $q^*$ がとれるかは $D$ によって違い，$D$ を動かしたときに $R(D)$ の値がどう動くかが次節の主題である．
