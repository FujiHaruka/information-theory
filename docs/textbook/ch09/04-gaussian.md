# 9.4 ガウス情報源と逆注水

本節は，本章がここまで置いてきた有限アルファベットの約束の外に出る．9.1 節は情報源アルファベットも再現アルファベットも空でない有限集合としたが，実数値をとる情報源はその枠に入らない．例 9.1.4 の $2$ 乗歪みが枠の外にあるのと同じ理由である．そこで本節は，実数値の情報源についてレート歪み関数を定義し直す．置き換えるものは第7章がすでに用意している．有限アルファベットのエントロピーの代わりに微分エントロピー（定義 7.1.2）を，定義 1.3.1 の相互情報量の代わりに密度で書いた相互情報量（定義 7.5.4）を使えばよい．最小にする量も制約の形も，定義 9.1.5 とそのままの対応がつく．

先に断っておくことが一つある．9.5 節と 9.6 節が示す符号化定理は，どちらも有限アルファベットの情報源についてのものである．本節で定める量が符号のレートの限界でもあることを，本書は示さない．したがって本節の値は，第8章 8.2 節の $C(P,N)$ と同じく，最適化問題の値としてだけ読むことになる．

## ガウス情報源のレート歪み関数

::: definition 9.4.1 ガウス情報源のレート歪み関数
$\sigma^2 > 0$，$D > 0$ とする．実数値確率変数の対 $(X,\hat X)$ が **歪み $D$ の再現の対** であるとは，$X$ が $\mathcal N(0,\sigma^2)$（定義 7.2.1）に従い，次の四つが成り立つことをいう．

1. $\hat X$ は密度をもち，$h(\hat X)$ が定まる（定義 7.1.2）．
2. 対 $(X,\hat X)$ は結合密度をもち（定義 7.1.1），$h(X,\hat X)$ が定まる．
3. $X - \hat X$ は密度をもち，$h(X-\hat X)$ が定まり，平均をもつ．
4. $\mathbb E\big[(X-\hat X)^2\big]$ が定まって $D$ 以下である．

歪み $D$ の再現の対の全体を $\mathcal Q_{\mathcal N}(D)$ と書く．$\mathcal Q_{\mathcal N}(D)$ が空でないとき，**分散 $\sigma^2$ のガウス情報源のレート歪み関数** の値を
$$
R_{\mathcal N}(D) \;:=\; \inf_{(X,\hat X)\,\in\,\mathcal Q_{\mathcal N}(D)} I(X;\hat X)
$$
で定める（$I$ は定義 7.5.4 の相互情報量である）．
:::

定義 9.1.5 との対応は素直である．あちらが動かしたのは条件付き分布 $q$ で，情報源の分布 $p$ のほうは固定されていた．こちらが動かすのは対 $(X,\hat X)$ で，第 $1$ 成分の分布が $\mathcal N(0,\sigma^2)$ に固定されている．あちらの期待歪みにあたるのが第 $4$ の条件で，あちらの制約集合 $\mathcal Q(D)$ にあたるのが $\mathcal Q_{\mathcal N}(D)$ である．違うのは第 $1$ から第 $3$ の条件で，これは量が定まるようにするための技術的な絞り込みである．定理 7.2.2 より $h(X)$ は定まるから，第 $1$ と第 $2$ の条件を合わせると定理 7.5.6 の仮定が満たされ，$\mathcal Q_{\mathcal N}(D)$ のどの元についても $I(X;\hat X)$ は定まって，その値は $h(X) + h(\hat X) - h(X,\hat X)$ に等しい．第 $3$ の条件は，下界の証明で $X-\hat X$ に定理 7.2.4 を当てるために要る．密度をもたない再現のほうが少ないレートで済むかどうかを，この定義が否定しているのではない．第8章 定義 8.2.1 が上限をとる範囲を絞ったのと同じ事情である．

::: formalization-note
定義 9.4.1 に対応する宣言はない．レート歪み関数を測度の言葉で書いた宣言 `rateDistortionFunction` (`InformationTheory/Shannon/RateDistortion/Converse.lean`) はアルファベットを有限に限らないので，実数値の情報源に対しても値を返す．ただしそれが動かすのは，情報源の分布を第 $1$ 周辺にもち期待歪みが $D$ 以下であるすべての同時分布であって，定義 9.4.1 のように結合密度をもつものに絞られていない．動かす範囲が違うので，二つの値が一致するかどうかを述べる宣言もない．レート歪み関数についてのそのほかの宣言のうち，符号を扱う逆定理と達成可能性の一連の宣言は，どれもアルファベットが有限であることを前提にしていて，実数値の情報源には当てられない．一方，非増加性（命題 9.2.1 に紐付けた宣言）と凸性（命題 9.2.3 に紐付けた宣言），および相互情報量で上から抑える `rateDistortionFunction_le_mutualInfo_perLetter` (`InformationTheory/Shannon/RateDistortion/ConverseNLetter.lean`) はアルファベットを有限に限らないので，実数値の情報源にも当たる．ただし凸性の宣言だけは，情報源の分布を第 $1$ 周辺にもつどの同時分布についても歪みが可積分である，という前提を受け取る．有限のアルファベットではこの前提が自動で満たされるのに対し，実数値の情報源では別に確かめることになる．そしてどれも `rateDistortionFunction` についての主張なので，動かす範囲が定義 9.4.1 と違うことは変わらない．
:::

道具を二つ借りる．どちらも既出の章が借りたものを，確率変数の言葉で引き直すだけである．一つめは第7章 7.2 節が借りた **ガウス分布の基本性質**，すなわち $\mathcal N(\mu,\sigma^2)$（定義 7.2.1）に従う実数値確率変数の平均が $\mu$，分散が $\sigma^2$ であることで，$2$ 乗の平均が $\mu^2+\sigma^2$ であることはここから出る．二つめは第8章 8.1 節が借りた **ガウス分布の畳み込み**，すなわち独立で $\mathcal N(\mu_1,\sigma_1^2)$ と $\mathcal N(\mu_2,\sigma_2^2)$ に従う二つの実数値確率変数の和が $\mathcal N(\mu_1+\mu_2,\ \sigma_1^2+\sigma_2^2)$ に従うことである．あちらは密度の形で述べたが，こちらは確率変数の形で使い，しかも差についても同じこと，すなわち差が $\mathcal N(\mu_1-\mu_2,\ \sigma_1^2+\sigma_2^2)$ に従うことをあわせて借りる．当てる対象はどちらも本節に現れるガウス分布に従う実数値確率変数だけで，依存するのは，順向きに作った対の相互情報量を求めるところと，命題 9.4.4 と命題 9.4.6 の証明である．

## 差への置き換え

下界の証明は，情報源と再現の対 $(X,\hat X)$ を，再現と食い違い $X-\hat X$ の対に取り替えるところから始まる．9.3 節が二値の場合に食い違いを表す確率変数を置いたのと同じ手である．取り替えても結合微分エントロピーが変わらないことを，先に見ておく．変わらない理由は絵で言える．この取り替えは平面のせん断であって面積を変えないので，密度の値の並び方もそのままだからである．ただし第 $1$ 成分に第 $2$ 成分が混じるので，第7章 7.3 節が借りた成分ごとの置換積分には含まれない．そこで一つ借りる．

**平面の差への置き換えを借りる.** 借りるのは二つの形である．一つめは置換積分で，$\mathbb R^2$ 上の実数値関数 $u$ について
$$
\int_{\mathbb R^2} u(x,\hat x)\,dx\,d\hat x \;=\; \int_{\mathbb R^2} u(w+\hat x,\ \hat x)\,dw\,d\hat x
$$
であり，一方が絶対収束すればもう一方も絶対収束する．二つめは密度の側の対応で，$(X,\hat X)$ が結合密度 $F$（定義 7.1.1）をもつならば $(X-\hat X,\ \hat X)$ は結合密度をもってその一つが $(w,\hat x)\mapsto F(w+\hat x,\ \hat x)$ であり，逆に $(V,\hat X)$ が結合密度 $G$ をもつならば $(V+\hat X,\ \hat X)$ は結合密度をもってその一つが $(x,\hat x)\mapsto G(x-\hat x,\ \hat x)$ である，という形である．当てる対象は，本節に現れる $\mathbb R^2$ 上の結合密度と，それに対数を掛けた関数だけであり，依存するのは補題 9.4.2 の証明だけである．密度の側もあわせて借りるのは，この置き換えが直方体を直方体に送らないので，定義 7.1.1 が直方体の確率で密度を定めたやり方からはそのまま読み取れないからである．本書はこの二つを証明しない．一つめの置換積分は，平面の測度を変えない写像であるという形で，Mathlib に無条件の機械検証済みの定理として置かれている．二つめの密度の側は，同じ主張を述べた単独の宣言が，結論の形で探しても見つからない．

::: lemma 9.4.2 差への置き換えでの結合微分エントロピーの不変性
$X$ と $\hat X$ を実数値確率変数とする．対 $(X,\hat X)$ が結合密度をもつことと，対 $(X-\hat X,\ \hat X)$ が結合密度をもつこととは同値である．そのとき，$h(X,\hat X)$ が定まることと $h(X-\hat X,\ \hat X)$ が定まることとは同値であり，定まるならば
$$
h\big(X-\hat X,\ \hat X\big) \;=\; h\big(X,\hat X\big)
$$
である．
:::

::: proof
$(X,\hat X)$ が結合密度 $F$ をもつとすると，借りた差への置き換えの密度の側より $(X-\hat X,\ \hat X)$ は結合密度をもち，その一つは $F_{*}(w,\hat x) := F(w+\hat x,\ \hat x)$ である．逆に $(X-\hat X,\ \hat X)$ が結合密度をもつとすると，$V := X-\hat X$ とおけば $V+\hat X = X$ だから，同じ借用の後半より $(X,\hat X)$ は結合密度をもつ．これで第 $1$ の同値を得る．

以下 $F$ と $F_{*}$ を上のとおりとする．借りた差への置き換えの置換積分を $u(x,\hat x) := \lvert F(x,\hat x)\log F(x,\hat x)\rvert$ に当てると
$$
\int_{\mathbb R^2}\big\lvert F_{*}(w,\hat x)\log F_{*}(w,\hat x)\big\rvert\,dw\,d\hat x
  \;=\; \int_{\mathbb R^2}\big\lvert F(x,\hat x)\log F(x,\hat x)\big\rvert\,dx\,d\hat x
$$
である．よって一方が有限であることと他方が有限であることとは同値で，定義 7.1.2 により，$h(X,\hat X)$ が定まることと $h(X-\hat X,\ \hat X)$ が定まることとは同値である．定まるとき，同じ差への置き換えの置換積分を $u := F\log F$ に当てれば符号を付けた積分も等しく，定義 7.1.2 より二つの結合微分エントロピーは等しい．
:::

::: formalization-note
補題 9.4.2 にあたる宣言は無い．平面のせん断で結合微分エントロピーが変わらないことを述べた宣言は形式化に無く，結論の形で探しても見つからない．補題 9.4.2 に付した証明が，この主張の保証のすべてである．
:::

## 下界

::: theorem 9.4.3 ガウス情報源についての相互情報量の下界
$\sigma^2>0$，$D>0$ とし，$\mathcal Q_{\mathcal N}(\cdot)$ を定義 9.4.1 のとおりとする．$(X,\hat X) \in \mathcal Q_{\mathcal N}(D)$ ならば
$$
I(X;\hat X) \;\ge\; \tfrac12\log\frac{\sigma^2}{D}
$$
である．
:::

::: proof
$V := X-\hat X$ とおく．定義 9.4.1 の第 $2$ の条件と補題 9.4.2 より，$(V,\hat X)$ は結合密度をもち，$h(V,\hat X)$ は定まって $h(X,\hat X)$ に等しい．

対 $(V,\hat X)$ に劣加法性を当てる．定義 9.4.1 の第 $3$ の条件より $h(V)$ が定まり，第 $1$ の条件より $h(\hat X)$ が定まり，いま見たとおり $h(V,\hat X)$ も定まるから，定理 7.4.3 を $2$ 個の確率変数の組に当てると
$$
h\big(X,\hat X\big) \;=\; h\big(V,\hat X\big) \;\le\; h(V) + h(\hat X)
$$
である．

$h(V)$ を上から抑える．定義 9.4.1 の第 $3$ の条件より $V$ は密度をもち，$h(V)$ は定まり，平均をもつ．その分散は $\mathbb E[V^2] - \mathbb E[V]^2$ で $\mathbb E[V^2]$ 以下であり，第 $4$ の条件よりこれは $D$ 以下である．$D>0$ だから，定理 7.2.4 をその主張の $\sigma^2$ を $D$ ととって当てて $h(V) \le \frac12\log(2\pi e D)$ である．

相互情報量に直す．定理 7.2.2 より $h(X)$ は定まって $\frac12\log(2\pi e\sigma^2)$ であり，定義 9.4.1 の第 $1$ と第 $2$ の条件と合わせて定理 7.5.6 の仮定が満たされるから
$$
I(X;\hat X) \;=\; h(X) + h(\hat X) - h\big(X,\hat X\big)
  \;\ge\; h(X) + h(\hat X) - h(V) - h(\hat X) \;=\; h(X) - h(V)
$$
である．よって
$$
I(X;\hat X) \;\ge\; \tfrac12\log\big(2\pi e\sigma^2\big) - \tfrac12\log\big(2\pi e D\big) \;=\; \tfrac12\log\frac{\sigma^2}{D}
$$
を得る．
:::

::: formalization-note
定理 9.4.3 にあたる宣言は無い．ガウス情報源についてこの下界を述べた宣言は形式化に無く，結論の形で探しても見つからない．定理 9.4.3 に付した証明が，この主張の保証のすべてである．
:::

証明で歪みの制約が効いたのは一か所だけで，食い違い $X-\hat X$ の分散を $D$ で抑えるところである．散らばりを抑えられた分布の微分エントロピーには上限があり（定理 7.2.4），その上限が $\frac12\log(2\pi eD)$ である．9.3 節の二値の情報源では「食い違いの不確かさは $H_b(D)$ を超えない」という段だったところが，そのまま「$\frac12\log(2\pi eD)$ を超えない」に置き換わっている．差し引かれる相手が情報源だけで決まる定数 $h(X)$ であることも，9.3 節で $H(X) = H_b(\pi)$ が条件付き分布によらなかったのと同じである．

## 逆向きの構成と達成

順向きに作るとどうなるかを，先に見ておく．情報源 $X$ に，$X$ と独立で $\mathcal N(0,D)$ に従う雑音 $V$ を足して $\hat X := X+V$ とするのが，いちばん素直な作り方である．食い違い $X-\hat X$ は $-V$ だから，借りたガウス分布の基本性質より $\mathbb E[(X-\hat X)^2] = \mathbb E[V^2] = D$ で，歪みは目標どおりちょうど $D$ になる．借りたガウス分布の畳み込みより $\hat X$ は $\mathcal N(0,\sigma^2+D)$ に従う．補題 9.4.2 を，第 $1$ 成分に $\hat X$，第 $2$ 成分に $X$ を置いて当てると $h(\hat X,X) = h(\hat X-X,\ X) = h(V,X)$ であり，$V$ と $X$ は独立だから系 7.4.4 よりこれは $h(V)+h(X)$ に等しい．そこで定理 7.5.6 を対 $(\hat X,X)$ に当て，定理 7.2.2 で微分エントロピーの値を入れると
$$
I(\hat X;X) \;=\; h(\hat X)+h(X)-h\big(\hat X,X\big) \;=\; h(\hat X)-h(V)
  \;=\; \tfrac12\log\frac{\sigma^2+D}{D} \;=\; \tfrac12\log\Big(1+\frac{\sigma^2}{D}\Big)
$$
となる．定義 7.5.4 は二つの確率変数を同じ形で扱っていて，値は二つの積分変数を入れ替えても変わらないので，これが $I(X;\hat X)$ でもある．歪みは同じ $D$ でありながら，$1+\sigma^2/D$ は $\sigma^2/D$ より大きいから，補題 8.2.5 よりこの値は定理 9.4.3 の下界 $\frac12\log(\sigma^2/D)$ より大きい．順向きに作ると損をする，ということである．

達成の側も 9.3 節と同じ形になる．定理 9.4.3 の証明で不等号が入ったのは，定理 7.4.3 の劣加法性を当てたところと，定理 7.2.4 で食い違いの微分エントロピーを抑えたところである．前者は，食い違いが再現と独立であれば等号になる（系 7.4.4）．後者は，食い違いが分散 $D$ のガウス分布に従えば等号になる（系 7.2.5）．どちらの条件も，再現 $\hat X$ を先に置き，そこに $\mathcal N(0,D)$ に従う雑音を独立に足して情報源 $X$ を作れば，作った時点で満たされる．残るのは，こうしてできた $X$ の分布が $\mathcal N(0,\sigma^2)$ になるように，$\hat X$ の分散を選ぶことだけである．

::: proposition 9.4.4 下界を達成する対
$\sigma^2>0$，$0<D<\sigma^2$ とする．$\hat X$ と $V$ を独立な実数値確率変数で，$\hat X$ が $\mathcal N(0,\ \sigma^2-D)$ に，$V$ が $\mathcal N(0,D)$ に従うもの（定義 7.2.1）とし，$X := \hat X + V$ とおく．このとき $X$ は $\mathcal N(0,\sigma^2)$ に従い，対 $(X,\hat X)$ は $\mathcal Q_{\mathcal N}(D)$ に属し（$\mathcal Q_{\mathcal N}(\cdot)$ は定義 9.4.1 のとおり），$\mathbb E[(X-\hat X)^2] = D$ かつ
$$
I(X;\hat X) \;=\; \tfrac12\log\frac{\sigma^2}{D}
$$
である．
:::

::: proof
$0<D<\sigma^2$ より $\sigma^2-D>0$ だから，$\mathcal N(0,\sigma^2-D)$ は定義 7.2.1 の意味で定まる．借りたガウス分布の畳み込みより，$X = \hat X + V$ は $\mathcal N(0,\ (\sigma^2-D)+D)$，すなわち $\mathcal N(0,\sigma^2)$ に従う．

定理 7.2.2 より $h(\hat X)$，$h(V)$，$h(X)$ はどれも定まって
$$
h(\hat X) = \tfrac12\log\big(2\pi e(\sigma^2-D)\big), \qquad
h(V) = \tfrac12\log\big(2\pi e D\big), \qquad
h(X) = \tfrac12\log\big(2\pi e\sigma^2\big)
$$
である．とくに定義 9.4.1 の第 $1$ の条件が成り立つ．

第 $2$ の条件を見る．$\hat X$ と $V$ は独立で，どちらも密度をもち微分エントロピーが定まるから，系 7.4.4 を対 $(V,\hat X)$ に当てると，$(V,\hat X)$ は結合密度をもち，$h(V,\hat X)$ は定まって $h(V)+h(\hat X)$ に等しい．$X-\hat X = V$ だから，補題 9.4.2 より $(X,\hat X)$ も結合密度をもち，$h(X,\hat X)$ は定まって $h(V,\hat X)$ に等しい．

第 $3$ と第 $4$ の条件を見る．$X-\hat X = V$ は $\mathcal N(0,D)$ に従うから密度をもち，定理 7.2.2 より $h(V)$ は定まり，借りたガウス分布の基本性質より平均 $0$ をもって $\mathbb E[V^2] = 0 + D = D$ である．よって $(X,\hat X)\in\mathcal Q_{\mathcal N}(D)$ であり，$\mathbb E[(X-\hat X)^2] = D$ である．

相互情報量を求める．いま確かめた条件から定理 7.5.6 の仮定が満たされ
$$
I(X;\hat X) \;=\; h(X)+h(\hat X)-h\big(X,\hat X\big) \;=\; h(X)+h(\hat X)-h(V)-h(\hat X) \;=\; h(X)-h(V)
$$
である．右辺は $\frac12\log(2\pi e\sigma^2) - \frac12\log(2\pi eD)$ で，$\frac12\log(\sigma^2/D)$ に等しい．
:::

::: formalization-note
命題 9.4.4 にあたる宣言は無い．ガウス情報源の下界を達成する対を作る宣言は形式化に無く，結論の形で探しても見つからない．命題 9.4.4 に付した証明が，この主張の保証のすべてである．
:::

::: corollary 9.4.5 ガウス情報源のレート歪み関数の値
$\sigma^2>0$，$0<D\le\sigma^2$ とし，$\mathcal Q_{\mathcal N}(\cdot)$ と $R_{\mathcal N}(\cdot)$ を定義 9.4.1 のとおりとする．このとき $\mathcal Q_{\mathcal N}(D)$ は空でなく
$$
R_{\mathcal N}(D) \;=\; \tfrac12\log\frac{\sigma^2}{D}
$$
である．
:::

::: proof
まず $R_{\mathcal N}(D) \le \frac12\log(\sigma^2/D)$ を見る．$D<\sigma^2$ のときは，命題 9.4.4 より $\mathcal Q_{\mathcal N}(D)$ は空でなく，$I(X;\hat X) = \frac12\log(\sigma^2/D)$ を満たす元をもつ．$R_{\mathcal N}(D)$ は値の集合 $\{I(X;\hat X) : (X,\hat X)\in\mathcal Q_{\mathcal N}(D)\}$ の下限だから，この元をとって不等式を得る．

$D = \sigma^2$ のときは，この値を与える元を命題 9.4.4 からは直接とれないので，値をいくらでも $0$ に近づける元でまかなう．$\varepsilon>0$ を任意にとり，$D' := \sigma^2\,2^{-2\varepsilon}$ とおくと $0<D'<\sigma^2$ である．命題 9.4.4 を $D'$ に当てて得られる対 $(X,\hat X)$ は $\mathbb E[(X-\hat X)^2] = D'$ を満たし，これは $\sigma^2$ 以下だから，定義 9.4.1 の第 $4$ の条件は $D = \sigma^2$ についても成り立つ．残る三つの条件は $D$ を含まないので，この対は $\mathcal Q_{\mathcal N}(\sigma^2)$ にも属する．とくに $\mathcal Q_{\mathcal N}(\sigma^2)$ は空でない．その相互情報量は $\frac12\log(\sigma^2/D') = \frac12\log 2^{2\varepsilon} = \varepsilon$ だから $R_{\mathcal N}(\sigma^2)\le\varepsilon$ であり，$\varepsilon$ は任意だから $R_{\mathcal N}(\sigma^2)\le 0 = \frac12\log(\sigma^2/\sigma^2)$ である．

逆向きはどちらの場合も同じである．定理 9.4.3 より値の集合のどの元も $\frac12\log(\sigma^2/D)$ 以上だから，$\frac12\log(\sigma^2/D)$ は下界であり，下限はそれ以上である．二つを合わせて等号を得る．
:::

::: formalization-note
系 9.4.5 にあたる宣言は無い．ガウス情報源のレート歪み関数の値を述べた宣言は形式化に無く，結論の形で探しても見つからない．系 9.4.5 に付した証明が，この主張の保証のすべてである．
:::

::: proposition 9.4.6
$\sigma^2>0$ とし，$D$ を $D>\sigma^2$ を満たす実数とし，$\mathcal Q_{\mathcal N}(\cdot)$ と $R_{\mathcal N}(\cdot)$ を定義 9.4.1 のとおりとする．このとき $\mathcal Q_{\mathcal N}(D)$ は空でなく $R_{\mathcal N}(D) = 0$ である．
:::

::: proof
$X$ を $\mathcal N(0,\sigma^2)$ に従う実数値確率変数とし，$\hat X$ を $X$ と独立で $\mathcal N(0,\ D-\sigma^2)$ に従う実数値確率変数とする（$D>\sigma^2$ より分散は正である）．

定理 7.2.2 より $h(X)$ と $h(\hat X)$ は定まるから，定義 9.4.1 の第 $1$ の条件が成り立つ．系 7.4.4 を対 $(X,\hat X)$ に当てると，$(X,\hat X)$ は結合密度をもち，$h(X,\hat X)$ は定まって $h(X)+h(\hat X)$ に等しく，第 $2$ の条件も成り立つ．借りたガウス分布の畳み込みの差についての形より $X-\hat X$ は $\mathcal N(0,\ \sigma^2+(D-\sigma^2))$，すなわち $\mathcal N(0,D)$ に従うから，密度をもち，定理 7.2.2 より $h(X-\hat X)$ は定まり，借りたガウス分布の基本性質より平均 $0$ をもって $\mathbb E[(X-\hat X)^2] = D$ である．よって第 $3$ と第 $4$ の条件も成り立ち，$(X,\hat X)\in\mathcal Q_{\mathcal N}(D)$ で，$\mathcal Q_{\mathcal N}(D)$ は空でない．

定理 7.5.6 より $I(X;\hat X) = h(X)+h(\hat X)-h(X,\hat X) = 0$ である．同じ定理より $\mathcal Q_{\mathcal N}(D)$ のどの元でも $I(X;\hat X)\ge0$ だから，$0$ は値の集合の下界であり，かつその元でもある．よって下限は $0$ である．
:::

::: formalization-note
命題 9.4.6 にあたる宣言は無い．歪みを分散より多く許したときにガウス情報源のレート歪み関数が $0$ になることを述べた宣言は形式化に無く，結論の形で探しても見つからない．命題 9.4.6 に付した証明が，この主張の保証のすべてである．
:::

これで $D>0$ のすべての点で値が決まったことになるが，$D = \sigma^2$ のちょうどの点だけは，二つの作り方のどちらも届いていない．命題 9.4.4 の作り方は $\hat X$ の分散が $\sigma^2-D$ なので $D<\sigma^2$ でしか使えず，命題 9.4.6 の作り方は $\hat X$ の分散が $D-\sigma^2$ なので $D>\sigma^2$ でしか使えない．分散 $0$ のガウス分布が定義 7.2.1 の外にあるからである．それでも値が決まるのは，歪みを $\sigma^2$ まで許してよいなら $D<\sigma^2$ 用の対をそのまま使ってよいからで，系 9.4.5 の証明はこの点だけ，相互情報量を $0$ にいくらでも近づける対で下限を押さえている．

**両端で確かめる.** 右の端では，系 9.4.5 の値 $\frac12\log(\sigma^2/D)$ が $D = \sigma^2$ でちょうど $0$ になり，そこから先を扱う命題 9.4.6 の値とつながる．左の端は 9.3 節と様子が違う．二値の情報源では $D = 0$ でも $R(0) = H_b(\pi)$ という有限の値だった（定理 9.3.4）が，こちらは $D$ を小さくすると $\frac12\log(\sigma^2/D)$ がいくらでも大きくなる．実数を有限の精度で読み取った値のエントロピーが，精度を上げると発散する（定理 7.1.6）ことと向きが合っている．定義 9.4.1 が $D>0$ を課しているのも，$D = 0$ をこの枠で扱えないからである．

**規模感.** $D = \sigma^2/4$，すなわち食い違いの $2$ 乗の平均を情報源の分散の $1/4$ まで許すなら，系 9.4.5 の値は $\frac12\log_2 4 = 1$ ビットである．$\sigma^2/100$ まで絞ると $\frac12\log_2 100 = 3.3219\ldots$ ビットになる．歪みを半分にするたびに $\frac12\log_2 2 = 0.5$ ビットずつ増える，という増え方である．効くのは比の対数であって，比そのものではない．第8章 8.1 節でガウス通信路の運ぶ量が信号対雑音比の対数で決まったのと，同じ形である．

## 歪みを配る

情報源が一つとは限らない．たがいに独立な $n$ 個のガウス情報源があって，分散が情報源ごとに違うとする．全体の歪みを $D$ 以下に抑えたいとき，どの情報源にどれだけの歪みを割り当てるのがよいか．第8章 8.6 節が並列ガウス通信路について，限られた総電力をどう配るかを問うたのと，同じ形の問いである．ただし向きが逆になる．あちらは電力を配って対数の和を最大にし，こちらは歪みを配って対数の和を最小にする．

記号を二つ断っておく．本節の $n$ は並列に並べる情報源の個数で，定義 9.1.2 がブロックの長さに使った $n$ とは別である．情報源の番号は本節に限り $1$ から $n$ までとする．水位は第8章 8.6 節と同じく $\nu$ と書く．

::: definition 9.4.7 並列ガウス情報源と歪み配分
$n\ge1$ とし，$\sigma_1^2,\dots,\sigma_n^2$ を正の実数とする．分散がそれぞれ $\sigma_1^2,\dots,\sigma_n^2$ である $n$ 個のガウス情報源，すなわち $\mathcal N(0,\sigma_i^2)$（定義 7.2.1）に従う情報源を，たがいに独立に並べたものを **並列ガウス情報源** と呼ぶ．合計歪み $D>0$ の制約のもとでの **歪み配分** とは，$D_i>0$（$1\le i\le n$）かつ $\sum_{i=1}^{n}D_i \le D$ を満たす実数の組 $(D_1,\dots,D_n)$ のことをいう．その **合計レート** を
$$
\sum_{i=1}^{n}\max\Big(0,\ \tfrac12\log\frac{\sigma_i^2}{D_i}\Big)
$$
で定める．
:::

合計レートの各項は，第 $i$ 情報源だけを歪み $D_i$ で再現するときのレート歪み関数の値である．$D_i\le\sigma_i^2$ なら系 9.4.5 によりその値は $\frac12\log(\sigma_i^2/D_i)$ で，対数の中身が $1$ 以上だからこれは $0$ 以上であり，$\max$ はその値を返す．$D_i>\sigma_i^2$ なら命題 9.4.6 により値は $0$ で，対数の中身が $1$ より小さいので $\frac12\log(\sigma_i^2/D_i)$ は負であり，$\max$ はやはり $0$ を返す．$\max$ は，この二つの場合を一つの式に畳んでいる．

::: formalization-note
定義 9.4.7 に対応する単独の宣言はない．$n$ 個をまとめた情報源のレート歪み関数を述べる宣言もない．形式化の並列ガウスの一連の宣言は通信路の側のもので，`parallelGaussianCapacity` (`InformationTheory/Shannon/ParallelGaussian/Basic.lean`) が扱うのは容量，すなわち相互情報量の上限であって，歪みの配分ではない．
:::

::: definition 9.4.8 逆注水配分
$n\ge1$ とし，$\sigma_1^2,\dots,\sigma_n^2$ を正の実数，$\nu$ を実数とする．
$$
D_i^{*}(\nu) \;:=\; \min\big(\nu,\ \sigma_i^2\big) \qquad (1\le i\le n)
$$
で定まる組を，**水位** $\nu$ の **逆注水配分** と呼ぶ．
:::

名前の由来は絵にあり，それは第8章 8.6 節の絵の裏返しである．裏返るのはまず水の意味である．あちらの水は配る電力だったが，こちらの水は捨てる歪みで，水面から上に出ている部分が符号で送る部分にあたる．装置も一つ変わる．こちらの容器には区画ごとに高さ $\sigma_i^2$ のふたがあり，ふたまで水で満たされた区画とは，分散をそのまま歪みとして払って何も送らない区画のことである．絵を順に見ていく．あちらは，底が段になった一続きの容器の第 $i$ の区画の底の高さを雑音の分散 $N_i$ にとり，水面 $\nu$ までの深さ $\max(0,\nu-N_i)$ をその通信路に配る電力と読んだ（定義 8.6.2）．こちらは底を平らにして，横幅を $n$ 等分した第 $i$ の区画に，高さ $\sigma_i^2$ のところでふたをする．そこに水を注ぐと，ふたに届いていない区画では水面が同じ高さ $\nu$ でそろい，ふたに届いた区画（$\sigma_i^2 \le \nu$）ではふたの高さで止まる．第 $i$ の区画に入る水の深さはどちらの場合も $\min(\nu,\sigma_i^2)$ で，これが第 $i$ 情報源に配る歪みにあたる．ふたまでの高さのうち水に浸かっていない部分 $\sigma_i^2 - \min(\nu,\sigma_i^2)$ が，符号で送る部分である．あちらでは底が水面より上に出た区画に電力を配らなかった．こちらではふたまで水で満たされた区画にレートを配らない．

水面がそろうところが最適なのはなぜか，を絵の言葉で言っておく．以下では，対数の導関数が $(\log e)/t$ であることを微積分の計算規則として既知とする．当てる相手は，この段落で $\frac12\log(\sigma_i^2/D_i)$ を $D_i$ で微分するところだけである．第 $i$ 情報源に配る歪みをほんの少し増やすと，合計レートの第 $i$ 項は歪み $1$ 単位あたり $\frac{\log e}{2D_i}$ だけ減る（$\frac12\log(\sigma_i^2/D_i) = \frac12\log\sigma_i^2 - \frac12\log D_i$ を $D_i$ で微分すればよい）．分母が配った歪みそのものなので，水の浅い区画ほど，歪みを $1$ 単位足したときに減るレートが大きい．任意の配分は，区画のあいだに仕切りを立てて水面の高さをばらばらにした状態にあたり，仕切りを外すと水面がそろう，と見ればよい．水面の高い区画から水面の低い区画へ歪みを少し移せば，増えるぶんより減るぶんが大きく，合計レートは減る．移して得をする組がなくなるのは，ふたに届いていない区画の水面がすべてそろい，しかもふたまで満たされた区画がそれ以上の歪みを受け取らないときで，これが逆注水配分の形にほかならない．そこでは，ふたに届いていないどの区画でも減り方が同じ $\frac{\log e}{2\nu}$ になる．この $\frac{\log e}{2\nu}$ が，あとで補題 9.4.10 が下から抑えるのに使う接線の傾きである．

## 水位の存在と一意性

道具を一つ借りる．**中間値の定理**，すなわち「有界閉区間の上の実数値連続関数は，両端での値のあいだのどの値もとる」という微積分の定理である．当てる相手は，定理 9.4.9 の証明で置く $1$ 変数の実数値関数 $\psi(\nu) = \sum_{i=1}^{n}\min(\nu,\sigma_i^2)$ の，有界閉区間 $[0,\ \max_i\sigma_i^2]$ への制限だけであり，依存するのは定理 9.4.9 の証明だけである．第8章 8.6 節が水位の存在（定理 8.6.3）のために借りたのと同じ定理である．また，連続関数の有限個の最小値と有限和がふたたび連続であることを，微積分の計算規則として既知とする．

::: theorem 9.4.9 水位の存在と一意性
$n\ge1$ とし，$\sigma_1^2,\dots,\sigma_n^2$ を正の実数，$D$ を $0<D<\sum_{i=1}^{n}\sigma_i^2$ を満たす実数とする．このとき
$$
\sum_{i=1}^{n}\min\big(\nu,\ \sigma_i^2\big) \;=\; D
$$
を満たす実数 $\nu$ がただ一つ存在し，それは $0 < \nu < \max_{1\le i\le n}\sigma_i^2$ を満たす．
:::

::: proof
$\psi(\nu) := \sum_{i=1}^{n}\min(\nu,\sigma_i^2)$，$\nu_1 := \max_{1\le i\le n}\sigma_i^2$ とおく．各 $\nu\mapsto\min(\nu,\sigma_i^2)$ は連続関数の最小値だから連続であり，その有限和である $\psi$ も連続である．

両端の値を見る．$\sigma_i^2>0$ より $\psi(0) = \sum_i\min(0,\sigma_i^2) = 0$ である．どの $i$ でも $\nu_1\ge\sigma_i^2$ だから $\psi(\nu_1) = \sum_i\sigma_i^2$ であり，仮定よりこれは $D$ より大きい．

$\psi$ は閉区間 $[0,\nu_1]$ の上で連続で，$\psi(0) = 0 < D < \psi(\nu_1)$ だから，借りた中間値の定理より $\psi(\nu) = D$ を満たす $\nu\in[0,\nu_1]$ が存在する．

解の位置を見る．$\nu\le0$ ならば，どの $i$ でも $\nu\le0<\sigma_i^2$ だから $\min(\nu,\sigma_i^2) = \nu$ で，$\psi(\nu) = n\nu \le 0 < D$ である．$\nu\ge\nu_1$ ならば $\psi(\nu) = \sum_i\sigma_i^2 > D$ である．よって $\psi(\nu) = D$ を満たす実数はすべて $0<\nu<\nu_1$ を満たす．

一意性を見る．$0\le\nu_a<\nu_b\le\nu_1$ とする．各 $i$ について $\min(\nu_a,\sigma_i^2)\le\min(\nu_b,\sigma_i^2)$ である．最大を与える番号を $i_1$（$\sigma_{i_1}^2 = \nu_1$）とすると，$\nu_a<\nu_b\le\sigma_{i_1}^2$ だから第 $i_1$ 項の二つの値は $\nu_a$ と $\nu_b$ に等しい．項ごとに足し合わせると $\psi(\nu_b)-\psi(\nu_a)\ge\nu_b-\nu_a>0$ である．よって $\psi$ は $[0,\nu_1]$ の上で狭義単調増加であり，そこで値 $D$ をとる実数は一つしかない．解はすべてこの区間に入るので，$\psi(\nu) = D$ を満たす実数はただ一つである．
:::

::: formalization-note
定理 9.4.9 に対応する宣言はない．形式化の水位は通信路の側のもので，`exists_waterFillingKKT_of_pos` (`InformationTheory/Shannon/ParallelGaussian/KKT.lean`) が与えるのは，注水配分 `waterFillingPower` (`InformationTheory/Shannon/ParallelGaussian/Basic.lean`) の総和が総電力に等しくなる水位の存在である．配分の式が $\max(0,\nu-N_i)$ で，定義 9.4.8 の $\min(\nu,\sigma_i^2)$ とは形が違う．
:::

## 逆注水の最適性

最適性の証明も，第8章 8.6 節と同じ道具ひとつで通る．1.1 節の信頼の底から出した対数不等式 $\log u \le (u-1)\log e$ である．逆注水配分の点で対数に接線を引き，そのぶんだけ下から抑える．それを述べるのが補題 9.4.10 である．

::: lemma 9.4.10 逆注水配分での接線
$\sigma^2>0$，$\nu>0$ とし，$D^{*} := \min(\nu,\sigma^2)$ とおく．このとき，どの実数 $t>0$ についても
$$
\max\Big(0,\ \tfrac12\log\frac{\sigma^2}{t}\Big)
  \;\ge\; \max\Big(0,\ \tfrac12\log\frac{\sigma^2}{D^{*}}\Big) \;-\; \frac{\log e}{2\nu}\big(t-D^{*}\big)
$$
である．
:::

::: proof
まず，どの $s>0$ と $t>0$ についても成り立つ不等式を用意する．1.1 節の信頼の底から出した対数不等式 $\log u\le(u-1)\log e$ を $u := t/s$ に当てると $\log(t/s)\le\frac{t-s}{s}\log e$ であり，両辺の符号を変えて $\log(s/t)\ge-\frac{t-s}{s}\log e$ を得る．$\frac12\log(\sigma^2/t) - \frac12\log(\sigma^2/s) = \frac12\log(s/t)$ だから
$$
\tfrac12\log\frac{\sigma^2}{t} \;\ge\; \tfrac12\log\frac{\sigma^2}{s} \;-\; \frac{\log e}{2s}\,(t-s)
$$
である．$\nu$ と $\sigma^2$ の大小で場合を分ける．

$\nu<\sigma^2$ のときは $D^{*} = \nu$ である．$\sigma^2/\nu>1$ より $\frac12\log(\sigma^2/\nu)>0$ で，主張の右辺の $\max$ はこの値を返す．用意した不等式を $s := \nu$ ととって使うと
$$
\tfrac12\log\frac{\sigma^2}{t} \;\ge\; \tfrac12\log\frac{\sigma^2}{\nu} \;-\; \frac{\log e}{2\nu}(t-\nu)
$$
である．$\frac12\log(\sigma^2/t)$ は $\max(0,\frac12\log(\sigma^2/t))$ 以下だから，主張の不等式を得る．

$\nu\ge\sigma^2$ のときは $D^{*} = \sigma^2$ で，$\frac12\log(\sigma^2/D^{*}) = \frac12\log 1 = 0$ だから，主張の右辺の $\max$ は $0$ を返し，示すべきことは
$$
\max\Big(0,\ \tfrac12\log\frac{\sigma^2}{t}\Big) \;\ge\; -\frac{\log e}{2\nu}\big(t-\sigma^2\big)
$$
である．$t\ge\sigma^2$ ならば右辺は $0$ 以下で左辺は $0$ 以上だから成り立つ．$t<\sigma^2$ とする．用意した不等式を $s := \sigma^2$ ととって使うと，$\frac12\log(\sigma^2/\sigma^2) = 0$ だから
$$
\tfrac12\log\frac{\sigma^2}{t} \;\ge\; -\frac{\log e}{2\sigma^2}\big(t-\sigma^2\big) \;=\; \frac{\log e}{2}\cdot\frac{\sigma^2-t}{\sigma^2}
$$
である．$0<\sigma^2\le\nu$ と $\sigma^2-t>0$ より $\frac{\sigma^2-t}{\sigma^2}\ge\frac{\sigma^2-t}{\nu}$ だから，右辺は $\frac{\log e}{2}\cdot\frac{\sigma^2-t}{\nu}$ 以上で，これは $-\frac{\log e}{2\nu}(t-\sigma^2)$ に等しい．$\frac12\log(\sigma^2/t)$ は $\max(0,\frac12\log(\sigma^2/t))$ 以下だから，主張の不等式を得る．
:::

::: theorem 9.4.11 逆注水配分の最適性
$n\ge1$ とし，$\sigma_1^2,\dots,\sigma_n^2$ を正の実数，$D>0$ を実数とする．実数 $\nu$ が $\sum_{i=1}^{n}\min(\nu,\sigma_i^2) = D$ を満たすとする．このとき逆注水配分 $(D_1^{*}(\nu),\dots,D_n^{*}(\nu))$ は合計歪み $D$ の制約のもとでの歪み配分（定義 9.4.7）であり，$D'_i>0$（$1\le i\le n$）かつ $\sum_{i=1}^{n}D'_i\le D$ を満たすどの実数の組 $(D'_1,\dots,D'_n)$ についても
$$
\sum_{i=1}^{n}\max\Big(0,\ \tfrac12\log\frac{\sigma_i^2}{D'_i}\Big)
  \;\ge\; \sum_{i=1}^{n}\max\Big(0,\ \tfrac12\log\frac{\sigma_i^2}{D_i^{*}(\nu)}\Big)
$$
である（$D_i^{*}(\nu)$ は定義 9.4.8 の逆注水配分）．
:::

::: proof
まず $\nu>0$ を見る．仮定の和は $D>0$ だから，ある $i$ で $\min(\nu,\sigma_i^2)>0$ であり，とくに $\nu>0$ である．したがって各 $D_i^{*}(\nu) = \min(\nu,\sigma_i^2)$ は正であり，総和は仮定よりちょうど $D$ で，$D$ 以下である．よって逆注水配分は定義 9.4.7 の歪み配分の条件を満たす．

各項に補題 9.4.10 を，$\sigma^2 := \sigma_i^2$，$t := D'_i$ ととって当てると，$D^{*} = D_i^{*}(\nu)$ であり
$$
\max\Big(0,\ \tfrac12\log\frac{\sigma_i^2}{D'_i}\Big)
  \;\ge\; \max\Big(0,\ \tfrac12\log\frac{\sigma_i^2}{D_i^{*}(\nu)}\Big) \;-\; \frac{\log e}{2\nu}\big(D'_i - D_i^{*}(\nu)\big)
$$
である．$i$ について足すと
$$
\sum_{i=1}^{n}\max\Big(0,\ \tfrac12\log\frac{\sigma_i^2}{D'_i}\Big)
  \;\ge\; \sum_{i=1}^{n}\max\Big(0,\ \tfrac12\log\frac{\sigma_i^2}{D_i^{*}(\nu)}\Big)
    \;-\; \frac{\log e}{2\nu}\Big(\sum_{i=1}^{n}D'_i - \sum_{i=1}^{n}D_i^{*}(\nu)\Big)
$$
となる．仮定より $\sum_i D_i^{*}(\nu) = D$ であり，$\sum_i D'_i\le D$ だから括弧の中は $0$ 以下である．$\nu>0$ と $\log e>0$ より係数 $\frac{\log e}{2\nu}$ は正だから，右辺の最後の項は $0$ 以上であり，これを落とすと右辺は小さくなる．よって主張を得る．
:::

::: formalization-note
定理 9.4.11 に対応する宣言はない．形式化の `IsWaterFillingOptimal` (`InformationTheory/Shannon/ParallelGaussian/Basic.lean`) が述べているのは，通信路の側の注水配分 `waterFillingPower` (`InformationTheory/Shannon/ParallelGaussian/Basic.lean`) が $\sum_i\frac12\log(1+P_i/N_i)$ を最大にすることであって，最適化の向きも配分の式も定理 9.4.11 と違う．無条件の機械検証済みの宣言 `isWaterFillingOptimal_of_kkt` (`InformationTheory/Shannon/ParallelGaussian/KKT.lean`) があるのはその最大化のほうで，第8章 定理 8.6.5 がそれに紐付けてある．定理 9.4.11 に付した証明が，この主張の保証のすべてである．
:::

証明で効いたのは，第8章 定理 8.6.5 のときと同じ二つである．接線の傾きが $\frac{\log e}{2\nu}$ という $i$ によらない一つの値であること（補題 9.4.10）と，逆注水配分が歪みの予算をちょうど使い切っていること（$\sum_i D_i^{*}(\nu) = D$）である．前者があるので，$n$ 個ぶんの接線の項が $\sum_i D'_i$ という一つの和にまとまる．後者があるので，その和が歪みの制約と直接くらべられる．分散が水位を超えない情報源（$\sigma_i^2\le\nu$）で接線の傾きがそのままでは足りないところは，補題 9.4.10 の第 $2$ の場合が $\frac{\log e}{2\sigma_i^2}\ge\frac{\log e}{2\nu}$ で吸収している．

定理 9.4.11 が言っているのはここまでで，合計レートという一つの式を歪み配分について最小にすると逆注水配分が最小を与える，ということである．$n$ 個をまとめて一つの情報源とみなしたときのレート歪み関数を，本書は定義しない．したがって，合計レートの最小値がその関数の値に等しいかどうかも述べない．第8章 8.6 節が合計容量について同じ断りを置いたのと，同じ事情である．

## 数で見る

::: example 9.4.12 $2$ 個の並列ガウス情報源
$n=2$，$\sigma_1^2 = 1$，$\sigma_2^2 = 4$ とする．合計歪み $D = 1$ のとき水位は $\nu = 1/2$ で，逆注水配分は $(1/2,\ 1/2)$，その合計レートは $2$ ビットである．分散に比例させた配分 $(1/5,\ 4/5)$ の合計レートは約 $2.3219$ ビットで，これより大きい．合計歪み $D = 3$ のときは水位が $\nu = 2$ で，逆注水配分は $(1,\ 2)$，その合計レートは $1/2$ ビットであり，等分した配分 $(3/2,\ 3/2)$ の合計レートは約 $0.7075$ ビットである．
:::

::: proof
$D = 1$ のとき．水位が第 $1$ の区画のふたの高さ $1$ に届かないと見当をつけると，どちらの区画にも水面までの水が入るので $\nu+\nu = 1$，すなわち $\nu = 1/2$ である．これは $1$ 以下だから見当と整合する．実際 $\min(1/2,1)+\min(1/2,4) = 1/2+1/2 = 1$ で定理 9.4.9 の等式を満たし，それを満たす実数はただ一つだから，これが水位である．逆注水配分は $(1/2,1/2)$ で，どちらの項も対数の中身が $1$ より大きく，対数は正だから，$\max$ はその値を返す．合計レートは $\frac12\log_2 2 + \frac12\log_2 8 = 0.5+1.5 = 2$ である．分散に比例させた配分では，二つの項の対数の中身がどちらも $5$ だから，合計レートは $\log_2 5 = 2.3219\ldots$ である．

$D = 3$ のとき．今度は水位が $1$ を超えると見当をつけると，第 $1$ の区画はふたまで満たされるので $1+\nu = 3$，すなわち $\nu = 2$ である．これは $1$ より大きく $4$ 以下だから見当と整合する．実際 $\min(2,1)+\min(2,4) = 1+2 = 3$ で，これが水位である．逆注水配分は $(1,2)$ で，第 $1$ 項は $\frac12\log_2 1 = 0$ だから $\max$ は $0$ を返し，第 $2$ 項は $\frac12\log_2 2 = 1/2$ である．合計レートは $1/2$ である．等分した配分では，第 $1$ 項の対数の中身が $2/3$ で $1$ より小さく，その対数は負だから $\max$ は $0$ を返す．第 $2$ 項は $\frac12\log_2\frac83 = \frac12\times 1.4150\ldots = 0.7075\ldots$ である．
:::

::: formalization-note
例 9.4.12 に対応する宣言は形式化されていない．例 9.4.12 に付した証明が，この主張の保証のすべてである．
:::

例 9.4.12 の前半は，どの情報源にも歪みを配る場合である．水位 $1/2$ がどちらのふたの高さにも届かないので，二つの区画に同じ深さの水が入る．配る歪みは同じでも，レートは分散の大きいほうに多く配られている（$1.5$ ビット対 $0.5$ ビット）．後半では合計歪みが $3$ に増えて水位が $2$ まで上がり，ふたの高さが $1$ の区画は水で満たされる．そこにはレートを配らず，分散 $1$ のぶんの歪みをそのまま払う．第8章 8.6 節で雑音の強すぎる通信路に電力を配らなかったのと，裏返しの同じことが起きている．逆注水配分と，比べた配分との合計レートの差は，前半が約 $0.32$ ビット，後半が約 $0.21$ ビットである．

ここまでで，レート歪み関数の形が二つの具体例で決まった．9.3 節の二値の情報源では，歪みが $D_{\max}$ に届かない範囲で $H_b(\pi)-H_b(D)$ であり（定理 9.3.4），本節のガウス情報源では，歪みが分散を超えない範囲で $\frac12\log(\sigma^2/D)$ である（系 9.4.5）．どちらもまだ最適化問題の値であって，符号については何も言っていない．その資格を与えるのが 9.5 節と 9.6 節で，前者は歪みを $D$ 以下に抑える符号のレートが $R(D)$ を下回れないこと，後者は，期待歪みが $D$ より小さい再現の作り方があるかぎり，$R(D)$ より大きいレートをとれば歪みを $D$ 以下に抑える符号が作れることを示す．どちらも 9.1 節の約束どおり，有限アルファベットの情報源についての主張である．
