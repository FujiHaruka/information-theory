# 9.3 二値情報源

9.2 節は $R$ のグラフの両端を決めた．左の端では，情報源アルファベットが再現アルファベットに含まれ，しかも歪み尺度が「$0$ になるのは一致するときだけ」を満たすとき，値は情報源のエントロピーである（命題 9.2.4）．右の端では，$D_{\max}$ 以上の歪みを許すと値が $0$ になる（命題 9.2.5）．残っているのは両端のあいだの形で，本節はいちばん小さい情報源についてそれを決める．情報源も再現も $0$ と $1$ の二文字にとり，歪みは当たったか外れたかだけを見る Hamming 歪み（例 9.1.3）にとる．答えは，歪みを許しすぎない範囲では，情報源のエントロピーから，許した歪みのぶんのエントロピーを引いた形になる．

本節のアルファベットは有限だから，定義 9.1.5 と 9.2 節の主張はそのまま当てられる．記号を一つ断っておく．本節は $\Pr[X = 1]$ を $\pi$ と書く．補題 9.2.2 の証明が同時分布を $\pi_j(x,\hat x)$ と書いていて字が重なるが，あちらはつねに二つの引数をとるので，引数のない $\pi$ はつねに二値情報源のパラメータである．9.2 節が両端を確かめたときに使った $\pi$ と同じものである．

## 二値エントロピー関数の形

答えを書き下すには，二値エントロピー関数 $H_b$（例 1.1.2）について三つのことが要る．左右対称であること，凹であること，そして左半分で増えることである．$H_b$ が $p = 1/2$ で最大になるのだから三つめもそうなっているはずで，実際に前の二つから出る．出発点は 1.1 節で認めた $\varphi(t) = -t\log t$ の凹性ひとつである．

::: lemma 9.3.1 二値エントロピー関数の対称性・凹性・単調性
$H_b$ を例 1.1.2 の二値エントロピー関数とする．次の三つが成り立つ．

1. どの $p \in [0,1]$ についても $H_b(1-p) = H_b(p)$ である．
2. $a, b \in [0,1]$ と $\lambda \in [0,1]$ について $H_b\big(\lambda a + (1-\lambda)b\big) \ge \lambda H_b(a) + (1-\lambda)H_b(b)$ である．すなわち $H_b$ は $[0,1]$ の上で凹である．
3. $0 \le s \le t \le 1/2$ を満たす実数 $s$，$t$ について $H_b(s) \le H_b(t)$ である．
:::

::: proof
1. 例 1.1.2 の定め方から $H_b(p) = \varphi(p) + \varphi(1-p)$ である（$\varphi(t) = -t\log t$ は 1.1 節の記号である）．右辺は $p$ と $1-p$ を入れ替えても変わらない．

2. $c := \lambda a + (1-\lambda)b$ とおく．1.1 節で認めた $\varphi$ の凹性を $2$ 点の形で $a$，$b$ に当てると $\varphi(c) \ge \lambda\varphi(a) + (1-\lambda)\varphi(b)$ である．同じ凹性を $1-a$，$1-b$ に当てると，$\lambda(1-a) + (1-\lambda)(1-b) = 1-c$ だから $\varphi(1-c) \ge \lambda\varphi(1-a) + (1-\lambda)\varphi(1-b)$ である．二つを足すと第 $1$ の等式で使った形から $H_b(c) \ge \lambda H_b(a) + (1-\lambda)H_b(b)$ を得る．

3. $s = 1/2$ ならば $t = 1/2$ で両辺が等しいから，$s < 1/2$ としてよい．$t$ を $s$ と $1-s$ の凸結合として書けるように重みを選びたい．そうできれば，第 $2$ の主張の凹性より $H_b(t)$ は $H_b(s)$ と $H_b(1-s)$ の重み付き平均以上であり，第 $1$ の主張より後者は $H_b(s)$ に等しいから，$H_b(t) \ge H_b(s)$ が出る．$\lambda s + (1-\lambda)(1-s) = t$ を $\lambda$ について解くと
$$
\lambda \;:=\; \frac{1-s-t}{1-2s}
$$
とおく．$s < 1/2$ より分母は正である．$s < 1/2$ と $t \le 1/2$ より $s+t < 1$ だから分子も正であり，$s \le t$ より $1-s-t \le 1-2s$ だから $\lambda \in (0,1]$ である．また
$$
\lambda s + (1-\lambda)(1-s) \;=\; (1-s) - \lambda(1-2s) \;=\; (1-s) - (1-s-t) \;=\; t
$$
である．$s$ と $1-s$ はどちらも $[0,1]$ に入るから，第 $2$ の主張を $a := s$，$b := 1-s$ ととって当てると $H_b(t) \ge \lambda H_b(s) + (1-\lambda)H_b(1-s)$ であり，第 $1$ の主張より $H_b(1-s) = H_b(s)$ だから，右辺は $H_b(s)$ に等しい．
:::

::: formalization-note
補題 9.3.1 にあたる宣言は本書の形式化には無い．ただし本書が述べないだけで，三つの主張はどれも二値エントロピー関数についての Mathlib の無条件の機械検証済みの補題として存在する．対称性が `Real.binEntropy_one_sub`，凹性はさらに強い狭義凹性の形で `Real.strictConcave_binEntropy`，区間 $[0,1/2]$ での単調性もさらに強い狭義単調増加の形で `Real.binEntropy_strictMonoOn` である．どれも対数の底の取り方によらない性質である．
:::

## 下界

定義 9.1.5 が最小にするのは $I(p;q)$ である．定理 1.3.4 でこれを $H(X) - H(X\mid\hat X)$ と読むと，第 $1$ 項は $q$ を含まない定数だから，問いは「$X$ と $\hat X$ の結びつきをいちばん弱くする」から「再現を見たあとに残る $X$ の不確かさをいちばん大きくする」に移る．そして歪みの制約が言っているのは，二つの文字が食い違う確率が $D$ 以下だ，ということだけである．食い違ったかどうかを表す二値の確率変数を一つ置けば，そこに二値エントロピー関数が出てくる．

::: proposition 9.3.2 相互情報量の下界
$\pi \in [0,1]$，$0 \le D \le 1/2$ とする．$\mathcal X = \hat{\mathcal X} = \{0,1\}$ とし，$p$ を $p(1) = \pi$，$p(0) = 1-\pi$ で定まる $\mathcal X$ 上の分布，$d_H$ を例 9.1.3 の Hamming 歪みとし，$\mathcal Q(\cdot)$ と $I(p;\cdot)$ を定義 9.1.5 のとおりとする．このとき，どの $q \in \mathcal Q(D)$ についても
$$
I(p;q) \;\ge\; H_b(\pi) - H_b(D)
$$
である（$H_b$ は例 1.1.2 の二値エントロピー関数）．
:::

::: proof
$q \in \mathcal Q(D)$ をとり，$(X,\hat X)$ を定義 9.1.5 のとおり同時分布 $p(x)q(\hat x\mid x)$ をもつ対とする．定義 9.1.5 より $I(p;q) = I(X;\hat X)$ であり，定理 1.3.4 より $I(X;\hat X) = H(X) - H(X\mid\hat X)$ である．$X$ は確率 $\pi$ で $1$，確率 $1-\pi$ で $0$ をとるから，例 1.1.2 より $H(X) = H_b(\pi)$ である．

食い違いを表す確率変数を置く．$X \ne \hat X$ のとき $1$，$X = \hat X$ のとき $0$ をとる確率変数を $E$ とする．例 9.1.3 を $n = 1$ に当てると，$q$ の期待歪みは $\mathbb E[d_H(X,\hat X)] = \Pr[\hat X \ne X] = \Pr[E = 1]$ であり，$q \in \mathcal Q(D)$ より $\Pr[E = 1] \le D$ である．

$H(X\mid\hat X) = H(E\mid\hat X)$ を見る．$\Pr[\hat X = \hat x] > 0$ となる $\hat x \in \{0,1\}$ を固定し，$e_{\hat x} := \Pr[X \ne \hat x \mid \hat X = \hat x]$ とおく（$\Pr[\hat X = \hat x] = 0$ の項は，定義 1.2.2 のとおりどちらの量にも寄与しない）．$X$ は $\{0,1\}$ に値をとるから，$\hat X = \hat x$ のもとでの $X$ の条件付き分布は，$\hat x$ でないほうの文字に $e_{\hat x}$，$\hat x$ に $1 - e_{\hat x}$ を置いたものである．定義 1.2.2 の $H(X \mid \hat X = \hat x)$ はこの分布に定義 1.1.1 を当てたもので，項は二つだけだから $-e_{\hat x}\log e_{\hat x} - (1-e_{\hat x})\log(1-e_{\hat x})$ に等しく，例 1.1.2 よりこれは $H_b(e_{\hat x})$ である．一方 $\hat X = \hat x$ のもとで $E = 1$ となるのは $X \ne \hat x$ のときだから，$\hat X = \hat x$ のもとでの $E$ の条件付き分布は $1$ に $e_{\hat x}$，$0$ に $1-e_{\hat x}$ を置いたもので，同じ理由で $H(E\mid\hat X = \hat x) = H_b(e_{\hat x})$ である．定義 1.2.2 はこれらを $\Pr[\hat X = \hat x]$ で平均したものだから，二つの条件付きエントロピーは等しい．

条件を落として抑える．定理 1.2.4 の基本形（条件の一方を自明な定数にとった形）より $H(E\mid\hat X) \le H(E)$ である．$E$ は確率 $\Pr[E=1]$ で $1$，確率 $1 - \Pr[E=1]$ で $0$ をとるから，例 1.1.2 より $H(E) = H_b(\Pr[E=1])$ である．$\Pr[E=1] \le D \le 1/2$ だから補題 9.3.1 の第 $3$ の主張より $H_b(\Pr[E=1]) \le H_b(D)$ である．

以上を合わせると $H(X\mid\hat X) \le H_b(D)$ であり，$I(p;q) = H_b(\pi) - H(X\mid\hat X) \ge H_b(\pi) - H_b(D)$ を得る．
:::

::: formalization-note
命題 9.3.2 にあたる宣言は無い．形式化には歪み尺度を具体的にとった実例が一つも置かれていないので，Hamming 歪みのもとで相互情報量を下から抑える宣言も無い（結論の形で探しても見つからない）．
:::

## 逆向きに作る

命題 9.3.2 の証明で不等号が入ったのは二か所である．定理 1.2.4 で条件 $\hat X$ を落としたところと，補題 9.3.1 の第 $3$ の主張で $\Pr[E=1]$ を $D$ に置き換えたところである．下界を達成する条件付き分布を作る筋は，抑えたこの二つを抑えた値ちょうどにすることである．食い違いの確率をちょうど $D$ にし，しかも再現 $\hat X$ を知っても食い違いについて何も分からないようにする，ということである．

後者が逆向きの構成の理由になる．素直に思いつくのは，情報源 $X$ を先に置いて，そこに確率 $D$ の反転を独立に加えて再現 $\hat X$ を作る向きである．この作り方では，食い違いは作った時点で $X$ と独立になる．欲しいのはそちらではなく，$\hat X$ と独立な食い違いのほうである．順序を入れ替えて，再現 $\hat X$ を先に置き，そこに確率 $D$ の反転を独立に加えて情報源 $X$ を作れば，食い違いは作った時点で $\hat X$ と独立である．反転確率 $D$ の二元対称通信路（例 6.1.8）を，情報源から再現へではなく，再現から情報源へ向けて使う，と言ってもよい．残るのは，こうして作った同時分布の第 $1$ 周辺が情報源の分布 $p$ に一致するように，$\hat X$ の側のパラメータを選ぶことだけである．

::: proposition 9.3.3 下界を達成する条件付き分布
$\pi$ を実数，$D$ を実数とし，$0 \le D < \min(\pi, 1-\pi)$ とする．$\mathcal X = \hat{\mathcal X} = \{0,1\}$ とし，$p$ を $p(1) = \pi$，$p(0) = 1-\pi$ で定まる $\mathcal X$ 上の分布，$d_H$ を例 9.1.3 の Hamming 歪みとし，$\mathcal Q(\cdot)$ と $I(p;\cdot)$ を定義 9.1.5 のとおりとする．このとき，期待歪みがちょうど $D$ に等しい条件付き分布 $q^{*} \in \mathcal Q(D)$ であって
$$
I(p;q^{*}) \;=\; H_b(\pi) - H_b(D)
$$
を満たすものが存在する（$H_b$ は例 1.1.2 の二値エントロピー関数）．
:::

::: proof
仮定から $\min(\pi,1-\pi) > 0$，すなわち $0 < \pi < 1$ である．また $\min(\pi,1-\pi) \le 1/2$ だから $D < 1/2$ で，$1 - 2D > 0$ である．$\hat X$ が確率 $r$ で $1$ をとるとして，第 $1$ 周辺が $\pi$ になるという条件 $r(1-D) + (1-r)D = \pi$ を $r$ について解くと
$$
r \;:=\; \frac{\pi - D}{1 - 2D}
$$
とおく．分母は正であり，$D < \pi$ より分子も正だから $r > 0$ である．$D < 1-\pi$ より $\pi - D < 1 - 2D$ だから $r < 1$ である．

同時分布を書き下す．$\mathcal X\times\hat{\mathcal X}$ 上の数の組 $J$ を
$$
J(1,1) := r(1-D), \quad J(0,1) := rD, \quad J(1,0) := (1-r)D, \quad J(0,0) := (1-r)(1-D)
$$
で定める．どれも非負であり，総和は $r + (1-r) = 1$ である．これは「$\hat X$ を確率 $r$ で $1$ にとり，そこに確率 $D$ の反転を独立に加えて $X$ を作る」という手順が与える同時分布にほかならない．

第 $1$ 周辺が $p$ であることを見る．$J(1,1) + J(1,0) = r(1-D) + (1-r)D = D + r(1-2D) = D + (\pi - D) = \pi$ であり，$J(0,1) + J(0,0) = rD + (1-r)(1-D) = (1-D) - r(1-2D) = (1-D) - (\pi - D) = 1 - \pi$ である．すなわち $x$ について足すと $p(x)$ になる．

条件付き分布を取り出す．$p(1) = \pi > 0$，$p(0) = 1-\pi > 0$ だから $q^{*}(\hat x\mid x) := J(x,\hat x)/p(x)$ と定めることができ，値は非負で，各 $x$ について $\sum_{\hat x} q^{*}(\hat x\mid x) = p(x)/p(x) = 1$ である．よって $q^{*}$ は定義 9.1.5 の条件付き分布であり，$p(x)q^{*}(\hat x\mid x) = J(x,\hat x)$ だから，$q^{*}$ に対応する対 $(X,\hat X)$ の同時分布は $J$ である．

期待歪みを求める．$d_H$ は $x \ne \hat x$ の対でだけ値 $1$ をとるから，定義 9.1.5 の期待歪みは $J(0,1) + J(1,0) = rD + (1-r)D = D$ である．よって $q^{*} \in \mathcal Q(D)$ であり，期待歪みはちょうど $D$ である．

相互情報量を求める．定理 1.3.4 より $I(p;q^{*}) = H(X) - H(X\mid\hat X)$ である．第 $1$ 周辺が $p$ だから例 1.1.2 より $H(X) = H_b(\pi)$ である．第 $2$ 周辺は $\Pr[\hat X = 1] = J(1,1) + J(0,1) = r(1-D) + rD = r$，$\Pr[\hat X = 0] = 1 - r$ で，$0 < r < 1$ よりどちらも正である．$\Pr[X \ne 1 \mid \hat X = 1] = J(0,1)/r = D$ であり，$\Pr[X \ne 0\mid\hat X = 0] = J(1,0)/(1-r) = D$ である．したがって，どちらの $\hat x$ についても，$\hat X = \hat x$ のもとでの $X$ の条件付き分布は $\hat x$ でないほうの文字に $D$，$\hat x$ に $1-D$ を置いたものであり，定義 1.2.2 と定義 1.1.1 により $H(X\mid\hat X = \hat x)$ は二項の和 $-D\log D - (1-D)\log(1-D)$，すなわち例 1.1.2 の $H_b(D)$ に等しい．定義 1.2.2 はこれを $\Pr[\hat X = \hat x]$ で平均したものだから $H(X\mid\hat X) = H_b(D)$ であり，$I(p;q^{*}) = H_b(\pi) - H_b(D)$ を得る．
:::

::: formalization-note
命題 9.3.3 にあたる宣言は無い．Hamming 歪みを定めた宣言が形式化に無いので，その下界を達成する条件付き分布を作る宣言も無い（結論の形で探しても見つからない）．
:::

## レート歪み関数

::: theorem 9.3.4 二値情報源のレート歪み関数
$\pi \in [0,1]$ とする．$\mathcal X = \hat{\mathcal X} = \{0,1\}$ とし，$p$ を $p(1) = \pi$，$p(0) = 1-\pi$ で定まる $\mathcal X$ 上の分布，$d_H$ を例 9.1.3 の Hamming 歪みとし，$\mathcal Q(\cdot)$ と $R(\cdot)$ を定義 9.1.5 のとおりとする．実数 $D$ について次が成り立つ（$H_b$ は例 1.1.2 の二値エントロピー関数）．

1. $0 \le D < \min(\pi, 1-\pi)$ ならば $\mathcal Q(D)$ は空でなく，$R(D) = H_b(\pi) - H_b(D)$ である．
2. $D \ge \min(\pi, 1-\pi)$ ならば $\mathcal Q(D)$ は空でなく，$R(D) = 0$ である．
:::

::: proof
1. 命題 9.3.3 より，$I(p;q^{*}) = H_b(\pi) - H_b(D)$ を満たす $q^{*} \in \mathcal Q(D)$ が存在する．とくに $\mathcal Q(D)$ は空でなく，$R(D)$ は値の集合 $\{I(p;q) : q\in\mathcal Q(D)\}$ の下限だから $R(D) \le H_b(\pi) - H_b(D)$ である．逆向きを見る．$\min(\pi,1-\pi) \le 1/2$ だから $0 \le D \le 1/2$ であり，命題 9.3.2 よりこの値の集合のどの元も $H_b(\pi) - H_b(D)$ 以上である．下限は下界のうち最大のものだから $R(D) \ge H_b(\pi) - H_b(D)$ である．二つを合わせて等号を得る．

2. まず命題 9.2.5 の $D_{\max}$ を計算する．$\hat x = 0$ に対しては $\sum_x p(x)\,d_H(x,0) = p(1) = \pi$，$\hat x = 1$ に対しては $\sum_x p(x)\,d_H(x,1) = p(0) = 1-\pi$ だから，$D_{\max} = \min(\pi, 1-\pi)$ である．命題 9.2.5 より $\mathcal Q(D_{\max})$ は空でないから，$D_{\max} \le D$ に命題 9.2.1 を当てると $\mathcal Q(D)$ も空でない．そのうえで命題 9.2.5 の後半を $D$ に当てると，$D \ge D_{\max}$ だから $R(D) = 0$ である．
:::

::: formalization-note
定理 9.3.4 にあたる宣言は無い．形式化には歪み尺度を具体的にとった実例が一つも置かれていないので，Hamming 歪みを定めた宣言も，二値情報源のレート歪み関数の値を述べた宣言も無い（結論の形で探しても見つからない）．
:::

**両端で確かめる.** 左の端は $D = 0$ で，定理 9.3.4 の第 $1$ の場合の値は $H_b(\pi) - H_b(0) = H_b(\pi)$ である．$\mathcal X = \hat{\mathcal X}$ であり，$d_H(x,\hat x) = 0$ が $\hat x = x$ と同値だから，命題 9.2.4 の仮定が満たされていて，これはその $R(0) = H(X)$ と一致している．右の端は $D_{\max} = \min(\pi,1-\pi)$ で，第 $1$ の場合の式にこの値を入れると，$\pi \le 1/2$ なら $H_b(\pi) - H_b(\pi) = 0$，$\pi > 1/2$ なら $H_b(\pi) - H_b(1-\pi) = 0$ である（後者は補題 9.3.1 の第 $1$ の主張による）．すなわち第 $1$ の場合の式と第 $2$ の場合の値は，境目で段差なくつながっている．

**通信路容量と同じ式になる.** 公平なコイン（$\pi = 1/2$）では $D_{\max} = 1/2$ で，$0 \le D < 1/2$ のとき $R(D) = 1 - H_b(D)$ ビットである．第6章 例 6.1.8 の二元対称通信路の容量と同じ式が，ここでは最小にした相互情報量として現れている．偶然ではない．命題 9.3.3 の作り方は反転確率 $D$ の二元対称通信路を再現から情報源へ向けて使うもので，$\pi = 1/2$ のときは再現の側が一様分布になる（命題 9.3.3 の証明の $r$ が $1/2$ になる）．その通信路の容量を達成する入力がまさに一様入力なので，下界を達成する対の相互情報量が，例 6.1.8 の容量の値そのものになる．

得られた式が 9.2 節の一般論と食い違わないことも見ておく．$D$ について非増加であることは，補題 9.3.1 の第 $3$ の主張が $[0,1/2]$ の上で $H_b$ が増えると言っているので，$-H_b(D)$ が増えないことから読める（命題 9.2.1）．凸であることは，補題 9.3.1 の第 $2$ の主張により $H_b$ が凹だから，$-H_b$ が凸であることから読める（命題 9.2.3）．一般論が形だけを言っていたところに，二値の情報源では閉じた式が入る．

## 数で見る

::: example 9.3.5 $\pi = 1/4$ の二値情報源
$\mathcal X = \hat{\mathcal X} = \{0,1\}$ とし，$p(1) = 1/4$，$p(0) = 3/4$，$d = d_H$（例 9.1.3）として $R$ を定義 9.1.5 のとおりとする．このとき $R(0)$ は約 $0.8113$ ビット，$R(0.05)$ は約 $0.5249$ ビット，$R(0.1)$ は約 $0.3423$ ビットであり，$D \ge 1/4$ では $R(D) = 0$ である．
:::

::: proof
$\min(1/4, 3/4) = 1/4$ だから，定理 9.3.4 より $0 \le D < 1/4$ では $R(D) = H_b(1/4) - H_b(D)$ であり，$D \ge 1/4$ では $R(D) = 0$ である．

$H_b(1/4)$ を求める．$\log_2 3 = 1.5849\ldots$ だから
$$
H_b(1/4) \;=\; \tfrac14\log_2 4 + \tfrac34\log_2\tfrac43 \;=\; \tfrac12 + \tfrac34\big(2 - \log_2 3\big) \;=\; 0.5 + 0.75 \times 0.4150\ldots \;=\; 0.8112\ldots
$$
である．$D = 0$ では $H_b(0) = 0$ だから $R(0) = H_b(1/4)$ で，約 $0.8113$ ビットである．

$D = 0.05$ では $\log_2 0.05 = -4.3219\ldots$，$\log_2 0.95 = -0.0740\ldots$ だから $H_b(0.05) = 0.05\times 4.3219\ldots + 0.95\times 0.0740\ldots = 0.2160\ldots + 0.0703\ldots = 0.2863\ldots$ であり，$R(0.05) = 0.8112\ldots - 0.2863\ldots = 0.5248\ldots$ で約 $0.5249$ ビットである．

$D = 0.1$ では $\log_2 0.1 = -3.3219\ldots$，$\log_2 0.9 = -0.1520\ldots$ だから $H_b(0.1) = 0.1\times 3.3219\ldots + 0.9\times 0.1520\ldots = 0.3321\ldots + 0.1368\ldots = 0.4689\ldots$ であり，$R(0.1) = 0.8112\ldots - 0.4689\ldots = 0.3422\ldots$ で約 $0.3423$ ビットである．
:::

::: formalization-note
例 9.3.5 に対応する宣言は形式化されていない．
:::

**規模感.** 例 9.3.5 の情報源では，歪みをいっさい許さないときの値が約 $0.8113$ ビットである．文字の $5$ パーセントの食い違いを許すだけで約 $0.5249$ ビットまで下がり，減り方はおよそ $35$ パーセントである．$10$ パーセントの食い違いまで許すと約 $0.3423$ ビットで，およそ $58$ パーセント減る．最初のうちは，わずかな歪みを許すだけで値が大きく落ちる．$1/4$ まで許すと $0$ になる．情報源を見ずにいつも $0$ を出す再現でも，食い違うのは文字の $1/4$ だけだからである（命題 9.2.5 の $D_{\max}$ の読み方）．

ここまでの主張は，どれも最適化問題の値についてのものである．9.5 節と 9.6 節へ進む前に，9.4 節でもう一つの具体例，すなわち実数値をとる情報源を扱う．
