## 2. 訂正一覧

### 2.1 ⚠⚠ 主判定を動かすもの — **0 件**

### 2.2 主判定を動かさないもの — 7 件

**訂正 1 (数値、B6)** — 成果物 §5-2 は「`K` の最大は `p → 1/2` の極限で **`0.1803368950`**」と
「上限は解析的には `1/(8 log 2) = 0.18033688…`」を**併記している**が、⚠⚠ **前者は後者を `1.5e-8` 上回っており
内部矛盾している** (自分で引いた上限を超える「最大値」は原理的にありえない)。
正しくは `sup K = 1/(8 log 2) = 0.1803368801111204` の側で、掃引値は float64 の桁落ち artefact である —
監査が float64 で 10 万点を掃くと `0.18033699511887788` (`p = 0.49999`) が出て**同じ型の artefact を再現**した
(40 桁では `0.1803368801`)。さらに `K` は `(0,1/2)` 上で**狭義単調増加**なので、`1/(8 log 2)` は
**達成されない上限**であって「最大」ではない。⚠ **`K < 1/4` の結論は動かない**。

**訂正 2 (自己評価が過大に悲観、B7)** — 成果物 §5-2 は `max 0 (1 − 4K)` を
「**決して発火しない防御であり、テストされていない**」と書き、破り所として名指ししている。
⚠ **これは脆弱性ではない**: Lean を読むと `K < 1/4` を要求する補題は 1 本も無く
(`inflection_pos` は `K > 0` のみ、`inflection_mul_le` は無条件、`curvatureThreshold_le_inflection_mul` は
`inflection p < 2⁻¹` から `max` を外す)、⚠⚠ **kernel は到達不能枝も含めて両枝を検査している**。
⟹ 仮に `K ≥ 1/4` になる `p` があっても**壊れる箇所は名指しできない** (凸弧が空区間になるだけ、`C11`)。

**訂正 3 (射程が過小、D3 / D4 / D5)** — 仮説 `0 < p` と `p < 1/2` は **どちらも落とせる**。
命題は **`p ∈ [0,1]` の全体で真**である (probe の 4 定理が機械証明: `1/2 < p < 1` は
`binEntropy_one_sub` の対称性 3 行、`p ∈ {0, 1/2, 1}` はいずれも等号)。
⚠ **ただし `[0,1]` で止まる** — `p = 1.1, x = 0.295` で `gap = −0.00137 < 0` (`E4`)。
⚠⚠ **情報理論的には新しいことは何も出ない** (`BSC(1−p)` は `BSC(p)` の出力ラベル付け替えであり、
`p ∈ {0,1/2,1}` は退化チャネル) ⟹ **これは「Lean の仮説を緩められる」という記述の訂正であって、
射程の拡大ではない**。落とすかどうかは実装側の設計判断で、監査は判断しない。

**訂正 4 (自己申告の穴を閉じた、D9)** — 成果物 §5-3 は「起票の候補式は本定理 + `0 ≤ e` で 1 行で出る」
と主張しつつ「**その 1 行は Lean に書いていない**」と自己申告していた。
監査が probe `n11_ticket_candidate_form` として書き、**機械検証済**にした。
⭐ ついでに逆向き (`n11_main_from_halfspace`: 半空間版を境界 `e = binEntropy p / log 2` で使うと主定理が戻る)
も機械証明した ⟹ **2 本の `@[entry_point]` は互いに導出可能で、片方だけが真という食い違いは無い**。

**訂正 5 (構造の注記、C4 / A9)** — 半空間版の仮説 `he : e·log 2 ≤ binEntropy p` は、
⚠ **その結論の `x = 2⁻¹` の場合と命題として同値**である (`binConv p 2⁻¹ = 2⁻¹` ゆえ
結論は `log 2 − binEntropy p ≤ (1−e)·log 2` に潰れる)。
⚠⚠ **これは循環ではない** — 定理の内容は「1 点の場合 ⟹ `[0,1]` 全体」という増幅であり、
body も `he` を単調性の入力として実際に消費している (`:399–402`)。
`E5` が示すとおり `he` は**必要**でもある (`e > h₂(p)` では `x = 1/2` で偽、実測 `−0.0069`)。
⟹ ⭐ **`he` は「最も弱い十分条件」であり、同時に必要条件**である。
後の読み手が「仮説 ≡ 結論の 1 インスタンス」を defect と誤認しないよう、ここに記録する。

**訂正 6 (枠付けが過大、D11)** — 「N10 の判定を支えている**唯一の**解析的入力」という起票の枠付けは、
N10 §2.4 が併用する `σ_x := d*_t − ψ_t(x) ≥ 0` を勘定に入れていない。これは `d*_t` が
**最大値として達成される**ことに依る (連続関数 + コンパクト集合) ので、厳密には代数ではない。
⚠ **これは N10 の主張の継承であり、N11 が新たに作った誤りではない**。
⚠⚠ **監査もこの点を再導出していない** (§3-1)。

**訂正 7 (自己評価が過小、D10)** — 成果物は載った不等式の **tightness** を書いていない。
実際には probe `n11_tight_at_two_inv` が示すとおり、⚠ **すべての `p` について `x = 2⁻¹` で等号が成立する**。
⟹ 載ったのは「ある真な不等式」ではなく **`e` について最も鋭い 1 本**であり、

「コンパイルが通ったこと」だけでは単位は pin されない。pin しているのは tightness と有理点の厳密一致である)。
