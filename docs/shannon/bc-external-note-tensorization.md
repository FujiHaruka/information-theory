## 1. 主張の骨子 (原文の構造を保った転記)

### 前提となる立場

一般 2 受信者 DM-BC `T(y,z|x)` について `C(T) = M(T)` (容量領域が Marton 内界と一致するか) の
肯定証明も反例も得られていない。ただし問題を次の一点に縮約できる、というのがこのノートの主張:

> 長い符号を一文字 Marton 構造へ分解すると、観測によって生成される「事後的なメッセージ間相関」が
> 残る。その相関を常に Marton の共通層・再最適化で吸収できるかどうかが核心である。

### 定理1 — 多文字 Marton 表現

`M(T^{⊗n})` を長さ `n` のチャネル全体を 1 つの巨大な入力文字 `X^n → (Y^n, Z^n)` と見なした
Marton 領域とすると

```
C(T) = closure( ∪_{n≥1} (1/n) M(T^{⊗n}) )                                   … (1)
```

**達成側**: `M(T^{⊗n})` の点を取り、`T^{⊗n}` を 1 つのスーパー記号と見て `k` 回独立に使えば
`T` を `nk` 回使う符号になる。ゆえに `(1/n) M(T^{⊗n}) ⊆ C(T)`。和と閉包を取って `⊆` が出る。

**逆側**: 長さ `n` の任意の符号について `W = M₀`, `U = M₁`, `V = M₂` と置く。メッセージ独立より
`I(U;V|W) = 0`。符号器 `X^n = f(M₀,M₁,M₂)` より `(U,V,W) → X^n → (Y^n,Z^n)` は Markov 連鎖。
Fano から `δ_n → 0` について

```
n R₀        ≤ min{ I(W;Y^n), I(W;Z^n) } + n δ_n
n (R₀+R₁)   ≤ I(U,W;Y^n) + n δ_n
n (R₀+R₂)   ≤ I(V,W;Z^n) + n δ_n
n (R₀+R₁+R₂) = H(M₀) + H(M₁|M₀) + H(M₂|M₀)
             ≤ min{ I(W;Y^n), I(W;Z^n) } + I(U;Y^n|W) + I(V;Z^n|W) − I(U;V|W) + 3 n δ_n
```

(最後の行は `I(U;V|W) = 0` だが Marton の式に合わせて書いてある。) これらは `T^{⊗n}` に対する
Marton 領域の制約そのものなので、任意の達成可能レートは誤差項を除いて `(1/n) M(T^{⊗n})` に属する。

### 同値条件 — 自己加法性への還元

非負の支持ベクトル `θ = (θ₀,θ₁,θ₂)` に対し `h_n^T(θ) = sup_{R ∈ M(T^{⊗n})} θ·R` と置くと、定理1より

```
h_{C(T)}(θ) = sup_{n≥1} (1/n) h_n^T(θ)                                       … (2)
```

一文字 Marton 符号を `n` 個並べれば `h_n^T(θ) ≥ n h_1^T(θ)` は自明。したがって

```
C(T) = M(T)  ⟺  h_n^T(θ) = n h_1^T(θ)   ∀n, ∀θ ≥ 0                          … (3)
```

**つまり一般 BC 問題は「Marton 領域は同一チャネルのテンソル冪に対して自己加法的か」に等しい。**

### 定理2 — 通常の single-letterization を壊す正確な残差

私信のみ、独立メッセージ `A ⊥ B`。2 回のチャネル使用、決定論的符号器 `X₁ = f₁(A,B)`,
`X₂ = f₂(A,B)`。メモリレス性から

```
Y₁ ⊥ Z₂ | (A,B)                                                             … (4)
```

次を定義:

```
Φ = I(A;Y₁,Y₂) + I(B;Z₁,Z₂)

Ψ = I(A;Y₁|Z₂) + I(B;Z₁|Z₂) − I(A;B|Z₂)
  + I(A;Y₂|Y₁) + I(B;Z₂|Y₁) − I(A;B|Y₁)
```

(`Ψ` は Csiszár 型の前後向き条件付けで各座標に Marton の `I(U;Y) + I(V;Z) − I(U;V)` を割り当てた形。)
このとき**厳密に**

```
Φ = Ψ + I(Y₁;Z₂) + I(A;B | Y₁,Z₂)                                           … (5)
```

**証明**: 鎖則で `I(A;Y₁,Y₂) = I(A;Y₁) + I(A;Y₂|Y₁)`, `I(B;Z₁,Z₂) = I(B;Z₂) + I(B;Z₁|Z₂)`。
`Φ − Ψ` を取ると後半が消えて

```
Φ − Ψ = I(A;Y₁) − I(A;Y₁|Z₂) + I(B;Z₂) − I(B;Z₂|Y₁) + I(A;B|Z₂) + I(A;B|Y₁)   … (6)
```

一般に任意の `A,B,Y,Z` について

```
  I(A;Y) − I(A;Y|Z) + I(B;Z) − I(B;Z|Y) + I(A;B|Z) + I(A;B|Y)
= I(Y;Z) + I(A;B|Y,Z) + I(A;B) − I(Y;Z|A,B)                                 … (7)
```

`A ⊥ B` と (4) から `I(A;B) = 0`, `I(Y₁;Z₂|A,B) = 0` なので (5) が従う。

### 残差が実際に正になる例

`A,B` を独立な公平ビット、`X₁ = A ∧ B`, `X₂ = 0`、まずノイズなしで `Y_i = Z_i = X_i`。
`P(X₁ = 1) = 1/4` なので `I(A;X₁) = I(B;X₁) = h₂(1/4) − 1/2`。したがって

```
Φ = 2 h₂(1/4) − 1 ≈ 0.62256 bit
I(A;B|X₁) = 1 − h₂(1/4) ≈ 0.18872 bit
Φ − Ψ ≈ 0.18872 > 0
```

各受信者の出力に独立な小さな BSC ノイズを加えた `T_ε(y,z|x) = BSC_ε(y|x) BSC_ε(z|x)` は
full-support BC で、相互情報量の連続性から十分小さい `ε > 0` でも差は正のまま。
⟹ **`Φ ≤ Ψ` と置いて一文字化する証明は full-support BC に対しても偽**。

残差の正体は、独立だった `A,B` が両方に依存する観測 `Y₁` を条件付けることで依存する現象
(因果推論でいう collider conditioning)。

### 完全な Marton 汎関数でも残る障害

`λ-SRM = λ I(W;Y) + (1−λ) I(W;Z) + I(U;Y|W) + I(V;Z|W) − I(U;V|W)` について、積 BC `T₁ ⊗ T₂` で
`W₁ = (W,Z₂)`, `W₂ = (W,Y₁)` と置くと既知の分解

```
L₁₂ = L₁ + L₂ + Δ₁₂ − N₁₂                                                   … (8)
Δ₁₂ = I(U;V | W,Y₁,Z₂)
N₁₂ = λ I(Y₁;Y₂) + (1−λ) I(Z₁;Z₂) + I(Y₁;Z₂ | U,V,W)  ≥ 0
```

出力の向きを反転すると `Δ₂₁ = I(U;V|W,Y₂,Z₁)` を持つもう 1 つの分解。`L_i^★` を各成分チャネル上で
補助変数を自由に再最適化した最大値、`G₁₂ = (L₁^★ − L₁) + (L₂^★ − L₂) ≥ 0` と置くと、積チャネルの
因子分解に必要な条件は**正確に**

```
Δ₁₂ ≤ N₁₂ + G₁₂                                                             … (9)
```

左辺 = 条件付けが生成した `U,V` の事後相関。右辺 = 出力間に既に観測される相関 + 成分ごとの
補助変数再最適化の余裕。決定論的成分や more-capable 成分を持つ積 BC では補助変数の具体的交換で (9) を
証明できるが、**一般 BC ではこの吸収操作の存在が不明**。

### 肯定証明が止まる場所 / 否定証明に必要なもの

- **肯定**: すべての `T`, `n`, 補助変数分布で `h_n^T(θ) ≤ n h_1^T(θ)` … (10)。2 文字ではこれは
  本質的に (9) を全分布で示すこと。
- **否定**: 既知外界とのギャップでは足りない (UVW 外界が Marton より真に大きいのに別の逆定理で
  Marton が容量と判明している BC クラスが存在する)。本物の反例に必要なのは**同一チャネル** `T` と
  ある `n, θ` で

```
h_n^T(θ) > n h_1^T(θ)                                                       … (11)
```

  これが出れば `(1/n) M(T^{⊗n}) ⊄ M(T)` となり `C(T) ⊋ M(T)` が直ちに従う。
  ⚠ **異なる 2 つの BC `T₁ ≠ T₂` の積で Marton 領域が個別領域の Minkowski 和より真に大きい例は既知だが、
  それは同一チャネルの自己テンソル `T^{⊗2}` での (11) を与えない。**

## 2. このノートが我々の設計に与える含意

1. **軸 E (テンソル化) が本丸への最短路に昇格する**。(3) が正しければ、未解決問題は「Marton 領域の
   support function の自己加法性」という**単一の命題**に等価変形される。攻撃対象が 1 本に絞れる。
2. **軸 D (計算可能性の主語) の L3 の中身が、この定理1 そのもの**。multi-letter 表現を主語として
   立てる作業に、検証すべき散文が既にある状態で入れる。
3. **定理2 の恒等式 (5)/(7) は L1 (probe 基盤) の最初のテストケースとして理想的**。4 変数の線形情報
   恒等式なので数値で即座に真偽が判定でき、しかも判定結果がそのまま軸 B (外界の緩みの局所化) の
   入力になる。
4. **否定側の要求 (11) が明示された**ことで、数値探索の目標が具体化する — 同一チャネルの
   自己テンソルで `h_2 > 2 h_1` を探す、という探索問題に落ちる。
