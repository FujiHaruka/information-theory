## 0. 前提が変わった — Marton 内界は非最適 (2026-08-20、relay 終端の 11 日後)

**Huang–Liu–Liu, *Sub-optimality of Marton's Inner Bound for the Two-Receiver Broadcast Channel*,
arXiv:2608.19869 (2026-08-20)** が、1979 年以来の予想「Marton 内界 = 容量領域」を**反証**した
(逐語と行番号は facts)。骨子:

- **基底チャネル** = 三元入力・三元出力・**全成分正**の BC と固定入力 `p*`。`p*` を固定した
  **2 文字 Marton (和レート) が 1 文字の認証済上界を `2.83e-6` nats 上回る** (2 文字側は明示的な
  有理数 witness、1 文字側は区間演算の分枝限定証明書)。
- **無制約化** = 2 つの新しい一般的な道具: **gradient shaping** (凹関数の勾配を座標ごとに整形して
  `p*` を大域最大点にする) と **constraint removal** (受信者に開示される選択子 `Q` で基底チャネルと
  「共通決定論的成分 `G_i`」を混ぜる receiver-revealed mixture。Marton 汎関数が成分ごとに線形分解する)。
  結果 = 入力アルファベット `{0,1,2} × [2^{2,000,000}]` の**有限** BC で `M_{T⊗2} − 2 M_T > 1.88e-6`。
- 同じ基底チャネルが **Markovity 予想** (Gohari–Liu–Nair ISIT 2025 Conjecture 2) を破り
  (`I(U;V|X) ≈ 0.0668 > 0` の非矩形 2×2 写像 `X = f(U,V)`、ギャップ `8.74e-5`)、
  **additivity 予想** (同 Conjecture 1 = Anantharam–Gohari–Nair 2019) も系として破れる。
- 探索は AI 支援 (GPT-5.6 Sol / Claude Fable 5 / Opus 5)。著者ら自身の診断: 過去の探索が外した理由は
  (i) 反例は非二元入力に要る、(ii) 反例は探索空間の小さな領域にしか無い、(iii) ギャップが `1e-6` 桁。
- **開いたまま**: 二元入力 BC (BSSC を含む) での Marton 最適性は未決 (論文結語)。三元入力の
  *無制約* 反例も未決 (与えられたのは固定入力の三元反例と、巨大アルファベットへの持ち上げ)。

## 2. 問題の構造 — どの経路も通る 2 つの門

記法: `h_n(θ) := sup { θ·r : r ∈ M(W^⊗n) }` (n 文字 Marton 領域の支持関数、正規化なし)。
既知: `h_{n+m} ≥ h_n + h_m` (積 witness、L2 P3 の (H1)–(H5))、`h_n/n → h_C(θ)` (多文字 Marton は
タイト、L0 行 2)、各 `h_n` は `(n, W, θ)` について一様に計算可能 (基数境界)。

### 2.1 肯定側の門 — 「tight な converse」か「計算可能な収束率」か

`C` は computably overt (L0 行 3)。effective compactness は次のどれとも同値 (L2 P1):
`C` を共通部分にもつ一様半計算可能な外界の可算族の存在 ⟺ `n ↦ h_n/n` の**計算可能な収束率**。
したがって肯定側の証明は例外なく次のどちらかの形をとる:

- **(i) tight な外界**: 計算可能な `O(W) ⊇ C(W)` で `O = C` を示す (単文字か有限文字)。
- **(ii) 収束率**: 極限を同定せずに `h_C − h_n/n ≤ ψ(n)` を計算可能な `ψ → 0` で示す。

**補題 A (倍化ギャップの可和性 ⟹ 計算可能)**。`g(n) := h_{2n}/(2n) − h_n/n ≥ 0` と置く。
もし計算可能な `φ` で `g(2^j n) ≤ φ(j, n)` かつ `ψ(n) := Σ_j φ(j, n)` が計算可能に `0` へ収束するなら、
`h_C(θ) − h_n(θ)/n ≤ ψ(n)` であり `W ↦ C(W)` は計算可能である。
*証明*: `h_{2^k n}/(2^k n) = h_n/n + Σ_{j<k} g(2^j n)`、`k → ∞` の極限は部分列でも全体と同じ
(`h_n/n` は収束する)。支持関数の有限方向の ε 網 + 凸性で Hausdorff 近似に落ちる。∎
例: `g(m) ≤ c·m^{−δ}` なら `ψ(n) = O(n^{−δ})`。

**Marton の反証が言うこと** = `g(1) > 0` なるチャネルが在る。⟹ **肯定側の問いは
「倍化ギャップ `g(n)` は計算可能に可和か」に一本化される**。`g ≡ 0` (テンソル化) は偽。

### 2.2 否定側の門 — TM → BC 還元 (2 形)

- **(N-a) 単一チャネル**: 計算可能な (有理数の) `W` で `h_C(θ)` が非計算可能な左 c.e. 実数になる。
  `h_n/n` は計算可能な単調 (部分列で) 増加列なので、極限が非計算可能であるには「予測不能な尺度で
  利得が出続ける」構造が要る。
- **(N-b) 写像の非一様性**: 各 `C(W)` は計算可能だが `W ↦ C(W)` に一様なアルゴリズムが無い。
  不連続性はその十分条件 (計算可能写像は連続)。

**構造的な障害 (なぜ機構が見当たらないか)**: n 文字 Marton 最適化には**文字間の硬い結合制約が無い**。
結合は補助変数の同時法則を通じてしか入らず、それは最適化器が自由に選ぶ。グラフの Shannon 容量
`Θ(G) = sup_n α(G^n)^{1/n}` では強積の隣接が組合せ的な結合を与えるが、消失誤り BC にはその対応物が
無い。TM の計算履歴を「有効な符号語」として報酬づける機構が、記憶のないチャネルには無い。

### 2.3 較正 — `Θ(G)` と同型

`C = lim (1/n)M(W^⊗n)` は `Θ(G) = lim α(G^n)^{1/n}` と同じ形 (各項計算可能・超加法的・極限の
計算可能性が未知)。`Θ` は 60 年以上未決で、肯定的な結果は Lovász `θ` のような**計算可能な双対**が
特定のグラフでタイトになる場合だけである。BC での `θ` の対応物が auxiliary-receiver 族であり、
Marton の反証は「真の答えは一部のチャネルで本質的に多文字」と言っている。⟹ **§0 の一般解は
`Θ(G)` 級の難度**として見積もるのが正直である。

## 3. 残る経路と証明のアイデア

### P1 (肯定側) 多文字 auxiliary-receiver 族の漸近的タイト性 — `Thm7 = C` より真に弱い還元先

**主張**: `(C2) ⟸ ∩_n (1/n) Thm7(W^⊗n) = C(W)`。

*証明スケッチ*: `Thm7(V)` はチャネル `V` について一様に effectively compact (L2 P2)。`(n, W) ↦ W^⊗n`
と `1/n` 倍は計算可能なので、族 `O_n(W) := (1/n) Thm7(W^⊗n)` は `(n, W)` について一様に半計算可能。
各 `O_n ⊇ (1/n) C(W^⊗n) = C(W)`。一様半計算可能な可算族の共通部分は半計算可能 (L2 P1、減少性不要)。∎

**なぜ単文字 `Thm7` と違って縮みうるか**: `∃` 形外界の多文字化は優加法性で無駄だが (L2 P3)、`Thm7` は
`∃p ∀T_J ∃aux` 形で (H1) を満たさない。積 `J = J_1 ⊗ J_2` の族の上では優加法性が復活する一方、
**絡んだ `J` (`I(X_1;X_2|J) > 0`) だけが縮める余地を持つ** (L2 行 1 の残余不等式 (★))。
記憶のない補助受信器は「2 入力のパリティ」を観測できないが、`W^⊗2` 上の `J = X_1 ⊕ X_2` は観測できる。

**タイト性側の証明のアイデア** (⚠ 機構は未発見):
- 示すべきは証明書抽出: `r ∉ C ⟹ ∃n ∃T_J on X^n` で eligible witness が無い。これは
  「符号 (∃) ↔ genie (∀)」の双対定理で、compound channel の `min` 形達成可能性に形だけ似る。
- `J = X^n` の帰結は既に強い: (20a)/(20b) は `H(X | Ũ, W̃, Z) = 0` と `H(X | V̂, Ŵ, Y) = 0` を強制する
  (tilde 系 + `Z`、hat 系 + `Y` が入力を決定する)。`∀J` は「全ての劣化観測に対する整合性」を witness に
  課しており、`n → ∞` で「符号由来の witness しか生き残らない」ことを示すのが本筋になる。
  ⚠ これは希望であって議論ではない。

**最初の実験 E1** (`[構築 + probe]`、認証は上界側のみで足りる): HLL 基底チャネル (`p*` 固定) と BSSC で、
`W^⊗2` 上の絡んだ `J` (パリティ / AND / `(X_1, Z_2)` 型) を 1 つ選び、Theorem 5 / Theorem 6 型の弱化で
和レート上界を数値評価する。BSSC で `0.369296340638082` ([GK-outer] の `SR_GK`) を下回れば**それ自体が
公表価値のある新記録**であり、P1 の生存証拠になる。下回らなくても「無い」は言えない (`κ = ∞` の壁)。

### P2 (肯定側) 近似テンソル化 — 補題 A の仮定を示す

必要なのは「最適 witness の安定性」: `W^⊗2n` の最適 witness が `W^⊗n` の witness の積に近い、という
定量的主張。GGNY Claim 1 の恒等式 `L_12 = L_1 + L_2 + Δ_12 − N_12` (`Δ_12 = I(U;V|W,Y_1,Z_2)`) で言えば
「余剰 `Δ_12` が文字数に対して劣線形」である。
- ⚠ **de Finetti は効かない**: 最適 witness は WLOG 交換可能だが、交換可能列の total correlation は線形
  (全 0 / 全 1 の混合が反例) なので、エントロピー量の劣線形制御は出ない。
- ⚠ 安定性版は等式版より弱い主張だが、**既知の道具では等式版より難しい**。

**実験 E2 (§0 の賭け先を決める、最も情報量の大きい実験)**: HLL 基底チャネル・`p*` 固定で
**4 文字 Marton** を評価し `g(2)` を測る。2 文字 witness の積を初期値にして摂動 (著者らの探索法と同じ)。
`g(2) ≫ g(1)` なら階層は無限 (否定側寄り、`Θ(G)` 型)、`g(2) ≈ 0` なら飽和 (肯定側寄り)。
下界は witness で認証できる。⚠ 「見つからない」は証拠にならない (親 plan §4.5)。

### P3 有限文字予想 (テスト可能な新予想。期待値は偽)

「`∃ k = k(|X|)` 計算可能: `(1/k) M(W^⊗k) = C(W)` が全 `W` で成り立つ」。真なら肯定側は即決着
(`ΣH_1` の基数有界特徴づけ)。HLL 反例は `k = 2` で説明がつく。しかし同じ構成を基底 `W^⊗2` に対して
繰り返せば `k = 2` も破れる公算が高い (`W^⊗2` の固定入力 2 文字ギャップが要るだけ)。E2 がそのまま判定する。

### N1 (否定側) TM → BC 還元 — 障壁が 1 つ減った

必要な部品は 2 つ。
1. **利得の出現尺度を制御できる基底チャネル族 `T_N`** (`k` 文字ギャップが `k ≥ N` でだけ現れる、または
   ギャップの大きさが `N` を符号化する)。HLL の receiver-revealed mixture (Prop 3 の線形分解) と
   gradient shaping は「単文字最適点を指定分布に釘付けする」「成分を確率で混ぜる」装置で、**部品 1 の
   構成に使える初めての道具**である。⚠ 部品 1 だけでも新しい情報理論であり、`Θ(G)` 型の階層が
   実在するかを決める。
2. **`N` を TM の停止時間に繋ぐ**。§2.2 の構造的障害により機構が無い。

### N2 (否定側) `W ↦ C(W)` の不連続性

十分条件 (必要ではない)。`M ⊆ C ⊆ Thm7` の両端が連続なので、跳びは隙間の内側に限られる。
検査法は無い (隙間が開くチャネルで `C` が分からない)。

### 落とした候補

- **`Thm7 = C` (単文字) の直接証明**: 状況証拠が減った。auxiliary-receiver 外界は「Marton に合うまで締める」
  設計で検証されてきたが、その物差しが一部のチャネルで緩いことが分かった。
- **BSSC 和レートの直接決着**: 専門家が数値で 10 年以上。ただし二元入力の Marton 最適性は今も開いており、
  HLL は「非二元が要る」と診断している ⟹ 二元入力では Marton = C の可能性が残る (下記 (c))。

     2 文字 (4 元入力) のテンソル化 `h_2 = 2h_1` は有限次元の不等式 (Jog–Nair 型の摂動法で攻められる形)。
