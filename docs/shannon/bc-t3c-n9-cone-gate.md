## 2. 導出 (⚠ 道具は §4.5 の 3 つだけ。以下はすべて恒等式か明示構成であり、数値掃引は screen として明示する)

### 2.1 `D` は「和レベルごとの 2 本の天井」へ潰れる (恒等式)

`K` は `R1 ↔ R2` 対称 (N6-c の `C` の対称性の系。C9 で `g_β` について残差 `0.000e+00`)。
`σ := R0+R1+R2` と置くと、`D` の 2 つの射影は**どちらも和が `σ`** である。`K` は凸なので
`K ∩ {x+y = σ}` は区間であり、その右端を `r(σ)`、左端は対称性から `σ − r(σ)`。⟹

```
D = { R ≥ 0 : R0 ≤ 2C,  σ ≤ SR_C,  R0+R1 ≤ r(σ),  R0+R2 ≤ r(σ) }        … (D1)
```

⚠ `R0 ≤ 2C` の条項は (D1) の中では**冗長**である (2 本の天井から `R0 ≤ 2r(σ) − σ ≤ 2C` が出る)。

### 2.2 ⭐⭐ 本 leg の核 — `β` 族の箱では `R0` の天井が**ちょうど冗長**である (恒等式)

`β`-split witness (`V1 = U2 = const`) の caps は

```
M(β) = C(1−h(β)) + 1 − h(β*p),   B1(β) = B2(β) = R1(β),   S1(β) = S2(β) = R1(β) + R2(β)
```

であり (C3、評価器との残差 `2.220e-15`)、**`M(β) = R1(β) − R2(β)`、すなわち `S = B1 + B2 − M`**

一致しており、**冗長**である。

## 3. 判定

### 3.1 判定 = **閉じた (恒等式による。⚠ `ε = 2.0786e-07` つきで厳密 0 ではない)**

**[probc] 上で、錐 `0 < λ0 < λ1+λ2` を含めて `Thm7` と `C` の比較が閉じる**:

- `D_β ⊆ C` — §2.3 の恒等式 (本 leg)。
- `C ⊆ D` — §1.3 の恒等式 (本 leg が段を補った)。
- `K_β ⊆ K ⊆ K_β + [0,ε]²` — N6-p + N7-a。
- ⟹ `D_β ⊆ C ⊆ D ⊆ D_β + {0}×[0,ε]²` ⟹ **`D = C` は `ε` の幅の中で成り立つ** (⚠ **厳密な集合等式ではない**)。
- ⟹ §2.5 の連鎖で **`Thm7 ⊆ C + {0}×[0,ε]²`**、逆向き `C ⊆ Thm7` は N6-p から無条件。

⚠⚠ **落としてはならない 5 点**:

1. **これは `Thm7 ⊋ C` の材料ではない** — 得られたのは包含の**片側**であり、しかも `Thm7` を `C` の側へ閉じる向きである。
2. **`Thm7 ⊋ C` は排除されていない** — `ε > 0` なので、分離が幅 `ε` の内側に隠れている可能性は残る。
3. **1 インスタンス** — [probc] の話であって `Thm7 = C` 一般ではない。
4. **「尽きた」ではない** — 残るのは (β) の `ε` 厳密 0、`C ⊆ D_β` の厳密化 (§5-1)、一般 BC、他インスタンス。
5. **レート領域の包含について本 leg が Lean に載せたものは 1 つも無い** (本 leg は層 1 + 層 2 のみ)。

### 3.3 ⭐ 負の対照 2 本 (「class, not instance」の義務。⚠ 構造的に異なる 2 つ)

**恒等式が「自動的」ではないことを、機構が壊れる例で確かめた**:

1. **N6-n の有理数多面体** (C16): `外 = {R0 ≤ 1/2, R0+R1 ≤ 1, R0+R2 ≤ 1, 和 ≤ 1}` は `B1+B2−S−M = 0.5 > 0`
   ⟹ §2.2 の冗長性が成り立たない ⟹ **`D`(スライス) の支持値 `2.0` に対し `外` は `1.5`、`内` は `1.0`**
   (⚠ **N6-n が報告した `1.5` 対 `1.0` を独立に再現している**)。
2. **補助変数が非自明な本物の Theorem 3 witness** (C17): 400 本から `B1+B2−S−M = 0.624630` の witness が出る
   ⟹ その箱の 3 本のスライス由来の天井は `R0` を `0.897477` まで許すのに、箱自身は `M = 0.272846` しか許さない。
