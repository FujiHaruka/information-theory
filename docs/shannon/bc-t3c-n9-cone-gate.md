### 2.1 `D` は「和レベルごとの 2 本の天井」へ潰れる (恒等式)

`K` は `R1 ↔ R2` 対称 (N6-c の `C` の対称性の系。C9 で `g_β` について残差 `0.000e+00`)。
`σ := R0+R1+R2` と置くと、`D` の 2 つの射影は**どちらも和が `σ`** である。`K` は凸なので
`K ∩ {x+y = σ}` は区間であり、その右端を `r(σ)`、左端は対称性から `σ − r(σ)`。⟹

```
D = { R ≥ 0 : R0 ≤ 2C,  σ ≤ SR_C,  R0+R1 ≤ r(σ),  R0+R2 ≤ r(σ) }        … (D1)
```

⚠⚠ **`R0 ≤ 2C` の条項が冗長になるのは `D` / `D_β` の中だけである** (そこでは 2 本の天井から `R0 ≤ 2r(σ) − σ ≤ 2C` が出る。
`D_β` では `2r_β(σ) − σ = M(β) ≤ 2C`)。⚠ **`ε` で膨らませた `D(K_β+[0,ε]²)` の中では冗長ではない** — 監査 (`G4`) が
明示の反例を出している (⚠ 有理数的に明示、最適化器不使用):

```
R = (2C + ε, 0, 0):  (R0+R1, R2) = (2C+ε, 0) ∈ K_β + [0,ε]²   ((2C,0) ∈ K_β に (ε,0) を足したもの)
                     (R1, R0+R2) = (0, 2C+ε) ∈ K_β + [0,ε]²   (鏡映の角 (0,2C) に (0,ε) を足したもの)
                     しかし R0 = 2C + ε > 2C ⟹ R ∉ D_β + {0}×[0,ε]²  (R1 = R2 = 0 なので平行移動の余地が無い)
```

⟹ **§2.5 の帳簿は `R0 ≤ 2C` の条項を保持している限りだけ成り立つ**。⚠ **本 leg は当初この条項を射程なしで「冗長」と書いていた**
(監査 訂正 1) — ⚠⚠ **危険なのはその 1 語が §2.5 へ持ち越されることである**。⚠ **判定は動かない**: `Thm7` が入る `D′` の定義は
この条項を明示に持ち、検証器の `in_D` も `cap0 = 2C` を保持している。この反例が支持関数のどこに現れるかは §2.5 で扱う
(⚠ **錐の内側の話ではない**)。

### 2.2 ⭐⭐ 本 leg の核 — `β` 族の箱では `R0` の天井が**ちょうど冗長**である (恒等式)

`β`-split witness (`V1 = U2 = const`) の caps は

```
M(β) = C(1−h(β)) + 1 − h(β*p),   B1(β) = B2(β) = R1(β),   S1(β) = S2(β) = R1(β) + R2(β)
```

であり (C3、評価器との残差 `2.220e-15`)、**`M(β) = R1(β) − R2(β)`、すなわち `S = B1 + B2 − M`**
(C4、閉形側 `4.441e-16` / 評価器側 `4.441e-16`)。⟹ 箱 `Box(β)` の中で `R0 ≤ M(β)` は**他の 3 本が既に強制する水準**に
一致しており、**冗長**である。
⚠ **ここでの「冗長」は箱の中の `R0 ≤ M(β)` の話であり、§2.1 の `R0 ≤ 2C` の条項とは別物である** (混同すると訂正 1 の罠に落ちる)。

⭐ **これは数値の一致ではなく構造である** (C5): Theorem 3 の caps は `V1 = U2 = const` のとき
`S1 = M + I(X2;Z2|W2) + I(X1;Y1|W1) = B1 + B2 − M` (かつ `S2` も同じ) となる ⟹ **補助変数が不活性な witness すべてで成り立つ**
(150 本のランダム `(W1,W2)` で残差 `6.661e-16`)。

⭐ **上方修正 (監査による。本 leg は 150 本の観測で止めていた)** — 逆向きは**乱択ではなく恒等式 1 本で無条件に出る**:

```
S1 − (B1 + B2 − M) = I(X1;Y1|V1,W1) − I(X1;Y1|W1) − I(U2;Y2|W2) − I(V1;Z1|W1)  ≤ 0
```

(`min{I(V1;Z1|W1) + I(X1;Y1|V1,W1), I(X1;Y1|W1)}` の第 1 枝を取り、マルコフ性 `V1 −− X1 −− Y1` から
`I(X1;Y1|V1,W1) ≤ I(X1;Y1|W1)`)。⟹ **`S ≤ B1+B2−M` は全 witness で無条件**であり、
**等号 ⟺ 両補助変数が情報的に不活性**である。
⚠⚠ **等号の類は `V1 = U2 = const` より真に広い** — 補助変数が**定数でなくても** `(W,X)` と独立なら等号が立つ
(監査 `B7`、`|A| = 3` の不活性補助変数で残差 `4.441e-16`) ⟹ **本 leg が「補助変数が自明な族」と書いていたのは
「情報的に不活性な族」と書くのが正確**である (⚠ 主張を狭くも広くもしない言い直しであり、判定は動かない)。
⟹ **冗長性は「情報的に不活性な補助変数の族」の性質であって Theorem 3 一般の性質ではない**
(活性な補助変数では厳密不等。C5 の 150 本でも差は `[9.085e-04, 0.638633]`)。

### 2.3 ⭐ `D_β = ⋃_β Box(β)` (両向きの恒等式)

`K` を `K_β` に置き換えたものを `D_β` と書く。`S(β)` は `[0, α*]` から `[2C, SR_C]` への全単射 (C6、最小増分 `7.348e-10`)、
弧は凹 (C7)、`r_β(σ) = R1(β(σ))` は**弧の接線 `(1, t_β)`、`t_β < 1` を証明書として**出る
(C8、`max (t_β − 1) = −1.597e-07`、残差 `7.479e-10`)。

⚠⚠ **訂正 (監査 訂正 5) — 弧の傾きに有限の下限は無い**。本 leg は当初 C7 を「`dR2/dR1` が **`−4.1735`** から `−1` へ単調」と
書いていたが、**`−4.1735` は検証器の格子 `np.linspace(1e-6, α*, 4001)` の下端 `β = 1e-6` での値にすぎず、下限ではない**。
真の下限は **`−∞`** である (対数発散 `≈ −0.209·log₂(1/β)`):

| `β` | `1e-6` | `1e-20` | `1e-100` | `1e-300` |
|---|---|---|---|---|
| `dR2/dR1` | `−4.17` | `−13.91` | `−69.56` | `−208.68` |

⟹ **弧は `β = 0` の角で垂直であり、その端に有限の Lipschitz 定数は存在しない**。
⚠ **単調性 (= 凹性) 自体は `(0, α*]` 全域で立つ** — 分子 `C·h'(β)` は減少、分母 `−(1−2p)·h'(β*p)` は増加なので比は単調であり、
これは解析的に全域で言える。**検証器の C7 は訂正済**で、対数格子 (`β = 1e-300` まで 30001 点、最小増分 `6.816e-03`) と
線形格子 (`1e-6`–`α*`、最小増分 `3.993e-05`) の両方で単調性を確認し、上の 4 点を明示に出す。
⚠⚠ **「傾きが `−4.17` で有界」という読みで `ε` の伝播を見積もると壊れる** — その端では `ε` の水平移動が `ε·|傾き|` の
垂直低下を要求し、値は上限を持たない。⚠ **本 leg の §2.5 が集合レベル (Minkowski 和) の論法を取っているのはこの罠を回避する**
(⚠ ただしそれは結果的にそうなっていたのであって、本 leg が意識して選んだ回避ではない)。⚠ **判定は動かない**。
