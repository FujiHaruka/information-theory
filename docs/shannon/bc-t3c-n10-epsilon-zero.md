## 0. 着手前の見立てと「締める / 緩める」の明記 (§4.4 の義務。⚠ 事後に書き換えない)

### 見立て 1 (**締める**) — `t` 消去は成り立たず、真の標的は 4 変数である

起票ブロック (H1) と同じ内容を自前で立てる。`φ_b(t) := ψ_t(b) − d*_t` は「アフィン − 凸」= **凹**で
`φ_b′(t) = C·[h(b) − h(β*_t)]` ⟹ `h(b) < h(β*_1)` の帯では `[0,1]` 上で単調増加でない ⟹
**facts N7-p が「同値」と書いた 3 変数不等式 `G_1 ≥ ψ_1(b) − d*_1` は必要条件どまり**。
**予想値**: `max_b [ max_t φ_b(t) − φ_b(1) ] = d*_1 = 0.0387…` で、`b → 0` かつ `t = 0` で達成される
(`b → 0` では `ψ_t(0) ≡ 0` ゆえ `φ_0(t) = −d*_t`、その最大は `d*_0 = 0`)。
**機械反証の形**: `φ_b(t)` を自前で組み、`t` 格子と `b` 格子で上式を測る。

### 見立て 2 (**締める**) — (H2) の等号点で Hesse は正定値であり、標的は局所では死なない

⚠ **これは着手前に紙で出したものである** (機械にはこれから掛ける)。`t = 1`, `A0 = A1 = 1/2`, `b = β*_1` の
まわりで `A_i = 1/2 + u_i` と展開すると、2 次の項は
`Q̃ = (x+y)²·[(1−2p)² − C] + C·[ (1−2p)²·S_in − S_out ]` (`x = (1−b)u0`, `y = b·u1`) の形に**分解する**。
ここで `S_in` / `S_out` は `X2` の摂動測度の BSC(p) 通過**前 / 後**の χ² 型ノルム。⟹ 非負性は次の 2 本に帰着する:
**(i)** `(1−2p)² ≥ C`、**(ii)** `S_out ≤ (1−2p)²·S_in` (= BSC の χ²-SDPI、二値なので `b(1−b) ≤ (b*p)(1−(b*p))` 1 本と同値)。
**予想**: どちらも成立 ⟹ **等号点は狭義局所最小**。⚠ **この見立ては「標的が真だ」とは言っていない** — 局所の話である。

### 見立て 3 (**締める**) — (H3) は [probc] の設計そのものである

`X1 ⟂ X2` のスライスで `G_t = C·h(a) − t·J(a)`、`J(a) := h(a*p) − h(p)`。`C·h(a) ≥ J(a)` が全 `a` で立ち、
等号は `a ∈ {0, 1/2, 1}` ちょうど。**予想**: これは「2 つの周辺チャネル `BEC(h(p))` と `BSC(p)` の容量が
厳密に一致し、かつ `BEC` 側が more capable (`e = h(p)` は more capable の境界ちょうど)」という設計。
**確認の形**: 機械 (等号点の同定 + 容量の一致の残差) + 一次文献の逐語 (`lit-fetch.sh`)。

### 見立て 4 (**緩める**) — 「標的の不等式は真である」

殺す道具 = **§4.5-3 (有理数の明示構成による反例)**。⚠ 数値掃引の非違反は screen であり証拠にしない。

### 見立て 5 (**緩める**) — 「`β` を `t` に依らずに選ぶ構成が全域で可能である」

`d*_t ≥ ψ_t(β)` は任意の `β` で立ち、`ψ_t(β)` は `β` 固定なら `t` について**アフィン**、`G_t` も `t` について
アフィン ⟹ **`β` を `t` に依らず取れれば下界全体が `t` についてアフィンになり、端点 2 点 `t ∈ {0,1}` で尽きる**
(= 見立て 1 が壊した `t` 消去を、別の形で回復する)。必要条件は次の 2 本の同時充足:
**(A)** `ψ_1(β) − ψ_1(b) ≥ Ξ − C·H(X1|Y2)`、**(B)** `J(β) − J(b) ≤ C·H(X1|Y2)`
(`Ξ := I(X1;Z1|Z2)`)。⚠ `β = b` は (B) を自明に満たすが (A) が `G_1 ≥ 0` に戻り**偽**である

殺す道具 = **§4.5-3**: (A) の実行可能集合は `ψ_1` の優位集合、(B) のそれは `J` の劣位集合で、
どちらも `(0,1)` 上の**明示的な区間の合併**ゆえ、**有理点 `(b,A0,A1)` を 1 つ与えれば交叉が空か否かを厳密に判定できる**
⟹ 空になる有理点が 1 つ出れば見立て 5 は死ぬ。

### 見立て 6 (**予想**) — 最も起きやすい反証条件は 2 本目である

N9 §4.2 の 3 本のうち、**2 本目 (「不等式は真だが証明が `argmin_s f_t` の全域決定に等価で §4.5 の 3 道具の

## 2. 導出 (⚠ 道具は §4.5 の 3 つだけ。以下はすべて恒等式と明示構成であり、乱択掃引は `E4` 1 本だけで、判定には使っていない)

### 2.1 置き換えは 1 つだけ — `δ` を主役にする

```
δ(x) := C·h(x) − J(x) = ψ_1(x),        J(x) = h(x*p) − h(p)
```

**`δ ≥ 0`** が (H3) = more capable そのもの (§2.5 で初等的に証明)。`d*_1 = max_x δ(x)` であり、
`J = C·h − δ`、`ψ_t(x) = δ(x) − C(1−t)·h(x)` と書き換わる。⚠ **この置き換えだけで以下は全部代数になる**。

### 2.2 恒等式 1 — `BSC` を通した相互情報量の減りが `δ` の差になる

`X1 —— X2 —— Y2` (`Y2 = BSC(p)(X2)`) について `B_i := P(X2=1|X1=i)` とおくと

```
I(X1;Y2) − C·I(X1;X2) = E_{X1}[ δ(B_{X1}) ] − δ(b)
```

(証明: `I(X1;Y2) = h(b*p) − E[h(B*p)]`、`I(X1;X2) = h(b) − E[h(B)]`、
そして `h(x*p) − C·h(x) = h(p) − δ(x)` を `x = b` と `x = B_i` に当てるだけ)。
**残差 `2.609e-16`** (`D2`、120000 個の乱択繊維)。
⚠ **これは強データ処理不等式 (SDPI) の「差」形の恒等式であって、SDPI の定数は使っていない** —
§1.4 の 2 次の話 (χ²-SDPI) は局所の話で、本節は大域の恒等式である。

### 2.3 ⭐⭐ 本 leg の核 — 標的が対称な 2 つの量の差へ潰れる

`S_A := e·δ(a) + C·E_{X2}[δ(A_{X2})]`、`S_B := e·δ(b) + C·E_{X1}[δ(B_{X1})]`、`I2 := I(X1;X2)` とおくと

```
T_t = C(1−t)·[ h(a) + h(b) − C·I2 ] + t·S_A + d*_t − S_B          (∀ t ∈ [0,1], ∀ s)
```

**残差 `4.441e-15`** (`D3`、120000 繊維 × 7 個の `t`)。
導出は 3 段で、いずれも `e + C = 1` (= `e = h(p)`, `C = 1−h(p)`) を使う:
`I(X1;Z1|Z2) = C·h(a) − C²·I2 − S_A` / `C·H(X1|Y2) = C·h(a) − C·I(X1;Y2)` / §2.2 の恒等式。

⭐ **`S_A` と `S_B` は `X1 ↔ X2` を入れ替えた同じ形**である ⟹ **標的は「`X2` 側の `δ` 平均が `X1` 側のそれを
どれだけ上回れるか」という 1 本の問いに潰れる**。

### 2.4 ⭐⭐ 閉じる 1 行 — `ψ_t ≤ d*_t` を `S_B` の 2 か所へ当てる

`ψ_t(x) ≤ d*_t` は `d*` の定義であり、`ψ_t(x) = δ(x) − C(1−t)h(x)` だったので **`δ(x) ≤ d*_t + C(1−t)·h(x)`**。
これを `S_B` の 2 種類の引数 (`x = b` に重み `e`、`x = B_i` に重み `C·P(X1=i)`) に当てて `e + C = 1` で畳むと

```
S_B ≤ e·[d*_t + C(1−t)h(b)] + C·E[d*_t + C(1−t)h(B)]
    = d*_t + C(1−t)·[ e·h(b) + C·H(X2|X1) ] = d*_t + C(1−t)·[ h(b) − C·I2 ]
```

(最小余裕 `9.761e-10 ≥ 0`、畳み直しの残差 `2.220e-16`、`D4`)。§2.3 へ代入すると `d*_t` と `h(b) − C·I2` が**そのまま相殺し**

```
⭐  T_t ≥ C(1−t)·h(a) + t·S_A ≥ 0      (∀ t ∈ [0,1], ∀ (b,A0,A1))
```

最後の `≥ 0` は **`δ ≥ 0` (§2.5) だけ**による。機械確認: **最小 `4.030e-11`** (`D5`、120000 繊維 × 31 個の `t`)、
決定的格子でも **最小 `−1.110e-16`** (`D6`、`101³` 繊維 × 21 個の `t`)。

⟹ **`Ω(t) ≤ d*_t` が全 `t ∈ [0,1]` で成立**。逆向き `Ω(t) ≥ d*_t` は `X1` 決定的な法則が `ψ_t(β)` を達成することから

⟹ **二分法の精度も格子も `tol` も判定に入らない**。

### 2.5 `δ ≥ 0` の初等証明 (⚠ 唯一の解析的入力。名前は Mrs. Gerber だが自前で閉じた)

`(x*p)(1−x*p) = p(1−p) + (1−2p)²·x(1−x)` (残差 `1.388e-16`) を使うと

```
sign δ''(x) = sign [ e·(1−2p)²·x(1−x) − C·p(1−p) ]
```

⟹ **`(0,1/2)` 上で符号変化はちょうど 1 回**、変化点は `x0 = 0.198699324` (`C3b`。解析式と中心差分の相対差 `1.17e-06`)。
`δ(0) = 0`、`δ(1/2) = 0`、`δ'(1/2) = 0`、`δ(x0) = 0.025785088 > 0` なので
