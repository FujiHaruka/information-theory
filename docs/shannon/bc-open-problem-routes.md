## R1 — `F` は「`{a_x}` ↔ `θ` の Legendre」ではなく `min_α max_p min_a` の 3 段入れ子の中段である

### 主張 (条件 1)

有限アルファベットの DM-BC `T(y,z|x)` と 3 補助変数 Marton 内界 `M(T)` (= Jog–Nair Bound 1、
私信のみ、補助 `(U,V,W)`) について、次の 3 つを仮定する:

- **(H1)** Gohari–Liu–Nair Conjecture 1 (Additivity Conjecture) が `F` の内部パラメータ
  `(α, λ)` の**すべての値について**成り立つ。**⟹ L8 でこの読みが正しいことを確定** (facts §L8 (i))。
  未解決の予想そのものなので、依然として仮定である。
- **(H2)** step 6 のタイトさ — `F` から作る双対値 `h̄` が `M(T)` の support function `h^T` に一致する。
  **⟹ L8 で仮定ではなく既知の定理と判明** ([GLN25] 式 (1)、Appendix A に証明。facts §L8 (ii))。
- **(H3)** `M(T)` が閉凸である (support function が集合を決めるために要る)。
  **⟹ L8 で [AGN19] が地の文で主張していることを確認** (証明は付いていない。facts §L8 (vi))。
  ⚠ **我々の 2 補助変数 `def` の凸性は依然未証明** (facts V5) — これは別の対象。

このとき `h_n^T(θ) := sup_{R ∈ M(T^{⊗n})} θ·R` は **`h_n^T(θ) = n·h_1^T(θ)` を全 `n ≥ 1` /
全 `θ ∈ ℝ²₊` で満たし**、外部ノートの同値条件 (3) により `C(T) = M(T)` が従う。

⚠ **R1 は Conjecture 1 を証明しない**。R1 は含意 (conditional statement) であり、(H1) は未解決の
予想そのものである。R1 の内容は「(H1) から (3) へ至る導出を明示的に書き下すこと」— それが
attack `support-vs-dual-additivity` の標的だった (facts §L2 の最終行)。

```
A₁ = I(U,W;Y)                                  R₁ ≤ A₁
A₂ = I(V,W;Z)                                  R₂ ≤ A₂
```

`θ` は受信者ラベルの入替で **`θ = (1, μ)`, `μ ≥ 1`** と正規化してよい (以下この形で書く)。

## R2 — `|X| ≥ 3` の鋭いスラックは決定論的な「格子」チャネルで達成される

> 軸 C (`jog-nair-inequality`)。**前提となる一次文献の逐語は
> [`bc-facts.md`](bc-facts.md) §L10 の C1–C8 行が SoT**。
> **本節の数値・記号的検算の再検証**: `python3 docs/shannon/bc-jognair-general-check.py`
> (約 160s、`--quick` 約 25s)。乱数種と局所最適化の開始点を固定してあるので
> **再実行で報告値は一致する** (実行時間行を除く)。

### 主張 (条件 1)

有限アルファベットの 2 受信者 DM-BC `q(y,z|x)` と、`(U,V) → X → (Y,Z)` を満たす任意の
5 つ組について

```
I(U;Y) + I(V;Z) − I(U;V)  ≤  max{I(X;Y), I(X;Z)} + D(|X|)
```

が成り立つ。ここで `D(k)` は **`|X| = k` の決定論的 BC** (`Y = g(X)`, `Z = h(X)`) だけを
渡る次の量:

```
D(k) := max over (g, h) with |X| = k, max over p(x) of  [ H(Y,Z) − max{H(Y), H(Z)} ]
```

⚠ **`min{H(X|Y), H(X|Z)}` と書いてはいけない** — `(Y,Z)` が `X` を復元する場合 (格子 BC)
だけ両者は一致する。`g = h = 定数` のような復元しない `(g,h)` では `min{H(X|·)} = H(X)`
に跳ね上がるが、実際の `gap` は 0 である。上の形は復元条件を課さずに正しい値を返す。

同値な言い方 (以下ではこちらを使う)。[GNA12] の記法で `T(X) := max_{p(u,v|x)} I(U;Y) +
I(V;Z) − I(U;V)` (`p(x)` とチャネルの関数)、`gap(T,p) := T(X) − max{I(X;Y), I(X;Z)}`、
`f*(k) := sup over |X| = k のチャネルと p(x) の gap` とおくと、**R2 は `f*(k) = D(k)`**
である (`≥` は witness で確定するので、内容は `≤` の側)。

**退化条件**: `D(2) = 0` なので `|X| = 2` では R2 は [GJNW13] Theorem 1 **そのもの**に
なる (弱くならない)。`D(3) = log₂φ = 0.694242…` (φ = 黄金比)、`D(m²) = log₂ m`。

⚠ **R2 は「正しい一般化」の候補として弱い**ことが同時に分かっている — 下の step 8 が
示すとおり **完全平方 `k = m²` では `D(k)` が 3 行で出る自明上界と一致する**ので、そこでは
主張の中身が消える。中身が残るのは非平方の `k` (最小の例が `k = 3`) だけである。この
限界は「殺され方」の 2 番目に書いた。

### (H1) 厳密なスラック恒等式 — step 1 と step 2 を等式として閉じたもの (L13)

step 1 と step 2 は上界を与える不等式として書かれているが、**両者は等式まで閉じる**。L13 が
`prove_identity` で係数相殺により証明した (掃引ではない、Markov 連鎖も使わない) 5 変数の恒等式:

```
H(X) − [I(U;Y) + I(V;Z) − I(U;V)]
  = I(U;X|Y) + I(V;X|Z) + H(X|U,V) + I(U;V|X) − I(U;Y|X) − I(V;Z|X)
```

Markov 連鎖 `(U,V) → X → (Y,Z)` の下では減算 2 項が消える (機械確認、最大 `1.922e-15`)。
`I(X;Y) + H(X|Y) = H(X)` とその `Z` 版 (どちらも係数相殺で証明済) を併せ、

```
L'(T,p) := min over p(u,v|x) of [ I(U;X|Y) + I(V;X|Z) + H(X|U,V) + I(U;V|X) ]
```

と置くと `T(X) = H(X) − L'` かつ `max{I(X;Y),I(X;Z)} = H(X) − min{H(X|Y),H(X|Z)}` ゆえ

```
gap(T,p) = min{H(X|Y), H(X|Z)} − L'(T,p)
```

が**厳密に**成り立つ。`L'` は**非負 4 項の最小**なので、step 2 の上界
`gap ≤ min{H(X|Y),H(X|Z)}` は `L' ≥ 0` の系にあたる。

**この恒等式が R2 に対して持つ意味は 3 つ**:

1. **問いの言い換えが厳密である** — 「鋭いチャネル依存スラック `Φ` を作る」と「`L'` を下から
   抑える」は同じ問題。子候補 C2 の必要条件もそのまま翻訳される: **(N1)** ⟺ `|X|=2` で
   `L' = min{H(X|Y),H(X|Z)}` (= [GJNW13] Theorem 1 の言い換え)、**(N2)** ⟺ 格子 BC で `L' = 0`
   (`U = Y, V = Z` と取ると 4 項が**項別に** 0)。
2. **最適点での 4 項分解が新しい診断になる** — どの項が損失を担うかがチャネルで切り替わる
   (順は `I(U;X|Y) / I(V;X|Z) / H(X|U,V) / I(U;V|X)`)。Blackwell は 2 つの `p` のどちらでも 4 項とも
   ちょうど `0`；平滑化した dense Blackwell (`ε=0.1`) は `0.244929 / 0.270619 / 0.000003 / 0.000004`；
   BSC(0.1) 2 本は `0.000004 / 0.468996 / 0 / 0` で和がちょうど `min{H(X|Y),H(X|Z)}`。
   ⚠ **dense 行の後ろ 2 項は厳密な 0 ではなく `1e-6` スケール**。⟹ **dense チャネルでは `L'` はほぼ
   DPI 2 項で尽きる**ので、次の候補は `(U,V)` を「`X` を復元し `X` の下で条件付き独立」に絞ってよく、
   抑える対象が 4 項から 2 項に減る。

### novelty gate — 実施結果 (L10)

**判定: 標的の問い自体は open のまま。ただし「誰も攻めていない」ではなく「攻められて
いるが未達」に訂正が要る。** 根拠 4 点:

1. **問いは原典が逐語で open と宣言**: [GJNW13] §V Conclusion 逐語 "The inequality fails
   when |X| ≥ 3 so a natural question is whether there is a correct generalization for
   higher cardinality input-alphabets." (facts C5)。
2. **⚠ facts C8 の訂正 (本 leg の発見)**: C8 は著者 publications ページ通読で「`|X| ≥ 3`
   の一般化を掲げた項目は無い」としたが、**[GNA12] = Gohari–Nair–Anantharam,
   *On Marton's inner bound for broadcast channels*, arXiv:1202.0898 (ISIT 2012) が
   まさにそれを掲げている**。表題に濃度が出ないため見落とされたもの。逐語 (§I-B):
   "Beyond binary input alphabets: The inequality (1) itself fails to hold where |X| = 3,
   for instance in the Blackwell channel. Therefore, we attempt to establish properties of
   the optimizing distributions p(u,v|x) that achieve T(X), in Section III."
   ⟹ **攻め口は「極値分布 `p(u,v|x)` の必要条件」であって「スラック付き不等式」ではない**
   (§III の Theorem 2 = AND 型の一般化、Lemma 1/2)。
3. **`T(X) − max{I(X;Y),I(X;Z)}` の大きさを `|X|` の関数として抑える主張は [GNA12] に

   無い。⟹ **加法スラックの枝は空いている**。
4. **乗法スラックの枝は空いていない**: [GNA12] Appendix B が定数 `c_{p(u,x)}` (= 全チャネル
   で `I(U;Y) ≤ c·I(X;Y)` を満たす最小の `c`) を導入し、逐語 "If c_{p(u,x)} + c_{p(v,x)} ≤ 1
   then note: I(U;Y) + I(V;Z) ≤ c_{p(u,x)}I(X;Y) + c_{p(v,x)}I(X;Z) ≤ max(I(X;Y), I(X;Z))"、

⚠ **`(secondary)`**: 「加法スラックの枝が空いている」は 1 本の一次文献の通読 + 1 回の
WebSearch による NOT-FOUND であって、未解決であることの一次的裏づけではない。

**⟹ 副産物**: [GNA12] §III の必要条件 (極値 `p(u,v|x)` は AND 型の配置を持てない、行/列は
相異なる像を持つ) は **step 9 を攻める道具になりうる** — 決定論的極値性を示すには極値分布の
構造を絞る必要があり、それは同論文がやろうとしていることそのものである。

## R3 — 入力アルファベットの 2 分割で損失 `L'` は超加法的 (base case は Theorem 1)

### 主張 (条件 1)

有限アルファベットの 2 受信者 DM-BC `q(y,z|x)` と入力分布 `p(x)` について、`X` の任意の
関数 `W = m(X)` を取ると

```
L'(p)  ≥  Σ_w p(w) · L'(p_w)          (p_w := p(· | W = w))
```

が成り立つ (`L'` は (H1) の非負 4 項損失)。同値に `T(p) ≤ H(W) + Σ_w p(w) T(p_w)`。
`|X| ≤ 2` では [GJNW13] Theorem 1 が `L' = min{H(X|Y), H(X|Z)}` を**厳密に**与えるので、
2 分割を再帰的に取ることで**チャネル依存の下界**

```
Λ_split(p,q) := max over 2 分割 {S, Sᶜ} of [ p(S)·Λ_split(p|S) + p(Sᶜ)·Λ_split(p|Sᶜ) ]
                base case: |X| ≤ 2 で min{H(X|Y), H(X|Z)}、|X| = 1 で 0
gap(T,p)  ≤  min{H(X|Y), H(X|Z)} − Λ_split(p,q)
```

が得られる。**Λ_split は最適化を含まない有限の再帰**であり、2 つの周辺 `q(y|x)`, `q(z|x)`
と `p(x)` だけで決まる (P3 の ill-posed を避ける制約、facts §L13)。

### 数値の結果 (条件 4)

**`Λ_split` が厳密 (`= L'`) になる点が 3 種類ある**:

- **格子 BC 全部** (Blackwell / L 字 / 十字 / `2x2` / `2x3` / `3x3`): 右辺が `H(X)` に一致
  ⟹ `Λ_split = 0 = L'`。
- **`|X| = 2`**: base case ゆえ構成から厳密 (= (N1) を**構成から**満たす)。
- **P2 の kill witness** (部分併合チャネル、`p = (0.45,0.45,0.10)`): margin `−1.7e-07`、
  slack `0.413233` が facts §L13 の `gap = 0.4132331253245206` と一致 ⟹ **P2 を殺した
  witness の上でちょうど鋭い**。そこでは `D(p) = 0.376221 < 0.413233` なので、`Λ_split` は
  **P2 の反例を「説明する」側に立っている**。

**殺しにいった結果**: 族の掃引 (格子 / 平滑化 Blackwell / dense ランダム `|X|=3,4`) で違反
`0/16`、**チャネルと `p(u,v|x)` を同時に振る敵対的探索**で最良 margin `−2.0e-08`
(`|X|=3` の 3 形状、直接評価) ⟹ 反例は出ず、記号的証明 (step 2–4) と整合。

**鋭さの比較 (dense ランダム `|X|=3`)**: `slack(Λ_sup)/gap` の中央 `1.35`、自明上界
`min{I(X;Y),I(X;Z)}` / `min{H(X|Y),H(X|Z)}` より鋭い点が `12/12`。`Λ_split` はこの領域では
緩い (slack 中央 `0.577`) ので、`Λ_comb` の両輪が要る。

### novelty gate (条件 5) — 本候補について単独で実施 (L15)

一次文献 5 本を逐語で当たった: [GNA12] (arXiv:1202.0898) / [GEA11] (arXiv:1006.5166) /

持っていない**。最近傍は 2 つで、どちらも**別の対象**である:

- **[GNA12] の Equation (2) / Conjecture 1** — `C[f] := max_{p(v\|x)} Σ p(v) f(X\|V=v)`
  (**上凸包**) を使う。分割は任意の `p(v|x)` (台が交わってよい) で、`H(W)` の罰も無く、
  かつ「ある `p(x)` では成り立たないことが分かっている」と原典自身が書いている。
- **concave envelope 手稿の sub-additivity** — **積チャネル**に関する加法性 (テンソル化の軸)
  であって、入力アルファベットの分割ではない。
