## 0. ゴール — 未解決本体そのもの

**一般 2 受信者 DM-BC の容量領域の計算可能な特徴付けを、肯定側か否定側のどちらかで決着させる。
散文の証明と、その Lean による機械検証の両方をもって完了とする。**

完了条件 (どちらか一方):

- **肯定側** — 任意の `ε > 0` に対し有界時間で `ε` 近似を返す手続きを構成し、その正当性を証明する。
- **否定側** — そのような手続きが存在しないことを証明する。

いずれの側も、**散文の証明が立つこと**と**Lean で proof done に到達すること** (0 sorry / 0 residual、
`#print axioms` が sorryAx-free、かつ署名走査で load-bearing hypothesis が無いこと) の両方を満たして
初めて達成とする。片側だけでは達成ではない。

### 0.1 ⚠ ゴール保護条項 — 本節は leg / planner が書き換えてはならない

**前 relay の前身で実際に起きた事故がこれである**。原案 (`487afc03`) は T2 の完了条件を
「文献に無い命題が **Lean で機械検証される**」と書き、「**ユーザー指定の二段構え
(散文で証明 → 形式化で検証)**」と明記していた。それを `28a740c5` が **L0 が走る前に**
「散文レベルの候補経路」へ書き換え、形式化をスコープ外にした。判断ログにはユーザー判断としての
記録が無い ⟹ **planner の独断でゴールが狭まり、20 leg がその狭いゴールで回った**。

したがって本 plan でも以下を規約とする:

1. **§0 のゴールと完了条件を狭める変更は、leg / planner が適用してはならない**。狭める提案は
   判断ログに **`GOAL-CHANGE`** として起票し、**ユーザーの承認を得るまで適用しない**。
   広げる方向 (より強い完了条件) は起票不要。
2. **中間結果は記録するが、ゴールの代替にはしない**。台帳 (facts / attacks / 在庫) への収穫は

   持っていた「どこで止まっても成果が残る」というヘッジは、**記録の設計としては継承し、
   ゴールの設計からは外す** — ユーザーが「成果ゼロで終わる可能性を引き受ける」と明示的に選んだ。
3. **各 leg は冒頭に「この leg は §0 のゴールに対して何を動かすか」を 1 行で書く**。書けない leg は
   起票しない。⚠ **本 relay ではこの 1 行に「側」を併記させる** (§5.1)。

## 2. Approach

**§0 の完了条件は「散文の証明」と「Lean の proof done」の両方**である。前 2 次はどちらにも届かず、**未達の形が 2 次で違う** (逐語は §7 判断ログ 1) ⟹ 本 relay は「配分を守る枠構造」をそのまま継承し、**その上に「Lean 側の最も重い段の員数を先に測る早期 gate」を 1 本足す**。20 leg の形は次のとおり。

- **入口 1 点を両側から測る系統 (判定枠、側 = `(C2)`)** — §1 の問いを [探索 + gate] → [構築 + probe] → [層 3 へ載せる] の 3 段 1 組で回す。**肯定側 (押し上げられる = `Thm7 ⊋ C`) と否定側 (押し上げは不可能 = 天井が `Thm7` 側にも立つ) のどちらに転んでも軸が 1 本確定する**。
  ⚠ **N2 着地後の改定で、可変枠 14 のうち 7 leg がこの系統、6 leg が下の探索アークになった**
  (§5 / §7 判断ログ 4)。
- **⭐ 決着を返さない探索アーク系統 (可変枠の内数 6 leg = 3 leg × 2 本、側 = `(C2)`)** —
  **決着圧力を落とすのではなく、成果物の型を 4 つに増やして圧力の当たり先を変える** (§5.3。
  起票の診断と引き受けたリスクは §7 判断ログ 4)。⚠ **道具立て (§4.5 の 3 つ) は変えない。
  変えるのは何を検証するかだけである**。
- **⭐ Lean 側の員数を先に測る系統 (early gate 1 leg、形式化枠の内数、側 = `形式化債務`)** —
  ⚠ **この leg は形式化枠 3 の内数**であり、**可変枠からは 1 leg も出さない** (§5.2)。
- **層 1 が通った命題はその命題単位で層 3 へ載せる** — 全体が揃うのを待たない (前 relay で有効)。
- **層 2 の道具は 3 つに限る** (§4.5)。⚠ **数値掃引は原理的に効かない** — T3 の主語は計算可能性で
  あり、**最適化器の非違反は証拠価値がほぼ 0** (前 relay で 6 度再現)。

**層 1** 散文 (アイデア + 証明スケッチ) / **層 2** proof-probe (核 1〜2 ステップを機械検証 — 散文の自己欺瞞を最短で殺す装置) / **層 3** 形式化 (散文全体を Lean へ ← スコープ内)

   有限個に落としてから尽くす。⚠ **決定的 witness の全探索は整数 bit しか実現できない**
   ⟹ **確率的 witness を併せる** (前 relay は決定的全探索が完全適格な反例を取りこぼす事故を 3 度検出している)。
3. **閉形の族 / 反例の手構成** — 明示 witness の直接評価。

⚠ **1 と 3 は「値は機械・導出は我々」という混合の confidence を持つ** — facts へ書くときは
`machine` と `human-judgment` を**分けて書く**。⚠ **探索アーク (§5.3) でもこの 3 つを使う — 道具は
