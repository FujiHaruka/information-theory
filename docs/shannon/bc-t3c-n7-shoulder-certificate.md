## 0. 判定

**NO-GO。ただし許容差 `ε = 2.0786e-07` つきであり、厳密 0 ではない。**

証明書が与える言明は次の 3 行がすべてである:

```
(a) 任意の t ∈ [0,1] で   h_Thm7(0,1,t) ≤ h_C(0,1,t) + ε,     ε = 2.0786e-07

(c) 逆向き C|_{R0=0} ⊆ Thm7|_{R0=0} は [auxrec] Theorem 7 の逐語から無条件 (N6-p)
```

⟹ **[probc] インスタンスの `R0 = 0` スライスでは、`Thm7` と `C` は `2.0786e-07` の幅の中で
一致する**。N6-e が測った「4 本の天井だけでは開いたままの幅」は **`0.022030`** だったので、

**判定の入力は §4.5 の道具 1 (恒等式への帰着) と 3 (閉形の手構成) と機械証明書だけである。**

## 1. 着手前の反証 1 本 (§4.4-1 の義務) — 標的 = **gate が渡した還元そのもの**

N6audit §8-3 は「gate が渡す還元後の対象の正しさは監査の射程外」と名指ししている
(親 plan §5 も「N7 は還元そのものを疑える形で始めること」と書いている) ⟹ **反証の標的を
還元式そのものに置いた**。N6 §3.1 の主張は

```
h_free(0,1,t) = max_p [ H(Y)_p − t·H(Z|X) − conv(f_t)(p) ]          (N6-i)
```

であり、可動部は 4 つ = **`max_p`** / **`conv`** / **`W = const` の WLOG** / **`f_t` の DC 性**。

**結果: 等式そのものは生存する (§2.5 で `ε` 以内に確認した) が、4 つのうち 3 つは不要だった。**

1. ⭐ **`conv` は消える** — Klein 4 群 (`X = {0,1}²` の平行移動、`## N1 (T3c)` N1-c と同じ群) は
   `H(Y)_s` も `H(Z)_s` も保つので `f_t` を保ち、**任意の `s` の軌道の重心は一様**である。
   ⟹ `conv(f_t)(一様) ≤ (1/4)Σ_a f_t(s∘τ_a) = f_t(s)` が全 `s` で立ち、`conv ≥ min` と合わせて
   **`conv(f_t)(一様) = min_{s∈Δ₃} f_t(s)`** (1 行の恒等式)。⟹ **下側凸包絡も LP 双対 `θ` も
   列生成 (T17) も要らない**。
2. ⭐ **`max_p` は消える** — 上界を出すのに `p` の最適化は要らない。`H(Y)_p ≤ H(Y1)+H(Y2) ≤
   `(h(e)+C) + 1` = H(Y)_一様` (劣加法性 + ブロックごとの最大) の 1 行で足りる。
   ⟹ **反証条件 3.3-2 (「`p ≠ 一様` が支配する」) は起こりようがない**。
3. ⭐ **`W = const` の WLOG は要らない** — N6-h はこの WLOG に依っており、N6audit は
   「併合は `(20c)` を破るので `h_free` の内側でしか成り立たない」と射程を切っていた。
   下の 2 行の評価は `U' := (U,W)` に対して**直接**立つので、**併合も射程の但し書きも要らない**。
4. **`f_t` の DC 性だけが本当に要る** — これが本 leg の実装本体である (§2.3)。

⟹ ⚠ **ブリーフが「本 leg の本体」と名指しした「N1-j の台を使わない Lagrange 証明書の再実装」の
うち、Lagrange 乗数の部分は不要だった** (再実装が要ったのは DC 分枝限定の側だけ)。
⚠ **これは N1-j の格下げではない** — N1-j は**平均制約つき**の問題を解いており、本 leg の対象は
Klein 軌道で平均制約が落ちた後の**制約なし**の最小化である。

## 2. 構築したもの

### 2.1 上界の連鎖 (⚠ 使う Theorem 7 の制約は `(18b)` と `(18i)` の 2 本だけ)

逐語 (`auxrec.txt:1038` / `1069-1071` / `1074`):

```
(18b)  R0+R1     ≤ min{I(W;Y), I(W;Z)} + I(U;Y|W)
(18i)  R0+R1+R2  ≤ min{I(W;Y), I(W;Z)} + min{ I(V;Z|W)+I(X;Y|V,W), I(U;Y|W)+I(X;Z|U,W) }
同時分布 p_{U,V,W,X} · T_{Y,Z|X}  ⟹  (U,V,W) −− X −− (Y,Z)
```

方向 `(0,1,t)`, `t ∈ [0,1]` について、4 天井の箱の支持値は初等 LP で
`≤ (1−t)·(18b) + t·(18i)` (N4、残差 `2.220e-16`)。両者に上の 2 本を代入すると
`min{·,·} ≤ I(W;Y)` と `(18i) ≤ 第 2 枝` だけで

```
(1−t)(18b) + t(18i) ≤ I(U,W;Y) + t·I(X;Z|U,W)                                  … (R1)
```

(N5、残差 `8.882e-16`、相関ありの `(U,V,W)|X`・基数 1–4 の 240 系 × 5 個の `t`)。
`U' := (U,W)` と置き、`p` = `X` の法則、`s_u` = `U' = u` の下での `X` の事後、`λ_u` = その重みとすると

```
I(U';Y) + t·I(X;Z|U') = H(Y)_p − Σ_u λ_u f_t(s_u) − t·H(Z|X),   f_t(s) := H(Y)_s − t·H(Z)_s   … (R2)
```

(N6、残差 `8.882e-16`。`H(Z|X,U') = H(Z|X)` はマルコフ性から)。あとは 2 つの緩和

```
Σ_u λ_u f_t(s_u) ≥ min_{s∈Δ₃} f_t(s)        H(Y)_p ≤ H(Y)_一様 = C + h(e) + 1
```

を掛けて

```
h_Thm7(0,1,t) ≤ H(Y)_一様 − min_{s∈Δ₃} f_t(s) − t·H(Z|X)                       … (R3)
```

⚠ **`(19)` / `(20a)` / `(20b)` / `(20c)` / `(18c)(18d)(18f)(18g)(18h)` / `∀T_J` を 1 本も使っていない**
⟹ **`Thm7` だけでなく、それを含む任意の緩和にも同じ上界が立つ**。
⚠ **補助変数の基数にも依らない** ⟹ N6 やり残し 3 (基数の打ち切り) は本面では発生しない。

### 2.2 `C` 側の下界 (⚠ 閉形の手構成)

`W1 = W2 = β-split`, `V1 = U2 = const` の [probc] Theorem 3 witness は `R0 = 0` で
`(R1, R2) = (C + 1 − h(β*p), C·h(β))` を達成する (N18 が N6 の評価器 `capacity_probc.py` で
残差 `8.882e-16` に再現)。⟹ **任意の固定した `β` について**

```
h_C(0,1,t) ≥ 2C + ψ_t(β),      ψ_t(β) := t·C·h(β) − h(β*p) + h(p)              … (C1)
```

同じ `(β, t)` で **`h_free` 側の 4 原子族** (`(X1 = c ∈ {0,1}) × (X2 ~ Bern(β) or Bern(1−β))`) が
`I(U;Y) + t·I(X;Z|U) = R1(β) + t·R2(β)` を厳密に与える (N9、残差 `2.442e-15`)。
さらにその 4 原子族の各原子 `s = δ_c ⊗ Bern(β)` について

```
f_t(s) = (1−t)(h(e)+h(p)) − ψ_t(β)                                              … (C2)
```

(N10、残差 `3.331e-16`) ⟹ **(R3) の右辺に `min_s f_t ≥ (1−t)(h(e)+h(p)) − ψ_t(β)` を入れると
ちょうど `2C + ψ_t(β)` になる**。⟹ **上界と下界は同じ 1 つの量 `min_s f_t(s)` に載っている**。

### 2.3 証明書 = `min_{s∈Δ₃} f_t(s)` の DC 分枝限定 (`Δ₃` = 4 点上の法則、3 次元)

`f_t = H(sM_Y) − t·H(sM_Z)` は**凹 − t·凹**。セルごとに:

- `H(sM_Z)` は凹 ⟹ **内点での接平面が大域的な上界** ⟹ `−t·H(sM_Z) ≥ −t·(接平面)`。
- 残る `H(sM_Y) − t·(接平面)` は**凹 + アフィン = 凹** ⟹ **単体セル上の最小は頂点にある**。

⟹ セルの下界 = **頂点値の最小**。⚠ **凹の側には緩みが 1 つも入らない** (N1-a が凹側に接平面を
使ったのとは分解の向きが逆であり、これがセル数の差になっている)。分岐は最長辺の 2 等分。
接平面の評価点は重心を一様分布と `1e-9` で混ぜて内点に保つ (接平面はどの内点で取っても
大域上界なので、これは健全性を壊さない)。

**実測**: `tol = 1e-9` で `t = 1` が **`2626` セル / 55 ラウンド / 0.07 秒**、`t ≤ 0.95` はすべて
`600` セル未満。⚠ `## N1 (T3c)` N1-a の `41051` セル (`tol = 1e-9`) / N1-j の `64746` セル
(`η = 1e-13`) と比べて 1–2 桁少ないが、**同じ問題ではない** (N1 は平均制約つき)。

**アンカー 2 本** (N7 テスト):

### 2.4 `t ∈ [0,1]` 全体への持ち上げ (⚠ 格子点だけでは足りない)

`Ω(t) := max_s [t·I(X;Z)_s − I(X;Y)_s]` と置くと `(R3)` は `h_Thm7(0,1,t) ≤ 2C + Ω(t)` と書ける。
**`Ω` は `t` についてアフィン関数の上限なので凸**である ⟹ **格子区間の上では弦の下**にある。
一方 `ψ_t(β)` は `β` を固定すれば `t` についてアフィンなので、`(C1)` は区間上でアフィンな下界を与える。
⟹ **区間上で「証明書の弦 − アフィン下界」はアフィン**であり、**端点と `β` witness の交点だけ調べれば
その区間全体が尽きる**。⟹ 結論は格子点ではなく **`t ∈ [0,1]` の連続体**について立つ。

**格子**: `t_i = (i/320)^{1/3}`, `i = 0..320` (`Ω″` が `t = 1` 側で大きいので勾配をつけた)。
`tol = 1e-9`。⟹ **`ε = 2.0786e-07`**、最悪の `t` は **`0.49895`**。掃引 16 秒。

⚠ **`ε` の内訳**: 格子点そのものでは上界と `(C1)` の差は **厳密に `tol = 1.0e-09`** (N16 / N17)
⟹ **`ε` のほぼ全部は区間内挿の 2 次項**である。実測は `ε ∝ δ²` (`41 / 81 / 161 / 321` 点で
`6.96e-05 / 1.76e-05 / 4.46e-06 / 1.12e-06`、勾配なし格子) ⟹ **計算資源で単調に下がる**。

### 2.5 許容差の伝播 (⚠ N1-i の `√` 増幅が掛かるかを明示的に追った)

`η` (分枝限定の許容差) は `min_s f_t` にそのまま乗り、`(R3)` は `min_s f_t` を**係数 `−1` の線形**で
使う ⟹ **`η ↦ η`、係数はちょうど 1**。N15 が機械で確認 (`η` を `1e-8 → 1e-9 → 1e-10` と動かすと
下界は `9e-9 / 9e-10` ちょうど動き、残差は incumbent 自身の分解能 `≤ 7.96e-10`)。
⚠⚠ **`## N1 (T3c)` N1-i の `leak = 1.358√ε` は掛からない** — あれは**平均制約
`E[D(s_UW)] ≤ −d* + ε`** を台の制約と取り違えたことから来る転送則であり、**本 leg の連鎖には
平均制約が 1 本も無い** (Klein 軌道で `conv` が `min` に潰れた時点で消えている)。
⚠ **異なる許容差の機械事実を無条件形で合成していない** — 合成しているのは
`tol = 1e-9` の証明書 1 種類と、残差 `1e-15` 級の恒等式だけである。
⚠ **浮動小数**: 区間演算ではなく float64。項の大きさは `~3`、丸めは `~1e-15` で `ε` の 8 桁下。

### 2.6 gate の還元式は結局どうなったか

`h_free(0,1,t)` は `2C + ψ_t(β)` (4 原子 free witness、下から) と `2C + Ω̄(t)` (証明書、上から) に

## 3. 反証条件 3 本 (N6 §3.3 が**事前に**書いたもの) の行方

**1. 「DC 分枝限定が `f_t` に効かない」** — ⚠⚠ **機構は実在した。ただし発火しなかった**。
`tol` を `1e-11` 以下に締めると **`t ∈ (0, 0.2)` の帯でセル数が `16 → 300000 超` へ跳ぶ**
(実測: `t = 0.05` / `0.1462` で `tol = 1e-10` は `16` セル、`1e-11` は打ち切り)。
原因は `d*_t` がこの帯で `~1e-15` まで小さく、最小点が単体の**頂点**に貼りつくため
(`t = 0.1` で `β*_t ≈ 1.5e-10`)、頂点近傍でエントロピーの曲率が発散することにある。
⟹ ⚠ **条件文が書いた「`t` の格子を 1 本も閉じられない」は起きていない** — `tol = 1e-9` では
**321 点中 321 点が閉じた**。⚠ **`tol` を締める価値も無い** — `ε` は区間内挿の 2 次項で
決まっており、`tol` は `ε` の 200 分の 1 以下である。⟹ **面は捨てない**。

**2. 「`p ≠ 一様` が支配する」** — ⭐ **恒等式で消えた**。`p` を最大化する段が連鎖に無い
(§1-2)。⟹ N6 やり残し 2 (「`p ≠ 一様` は screen しかしていない」) は**この面については閉じた**。

**3. 「`(18c)/(18d)/(18f)/(18g)/(18h)` が肩の上で先に効く」** — **発火せず、しかも逆向きの
収穫になった**。`C ⊆ Thm7 ⊆ (4 天井の緩和)` の 3 者が `ε` 以内で一致した ⟹ **`R0=0` の肩の上では
`J` 依存の 5 本も `(19)/(20a)/(20b)` も `∀T_J` の層も、支持値を `ε` より大きくは動かせない
= 不活性である**。⚠ **これは「制約が冗長」ではなく「この 1 枚の面の支持値に効かない」である**
(`## M3 (T3b)` 行 1 の `(18h)` 冗長性の領域版に相当するが、射程はこの面に限る)。
⟹ N6 §3.5-2 の次点はここで消化された。

## 5. 収穫 (⚠ どれも「§0 に近づいた」ではない)

1. ⭐ **`Ω(t) = max_s [t·I(X;Z)_s − I(X;Y)_s]` という 1 変数の凸関数へ面が潰れた**。
   `Ω(0) = 0` / `Ω(1) = d*` / `h_Thm7(0,1,t) ≤ 2C + Ω(t)` / `h_C(0,1,t) = 2C + d*_t` であり、
