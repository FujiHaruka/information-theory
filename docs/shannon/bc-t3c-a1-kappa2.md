**判定 = `κ=2 不可能`** (⚠ **より強く `κ = ∞`**。⚠ **射程は「[probc] インスタンス / `SR_C` を運ぶ

**記号** `𝒯` = `T_{J|X}` の空間 = 重心 `p` の `Δ(X)` 上の測度 `μ` 全体 (`## M7 (T3b)` 行 2)。

## 0. 主結果 (2 本)

**(K1) 有限被覆の構造定理 (インスタンス非依存)** — `κ(R) < ∞` なら、**最小被覆の各成員は (19) を
全 `μ` で満たす** (`= (19)-uniform`)。⚠ **Baire もコンパクト性も分離定理も使わない**。
`human-judgment (導出)` + `machine` (アフィン性 = T4)。

**(K2) [probc] / `SR_C` 点での帰結** — `R*` を `SR_C = 2C + d* = 1.1007802` を運ぶレート点とすると
**`κ(R*) = ∞`**。したがって `κ(R*) = 2` は実現しない。`human-judgment (導出)` + `machine` (T1/T2/T3/T5/T5b/T5c/T7)。

**(K3、系) 障害の形** — `μ_X` を覆う witness の `E_R(w)` は**すべて `𝒯` の真のアフィン切片に含まれる**
(= `𝒯` で内点を持たない)。⟹ `SR_C` 点での witness 取り替え機構は「有限個に落ちない」だけでなく
**被覆族の全成員が薄い**。

## 1. 導出 (⚠ 各段は §4.5 の道具 1 = 恒等式への帰着)

**(D1) 制約はすべて `μ` について非狭義アフィン**。(19a)–(19c) は等式 (`auxrec.txt:1076-1078`)、
(20a)/(20b) は各 2 本の不等式 (`:1080-1081`)、(18) の `J` 依存本 (18c)(18d)(18f)(18g)(18h) は
`min{アフィン, アフィン} + アフィン ≥ R` = 半空間 2 本。⟹ **`E_R(w)` は有限本の非狭義アフィン制約で
切り出される凸集合** (machine: T4 で残差 4.11e-15)。

**(D2) 線分補題**。`E` が有限本の非狭義アフィン制約で切られ `ν₀ ∉ E` なら、任意の `ν ∈ 𝒯` に対し
`E ∩ [ν₀,ν]` は `0` を含まない閉部分区間 ⟹ その下限は正。最小被覆 `{E_1..E_k}` (`k ≥ 2`) では
最小性より `ν₀ ∈ E_1 ∖ ⋃_{j≥2}E_j` が取れ、有限個の閉部分区間が `0` を避ける ⟹ **`[ν₀, ν₀+δ(ν−ν₀)] ⊆ E_1`**。
(19) 残差は線分上アフィンで 2 点で 0 ⟹ 直線上で恒等的に 0 ⟹ `ν` で 0。`ν` は任意 ⟹ **(K1)**。

**(D3) 場合分けの要らない鎖 (⭐ `## M12 (T3b)` 行 3 の仮説を弱めた形)**。任意の witness で
`(18i) ≤ I(W;Z) + I(V;Z|W) + I(X;Y|V,W)` (2 つの `min` を各々上から落とす。`I(W;Y) ≤ I(W;Z)` の側でも
`min = I(W;Y) ≤ I(W;Z)` なので**符号の場合分けは不要**) `= I(X;Y) + I(Ṽ,W̃;Z) − I(V̂,Ŵ;Y) − [(19a)+(19c)]@const`
(連鎖律 + Markov。machine: T5b で恒等式残差 2.44e-15、第 1 段の超過 0.00e+00)。
⟹ **`(19a),(19c)@const` と `(20b) 下側@X` だけで `(18i) ≤ I(Ṽ,W̃;Z) ≤ I(X;Z) ≤ 2C`**
(`(20b)` 下側@`J=X` は恒等的に `−H(X|V̂,Ŵ,Y)` = machine T5c 1.55e-15 ⟹ `H(X|V̂,Ŵ,Y) = 0`
⟹ 構造補題 `## M12 (T3b)` 行 2 で `H(X|V̂,Ŵ) = 0` ⟹ `I(V̂,Ŵ;Y) = I(X;Y)`)。
⚠ **`J = const` での適格性は要らない — (19) だけでよい**のが (K2) を動かす点である
(machine: T6 で weakened 仮説だけを満たし `J = const` で非適格な witness が **95 本**実在)。

**(D4) 組み立て**。`(18i)` は `J` 非依存 (`auxrec.txt:1069-1071` 逐語 / machine T3 で `J` 掃きの
振れ幅 **0.00e+00**、他 5 本は `≥ 1.10e-01`) ⟹ `E_R(w) ≠ ∅` なら `(18i) ≥ SR_C`。
`κ(R*) = k < ∞` を仮定 ⟹ (K1) で最小被覆の全成員が (19)-uniform ⟹ `μ_X` を含む成員 `w₁` は
`(19)@const` を満たし、かつ `μ_X` で適格 ⟹ (D3) で `(18i)(w₁) ≤ 2C = 1.0620088 < 1.1007802 = SR_C`。
`E_R(w₁) ∋ μ_X ≠ ∅` と矛盾 ⟹ **有限被覆は存在しない**。⟹ (K2)。(K3) は同じ対偶。

⚠ **`R*` の存在は Thm7 の量化子構造からで、矛盾ではない** — Thm7 が与えるのは `∃p ∀μ ∃w` の
点ごとの選択であり、有限化を主張していない。(K2) は**その選択が有限族に取れないこと**を言う。

## 2. (S1)–(S4) の逐語確認

- **(S1) 有限被覆は (19) 一様 witness に限られる = ⭕ 結論は成立。⚠ ただし gate §4-b の Baire 論証は
  差し替えた**。反証を 1 本当てたところ**位相依存の穴**が出た: `𝒯` を有限台の測度 (= 有限アルファベット
  `J`) と読むと `𝒯 = ⋃_n {|supp| ≤ n}` が**自分自身の中で痩せた閉集合の可算和** ⟹ **`𝒯` は Baire 空間で
  ない** ⟹ 「疎閉集合の有限和は覆えない」が使えない。閉包 (全測度) を取れば Baire は回る。
  ⟹ **どちらの読みでも成り立つ (D2) の線分補題へ置換した** (最小性 + アフィン性のみ、有限的)。
  ⚠ 「`E_R(w)` が真の閉アフィン超平面に含まれるなら疎」自体は正しい (内点を持てば アフィン包が `𝒯` の
  アフィン包と一致し超平面に入らない)。
- **(S2) `J = X` を覆う witness の適格集合は `{I(X;J_μ) ≥ d*}` に含まれる = ⭕ 逐語どおり**。
  `## M12 (T3b)` 行 8 の頑健性 `(18i) ≤ 2C + I(X;J₁)` を machine で再現 (T7、`|I(V̂,Ŵ;J₁) − I(X;J₁)| = 1.78e-15`、
  depolarizer 較正 `I(X;J₁) = 0.020414 / 0.078072 / 0.227782`、上限 `1.0824230 / 1.1400807`)。
  ⚠ **本書の (K2) はこの行を使っていない** — `I(X;J₁) < d*` の窓を要求しない ((19)-uniform が
  `J₁ = const` そのものを与えるため)。⟹ 行 8 は下界 `κ ≥ 2` の再現用としてのみ引いた。
- **(S3) 幾何的障害 1 本は閉じている = 再探索していない**。⚠ 併記の宿題「`I(X;J_μ)` がチャネルに
  ついて凸」は確認済 — `p_X` 固定で `I(X;J) = H(X)_p − ∫H(X)_q dμ(q)` は `μ` について**アフィン**
  (したがって凸かつ凹) であり、劣位集合 `{I < d*}` は凸。machine: T4 の `XJ` 項の残差 (4.11e-15 に含む)。
- **(S4) 決着は反平行条件の側で付く = ❌ 訂正した**。見立ての ⚠ 部分「(20) 上側は `μ` についてアフィン
  ではなく凹包条件」は**取り違えである**: `## M12 (T3b)` 行 7 の凹包は **`∀μ` を潰したときの形**であって、
  **`μ` を固定した (20) 上側はアフィン不等式**である (machine T4 が (20a)/(20b) の上側残差まで込みで
  4.11e-15)。⟹ `E_R(w)` は**上側も含めて半空間の有限交わり**。
  ⟹ **反平行条件を書き下す前に (D2) が効いてしまい、`SR_C` 点では (20) 側の代数に入る前に決着した**。
  ⚠ **反平行条件そのものが死んだのではない** — それは `κ = 2` の**一般の**判定条件として残る (§5-d)。

## 5. 残る段 (⚠ 未決部分)

- **(a) witness 粒度を落とした被覆数 `κ'` は未決** — A1 は `w` を full witness に取る (`## M11 (T3b)` 行 4 /
  gate §0-a)。**plain `(U,V,W)` を `μ` ごとに選び直し `(hat,tilde)` だけを固定する** 読み `κ'` では、
  (19) が「`L(μ) ∈ 𝒞` (`## M11 (T3b)` 行 2 の凸体帰属)」に緩み**等式でなくなる** ⟹ (D2) が効かない
  ⟹ **`κ' = 2` は排除されていない**。⚠ `κ' ≤ κ` なので (K2) からは何も出ない。**A1 を延命させるなら
  ここが唯一の入口**である。
- **(b) `SR_C` 以外のレート点は未決** — (D4) は `2C < 和レート` を使う。和レートが `2C` 以下の点では
  uniform 到達 witness (再現 #4) が効いて `κ = 1` になる場合があるが、`R₁`/`R₂` 側の角は測っていない。
- **(c) 他チャネルは未決** — 構造補題 (再現 #2) と `2C < SR_C` の 2 つが [probc] 固有。(K1) だけは
  インスタンス非依存である。
- **(d) 反平行条件の代数は未着手** — (K1) により一般の `κ = 2` 判定は「**(19)-uniform な 2 本の
  witness の (20) + レート束の半空間系が `𝒯` を覆うか**」に落ちる (S4 の訂正後の形)。本 leg は
  `SR_C` 点で (D4) が先に効いたため、この代数へ入っていない。
- **(e) N5 への入力 (⚠ 判定は N5 の担当)** — 本インスタンスの `SR_C` 点で `κ ∈ {1, ∞}` が確定した。
  gate §5 の `inert` 条件に直接効くのはこの 1 点であり、(a)–(d) が開いている間は本 leg は
  「`κ` が 2 値へ潰れる」を**このレート点についてのみ**支持する。
