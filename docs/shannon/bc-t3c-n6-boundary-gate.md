### 2.4 ⭐ 箱の射影恒等式 — ⚠⚠ **そこから「`R0 > 0` はスライスに従属する」は導かれない (監査で覆った)**

**箱の射影恒等式** (1 行、⭐ **監査でも生存**): 任意の箱
`{R ≥ 0 : R0 ≤ A, R0+R1 ≤ B1, R0+R2 ≤ B2, 和 ≤ S}` について `R` が入るなら `(0, R0+R1, R2)` も入る
(`R0+R1 ≤ B1` / `R2 ≤ R0+R2 ≤ B2` / 和は不変 / `0 ≤ A`)。⟹ `φ(R) := (0, R0+R1, R2)` は
**個々の箱を自分自身へ写す** (`φ(B) ⊆ B`) ので、`x ∈ ⋂B_i` なら全 `i` で `φ(x) ∈ B_i` ⟹
**射影は箱の任意の合併にも交叉にもそのまま通る** (⚠ これは射影と交叉の可換性の主張では**ない**)。

⚠ **量化子の訂正 (監査)**: Theorem 7 の逐語 (`auxrec.txt:1034-1074`) は `∃p(x) ∀T_{J|X,Y,Z} ∃(aux)` なので、
正しい表示は **`Thm7 = ⋃_p ⋂_J ⋃_w (箱)`** である (本 leg は外側の `⋃_p` を落としていた)。射影の議論は

⚠⚠ **`Thm7 ⊆ D` は無条件ではない (監査の訂正)**。無条件に言えるのは

```
Thm7 ⊆ D′ := { R ≥ 0 : R0 ≤ 2C,  (0, R0+R1, R2) ∈ Thm7|_{R0=0},  (0, R1, R0+R2) ∈ Thm7|_{R0=0} }
D   := 上の Thm7|_{R0=0} を C|_{R0=0} に置き換えたもの
```

だけであり、**`D′ = D` は `Thm7|_{R0=0} ⊆ C|_{R0=0}` と同値 = N7 の問いそのもの**である
(監査の反例: 内 `= {R0≤0, R0+R1≤1, R0+R2≤1, 和≤1}`、外 `=` 同じ上限を 2 倍にしたもの。`R = (0,2,0)` は

⚠⚠ **さらに「`R0 = 0` スライスが閉じれば `R0 > 0` 方向も閉じる」も導かれない (監査の反例)**:
有理数の明示多面体 `外 = {R ≥ 0 : R0 ≤ 1/2, R0+R1 ≤ 1, R0+R2 ≤ 1, 和 ≤ 1}` と `内 =` 同じで `R0 ≤ 0` は
**`R0 = 0` スライスが集合として同一**であるにもかかわらず、方向 `(2,1,1)` の支持値が **`1.5` 対 `1.0`** で
異なる。⟹ **「スライスが閉じること」は「`R0>0` 方向が閉じること」を含意しない**。

⟹ **`R0 > 0` の錐は 2 つに分かれる** (§2.3 の F-R0MIX (a)/(b)):

## 3. gate — N7 へ渡す面 1 枚

### 3.1 選んだ面 = **F-SH1 (`R0 = 0` スライスの `R1` 側の肩、方向 `(0,1,t)`, `t ∈ (0,1)`)**

**選んだ理由 (§2.3 の判定表を根拠に、prose の印象ではなく)**:

1. ⚠⚠ **訂正済 (監査)。未着手の面は 2 枚あり、順序でこの 1 枚を先に置いた** — 表の 5 枚は (I1)–(I3) で
   無料で閉じ、F-SUM 値は (I4) で `η = 1e-13` の条件つきに閉じ、F-SUM の広がりは N1 が閉じ、
   F-R0MIX (a) (`λ0 ≥ λ1+λ2`) は無料で閉じる。⚠ **残るのは本面と F-R0MIX (b) = 「`D = C` か」の 2 枚**で
   あって 1 枚ではない (§2.4)。**本面を先に置く理由は順序である** — `D` の定義は `C|_{R0=0}` を参照する
   ので、**`R0=0` スライスが閉じるまで「`D = C` か」は空回りする** (次点の扱いは §3.5-1 と同じ)。
2. **未閉の幅が定量化できている** — T16 の `0.568 × d*`。
3. ⭐ **N1-b が問題を 1 本の凸包絡へ潰す** (下の還元)。⟹ N7 が作るものが「何を計算するか」の
   水準で確定しており、道具は §4.5 の 1 (恒等式への帰着) と 3 (閉形の手構成) だけで足りる。
4. ⭐ **N1 の道具がそのまま伸びる** — 還元後の対象は `t = 1` でちょうど N1-j の Lagrange 証明書に
   一致する。⟹ 本面は N1 の 1 パラメータ族への拡張である。

**還元 (本 leg で機械に掛けた恒等式)**。`W = const` は方向 `(0,1,t)` について WLOG である
(T11: `(U,V,W) ↦ ((U,W),(V,W),const)` の併合で `(18b)` も `(18i)` も下がらない、
最小増分 `−1.554e-15`)。⭐ **監査の訂正 (過小評価側) = これは数値ではなく 2 行の恒等式である** —
`(18b)` は `min{I(W;Y),I(W;Z)} + I(U;Y|W) ≤ I(W;Y) + I(U;Y|W) = I(U,W;Y)`、`(18i)` は
`m + min{A,B} = min{m+A, m+B} ≤ min{I(W;Z)+A, I(W;Y)+B}` (`A := I(V;Z|W)+I(X;Y|V,W)`,
`B := I(U;Y|W)+I(X;Z|U,W)`, `m := min{I(W;Y),I(W;Z)}`) ⟹ **数値は要らない**。
⚠⚠ **射程の訂正 = 併合は `(20c)` を破る** (残差が `C_a = I(W;Z) − I(W;Y)` だけずれる、実測 `|C_a|` 最大
`0.0227`) ⟹ **この WLOG は `(19)`/`(20)` を 1 本も課さない `h_free` の内側でしか成り立たない**。
その下で

```
h_free(0,1,t) = max_p [ H(Y)_p − t·H(Z|X) − conv( H(Y)_· − t·H(Z)_· )(p) ]
```

(`conv` = 4 点上の法則 `s ∈ Δ₃` の関数としての下側凸包絡、`h_free` = `(18a)/(18b)/(18e)/(18i)`
だけを課した緩和の支持関数)。⚠ **被凸包絡関数 `f_t(s) = H(Y)_s − t·H(Z)_s` は凹 − t·凹** ⟹
N1-a / N1-j が使った **DC 分枝限定がそのまま当たる**。`t = 1` で `f_1 = D` となり、
`conv(D)(一様) = −d*` から `h_free = SR_C` (T13 で機械確認)。

**C 側との突き合わせ**: `p = 一様`・4 原子族
`(X1 = c ∈ {0,1}) × (X2 ~ Bern(β) or Bern(1−β))` を取ると、`(18b) = R1(β)`, `(18i) = S(β)`,
`(20c)` 残差 `= 0` の**明示 free witness** が得られ、その箱の支持値は
**`§2.2 の C の肩の値と厳密に一致する**(T12、残差 `1.776e-15`、41 × 5 の `(β,t)` 対)。
⟹ **問いは「`conv(f_t)(一様)` がこの 4 原子族で達成されるか」の 1 点に落ちる**。

### 3.2 GO / NO-GO の判定条件 (⚠ **事前に書く**)

- **NO-GO** = `conv(f_t)(一様)` が 4 原子族の値と一致することを、**証明書つきで** (原子の全探索でなく
  `min_s [ f_t(s) − θ·s ]` の DC 分枝限定下界 + LP 双対 `θ`) `t ∈ [0,1]` 全体について示せた、
  かつ `p ≠ 一様` が上回らないことを同じ道具で押さえられた。
  ⟹ **`Thm7` の `R0 = 0` スライス ⊆ `C` の `R0 = 0` スライス**。
  ⚠ **中間段 (監査が名指しした欠落。書いておく)**: 上で直接得られるのは**支持関数の優越**
  `h_Thm7(λ) ≤ h_C(λ)` (∀`λ ≥ 0`) であって集合の包含ではない。そこから包含を出すには
  **`C` のスライスが閉・凸・下方閉**であることが要る (容量領域なので 3 つとも成り立つ) ⟹ **段は埋まる**。
  `C ⊆ Thm7` は [auxrec] Theorem 7 の逐語 (`auxrec.txt:1034-1036`「**any achievable rate triple**」)
  そのものなので常に成立 ⟹ **スライス上で両者は一致**。§2.4 の射影と合わせると、
  **残るのは `D = C` (`C` 側だけの問い) だけになる** (⚠ **「尽きた」ではない** — §2.4 の訂正)。
  ⚠ **これは [probc] 1 インスタンスの話であって `Thm7 = C` ではない**。
- **GO 候補** = ある `t` で `conv(f_t)(一様)` が 4 原子族の値より**証明書つきで厳密に下**
  ⟹ 緩和の支持値が `h_C` を厳密に超える。⚠⚠ **これは `Thm7 ⊋ C` ではない** — 緩和は `(19)`,
  `(20a)`, `(20b)` と `∀T_J` を 1 本も課していないので、**適格 witness の構成が別に要る**
  (それが N8 の [構築 + probe] の仕事になる)。本 leg の gate が渡すのは
  「**適格性が働かなければならない場所の名指し**」までである。
- ⚠ **数値掃引で「超えた」が出ても GO ではない** (§4.5)。**最適化器が出した違反も同じだけ証拠価値が低い**。
  判定入力は恒等式か閉形の証明書のみ。

⭐ **どちらに転んでも軸が 1 本確定する** (§3 の設計要件): NO-GO なら
「**[probc] インスタンスの `R0=0` スライスは尽きた**」が確定し、(C2) の還元先を反証する的は
別インスタンスか T3-β へ移る。GO 候補なら「**緩和と `Thm7` の差 = 適格性が担っている仕事**」が
初めて 1 つの数として局在する (§5.3 の型「障害の構造」の合格条件を満たす形になる)。

### 3.3 反証条件 (⚠ **先に書く**、§4.4-2) — どうなったら N7 でこの面を捨てるか

1. **DC 分枝限定が `f_t` に効かない** — `t = 1` (= N1-a / N1-j) では `64746` セルで `η = 1e-13` まで
   到達しているが、`t < 1` でセル数が桁で増えて `t` の格子を 1 本も閉じられない ⟹ 面を捨て、
   §2.3 の次点へ移る。
2. **`p ≠ 一様` が支配する** — `p` の釘付け (`## M14 (T3b)` M14-b) は `(18i) ≥ SR_C` の下でしか
   効かない。`t < 1` では `p` が自由になるので、`max_p` が 4 点単体上の非自明な最適化に化けて
   `t` ごとに別問題になるなら、面としての一体性が失われる ⟹ 捨てる。
3. **`(18c)/(18d)/(18f)/(18g)/(18h)` が肩の上で先に効く** — 緩和が `h_C` を超えても、超過が
   `J` 依存の 5 本で無条件に潰れるなら、この面は `Thm7` 側の面としては空である ⟹ 捨てる。

### 3.5 落とせなかった面 (次点)

1. **F-R0MIX (b) (`0 < λ0 < λ1+λ2`) の残り = 「`D = C` か」** (`C` 側だけの問い)。
   ⚠⚠ **これは「未着手の面 2 枚」のもう 1 枚である** (§2.4 の訂正。§3.1 の理由 1 と整合する)。
   ⚠ 選ばなかったのは **`Thm7` を 1 mm も動かさないから** — スライスが閉じない限り `D` の定義が
   空回りする。⟹ **N7 が NO-GO を返したときに初めて意味を持つ** (順序が固定されている)。
2. **`(18c)/(18d)/(18f)/(18g)/(18h)` の 5 本が肩の上で何を足すか**。緩和が `h_C` に一致するなら
   この 5 本は `R0=0` スライスで**不活性**であり、それ自体が `## M3 (T3b)` 行 1 (`(18h)` の冗長性)
   の領域版になる。⚠ 選ばなかったのは、**緩和の値が確定するまで「不活性」が言えない**から。
