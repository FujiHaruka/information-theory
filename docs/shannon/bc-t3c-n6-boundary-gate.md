## 2. `C` の境界の棚卸し — 面ごとの判定

⚠ **道具は §4.5 の 3 つだけ**。下の「閉」判定はすべて**恒等式への帰着**で書いてあり、

- **(I1)** `(18a) ≤ I(W;Y) ≤ I(X;Y) ≤ I(X1;Y1)+I(X2;Y2) ≤ 2C` (データ処理 + 積構造)。
- **(I2)** `(18b) = I(U,W;Y) + min{C_a,0} ≤ I(X;Y) ≤ 2C` (T9、残差 `1.110e-15`)。

- **(I4)** N1-b の 2 本 (T7、残差 `3.775e-15`) に包絡の上界を掛けて

### 2.2 ⭐ `C` の `R0 = 0` スライスの境界は閉形で書ける (T5、残差 `8.882e-16`)

### 2.4 ⭐ `R0 > 0` の方向は独立の面ではない — スライスに従属する

**箱の射影恒等式** (1 行): 任意の箱 `{R ≥ 0 : R0 ≤ A, R0+R1 ≤ B1, R0+R2 ≤ B2, 和 ≤ S}` について
`R` が入るなら `(0, R0+R1, R2)` も入る (`R0+R1 ≤ B1` / `R2 ≤ R0+R2 ≤ B2` / 和は不変)。
`Thm7 = ⋂_J ⋃_w (箱)` なので射影は交叉にもそのまま効く。⟹

```
Thm7 ⊆ D := { R ≥ 0 : R0 ≤ 2C,  (0, R0+R1, R2) ∈ C|_{R0=0},  (0, R1, R0+R2) ∈ C|_{R0=0} }
```

⟹ **`R0 = 0` スライスが閉じれば、残るのは `D = C` かという `C` 側だけの問い**になる。
その問いを screen したのが T18 で、7 方向 (`(1,1,1)`, `(1.1,1,1)`, `(1.2,1,1)`, `(1.5,1,1)`,
`(2,1,1)`, `(1,1,0.5)`, `(1.3,1,0.7)`) で `h_D − h_C ≤ 5.4e-8` (格子分解能の内側)。
⚠ **screen であって証拠ではない** / ⚠ **`Thm7 ⊆ D` の側は恒等式** (射影) である。

## 3. gate — N7 へ渡す面 1 枚

### 3.1 選んだ面 = **F-SH1 (`R0 = 0` スライスの `R1` 側の肩、方向 `(0,1,t)`, `t ∈ (0,1)`)**

**選んだ理由 (§2.3 の判定表を根拠に、prose の印象ではなく)**:

1. **未着手の面はここしか残っていない** — 表の 6 枚は (I1)–(I4) で閉じ、F-SUM の広がりは N1 が閉じ、
   F-R0MIX は §2.4 の射影恒等式でスライスに従属する。
2. **未閉の幅が定量化できている** — T16 の `0.568 × d*`。
3. ⭐ **N1-b が問題を 1 本の凸包絡へ潰す** (下の還元)。⟹ N7 が作るものが「何を計算するか」の
   水準で確定しており、道具は §4.5 の 1 (恒等式への帰着) と 3 (閉形の手構成) だけで足りる。
4. ⭐ **N1 の道具がそのまま伸びる** — 還元後の対象は `t = 1` でちょうど N1-j の Lagrange 証明書に
   一致する。⟹ 本面は N1 の 1 パラメータ族への拡張である。

**還元 (本 leg で機械に掛けた恒等式)**。`W = const` は方向 `(0,1,t)` について WLOG である
(T11: `(U,V,W) ↦ ((U,W),(V,W),const)` の併合で `(18b)` も `(18i)` も下がらない、
最小増分 `−1.554e-15`)。その下で

```
h_free(0,1,t) = max_p [ H(Y)_p − t·H(Z|X) − conv( H(Y)_· − t·H(Z)_· )(p) ]
```

(`conv` = 4 点上の法則 `s ∈ Δ₃` の関数としての下側凸包絡、`h_free` = `(18a)/(18b)/(18e)/(18i)`
だけを課した緩和の支持関数)。⚠ **被凸包絡関数 `f_t(s) = H(Y)_s − t·H(Z)_s` は凹 − t·凹** ⟹
N1-a / N1-j が使った **DC 分枝限定がそのまま当たる**。`t = 1` で `f_1 = D` となり、
`conv(D)(一様) = −d*` から `h_free = SR_C` (T13 で機械確認)。

**C 側との突き合わせ**: `p = 一様`・4 原子族
`(X1 = c ∈ {0,1}) × (X2 ~ Bern(β) or Bern(1−β))` を取ると、`(18b) = R1(β)`, `(18i) = S(β)`,
`(20c)` 残差 `= 0` の**明示 free witness** が得られ、その箱の支持値は
**`§2.2 の C の肩の値と厳密に一致する**(T12、残差 `1.776e-15`、41 × 5 の `(β,t)` 対)。
⟹ **問いは「`conv(f_t)(一様)` がこの 4 原子族で達成されるか」の 1 点に落ちる**。

### 3.2 GO / NO-GO の判定条件 (⚠ **事前に書く**)

- **NO-GO** = `conv(f_t)(一様)` が 4 原子族の値と一致することを、**証明書つきで** (原子の全探索でなく
  `min_s [ f_t(s) − θ·s ]` の DC 分枝限定下界 + LP 双対 `θ`) `t ∈ [0,1]` 全体について示せた、
  かつ `p ≠ 一様` が上回らないことを同じ道具で押さえられた。
  ⟹ **`Thm7` の `R0 = 0` スライス ⊆ `C` の `R0 = 0` スライス**。`C ⊆ Thm7` は外界なので常に成立
  ⟹ **スライス上で両者は一致**。§2.4 の射影と合わせると、残るのは `D = C` (`C` 側だけの問い) だけになる。
  ⚠ **これは [probc] 1 インスタンスの話であって `Thm7 = C` ではない**。
- **GO 候補** = ある `t` で `conv(f_t)(一様)` が 4 原子族の値より**証明書つきで厳密に下**
  ⟹ 緩和の支持値が `h_C` を厳密に超える。⚠⚠ **これは `Thm7 ⊋ C` ではない** — 緩和は `(19)`,
  `(20a)`, `(20b)` と `∀T_J` を 1 本も課していないので、**適格 witness の構成が別に要る**
  (それが N8 の [構築 + probe] の仕事になる)。本 leg の gate が渡すのは
  「**適格性が働かなければならない場所の名指し**」までである。
- ⚠ **数値掃引で「超えた」が出ても GO ではない** (§4.5)。**最適化器が出した違反も同じだけ証拠価値が低い**。
  判定入力は恒等式か閉形の証明書のみ。

⭐ **どちらに転んでも軸が 1 本確定する** (§3 の設計要件): NO-GO なら
「**[probc] インスタンスの `R0=0` スライスは尽きた**」が確定し、(C2) の還元先を反証する的は
別インスタンスか T3-β へ移る。GO 候補なら「**緩和と `Thm7` の差 = 適格性が担っている仕事**」が
初めて 1 つの数として局在する (§5.3 の型「障害の構造」の合格条件を満たす形になる)。

### 3.3 反証条件 (⚠ **先に書く**、§4.4-2) — どうなったら N7 でこの面を捨てるか

1. **DC 分枝限定が `f_t` に効かない** — `t = 1` (= N1-a / N1-j) では `64746` セルで `η = 1e-13` まで
   到達しているが、`t < 1` でセル数が桁で増えて `t` の格子を 1 本も閉じられない ⟹ 面を捨て、
   §2.3 の次点へ移る。
2. **`p ≠ 一様` が支配する** — `p` の釘付け (`## M14 (T3b)` M14-b) は `(18i) ≥ SR_C` の下でしか
   効かない。`t < 1` では `p` が自由になるので、`max_p` が 4 点単体上の非自明な最適化に化けて
   `t` ごとに別問題になるなら、面としての一体性が失われる ⟹ 捨てる。
3. **`(18c)/(18d)/(18f)/(18g)/(18h)` が肩の上で先に効く** — 緩和が `h_C` を超えても、超過が
   `J` 依存の 5 本で無条件に潰れるなら、この面は `Thm7` 側の面としては空である ⟹ 捨てる。
