### 見立て A (**緩める**) — 現行 [probc] more-capable インスタンスでも `UV ⊋ C` が立つ

理由 = [probc] の寄与そのものが「**容量が既知でありながら UV と一致しないクラス**」の構成であり、その厳密性を
生む機構は **UV がブロック間で相関した補助変数を許す**ことである (facts [`bc-facts.md`](bc-facts.md)
`## M5 (T3b)` = 争点が優加法性と同型であるという判定)。**more-capable 積でも積構造は同じ**なので同じ機構が
効く公算がある。⚠ **`C` 側が超加法性の分だけ持ち上がっていることは分かっている**が (facts `## M1 (T3b)` の
副産物行 = [probc] Lemma 8 の閉形。⚠⚠ **値はここへ写さない**)、⚠ **`UV` 側が同じ量ちょうどしか持ち上がらない
理由は無い**。

**殺す道具 (§4.4-2 の義務どおり着手前に決めた)** = **§4.5 の道具 1 (恒等式への帰着)** — 「相関補助変数の利得が
**UV の制約の側で**恒等式により潰れる」ことを示せれば A は死ぬ。
⚠⚠ **道具 2 / 道具 3 では A を殺せない** — 明示 witness の直接評価 (道具 3) は `UV ⊋ C` を**立てる**方向にしか
効かず、**「witness が見つからない」は §4.5 により証拠価値がほぼ 0** である。⟹ **A を殺すのは恒等式だけである**。

### 見立て B (**締める**) — 本 gate はどちらの側も返せず「開いている」で終わる

理由 = N15 成果物 §6-8 と N15 監査 §5-5 が**独立に攻めて settle できなかった**と明記しており、しかも監査は
[probc] 内の strictness の言明を**全走査**している (= **文献側の材料は尽きている**)。⟹ `UV` の支持関数を
自前で評価するしかなく、それは N15 §6-2 (「`Thm7` の値を 1 つも計算していない」) と同じコストの側にある。

**着手前の 1 行反証 (§4.4-1 の義務)** = ⚠ **本 gate が要るのは `UV` と `C` の比較であって `Thm7` の値ではない**。
しかも `UV ⊋ C` の側は**片側**でよい — N15 は [glnsum] 側で**明示 witness 1 本の直接評価**だけで `UV ⊋ C` を
立てている (facts `## N15 (T3c)` の **N15-c**) ⟹ **同型の片側評価は [probc] インスタンス上でも成り立ちうる**
⟹ **B は無条件には成り立たない**。
⚠ **裏取りの状態を正直に書く**: この反証が引く片側評価は **facts N15-c の再検証コマンド (検証器 `G4`) が
[glnsum] 側で機械に持っている**形であって、⚠⚠ **[probc] インスタンス上で同型の witness が実際に構成できるかは
別問題である** (それは本 leg の仕事であり、起票時点では裏が無い)。
⚠ **逆側 (`UV = C`) は全 witness にわたる主張ゆえ片側評価では出ない** ⟹ **B は「`UV = C` の側は本 leg では
出ない公算が高い」という弱い形でなら生き残る** (⚠ **その弱い形を判定するのは §1-(b) の反証条件 1 である**)。

### 見立て C (**締める**) — `UV = C` が出ても較正は [probc] の 1 点の上に限られ、N10 の半空間全体には及ばない

理由 = N15-h が名指した問いの主語は「**現行 [probc] more-capable インスタンス**」= **1 点**である。一方
N10 の決着の射程は**半空間 `e ≤ h(p)` の全体**へ広がっている (親 plan §7 判断ログ 7、逐語の SoT = facts
`## N10 (T3c)`)。⟹ **1 点で `UV = C` が出ても、挟み込みが `Thm7 = C` を強制するのはその点の上だけ**であり、
**半空間の内部では `UV` を別に評価する必要が残る**。

**着手前の 1 行反証 (§4.4-1 の義務)** = 挟み込み `C ⊆ Thm7 ⊆ UV` の 2 本は**チャネルにもレートにも仮説を
持たない** (facts `## N15 (T3c)` の **N15-b** が逐語 2 本で確認済) ⟹ **`UV = C` が半空間の全体で立つなら
`Thm7 = C` も全体で強制され、C の言う「1 点に限られる」は崩れる** ⟹ **C が成り立つのは `UV = C` が 1 点
(あるいは半空間の真部分) でしか立たない場合に限る**。
⟹ ⚠⚠ **C を生かすも殺すも、`UV` 側の判定が `(p,e)` にどう依存するかを見なければ決まらない** —
⚠⚠ **1 点の判定を半空間へ黙って延長するのが本 leg の最大の誤り方**であり、**C はそれを先に名指しするために
置いた見立てである**。

### 見立て D (**締める**) — `UV` の版の取り違えで gate が空回りする

理由 = `UV` には**一般 witness 版**と**独立版** (`p(u)p(v)p(w|u,v)`) の 2 つがあり、facts `## M1 (T3b)` は

版を固定せずに問うと**答が 2 通りある**。

**着手前の 1 行反証 (§4.4-1 の義務)** = 本 gate の挟み込みが使う `UV` は **N15 §2.1 が版を明示して照合した
一般 witness 版**であり (facts N15-b)、⚠ **`Thm7 ⊆ UV` が成り立つのもその版である** ⟹ **本 gate が問うべき
版は一意に決まっている** ⟹ **D は無条件には成り立たない**。
⚠ **弱い形では生き残る** — `O_indep ⊆ UV_general` ゆえ、⚠⚠ **文献が `O_indep = C` を言っていても
`UV_general = C` は従わない**。⟹ **一次文献の言明を引くときに版を確認する義務は残り、それは §1-(b) の

### 3.1 段 1 — `R0 = 0` のスライス (**道具 1**)

§2.4 より `UV` の各箱は (18b) と (18i) を満たす。方向 `(0,1,t)`, `t ∈ [0,1]` に対し

  `R1 + t·R2 = (1−t)·R1 + t·(R1+R2) ≤ (1−t)·(18b) + t·(18i)`  (⚠ `R0 ≥ 0` を使う。検証器 `B2`、厳密有理)

右辺は `(18i) ≤ min{I(W;Y),I(W;Z)} + I(U;Y|W) + I(X;Z|U,W)` を経て `U' := (U,W)` の併合で

  `≤ I(U';Y) + t·I(X;Z|U') = H(Y)_p − t·H(Z|X) − E[f_t(s_{U'})] ≤ H(Y)_一様 − t·H(Z|X) − min_s f_t(s)`

⚠ **この 2 段が使うのはインスタンスの 2 性質だけ**である: **`H(Z|X=x)` が 4 入力すべてで定数**
(検証器 `D2`、`h(e)+h(p)`) と **`H(Y)_p ≤ H(Y)_一様`** (検証器 `D3`。証明は `H(Y1Y2) ≤ H(Y1)+H(Y2) ≤ 最大`

そして ⭐ **各点で成り立つ恒等式** (検証器 `D4`、20000 点で残差 `4.441e-16`):

  `H(Y)_一様 − t·H(Z|X) − f_t(s) = I(X;Y)_一様 + [t·I(X;Z)_s − I(X;Y)_s]`  (**全ての `s` で成立**)

⟹ 右辺の `s` 上の最大が定義により `I(X;Y)_一様 + Ω(t)` である ⟹ ⚠ **最小化 / 最大化を 1 度も実行せずに**

  **`h_UV(0,1,t) ≤ I(X;Y)_一様 + Ω(t)`**

が出る。`I(X;Y)_一様 = C1 + C2` (検証器 `D4b` / `D11`。曲線 `e = h(p)` の上では `= 2C`)、
`Ω(t) = d*_t` は facts `## N10 (T3c)` N10-a からの**引用** (⚠ **本 leg は再導出していない**) ⟹

### 3.2 段 2 — 枝 (ii) の錐 (**道具 1**。⚠ 本 leg が新たに書いた恒等式)
