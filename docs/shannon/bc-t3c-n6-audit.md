## 2. 標的 2 (⭐⭐⭐ §2.4 の射影恒等式) — **試行 6 系統。恒等式は生存、そこからの帰結は覆った**

### 結果

**(1)(2) ⭐ 射影恒等式は生存。⚠ ただしブリーフが指定した攻撃 (交叉と可換でない) は的外れである。**
`φ(R) := (0, R0+R1, R2)` は**個々の箱を自分自身へ写す** (`R0+R1 ≤ B1` / `R2 ≤ R0+R2 ≤ B2` / 和は不変 /
`0 ≤ A`)。⟹ `φ(B) ⊆ B` が各箱で成り立つので、`x ∈ ⋂B_i` なら全 `i` で `φ(x) ∈ B_i`、
すなわち **`φ` は合併にも交叉にもそのまま通る**。これは射影と交叉の可換性の主張では**ない**ので、
「射影は交叉と可換でない」は本件に当たらない。20000 組で違反 0 (`C1`)。

**(6) ⚠ 精度の訂正 (訂正 2)。** Theorem 7 の逐語 (`auxrec.txt:1034-1074`) は
`∃p(x) ∀T_{J|X,Y,Z} ∃(aux 分布)` であり、正しくは **`Thm7 = ⋃_p ⋂_J ⋃_w (箱)`** である。
N6 §2.4 は **`Thm7 = ⋂_J ⋃_w (箱)`** と書いて外側の `⋃_p` を落としている。
⚠ **射影の議論は壊れない** (`φ` は箱ごとに効くので合併が 1 段増えても同じ) が、
`∃p ∀T_J ∃aux` は T3 家系の争点そのものなので、表示は正しく書くべきである。

**(3) ⚠⚠ 訂正 3 = 主判定の一部が覆った — 射影恒等式から「`R0>0` は独立の面ではない」は出ない。**
反例 (`C2`、有理数の明示多面体。最適化器を一切使っていないので未収束の artefact ではありえない):

```
外  = {R ≥ 0 : R0 ≤ 1/2, R0+R1 ≤ 1, R0+R2 ≤ 1, 和 ≤ 1}
内  = {R ≥ 0 : R0 ≤ 0,   R0+R1 ≤ 1, R0+R2 ≤ 1, 和 ≤ 1}
```

両者の `R0 = 0` スライスは**集合として同一**である。にもかかわらず方向 `(2,1,1)` の支持値は
**`1.5` 対 `1.0`** で異なる。⟹ **「スライスが閉じること」は「`R0>0` 方向が閉じること」を含意しない**。
⟹ 台帳 N6-g の見出し「`R0 > 0` の方向は独立の面ではない」と §2.3 判定表の
「**スライスに従属** (§2.4)」は、射影恒等式からは**導かれない**。

**(4) ⚠ 訂正 4 — `Thm7 ⊆ D` は無条件ではなく、gate が問うている当のものに条件づいている。**
反例 (`C3`): 内 `= {R0≤0, R0+R1≤1, R0+R2≤1, 和≤1}`、外 `=` 同じ上限を 2 倍にしたもの。
`R = (0,2,0)` は外に入るが、その射影 `(0,2,0)` は内の `R0=0` スライスに入らない ⟹ `R ∉ D`。
⟹ **無条件に言えるのは `Thm7 ⊆ D′`** (`D′` は `C|_{R0=0}` を **`Thm7|_{R0=0}`** に置き換えたもの) **だけ**であり、
`D′ = D` は **`Thm7|_{R0=0} ⊆ C|_{R0=0}`** と同値 = **N7 の問いそのもの**である。
⚠ N6 §2.4 は直後の文 (「`R0=0` スライスが閉じれば…」) で条件性を担っているが、**表示された包含式は無条件形**で
書かれており、台帳 N6-g の notes も「⚠ **`Thm7 ⊆ D` は恒等式**」と無条件に書いている。

**(5) ⭐⭐ 訂正 5 — 逆に、`λ0 ≥ λ1 + λ2` の錐は「従属」ではなく *無料で閉じている* (N6 の過小評価)。**
任意の `λ ≥ 0` について `λ·R = λ1(R0+R1) + λ2(R0+R2) + (λ0−λ1−λ2)R0` と分解できるので、
**`λ0 ≥ λ1+λ2` なら (I1)/(I2)/(I3) だけで `h_Thm7(λ) ≤ 2C·λ0`**、かつ `C` 側は `(2C,0,0)` が
**厳密に達成する** ⟹ **両側 `= 2C·λ0` の恒等式**である (`C4`、3000 方向で残差 `< 1e-12`)。
さらに `h_D(1,1,1) = h_C(1,1,1) = SR_C` も射影から**恒等式**で出る (`C5`)。
⟹ **T18 が screen した 7 方向のうち `(1,1,1)` と `(2,1,1)` の 2 本は screen ではなく恒等式**であり、
screen 止まりなのは残り 5 本 (`(1.1,1,1)`, `(1.2,1,1)`, `(1.5,1,1)`, `(1,1,0.5)`, `(1.3,1,0.7)`) である。

### 主判定への効き

⟹ **「未着手の面は `R0 = 0` の肩 1 枚に落ちた」は成り立たない**。正しくは:

- `λ0 ≥ λ1+λ2` の錐: **無料で閉** (新規、上の訂正 5)。
- `0 < λ0 < λ1+λ2` の錐: 射影で **`C` 側だけの問い「`D = C` か」へ還元される**が、
  **その問いは未着手のまま残っている** (screen が 5 方向あるだけ)。
- `R0 = 0` スライスの肩: 未着手 (gate が選んだ面)。

⟹ 未着手の面は **2 枚** (肩 + `D = C`) であり、N6 が 1 枚に落としたのは **順序を固定した結果**であって
射影が 1 枚を消した結果ではない。⚠ **N6 自身の §3.5-1 は `D = C` を「次点 1」として挙げており**、
§3.1 の理由 1 (「未着手の面はここしか残っていない」) と**文書内で食い違っている**。
⚠⚠ **これは gate の選択を無効にしない** — 順序 (「スライスが閉じるまで `D` の定義が空回りする」) は
それ自体が妥当な理由であり、**選定は生存する**。覆ったのは「1 枚しかない」という数え方だけである。
