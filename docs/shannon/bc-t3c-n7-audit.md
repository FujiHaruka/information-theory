## 1. 標的 1 (⭐⭐⭐ 分枝限定エンジンそのもの) — **試行 4 系統 / 約 99 万プローブ。生存**

N7 のやり残し 3 が「第 2 の実装は誰も書いていない」と名指しした点である。

### 破りに振った試行

1. **独立な下界法を 1 つ自前で実装した** (§1-1) — N7 の DC 分解とは**機構が違う**もの。
2. **反例の直接探索** — Dirichlet 掃引 + Nelder-Mead 多点開始 + 境界に張りついた構造族。
3. **面を別の代数へ潰して探索し直した** (§1-2) — 同じ集合を違う座標で見る。
4. **`ε` を厳密 0 にする十分条件を立てて、それを反証した** (§1-3)。

### 1-1 独立に実装した下界の方法 (⚠ ここが本監査の中心)

**1 文字ずつの割線 / 接線によるアフィン緩和。** 出力法則 `q = sM` は `s` についてアフィンなので、
単体セルの上で各座標 `q_j` の値域は頂点値の `[min, max]` に**厳密に一致する**。
凹なスカラー関数 `q ↦ −q log q` に対し、その区間上では

- **弦が下界** ⟹ `+H_Y` 側の 6 文字にはこれを使う、
- **中点接線が上界** ⟹ `−t·H_Z` 側の 6 文字にはこれを使う。

どちらも `q` についてアフィン ⟹ `s` についてアフィン ⟹ 緩和全体がアフィンで、
セル上の最小は頂点にある。分岐は最長辺の 2 等分。

⚠ **`H_Y` / `H_Z` を単体上の凹関数として扱う議論も、DC 分解も、1 度も使っていない**。
N7 は「単体上の凹性 + 頂点最小原理 + 接平面」で 1 本の緩和を作るが、本実装は
「文字ごとのスカラー凹性」だけで作る。⟹ **実装の誤りを共有しえない**。

|---|---|---|

| `0.1462` | `−8.180e-10` | `1259` |
| `0.3` | `−9.633e-10` | `4141` |

`tol = 1e-9` で 7 点すべて**ちょうど `F*(t) − tol`** に着地した ⟹ **`min_s f_t = F*(t)` が
独立に確認された** (A11)。⚠ セル数は N7 の報告値と 1–2 桁違うが、これは緩和の強さの差であって
値の差ではない (§8 に別途記載)。

**反例探索**: 7 個の `t` × (Dirichlet 掃引 + Nelder-Mead 40 restart + 対数格子の構造族) =
**507,535 プローブ**。最良の余裕は `−1.082e-15` (float64 のノイズ) で、
達成点は `s = (0.4612, 0.0388, 0.4612, 0.0388)` = **予想どおりの最小化子**であった (A12)。
探索段階ではさらに繊維格子 `1.29e8` 点を掃いたが、負の余裕は 1 点も出ていない。

⚠ **これは「未収束の artefact ではない」側の確認である** — 反例が出なかった方向なので、
親 plan §4.5 の「数値掃引の非違反は証拠価値がほぼ 0」がそのまま当たる。
**証拠価値を担っているのは上の表 (独立エンジンの下界) の方**であって掃引ではない。

### 1-2 面を別の代数へ潰した (独立性を上げるための座標変換)

`X = (X1,X2)` のブロック構造から、**恒等式**

```
Ω(t) = max_s [ ψ_t(b) − G_t(s) ],   G_t(s) := I(X1;Y1|Y2) − t·I(X1;Z1|Z2),  b = P(X2=1)
```

が立つ (A13、残差 `1.582e-15`)。導出は `I(X;Y) = I(X1;Y1)+I(X2;Y2) − I(Y1;Y2)` と
`I(X1;Y1|Y2) = I(X1;Y1) − I(Y1;Y2)` (`Y1 ⊥ Y2 | X1` による) の 2 行だけ。
`Y1 = BEC` なので `I(X1;Y1|W) = C·H(X1|W)`、`Z2 = BEC` なので
`I(X1;Z1|Z2) = e·I(X1;Z1) + C·I(X1;Z1|X2)` がどちらも厳密に成り立つ。

⟹ 面は `b` を固定した 2 次元繊維の族に分解でき、`6 × 401 × 201 = 483,606` 点の繊維格子で
`d*_t − [ψ_t(b) − G_t]` の最小は `+3.220e-16` (A13)。**負にならない**。

### 1-3 ⚠ `ε` を厳密 0 にする十分条件 — **立てて、反証した**

`I(X1;Z1|Z2) ≥ 0` なので `t ∈ [0,1]` で `G_t ≥ G_1`。⟹ **`G_1 ≥ 0` が全 `s` で成り立てば
`Ω(t) ≤ max_b ψ_t(b) = d*_t` が全 `t` で一斉に出る = 格子も分枝限定も要らず `ε` は厳密 0**。

⚠ **これは偽である**。**有理数の明示構成**: `s = (0, 3/8, 1/2, 1/8)` で

```
G_1 = −0.00130749 < 0
```

(A20)。さらに `G_1` は族 `{X2 ~ 一様, X1 = X2 ⊕ Bern(q)}` の上で **`q` によらず恒等的に 0**
(5 個の `q` で `|G_1| = 0.000e+00`) ⟹ この不等式は**剃刀の刃の上**にある。

⚠ **証明書は壊れていない** — その `s` での `Ω(1) = +0.00130749` に対し `d*_1 = 0.03877137` なので
余裕は `+0.037464` ある。⟹ **反証したのは私の近道であって N7 の判定ではない**。

⚠ **やり残し 1 への効き**: N7 が「厳密 0 に必要」と書いた `argmin_s f_t` の解析的決定は、
上の恒等式によって **`t` を含まない 3 変数の不等式 `G_1(s) ≥ ψ_1(b(s)) − d*_1`** と同値になる。
⚠⚠ **これは「あと少し」ではない** — 対象が小さくなっただけで、その不等式は未証明であり、
等号が 1 パラメータ族全体で立つ以上、易しい対象である保証は何もない。

## 2. 標的 2 (⭐⭐⭐ `Ω(t)` の凸性と区間内挿) — **試行 10 系統。値は生存、論法の記述を訂正**

### 破りに振った試行

1. **凸性の向きを検算した** — 上界として使いたい向きと一致しているか。
2. **`ε` を独立に再計算した** (連続体上の厳密上限)。
3–6. **`C` 側下界の `β` 族を 1 / 2 / 3 / 9 点に変えて再計算した** (どの読みが `2.0786e-07` を出すか)。
7–10. **一様格子 4 本 (`41/81/161/321` 点) で `ε ∝ δ²` の表を再現した**。

### 結果 1 (⭐ 凸性の向きは正しい)

`Ω(t) = max_s [t·I(X;Z)_s − I(X;Y)_s]` は `s` 固定で `t` にアフィンな関数の上限なので凸。
凸関数は**格子区間の上で弦の下**にあり、**弦は上界**として使いたい向きと一致する。
さらに N7 が持つのは格子点での**上界** `Ω̄_i ≥ Ω(t_i)` だけだが、
`Ω̄` の弦 ≥ 真値の弦 ≥ 区間上の `Ω(t)` なので、そこも通る。⟹ **論理は健全**。

### 結果 2 (⚠⚠ 訂正 — §2.4 / N7-e の文言が、報告された数値を出す論法と一致しない)

§2.4 は「`ψ_t(β)` は `β` 固定で `t` についてアフィン ⟹ 区間上で差はアフィン ⟹ **端点だけで尽きる**」
と書く。⚠ **これを文字どおり (区間ごとに `β` を 1 つ固定) 実行すると `ε = 8.2155e-07` になる** — 
報告値の **4 倍悪い** (A14)。

`2.0786e-07` が出るのは、`C` 側下界を**複数の `β` のアフィン関数の上包絡**に取る読みのときだけである。
そのとき差は**区分アフィン (凹)** になり、最大は「端点**または折れ点**」で取る
(= §2.4 の「`β` witness の交点」が指しているもの)。区間あたりの `β` 点数を増やすと:

| `C` 側下界の `β` 族 | `ε` |
|---|---|
| 1 点固定 (§2.4 の逐語) | `8.2155e-07` |
| 2 点 | `4.1357e-07` |
| 3 点 | `2.087102e-07` |
| **N7 の報告値** | **`2.0786e-07`** |
| 9 点 | `2.076361e-07` |
| 連続体 (厳密上限) | **`2.072916e-07`** (`t = 0.497905`) |

⟹ ⭐ **N7 の `2.0786e-07` は妥当かつやや保守的**であり、厳密上限との差は `0.3 %`。
⚠ **訂正されるのは文言だけで、`ε` の値は動かない**。

⚠ **最悪 `t` は訂正する**: N7 は `0.49895` と書くが、連続体上の厳密な argmax は **`0.497905`**
であり、どちらも格子点ではない (格子は `t_39 = 0.495793`、`t_40 = 0.5`)。
⟹ **N7 が報告した最悪 `t` は「端点だけで尽きる」論法の出力ではありえない** — 区間内部の点である。
これも上の「区分アフィンの読みが正しい」ことの傍証になっている。

### 結果 3 (⭐ 一様格子の表を再現)

| 点数 | 本監査 | N7 の報告 |
|---|---|---|
| `41` | `6.8467e-05` | `6.96e-05` |
| `81` | `1.7555e-05` | `1.76e-05` |
| `161` | `4.4457e-06` | `4.46e-06` |
| `321` | `1.1193e-06` | `1.12e-06` |

比は `3.90 / 3.95 / 3.97` (`δ²` なら 4) ⟹ **`ε ∝ δ²` は生存** (A15)。
⚠ 一様格子の argmax は `t = 0.9876 … 0.9984` と `t = 1` 側に寄る ⟹
**「`Ω″` が `t = 1` 側で大きいので勾配をつけた」という N7 の設計判断も裏が取れた**。

## 3. 標的 3 (⭐⭐ Klein 群の 1 行恒等式) — **試行 2 系統 (32,000 検査)。生存**

### 破りに振った試行

1. **群が `Y` 側と `Z` 側の**両方**の出力エントロピーを保つかを機械で測った** — チャネルが群作用と
   可換でなければここで崩れ、`conv` が `min` に潰れず §2 全体が崩れる。
2. **軌道の重心が本当に一様かを測った**。

### 結果 (⭐ 生存)

`4000` 個の法則 × 4 個の群元 × 2 受信機 = **32,000 検査**で
`max |H(s∘τ_a) − H(s)| = 1.332e-15`、`max |重心 − 一様| = 1.110e-16` (A2)。

**理由も通る**: `X1` の反転は `BEC` の出力アルファベット `{0,1,?}` の `0↔1` 置換を、
`BSC` の `{0,1}` の置換を誘導するだけで、`?` は固定される。⟹ **どちらのチャネルも入力ビット反転と
出力の置換で可換** ⟹ `H(Y)_s` も `H(Z)_s` も保たれる。Klein 群は `{0,1}²` に単純推移的に作用するので
軌道の重心は一様。⟹ `conv(f_t)(一様) ≤ (1/4)Σ_a f_t(s∘τ_a) = f_t(s)` が全 `s` で立ち、
`conv ≥ min` と合わせて等号。**N7-c は正しい**。

## 5. 標的 5 (⭐⭐ 上界の連鎖と `(18b)`/`(18i)` の逐語) — **試行 4 系統 (1200 witness + 逐語 3 本)。生存**

`(U,V,W) −− X −− (Y,Z)` のマルコフ性が読み取れる。

**連鎖の 3 段** (各 400 witness、補助変数の基数 1–3 をランダムに):

| 段 | 最大の超過 / 残差 |
|---|---|

⚠ 2 つの緩和 (`H(Y)_p ≤ H(Y)_一様` と `E[f_t] ≥ min_s f_t`) は**同時にはタイトでない**が、
和はタイトになる。⟹ N7-b の「導出はチャネル非依存」は正しいが、

## 7. 標的 7 (⭐ 許容差の伝播) — **試行 3 系統 (6 回の許容差ラダー + 400 点の多倍長比較)。生存**

## 8. 標的 8 (⭐ 反証条件 1 の扱い) — **試行 7 系統。面は生存、⚠⚠ 原因の帰属は覆った**

### 破りに振った試行

1–4. **自前エンジンで帯 `t ∈ {0.05, 0.1, 0.1462, 0.2}` を `tol = 1e-11 / 1e-12` まで締めた**。
5–7. **N7 が §2.3 で述べた DC 規則を自前コードで再実装し、接平面評価点の混ぜ方だけを変えて比較した**。

### 結果 1 (⭐ 面は捨てなくてよい、ただし理由は N7 より強い)

自前エンジンでは帯にセル爆発が**起きない** (A18):

| `t` | `tol = 1e-11` | `tol = 1e-12` |
|---|---|---|
| `0.05` | `1499` セル | `1669` セル |
| `0.1` | `1547` セル | `1717` セル |
| `0.1462` | `1559` セル | `2431` セル |
| `0.2` | `3767` セル | `4965` セル |

⟹ **帯は `tol = 1e-12` でも閉じる**。N7 の「`tol = 1e-9` で 321 点中 321 点が閉じたので面は捨てない」
という結論は生存し、しかも**より強い形で**生存する。

### 結果 2 (⚠⚠ 訂正 — N7-h / §3-1 の因果帰属は誤り)

N7-h は爆発の原因を「`d*_t` が小さく最小点が単体の**頂点**に貼りつくため、
頂点近傍でエントロピーの曲率が発散すること」と書く。⚠ **これは違う** — 自前エンジンは
**同じ幾何・同じ最小化子・同じ曲率発散**に当たったうえで爆発しない。

原因を機械で特定した。§2.3 の「接平面の評価点は重心を一様分布と **`1e-9`** で混ぜて内点に保つ」の
**絶対値の混合定数**である。N7 の規則を自前コードで再実装して混ぜ方だけを変えると:

| 混ぜ方 | `t = 0.05` | `t = 0.1462` |
|---|---|---|
| **絶対 `1e-9`** (N7 の逐語)、`tol = 1e-10` | `1327` セルで閉じる | `1445` セルで閉じる |
| **絶対 `1e-9`**、`tol = 1e-11` | ⚠ **閉じない** (`60001` セルで打ち切り) | ⚠ **閉じない** |
| **セル径相対**、`tol = 1e-12` | `1635` セルで閉じる | `2405` セルで閉じる |

⟹ **N7 が報告した崖 (`1e-10` は閉じる / `1e-11` は打ち切り、しかも帯だけ) が逐語で再現し、
混合をセル径相対にするだけで完全に消える**。機構は「セル径が `1e-9` を下回ると接平面の評価点が
セルの外へ `1e-9` 押し出され、緩和がそれ以上締まらなくなる」ことである
(下界が `F* − 1.9e-11` / `−4.0e-11` で停止するのがその指紋)。

⚠ **健全性は壊れていない** — 接平面はどの内点で取っても大域上界なので、下界は下界のままである。
⚠⚠ **ただし `tol = 1e-9` の本掃引は、このエンジン床のすぐ上に座っている**。
`ε` は内挿の 2 次項で決まるので実害は無いが、「`tol` を締める価値も無い」という N7-h の一文は
**「締められない理由が問題側にある」と読ませる点で誤り**である (エンジン側の 1 行で締まる)。

### 結果 3 (⚠ 訂正 — `β*_t` の値、5 桁のずれ)

N7-h / §3-1 は「`t = 0.1` で `β*_t ≈ 1.5e-10`」と書く。⚠ **正しくは**:

```
β*_(t = 0.1)      = 4.203241e-15   (d*_0.1 = 3.2200e-16)
β*_(t = 0.146201) = 1.467811e-10   ← 1.5e-10 はこちら
```

`0.146201 = (1/320)^{1/3}` は**格子の第 1 点**である ⟹ N7 は `t = 0.1` と格子第 1 点の値を
取り違えている (A19)。⚠ **`ε` には影響しない**。
同じ理由で「`d*_t` がこの帯で `~1e-15` まで小さく」も帯の上端付近でしか当たらない
(`t = 0.05` では `6.8e-31`)。

### 結果 4 (⚠ 訂正 — 内部不整合、非実質)

§2.3 のアンカー 2 本は証明書の下界と既知値の差が `t = 0` で `1.0e-11`、`t = 1` で `9e-12` である。
