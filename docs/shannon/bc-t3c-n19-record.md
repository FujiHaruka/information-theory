### 見立て A (**締める**) — 較正は「前 relay の全件命題が再現したか」の形では書けない ⟹ 母集団を 2 欄に割る義務が立つ

1. **母集団の作り方が前 relay と違う**。前 relay の母集団 B は facts の各節から「義務を締める方向の見立て」を
   **事後に**拾ったもの (定義と抽出の SoT = 前 relay proof-log §3 冒頭 + §3.1)。本 relay の r19–r22
   (N15 / N16 / N17 / N18) は §4.4-2 の義務で **起票 md の §0 に向きタグつきで着手前に凍結**され、しかも
   §4.4-1 が締める側に **着手前の 1 行反証**を課している ⟹ ⚠⚠ **その義務そのものが交絡である**
   (親 plan §5.1 の N12 着地ブロックが既に名指し。⚠ **逐語はここへ複製しない**)。
2. **relay 内でも見立ての形式が一様でない**。起票 md を持たない leg (親 §5.1 の N12 着地ブロックが
   「**N8 には反証条件も見立ても書かれていなかった**」と名指し) と、6 本立ての leg (N10) と、
   4 本立ての凍結型 (N15–N18) が混在する ⟹ **relay 全体で 1 つの比率を出すと、分母が形式の違いを吸収する**。
3. **前 relay §10 が名指しで禁じた形にちょうど当たる** — 「母集団を書かずに数だけ書く」。
   ⚠ **前 relay は母集団が 2 種類だったが、本 relay は leg ごとに違う公算がある**。

⟹ **A が主張するのは**: 記録は較正欄を **(i) 凍結型 4 leg / (ii) それ以外**の 2 欄に割り、
**各欄に母集団の定義と抽出コマンドを併記する義務**を負う。⚠⚠ **relay 全体の単一の比率を書いてはならない**。

**実行 leg が着手前に機械へ掛ける 1 行の反証 (§4.4-1 の義務。⚠ 起票では実行していない)**:

```bash

```

⟹ ⭐ **t3c の成果物で見立てが同一形式 (本数が揃い、全件に向きタグが付く) に揃っていれば、母集団は 1 つでよく
A は死ぬ**。⚠ **A は締める側ゆえ §4.4 の非対称性が効く** — 前 relay の実測では締める向きの見立ては
**例外なく機械が覆している** (SoT = 前 relay proof-log §3.1) ⟹ ⚠ **A も覆る側が既定である**。

### 見立て B (**締める**) — 層 3 の到達点は `@[entry_point]` の本数では書けない ⟹ 3 欄が要る

理由 3 点:

1. **親 plan §5「relay 終端の棚卸し」の層 3 の本数は「N16 着地時点」と明示的にラベルされている**
   ⟹ ⚠ **stale ではなく、その時点の正直な棚卸しである**。⚠⚠ **しかし relay 終端の数としてそのまま写すと
   誤りになる** — その後 N17 が `InformationTheory/Shannon/BroadcastChannel/Thm7Region.lean` を**新設**し、
   N18 が同ファイルへ追記している。⚠⚠ **正しい本数はここでは決めない — 実行 leg が機械で数える**。
2. **本 relay は層 3 に初めて `sorry` + `@residual` を残した** (N17 / N18。分類は `plan:`)。前 relay は
   `sorry` も `@residual` も置かずに終わっており (SoT = 前 relay proof-log §8「ボトルネックではなかったもの」)、
   ⟹ ⚠⚠ **`@[entry_point]` の本数は `sorry` の有無を 1 文字も表さない**ので、前 relay の層 3 欄の書き方は
   **そのままでは使えない**。
3. **対象ファイルの列挙を更新しないと新設分が落ちる** — 前 relay の再導出コマンド (proof-log §10) は

(ii) `sorry` と `@residual` の本数と分類 / (iii) type-check done と proof done の区別**の
