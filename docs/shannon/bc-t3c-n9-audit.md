## 5. 標的 5 — §2.5 の `ε` の伝播係数 (⚠⚠ 親 plan が「未計算」と名指しした量) — **試行 10 系統、6 系統が落ち、4 系統が成立 (訂正 1–4)**

### 結果 (値) — **`λ1+λ2` は正しく、しかも錐の中では厳密 (緩くない)。`λ0` は入らない**

`g_{K+[0,ε]²}(a,b) = g_K(a,b) + ε(a+b)` なので、(D2) の `(a,b)` に対する伝播係数は `a + b` である。

| 枝 | `a + b` | `λ1+λ2` との関係 |
|---|---|---|
| `λ0 ≤ max(λ1,λ2)` | `λ1 + λ2` | **等しい** |
| `max(λ1,λ2) ≤ λ0 ≤ λ1+λ2` | `λ0 + (λ1+λ2−λ0) = λ1+λ2` | **等しい** |
| `λ0 ≥ λ1+λ2` | `λ0` | ⚠ **厳密に大きい** |

⟹ **錐 `0 < λ0 < λ1+λ2` の内側では `a+b = λ1+λ2` が恒等的に立つ** (`G1`、残差 `0.000e+00`) ⟹ **`λ0` は入らない**。

支持関数のレベルで、cap 込みの `D(K_β+[0,ε]²)` は `D_β + {0}×[0,ε]²` を**1 度もはみ出さない**

(`G9`、残差 `0.000e+00`) ⟹ **§4.1 の連鎖に隠れた残余幅は無い**。

### ⚠⚠ **訂正 1 (成立)** — §2.1 の「`R0 ≤ 2C` は冗長」は `ε` 膨張後には**偽**

N9 §2.1 は「`R0 ≤ 2C` の条項は (D1) の中では**冗長**である (2 本の天井から `R0 ≤ 2r(σ) − σ ≤ 2C` が出る)」と書く。
**`D` / `D_β` については真である** (`2r_β(σ) − σ = M(β) ≤ 2C`)。**`ε` で膨らませた `D(K_β+[0,ε]²)` については偽である**:

```

  (R0+R1, R2) = (2C+ε, 0) ∈ K_β + [0,ε]²        ← (2C,0) ∈ K_β に (ε,0) を足したもの
  (R1, R0+R2) = (0, 2C+ε) ∈ K_β + [0,ε]²        ← 鏡映の角 (0,2C) に (0,ε) を足したもの
```
