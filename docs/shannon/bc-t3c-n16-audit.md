## 2. 凍結の確認 (⭐⭐ 機械の実測値)

**結論 = 凍結は守られている。** ⚠ ただし**親 plan / ブリーフが指定した確認コマンドそのものは偽陽性を出す**。

```
# 起票時 (d9398597) の §0 冒頭から §2 直前まで
git show d9398597:docs/shannon/bc-t3c-n16-uv-gate.md \
  | awk '/^## 0\./{f=1} /^## 2\./{f=0} f' | grep -v '以下 §2 以降は未記入である'  -> md5 12266a2c341c00137a8cd61a5d186351  (154 行)
# 現行 (262d43d7) の同区間
awk '/^## 0\./{f=1} /^## 2\./{f=0} f' docs/shannon/bc-t3c-n16-uv-gate.md \
  | grep -v '以下 §2 以降は未記入である'                                          -> md5 807ce1ad6ebe5d80c2c51e4d0a79bcba  (153 行)
```

⚠ **md5 は一致しない**。しかし `diff` は **`154d153 <` (末尾の空行 1 本) の 1 か所だけ**である:
起票版ではプレースホルダ行 `⏳ **以下 §2 以降は未記入である。**` の**直後の空行**が区間に入っており、
`grep -v` はその行しか落とさないので空行が残る。⟹ **これはコマンドの副作用であって書き換えではない**。

**空行を落として正規化すると完全一致する**:

```
... | grep -v '^[[:space:]]*$'   ->  両者とも md5 7284657df169569e33b3cba072d2c8b8  (121 行、diff 空)
```

⭐ **さらに機械で裏を取った** — 起票 commit と実行 commit の間でこのファイルから**削除された行は 3 本だけ**であり、
3 本とも **§0 / §1 の外側**である:

```
git diff d9398597 262d43d7 -- docs/shannon/bc-t3c-n16-uv-gate.md | grep '^-' | grep -v '^---'
  -> "> ⏳ **未実行 — 判定はまだ 1 つも出ていない**。"   (冒頭ブロック = 凍結対象外)
  -> "⏳ **以下 §2 以降は未記入である。**"               (プレースホルダ)
  -> "## 2. （実行 leg がここから書く）"                 (プレースホルダ見出し)
```

⟹ **§0 / §1 は 1 文字も動いていない**。

**区間の外 (冒頭ブロック) の書き換えも見た** — 差し替わったのは「未実行」→「実行済 + 判定 + 検証器の本数」の
**状態行だけ**であり、**leg 冒頭宣言 (側 / 動かすもの) は 1 文字も動いていない**。
⟹ **見立てを事後に有利にする書き換えは無い**。

> ⚠ **プロセスへの申し送り**: ブリーフが指定した md5 比較コマンドは**構造的に偽陽性を出す**
> (プレースホルダ行を消すと空行が残るため)。次回以降は `grep -v '^[[:space:]]*$'` を挟むか、
> `git diff` の削除行走査を正とすること。

  ⭐ **ただし `V6` / `V7` / `V13` は (α) の周辺に材料を 1 つ足す** — **同一著者・同一題名の 1 本の論文が、
  2 版のあいだで `O(T)` の witness を独立版 (`sumofbc.txt:55`) から一般版 (`glnsum.txt:61`) へ変えている**。
  ⟹ **文献側でも版が揺れている**という事実である。
  ⚠⚠ **これは (α) の等号の証拠ではない** — 著者が版を差し替えた理由は書かれておらず、
  「等号だから差し替えた」とも「差し替えたので別物になった」とも読める。
  ⟹ 台帳へ写すなら**この事実だけ**を足し、「(α) は依然未確認」を落とさないこと。
